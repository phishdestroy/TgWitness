# Telegram · در چند دقیقه شروع کنید

Canonical page: https://phishdestroy.github.io/TgWitness/fa/docs/start/

اول کمی در دمو بگردید، بعد حساب خودتان را وصل کنید.

## بدون حساب کاربری نگاهی بیندازید

پروژه را بگیرید، **Python 3.11 یا بالاتر** داشته باشید، دمو را اجرا کنید. بقیه را راه‌انداز تنظیم می‌کند.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### ویندوز

```
.\scripts\Demo.cmd
```

### لینوکس / مک‌اواس

```
sh start.sh --demo
```

یک فضای کاری با پیام‌های ساختگی در مرورگر باز می‌شود. گفتگویی را باز کنید، یک ویرایش را مقایسه کنید، به یک خروجی نگاه کنید. Telegram دخالتی ندارد.

![نمای گفتگو با تلگرام‌ویجت همراه با پیام‌های نمونه](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

یک فضای کاری نمونه. دفترچهٔ شما به‌طور جداگانه آغاز می‌شود.

## فضای کاری خود را راه‌اندازی کنید

دمو را ببندید، سپس:

### ویندوز

```
.\Start.cmd
```

### لینوکس / مک‌اواس

```
sh start.sh
```

آدرسی را که راه‌انداز نشان می‌دهد باز کنید و **توکن دسترسی پنل** را از فایلی که نام می‌برد بچسبانید. این برای TgWitness است، نه Telegram.

## اولین پیام خود را ضبط کنید

1. [یک حساب تلگرام اختصاصی را متصل کنید.](https://phishdestroy.github.io/TgWitness/fa/docs/accounts/)
2. یک گروه یا کانال انتخاب کنید و مشاهده را شروع کنید.
3. در گروه آزمایشی پیامی بفرستید و ببینید در ژورنال ظاهر می‌شود.

برای نصب روی سرور، بخش [«نگه داشتن آن در حال اجرا» را](https://phishdestroy.github.io/TgWitness/fa/docs/server/) دنبال کنید.
