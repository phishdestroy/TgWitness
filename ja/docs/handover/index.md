# 共有用コピーを作成してください

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/handover/

必要なものだけを共有し、原本には手を付けません。

引き渡しは別の署名付き抽出です：チャットと人物を選び、身元や本文を隠し、ファイルとチームのメモを選びます。マニフェストに、残したもの、削ったもの、除いたものが記録されます。

## 受信者向けの抜粋を作成する

1. **エクスポート → 引き渡し用抽出**：目的を書き、チャットと期間を選び、名前を出す人物が必要なら**選択したチャットの人物を読み込む**を使います。
2. それ以外の人：仮名、除外、または記録どおり。本文とファイルは別々のスイッチで、電話番号とメールはマスクできます。
3. Case Board：なし、ブックマークとスライス、またはコメント付きのカード。チームの名前は別名に置き換えられます。
4. **引き渡し用抽出をダウンロード**し、開いて検証し、送る前に目を通します。

## 各操作を組み合わせて使用してください

| 制御 | 翻訳文への影響 |
| --- | --- |
| 人物 | 選んだ人物は名前のまま、他の人は仮名になるか除外されます。 |
| テキスト | すべての本文、選んだ人物とあなたのアカウントの本文のみ、またはなし。 |
| ファイル | 選んだ人物とあなたのアカウントのファイル、表示されているすべてのファイル、またはなし。 |
| ケースボード | なし、ブックマークとスライス、または議論付きのカード。 |

本文とファイルも読んでください：仮名にしても、メッセージや添付ファイルの中に書かれた名前は消えません。選んだファイルが見つからない場合は、復元するか添付ファイルを除外してください。

## 翻訳文は、独立して検証可能であるようにしてください。

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

元のアーカイブとチェックポイントは自分で保管してください。相手はワークスペース全体を受け取らなくても自分のコピーを検証できます。デザイン：[Report studio](https://phishdestroy.github.io/TgWitness/ja/docs/reports/)。信頼できる照合先：[エクスポートの検証](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)。
