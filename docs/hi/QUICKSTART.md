# TgWitness: त्वरित शुरुआत

TgWitness एक स्वतंत्र एप्लिकेशन है, जिससे आप उन Telegram समूहों और चैनलों का निरीक्षण करते हैं
जिन तक आपके खातों की पहुँच है। यह अपनी अलग डेटा डायरेक्टरी के साथ स्थानीय रूप से चलता है।

**पहली बार आए हैं?** खाता कनेक्ट करने से पहले [डेमो देखें](#explore-the-interface)।
प्रॉक्सी, गवाह, निर्यात या सर्वर सेटअप के लिए [गाइड चुनें](../README.md)।
[GitHub Actions कैप्चर](../SEALED-ACTIONS.md) (प्रीव्यू) स्थानीय इंस्टॉलेशन के बजाय आपके अपने
GitHub फ़ोर्क में कैप्चर चलाता है।

<a name="install-and-start"></a>

## इंस्टॉल करें और शुरू करें

चरण-दर-चरण इंस्टॉलर में अपना Python शामिल है, और यह इंस्टॉल करने से पहले पैकेजों के हैश और रिलीज़
के हस्ताक्षर जाँचता है। इसे दोबारा चलाने पर मौजूदा इंस्टॉलेशन अपडेट हो जाता है।

**Linux / macOS:**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**Windows (PowerShell या Command Prompt):**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

Ubuntu सर्वर पर बैकग्राउंड सेवा इंस्टॉल करने के लिए इसे root के रूप में चलाएँ; डेस्कटॉप पर अपने
सामान्य उपयोगकर्ता के रूप में चलाएँ। Ubuntu पर इंस्टॉलर पैनल का पता और एक्सेस कुंजी दिखाता है;
macOS और Windows पर स्थानीय पैनल आपके ब्राउज़र में खुल जाता है। नीचे **Telegram जोड़ें** से आगे बढ़ें।
[इंस्टॉल, सत्यापन और अपडेट](../INSTALLATION.md) में सर्वर एक्सेस के विकल्प, चलाने से पहले स्क्रिप्ट
की जाँच, अपडेट और हटाने का तरीका बताया गया है।

### अन्य तरीके

GitHub रिलीज़, सोर्स कोड और Docker इंस्टॉलर के विकल्प हैं। पोर्टेबल डाउनलोड रिलीज़ बिल्ड
प्रकाशित होने के बाद उपलब्ध होते हैं:

| होस्ट | कुछ भी इंस्टॉल किए बिना | सोर्स से: Python 3.11+ | Docker: Compose 2.20+ के साथ Engine/Desktop |
| --- | --- | --- | --- |
| Windows | GitHub Releases से `TgWitness-<version>-windows-amd64-portable.zip` निकालें, `TgWitness.cmd` पर डबल-क्लिक करें | `Start.cmd` पर डबल-क्लिक करें | `scripts\Docker.cmd` पर डबल-क्लिक करें |
| Linux / macOS | — | `sh start.sh` | `sh scripts/docker-start.sh` |

सोर्स वाले तरीकों के लिए [मौजूदा `main` डाउनलोड करके निकालें](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip)
या रिपॉज़िटरी क्लोन करें:

```sh
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

अगर कोई उपयुक्त Python नहीं मिलता, तो `Start.cmd` आपके Windows उपयोगकर्ता के लिए Python 3.12
इंस्टॉल करने की पेशकश करता है (winget से, या python.org के हस्ताक्षरित इंस्टॉलर से)। Python न होने पर
`start.sh` आपके Linux डिस्ट्रीब्यूशन या macOS के लिए इंस्टॉल करने का सटीक कमांड दिखाता है।
सोर्स से पहली बार चलाने पर `.venv` बनता है और डिपेंडेंसी अपने-आप इंस्टॉल हो जाती हैं।

Docker एप्लिकेशन को बिल्ड करके बैकग्राउंड में शुरू करता है; होस्ट पर Python की ज़रूरत नहीं है।
कंटेनर के स्वस्थ स्थिति में आने पर `scripts\Docker.cmd` और `scripts/docker-start.sh` पैनल का पता
और टोकन दिखाते हैं। हर समर्थित होस्ट पर इनके समकक्ष Docker कमांड ये हैं:

```sh
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

**http://127.0.0.1:8787** खोलें। Docker हेल्पर या दूसरे Docker कमांड द्वारा दिखाया गया टोकन
इस्तेमाल करें, या पोर्टेबल या सोर्स इंस्टॉलेशन के लिए **data/live/panel-token.txt** पढ़ें। नीचे
**Telegram जोड़ें** से आगे बढ़ें। नेटिव और Docker इंस्टॉलेशन अलग-अलग स्टोरेज इस्तेमाल करते हैं;
Docker शुरू करने से मौजूदा नेटिव जर्नल आयात नहीं होता।

सर्वर के लिए [डिप्लॉयमेंट गाइड](DEPLOYMENT.md) में स्वचालित HTTPS, रीस्टार्ट, प्रकाशित इमेज,
अपडेट और बैकअप शामिल हैं।

<a name="explore-the-interface"></a>

## इंटरफ़ेस देखें

1. पोर्टेबल पैकेज में **TgWitness-Demo.cmd**, Windows सोर्स फ़ोल्डर में **scripts\Demo.cmd**, या
   Linux/macOS पर `sh start.sh --demo` चलाएँ। सोर्स से चलाने पर पहले `.venv` बनता है
   और डिपेंडेंसी इंस्टॉल होती हैं।
2. **http://127.0.0.1:8787** खोलें।
3. स्थानीय डेमो नमूना जर्नल अपने-आप खोल देता है। सीधे स्थानीय एक्सेस के लिए टोकन कॉपी करने की ज़रूरत नहीं है।

डेमो संदेश काल्पनिक हैं। डेमो मोड किसी असली Telegram खाते से कनेक्ट नहीं कर सकता।

## Telegram जोड़ें

> [!WARNING]
> **इसी काम के लिए अलग रखे गए खाते इस्तेमाल करें।** क्लाइंट कोई भी हो, Telegram अनुरोधों की जिस
> मात्रा को अत्यधिक मानता है, उसके लिए वह खातों को प्रतिबंधित या स्थायी रूप से बैन कर सकता है।
> निजी या मूल्यवान खातों के बजाय निरीक्षण के लिए तैयार किए गए खाते कनेक्ट करें, और API ID / हैश
> भी ऐसे ही अलग रखे गए खाते पर बनाएँ।

1. अगर नेटिव डेमो चल रहा है, तो उसे बंद करके **Start.cmd** या `sh start.sh` चलाएँ।
   अन्यथा ऊपर शुरू किए गए लाइव इंस्टॉलेशन को चलने दें।
2. साइन इन करने के लिए पैनल टोकन इस्तेमाल करें। नए वर्कस्पेस में [पहला सेटअप](../SETTINGS.md) खुलता है।
   **बस डाउनलोड करें**, **चैट पर नज़र रखें** या **मामले के लिए सबूत** चुनें।
3. कनेक्शन जाँच का नतीजा देखें। ज़रूरत हो तो अपना प्रॉक्सी कॉन्फ़िगर करें; कनेक्शन
   सेटिंग्स सेटअप के बाद भी उपलब्ध रहती हैं।
4. **Telegram जोड़ें** स्क्रीन पर QR कोड स्कैन करें या अपना फ़ोन नंबर दर्ज करें। फ़ाइल आयात
   और पूरी ऑथराइज़ेशन कुंजी **साइन इन के अन्य तरीके** में हैं।
   माँगे जाने पर Telegram में पुष्टि, कोड और दो-चरणीय पासवर्ड पूरा करें।
5. दिखाया गया खाता जाँचें, चैट चुनें और अपनी सेटिंग्स की समीक्षा करें। अंतिम स्क्रीन से सेटअप
   पूरा करें। **बस डाउनलोड करें** के लिए **निर्यात शुरू करें** एक बार का निर्यात शुरू करता है और
   उसकी प्रगति दिखाने के लिए निर्यात अनुभाग खोलता है; इससे लगातार निरीक्षण चालू नहीं होता।

सेटअप के बाद **चैट्स → चुनें** से चुनी गई चैट बदली जाती हैं। **सेटिंग्स** संग्रह और फ़ाइलों
को नियंत्रित करती हैं; **अधिक उपकरण → स्रोत** मानक या विशेषज्ञ स्तर पर स्रोतों की विस्तृत सूची
देता है। [पैनल गाइड](../PANEL.md) छह मुख्य अनुभागों और उनके संदर्भ के अनुसार बदलने वाले नियंत्रणों
का वर्णन करती है।

**एपीआई आईडी + हैश** वैकल्पिक है: वर्कस्पेस अपनी सहेजी या आयात की गई जोड़ी इस्तेमाल करता है,
या बिल्ट-इन पूल की कोई काम करने वाली जोड़ी। अपना ऐप इस्तेमाल करने के लिए एपीआई आईडी फ़ील्ड में
एक `API ID:API Hash` जोड़ी पेस्ट करें। **ऑथ कुंजी** के लिए सभी 512 हेक्साडेसिमल
वर्ण पेस्ट करें और दिया गया डीसी आईडी चुनें। उपयोगकर्ता आईडी वैकल्पिक है और दर्ज करने पर जाँची जाती है।

API क्रेडेंशियल आपके एप्लिकेशन की पहचान करते हैं; वे अपने-आप किसी खाते को अधिकृत नहीं
करते। निजी समूहों के लिए सार्वजनिक यूज़रनेम ज़रूरी नहीं है, लेकिन आपके खाते की उन तक पहुँच होनी चाहिए।

मौजूदा खातों के लिए [खाते और सेशन फ़ॉर्मैट](../ACCOUNTS.md) देखें: पैनल Telethon
StringSession, Telethon/Pyrogram SQLite, एक खाते वाला TData ZIP और समर्थित खाता JSON स्वीकार
करता है। सेशन और उसकी साथी JSON फ़ाइल एक साथ चुनें और **खाता कनेक्ट करें** दबाएँ।
QR लॉगिन भी इन्हीं वैकल्पिक API सेटिंग्स के साथ उपलब्ध है। TDLib, बॉट सेशन और CSV/JSON
खाता सूचियाँ समर्थित नहीं हैं।

कई खातों के लिए **खाते → खाते आयात करें** इस्तेमाल करें और उनकी समर्थित सेशन फ़ाइलें चुनें।
साथी JSON फ़ाइलें फ़ाइल के मूल नाम (बेसनेम) से जोड़ी जाती हैं; हर आयात किए गए खाते को अपना अलग
वर्कस्पेस मिलता है। [बल्क आयात और खाता समूह](../ACCOUNTS.md#bulk-import-and-account-groups) देखें।

एक और खाता जोड़ने के लिए खाता चयनकर्ता के बगल में **+** दबाएँ या
**खाते → खाता जोड़ें** इस्तेमाल करें। हर वर्कस्पेस के सेशन, जर्नल, कुंजियाँ, स्रोत और कतारें
अलग होती हैं। व्यू बदलने पर दूसरे संग्रहकर्ता चलते रहते हैं।
इस इंस्टॉलेशन में एक ही Telegram खाता दो वर्कस्पेस को असाइन नहीं किया जा सकता।
वर्कस्पेस की कोई तय संख्या नहीं है; वे एक ही प्रोसेस साझा करते हैं, इसलिए क्षमता मशीन पर निर्भर करती है।

लाइव पैनल टोकन आपके Telegram ऑथराइज़ेशन और सहेजी गई सामग्री तक पहुँच की सुरक्षा करता है;
यह Telegram API क्रेडेंशियल से अलग है। अपने-आप प्रवेश सिर्फ़ उस स्थानीय डेमो को मिलता है जिसे
स्पष्ट रूप से शुरू किया गया हो और जिसे सीधे खोला गया हो। रिमोट या प्रॉक्सी के ज़रिए खोला गया डेमो
फिर भी `data/demo/panel-token.txt` इस्तेमाल करता है।

## समीक्षा और निर्यात

- **जर्नल:** स्रोत और इवेंट के प्रकार के अनुसार निरीक्षण रिकॉर्ड खोजें और फ़िल्टर करें।
- किसी इवेंट को चुनकर उसका मूल रिकॉर्ड, एट्रिब्यूशन और सहेजे गए संस्करण देखें।
- संपादन के विवरण में पहले/बाद की उपलब्ध सामग्री दिखती है। हटाने के विवरण में आख़िरी बार
  कैप्चर की गई सामग्री दिखती है, यदि कोई हो; अज्ञात कर्ता अज्ञात ही रहता है।
- **निर्यात:** हस्ताक्षरित ZIP, JSONL, CSV और ऑफ़लाइन HTML।
- **पूर्ण चैट निर्यात** (**चैट्स → चैट निर्यात**, या **निर्यात → एक चैट कैप्चर या निर्यात करें**):
  किसी एक चैट का पूरा दिखाई देने वाला इतिहास हस्ताक्षरित बंडल के रूप में डाउनलोड करें, जिसमें
  `chat.json` (Telegram निर्यात की शैली में) और पढ़ने योग्य `chat.html` होते हैं। निजी चैट भी
  काम करती हैं, बशर्ते खाता उनका सदस्य हो। यह वर्तमान स्थिति का स्नैपशॉट है, हटाए गए या पहले
  संपादित संदेशों का पुनर्निर्माण नहीं। किसी प्रति का सत्यापन
  `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256` से करें।
- **चेकपॉइंट सहेजें:** हस्ताक्षरित जर्नल सीमा को संग्रहकर्ता से बाहर सुरक्षित रखें।
- **हस्ताक्षरित रन रसीद डाउनलोड करें:** संग्रहकर्ता के प्रोग्राम/संस्करण का रिकॉर्ड सुरक्षित रखें।
- **टाइमस्टैम्प अनुरोध तैयार करें:** टाइमस्टैम्प अथॉरिटी के लिए ऑफ़लाइन अनुरोध तैयार करें;
  जवाब पाने और उसे सत्यापित करने के लिए [TIMESTAMP.md](../TIMESTAMP.md) का पालन करें।
- **जर्नल सत्यापित करें:** इवेंट के हस्ताक्षर और चेन लिंक जाँचें। ZIP निर्यात मीडिया की भी जाँच करता है।

समर्थित ब्राउज़र बड़े निर्यात सीधे चुनी गई फ़ाइल में सहेजते हैं। अन्य ब्राउज़र अधिकतम
128 MiB बफ़र करते हैं। सर्वर चलते रहने के दौरान स्ट्रीमिंग CLI पूरे जवाब को बफ़र किए बिना
बड़े डाउनलोड संभव बनाता है:

```sh
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

किसी दूसरे वर्कस्पेस के लिए **निर्यात → वर्कस्पेस आईडी** से लेकर `--profile ID` जोड़ें।
रिमोट सर्वर के लिए `--url https://your-server` जोड़ें। डिफ़ॉल्ट ट्रांसफ़र सीमा
5 GiB है; `--max-mib` इसे बदलता है। हस्ताक्षरित ZIP सामग्री के सत्यापन के लिए डिफ़ॉल्ट रूप से
4 GiB की अलग असंपीड़ित सीमा है (**अधिक उपकरण → पैरामीटर** इसे बढ़ाता है; ऐसे आर्काइव
`verify.py --max-gib N` से सत्यापित करें)। आर्काइव का सत्यापन वेरिफ़ायर की विश्वसनीय प्रति,
स्वतंत्र रूप से सुरक्षित रखे गए कुंजी फ़िंगरप्रिंट और — सबूत के लिए न्यूनतम आवश्यकता के रूप में —
टाइमस्टैम्प अथॉरिटी के रूट प्रमाणपत्र (`--tsa-ca`) से करें।

## इंस्टॉलेशन जाँचें

```sh
python start.py --setup-only
python start.py --check
python start.py --check --json
```

`--check` स्थानीय डिपेंडेंसी, हस्ताक्षर समर्थन, स्टोरेज, कुंजी कॉन्फ़िगरेशन और लिसनिंग पते की
जाँच करता है। यह न कुछ इंस्टॉल करता है, न Telegram से कनेक्ट होता है। पोर्ट व्यस्त होने का मतलब
हो सकता है कि कोई दूसरा इंस्टेंस चल रहा है। कोई दूसरा `--port` इस्तेमाल करें या पहले उसे बंद करें।

लॉन्चर `.venv` में इंस्टॉल करता है। सहायक `python -m tgwitness...` कमांड Windows पर
`.venv\Scripts\python.exe` और Linux/macOS पर `.venv/bin/python` से ही चलाने चाहिए,
जब तक वह एनवायरनमेंट पहले से सक्रिय न हो।

## सेशन, सुरक्षा और संचालन

बंद और सुसंगत Telethon SQLite `.session` को
`python -m tgwitness.sessions account.session --out account.tgwitness-session` से स्थानीय रूप से
बदला जा सकता है और फिर **अधिक उपकरण → खाता → फ़ाइलें** में लोड किया जा सकता है। सीधा फ़ाइल आयात
और QR लॉगिन भी उपलब्ध हैं। लॉगिन फ़ॉर्मैट, SOCKS5, HTTP CONNECT, MTProxy और बाहरी मास्टर
कुंजियों के लिए [CONNECTION-SECURITY.md](../CONNECTION-SECURITY.md) देखें।

**निरीक्षण विराम** संग्रह रोक देता है। **लॉक** केवल ब्राउज़र एक्सेस बंद करता है।
टैब बंद करने पर संग्रहकर्ता प्रोसेस चलता रहता है। प्रोसेस रोकने से संग्रह बाधित होता है;
इतिहास का स्नैपशॉट छूटे हुए सभी संपादनों या हटाए गए संदेशों का पुनर्निर्माण नहीं कर सकता।
इवेंट नीतियों, अटैचमेंट कतारों, खातों के अलगाव और रीस्टार्ट के व्यवहार के लिए
[संग्रह कैसे काम करता है](../COLLECTION.md) देखें।

सेशन और गोपनीय जानकारी एन्क्रिप्टेड रहती है। संदेशों की सामग्री, मीडिया और निर्यात के लिए
एन्क्रिप्टेड डिस्क या वॉल्यूम ज़रूरी है। जर्नल के हस्ताक्षरों को किसी विश्वसनीय कुंजी से सत्यापित करें और चेकपॉइंट अलग से रखें।
चुने गए संग्रह मोड के लिए कैप्चर रिकॉर्ड, बाहरी समय रसीदों और एनवायरनमेंट अटेस्टेशन की समीक्षा करें।
