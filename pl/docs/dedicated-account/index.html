Dedykowane konto

Proszę oddzielić gromadzenie danych od prywatnych rozmów. Nawet oddzielne konto może podlegać ograniczeniom serwisu Telegram.

Przed nawiązaniem połączenia

  • Proszę zachować kontrolę nad numerem telefonu używanym do rejestracji.
  • Włącz weryfikację dwuetapową i dodaj adres e-mail do odzyskiwania dostępu.
  • Proszę sprawdzić aktywne sesje w ustawieniach Telegrama → Urządzenia.

Dane uwierzytelniające API

Aplikację identyfikują identyfikator API oraz skrót. Państwa autoryzacja w serwisie Telegram jest odrębna.

W przypadku procesu przechwytywania danych na GitHubie prosimy o użycie własnego identyfikatora API oraz skrótu.

Utwórz dane uwierzytelniające do API

Zaimportowane sesje

Nie należy uruchamiać tego samego importowanego uprawnienia w dwóch klientach jednocześnie. Telegram może je unieważnić, wyświetlając komunikat AUTH_KEY_DUPLICATED. W celu równoległego korzystania należy utworzyć oddzielne konto za pomocą numeru telefonu lub kodu QR.

Proszę połączyć konto

  1. Proszę otworzyć panel i wybrać logowanie za pomocą telefonu lub kodu QR.
  2. Przeprowadź pełną weryfikację danych z Telegrama i wybierz źródła.
  3. Rozpocznij gromadzenie danych i sprawdź, czy pojawiają się nowe wiadomości.

Przewodnik po łączeniu kont

Numery telefonów

Proszę wybrać numer, który będzie Pan/Pani w stanie zachować. Otrzymanie jednego kodu logowania nie gwarantuje możliwości odzyskania konta w przyszłości.
