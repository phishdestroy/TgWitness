# חקור בכל הצ'אטים

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/cases/

תיק שלם על פני ערוצים, קבוצות, צ'אטים פרטיים ובוטים: אספו, חברו את הנקודות, בנו מחדש את ציר הזמן, מסרו.

אירוע מומצא אחד, מהתחלה ועד הסוף. איסוף, חיפוש ופרופילי אנשים מוצאים את הרשומות, [Case Board](https://phishdestroy.github.io/TgWitness/he/docs/case-board/) מארגן אותן, [Report studio](https://phishdestroy.github.io/TgWitness/he/docs/reports/) מציג אותן.

מקרה שטופל / שינוי יעד התשלום

### אירוע אחד. ארבע שיחות. עקבות שיש לשחזר.

פוסט בערוץ מפנה לבוט. קבוצה מדברת על קישור תשלום חדש והבוט מציג אותו. הפוסט נערך, צ'אט פרטי חוזר על הקישור, הודעה בקבוצה נעלמת.

מי פרסם כל גרסה?היכן הופיע הקישור?איזה קובץ נשמר?מה השתנה, ומתי?

טעינת היסטוריה, AI, MCP, OCR ו-webhooks: [עבודה עם הארכיון](https://phishdestroy.github.io/TgWitness/he/docs/archive/).

## 1. להבטיח כיסוי של כל החשבון

היקף של חשבון שלם רק בחשבון ייעודי. חשבון ראשי מקבל צ'אטים נבחרים או תיקייה.

1. [חברו את החשבון](https://phishdestroy.github.io/TgWitness/he/docs/accounts/) בסביבת עבודה משלו. רשמו את מספר התיק, מזהה החשבון, סביבת העבודה וטביעת האצבע של המפתח.
2. **מקורות ← היקף המעקב ← מצב חקירה**: **החשבון כולו**, כל ארבעת סוגי המקורות, **פעולות עצמיות**. לכל צ'אט חדש נשמרים הפרופיל ו-**200 ההודעות הגלויות** האחרונות. **שמירת היקף** ואשרו.
3. **טעינת צ'אטים** והשוו לרשימת הצ'אטים של החשבון. המגבלה היא 1,000 שיחות (עד 20,000 ב-**פרמטרים ← צ'אטים שנקראים מרשימת החשבון**); צ'אטים מעבר לה מופיעים כשהם נעשים פעילים.
4. **הגדרות הקלטה** ← **כל הפעילות הגלויה**, בדקו מגבלות קבצים מצורפים ומקום בדיסק. התחילו, ואז בדקו עם הודעה, עריכה ומחיקה.

"החשבון כולו" אומר כל צ'אט שהחשבון הזה יכול לפתוח, פחות החרגות. בלי צ'אטים סודיים. צ'אטים חדשים מצטרפים כשהם מופיעים; היסטוריה ישנה לא יורדת אוטומטית.

## 2. איסוף היסטוריה ושמירת הקבצים

צרו אוסף ב-Case Board וסמנו מה שחשוב. נהלו רישום מקורות: מזהה צ'אט, כותרת, חשבון, תפקיד, תחילת לכידה חיה, תוצאת היסטוריה, תוצאת מדיה, פערים.

| נדרש | פעולה בלוח הבקרה | מה הוא מספק |
| --- | --- | --- |
| היסטוריית הצ'אטים המופעלים | מקורות → טען את ההיסטוריה המלאה | הודעות קודמות זמינות נכנסות ליומן סביבת העבודה, עם אפשרות להשהיה/המשך ודוח התקדמות חתום. [מדריך היסטוריה](https://phishdestroy.github.io/TgWitness/he/docs/reference/history/). |
| הקשר השיחה הקיים ביומן | מקורות → הגדרות הקלטה → תמונת מצב של ההיסטוריה | הודעות אחרונות כרשומות חתומות. 500 כברירת מחדל, עד 10,000 ב-**פרמטרים ← תמונת ההיסטוריה הגדולה ביותר**. |
| היסטוריית הצ'אט המלאה הנראית כרגע | ייצוא צ'אט מלא → ייצוא צ'אט מלא, או צ'אטים → ייצוא צ'אט | חבילה חתומה נפרדת עם `chat.json` ו-`chat.html`, אחת לכל צ'אט. |
| הקשר שבו מופיע צ'אט חדש | היקף הניטור → כאשר מופיע צ'אט או בוט חדש | הפרופיל שלו ועד 1,000 הודעות אחרונות (200 במצב חקירה). לא חל על צ'אטים קיימים. |
| נפח הקובץ המצורף | הורדת קבצים מצורפים גלויים + מגבלות לפי סוג | חפשו `media.saved` עם SHA-256 וגודל. בתור, דולג או נכשל אומר שלא נשמר. |

ייצוא צ'אט לא נכנס ליומן או לפרופילי אנשים. כדי לחפש היסטוריה ישנה בתוך TgWitness, השתמשו ב-**טעינת היסטוריה מלאה** או בתמונות מצב.

כאן: הערוץ, הקבוצה, הצ'אט עם הבוט והצ'אט הפרטי, ועוד קובץ החשבונית והגיבוב שלו. מה שנמחק לפני הלכידה אבד.

## 3. עקבו אחר התפתחות השיחה ופעולותיכם

השאירו את זה רץ. סמנו בכוכב צ'אטים חמים כעדיפות, כווננו בדיקות חוזרות ב-**הגדרות הקלטה ← בדיקה חוזרת**, ועקבו אחרי `recheck.completed`, FloodWait ותוצאות מדיה.

**צ'אטים ← פרופיל ← שמירת פרופיל עכשיו** שומר את תיאור הצ'אט, פקודות הבוט ומטא-נתונים נוספים.

**מעקב אחר בוט או הזמנה כחלק מהתיק**

1. **צ'אטים ← פתיחת קישור Telegram**, שמרו קודם את התצוגה המקדימה. הקישור והתצוגה המקדימה הופכים לרשומות חתומות.
2. אם צריך, **הצטרפות / פתיחה ומעקב** מצטרף לצ'אט או מפעיל את הבוט עם פרמטר ההפעלה שלו.
3. כדי לתעד פעולה, השיבו או השתמשו ב-**לחיצה על כפתור** מהלוח. מקבלים `interaction.requested` ו-`interaction.result` עם תשובת הבוט.

אלה פעולות אמיתיות. כפתורים שנלחצו באפליקציה אחרת לא נראים, רק תשובת הבוט. בלי אפליקציות ווב, תשלומים או טלפון/מיקום.

## 4. עקבו אחר אנשים, קישורים וקבצים בצ'אטים

1. **יומן**, **כל המקורות**, חפשו ביטוי, דומיין או שם משתמש. פתחו תוצאות ושלחו אותן **ללוח**.
2. **צ'אטים ← אנשים ← הפעלת פרופילים**, בחרו אדם: היסטוריית שמות, תגובות, פעילות, **מופיע גם ב…**, קישורים, ארנקים, טלפונים. פתחו את הרשומות המצוטטות.
3. עקבו אחרי אותו מזהה משתמש מספרי בצ'אטים אחרים. שם, ארנק או תמונת פרופיל תואמים הם רמז, לא הוכחה.
4. השוו גיבובי קבצים. אותו SHA-256 = אותם בתים. מי שיתף אותם זו שאלה אחרת.

## 5. לשחזר את הרצף ולסמן את החוסרים

גרסאות ב-**צ'אטים**, ואז **יומן** עם **כל המקורות** + **עריכות**, **מחיקות**, **כיסוי**. שימו את שני הזמנים בציר הזמן: התאריך של Telegram ומתי זה נצפה.

   מטא-הנתונים של המקלדת שנשמרו מכילים את הקישור.

זמני תצפית והפניות להמחשה. בין רשומות אלה מופיעים רישומים נוספים ביומן.

סדר היומן הוא סדר ההגעה, לא בהכרח סדר ההתרחשות. הפרידו בין רשומות חיות, תמונות מצב, הודעות ששוחזרו, מחיקות ו"חסר בבדיקה חוזרת", וסמנו כל פער כלא ידוע.

## 6. הרחבת הטיפול למקרים של חשבונות איסוף אחרים

סביבת עבודה אחת לכל חשבון, אותם שלבים. רשמו את התפקיד וטביעת האצבע של כל אחד. מספרי הודעות הם לפי חשבון, אז תמיד ציינו איזו סביבת עבודה ואיזה צ'אט.

[קבוצת חשבונות](https://phishdestroy.github.io/TgWitness/he/docs/groups/) מציגה סטטוס, משתפת הגדרות ומייצאת את כולם יחד, כל אחד עם יומן ומפתח משלו. ציר זמן חוצה חשבונות בונים בהערות.

תיק ארוך? הוסיפו [עד עצמאי](https://phishdestroy.github.io/TgWitness/he/docs/witness/), ובדקו מה כל חשבון באמת תופס.

## 7. מסרו חבילת תיק הניתנת לבדיקה

ZIP חתום מכל סביבת עבודה (תמיד היומן המלא, מסננים לא משנים), ועוד פרופילי אנשים, ייצואי צ'אטים וקבצים.

```
CASE-001/                         # assembled by the analyst
  case-notes.md                   # question, findings, alternative explanations
  sources.csv                     # every chat, role, acquisition result and gap
  timeline.csv                    # account + chat + message + seq + both times
  workspace-A/
    evidence.zip                  # complete signed observation journal
    retained-checkpoint.json
    profiles-operations.json      # separately signed people profiles
    history-channel.zip           # signed current-history export
    history-group.zip
    verification.txt
  workspace-B/                    # separate journal and trusted fingerprint
  witness/                        # retained checks, journal and signed posts
  SHA256SUMS                      # hashes of the delivered files
```

שלחו טביעות אצבע בנפרד. אמתו הכול מול סביבת העבודה שלו:

```
python -m tgwitness.verify evidence.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --checkpoint retained-checkpoint.json
python -m tgwitness.verify profiles-operations.json --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --evidence evidence.zip
python -m tgwitness.verify history-channel.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

שמרו את פלט כלי האימות, המקוריים, הכיסוי ורישום ההעברה עם הממצאים. כתבו את זה ב-Report studio. אם הנמען צריך פחות, הכינו [מסירה מצומצמת](https://phishdestroy.github.io/TgWitness/he/docs/handover/).
