תיעוד / 01

עבוד עם הארכיון

מצא את ההודעה. בדוק את המקור. בנה את התיק.

כלים אלה זמינים בענף הראשי הנוכחי. גרסת התצוגה המקדימה הניידת 0.7.0 קדמה להם; יש להשתמש בבדיקת קוד המקור עבור זרימת עבודה זו.

טען הודעות קודמות

  1. פתחו את מקורות → צ'אטים בהיקף האיסוף, עיינו בצ'אטים המופעלים והתחילו בתצפית.
  2. בחר באפשרות "טען היסטוריה מלאה". ההרצה משתמשת ברשימת המקורות שנבחרה באותו הרגע.
  3. יש להשתמש ב"היסטוריית הפסקות" ו"היסטוריית המשך" לפי הצורך. לאחר הפעלה מחדש, יש לחדש את הפעילות במפורש.
  4. בדקו את התוצאות לכל מקור ואת תור הקבצים המצורפים. שמרו את דוח ההתקדמות החתום יחד עם ייצוא הראיות.

פעולה זו ממלאת את סביבת העבודה בהודעות הזמינות. ייצוא בפורמט HTML/JSON לכל צ'אט הוא פעולה נפרדת. היסטוריה ופרטי שחזור.

חפשו תחילה, ורק אחר כך החליטו לגבי השימוש ב-AI

  1. פתחו את יומן לחיפוש מקומי. בחרו סביבת עבודה והשתמשו במסנני המקור והזמן.
  2. חפשו ביטוי או דומיין. פתחו את הרשומה התואמת ואת הגרסאות השמורות שלה.
  3. לצורך ניתוח באמצעות בינה מלאכותית, המנהל מפעיל ומגדיר ספק בשילובים. פתחו את שאל את הארכיון ובחרו צ'אטים ותקופה. עיינו בנתונים שנשלחו למודל ובטלו את הסימון של קטעים לא רצויים לפני אישור הבקשה.
  4. בדוק את הציטוטים שהוחזרו. שמור את התשובה כדו"ח והוסף את התיקונים או ההערות שלך.

החיפוש מתבצע באופן מקומי ללא שימוש ב-AI. דוחות ניתוחיים שומרים על הפניות למקורות והיסטוריית הגרסאות; הם נפרדים מהיומן החתום. הגדרת הספק ודוחות.

לאן שייך כל אסימון גישה?

הגישה לפאנל מיועדת לאנשים הבוחנים את התיק. למשתמשי MCP ניתנים אסימוני ארכיון נפרדים לקריאה בלבד. מקלט webhook משתמש בסוד HMAC משלו. אף אחד אינו זקוק לקובץ הפעלה של Telegram.

שתף גישה ללוח הבקרה או הגדר לקוח MCP.

הצגת מקורות ומסקנות

יש לשמור את הדוח האנליטי שעבר בדיקה יחד עם קובץ ה-ZIP של הראיות החתומות. הדוח מסביר את פרשנותכם למקורות; קובץ ה-ZIP מאפשר למקבל לבדוק את התיעוד השמור מול טביעת אצבע ונקודת ביקורת מהימנות ועצמאיות.
