# Telegram · ربط حساب

Canonical page: https://phishdestroy.github.io/TgWitness/ar/docs/accounts/

مساحة عمل واحدة = حساب واحد وسجله ومفتاحه.

## اختر طريقة تسجيل الدخول

**الحسابات** ← أضف مساحة عمل ← إعدادات الاتصال. استخدم حسابًا منفصلاً لهذا الغرض.

- **رمز QR:** امسحه من شاشة الأجهزة في Telegram وأكّد.
- **رقم الهاتف:** الرقم، ثم الرمز، ثم كلمة مرور التحقق بخطوتين إن وُجدت.
- **استيراد الجلسة:** ملف جلستك الخاص أو بيانات Telegram Desktop.

استخدم ملف API مدمجًا أو API ID وhash الخاصين بك. هذا يعرّف التطبيق فقط، ولا يسجّل دخولك ولا يخفي أي شيء.

**هل تحتاج إلى وكيل (بروكسي) أولاً؟**

يمكنك [اختيار مسار الاتصال واختباره](https://phishdestroy.github.io/TgWitness/ar/docs/proxies/) قبل تسجيل الدخول. لكل حساب مساره الخاص.

## اختر ما تريد مراقبته

1. اختر المحادثات أو المجموعات أو القنوات التي تحتاجها.
2. راجع إعدادات الجمع، بما فيها الوسائط.
3. شغّله وتحقق من الاتصال والنشاط الأخير.

يجب أن يملك الحساب صلاحية الوصول. يرى المشرفون والأعضاء أشياء مختلفة، والسجل يُظهر ما وصل إلى هذا الحساب.

الحساب بأكمله؟ **المصادر ← نطاق المراقبة ← وضع التحقيق**، راجعه، ثم **حفظ النطاق**. الشرح الكامل: [التحقيق في حساب كامل](https://phishdestroy.github.io/TgWitness/ar/docs/cases/).

## تحقق من المسار بالكامل

في مجموعة الاختبار، أرسل رسالة من حساب آخر، وعدّلها، ثم احذفها. يجب أن تظهر الأحداث الثلاثة في السجل. ثم [صدّر وتحقق](https://phishdestroy.github.io/TgWitness/ar/docs/exports/).

"متصل" يعني أن الاتصال يعمل. أما رسالة الاختبار الملتقطة فتعني أن الأحداث تصل فعلاً.

## إضافة حساب آخر

مساحة عمل جديدة في **الحسابات**، بالخطوات نفسها. دوّن بصمة مفتاح كل حساب لتميّز الصادرات لاحقًا.
