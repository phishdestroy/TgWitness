Підготуйте копію для поширення

Поділіться відповідними спостереженнями, зберігаючи оригінальний робочий простір у незмінному вигляді.

Передача — це окремий підписаний витяг. Виберіть чати та учасників, скоротіть ідентифікаційні дані або текст, а також визначте, які файли та нотатки команди мають увійти до копії одержувача. У маніфесті фіксується вибір, а також кількість незмінених, скорочених та пропущених записів.

Підготуйте витяг для одержувача

  1. Відкрийте «Експорт» → «Витяг для передачі». Вкажіть його призначення, виберіть чати та, за бажанням, період за UTC, а потім виберіть «Завантажити учасників вибраних чатів», якщо вам потрібні імена суб’єктів.
  2. Виберіть, як поводитися з усіма іншими: використовувати псевдоніми, опускати їхні повідомлення або показувати їх у тому вигляді, в якому вони були записані. Налаштовуйте текст повідомлень та вкладення окремо; за бажанням маскуйте номери телефонів та адреси електронної пошти.
  3. Виберіть, чи включати закладки та фрагменти Case Board, чи картки з коментарями. У цьому тексті псевдоніми слідчих можуть замінювати назви команд.
  4. Виберіть «Завантажити витяг для передачі». Відкрийте згенерований звіт та вибрані записи локально, перевірте архів та огляньте копію перед відправленням.

Один оригінал, одна копія для поширення

Синтетичний приклад · наведено лише для ілюстрації

  1. Виберіть. Включіть чат справи та вкажіть особу, про яку йдеться у витягу.
  2. Зменшуйте обсяг тексту. Вибирайте, як інший учасник відображатиметься у копії, що надається для спільного доступу.
  3. Перевірте. Відкрийте згенерований звіт та записи архіву перед відправленням.
  4. Поділіться. Надішліть перевірений текст та окремо повідомте його надійний цифровий відбиток.

Нора · користувач 71002

«Я отримав переглянуте посилання».

Журнал джерел зберігає ці збережені спостереження.

Копія для одержувача

Показати так, як записано: Нора · користувач 71002 · «Я отримала оновлене посилання».

Псевдонім: P01 · «Я отримав оновлене посилання».

Опустити: повідомлення цього учасника не включається до тексту.

Перегляньте фактичні файли

Ознайомтеся з файлами report.html та records.jsonl.

Перевіряйте ідентифікаційні дані, текст, вкладення та додаткові коментарі команди.

Підписаний витяг

Вибір + хеші файлів + підписаний маніфест

Окремий пакет, пов’язаний із межами вихідного журналу

Рішення, що визначають процес передачі
КонтрольВплив на текст
ЛюдиВибрані особи мають залишатися ідентифікованими; інших учасників слід псевдонімізувати або опустити за власним вибором.
ТекстВключіть весь текст, лише текст вибраних осіб та облікового запису спостерігача, або опустіть текст повідомлення та його текстові поля з деталями.
ФайлиВиберіть файли обраних осіб та об’єкта спостереження, усі файли показаних повідомлень або жодних файлів.
Case BoardНе використовуйте матеріали дошки, закладки та фрагменти, а також картки з обговореннями команди.

Перевіряйте текст у довільній формі та вміст файлів, а також ідентифікаційні дані: використання псевдоніма не призводить до автоматичного видалення всіх імен, зазначених у повідомленні чи вкладенні. Якщо вибраний збережений файл недоступний, відновте його або явно пропустіть вкладення перед генерацією витягу.

Текст має бути таким, щоб його можна було незалежно перевірити

python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256

Зберігайте окремо оригінальний підписаний архів доказів та контрольні точки. Процес передачі фіксує власну проекцію, тому одержувач може перевірити надану копію, не отримуючи весь робочий простір. «Report Studio» забезпечує дизайн для читання; перевірка експорту пояснює надійні посилання.
