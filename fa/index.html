منبع را دریافت کنید．

فایل ZIP منبع را دانلود و از حالت فشرده خارج کنید، یا مخزن را کلون کنید：

git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

به Python 3.11 یا بالاتر نیاز دارد． در Windows راه‌انداز پیشنهاد نصب آن را می‌دهد．

مرور نسخه‌های منتشرشده ↗
مرحلهٔ ۰۲

انتخاب کنید چگونه اجرا شود．

روی Start.cmd دوبار کلیک کنید، یا در PowerShell اجرا کنید：

.\Start.cmd

فقط در حال کاوش هستید؟ برای یک دمو جداگانه روی scripts\Demo.cmd دوبار کلیک کنید． نیازی به ورود به تلگرام نیست．

با پایتون ۳.۱۱+ و venv در دسترس：

sh start.sh

برای باز کردن مجلهٔ فرضی، دستور sh start.sh --demo را اجرا کنید．

با اجرای Docker و نصب Compose 2.20+：

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

دستور دوم توکن پنل خصوصی شما را نمایش می‌دهد． آن را روی دستگاه خود نگه دارید．

پس از راه‌اندازی، 127.0.0.1:8787 ↗ را باز کنید．

در نصب از سورس، توکن در data/live/panel-token.txt است． جفت API خودتان از my.telegram.org اختیاری است． راهنمای کامل راه‌اندازی ↗

آیا می‌تواند پیام‌هایی را که قبل از ضبط حذف شده‌اند بازیابی کند؟

نه． چیزی را نگه می‌دارد که حساب شما هنگام اجرا دید． اسنپ‌شات بعدی نمی‌تواند ویرایش‌های ازدست‌رفته یا پیام‌های حذف‌شده را بازسازی کند．
