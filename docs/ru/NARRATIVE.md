# Настройка нарратива доказательств

Нарратив читает подписанный полный ZIP-пакет TgWitness, проверяет его и создаёт отчёт со ссылками на записи. Настройки сохраняются в локальном JSON-файле. [Пример](../examples/narrative.json) содержит профили `ru-html`, `de-proof` и `json-only`.

```sh
python -m tgwitness.narrative evidence.zip --config docs/examples/narrative.json --profile ru-html --out narrative-ru/
```

Команда создаст русский HTML, машинную модель JSON, четыре SVG и файл параметров запуска. Каталог назначения должен быть пустым. Исходный архив не меняется.

Чтобы создать собственный файл настроек и посмотреть результат их объединения:

```sh
python -m tgwitness.narrative --write-config narrative-config.json
python -m tgwitness.narrative --config narrative-config.json --profile ru-html --print-config
```

Создание файла откажет, если такой файл уже существует. `--print-config` не открывает пакет и не обращается к сети.

## Что настраивается

| Поле JSON | Назначение |
|---|---|
| `lang`, `jurisdiction` | Язык и отдельный справочник юрисдикции; `null` означает отсутствие справочника |
| `outputs` | Любая комбинация `pdf`, `html`, `json`, `svg`; обязательно оставить хотя бы один из первых трёх форматов |
| `diagrams` | `timeline`, `flow`, `ladder`, `files`; пустой список разрешён без SVG-вывода |
| `max_records` | Предел записей в каждом журнале: от 1 до 1000000, по умолчанию 100000 |
| `scene_max_records` | Предел группировки исходных записей: от 1 до 10000, по умолчанию 2000; ссылка на последующий перезапуск добавляется сверх этого предела |
| `fingerprint`, `witness`, `witness_fingerprint`, `tsa_ca` | Доверенные отпечатки ключей, архив свидетеля, файл корневого сертификата TSA |
| `check_drand`, `check_bitcoin` | Проверки через внешние сервисы; по умолчанию выключены |
| `require_tier` | Минимальная ступень: `self_attested`, `timestamped`, `witnessed`, `fresh`, `witness_anchored`, `sealed` |
| `require_pinned_signer` | Требование доверенного отпечатка коллектора либо проверенного закреплённого свидетеля, связанного с этим архивом |

Порядок применения: встроенные значения → `defaults` → выбранный `profiles` → параметры командной строки. Относительные пути внутри JSON считаются от каталога JSON; пути в CLI — от текущего каталога.

Пример переопределения: немецкий HTML без диаграмм и без справочника юрисдикции:

```sh
python -m tgwitness.narrative evidence.zip --config narrative-config.json --profile ru-html --lang de --jurisdiction none --outputs html --diagrams none --out narrative-de/
```

Флаги `--no-check-drand`, `--no-check-bitcoin` и `--no-require-pinned-signer` явно переопределяют соответствующие значения профиля. Это меняет требования конкретного запуска и фиксируется в его настройках. Проверки подписей остаются обязательными; отсутствие внешней проверки не превращается в её успешное прохождение.

Профиль `de-proof` требует `witness_anchored` и доверенный ключ. Передайте полученные независимо отпечатки и архив свидетеля:

```sh
python -m tgwitness.narrative evidence.zip --config narrative-config.json --profile de-proof --fingerprint COLLECTOR_FP --witness witness.zip --witness-fingerprint WITNESS_FP --out narrative-proof/
```

Если доказательств не хватает, отчёт не создаётся. Установка высокой ступени сама по себе не включает сетевые проверки и не создаёт недостающие доказательства. Один отпечаток свидетеля без соответствующего архива не удовлетворяет требованию закреплённого ключа.

## Что остаётся обязательным

Все факты сохраняют ссылки на номера и хеши записей. Ограничения и текстовая лестница уверенности остаются даже без диаграмм. Превышение лимита записей останавливает генерацию; тихого обрезания нет. Настроек «пропустить подпись», «скрыть ограничения», «подтвердить вручную» или «перевод вычитан» нет. Неизвестные поля, повторяющиеся ключи JSON и неверные типы вызывают отказ.

`narrative-run.json` сохраняет применённые параметры, их хеш, хеши входных архивов и файла TSA CA, если он использовался, признак закреплённого ключа и достигнутую ступень. Локальные пути к архиву свидетеля и сертификату не попадают в отчёт. Этот файл не подписан и не является независимым свидетельством. Он создаётся при любом выборе форматов.

Коды выхода: **0** — отчёт создан; **1** — ошибка проверки пакета, превышение лимита записей или ошибка генерации; **2** — неверные настройки либо недостаточная ступень/незакреплённый ключ при соответствующем требовании.

## Проверки и границы готовности

Автотесты проверяют все 25 языков, ссылки на записи, старый подписанный пакет, приоритет профилей, относительные пути, выбор форматов, лимиты и коды выхода. Подмена архива должна приводить к отказу. Сквозной тест с подписанными журналами проверяет профиль `witness_anchored` при наличии, отсутствии и подмене подтверждения; ответы внешних drand/Bitcoin-сервисов в нём подставные.

Юридическая вычитка переводов и интеграции T7/T13 остаются незавершёнными. Все языки обозначены как переводы без ручной вычитки. Проверка `python tools/check_narrative_texts.py --for-release` поэтому должна отказать. Полные ограничения описаны в [английской документации](../NARRATIVE.md) и [документе для читателя](FOR-THE-RECORD.md).
