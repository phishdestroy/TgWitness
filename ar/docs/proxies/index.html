اختر وكيلًا

حافظ على اتصال الحساب. حدد بوضوح متى يجوز لمساره استخدام عنوان الخادم.

اختر وضع IP أولاً

دع المجموعة تتولى إدارة المسار

  1. افتح الحساب → الإعدادات → إعدادات الاتصال.
  2. اختر وضع IP و MTProxy التلقائي، أو أدخل مسارًا ثابتًا.
  3. احفظ الأداة وقم بتشغيل اختبار اتصال Telegram. تعمل الأداة أيضًا قبل تسجيل الدخول.
  4. بعد بدء عملية التجميع، تحقق من وصول الرسالة الخاضعة للمراقبة إلى السجل.

تستخدم مساحات العمل الجديدة ميزة MTProxy التلقائية مع وظيفة إخفاء عنوان IP. يجمع المجمع بين أربعة مصادر عامة، ويفحص الإدخالات، ويحتفظ بالمسارات العاملة، ويستبدل البروكسيات المعطلة. تحتفظ عمليات التنزيل الفاشلة باللقطات السابقة.

استخدم بروكسي خاص بك

أدخل تفاصيل SOCKS5 أو HTTP CONNECT، أو الصق رابط وكيل Telegram مدعوم، أو أدخل كتالوج مشغل. أوقف المراقبة مؤقتًا قبل تغيير المسار النشط. لا تزال أسرار MTProxy المزيفة لـ TLS التي تبدأ بـ ee غير مدعومة.

إعدادات التناوب والمشاركة وإعادة المحاولة

ضمن «المعلمات» → «MTProxy التلقائي»، قم بتعيين عتبات الفشل، وفترات التهدئة، والتناوب المخطط، وعدد الحسابات لكل وكيل. يؤدي حد المشاركة المحدد بـ«واحد» إلى جعل الحساب ينتظر عندما لا يتوفر دخول حصري. تتبع فترات تحديث القائمة وفترات الفحص القيم المحددة في مساحة العمل الرئيسية. لا تضمن الوكلاء المنفصلون عناوين IP منفصلة عند الخروج.

فصل Telegram عن الطلبات الخارجية

تنقل MTProxy حركة مرور Telegram فقط. أما الطوابع الزمنية والإشعارات والنسخ والتحقق من المصادر، فتستخدم وكيل SOCKS5/HTTP منفصلاً، أو مسار SOCKS5/HTTP الخاص بالحساب، أو الاتصال المباشر (Direct) حيثما يسمح وضع IP بذلك. ويمكن تعطيل تلك الطلبات الخارجية.

يحدد الرمز «TGWITNESS_PROXY_FEED_PROXY» مسار أداة تنزيل الخلاصة. ويحتفظ «الشاهد المستقل» بإعداداته الخاصة. ولا تؤدي هذه الضوابط إلى تثبيت شبكة VPN على النظام أو توجيه حركة مرور المتصفح.

اطلع على جميع الأوضاع والإعدادات الافتراضية وقوائم المصادر، أو اختر من يمكنه تغيير مسار الحساب.
