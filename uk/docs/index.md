# Слідкуйте за повідомленнями. Розумійте докази.

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/

Зробіть свій перший знімок, ознайомтеся з принципом роботи доказів, а потім налаштуйте систему відповідно до своїх потреб.

[ІНТЕРАКТИВНИЙ ПОЛОВИЙ ПОСІБНИК**Зробіть крок до змін. Подивіться, що виявляють докази.** Перегляньте історію повідомлення, змініть запис та відстежте його хеш. Ознайомтеся з ілюстрованим посібником](https://phishdestroy.github.io/TgWitness/uk/docs/concepts/) [## Режими, сценарії та рівні доказовості Області збору даних, межі подій, вісім механізмів верифікації та шість вигаданих сценаріїв розслідування.](https://phishdestroy.github.io/TgWitness/uk/guides/modes.html)

## Ваше перше зафіксоване повідомлення

[### Почніть за лічені хвилини Спробуйте TgWitness із зразками даних, а потім запустіть власний робочий простір для спостереження за Telegram на Windows, Linux або macOS.](https://phishdestroy.github.io/TgWitness/uk/docs/start/)[### Спеціальний обліковий запис Створіть окремий акаунт у Telegram для збору даних.](https://phishdestroy.github.io/TgWitness/uk/docs/dedicated-account/)[### Підключити обліковий запис Підключіть Telegram за допомогою QR-коду, номера телефону або імпорту сеансу. Оберіть джерела та переконайтеся, що нові повідомлення надходять до вашого журналу.](https://phishdestroy.github.io/TgWitness/uk/docs/accounts/)[### Виберіть проксі-сервер Підтримуйте автоматичні маршрути MTProxy або використовуйте власний проксі-сервер. Обирайте режими IP, правила резервного переходу та маршрут для зовнішніх запитів.](https://phishdestroy.github.io/TgWitness/uk/docs/proxies/)[### Експорт та перевірка Експортуйте збережену історію Telegram, перевіряйте підписи та порівнюйте журнал із контрольною точкою, збереженою незалежним свідком.](https://phishdestroy.github.io/TgWitness/uk/docs/exports/)[### Запис дій на GitHub Actions Експорт одного чату Telegram на тимчасовий GitHub Runner.](https://phishdestroy.github.io/TgWitness/uk/docs/capture/)

## Дізнайтеся, спробувавши його

[### Дізнайтеся, як працює система збереження доказів Простежте шлях повідомлення від моменту фіксації до контрольної точки. Змініть зразок запису, перерахуйте його ланцюжок SHA-256 і подивіться, що виявить збережена контрольна точка.](https://phishdestroy.github.io/TgWitness/uk/docs/concepts/)[### Проведіть розслідування у всіх чатах Проведіть комплексне розслідування в Telegram, охопивши канали, групи, приватні чати та боти: повне копіювання облікового запису, історію, користувачів, посилання, файли, хронологію та перевірені докази.](https://phishdestroy.github.io/TgWitness/uk/docs/cases/)[### Забезпечте безпеку Дізнайтеся, де зберігаються сесії, ключі та докази, що виходить за межі вашого комп’ютера, що охоплює система захисту та як посилити безпеку інсталяції.](https://phishdestroy.github.io/TgWitness/uk/docs/security/)

## Додавайте лише те, що потрібно

[### Робота з архівом Завантажуйте історію, шукайте збережені записи, переглядайте джерела штучного інтелекту та підключайте свої інструменти.](https://phishdestroy.github.io/TgWitness/uk/docs/archive/)[### Поділитися справою Надайте рецензентам та аналітикам доступ до вибраних акаунтів і чатів із окремими правами доступу, обмеженнями сеансів та токенами, які можна скасувати.](https://phishdestroy.github.io/TgWitness/uk/docs/access/)[### Налаштування бота-свідка Публікуйте підписані контрольні точки журналу у своєму каналі Telegram із окремим свідком, власним ключем та доступом до колектора лише для читання.](https://phishdestroy.github.io/TgWitness/uk/docs/witness/)[### Забезпечте його безперебійну роботу Запустіть TgWitness на сервері з постійним сховищем даних, приватним доступом до панелі управління, резервним копіюванням та перевірками після перезапуску.](https://phishdestroy.github.io/TgWitness/uk/docs/server/)[### З’ясуйте, що пішло не так Перевіряйте доступ до панелі, з’єднання з Telegram, відсутні повідомлення, FloodWait та статус свідка, використовуючи відповідні сигнали для кожної проблеми.](https://phishdestroy.github.io/TgWitness/uk/docs/troubleshooting/)
