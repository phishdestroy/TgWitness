# একটি প্রক্সি নির্বাচন করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/proxies/

অ্যাকাউন্ট অনলাইন রাখুন, এবং নিজেই ঠিক করুন এটি কখনো আপনার সার্ভারের IP দেখাতে পারবে কিনা।

## প্রথমে আইপি মোড নির্বাচন করুন

01**ঠিকানা লুকান**

শুধু প্রক্সি। কোনোটি কাজ না করলে অপেক্ষা করে।

02**চরম বিকল্প হিসেবে সরাসরি**

বিলম্বের পরে সরাসরি যায়, কোনো প্রক্সি কাজ করলেই আবার সেটিতে ফেরে।

03**টানেল বা VPN-এর পেছনের সার্ভার**

সরাসরি সংযোগ ঠিক আছে। এটি আপনার জন্য VPN সেট বা যাচাই করে না।

রুট সংযোগটি নির্বাচন করে। আইপি মোড নির্ধারণ করে সরাসরি সংযোগ অনুমোদিত কিনা।

## পুলটিকে পথটি বজায় রাখতে দিন

1. **অ্যাকাউন্ট → সেটিংস → সংযোগ সেটিংস**।
2. IP মোড ও **স্বয়ংক্রিয় MTProxy** বেছে নিন, বা একটি নির্দিষ্ট রুট।
3. সংরক্ষণ করুন, **Telegram সংযোগ পরীক্ষা** (সাইন ইনের আগেও কাজ করে)।
4. সংগ্রহ শুরু করুন এবং নিজেকে একটি টেস্ট বার্তা পাঠান।

নতুন ওয়ার্কস্পেস স্বয়ংক্রিয় MTProxy ও **ঠিকানা লুকান** দিয়ে শুরু হয়। পুল চারটি পাবলিক তালিকা টানে, সার্ভার যাচাই করে, ভালোগুলো রাখে আর অচলগুলো বদলায়।

## আপনার নিজস্ব প্রক্সি ব্যবহার করুন

SOCKS5, HTTP CONNECT, Telegram প্রক্সি লিংক বা অপারেটর ক্যাটালগ। বদলানোর আগে পর্যবেক্ষণ থামান। Fake TLS সিক্রেট (`ee`…) কাজ করে না।

**ঘূর্ণন, ভাগাভাগি এবং পুনঃচেষ্টা সেটিংস**

**প্যারামিটার → স্বয়ংক্রিয় MTProxy**: ব্যর্থতার সীমা, বিরতি, রোটেশন, প্রক্সি প্রতি অ্যাকাউন্ট। সীমা 1 মানে অ্যাকাউন্ট শেয়ার না করে অপেক্ষা করে। আলাদা প্রক্সিও একই এক্সিট IP শেয়ার করতে পারে।

## বহিঃপ্রাঙ্গণ অনুরোধ থেকে টেলিগ্রামকে আলাদা করুন

MTProxy শুধু Telegram বহন করে। টাইমস্ট্যাম্প, নোটিফিকেশন, কপি ও কোড যাচাই যায় আলাদা SOCKS5/HTTP প্রক্সি, অ্যাকাউন্টের SOCKS5/HTTP রুট, বা মোড অনুমতি দিলে সরাসরি। অথবা এগুলো বন্ধ করুন।

`TGWITNESS_PROXY_FEED_PROXY` তালিকা ডাউনলোডের রুট ঠিক করে। [সাক্ষী](https://phishdestroy.github.io/TgWitness/bn/docs/witness/)-র নিজস্ব সেটিংস আছে। এর কিছুই আপনার ব্রাউজার বা সিস্টেম নেটওয়ার্ক ছোঁয় না।

আরও: [মোড ও ডিফল্ট](https://phishdestroy.github.io/TgWitness/bn/docs/reference/connection/#ip-modes), [কে রুট বদলাতে পারে](https://phishdestroy.github.io/TgWitness/bn/docs/access/)।
