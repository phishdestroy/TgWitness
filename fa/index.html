به‌طور پیش‌فرض غیرفعال

همه چیز را به یک فضای ذخیره‌سازی سازگار با S3 کپی کنید

ژورنال، فایل‌ها، نقاط کنترل زمان‌دار و خروجی‌های چت — رمزگذاری‌شده پیش از بارگذاری به AWS S3 یا ذخیره‌سازی سازگار.

تنظیمات ذخیره‌سازی و بازیابی
رمزگذاری سمت کلاینت
AES-256-GCM اشیاء را روی این دستگاه رمزگذاری می‌کند. ارائه‌دهنده اشیاء رمزگذاری‌شده را دریافت می‌کند.
نسخه‌های زمان‌بندی‌شده یا دستی
هم‌اکنون کپی کنید، یا یک بازه زمانی از ۱ تا ۱٬۴۴۰ دقیقه را انتخاب کنید. پیشرفت را در پنل بررسی کنید.
قفل اشیاء
روزهای نگهداری و حالتی را انتخاب کنید که باکت از آن پشتیبانی کند. پنل گزارش می‌دهد که آیا نگهداری بر روی یک شیء بارگذاری‌شده تأیید شده است یا خیر.
بازیابی تأییدشده
کلید رمزگذاری را دانلود کرده و به‌طور جداگانه نگهداری کنید. آن را روی دستگاه دیگری بازیابی کنید؛ فایل‌ها تنها پس از تأیید منتشر می‌شوند.

یک جلسه واردشده، یک کلاینت در حال اجرا.

منبع را دریافت کنید.

فایل ZIP منبع را دانلود و از حالت فشرده خارج کنید، یا مخزن را کلون کنید:

git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

راه‌انداز منبع به پایتون ۳.۱۱ یا بالاتر نیاز دارد. راه‌انداز ویندوز در صورت عدم وجود پایتون، امکان نصب را فراهم می‌کند.

مرور نسخه‌های منتشرشده ↗

پایتون روی ویندوز ندارید؟ بستهٔ قابل حمل را دانلود کنید، آن را استخراج کرده و روی TgWitness.cmd دوبار کلیک کنید.

مرحلهٔ ۰۲

انتخاب کنید چگونه اجرا شود.

روی Start.cmd دوبار کلیک کنید، یا در PowerShell اجرا کنید:

.\Start.cmd

فقط در حال کاوش هستید؟ برای یک دمو جداگانه روی scripts\Demo.cmd دوبار کلیک کنید. نیازی به ورود به تلگرام نیست.

با پایتون ۳.۱۱+ و venv در دسترس:

sh start.sh

برای باز کردن مجلهٔ فرضی، دستور sh start.sh --demo را اجرا کنید.

با اجرای Docker و نصب Compose 2.20+:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

دستور دوم توکن پنل خصوصی شما را نمایش می‌دهد. آن را روی دستگاه خود نگه دارید.

پس از راه‌اندازی، 127.0.0.1:8787 ↗ را باز کنید.

برای نصب از سورس، توکن در data/live/panel-token.txt قرار دارد. ورود به تلگرام می‌تواند از تنظیمات API داخلی استفاده کند یا از جفت توکن خودتان از my.telegram.org. راهنمای کامل راه‌اندازی ↗

آیا این صفحه به تلگرام متصل است؟

خیر. این یک صفحهٔ پروژهٔ ایستا با مثال‌های خیالی و اسکرین‌شات‌ها است. اپلیکیشن واقعی روی رایانه یا سرور شما اجرا می‌شود؛ ورود به سیستم در آنجا انجام می‌شود.

آیا می‌تواند پیام‌هایی را که قبل از ضبط حذف شده‌اند بازیابی کند؟

خیر. TgWitness محتوایی را که حساب کاربری شما در حین اجرای جمع‌آوری مشاهده کرده است، حفظ می‌کند. یک اسنپ‌شات تاریخی بعدی نمی‌تواند ویرایش‌های از دست رفته یا پیام‌های حذف‌شده را بازسازی کند.

آیا کل دفترچهٔ یادداشت من رمزگذاری شده است؟

اطلاعات حساب کاربری و اسرار امضایی در گاوصندوق رمزگذاری‌شده نگهداری می‌شوند. پیام‌ها و پیوست‌های محلی نیازمند یک دیسک یا حجم رمزگذاری‌شده هستند. خروجی‌ها به‌صورت اختیاری می‌توانند از فایل ZIP AES-256 محافظت‌شده با رمز عبور استفاده کنند.

آیا این با تلگرام مرتبط است؟

خیر. TgWitness یک پروژه مستقل است که از Telethon استفاده می‌کند و تحت مجوز MIT توزیع شده است. شما حساب‌های خود را با استفاده از تنظیمات داخلی API یا جفت API خود مجاز می‌کنید.
