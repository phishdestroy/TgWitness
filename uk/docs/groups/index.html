Управління групою облікових записів

Ведіть кілька акаунтів разом — у кожного, як і раніше, свої записи й ключ.

Група збирає статус підключення, запуск/паузу, спільні налаштування й експорт на одному екрані. Зручно, коли кілька акаунтів працюють над однією справою.

Відкрити огляд групи

Відкрийте групу в Акаунтах. Для кожного акаунта видно стан, маршрут, затримку й останнє збережене повідомлення. Потребує уваги перелічує зламані, Виправити веде просто туди.

Запустити всі / Призупинити всі питають перед дією. Налаштування групи спільні, але власні значення акаунта лишаються, доки ви їх не заміните.

Переглянути зміну маршруту в групі

Синтетичний приклад · ілюстративні перевірки та результати

  1. Виберіть. Оберіть групу та перегляньте, які облікові записи зазнають змін.
  2. Підготуйте текст. Зберігайте окремий маршрут для кожного облікового запису, коли це необхідно.
  3. Перевірте. Протестуйте запропоноване з’єднання та проаналізуйте отримані результати.
  4. Подайте заявку. Перед збереженням перевірте текст ще раз і перегляньте результат для кожного облікового запису.

Команда, що веде справу

Колектор каналів · Колектор груп · Довідковий обліковий запис

3 окремі робочі простори

Переглянутий вибір

2 акаунти дотримуються запропонованого підходу.

Довідковий обліковий запис має власний маршрут.

Перевірка підготовки

Колектор каналів: час передачі даних у Telegram — 84 мс

Груповий колектор: час передачі даних Telegram — 91 мс

Ці цифри є вигаданими показниками, наведеними для прикладу.

Результати застосування

Колектор каналів: маршрут збережено, спостереження відновлено.

Груповий колектор: повторна перевірка завершилася невдало, відновлено попередні налаштування.

Довідковий обліковий запис: збережено власний маршрут.

Змінити маршрут, додавши етап перевірки

  1. Змінити маршрут групи, оберіть тип і налаштування.
  2. Перевірити вибір: які акаунти зміняться і в яких свій маршрут.
  3. Підготувати й перевірити перевіряє нове підключення до Telegram і, де можливо, зовнішню IP.
  4. Застосувати перевірене підключення й подивіться на кожен результат. Акаунти, що працювали, продовжать, неактивні такими й лишаться.

Затримка — це час встановлення з'єднання з Telegram, зовнішня IP — те, що показав маршрут під час перевірки. Результати в акаунтів можуть відрізнятися.

Використовуйте перекривний доступ

Чати, які бачать кілька акаунтів, показують спільні джерела та їхнє охоплення. Канали й супергрупи можна експортувати одразу кількома акаунтами через Експорт … акаунтами. Особисті чати й звичайні групи — ні: номери повідомлень там свої в кожного акаунта.

Експортувати групу як пакет

Експорт групи дає один ZIP з підписаним експортом кожного акаунта й підписаним їх списком. У кожного свій відбиток для перевірки. Спільну хронологію, як і раніше, збираєте ви.

Далі: звіти, Case Board, перевірка експорту.
