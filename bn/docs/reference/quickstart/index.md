# দ্রুত শুরু

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/reference/quickstart/

TgWitness ইনস্টল ও চালু করার প্রতিটি উপায়: উইন্ডোজ প্যাকেজ, পাইথন, ডকার এবং সিন্থেটিক ডেমো, প্রাথমিক যাচাইসহ।

TgWitness হল একটি স্বতন্ত্র অ্যাপ্লিকেশন যা আপনার অ্যাকাউন্টগুলো অ্যাক্সেস করতে পারা টেলিগ্রাম গ্রুপ এবং চ্যানেলগুলো পর্যবেক্ষণের জন্য। এটি নিজস্ব ডেটা ডিরেক্টরি সহ স্থানীয়ভাবে চলে।

**প্রথমবার আসছেন?** একটি অ্যাকাউন্ট সংযুক্ত করার আগে [ডেমোটি দেখুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/quickstart/#explore-the-interface)। প্রক্সি, সাক্ষী, এক্সপোর্ট বা সার্ভার সেটআপের জন্য [একটি গাইড নির্বাচন করুন](https://github.com/phishdestroy/TgWitness/blob/main/docs/README.md)।

## ইনস্টল করুন এবং শুরু করুন

[GitHub Actions দিয়ে সংগ্রহ (প্রাথমিক সংস্করণ)](https://github.com/phishdestroy/TgWitness/blob/main/docs/SEALED-ACTIONS.md)

একটি পদ্ধতি নির্বাচন করুন। রিলিজ বিল্ড প্রকাশের পর পোর্টেবল ডাউনলোডগুলি উপলব্ধ হবে:

| আয়োজক | কিছুই ইনস্টল করা নেই | উৎস: পাইথন ৩.১১+ | ডকার: ইঞ্জিন/ডেস্কটপ কম্পোজ 2.20+ সহ |
| --- | --- | --- | --- |
| উইন্ডোজ | GitHub রিলিজ থেকে `TgWitness-<version>-windows-amd64-portable.zip` এক্সট্র্যাক্ট করুন, `TgWitness.cmd`-এ ডাবল-ক্লিক করুন। | `Start.cmd`-এ ডাবল-ক্লিক করুন | `scripts\Docker.cmd`-এ ডাবল-ক্লিক করুন |
| লিনাক্স / ম্যাকওএস | — | `sh start.sh` | `sh scripts/docker-start.sh` |

সোর্স পদ্ধতির জন্য, [বর্তমান `main` ডাউনলোড ও এক্সট্র্যাক্ট করুন](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) অথবা রিপোজিটরিটি ক্লোন করুন:

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

বর্তমান সোর্সে ব্যাচ অ্যাকাউন্ট ইমপোর্ট, MTProxy ড্যাশবোর্ড এবং পুনরায় শুরু করার যোগ্য হিস্ট্রি লোডিং অন্তর্ভুক্ত রয়েছে। 0.7.0 পোর্টেবল প্রিভিউ এবং এর রিলিজ সোর্স আর্কাইভ এই সংযোজনগুলোর আগের। সংস্করণের সীমারেখা জানতে [চেঞ্জলগ](https://phishdestroy.github.io/TgWitness/bn/docs/reference/changelog/) দেখুন।

উপযুক্ত কোনো Python খুঁজে না পাওয়া গেলে `Start.cmd` আপনার Windows ব্যবহারকারীর জন্য Python 3.12 ইনস্টল করার প্রস্তাব দেয় (winget, অথবা স্বাক্ষরিত python.org ইনস্টলারের মাধ্যমে)। Python না থাকলে `start.sh` আপনার Linux ডিস্ট্রিবিউশন বা macOS-এর জন্য সঠিক ইনস্টল কমান্ডটি প্রিন্ট করে। প্রথমবার সোর্স চালু করলে তা স্বয়ংক্রিয়ভাবে `.venv` তৈরি করে এবং ডিপেন্ডেন্সিগুলো ইনস্টল করে নেয়।

Docker অ্যাপ্লিকেশনটি বিল্ড করে এবং পটভূমিতে চালু করে; হোস্ট Python অপ্রয়োজনীয়। `scripts\Docker.cmd` এবং `scripts/docker-start.sh` প্যানেলের ঠিকানা এবং টোকেন প্রিন্ট করে যখন কন্টেইনারটি সুস্থ থাকে। প্রতিটি সমর্থিত হোস্টে সমতুল্য Docker কমান্ডগুলো হল:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

http://127.0.0.1:8787 খুলুন। ডকার হেল্পার বা দ্বিতীয় ডকার কমান্ড দ্বারা প্রিন্ট করা টোকেন ব্যবহার করুন, অথবা পোর্টেবল বা সোর্স ইনস্টলেশনের জন্য **data/live/panel-token.txt ফাইল থেকে** পড়ুন। নিচে **'Connect Telegram**'-এ চালিয়ে যান। নেটিভ এবং ডকার ইনস্টলেশন আলাদা স্টোরেজ ব্যবহার করে; ডকার চালু করলে বিদ্যমান নেটিভ জার্নাল আমদানি হয় না।

একটি সার্ভারের জন্য, [ডিপ্লয়মেন্টে](https://phishdestroy.github.io/TgWitness/bn/docs/reference/deployment/) স্বয়ংক্রিয় HTTPS, রিস্টার্ট, প্রকাশিত ইমেজ, আপডেট এবং ব্যাকআপ অন্তর্ভুক্ত।

## ইন্টারফেসটি অন্বেষণ করুন

1. পোর্টেবল প্যাকেজে Run **TgWitness-Demo.cmd** চালান, Windows সোর্স ফোল্ডারে **scripts\Demo.cmd** চালান, অথবা Linux/macOS-এ `sh start.sh --demo` চালান। একটি সোর্স লঞ্চ প্রথমে `.venv` তৈরি করে এবং নির্ভরতা ইনস্টল করে।
2. **http://127.0.0.1:8787** খুলুন।
3. স্থানীয় ডেমো স্বয়ংক্রিয়ভাবে নমুনা জার্নাল খুলে। সরাসরি স্থানীয় অ্যাক্সেসের জন্য টোকেন কপি করার কোনো প্রয়োজন নেই।

ডেমো বার্তাগুলো কাল্পনিক। ডেমো মোড কোনো প্রকৃত টেলিগ্রাম অ্যাকাউন্টের সাথে সংযোগ করতে পারে না।

## টেলিগ্রাম সংযোগ করুন

> [!WARNING] **এমন কোনো কিছু ব্যবহার করবেন না যা আপনি হারাতে পারেন না।** আমরা ব্যক্তিগত বা মূল্যবান অ্যাকাউন্ট সংযোগ করার এবং আপনি যে অ্যাকাউন্টটিকে মূল্য দেন সেটিতে API আইডি/হ্যাশ তৈরি করার বিরুদ্ধে দৃঢ়ভাবে পরামর্শ দিচ্ছি। টেলিগ্রাম ক্লায়েন্ট যাই হোক না কেন, অনিশ্চিতভাবে এবং প্রায়ই স্থায়ীভাবে অ্যাকাউন্ট নিষিদ্ধ করে। একটি মসৃণ পরীক্ষা চালানো টেলিগ্রামের ওপর নির্ভর করে, TgWitness-এর ওপর নয়, এবং ভবিষ্যতের জন্য কোনো নিশ্চয়তা দেয় না।

1. যদি নেটিভ ডেমো চলছে, তা বন্ধ করুন এবং **Start.cmd** অথবা `sh start.sh` চালান। অন্যথায়, উপরের লাইভ ইনস্টলেশন চালু রাখুন।
2. প্যানেল খুলতে আপনার ইনস্টলেশন পদ্ধতির জন্য প্যানেল টোকেন ব্যবহার করুন।
3. যদি আপনার প্রক্সি প্রয়োজন হয়, তাহলে এটিকে **Account → Settings → Connection settings → Change connection route**-এ সংরক্ষণ করুন।
4. **Account**-এ আপনার ফোন নম্বর লিখুন এবং **Continue** চাপুন, **QR code → Show QR code** নির্বাচন করুন, অথবা ফাইলগুলো নির্বাচন করে **Connect account** চাপুন। **API ID + Hash** ঐচ্ছিক: ওয়ার্কস্পেস সংরক্ষিত বা আমদানি করা পেয়ার ব্যবহার করে, অথবা বিল্ট-ইন পুল থেকে একটি কার্যকর পেয়ার ব্যবহার করে। আপনার নিজস্ব অ্যাপ ব্যবহার করতে, একটি `API ID:API Hash` পেয়ার API ID-এ পেস্ট করুন। সম্পূর্ণ অথরাইজেশন কী-এর জন্য **Auth key** নির্বাচন করুন, সমস্ত ৫১২ হেক্সাডেসিমাল অক্ষর পেস্ট করুন, এবং সরবরাহিত DC ID নির্বাচন করুন। User ID ঐচ্ছিক এবং প্রবেশ করালে চেক করা হয়।
5. আপনার নির্বাচিত সাইন-ইন পদ্ধতি সম্পূর্ণ করুন: ফোন/কোড/2FA, QR-এর জন্য সাইন-ইন করা টেলিগ্রাম অ্যাপ থেকে নিশ্চিতকরণ, অথবা সমর্থিত অনুমোদিত সেশন আমদানি।
6. প্রদর্শিত অ্যাকাউন্ট আইডি পরীক্ষা করুন। ওপেন সোর্সেস: আপনার চ্যাটগুলো স্বয়ংক্রিয়ভাবে লোড হয়; আপনার গ্রুপগুলো যোগ করুন।
7. **'কোন পরিবর্তনগুলো সংরক্ষণ করবেন'** এর অধীনে ইভেন্ট বিভাগ বা **'বার্তা, সম্পাদনা ও মুছে ফেলা**' প্রিসেট নির্বাচন করুন, তারপর মনিটরিং সেটিংস সংরক্ষণ করুন।
8. সংযুক্তি সেটিংস আলাদাভাবে নির্বাচন করুন, তারপর **পর্যবেক্ষণ শুরু করতে** চাপুন।

API ক্রেডেনশিয়ালগুলো আপনার অ্যাপ্লিকেশন সনাক্ত করে; এগুলো নিজে থেকেই কোনো অ্যাকাউন্ট অনুমোদন করে না। ব্যক্তিগত গ্রুপের জন্য কোনো পাবলিক ব্যবহারকারীর নাম প্রয়োজন নেই, তবে আপনার অ্যাকাউন্টের অবশ্যই অ্যাক্সেস থাকতে হবে।

বিদ্যমান অ্যাকাউন্টগুলোর জন্য, [অ্যাকাউন্ট এবং সেশন ফরম্যাট](https://phishdestroy.github.io/TgWitness/bn/docs/reference/accounts/) দেখুন: প্যানেলটি Telethon StringSession, Telethon/Pyrogram SQLite, একক-অ্যাকাউন্টের TData ZIP এবং সমর্থিত অ্যাকাউন্ট JSON গ্রহণ করে। একটি সেশন এবং তার সাথে থাকা JSON একসাথে নির্বাচন করুন, এরপর **অ্যাকাউন্ট সংযুক্ত করুন** চাপুন। একই ঐচ্ছিক API সেটিংসসহ QR লগইনও উপলব্ধ। TDLib, বট সেশন এবং CSV/JSON অ্যাকাউন্ট ইনভেন্টরি সমর্থিত নয়।

একাধিক অ্যাকাউন্টের জন্য, **হিসাবসমূহ → অ্যাকাউন্ট আমদানি করুন** ব্যবহার করুন এবং সেগুলোর সমর্থিত সেশন ফাইল নির্বাচন করুন। সাথে থাকা JSON ফাইলগুলো বেসনেম (basename) অনুযায়ী যুক্ত হয়; আমদানি করা প্রতিটি অ্যাকাউন্ট নিজস্ব আলাদা ওয়ার্কস্পেস পায়। [বাল্ক ইমপোর্ট এবং অ্যাকাউন্ট গ্রুপ](https://phishdestroy.github.io/TgWitness/bn/docs/reference/accounts/#bulk-import-and-account-groups) দেখুন।

অন্য একটি অ্যাকাউন্ট যোগ করতে, অ্যাকাউন্ট সিলেক্টরের পাশে **+** চাপুন অথবা **Account → Settings → Connection settings → Workspaces** খুলুন, অথবা **Accounts** ব্যবহার করুন। ওয়ার্কস্পেসগুলির পৃথক সেশন, জার্নাল, কী, সোর্স এবং কুই রয়েছে। ভিউ পরিবর্তন করলে অন্যান্য কালেক্টরগুলি চলতেই থাকবে। এই ইনস্টলেশনে একই টেলিগ্রাম অ্যাকাউন্ট দুটি ওয়ার্কস্পেস-এ বরাদ্দ করা যাবে না। ওয়ার্কস্পেসের কোনো নির্দিষ্ট সংখ্যা নেই; এগুলো একটি প্রক্রিয়া শেয়ার করে, তাই ধারণক্ষমতা মেশিনের উপর নির্ভর করে।

লাইভ প্যানেল টোকেন আপনার টেলিগ্রাম অনুমোদন এবং সংরক্ষিত সামগ্রীর অ্যাক্সেস সুরক্ষিত রাখে; এটি টেলিগ্রাম API ক্রেডেনশিয়াল থেকে আলাদা। শুধুমাত্র স্পষ্টভাবে শুরু করা এবং সরাসরি অ্যাক্সেস করা লোকাল ডেমো স্বয়ংক্রিয়ভাবে প্রবেশাধিকার পায়। রিমোট/প্রক্সিড ডেমো এখনও `data/demo/panel-token.txt` ব্যবহার করে।

## পর্যালোচনা এবং রপ্তানি

- জার্নাল: উৎস এবং ইভেন্টের ধরন অনুযায়ী পর্যবেক্ষণ অনুসন্ধান ও ফিল্টার করুন।
- কোনো ইভেন্ট নির্বাচন করুন তার মূল রেকর্ড, তথ্যসূত্র এবং সংরক্ষিত সংস্করণগুলো পরিদর্শন করতে।
- সম্পাদনা বিবরণ উপলব্ধ আগে/পরে বিষয়বস্তু দেখায়। মুছে ফেলার বিবরণ শেষ ধারণকৃত বিষয়বস্তু দেখায়, যদি থাকে; একটি অজানা অভিনেতাই অজানা থাকে।
- **রপ্তানি:** স্বাক্ষরিত ZIP, JSONL, CSV এবং অফলাইন HTML।
- **পূর্ণ চ্যাট রপ্তানি** (সূত্র → পূর্ণ চ্যাট রপ্তানি): একটি চ্যাটের সম্পূর্ণ দৃশ্যমান ইতিহাস `chat.json`-এর স্বাক্ষরিত বান্ডিল (টেলিগ্রাম-রপ্তানি শৈলী) এবং পাঠযোগ্য `chat.html` হিসেবে ডাউনলোড করুন। ব্যক্তিগত চ্যাট তখনই কাজ করে যখন অ্যাকাউন্টের সদস্যতা থাকে। এটি একটি বর্তমান স্ন্যাপশট, মুছে ফেলা বা পূর্বে সম্পাদিত বার্তাগুলির পুনর্গঠন নয়। `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256` দিয়ে একটি অনুলিপি যাচাই করুন।
- **চেকপয়েন্ট সংরক্ষণ করুন:** স্বাক্ষরিত জার্নাল সীমানা কালেক্টরের বাইরে রাখুন।
- **স্বাক্ষরিত রান রসিদ ডাউনলোড করুন:** সংগ্রহকারীর প্রোগ্রাম/সংস্করণ রেকর্ড সংরক্ষণ করুন।
- **টাইমস্ট্যাম্প অনুরোধ প্রস্তুত করুন:** একটি অফলাইন অনুরোধ প্রস্তুত করুন একটি টাইমস্ট্যাম্প কর্তৃপক্ষের জন্য; [TIMESTAMP.md](https://phishdestroy.github.io/TgWitness/bn/docs/reference/timestamp/) অনুসরণ করুন একটি প্রতিক্রিয়া পেতে এবং যাচাই করতে।
- **জার্নাল যাচাই করুন:** ইভেন্ট স্বাক্ষর এবং চেইন লিঙ্ক পরীক্ষা করুন। ZIP রপ্তানি মিডিয়াও পরীক্ষা করে।

সমর্থিত ব্রাউজারগুলো বড় এক্সপোর্টগুলো সরাসরি নির্বাচিত ফাইলে সংরক্ষণ করে। অন্যান্য ব্রাউজারগুলো সর্বোচ্চ 128 MiB বাফার করে। সার্ভার চলার সময়, স্ট্রিমিং CLI পুরো প্রতিক্রিয়া বাফার না করেই বড় ডাউনলোড সমর্থন করে:

```
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

অন্য একটি ওয়ার্কস্পেসের জন্য, **Exports → Workspace ID** ব্যবহার করে `--profile ID` যোগ করুন। রিমোট সার্ভারের জন্য, `--url https://your-server` যোগ করুন। ডিফল্ট ট্রান্সফার সীমা হল 5 GiB; `--max-mib` এটি পরিবর্তন করে। স্বাক্ষরিত ZIP সামগ্রীর জন্য ডিফল্টভাবে একটি পৃথক 4 GiB অব্যবহৃত যাচাই সীমা রয়েছে (**Parameters** এটি বাড়ায়; এমন আর্কাইভগুলি যাচাই করতে `verify.py --max-gib N` ব্যবহার করুন)। যাচাইকারী সফটওয়্যারের একটি বিশ্বাসযোগ্য অনুলিপি এবং একটি স্বতন্ত্রভাবে সংরক্ষিত কী ফিঙ্গারপ্রিন্ট/চেকপয়েন্ট ব্যবহার করে আর্কাইভটি যাচাই করুন।

## ইনস্টলেশন পরীক্ষা করুন

```
python start.py --setup-only
python start.py --check
python start.py --check --json
```

`--check` স্থানীয় নির্ভরতা, সাইন-ইন সমর্থন, স্টোরেজ, কী কনফিগারেশন এবং লিসেনিং ঠিকানা পরীক্ষা করে। এটি কিছুই ইনস্টল করে না বা টেলিগ্রামের সাথে সংযোগ করে না। ব্যস্ত পোর্ট মানে অন্য একটি ইনস্ট্যান্স চলছে। অন্য কোনো `--port` ব্যবহার করুন অথবা প্রথমে এটি বন্ধ করুন।

লঞ্চারটি `.venv`-এ ইনস্টল হয়। সহায়ক `python -m tgwitness...` কমান্ডগুলো Windows-এ `.venv\Scripts\python.exe` এবং Linux/macOS-এ `.venv/bin/python` ব্যবহার করতে হবে, যদি না সেই পরিবেশ ইতিমধ্যেই সক্রিয় থাকে।

## সেশন, সুরক্ষা এবং পরিচালনা

একটি বন্ধ, সামঞ্জস্যপূর্ণ টেলিথন SQLite `.session` স্থানীয়ভাবে `python -m tgwitness.sessions account.session --out account.tgwitness-session` দিয়ে রূপান্তর করা যেতে পারে, তারপর Account-এ লোড করা যায়। ডিরেক্ট ফাইল ইমপোর্ট এবং QR লগইনও উপলব্ধ। লগইন ফরম্যাট, SOCKS5, HTTP CONNECT, MTProxy এবং বাহ্যিক মাস্টার কী-এর জন্য [CONNECTION-SECURITY.md](https://phishdestroy.github.io/TgWitness/bn/docs/reference/connection/) দেখুন।

**পজ পর্যবেক্ষণ** সংগ্রহ বন্ধ করে। **লক** শুধুমাত্র ব্রাউজার অ্যাক্সেস বন্ধ করে। ট্যাব বন্ধ করলে কালেক্টর প্রসেস চলতেই থাকে। প্রসেস বন্ধ করলে সংগ্রহ বিঘ্নিত হয়; একটি হিস্ট্রি স্ন্যাপশট সমস্ত মিস হওয়া সম্পাদনা বা মুছে ফেলা পুনর্গঠন করতে পারে না। ইভেন্ট পলিসি, অ্যাটাচমেন্ট কুই, অ্যাকাউন্ট আইসোলেশন, এবং রিস্টার্ট আচরণের জন্য [সংগ্রহ কীভাবে কাজ করে তা](https://phishdestroy.github.io/TgWitness/bn/docs/reference/collection/) দেখুন।

সেশন এবং গোপনীয়তা এনক্রিপ্ট করা হয়। বার্তার বিষয়বস্তু, মিডিয়া এবং এক্সপোর্টগুলির জন্য একটি এনক্রিপ্ট করা ডিস্ক বা ভলিউম প্রয়োজন। স্বাক্ষরগুলি একটি বিশ্বস্ত কী-র সাপেক্ষে অখণ্ডতা প্রতিষ্ঠা করে; এগুলি টেলিগ্রামের উৎস নিশ্চিত করে না বা কালেক্টর এবং এর কী নিয়ন্ত্রণকারী অপারেটর দ্বারা জালিয়াতি প্রতিরোধ করে না।
