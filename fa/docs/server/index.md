# آن را در حال اجرا نگه دارید

Canonical page: https://phishdestroy.github.io/TgWitness/fa/docs/server/

مطمئن شوید که ابزار جمع‌آوری در دسترس باقی بماند و داده‌های آن در طول راه‌اندازی مجدد دست‌نخورده باقی بماند.

## روش راه‌اندازی را انتخاب کنید

برای نصب بومی، از [لانچر](https://phishdestroy.github.io/TgWitness/fa/docs/start/) و مثال‌های سرویس در [deploy/ استفاده کنید.](https://github.com/phishdestroy/TgWitness/blob/main/deploy/README.md) برای Docker، Docker را با Compose نصب کرده و از دایرکتوری پروژه اجرا کنید:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

پنل پیش‌فرض روی آدرس لوپ‌بک میزبان، پورت 8787 گوش می‌دهد. آن را به‌صورت محلی یا از طریق تونل SSH باز کنید. از توکن دستور دوم برای باز کردن پنل استفاده کنید.

## تمام دایرکتوری داده‌ها را حفظ کنید

نصب‌های بومی از `data/live` استفاده می‌کنند. داکر از حجم پایدار `tgwitness-data` استفاده می‌کند. دفترچه‌ها، جلسات حساب کاربری، کلیدها و وضعیت عملیاتی را با هم نگه می‌دارد. یک خروجی امضا‌شده مدرک مفیدی است، اما پشتیبان کامل نصب نیست.

1. پیش از انجام یک نسخه پشتیبان یکپارچه، جمع‌آوری را متوقف کنید.
2. کل دایرکتوری داده‌های خصوصی را به یک فضای ذخیره‌سازی محافظت‌شده خارج از میزبان کپی کنید.
3. پیش از اتکا به نسخهٔ پشتیبان، بازیابی را در یک نصب ایزوله آزمایش کنید.

## پس از راه‌اندازی مجدد بررسی کنید

فضا و کلید مورد انتظار، اتصال تلگرام، منابع انتخاب‌شده و ضبط پیام جدید را تأیید کنید. وضعیت ذخیره‌شده‌ی MTProto و قابلیت جبران به بازیابی به‌روزرسانی‌هایی کمک می‌کند که تلگرام هنوز نگه داشته است. آن‌ها نمی‌توانند هر به‌روزرسانی منقضی‌شده یا ویرایشی را که پیش از ضبط حذف شده است بازسازی کنند.

وضعیت کانتینر به معنای پاسخ‌دادن وب‌سرور است. برای ارزیابی جمع‌آوری و انتشار خارجی از یک پیام کنترل‌شده و بررسی شاهد استفاده کنید.

## فقط آنچه را که قصد دارید منتشر کنید

مرجع استقرار شامل مثال‌های HTTPS، دستورات حجم پایدار، مراحل به‌روزرسانی و بازیابی است. دستورات Docker برای استقرار ارائه شده‌اند؛ [رکورد اعتبارسنجی](https://phishdestroy.github.io/TgWitness/fa/docs/reference/verification/) فعلی، محیط‌های واقعاً آزمایش‌شده را شناسایی می‌کند.
