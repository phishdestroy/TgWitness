ডকুমেন্টেশন / 03

মিনিটখানেকের মধ্যে শুরু করুন

প্রথমে একটি কার্যকর উদাহরণ অন্বেষণ করুন। তারপর আপনার নিজস্ব অ্যাকাউন্ট সংযুক্ত করুন।

অ্যাকাউন্ট ছাড়াই চারপাশে দেখুন

প্রজেক্টটি ডাউনলোড বা ক্লোন করুন, Python 3.11 বা তার পরবর্তী সংস্করণ ইনস্টল করুন, এবং ডেমো চালান। লঞ্চারটি একটি স্থানীয় পরিবেশ তৈরি করে এবং পিন করা নির্ভরতাগুলো ইনস্টল করে।

git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

উইন্ডোজ

.\scripts\Demo.cmd

লিনাক্স / ম্যাকওএস

sh start.sh --demo

ব্রাউজার কাল্পনিক বার্তা সহ একটি কর্মক্ষেত্র খোলে। একটি কথোপকথন খুলুন, একটি সম্পাদনা তুলনা করুন এবং একটি রপ্তানি পরীক্ষা করুন। ডেমো মোড টেলিগ্রামের সাথে সংযোগ করে না।

আপনার নিজস্ব কর্মক্ষেত্র শুরু করুন

ডেমো প্রক্রিয়াটি বন্ধ করুন, তারপর সাধারণ লঞ্চার ব্যবহার করুন:

উইন্ডোজ

.\Start.cmd

লিনাক্স / ম্যাকওএস

sh start.sh

লঞ্চারে প্রদর্শিত স্থানীয় ঠিকানাটি খুলুন। যদি জিজ্ঞাসা করা হয়, টার্মিনালে উল্লেখিত নামের স্থানীয় ফাইল থেকে প্যানেল অ্যাক্সেস টোকেনটি প্রবেশ করান। এটি TgWitness আনলক করে; এটি টেলিগ্রাম সাইন-ইন থেকে আলাদা।

আপনার প্রথম বার্তাটি ধারণ করুন

  1. একটি নিবেদিত টেলিগ্রাম অ্যাকাউন্ট সংযুক্ত করুন।
  2. অ্যাকাউন্টটি যে গ্রুপ বা চ্যানেলে অ্যাক্সেস করতে পারে তা নির্বাচন করুন, তারপর পর্যবেক্ষণ শুরু করুন।
  3. আপনি নিয়ন্ত্রণ করেন এমন একটি পরীক্ষা গ্রুপে একটি নতুন বার্তা পাঠান এবং যাচাই করুন যে এটি জার্নালে প্রদর্শিত হচ্ছে।

সার্ভার ইনস্টলেশনের জন্য Keep it running অনুসরণ করুন।
