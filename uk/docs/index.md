# Від записів Telegram до чіткої справи.

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/

Працюйте зі збереженими повідомленнями та змінами, пов’язуйте свої висновки з їхніми джерелами та готуйте підписані файли для перевірки.

## Ознайомтеся з робочими процесами

Ілюстровані посібники

[### Case Board Зберігайте зв’язок між спостереженнями, точними цитатами та нотатками команди.](https://phishdestroy.github.io/TgWitness/uk/docs/case-board/) [### Студія звітів Оберіть матеріал та один із восьми макетів звітів.](https://phishdestroy.github.io/TgWitness/uk/docs/reports/) [### Поділитися копією Підготуйте підписаний витяг із полями, необхідними для одержувача.](https://phishdestroy.github.io/TgWitness/uk/docs/handover/) [### Групи облікових записів Переглядайте облікові записи разом, але зберігайте їхні робочі простори окремо.](https://phishdestroy.github.io/TgWitness/uk/docs/groups/)

[## Режими, сценарії та рівні доказовості Області збору даних, межі подій, вісім механізмів верифікації та шість вигаданих сценаріїв розслідування.](https://phishdestroy.github.io/TgWitness/uk/guides/modes.html)

## Ваше перше зафіксоване повідомлення

[### Почніть за лічені хвилини Спробуйте TgWitness із зразками даних, а потім запустіть власний робочий простір для спостереження за Telegram на Windows, Linux або macOS.](https://phishdestroy.github.io/TgWitness/uk/docs/start/)[### Спеціальний обліковий запис Створіть окремий акаунт у Telegram для збору даних.](https://phishdestroy.github.io/TgWitness/uk/docs/dedicated-account/)[### Підключити обліковий запис Підключіть Telegram за допомогою QR-коду, номера телефону або імпорту сеансу. Оберіть джерела та переконайтеся, що нові повідомлення надходять до вашого журналу.](https://phishdestroy.github.io/TgWitness/uk/docs/accounts/)[### Виберіть проксі-сервер Підтримуйте автоматичні маршрути MTProxy або використовуйте власний проксі-сервер. Обирайте режими IP, правила резервного переходу та маршрут для зовнішніх запитів.](https://phishdestroy.github.io/TgWitness/uk/docs/proxies/)[### Експорт та перевірка Експортуйте збережену історію Telegram, перевіряйте підписи та порівнюйте журнал із контрольною точкою, збереженою незалежним свідком.](https://phishdestroy.github.io/TgWitness/uk/docs/exports/)[### Запис дій на GitHub Actions Виберіть Takeout，експорт через звичайний API або журнал чату на тимчасовому раннері GitHub．](https://phishdestroy.github.io/TgWitness/uk/docs/capture/)

## Від збережених записів до спільного звіту

[### Проведіть розслідування у всіх чатах Проведіть комплексне розслідування в Telegram, охопивши канали, групи, приватні чати та боти: повне копіювання облікового запису, історію, користувачів, посилання, файли, хронологію та перевірені докази.](https://phishdestroy.github.io/TgWitness/uk/docs/cases/)[### Створити «Case Board» Збирайте збережені спостереження, точні виділення та фрагменти дій на приватній дошці, обговорюйте їх зі своєю командою та презентуйте збірку.](https://phishdestroy.github.io/TgWitness/uk/docs/case-board/)[### Створіть звіт Виберіть дані звіту, один із восьми макетів та зміст, а потім перегляньте попередній варіант і експортуйте HTML, підписаний PDF або повний пакет доказів.](https://phishdestroy.github.io/TgWitness/uk/docs/reports/)[### Підготуйте копію для поширення Виберіть записи та поля, які може отримати одержувач, перевірте готову копію та переконайтеся у правильності підписаного маніфесту та меж журналу джерел.](https://phishdestroy.github.io/TgWitness/uk/docs/handover/)[### Управління групою облікових записів Порівнюйте групові робочі простори, знаходьте джерела, переглядайте періоди спостереження та застосовуйте спільні налаштування з винятками для окремих облікових записів.](https://phishdestroy.github.io/TgWitness/uk/docs/groups/)

## Дізнайтеся, спробувавши його

[### Дізнайтеся, як працює система збереження доказів Простежте шлях повідомлення від моменту фіксації до контрольної точки. Змініть зразок запису, перерахуйте його ланцюжок SHA-256 і подивіться, що виявить збережена контрольна точка.](https://phishdestroy.github.io/TgWitness/uk/docs/concepts/)[### Забезпечте безпеку Дізнайтеся, де зберігаються сесії, ключі та докази, що виходить за межі вашого комп’ютера, що охоплює система захисту та як посилити безпеку інсталяції.](https://phishdestroy.github.io/TgWitness/uk/docs/security/)[### Налаштування бота-свідка Публікуйте підписані контрольні точки журналу у своєму каналі Telegram із окремим свідком, власним ключем та доступом до колектора лише для читання.](https://phishdestroy.github.io/TgWitness/uk/docs/witness/)

[### Export Clinic Watch a controlled Telegram Desktop export experiment, compare seven test conversations, and inspect the original recording and paired files.](https://phishdestroy.github.io/TgWitness/docs/export-clinic/)

## Додавайте лише те, що потрібно

[### Робота з архівом Завантажуйте історію, шукайте збережені записи, переглядайте джерела штучного інтелекту та підключайте свої інструменти.](https://phishdestroy.github.io/TgWitness/uk/docs/archive/)[### Поділитися справою Надайте рецензентам та аналітикам доступ до вибраних акаунтів і чатів із окремими правами доступу, обмеженнями сеансів та токенами, які можна скасувати.](https://phishdestroy.github.io/TgWitness/uk/docs/access/)[### Забезпечте його безперебійну роботу Запустіть TgWitness на сервері з постійним сховищем даних, приватним доступом до панелі управління, резервним копіюванням та перевірками після перезапуску.](https://phishdestroy.github.io/TgWitness/uk/docs/server/)[### З’ясуйте, що пішло не так Перевіряйте доступ до панелі, з’єднання з Telegram, відсутні повідомлення, FloodWait та статус свідка, використовуючи відповідні сигнали для кожної проблеми.](https://phishdestroy.github.io/TgWitness/uk/docs/troubleshooting/)
