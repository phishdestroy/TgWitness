公開ショーケース

選択した公開チャンネルの保存済みメッセージや署名付きスナップショットを、有効期限付きかつ取り消し可能なリンクを通じて公開します。

[アクセス] → [パブリックショーケース] を選択すると、既存の アクセストークンシステムを使用して、独立した読み取り専用のページが作成されます。このページは、インストール先に保存された観測データを読み込みます。ただし、 コレクターを起動したり、Telegram にログインしたり、訪問者用にチャンネルを取得したりすることはありません。

ページを公開する#

  1. 表示したい公開チャンネルごとに、ソースプロファイルを保存してください。チャンネルは、 最後に保存されたプロファイルに公開ユーザー名が含まれている必要があります。グループやプライベートチャットは 対象外となります。
  2. オープンアクセス → 公開ショーケース（または /showcase-manage.html）として公開します。
  3. 最大16のワークスペースにまたがるチャンネルを選択し、公開ページのタイトルを入力して、 リンクの有効期間を1日、7日、または30日から選択します。ワークスペース内のラベルは 公開されません。最大64のチャンネルを含めることができます。
  4. 公開する選択したチャンネルのテキストを確認し、「選択した レコードをプレビュー」をクリックします。プレビューでは、ビジターページと同じサーバーサイドのプロジェクションが使用されます。
  5. 「ショーケースリンクを作成」をクリックします。リンクが表示されている間にコピーしてください。別の ブラウザで開いて、受信者のページを確認してから配布してください。

リンクのURLフラグメントにはアクセストークンが含まれています。ページは、 APIリクエストを行う前にこのフラグメントを削除し、ブラウザセッションと交換します。 リンクを所持しているユーザーは、有効期限が切れるか取り消されるまで、選択されたコンテンツを開くことができます。 新しいリンクでは、最大100の同時セッションが許可され、各セッションの最大継続時間は1時間です。既存の アクセス制御では、grant APIを通じて アドレスの制限やログイン回数の制限を適用することも可能です。通常のレビューアアクセスは別のモードであり、 もともと許可されていたメッセージやファイルは引き続き含まれます。

訪問者に表示される内容#

表示中 非公開に設定されています
公開チャンネルのタイトル、ユーザー名、およびプロフィール確認日の抜粋 アカウントID、ワークスペース内のラベル、および選択されていない情報源
キャプチャされたテキストと保存された各編集内容 構造化された送信者ID、名前、ユーザー名、電話番号、およびプロフィール情報
削除時の記録（利用可能な場合、以前に保存されたテキストを含む） 添付ファイル、アバター、サムネイル、ファイル名、および元のペイロード
著者／プロフィールまたは添付ファイルが記録されたことを示すマーカー 転送および返信のメタデータ、ネットワーク経路、IPアドレス、認証情報
選択したチャンネルのイベント数、現在のコレクション切り替え、ハートビートおよびチェックポイントの間隔 コレクションの制御機能および通常の証拠データエクスポートAPI
署名フィンガープリント、ジャーナルチェックポイント、整合性証明 署名鍵とTelegramセッション

公開メッセージのテキストは自動的に匿名化されません。メッセージ内に記載された名前、メンション、電話番号、 リンクは、そのテキストの一部として残ります。 Redactedこれは、構造化された作成者／プロフィールフィールドに適用されます。公開する前に、 編集や削除の履歴を含め、実際に選択された内容を必ず確認してください。

適格性は、Telegramのリアルタイム検索結果ではなく、最後に保存されたソースプロファイルを反映しています。 後続のプロファイルに公開チャンネルのユーザー名が含まれていない場合、新しいリクエストでは そのチャンネルが除外されます。公開設定が変更された場合は、ソースプロファイルを更新してください。 読者は、以前に受信したコンテンツをすでに保存している可能性があります。

元の署名付き記録は変更されません。表示されるプロジェクションには 別途署名が行われ、元の記録を参照するハッシュが含まれています。プロジェクションの 署名は、表示された内容の真正性を保証するものであり、編集されたバイト列に対する 元のイベントの署名ではありません。

署名と連続性を確認する#

「フィンガープリントと署名付きチェックポイント」を展開し、スナップショットをダウンロードします。ページが 更新されると、ダウンロードには直前のブラウザスナップショットと、それらのジャーナルの境界間の Merkle一貫性証明が含まれます。自動更新は、ページが表示されており、観測結果の最初のページが表示されている間、 1分ごとに実行されます。

TgWitnessをインストールしたら、ダウンロードしたファイルをオフラインで確認してください：

python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256

フィンガープリントは、別途信頼されている参照元から取得する必要があります。ご自身で保持しているスナップショットと比較するには、 以下を使用してください --previous earlier.jsonを使用してください。これにより、 ダウンロードに含まれていた以前のスナップショットが上書きされます。現在の証明は、 その保存済みの境界から開始されなければなりません。認証済みのクライアントは、 GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>を使用してその証明を要求できます。 ジャーナルが短い場合、境界が黙ってリセットされるのではなく、HTTP 409が返されます。

署名付きチェックポイントは、レコード数や不透明なヘッドハッシュを含め、コレクター・ジャーナル全体をコミットします。 表示されるメッセージ数は、 選択された公開チャンネルのみに適用されます。このページには、他のジャーナルの内容は一切表示されません。 これらはイベント数であり、一意のメッセージ数ではありません。設定は 現在の構成を表しており、過去のすべての記録間隔を表すものではありません。

署名および整合性検証により、保持されている 境界に対する変更を検出できます。ただし、署名済みカウンターの再集計、Telegramの 発信元の認証、中断のないキャプチャの証明、あるいは独立した証人の代替は行いません。 それらの検証には、証拠検証ツール、 独立した証人、および実規模でテスト済みの記録をご利用ください。 合成環境は、明示的に「合成」とラベル付けされています。

ページの公開を取り消す、またはホストする#

ショーケースマネージャーまたは既存の「アクセス」セクションにある「取り消し」機能を使用して、 リンクを閉じ、そのすべてのセッションを終了させます。リクエストによりアクセスが終了したと 検出されると、ビジターは表示されている記録を消去します。有効期限と権限は、すべての リクエストごとにチェックされます。ショーケースのアクセス権は、その場で通常のパネルアクセスに変換することはできません。 モードを変更するには、新しいアクセス権を作成してください。

インストール環境の既存のHTTPSアドレスを通じてページを提供します。リンクを公開しても、 新しいポートが開かれたり、トンネルが作成されたり、DNSが変更されたりすることはありません。HTMLおよびAPIは 引き続きユーザーのインストール環境上に残ります。ショーケースの訪問者は、このアクセス権限では通常の メッセージ、プロフィール、メディア、エクスポート、管理用のAPIを利用することはできません。
