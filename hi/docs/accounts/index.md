# Telegram · एक खाता कनेक्ट करें

Canonical page: https://phishdestroy.github.io/TgWitness/hi/docs/accounts/

एक वर्कस्पेस = एक खाता, उसका जर्नल और उसकी कुंजी।

## साइन इन करने का तरीका चुनें

**खाते** → वर्कस्पेस जोड़ें → कनेक्शन सेटिंग्स। इसके लिए अलग खाता इस्तेमाल करें।

- **QR कोड:** Telegram की डिवाइस स्क्रीन से स्कैन करें और पुष्टि करें।
- **फ़ोन नंबर:** नंबर, कोड, फिर 2FA पासवर्ड अगर हो।
- **सेशन इम्पोर्ट:** आपकी अपनी सेशन फ़ाइल या Telegram Desktop डेटा।

बिल्ट-इन API प्रोफ़ाइल या अपना API ID और hash इस्तेमाल करें। यह सिर्फ़ ऐप की पहचान करता है, न आपको लॉगिन करता है न कुछ छिपाता है।

**क्या पहले प्रॉक्सी की आवश्यकता है?**

आप साइन इन करने से पहले [कनेक्शन मार्ग चुन सकते हैं और उसका परीक्षण कर सकते हैं](https://phishdestroy.github.io/TgWitness/hi/docs/proxies/)। प्रत्येक खाते का अपना मार्ग होता है।

## निगरानी के लिए चुनें

1. अपनी ज़रूरत की चैट, ग्रुप या चैनल चुनें।
2. संग्रह सेटिंग्स जाँचें, मीडिया सहित।
3. शुरू करें और कनेक्शन व हाल की गतिविधि जाँचें।

खाते के पास एक्सेस होना चाहिए। एडमिन और सदस्य अलग चीज़ें देखते हैं, जर्नल दिखाता है कि इस खाते को क्या मिला।

पूरा खाता? **स्रोत → अवलोकन दायरा → जाँच मोड**, जाँचें, **दायरा सहेजें**। पूरी गाइड: [पूरे खाते की जाँच](https://phishdestroy.github.io/TgWitness/hi/docs/cases/)।

## पूरा पथ जाँचें

अपने टेस्ट ग्रुप में दूसरे खाते से संदेश भेजें, संपादित करें, हटाएँ। तीनों जर्नल में दिखने चाहिए। फिर [एक्सपोर्ट और सत्यापित करें](https://phishdestroy.github.io/TgWitness/hi/docs/exports/)।

"कनेक्टेड" का मतलब है कनेक्शन काम कर रहा है। पकड़ा गया टेस्ट संदेश का मतलब है घटनाएँ सच में पहुँच रही हैं।

## एक और खाता जोड़ें

**खाते** में नया वर्कस्पेस, वही चरण। हर खाते की कुंजी का फ़िंगरप्रिंट नोट करें ताकि बाद में एक्सपोर्ट अलग पहचान सकें।
