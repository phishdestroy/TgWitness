# תצוגה ציבורית

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/reference/showcase/

פרסם הודעות שנשמרו מערוצים ציבוריים נבחרים ותמונות מצב חתומות באמצעות קישורים שתוקפם פג וניתנים לביטול.

**Access → Public showcase** יוצר דף נפרד, לקריאה בלבד, באמצעות מערכת ה-access-token הקיימת. הוא קורא את התצפיות השמורות של ההתקנה. הוא אינו מפעיל אספן, אינו מתחבר ל-Telegram ואינו רוכש ערוץ עבור מבקר.

## פרסום דף

1. שמור פרופיל מקור עבור כל ערוץ ציבורי שברצונך להציג. על הערוץ להיות בעל שם משתמש ציבורי בפרופיל האחרון שנשמר; קבוצות וצ'אטים פרטיים אינם זכאים.
2. פתח **גישה → תצוגה ציבורית** (או `/showcase-manage.html`) כמנהל.
3. בחרו ערוצים מתוך עד 16 סביבות עבודה, הזינו את כותרת הדף הציבורי, ו בחרו משך חיים לקישור של 1, 7 או 30 ימים. תוויות פנימיות של סביבות העבודה אינן מתפרסמות. ניתן לכלול עד 64 ערוצים.
4. בדקו את הטקסט של הערוצים שנבחרו לקראת פרסום, ולאחר מכן לחצו על **"תצוגה מקדימה של הרשומות שנבחרו"**. התצוגה המקדימה משתמשת באותה הקרנה בצד השרת כמו דף המבקרים.
5. לחצו על **"צור קישור לתצוגה**". העתיקו את הקישור כל עוד הוא מוצג. פתחו אותו ב דפדפן נפרד כדי לעיין בדף של הנמען לפני שתפיצו אותו.

הקישור מכיל אסימון גישה (access token) בחלק ה-URL שלו. הדף מסיר את החלק לפני ביצוע בקשות API ומחליף אותו בהפעלת דפדפן. כל מי שמחזיק בקישור יכול לפתוח את החומר הנבחר עד לתום תוקפו או לביטולו. קישורים חדשים מאפשרים 100 הפעלות בו-זמנית, שכל אחת מהן נמשכת שעה לכל היותר. בקרות הגישה הקיימות יכולות גם לאכוף הגבלות כתובת ומגבלות כניסה באמצעות API ההרשאה. גישת סוקר רגילה היא מצב שונה ועדיין כוללת את ההודעות והקבצים המותרים המקוריים.

## מה רואים המבקרים

| גלוי | נשמר כפרטי |
| --- | --- |
| כותרות ערוצים ציבוריים נבחרים, שמות משתמש ותאריכי תצפית בפרופילים | זהויות חשבונות, תוויות פנימיות של סביבות עבודה ומקורות שלא נבחרו |
| טקסט שנלכד וכל עריכה שנשמרה | מזהי שולח מובנים, שמות, שמות משתמש, מספרי טלפון וערכי פרופיל |
| תצפיות מחיקה עם הטקסט שנשמר קודם לכן, אם קיים | קובצים מצורפים, אווטרים, תמונות ממוזערות, שמות קבצים ותכנים מקוריים |
| סימונים המציינים כי מחבר/פרופיל או קובץ מצורף תועדו | מטא-נתונים של העברה ותגובה, נתיבי רשת, כתובות IP ופרטי הזדהות |
| מספר האירועים בערוצים הנבחרים, מתגי האוסף הנוכחיים, פעימות לב ומרווחי הבדיקות | אמצעי בקרה על האוסף וממשקי API רגילים לייצוא ראיות |
| חתימת טביעת אצבע, נקודת ביקורת ביומן והוכחת עקביות | מפתחות חתימה והפעלות Telegram |

**טקסט של הודעות ציבוריות אינו הופך לאנונימי באופן אוטומטי.** שם, אזכור, מספר טלפון או קישור שנכתבו בהודעה נשארים חלק מאותו טקסט. `Redacted`חלה על שדות המחבר/הפרופיל המובנים. יש לעיין בתוכן שנבחר בפועל לפני פרסומו, כולל עריכות ומחיקות שנשמרו.

הזכאות משקפת את **פרופיל המקור האחרון שנשמר**, ולא חיפוש בזמן אמת ב-Telegram. אם בפרופיל הבא כבר אין שם משתמש של ערוץ ציבורי, בקשות חדשות לא יכללו את הערוץ. יש לרענן את פרופילי המקור כאשר הנראות הציבורית משתנה. ייתכן שהקוראים כבר שמרו חומר שקיבלו בעבר.

התיעודים המקוריים החתומים נשארים ללא שינוי. ההקרנה המוצגת חתומה בנפרד ומכילה חתימות hash המפנות לתיעודים המקוריים. חתימת ההקרנה מאמתת את ההצהרה המוצגת; זו אינה חתימת האירוע המקורי על בייטים שעברו עריכה.

## בדוק חתימות ורציפות

הרחב את **"טביעת אצבע ונקודת ביקורת חתומה**" והורד תמונת מצב. לאחר רענון הדף, ההורדה כוללת את תמונת המצב הקודמת של הדפדפן ואת הוכחת העקביות של מרקל בין גבולות היומן שלהם. הרענון האוטומטי מתבצע פעם בדקה כל עוד הדף גלוי ומציג את עמוד התצפיות הראשון שלו.

לאחר התקנת TgWitness, אמת את הקובץ שהורדת במצב לא מקוון:

```
python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256
```

טביעת האצבע חייבת להגיע ממקור מהימן נפרד. כדי להשוות אותה לתמונת מצב ששמרת בעצמך, השתמש ב- `--previous earlier.json`; פעולה זו מבטלת את תמונת המצב הקודמת הכלולה בהורדה. ההוכחה הנוכחית חייבת להתחיל בגבול שנשמר. לקוחות מאומתים יכולים לבקש הוכחה זו באמצעות `GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>`. יומן קצר יותר מחזיר HTTP 409 במקום לאפס את הגבול בשקט.

נקודת הבדיקה החתומה מתועדת ביומן **האספן כולו**, כולל מספר הרשומות והאש של הכותרת הלא שקופה. ספירת ההודעות המוצגת חלה רק על הערוצים הציבוריים שנבחרו. הדף לעולם אינו מפרט את תוכן היומנים האחרים. מדובר בספירת אירועים, ולא בספירת הודעות ייחודיות. ההגדרות מתארות את התצורה הנוכחית, ולא כל מרווח הקלטה קודם.

אימות החתימה והעקביות יכול לזהות שינויים ביחס לגבול שנשמר. הוא אינו סופר מחדש באופן עצמאי את מוני החתימות, אינו מאשר את מקור ה-Telegram, אינו מוכיח תיעוד רציף, ואינו מחליף עד עצמאי. לצורך בדיקה זו, יש להשתמש [במאמת הראיות](https://github.com/phishdestroy/TgWitness/blob/main/docs/TRUST.md), [בעד העצמאי](https://phishdestroy.github.io/TgWitness/he/docs/reference/witness/) [וברשומה בקנה מידה שנבדקה](https://phishdestroy.github.io/TgWitness/he/docs/reference/verification/). התקנות סינתטיות מסומנות בבירור כסינתטיות.

## לבטל או לארח את הדף

השתמשו **ב-Revoke** במנהל התצוגה או בקטע **ה-Access** הקיים כדי לסגור את הקישור ולסיים את כל הפעילויות שלו. המבקר מוחק את הרשומות המוצגות כאשר בקשה מזהה שהגישה הסתיימה. תוקף וההרשאות נבדקים בכל בקשה. לא ניתן להמיר הרשאות תצוגה לגישה רגילה לפאנל במקום; צרו הרשאה חדשה כדי לשנות מצבים.

הדף מוגש דרך כתובת ה-HTTPS הקיימת של ההתקנה. פרסום קישור אינו פותח יציאה חדשה, אינו יוצר מנהרה ואינו משנה את ה-DNS. ה-HTML וה-API נשארים בהתקנה של המשתמש. מבקר בתערוכה אינו יכול להשתמש ב-API הרגילים להודעות, פרופיל, מדיה, ייצוא או ניהול עם גישה זו.
