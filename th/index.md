## สำเนา S3 การตรวจสอบจากภายนอก

เก็บสำเนาที่เข้ารหัสไว้และเพิ่มการตรวจสอบจากแหล่งอิสระ

ปิดตามค่าเริ่มต้น

### คัดลอกข้อมูลทั้งหมดไปยังพื้นที่จัดเก็บข้อมูลที่รองรับ S3

บันทึก ไฟล์ checkpoint และการส่งออกแชท ถูกเข้ารหัสก่อนส่งไปยัง S3

**การตั้งค่าการเก็บข้อมูลและการกู้คืน**

การเข้ารหัสฝั่งลูกค้า

`AES-256-GCM` บนเครื่องของคุณ ผู้ให้บริการเห็นเพียงข้อมูลที่เข้ารหัสแล้ว

การคัดลอกตามกำหนดเวลาหรือแบบมือ

คัดลอกทันทีหรือทุก 1 ถึง 1，440 นาที ดูความคืบหน้าได้ในแผงควบคุม

Object Lock

เลือกจำนวนวันและโหมดการเก็บรักษา แผงควบคุมจะตรวจว่าค่านั้นมีผลจริง

การกู้คืนที่ได้รับการยืนยัน

เก็บคีย์แยกไว้ กู้คืนได้ทุกที่ ไฟล์จะออกมาหลังผ่านการตรวจสอบเท่านั้น

![แผงคัดลอกข้อมูลนอกไซต์แบบครบถ้วน： จุดปลายทาง （endpoint）， ภูมิภาค （region）， บักเก็ต （bucket）， กุญแจเข้าถึง （access keys）， ตารางเวลา （schedule）， การล็อกวัตถุ （Object Lock） และการควบคุมกุญแจกู้คืน （recovery key controls）](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

แผงควบคุมแบบเต็มที่มีตัวเลือกขั้นสูงถูกขยายออกแล้ว ไม่แสดงข้อมูลรับรองการเข้าถึงพื้นที่จัดเก็บข้อมูล

บันทึกและสื่อ`AES-256-GCM`พื้นที่จัดเก็บข้อมูลที่รองรับ S3

[ตั้งค่า S3 และกู้คืนสำเนา](https://phishdestroy.github.io/TgWitness/th/docs/exports/#s3)[อ่านรายละเอียดการตรวจสอบได้ที่](https://phishdestroy.github.io/TgWitness/th/docs/reference/evidence/#off-site-copy-and-restore-s3)

**คีย์กู้คืน** เก็บแยกไว้ หากไม่มีคีย์ สำเนาจะอ่านไม่ได้

### การแจ้งเตือน · Apprise

ปัญหา การเปลี่ยนแปลงในแชท และสรุปรายวัน ส่งไปยังแอปแชท อีเมล หรือ webhook ของคุณเอง

**เลือกสิ่งที่จะแชร์** ไม่มีเนื้อหาข้อความเว้นแต่คุณจะเปิดไว้

 [กำหนดจุดหมายการแจ้งเตือน](https://phishdestroy.github.io/TgWitness/th/docs/reference/operations/#notifications)

### ข้อมูลเวลาจากแหล่งภายนอก

แฮชจุดตรวจสอบเวลาตาม RFC 3161 และ OpenTimestamps．

**ติดตามผล** ตรวจคำตอบของ TSA หรืออัปเกรดใบรับ OpenTimestamps เป็นหลักฐาน Bitcoin

 [ตรวจสอบหลักฐานเวลา](https://phishdestroy.github.io/TgWitness/th/docs/reference/timestamp/)

### พยานอิสระ

เซิร์ฟเวอร์แยกต่างหากจะเก็บรักษาข้อมูลการสังเกตที่ลงนามแล้ว และสามารถเผยแพร่จุดตรวจสอบ`TGW1` ได้

**แยกจุดอ้างอิง** รันบนโฮสต์อื่น พร้อมคีย์และบันทึกของตัวเอง

 [ตั้งค่า witness](https://phishdestroy.github.io/TgWitness/th/docs/witness/)

### การกู้คืนข้อมูลและช่องว่างที่มองเห็นได้

ต่อจากจุดที่หยุดไว้หลังการรีสตาร์ท ระบบตรวจสอบซ้ำและ`coverage.json` แสดงข้อความที่กู้คืนได้และช่องว่าง

**ตรวจช่วงเวลา** ข้อความที่กู้คืนและช่องว่างที่บันทึกไว้วางคู่กัน

 [ตรวจสอบความต่อเนื่องและช่องว่าง](https://phishdestroy.github.io/TgWitness/th/guides/modes.html#continuity)

### ดาวน์โหลดแหล่งต้นแบบ

[ดาวน์โหลดไฟล์ ZIP ที่ประกอบด้วยซอร์สโค้ด](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip)และแตกไฟล์ออก หรือคัดลอก （clone） รีโพสิตอรี：

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

ต้องใช้ Python 3.11 ขึ้นไป บน Windows ตัวเปิดโปรแกรมจะเสนอให้ติดตั้งให้

[ดูเวอร์ชันที่ปล่อยออกมา](https://github.com/phishdestroy/TgWitness/releases)

ขั้นตอน 02

### เลือกวิธีดำเนินการ

คลิกสองครั้งที่ `Start.cmd` หรือเรียกใช้ใน PowerShell：

```
.\Start.cmd
```

กำลังสำรวจอยู่ใช่ไหม？ คลิกสองครั้งที่ `scripts\Demo.cmd` เพื่อดูเดโมแบบแยกส่วน ไม่จำเป็นต้องเข้าสู่ระบบ Telegram

เมื่อใช้ Python 3.11+ และ`venv`：

```
sh start.sh
```

หากต้องการเปิดสมุดบันทึกสมมติแทน ให้รันคำสั่ง `sh start.sh --demo`

เมื่อ Docker กำลังทำงานและ Compose 2.20+ ได้ติดตั้งแล้ว：

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

คำสั่งที่สองจะแสดงโทเค็นของแผงควบคุมส่วนตัวของคุณ โปรดเก็บไว้บนเครื่องของคุณ

เปิด [127.0.0.1:8787](http://127.0.0.1:8787) หลังจากเปิดใช้งาน

การติดตั้งจากซอร์สเก็บโทเค็นไว้ที่ `data/live/panel-token.txt` คู่ API ของคุณเองจาก [my.telegram.org](https://my.telegram.org) เป็นตัวเลือก [คู่มือการตั้งค่าฉบับเต็ม ↗](https://phishdestroy.github.io/TgWitness/th/docs/reference/quickstart/)

## ก่อนที่จะเริ่ม

**หน้านี้มีการเชื่อมต่อกับ Telegram หรือไม่？**

ไม่ นี่เป็นหน้าเว็บแบบคงที่พร้อมตัวอย่างสมมติ แอปทำงานบนเครื่องของคุณเองและคุณเข้าสู่ระบบที่นั่น

**เครื่องมือนี้สามารถกู้คืนข้อความที่ถูกลบก่อนการบันทึกได้หรือไม่？**

ไม่ได้ มันเก็บสิ่งที่บัญชีของคุณเห็นขณะทำงาน สแนปช็อตภายหลังไม่สามารถสร้างการแก้ไขที่พลาดไปหรือข้อความที่ถูกลบขึ้นใหม่ได้

**บันทึกทั้งหมดของฉันถูกเข้ารหัสหรือไม่？**

เซสชันและคีย์ใช่ ข้อความและไฟล์ไม่ใช่ ให้ใช้การเข้ารหัสดิสก์ การส่งออกตั้งรหัสผ่าน AES－256 ได้

**เว็บไซต์นี้มีความเกี่ยวข้องกับ Telegram หรือไม่？**

ไม่ใช่ นี่เป็นโปรเจกต์อิสระภายใต้สัญญาอนุญาต MIT ที่สร้างบน Telethon คุณเข้าสู่ระบบด้วยบัญชีของคุณเอง
