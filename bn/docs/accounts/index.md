# একটি অ্যাকাউন্ট সংযুক্ত করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/accounts/

একটি ওয়ার্কস্পেস একটি অ্যাকাউন্ট, তার জার্নাল এবং তার স্বাক্ষর কী ধারণ করে।

## কিভাবে সাইন ইন করবেন তা নির্বাচন করুন

**অ্যাকাউন্টগুলো** খুলুন, একটি ওয়ার্কস্পেস যোগ করুন এবং এর সংযোগ সেটিংস খুলুন। পর্যবেক্ষণের জন্য একটি নিবেদিত অ্যাকাউন্ট ব্যবহার করুন।

- **কিউআর কোড:** টেলিগ্রামের ডিভাইস সেটিংস থেকে স্ক্যান করুন এবং নতুন লগইন নিশ্চিত করুন।
- **ফোন নম্বর:** নম্বরটি লিখুন, টেলিগ্রাম যে কোড পাঠায় তা এবং আপনার দুই-ধাপ যাচাইকরণ পাসওয়ার্ড (যদি সক্রিয় থাকে) লিখুন।
- **সেশন আমদানি:** আপনার কোনো সমর্থিত সেশন বা টেলিগ্রাম ডেস্কটপ ডেটা আমদানি করুন।

নির্মাণকৃত API প্রোফাইল নির্বাচন করুন অথবা আপনার নিজস্ব API আইডি এবং হ্যাশ লিখুন। একটি API প্রোফাইল ক্লায়েন্টকে চিহ্নিত করে; এটি কোনো অ্যাকাউন্টে সাইন ইন করে না বা সংযোগটিকে অজ্ঞাতনামা করে না।

**প্রথমে কি একটি প্রক্সি দরকার?**

আপনি সাইন ইন করার আগে [সংযোগের পথ বেছে নিতে এবং পরীক্ষা করতে](https://phishdestroy.github.io/TgWitness/bn/docs/proxies/) পারেন। প্রতিটি অ্যাকাউন্টের নিজস্ব পথ রয়েছে।

## কি পর্যবেক্ষণ করবেন তা নির্বাচন করুন

1. সোর্স তালিকা খুলুন এবং আপনার প্রয়োজনীয় চ্যাট, গ্রুপ বা চ্যানেলগুলো নির্বাচন করুন।
2. পর্যবেক্ষণ শুরু করার আগে মিডিয়া সহ সংগ্রহ সেটিংস পর্যালোচনা করুন।
3. সংগ্রাহকটি চালু করুন এবং এর সংযোগ ও সাম্প্রতিক কার্যকলাপ পরীক্ষা করুন।

অ্যাকাউন্টটিকে উৎস অ্যাক্সেস করার সক্ষমতা থাকতে হবে। বিভিন্ন ভূমিকা বিভিন্ন ইভেন্ট দেখতে পারে; জার্নালটি প্রতিফলিত করে ওই অ্যাকাউন্টটি কী পেয়েছে।

পুরো অ্যাকাউন্ট জুড়ে বিস্তৃত একটি মামলার জন্য, Sources → Observation scope → Investigation mode ব্যবহার করুন, সেটিংস পর্যালোচনা করুন এবং Save scope চাপুন। [সম্পূর্ণ তদন্তের ওয়াকথ্রুতে](https://phishdestroy.github.io/TgWitness/bn/docs/cases/) সব দৃশ্যমান চ্যাট ধরন, পুরনো ইতিহাস, ব্যক্তিদের প্রোফাইল, ক্রস-চ্যাট রেফারেন্স এবং প্রমাণ হস্তান্তর অন্তর্ভুক্ত রয়েছে।

## পুরো পথটি পরীক্ষা করুন

আপনি যে পরীক্ষা গ্রুপটি নিয়ন্ত্রণ করেন, তাতে অন্য একটি অ্যাকাউন্ট থেকে একটি অনন্য বার্তা পাঠান, সেটি সম্পাদনা করুন এবং মুছে ফেলুন। জার্নালে তিনটি ইভেন্টই নিশ্চিত করুন, তারপর রেকর্ডটি [রপ্তানি করে যাচাই করুন](https://phishdestroy.github.io/TgWitness/bn/docs/exports/)।

সংযুক্ত অবস্থা সংযোগ নিশ্চিত করে। ধারণকৃত পরীক্ষা বার্তা নিশ্চিত করে যে একটি নির্দিষ্ট ঘটনা এই কর্মস্থলে পৌঁছেছে।

## আরেকটি অ্যাকাউন্ট যোগ করুন

**Accounts**-এ আরেকটি ওয়ার্কস্পেস তৈরি করুন এবং সেটআপটি পুনরাবৃত্তি করুন। প্রতিটি অ্যাকাউন্টের স্বাক্ষর-কী ফিঙ্গারপ্রিন্ট সংরক্ষণ করুন যাতে পরে এর রপ্তানিগুলো সনাক্ত করতে পারেন।
