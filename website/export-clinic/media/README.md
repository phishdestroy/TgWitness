# Export Clinic media

Images, comparison data and publication manifests used by the Export Clinic.
Start with the [review-package guide](REVIEW_README.md) for its scope and file layout.

| Material | Purpose |
| --- | --- |
| [assets/comparisons/](assets/comparisons/README.md) | Before/modified image pairs |
| [`comparison-data.json`](comparison-data.json) | Structured comparison data |
| [`comparison-poster.jpg`](comparison-poster.jpg) | Video poster |
| [`download-manifest.json`](download-manifest.json) | Published download metadata |
| [`recording-manifest.json`](recording-manifest.json) | Recording and edit metadata |
| [`publication-review.json`](publication-review.json), [`review-file-manifest.json`](review-file-manifest.json) | Publication review and file inventory |
| [`SHA256SUMS.txt`](SHA256SUMS.txt) | Published file checksums |

Keep original and modified materials clearly identified. Changes to the page's
presentation must not silently replace the published demonstration files or their
recorded hashes. The [page source](../README.md) explains local preview.
