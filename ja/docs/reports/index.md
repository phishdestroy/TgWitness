# レポートの作成

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/reports/

読者が、事案の課題から保存された記録へと明確にたどり着けるようにしてください。

Report Studioは、データ選択機能、読みやすい変更履歴、グラフ、および作成者が記述した調査結果を統合します。8つの統合デザインが、サポートされているHTMLおよびネイティブPDF出力に適用されます。HTML、PDF、JSONレポートにはそれぞれ独自の署名付きシールが付与され、ZIPマニフェストもパッケージ内のファイルを結合します。HTMLおよびPDFは、最終的なレイアウトが完了した後にシールが適用されます。

## 3つのステップでレポートを作成する

1. **[エクスポート] → [設定とプレビュー] → [データ]** を開きます。ワークスペース全体を使用するか、チャット、作成者、UTC 観測日（期間を含む）、およびレコードタイプを選択します。日付は、TgWitness がそのレコードを観測した日時を表しています。
2. 「**デザインとコンテンツ**」で、デザインとコンテンツのプリセットを選択してください。アクティビティチャート、参加者ラベル、トランスクリプト、保存された変更点、およびオプションのケースボード資料を選択します。事件の詳細と調査メモを追加してください。
3. **「プレビュー」**を開き、件数、アクティビティ、参加者、サンプリングされた記録、および欠落しているID範囲を確認してください。設定を保存してから、必要な形式でダウンロードしてください。

### 保存された資料を、読者が理解しやすいように整理してください

合成例・概略レイアウトであり、生成されたレポートではありません

1. **[選択]。**本案件の対象となるチャットを2つと、観察期間を選択してください。
2. **文章を作成してください。**レイアウトを選択し、質問に答えるセクションを選んでください。
3. **プレビュー。**選択された件数と、保存された「変更前」および「変更後」のテキストを確認してください。
4. **検証を行ってください。**最終ファイルを生成し、その署名を信頼できるワークスペースのフィンガープリントと照合して確認してください。

## 読み方のスタイルを選択してください

**「Classic」、「Editorial」、「Briefing」、「Analytics」、「Technical」、「Overview」、「Reading series」、および「Ledger & margin」**は、同じ基礎となる記録を異なる構成で提示します。デザインを変更しても、データの選択内容や記述されたメモは保持されます。レポートの言語は、サポートされている 25 言語から選択可能です。

「Reading」シリーズでは、セクションレールを軸に、ケース、範囲、調査結果、変更点をまとめています。「Ledger & margin」では、番号付き章と広い余白を採用しています。どちらの形式も、アカウントのHTML概要表示やコピーの共有に対応しています。 ネイティブPDFはバンドルされたフォントを使用して生成されます。PDF作成のために、ユーザーのマシンにブラウザやNodeのインストールは必要ありません。中国語、日本語、韓国語のPDFについては、さらにサーバー上にNoto Sans CJKなどの適切なフォントが、システム全体にインストールされているか、`TGWITNESS_FONT_DIR`に配置されている必要があります。それがない場合、ZIPファイルにはHTMLおよびJSONレポートのみが含まれます。

## 変更内容をその文脈とともに読み取る

保存された編集内容は「変更前」と「変更後」の両方が表示されます。削除通知には、最後にキャプチャされたバージョンが併記される場合があります。返信、引用、転送、リアクション、ボタン、および添付ファイルのメタデータについては、利用可能な参照情報が保持されます。ファイルの SHA-256 ハッシュとジャーナルレコードのハッシュは、個別にラベル付けされています。

デザインプレビューでは、最初の 50,000 件のソースレコードの中から一致するレコードを使用した、表紙、調査、およびチャートの各コンポーネントが表示されています。別のデータプレビューでは、安定版のジャーナルスナップショット全体をスキャンして正確な選択件数を算出し、表示されるサンプル数の上限にはラベルが付いています。PDF を生成して、最終的なページ構成を確認してください。 アカウント全体のエクスポートにはHTML形式の概要が含まれ、個々のチャットPDFには選択したデザインが適用されます。

## 受信者向けの文言は慎重に選定してください

レポートフィルターにより、読みやすいレポートが生成されます。完全な証拠用ZIPファイルには、元のジャーナルと添付ファイルがそのまま保持されます。受信者が選択されたデータのみを受け取る必要がある場合は、[最小限の引き渡し](https://phishdestroy.github.io/TgWitness/ja/docs/handover/)を行ってください。[レポートの内容と検証](https://phishdestroy.github.io/TgWitness/ja/docs/reference/case-reports/)を確認するか、[完成したエクスポートファイルを検証してください](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)。
