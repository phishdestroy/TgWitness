# Telegram · আর্কাইভ নিয়ে কাজ করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/archive/

বার্তাটি খুঁজে বের করুন। উৎস যাচাই করুন। মামলা গড়ে তুলুন।

01**ইতিহাস আনুন**

সক্রিয় উৎসগুলোর পুরোনো বার্তা ওয়ার্কস্পেসে টেনে আনুন।

02**উৎসগুলো অনুসরণ করুন**

খুঁজুন, তারপর প্রতিটি ফলাফলের পেছনের সংরক্ষিত বার্তা খুলুন।

03**হ্যান্ডঅফ পরিষ্কার রাখুন**

আপনার বিশ্লেষণ একটি ফাইলে, স্বাক্ষরিত প্রমাণ তার পাশে।

ধৃত রেকর্ড, স্বীকৃত পাঠ্য এবং বিশ্লেষকের উপসংহার পৃথকভাবে থাকে।

## পূর্বের বার্তাগুলো লোড করুন

1. **উৎস → পরিসরের চ্যাট**: সক্রিয় চ্যাট যাচাই করুন, পর্যবেক্ষণ শুরু করুন।
2. **সম্পূর্ণ ইতিহাস লোড করুন**। এটি উৎসের তালিকা এখন যেমন আছে তেমনই নেয়।
3. **ইতিহাস থামান** / **ইতিহাস চালিয়ে যান** যেকোনো সময়। রিস্টার্টের পরে নিজে আবার শুরু করুন।
4. প্রতিটি উৎসের ফলাফল ও ডাউনলোড সারি দেখুন, স্বাক্ষরিত অগ্রগতি রিপোর্ট এক্সপোর্টের সাথে রাখুন।

এটি ওয়ার্কস্পেস ভরে। একটি চ্যাটের HTML/JSON এক্সপোর্ট আলাদা জিনিস। [বিস্তারিত](https://phishdestroy.github.io/TgWitness/bn/docs/reference/history/)।

## প্রথমে অনুসন্ধান করুন, তারপর এআই সম্পর্কে সিদ্ধান্ত নিন।

1. **জার্নাল** স্থানীয়ভাবে খোঁজে, উৎস ও সময় দিয়ে ফিল্টার করুন।
2. কোনো বাক্যাংশ বা ডোমেইন খুঁজুন, রেকর্ড ও তার সংস্করণ খুলুন।
3. AI-এর জন্য অ্যাডমিন **ইন্টিগ্রেশন**-এ প্রদানকারী সেট করেন। তারপর **আর্কাইভকে জিজ্ঞাসা করুন**: চ্যাট ও সময়কাল বেছে নিন, **মডেলে পাঠানো ডেটা** দেখুন এবং যা বাইরে যাওয়া উচিত নয় তার টিক তুলে দিন।
4. উদ্ধৃতি যাচাই করুন, উত্তর রিপোর্ট হিসেবে সংরক্ষণ করুন, নিজের নোট যোগ করুন।

খোঁজার জন্য AI লাগে না। রিপোর্ট স্বাক্ষরিত জার্নাল থেকে আলাদা নিজের উৎস ও সংশোধন রাখে। [প্রদানকারী সেটআপ](https://phishdestroy.github.io/TgWitness/bn/docs/reference/analysis/)।

## আপনার প্রয়োজনীয় সংযোগ নির্বাচন করুন

| টাস্ক | খোলা | সেটআপ |
| --- | --- | --- |
| AI ক্লায়েন্টকে নির্বাচিত চ্যাট পড়তে দিন | **ইন্টিগ্রেশনসমূহ → MCP** | [MCP ইনস্টল করুন, সীমিত টোকেন বানান, সংযোগ করুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/mcp/) |
| সংরক্ষিত মিডিয়ায় টেক্সট সনাক্ত করুন | `media.saved` রেকর্ড → **সংযুক্তি সনাক্ত করুন** | [স্থানীয় Docker ওয়ার্কার সেট করুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/media-analysis/) |
| n8n বা SIEM-এ ইভেন্ট পাঠান | **ইন্টিগ্রেশনসমূহ → আউটগোয়িং ওয়েবহুকস** | [প্রাপক যোগ করুন, HMAC যাচাই করুন, দ্বৈত ID বাদ দিন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/webhooks/) |

**কোন অ্যাক্সেস টোকেন কোথায় যাবে?**

প্যানেল অ্যাক্সেস মানুষের জন্য। MCP-র নিজস্ব শুধু-পড়ার টোকেন আছে, webhooks-এর নিজস্ব HMAC সিক্রেট। কারও Telegram সেশন লাগে না।

[প্যানেল অ্যাক্সেস শেয়ার করুন](https://phishdestroy.github.io/TgWitness/bn/docs/access/) অথবা [একটি MCP ক্লায়েন্ট কনফিগার করুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/mcp/)।
