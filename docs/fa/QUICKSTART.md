# راه‌اندازی سریع TgWitness

برنامهٔ TgWitness ابزاری مستقل برای مشاهدهٔ گروه‌ها و کانال‌های Telegram است که حساب‌های شما به
آن‌ها دسترسی دارند. این برنامه به‌صورت محلی و با دایرکتوری دادهٔ مخصوص خودش اجرا می‌شود.

**اولین بار است که به اینجا می‌آیید؟** پیش از اتصال حساب، [دمو را امتحان کنید](#explore-the-interface).
برای پروکسی‌ها، شاهدها، خروجی‌ها یا راه‌اندازی سرور، [راهنمای مناسب را انتخاب کنید](../README.md).
[ثبت با GitHub Actions](../SEALED-ACTIONS.md) (پیش‌نمایش) به‌جای نصب محلی، ثبت را در fork خودتان
در GitHub اجرا می‌کند.

<a name="install-and-start"></a>

## نصب و اجرا

نصب‌کنندهٔ مرحله‌به‌مرحله Python مخصوص خودش را همراه دارد و پیش از نصب، هش بسته‌ها و امضای
نسخه‌ها را بررسی می‌کند. اجرای دوبارهٔ آن، نصب موجود را به‌روزرسانی می‌کند.

**در Linux / macOS:**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**در Windows (PowerShell یا خط فرمان):**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

روی سرور Ubuntu، برای نصب سرویس پس‌زمینه آن را با کاربر root اجرا کنید؛ روی دسکتاپ، با کاربر
معمولی خودتان. در Ubuntu، نصب‌کننده نشانی پنل و کلید دسترسی را چاپ می‌کند؛ در macOS و Windows،
پنل محلی در مرورگر شما باز می‌شود. از مرحلهٔ **اتصال Telegram** در ادامه پیش بروید. راهنمای
[نصب، راستی‌آزمایی و به‌روزرسانی](../INSTALLATION.md) گزینه‌های دسترسی به سرور، بررسی اسکریپت
پیش از اجرا، به‌روزرسانی‌ها و حذف برنامه را شرح می‌دهد.

### روش‌های دیگر

انتشارهای GitHub، کد منبع و Docker جایگزین‌های نصب‌کننده هستند. بسته‌های قابل‌حمل پس از
انتشار بیلد نسخه برای دانلود در دسترس قرار می‌گیرند:

| میزبان | بدون نیاز به نصب | از کد منبع: Python 3.11 یا جدیدتر | با Docker: Engine/Desktop همراه با Compose 2.20 یا جدیدتر |
| --- | --- | --- | --- |
| Windows | فایل `TgWitness-<version>-windows-amd64-portable.zip` را از GitHub Releases استخراج کنید و روی `TgWitness.cmd` دوبار کلیک کنید | روی `Start.cmd` دوبار کلیک کنید | روی `scripts\Docker.cmd` دوبار کلیک کنید |
| Linux / macOS | — | `sh start.sh` | `sh scripts/docker-start.sh` |

برای روش‌های مبتنی بر کد منبع، [شاخهٔ فعلی `main` را دانلود و استخراج کنید](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip)
یا مخزن را clone کنید:

```sh
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

اگر Python مناسبی پیدا نشود، `Start.cmd` پیشنهاد می‌کند Python 3.12 را برای کاربر Windows شما
نصب کند (با winget یا نصب‌کنندهٔ امضاشدهٔ python.org). اگر Python نصب نباشد، `start.sh` دستور
دقیق نصب را برای توزیع Linux یا macOS شما چاپ می‌کند. نخستین اجرا از کد منبع، `.venv` را می‌سازد
و وابستگی‌ها را خودکار نصب می‌کند.

با Docker، برنامه ساخته و در پس‌زمینه اجرا می‌شود؛ به Python روی میزبان نیازی نیست.
`scripts\Docker.cmd` و `scripts/docker-start.sh` وقتی کانتینر سالم باشد، نشانی پنل و توکن را چاپ
می‌کنند. دستورهای معادل Docker روی همهٔ میزبان‌های پشتیبانی‌شده این‌هاست:

```sh
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

نشانی **http://127.0.0.1:8787** را باز کنید. از توکنی که ابزار کمکی Docker یا دومین دستور Docker
چاپ می‌کند استفاده کنید، یا در نصب قابل‌حمل یا نصب از کد منبع، **data/live/panel-token.txt** را
بخوانید. از مرحلهٔ **اتصال Telegram** در ادامه پیش بروید. نصب بومی و نصب Docker فضای ذخیره‌سازی
جداگانه دارند؛ اجرای Docker ژورنال موجودِ نصب بومی را وارد نمی‌کند.

برای سرور، راهنمای [استقرار](DEPLOYMENT.md) HTTPS خودکار، راه‌اندازی مجدد، ایمیج‌های منتشرشده،
به‌روزرسانی‌ها و پشتیبان‌گیری را پوشش می‌دهد.

## آشنایی با رابط کاربری

1. در بستهٔ قابل‌حمل **TgWitness-Demo.cmd**، در پوشهٔ کد منبع روی Windows **scripts\Demo.cmd**
   و روی Linux/macOS دستور `sh start.sh --demo` را اجرا کنید. اجرا از کد منبع ابتدا `.venv` را
   می‌سازد و وابستگی‌ها را نصب می‌کند.
2. نشانی **http://127.0.0.1:8787** را باز کنید.
3. دموی محلی ژورنال نمونه را خودکار باز می‌کند. برای دسترسی مستقیم محلی نیازی به کپی توکن نیست.

پیام‌های دمو ساختگی‌اند. در حالت دمو نمی‌توان حساب واقعی Telegram را متصل کرد.

## اتصال Telegram

> [!WARNING]
> **از حساب‌های اختصاصی استفاده کنید.** ممکن است Telegram، فارغ از نوع کلاینت، حساب‌ها را به
> دلیل حجم درخواست‌هایی که آن را بیش از حد می‌داند محدود یا برای همیشه مسدود کند. به‌جای
> حساب‌های شخصی یا ارزشمند، حساب‌هایی را متصل کنید که برای مشاهده آماده شده‌اند، و شناسهٔ API و
> هش (API ID / hash) را هم روی یک حساب اختصاصی بسازید.

1. اگر دموی بومی در حال اجراست، آن را متوقف کنید و **Start.cmd** یا `sh start.sh` را اجرا کنید.
   در غیر این صورت، بگذارید نصب واقعی‌ای که بالاتر راه انداختید همچنان در حال اجرا بماند.
2. با توکن پنل وارد شوید. فضای کاری جدید [راه‌اندازی نخست](../SETTINGS.md) را باز می‌کند. یکی از
   گزینه‌های **فقط دانلود**، **دنبال کردن گفتگوها** یا **مدارک یک پرونده** را انتخاب کنید.
3. نتیجهٔ بررسی اتصال را مرور کنید. در صورت نیاز پروکسی خودتان را پیکربندی کنید؛ تنظیمات اتصال
   پس از راه‌اندازی هم در دسترس می‌مانند.
4. در **اتصال تلگرام**، یک شماره تلفن، یک کد QR، فایل‌های حساب (TData، `.session`،
   StringSession، فایل JSON حساب) یا یک کلید دسترسی کامل را انتخاب کنید. هنگام درخواست، تأیید
   تلگرام، کد و رمز عبور دو مرحله‌ای را تکمیل کنید.
5. حساب نمایش‌داده‌شده را بررسی کنید، چت‌ها را انتخاب کنید و تنظیمات خود را مرور کنید. راه‌اندازی
   را از صفحهٔ آخر به پایان برسانید. در حالت **فقط دانلود**، دکمهٔ **شروع صدور** یک خروجی یک‌باره
   را آغاز می‌کند و برای نمایش پیشرفت آن، صفحهٔ خروجی‌ها را باز می‌کند؛ مشاهدهٔ پیوسته را فعال
   نمی‌کند.

پس از راه‌اندازی، چت‌های انتخاب‌شده را با **چت‌ها → انتخاب کنید** تغییر دهید. **تنظیمات**
جمع‌آوری و فایل‌ها را کنترل می‌کند؛ **ابزارهای بیشتر → منابع** فهرست مفصل منابع را در سطح
استاندارد یا متخصص در اختیار می‌گذارد. [راهنمای پنل](../PANEL.md) شش بخش اصلی و کنترل‌های وابسته
به زمینهٔ هر کدام را شرح می‌دهد.

فیلد **شناسهٔ API + هش** اختیاری است: فضای کاری از جفت ذخیره‌شده یا واردشدهٔ خود، یا از یک جفت
کارا از مجموعهٔ داخلی استفاده می‌کند. برای استفاده از اپلیکیشن خودتان، یک جفت `API ID:API Hash`
را در فیلد شناسهٔ API بچسبانید. برای **کلید احراز هویت**، هر 512 نویسهٔ هگزادسیمال را بچسبانید و
شناسهٔ DC ارائه‌شده را انتخاب کنید. شناسهٔ کاربر اختیاری است و اگر وارد شود، بررسی می‌شود.

اعتبارنامه‌های API اپلیکیشن شما را شناسایی می‌کنند و به‌تنهایی به هیچ حسابی مجوز نمی‌دهند.
گروه‌های خصوصی به نام کاربری عمومی نیاز ندارند، اما حساب شما باید به آن‌ها دسترسی داشته باشد.

برای حساب‌های موجود، [حساب‌ها و قالب‌های جلسه](../ACCOUNTS.md) را ببینید: پنل Telethon
StringSession، Telethon/Pyrogram SQLite، TData ZIP تک‌حسابی و JSON حساب در قالب‌های
پشتیبانی‌شده را می‌پذیرد. جلسه و فایل JSON همراهش را با هم انتخاب کنید و **اتصال حساب** را بزنید.
ورود با QR هم با همان تنظیمات اختیاری API در دسترس است. TDLib، جلسه‌های بات و فهرست‌های حساب
CSV/JSON پشتیبانی نمی‌شوند.

برای چند حساب، از **حساب‌ها → وارد کردن حساب‌ها** استفاده کنید و فایل‌های جلسهٔ پشتیبانی‌شدهٔ
آن‌ها را انتخاب کنید. فایل‌های JSON همراه بر اساس نام فایل بدون پسوند جفت می‌شوند؛ هر حساب
واردشده فضای کاری خودش را می‌گیرد.
[وارد کردن گروهی و گروه‌های حساب](../ACCOUNTS.md#bulk-import-and-account-groups) را ببینید.

برای افزودن حساب دیگر، روی **+** کنار انتخابگر حساب بزنید یا از **حساب‌ها → افزودن حساب** استفاده
کنید. فضاهای کاری جلسه‌ها، ژورنال‌ها، کلیدها، منابع و صف‌های جداگانه دارند. جابه‌جایی بین نماها
جمع‌آورنده‌های دیگر را متوقف نمی‌کند. در این نصب، یک حساب Telegram را نمی‌توان به دو فضای کاری
اختصاص داد. تعداد فضاهای کاری ثابت نیست؛ همه در یک فرایند مشترک‌اند، پس ظرفیت به دستگاه بستگی
دارد.

توکن پنل نصب واقعی از دسترسی به مجوزهای Telegram و مطالب ذخیره‌شدهٔ شما محافظت می‌کند و از
اعتبارنامه‌های Telegram API جداست. فقط دموی محلی‌ای که صراحتاً راه‌اندازی شده و مستقیم به آن
دسترسی پیدا می‌شود، ورود خودکار دارد. دموی راه دور یا پشت پروکسی همچنان از
`data/demo/panel-token.txt` استفاده می‌کند.

## بازبینی و خروجی گرفتن

- **ژورنال:** مشاهدات را بر اساس منبع و نوع رویداد جست‌وجو و فیلتر کنید.
- یک رویداد را انتخاب کنید تا رکورد اصلی، انتساب و نسخه‌های ذخیره‌شدهٔ آن را بررسی کنید.
- جزئیات ویرایش، محتوای موجودِ پیش و پس از ویرایش را نشان می‌دهد. جزئیات حذف، آخرین محتوای
  ثبت‌شده را در صورت وجود نشان می‌دهد؛ عاملِ ناشناخته ناشناخته باقی می‌ماند.
- **خروجی‌ها:** ZIP امضاشده، JSONL، CSV و HTML آفلاین.
- **خروجی کامل چت** (**چت‌ها → خروجی چت** یا **خروجی‌ها → ثبت یا خروجی گرفتن از یک گفتگو**): کل
  تاریخچهٔ قابل‌مشاهدهٔ یک چت را به‌صورت بستهٔ امضاشده با `chat.json` (به سبک خروجی Telegram) و
  یک `chat.html` خوانا دانلود کنید. از چت‌های خصوصی هم، در صورتی که حساب عضو باشد، می‌توان خروجی
  گرفت. این خروجی تصویری لحظه‌ای از وضعیت فعلی است، نه بازسازی پیام‌های حذف‌شده یا پیش‌تر
  ویرایش‌شده. یک نسخه را با `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256`
  راستی‌آزمایی کنید.
- **ذخیره نقطه کنترل:** مرز ژورنالِ امضاشده را بیرون از جمع‌آورنده نگه دارید.
- **دانلود رسید اجرای امضا شده:** سابقهٔ برنامه و نسخهٔ جمع‌آورنده را حفظ کنید.
- **درخواست مهر زمانی را آماده کنید:** یک درخواست آفلاین برای مرجع مهر زمانی آماده کنید؛ برای
  دریافت و راستی‌آزمایی پاسخ، [TIMESTAMP.md](../TIMESTAMP.md) را دنبال کنید.
- **تأیید ژورنال:** امضای رویدادها و پیوندهای زنجیره را بررسی می‌کند. خروجی ZIP رسانه‌ها را هم بررسی
  می‌کند.

مرورگرهای پشتیبانی‌شده خروجی‌های بزرگ را مستقیم در فایلی که انتخاب می‌کنید ذخیره می‌کنند.
مرورگرهای دیگر حداکثر 128 MiB را بافر می‌کنند. تا زمانی که سرور در حال اجراست، CLI جریانی
دانلودهای بزرگ‌تر را بدون بافر کردن کل پاسخ پشتیبانی می‌کند:

```sh
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

برای فضای کاری دیگر، با استفاده از **خروجی‌ها → شناسهٔ فضای کاری**، `--profile ID` را اضافه کنید.
برای سرور راه دور، `--url https://your-server` را اضافه کنید. سقف پیش‌فرض انتقال 5 GiB است و
`--max-mib` آن را تغییر می‌دهد. محتوای ZIP امضاشده به‌طور پیش‌فرض سقف جداگانه‌ای برای
راستی‌آزمایی دارد: 4 GiB بدون فشرده‌سازی (**ابزارهای بیشتر → پارامترها** آن را بالا می‌برد؛ چنین
آرشیوهایی را با `verify.py --max-gib N` راستی‌آزمایی کنید). آرشیو را با یک نسخهٔ مورد اعتماد از
ابزار راستی‌آزمایی، اثر انگشت کلیدی که به‌طور مستقل نگهداری شده و، برای حداقلِ لازم برای مدرک،
گواهی ریشهٔ مرجع مهر زمانی (`--tsa-ca`) راستی‌آزمایی کنید.

## بررسی نصب

```sh
python start.py --setup-only
python start.py --check
python start.py --check --json
```

گزینهٔ `--check` وابستگی‌های محلی، پشتیبانی از امضا، ذخیره‌سازی، پیکربندی کلید و نشانی شنود را
بررسی می‌کند. چیزی نصب نمی‌کند و به Telegram وصل نمی‌شود. اشغال بودن پورت ممکن است به این معنا
باشد که نمونهٔ دیگری در حال اجراست. از `--port` دیگری استفاده کنید یا ابتدا آن نمونه را متوقف کنید.

راه‌انداز در `.venv` نصب می‌کند. دستورهای کمکی `python -m tgwitness...` باید در Windows با
`.venv\Scripts\python.exe` و در Linux/macOS با `.venv/bin/python` اجرا شوند، مگر آنکه آن محیط از
قبل فعال باشد.

## جلسه‌ها، محافظت و بهره‌برداری

یک فایل `.session` از نوع Telethon SQLite را که بسته و یکپارچه باشد می‌توان به‌صورت محلی با
`python -m tgwitness.sessions account.session --out account.tgwitness-session` تبدیل کرد و سپس در
**ابزارهای بیشتر → حساب → فایل‌ها** بارگذاری کرد. وارد کردن مستقیم فایل و ورود با QR هم در دسترس
است. برای قالب‌های ورود، SOCKS5، HTTP CONNECT، MTProxy و کلیدهای اصلی خارجی،
[CONNECTION-SECURITY.md](../CONNECTION-SECURITY.md) را ببینید.

گزینهٔ **تعویق مشاهده** جمع‌آوری را متوقف می‌کند. **قفل** فقط دسترسی مرورگر را می‌بندد. بستن
زبانه، فرایند جمع‌آورنده را متوقف نمی‌کند. متوقف کردن فرایند، جمع‌آوری را قطع می‌کند؛ تصویر لحظه‌ای
تاریخچه نمی‌تواند همهٔ ویرایش‌ها یا حذف‌های ازدست‌رفته را بازسازی کند. برای سیاست‌های رویداد،
صف‌های پیوست، جداسازی حساب‌ها و رفتار هنگام راه‌اندازی مجدد، [نحوهٔ کار جمع‌آوری](../COLLECTION.md)
را ببینید.

جلسه‌ها و رازها رمزگذاری می‌شوند. محتوای پیام‌ها، رسانه‌ها و خروجی‌ها به دیسک یا ولوم رمزگذاری‌شده
نیاز دارند. امضای ژورنال را در برابر یک کلید مورد اعتماد راستی‌آزمایی کنید و نقاط کنترل را جداگانه
نگه دارید. سوابق ثبت، رسیدهای زمانی خارجی و گواهی‌های محیط (attestation) را برای حالت جمع‌آوری
انتخاب‌شده بررسی کنید.

برای پشتیبان‌گیری/بازیابی [OPERATIONS.md](../OPERATIONS.md)، برای میزبانی [DEPLOYMENT.md](DEPLOYMENT.md)
و برای نمونه‌های سرویس [deploy/](../../deploy/README.md) را بخوانید. پنل نصب‌شده یک راهنمای
راه‌اندازی آفلاین هم در `/guide.html` دارد.

و [READINESS.md](../internal/READINESS.md) ثبت شده‌اند.
