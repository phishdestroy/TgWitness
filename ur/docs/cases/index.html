تمام چیٹس میں تفتیش کریں

چینلز، گروپس، نجی چیٹس اور بوٹس پر پھیلا ایک پورا کیس: جمع کریں، کڑیاں جوڑیں، ٹائم لائن دوبارہ بنائیں، حوالے کریں۔

ایک فرضی واقعہ، شروع سے آخر تک۔ جمع کرنا، تلاش اور افراد کے پروفائل ریکارڈ ڈھونڈتے ہیں، Case Board انہیں منظم کرتا ہے، Report studio پیش کرتا ہے۔

حل شدہ کیس / ادائیگی کے مقام میں تبدیلی

ایک واقعہ۔ چار گفتگوئیں۔ ایک سراغ دوبارہ ترتیب دینا ہے۔

ایک چینل پوسٹ ایک بوٹ کی طرف اشارہ کرتی ہے۔ ایک گروپ نئے ادائیگی لنک کی بات کرتا ہے اور بوٹ اسے دکھاتا ہے۔ پوسٹ میں ترمیم ہوتی ہے، نجی چیٹ لنک دہراتی ہے، گروپ کا ایک پیغام غائب ہو جاتا ہے۔

ہر ورژن کون نے پوسٹ کیا؟لنک کہاں ظاہر ہوا؟کنہیں فائل محفوظ کی گئی تھی؟کیا تبدیل ہوا، اور کب؟
1. تمام چیٹس2. تاریخ اور فائلیں3. لائیو ایکشنز4. روابط5. ٹائم لائن6. دیگر اکاؤنٹس7. کیس پیکج

تاریخ لوڈ کرنا، AI، MCP، OCR اور webhooks: آرکائیو پر کام۔

1. پورے اکاؤنٹ پر کوریج قائم کریں

پورے اکاؤنٹ کا دائرہ صرف مخصوص اکاؤنٹ پر۔ مرکزی اکاؤنٹ کو منتخب چیٹس یا ایک فولڈر ملتا ہے۔

  1. اکاؤنٹ جوڑیں اس کی اپنی ورک اسپیس میں۔ کیس حوالہ، اکاؤنٹ ID، ورک اسپیس اور کلید فنگر پرنٹ نوٹ کریں۔
  2. ذرائع ← مشاہدے کا دائرہ ← تفتیشی موڈ: پورا اکاؤنٹ، چاروں ذرائع کی اقسام، اپنی کارروائیاں۔ ہر نئی چیٹ کا پروفائل اور آخری 200 نظر آنے والے پیغامات محفوظ ہوتے ہیں۔ دائرہ محفوظ کریں اور تصدیق کریں۔
  3. چیٹس لوڈ کریں اور اکاؤنٹ کی چیٹ فہرست سے موازنہ کریں۔ حد 1,000 مکالمے ہے (پیرامیٹرز ← اکاؤنٹ کی فہرست سے پڑھی گئی چیٹس میں 20,000 تک)؛ اس سے آگے کی چیٹس فعال ہونے پر نظر آتی ہیں۔
  4. ریکارڈنگ سیٹنگز ← تمام نظر آنے والی سرگرمی، اٹیچمنٹ کی حدیں اور ڈسک کی جگہ جانچیں۔ شروع کریں، پھر ایک پیغام، ایک ترمیم اور ایک حذف سے ٹیسٹ کریں۔

"پورا اکاؤنٹ" کا مطلب ہے ہر وہ چیٹ جو یہ اکاؤنٹ کھول سکے، مستثنیات کے سوا۔ خفیہ چیٹس نہیں۔ نئی چیٹس ظاہر ہوتے ہی شامل ہوتی ہیں؛ پرانی تاریخ خودکار ڈاؤن لوڈ نہیں ہوتی۔

2. تاریخ حاصل کریں اور فائلوں کو محفوظ کریں

Case Board کلیکشن بنائیں اور اہم چیزوں کو بک مارک کریں۔ ذرائع کا رجسٹر رکھیں: چیٹ ID، عنوان، اکاؤنٹ، کردار، براہِ راست کیپچر کا آغاز، تاریخ کا نتیجہ، میڈیا کا نتیجہ، خلا۔

اس حصول کو منتخب کریں جو سوال کا جواب دیتا ہو۔
ضرورتپینل میں کارروائییہ کیا فراہم کرتا ہے
چالو کی گئی چیٹس کی تاریخماخذ → مکمل تاریخ لوڈ کریںماضی کے دستیاب پیغامات ورک اسپیس جرنل میں داخل ہوتے ہیں، وقف/ازسرنو شروع کرنے کی سہولت اور ایک دستخط شدہ پیش رفت رپورٹ کے ساتھ۔ تاریخ رہنما۔
جرنل میں موجودہ چیٹ کا سیاق و سباقماخذ → ریکارڈنگ ترتیبات → ہسٹری کا اسنیپ شاٹحالیہ پیغامات دستخط شدہ ریکارڈز کے طور پر۔ ڈیفالٹ 500، پیرامیٹرز ← سب سے بڑا تاریخ اسنیپ شاٹ میں 10,000 تک۔
ایک چیٹ کی فی الحال دکھائی دینے والی مکمل تاریخمکمل چیٹ ایکسپورٹ → مکمل چیٹ یا چیٹس کی برآمدchat.json اور chat.html کے ساتھ الگ دستخط شدہ بنڈل، فی چیٹ ایک۔
نئی چیٹ ظاہر ہونے کا سیاق و سباقمشاہدے کا دائرہ → جب کوئی نیا چیٹ یا بوٹ ظاہر ہواس کا پروفائل اور 1,000 تک حالیہ پیغامات (تفتیشی موڈ میں 200)۔ موجودہ چیٹس پر لاگو نہیں۔
منسلک بائٹسنظر آنے والی منسلکات ڈاؤن لوڈ کریں + فی قسم حدودSHA-256 اور سائز کے ساتھ media.saved تلاش کریں۔ قطار میں، چھوڑا گیا یا ناکام کا مطلب ہے محفوظ نہیں ہوا۔

چیٹ ایکسپورٹ جرنل یا افراد کے پروفائلز میں نہیں جاتا۔ TgWitness کے اندر پرانی تاریخ تلاش کرنے کے لیے پوری تاریخ لوڈ کریں یا اسنیپ شاٹس استعمال کریں۔

یہاں: چینل، گروپ، بوٹ چیٹ اور نجی چیٹ، ساتھ میں انوائس فائل اور اس کا ہیش۔ جو کیپچر سے پہلے حذف ہوا وہ جا چکا۔

3. ترقی پذیر گفتگو اور اپنے اعمال کو برقرار رکھیں

اسے چلتا رہنے دیں۔ گرم چیٹس کو ترجیح کے لیے ستارہ لگائیں، ریکارڈنگ سیٹنگز ← دوبارہ جانچ میں دوبارہ جانچ ایڈجسٹ کریں، اور recheck.completed، FloodWait اور میڈیا نتائج پر نظر رکھیں۔

چیٹس ← پروفائل ← پروفائل ابھی محفوظ کریں چیٹ کی تفصیل، بوٹ کمانڈز اور دیگر میٹا ڈیٹا محفوظ کرتا ہے۔

کیس کے حصے کے طور پر بوٹ یا دعوت نامہ کی پیروی
  1. چیٹس ← Telegram لنک کھولیں، پہلے پیش نظارہ محفوظ کریں۔ لنک اور پیش نظارہ دستخط شدہ ریکارڈ بن جاتے ہیں۔
  2. ضرورت ہو تو شامل ہوں / کھولیں اور مشاہدہ کریں چیٹ میں شامل ہوتا ہے یا بوٹ کو اس کے اسٹارٹ پیرامیٹر کے ساتھ شروع کرتا ہے۔
  3. کسی کارروائی کو دستاویز کرنے کے لیے پینل سے جواب دیں یا بٹن دبائیں استعمال کریں۔ بوٹ کے جواب کے ساتھ interaction.requested اور interaction.result ملتے ہیں۔

یہ حقیقی کارروائیاں ہیں۔ دوسری ایپ میں دبائے گئے بٹن نظر نہیں آتے، صرف بوٹ کا جواب۔ ویب ایپس، ادائیگیاں یا فون/مقام نہیں۔

4. چیٹس میں افراد، روابط اور فائلوں کا سراغ لگائیں

  1. جرنل، تمام ذرائع، جملہ، ڈومین یا یوزر نیم تلاش کریں۔ نتائج کھولیں اور بورڈ پر بھیجیں۔
  2. چیٹس ← افراد ← پروفائلز آن کریں، کسی شخص کو چنیں: ناموں کی تاریخ، جوابات، سرگرمی، یہاں بھی…، لنکس، والیٹس، فونز۔ حوالہ دیے گئے ریکارڈ کھولیں۔
  3. اسی عددی یوزر ID کو دوسری چیٹس میں ٹریس کریں۔ میل کھاتا نام، والیٹ یا اوتار ایک سراغ ہے، ثبوت نہیں۔
  4. فائلوں کے ہیش ملائیں۔ ایک جیسا SHA-256 = ایک جیسے بائٹس۔ انہیں کس نے شیئر کیا یہ الگ سوال ہے۔

ایک ہی فائل بائٹسمکمل میڈیا رسیدوں #151 اور #209 میں برابر SHA-256 اقداردونوں فائلیں بائٹ بائٹ یکساں ہیں۔

پروفائلز صرف ان لوگوں کا احاطہ کرتے ہیں جنہوں نے اس ورک اسپیس میں کچھ لکھا، ممبرز کی فہرست نہیں۔ فی حقیقت حوالے: پیرامیٹرز ← فی حقیقت حوالہ شدہ ریکارڈز۔

5. ترتیب کو دوبارہ تشکیل دیں اور خالی جگہوں کو نشان زد کریں

6. کیس کو دیگر اکاؤنٹس تک بڑھائیں

فی اکاؤنٹ ایک ورک اسپیس، وہی مراحل۔ ہر ایک کا کردار اور فنگر پرنٹ نوٹ کریں۔ پیغام نمبر فی اکاؤنٹ ہوتے ہیں، اس لیے ہمیشہ بتائیں کون سی ورک اسپیس اور چیٹ۔

اکاؤنٹ گروپ اسٹیٹس دکھاتا ہے، سیٹنگز شیئر کرتا ہے اور سب کو ایک ساتھ ایکسپورٹ کرتا ہے، ہر ایک اپنے جرنل اور کلید کے ساتھ۔ اکاؤنٹس کے درمیان ٹائم لائن آپ اپنے نوٹس میں بناتے ہیں۔

لمبا کیس؟ آزاد گواہ شامل کریں، اور جانچیں کہ ہر اکاؤنٹ واقعی کیا پکڑتا ہے۔

7. ایک قابلِ تصدیق کیس پیکیج فراہم کریں

  case-notes.md                   # question, findings, alternative explanations

  timeline.csv                    # account + chat + message + seq + both times
  workspace-A/

فنگر پرنٹس الگ بھیجیں۔ ہر چیز کی تصدیق اس کی اپنی ورک اسپیس کے مقابل کریں:

python -m tgwitness.verify evidence.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --checkpoint retained-checkpoint.json
python -m tgwitness.verify profiles-operations.json --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --evidence evidence.zip
python -m tgwitness.verify history-channel.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
