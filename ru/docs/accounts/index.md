# Подключение Telegram: QR, телефон и импорт сессий

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/accounts/

Одно пространство = один аккаунт, его журнал и его ключ.

## Выберите способ входа

**Аккаунты** → добавить пространство → настройки подключения. Используйте для этого отдельный аккаунт.

- **QR-код:** отсканируйте его на экране «Устройства» в Telegram и подтвердите.
- **Номер телефона:** номер, код, затем пароль 2FA, если он есть.
- **Импорт сессии:** ваш собственный файл сессии или данные Telegram Desktop.

Используйте встроенный профиль API или свои API ID и hash. Он только называет приложение — не входит в аккаунт и ничего не скрывает.

**Вам сначала нужен прокси-сервер?**

Вы можете [выбрать и протестировать маршрут подключения](https://phishdestroy.github.io/TgWitness/ru/docs/proxies/) перед входом в систему. У каждой учетной записи есть свой собственный маршрут.

## Выберите, что следует отслеживать

1. Выберите нужные чаты, группы или каналы.
2. Проверьте настройки сбора, в том числе медиа.
3. Запустите и проверьте подключение и недавнюю активность.

У аккаунта должен быть доступ. Админы и участники видят разное, журнал показывает то, что получил этот аккаунт.

Весь аккаунт? **Источники → Охват наблюдения → Режим расследования**, проверьте и нажмите **Сохранить охват**. Полный разбор: [расследование по всему аккаунту](https://phishdestroy.github.io/TgWitness/ru/docs/cases/).

## Проверьте весь путь

В тестовой группе отправьте сообщение с другого аккаунта, отредактируйте и удалите его. В журнале должны появиться все три события. Затем [экспортируйте и проверьте](https://phishdestroy.github.io/TgWitness/ru/docs/exports/).

«Подключено» значит, что связь работает. Пойманное тестовое сообщение значит, что события действительно доходят.

## Добавить ещё один аккаунт

Новое пространство в **Аккаунтах**, те же шаги. Запишите отпечаток ключа каждого аккаунта, чтобы потом различать экспорты.
