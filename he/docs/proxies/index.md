# בחר פרוקסי

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/proxies/

השאירו את החשבון מחובר, והחליטו בעצמכם אם מותר לו אי פעם לחשוף את ה-IP של השרת.

## בחר תחילה את מצב ה-IP

01**הסתר את הכתובת**

פרוקסי בלבד. אם אף אחד לא עובד, הוא מחכה.

02**Direct כפתרון אחרון**

עובר לחיבור ישיר אחרי השהיה, וחוזר לפרוקסי ברגע שאחד עובד.

03**שרת מאחורי מנהרה או VPN**

חיבור ישיר בסדר. הוא לא מגדיר ולא בודק את ה-VPN בשבילכם.

המסלול קובע את אופן החיבור. מצב ה-IP קובע אם חיבור ישיר מותר.

## תנו לבריכה לשמור על המסלול

1. **חשבון ← הגדרות ← הגדרות חיבור**.
2. בחרו מצב IP ו-**MTProxy אוטומטי**, או נתיב קבוע.
3. שמרו, **בדיקת חיבור ל-Telegram** (עובד גם לפני התחברות).
4. התחילו איסוף ושלחו לעצמכם הודעת בדיקה.

סביבות עבודה חדשות מתחילות עם MTProxy אוטומטי ו-**הסתרת הכתובת**. המאגר מושך ארבע רשימות ציבוריות, בודק שרתים, שומר את הטובים ומחליף את המתים.

## השתמש בפרוקסי משלך

SOCKS5, HTTP CONNECT, קישור פרוקסי של Telegram או קטלוג של מפעיל. השהו את המעקב לפני מעבר. סודות Fake TLS (`ee`…) לא עובדים.

**הגדרות סיבוב, שיתוף וניסיון חוזר**

**פרמטרים ← MTProxy אוטומטי**: ספי כשל, זמני צינון, רוטציה, חשבונות לכל פרוקסי. מגבלה 1 אומרת שחשבון מחכה במקום לשתף. פרוקסים שונים עדיין יכולים לחלוק IP יציאה.

## הפרדה בין טלגרם לבקשות חיצוניות

MTProxy מעביר רק את Telegram. חותמות זמן, התראות, עותקים ובדיקות קוד עוברים דרך פרוקסי SOCKS5/HTTP נפרד, נתיב ה-SOCKS5/HTTP של החשבון, או ישירות אם המצב מאפשר. או כבו אותם.

`TGWITNESS_PROXY_FEED_PROXY` קובע את הנתיב להורדת רשימות. ל[עד](https://phishdestroy.github.io/TgWitness/he/docs/witness/) יש הגדרות משלו. שום דבר מזה לא נוגע בדפדפן או ברשת המערכת שלכם.

עוד: [מצבים וברירות מחדל](https://phishdestroy.github.io/TgWitness/he/docs/reference/connection/#ip-modes), [מי רשאי לשנות נתיבים](https://phishdestroy.github.io/TgWitness/he/docs/access/).
