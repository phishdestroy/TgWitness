# Текущие возможности

[Начало, масштабирование и доказательства](../OVERVIEW.md) — здесь рассказывается об установке с помощью одной команды,
временном сохранении данных на GitHub, вариантах исследования и опубликованных результатах измерений.

Версия исходного кода: **1.0.0**. [Установщик](https://get.destroy.tools/)
содержит точную ревизию исходного кода в своём подписанном манифесте. Пакеты с тегами
доступны в разделе [Релизы](https://github.com/phishdestroy/TgWitness/releases)
.

| Рабочий процесс | Руководство |
| --- | --- |

| История стандартных операций и операций «Takeout» с курсорами, поддерживающими возобновление | [Полная история](../BACKFILL.md) |
| Секретные чаты, созданные или принятые пользователем TgWitness; модуль протокола, установленный с панели | [Секретные чаты](../PSEUDO-SECRET.md) |
| Экспорт аккаунтов и чатов, политики в отношении файлов и свернутые копии для совместного доступа | [Экспорт учетной записи](../ACCOUNT-EXPORT.md) |
| Приостановка экспорта чатов: подписанный сохраненный диапазон, возобновление, начало сначала, частичное архивирование после потери авторизации | [Экспорт хешей](../EXPORT_HASHES.md) |

[Выберите метод сбора данных ](../COLLECTION-MODES.md), чтобы определить область действия, выходные данные и поведение при восстановлении.
[Установка «Секретного чата» и проверка пакета ](../PSEUDO-SECRET.md) фиксируют поставляемую
интеграцию, протокольный модуль и средства контроля на уровне учетной записи.
[История разработки и масштабируемость](../OVERVIEW.md#testing-history-and-duration) позволяют
оценить хронологию публичных выпусков и отдельные показатели в контексте.
[Действия](https://github.com/phishdestroy/TgWitness/actions) фиксируют автоматические проверки
для каждой ревизии; [Верификация](../VERIFICATION.md) фиксирует завершённое развертывание и
тесты на реальных учётных записях. См. [журнал изменений](../CHANGELOG.md) для ознакомления с изменениями.

Дополнительные средства криминалистической экспертизы осуществляют сравнение полных кадров MTProto с журналом в автономном режиме:
средство проверки кадров сверяет дайджесты полезных данных и идентификаторы сообщений со ссылками в журнале.
Кадры предоставляются явно; файл PCAP передаётся в пакете в качестве вложения.
Результат сопоставления кадров анализируется вместе с путём сбора данных, записями о захвате и информацией о хранении.
