# Текущие возможности

[В разделе Запуск, масштабирование и подтверждение](OVERVIEW.md) описаны установка с помощью одной команды, временное сохранение данных на GitHub, варианты расследования и опубликованные результаты измерений.

Версия исходного кода: **1.0.2**. [Установщик](https://get.destroy.tools/) включает точную ревизию исходного кода в свой подписанный манифест. Пакеты с тегами доступны в разделе [Релизы](https://github.com/phishdestroy/TgWitness/releases).

[Выберите метод сбора данных](COLLECTION-MODES.md) с учётом объёма, формата вывода и алгоритма восстановления. Записи [об установке Секретного чата и проверке пакетов](PSEUDO-SECRET.md) фиксируют поставляемую интеграцию, протокольный модуль и средства контроля на уровне аккаунтов. [История разработки и масштабирования](OVERVIEW.md#testing-history-and-duration) позволяют оценить хронологию публичных выпусков и выбранные показатели в контексте. [В разделе Действия](https://github.com/phishdestroy/TgWitness/actions) фиксируются автоматические проверки для каждой ревизии; в разделе [Верификация](VERIFICATION.md) — завершённые тесты развёртывания и тесты на живых аккаунтах. См. [журнал изменений](../CHANGELOG.md) для ознакомления с обновлениями.

Дополнительные инструменты для криминалистической экспертизы сопоставляют полные кадры MTProto с журналом в автономном режиме: верификатор кадров сверяет дайджесты полезных данных и идентификаторы сообщений со ссылками в журнале. Кадры предоставляются явно; файл PCAP передаётся в составе пакета в качестве вложения. Результат сопоставления кадров анализируется вместе с путём получения данных, записями о перехвате и условиями хранения.
