Witnessボットおよびプロキシ設定の監査 · 2026年10月29日#

アカウント設定では、オペレーターが管理する公開MTProxyカタログ、カスタムTelegram プロキシリンクのプレビュー、および既存の手動入力フィールドに対応しています。カタログの応答からは機密情報が省略され、 選択されたルートはワークスペースのボールトに保存されます。カタログが見つからない場合や形式が不正な場合は、 手動でのルート設定が可能となります。 プロジェクトのプロキシアドレスやホスト型ウィットネスサービスは、 デフォルトでは生成も有効化もされません。Caddyの例では、パネルが非公開のままのコレクターに外部ウィットネスがアクセスする必要がある場合、 スコープ指定されたヘッドエンドポイントのみを公開します。
