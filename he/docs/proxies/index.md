# בחר פרוקסי

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/proxies/

השאר את החשבון מחובר. קבע במפורש מתי המסלול שלו רשאי להשתמש בכתובת השרת.

## בחר תחילה את מצב ה-IP

01**הסתרת כתובת IP**

השתמש בפרוקסי. כאשר אף אחד מהם לא עובד, המתן ללא חיבור ישיר ל-Telegram.

02**אפשר חלופה**

אפשרת Direct לאחר העיכוב שהוגדר; חזור לפרוקסי פעיל כאשר מתקבלת תשובה.

03**מנהרה / VPN**

אפשר מסלולים ישירים דרך רשת המארח. אפשרות זו אינה מתקינה או מאמתת VPN.

המסלול קובע את אופן החיבור. מצב ה-IP קובע אם חיבור ישיר מותר.

## תנו לבריכה לשמור על המסלול

1. פתח **חשבון → הגדרות → הגדרות חיבור**.
2. בחר במצב IP **וב-MTProxy אוטומטי**, או הזן מסלול קבוע.
3. שמור והפעל **את בדיקת החיבור ל-Telegram**. זה עובד גם לפני הכניסה.
4. לאחר תחילת האיסוף, יש לוודא שהודעה מבוקרת מגיעה ליומן.

סביבות העבודה החדשות משתמשות ב-MTProxy אוטומטי עם התנהגות "הסתרת IP". המאגר משלב ארבעה מקורות ציבוריים, בודק כניסות, שומר על נתיבים תקינים ומחליף פרוקסי שנכשלו. הורדות שנכשלו שומרות את התמונות הקודמות.

## השתמש בפרוקסי משלך

הזן פרטי SOCKS5 או HTTP CONNECT, הדבק קישור לפרוקסי Telegram נתמך, או ספק קטלוג מפעילים. הפסק את המעקב לפני שינוי מסלול פעיל. סודות MTProxy מזויפים של TLS המתחילים ב-`ee` אינם נתמכים.

**הגדרות סיבוב, שיתוף וניסיון חוזר**

תחת **"פרמטרים" → "MTProxy אוטומטי**", הגדר ספי כשל, זמני המתנה, רוטציה מתוכננת ומספר חשבונות לכל פרוקסי. מגבלת שיתוף של אחד גורמת לחשבון להמתין כאשר אין כניסה בלעדית זמינה. מרווחי הרענון והבדיקה של הרשימה עוקבים אחר הערכים של סביבת העבודה הראשית. פרוקסי נפרדים אינם מבטיחים כתובות IP יציאה נפרדות.

## הפרדה בין טלגרם לבקשות חיצוניות

MTProxy מעביר תעבורת טלגרם בלבד. חותמות זמן, התראות, עותקים ובדיקות מקור נעשות באמצעות פרוקסי SOCKS5/HTTP נפרד, נתיב ה-SOCKS5/HTTP של החשבון, או באופן ישיר (Direct) כאשר מצב ה-IP מאפשר זאת. ניתן להשבית בקשות חיצוניות אלה.

קוד `TGWITNESS_PROXY_FEED_PROXY` מפורש מגדיר את מסלול הורדת העדכונים. ה-[Witness העצמאי](https://phishdestroy.github.io/TgWitness/he/docs/witness/) שומר על ההגדרות שלו. בקרות אלה אינן מתקינות VPN מערכתי ואינן מנתבות את תעבורת הדפדפן.

צפו [בכל המצבים, הגדרות ברירת המחדל ורשימות המקורות](https://phishdestroy.github.io/TgWitness/he/docs/reference/connection/#ip-modes), או [בחרו מי רשאי לשנות את נתיב החשבון](https://phishdestroy.github.io/TgWitness/he/docs/access/).
