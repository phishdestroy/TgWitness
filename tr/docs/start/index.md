# Birkaç dakika içinde başlayın

Canonical page: https://phishdestroy.github.io/TgWitness/tr/docs/start/

Önce demoda dolaşın, sonra kendi hesabınızı bağlayın.

## Hesap oluşturmadan siteyi inceleyin

Projeyi indirin, **Python 3.11 veya üstü** olsun ve demoyu çalıştırın. Gerisini başlatıcı halleder.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

Tarayıcıda uydurma mesajlarla bir çalışma alanı açılır. Bir sohbet açın, bir düzenlemeyi karşılaştırın, bir dışa aktarıma göz atın. Telegram işin içinde değil.

![Örnek mesajların yer aldığı TgWitness sohbet görünümü](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Örnek bir çalışma alanı. Kendi günlüğünüz ayrı olarak başlar.

## Kendi çalışma alanınızı oluşturun

Demoyu kapatın, ardından:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Başlatıcının gösterdiği adresi açın ve belirttiği dosyadaki **panel erişim belirtecini** yapıştırın. Bu, TgWitness içindir, Telegram için değil.

## İlk mesajınızı kaydedin

1. [Özel bir Telegram hesabı bağlayın.](https://phishdestroy.github.io/TgWitness/tr/docs/accounts/)
2. Bir grup ya da kanal seçin ve gözlemi başlatın.
3. Test grubunuza bir mesaj gönderin ve günlükte belirişini izleyin.

Sunucu kurulumu için "[Keep it running](https://phishdestroy.github.io/TgWitness/tr/docs/server/)" kılavuzunu izleyin.
