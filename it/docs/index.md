## Il Suo primo messaggio acquisito

[### Iniziate in pochi minuti Provi TgWitness con dati di esempio, quindi avvii il Suo spazio di lavoro dedicato al monitoraggio di Telegram su Windows, Linux o macOS.](https://phishdestroy.github.io/TgWitness/it/docs/start/)[### Account dedicato Si prega di predisporre un account Telegram separato per la raccolta dei dati.](https://phishdestroy.github.io/TgWitness/it/docs/dedicated-account/)[### Collegare un account Collegate Telegram tramite codice QR, numero di telefono o importazione della sessione. Scegliete le fonti e verificate che i nuovi messaggi vengano inseriti nel vostro registro.](https://phishdestroy.github.io/TgWitness/it/docs/accounts/)[### Scegliere un proxy Gestisca i percorsi automatici di MTProxy oppure utilizzi un proprio proxy. Sceglia le modalità IP, le regole di fallback e il percorso per le richieste esterne.](https://phishdestroy.github.io/TgWitness/it/docs/proxies/)[### Esportare e verificare Esportare la cronologia di Telegram acquisita, verificare le firme e confrontare il registro con un punto di controllo conservato da un testimone indipendente.](https://phishdestroy.github.io/TgWitness/it/docs/exports/)[### Acquisizione tramite GitHub Actions Scegli Takeout，l’esportazione tramite API normale o un diario della chat su un runner GitHub temporaneo．](https://phishdestroy.github.io/TgWitness/it/docs/capture/)
