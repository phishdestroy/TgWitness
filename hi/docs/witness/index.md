# एक विटनेस बॉट सेट अप करें

Canonical page: https://phishdestroy.github.io/TgWitness/hi/docs/witness/

एक अलग प्रक्रिया आपका जर्नल जाँचती है और हस्ताक्षरित चेकपॉइंट चैनल पर पोस्ट करती है।

## दो होस्ट, दो हस्ताक्षर कुंजी

होस्ट ए / कलेक्टर**खाता + जर्नल**

टेलीग्राम सत्र कलेक्टर हस्ताक्षर कुंजी

केवल-पठन चेकपॉइंट एंडपॉइंट

← हस्ताक्षरित उत्तर का अनुरोध करें →

होस्ट बी / विटनेस**सत्यापित करें + संरक्षित करें**

पिन किए गए कलेक्टर फिंगरप्रिंट अलग विटनेस साइनिंग की

अपना जर्नल + बॉट टोकन

विटनेस → टेलीग्राम बॉट एपीआई →**आपका चैनल · हस्ताक्षरित TGW1 पोस्ट्स**

विटनेस स्वयं चेक्स खींचता है। कलेक्टर की पहुँच केवल-पढ़ने के लिए है। बॉट प्रकाशन विटनेस के कनेक्शन और टोकन का उपयोग करता है; विटनेस को कोई खाता सत्र नहीं दिया जाता।

03 / चेकपॉइंट निर्णयउदाहरण सहित उत्तर

अंतिम स्वीकृत**120 रिकॉर्ड**`head 9c7d…`

अगला उत्तर**128 रिकॉर्ड**`head a4f2…`

स्वीकार किया गया: गिनती बढ़ती है, हस्ताक्षर सत्यापित होता है और कुंजी मेल खाती है। गवाह इस नई सीमा को बनाए रखता है।

सभी उत्तर उदाहरण मान्य हस्ताक्षर और पिन की गई कुंजी को मानते हैं। यहाँ हैश संक्षिप्त उदाहरण हैं। केवल अधिक संख्या यह साबित नहीं कर सकती कि पुराना पूरा उपसर्ग अपरिवर्तित है; बनाए रखे गए चेकपॉइंट्स के साथ एक्सपोर्ट की तुलना करें।

## एक बॉट और एक चैनल तैयार करें

BotFather से बॉट बनाएँ और उसे अपने चैनल में पोस्ट करने दें। गवाह कहीं और चलाएँ: दूसरा होस्ट, बेहतर हो कोई और चलाए, कलेक्टर के बगल में दूसरी प्रक्रिया से कहीं ज़्यादा कीमती है।

## एक्स्ट्रा में तीन चरण

1. **केवल-पठन एक्सेस।** **अतिरिक्त → स्वतंत्र गवाह**, टोकन बनाएँ, फ़ाइल सहेजें। यह केवल चेकपॉइंट और स्वास्थ्य पढ़ता है।
2. **चैनल और अंतराल।** Telegram चैनल या Discord webhook, साथ में कलेक्टर का पता जहाँ गवाह पहुँच सके। सेटिंग्स फ़ाइल सहेजें।
3. **लॉन्च।** `witness.json`, `witness-token.txt` और `bot-token.txt` गवाह होस्ट पर साथ रखें और चलाएँ:

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

चैनल में पहली हस्ताक्षरित पोस्ट का इंतज़ार करें, फिर गवाह का फ़िंगरप्रिंट सुरक्षित जगह सहेजें।

इसके बजाय Discord? webhook URL को `discord-webhook.txt` के रूप में सहेजें। एक गवाह एक जगह पोस्ट करता है; लंबी जाँचें Discord पर फ़ाइल के रूप में आती हैं।

## प्रकाशन की आवृत्ति चुनें

हर जाँच पोस्ट करने से नियमित बाहरी रिकॉर्ड बनता है: हर पाँच मिनट यानी प्रति वर्कस्पेस रोज़ लगभग 288 पोस्ट। उन्नत सेटिंग्स केवल बदलाव या समस्या पर पोस्ट कर सकती हैं, प्रॉक्सी या कस्टम Bot API इस्तेमाल कर सकती हैं।

**बॉट वास्तव में क्या प्रमाणित करता है?**

यह कलेक्टर से हस्ताक्षरित चेकपॉइंट माँगता है, अपेक्षित कुंजी से जाँचता है और अपना हस्ताक्षरित जर्नल रखता है, छूटे और अस्वीकृत उत्तरों सहित।

यह जर्नल की स्थिति जाँचता है, खुद Telegram पर नज़र नहीं रखता। उसके लिए नियंत्रित डिलीवरी टेस्ट चलाएँ।

## बाद में सबूत देखें

गवाह का जर्नल, पोस्ट और फ़िंगरप्रिंट रखें। कलेक्टर के एक्सपोर्ट से [उन्हें कैसे जाँचें](https://phishdestroy.github.io/TgWitness/hi/docs/reference/witness/#verify)।
