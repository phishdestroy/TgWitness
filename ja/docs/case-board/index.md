# Case Boardの作成

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/case-board/

保存されたTelegramの観測データを、チームで共同で確認できる案件に変換します。

Case Board は、ソース参照の横にブックマーク、正確なテキストのハイライト、保存されたスライス、およびディスカッションを保持します。コレクションは案件に作業構造を与え、署名付きリビジョンにより、チームがどのように案件を展開したかが記録されます。

## メッセージからケースカードへ

1. **「調査」→「Case Board」**を「標準」モードまたは「エキスパート」モードで開きます。その案件用のコレクションを作成し、チャットの範囲を選択します。
2. 「**ジャーナル**」または保存済みのチャットで、**「ボードへ**」を選択するか、レコードをハイライト表示して **B** キーを押してください。カードが「受信箱」に入ります。わかりやすいタイトルを付けて、コレクションに移動してください。
3. 保存されたチャットメッセージ内の文章を選択し、「**ハイライト」→「ボード」**を選択して、正確な引用文とメッセージのバージョンを保持してください。それがなぜ重要なのかを説明するメモを追加してください。
4. カードについて議論し、レビューステータスを割り当て、主張の確認が必要な場合はいつでも元の文脈に戻ることができます。「**プレゼンテーション」**機能を使用して、同僚と共に収集データを順を追って確認してください。

### 変更された支払いリンクを1つ追跡してください

合成例・ローカルな図解

1. **キャプチャ。**保存済みの観察記録 #142 およびそのメッセージバージョンを開きます。
2. **ブックマーク。**引用文、出典情報、およびご質問をカードに保存してください。
3. **レビュー。**チームコメントを追加し、カードを「レビュー」に移動してください。
4. **現在形を使用してください。**収集手順を順を追って説明し、引用されたソースのコンテキストを開いてください。

#### 保存された観察記録 #142

「新しい支払いリンクをご利用ください。」

運用チャット・メッセージ 38・確認時刻 09:12 UTC

#### カード：宛先を変更

> 新しい支払いリンクをご利用ください。

質問：以前のバージョンにはどの宛先が表示されていましたか？

#### チームによるレビュー

アナリスト：観察事項#101と比較してください。

ステータス：レビュー済み・修正内容を反映

#### 原文の文脈

カード → 保存されたバージョン → 以前の観察記録

注釈とTelegramの監視記録は、それぞれ個別に識別可能です。

## 有用な範囲を一度保存する

1つのチャット内で2つのレコードをShiftキーを押しながらクリックして「**その間のスライス**」を作成するか、「**時間でスライス**」を選択するか、現在のジャーナルフィルターを保存してください。保存前に件数を確認してください。スライスを再度開いて保存されたクエリを適用してください。「**ブックマーク以降に追加されたレコードを表示」**を選択すると、後から追加されたレコードを確認できます。

タイムスライスは、コレクターの監視時刻に準じて作成されます。メッセージIDスライスは、選択したメッセージに対して、その後の変更が反映された際に追跡可能です。保存された作成時点の境界情報により、受信者は元の選択内容とそれ以降の状態で比較を行うことができます。

## 各同僚に適切な役割を割り当てる

**レビュー担当者は**ボードを確認し、**アナリストは**カードやコメントを追加します。**オペレーターは**、データの収集やレビューの決定も管理します。ワークスペースおよびチャットの権限は、カード、ソースのコンテキスト、およびディスカッションに適用されます。明確な帰属を示すため、名前付きアクセス権限を使用してください。

## この作業を成果物としてまとめ上げてください

スライスを署名付きJSONとしてエクスポートするか、スプレッドシート用にCSVを使用してください。レポート設定には、ブックマークやスライスを含めることができ、選択した場合はチームのコメントも追加できます。これらの内容は「[Report Studio](https://phishdestroy.github.io/TgWitness/ja/docs/reports/)」で選択してください。保存されたスライスだけでは、レポートが自動的に構成されるわけではありません。受信者が制限されている場合は、別途用意[された引き渡し](https://phishdestroy.github.io/TgWitness/ja/docs/handover/)コントロールを使用してください。

署名付き改訂版、正確な引用一致、選択内容の検証、および権限については、「[Case Board」のリファレンス](https://phishdestroy.github.io/TgWitness/ja/docs/reference/case-board/)を参照してください。
