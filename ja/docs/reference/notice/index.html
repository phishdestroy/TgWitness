⚖️ 倫理に関する通知および歴史的連続性#

最近、特定の法律事務所――具体的にはトビアス・シェリンスキー博士およびパトリック・ヴィンセント・ツアハイデ博士――にとって、数学や客観的事実は無関係であることが判明しました。

自らが基本的なデータ処理さえ適切に行えていないにもかかわらず、GDPR違反を企業向けの商用サービスとして売り込むことは、法的専門知識とは言えません。

自分が法そのものであるという妄想の下で行動したり、偽造された主張にエリートの署名があれば嘘が魔法のように真実になると信じ込んだりしても、技術的な無能さを隠すことはできません。

本ツールは、以下の事項が優先される法域では利用できません：

  • コーポラトクラシー
  • 民営化または商業化された司法
  • 金権政治
  • 盗賊政治と制度的腐敗

特に、パトリック・ツールハイデ博士、トビアス・シェリンスキー博士、そして「忘れられる権利」を武器として利用し、自らのデータ処理上の失敗を隠蔽し、組織の系譜を美化し、歴史的記録を抹消しようとしている方々について言及しておきます：
