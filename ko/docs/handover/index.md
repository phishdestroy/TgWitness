# Telegram · 공유용 사본을 준비하십시오

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/handover/

필요한 것만 공유하고, 원본은 그대로 둡니다.

인계는 별도의 서명된 추출입니다: 채팅과 사람을 고르고, 신원이나 본문을 숨기고, 파일과 팀 메모를 선택합니다. 매니페스트에 유지된 것, 줄인 것, 뺀 것이 기록됩니다.

## 수신자용 발췌본 준비

1. **내보내기 → 인계용 추출**: 목적을 적고, 채팅과 기간을 고르고, 이름을 밝힐 사람이 필요하면 **선택한 채팅의 참여자 불러오기**.
2. 나머지 모든 사람: 가명, 제외, 또는 기록된 그대로. 본문과 파일은 별도의 스위치이며, 전화번호와 이메일은 가릴 수 있습니다.
3. Case Board: 없음, 북마크와 슬라이스, 또는 댓글이 있는 카드. 팀 이름은 별칭으로 바꿀 수 있습니다.
4. **인계 추출 다운로드**, 열어서 검증하고, 보내기 전에 훑어보십시오.

### 원본 1부, 공유용 사본 1부

합성 예시 · 실제 사례와는 무관함

1. **선택.** 사건 채팅을 포함하고, 발췌 내용이 누구에 관한 것인지 명시하십시오.
2. **최소화.** 공유 사본에서 다른 참여자가 어떻게 표시될지 선택하십시오.
3. **검토.** 생성된 아카이브의 보고서와 기록을 전송하기 전에 열어 확인하십시오.
4. **공유해 주십시오.** 교정된 사본을 전달하고, 신뢰할 수 있는 지문 정보를 별도로 알려주십시오.

#### 원문 관찰 사항

Nora · 사용자 71002

“수정된 링크를 받았습니다.”

원본 저널에는 이 저장된 관찰 내용이 보관됩니다.

#### 수신자용 사본

기록된 대로 표시: Nora · 사용자 71002 · “수정된 링크를 받았습니다.”

가명: P01 · “수정된 링크를 받았습니다.”

생략: 이 참가자의 메시지는 본문에서 제외됩니다.

#### 실제 파일을 검토하십시오

report.html 및 records.jsonl 파일을 참조하십시오.

신원 정보, 본문, 첨부 파일 및 선택 사항인 팀 코멘트를 확인하십시오.

#### 서명된 발췌문

선택 항목 + 파일 해시 + 서명된 매니페스트

원본 저널 경계와 연결된 별도의 패키지

## 제어 기능을 함께 사용하십시오

| 제어 | 문안 수정 사항 |
| --- | --- |
| 사람들 | 선택한 사람은 이름이 유지되고, 다른 사람은 가명이 되거나 제외됩니다. |
| 텍스트 | 모든 본문, 선택한 사람과 귀하 계정의 본문만, 또는 없음. |
| 파일 | 선택한 사람과 귀하 계정의 파일, 표시된 모든 파일, 또는 없음. |
| 케이스 보드 | 없음, 북마크와 슬라이스, 또는 토론이 있는 카드. |

본문과 파일도 읽어 보십시오: 가명을 써도 메시지나 첨부 파일 안에 적힌 이름은 지워지지 않습니다. 선택한 파일이 없으면 복원하거나 첨부 파일을 빼십시오.

## 번역본은 독립적으로 검증 가능해야 합니다.

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

원본 아카이브와 체크포인트는 직접 보관하십시오. 받는 사람은 작업 공간 전체를 받지 않고도 사본을 검증할 수 있습니다. 디자인: [Report studio](https://phishdestroy.github.io/TgWitness/ko/docs/reports/). 신뢰할 수 있는 기준: [내보내기 검증](https://phishdestroy.github.io/TgWitness/ko/docs/exports/).
