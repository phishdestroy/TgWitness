# Запуск за несколько минут

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/start/

Сначала ознакомьтесь с рабочим примером. Затем подключите свою учетную запись.

## Ознакомьтесь с сайтом без регистрации

Скачайте или клонируйте проект, установите **Python 3.11 или более позднюю версию** и запустите демо-версию. Программа запуска создаёт локальную среду и устанавливает закреплённые зависимости.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

В браузере открывается рабочая область с вымышленными сообщениями. Откройте переписку, сравните изменения и просмотрите экспортированные данные. В демонстрационном режиме подключение к Telegram не осуществляется.

![Вид диалога в TgWitness с примерами сообщений](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Пример рабочей области. Ваш собственный журнал создаётся отдельно.

## Создайте собственное рабочее пространство

Закройте демонстрационный процесс, а затем воспользуйтесь обычным лаунчером:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Откройте локальный адрес, указанный программой-запуска. При появлении запроса введите **токен доступа к панели** из локального файла, имя которого указано в терминале. Это разблокирует TgWitness; данная процедура не связана с входом в Telegram.

## Сохраните своё первое сообщение

1. [Подключите специальный аккаунт в Telegram.](https://phishdestroy.github.io/TgWitness/ru/docs/accounts/)
2. Выберите группу или канал, к которым у аккаунта есть доступ, а затем начните наблюдение.
3. Отправьте новое сообщение в тестовой группе, которой вы управляете, и убедитесь, что оно появилось в журнале.

Для установки на сервере следуйте инструкциям в разделе [«Обеспечение непрерывной работы](https://phishdestroy.github.io/TgWitness/ru/docs/server/)».
