# 계정 그룹 관리

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/groups/

각 계정의 기록과 서명 주체를 별도로 구분하면서 여러 수집 계정을 함께 관리하십시오.

계정 그룹을 사용하면 연결 상태, 모니터링 제어, 공유 설정 및 내보내기 기능을 하나의 작업 화면에 통합할 수 있습니다. 이는 여러 계정이 동일한 수사를 다루거나 일관된 운영 설정이 필요한 경우에 유용합니다.

## 그룹 개요 열기

**‘계정**(**Accounts**)’에서 그룹을 엽니다. 각 계정에는 관찰 상태, 연결 경로, 최근 점검 성공 시 측정된 경로 지연 시간, 마지막으로 저장된 메시지가 표시됩니다. **‘주의 필요**(**Needs attention**)’ 링크는 조치가 필요한 계정으로 연결되며, **‘수정(Fix)’을** 클릭하면 관련 작업 공간과 제어 화면이 열립니다.

**'모두 시작'** 및 **'모두 일시 중지'** 기능은 확인 후 해당 계정에 적용됩니다. **그룹 설정은** 선택한 설정을 공유하며, 개별 값을 가진 계정은 사용자가 해당 값을 대체하기로 선택할 때까지 기존 값을 유지합니다.

### 그룹 전반에 걸친 경로 변경 사항 검토

합성 예시 · 예시적인 검증 항목 및 결과

1. **선택.** 그룹을 선택하고 변경될 계정을 검토하십시오.
2. **준비.** 별도로 유지해야 할 경우 계정의 고유 경로를 유지하십시오.
3. **확인.** 제안된 연결을 테스트하고 측정 결과를 검토하십시오.
4. **적용하십시오.** 저장하기 전에 다시 확인하고 각 계정에 대한 결과를 검토하십시오.

#### 사건 담당 팀

채널 수집기 · 그룹 수집기 · 참조 계정

3개의 별도 작업 공간

#### 검토된 내용

2개의 계정이 제안된 경로를 따릅니다.

참조 계정은 별도의 경로를 따릅니다.

#### 준비 점검 사항

채널 수집기: 텔레그램 전송 시간 84 ms

그룹 수집기: 텔레그램 전송 시간 91 ms

이 숫자들은 예시를 위한 가상의 측정값입니다.

#### 응용 결과

채널 수집기: 저장 완료, 관찰 재개.

그룹 수집기: 재확인 실패, 이전 설정으로 복원됨.

참조 계정: 기존 경로 유지.

## 검토 단계를 추가하여 경로를 변경하십시오.

1. **'그룹 경로 변경'을** 선택한 다음, 연결 유형과 설정을 선택하십시오.
2. **'검토' 항목을** 선택하십시오. 나열된 계정과 각 계정의 개별 경로 재정의 사항을 검토하십시오.
3. **'준비 및 확인'을** 선택하십시오. 확인 과정에서는 새로운 텔레그램 전송 경로를 사용하며, 지원되는 HTTP 경로의 경우 HTTPS 출구 확인 결과도 함께 보고됩니다.
4. **‘선택한 연결 적용’을** 선택하고 각 계정의 결과를 확인하십시오. 이전에 실행 중이던 모니터링은 적용이 성공한 지점에서 재개되며, 비활성 계정은 비활성 상태로 유지됩니다.

지연 시간(Latency)은 측정된 텔레그램 연결 설정 시간을 의미합니다. 출구 IP(Exit-IP) 확인은 기록된 확인 시점의 경로를 나타냅니다. 계정 인증 및 모니터링 상태에는 각각 고유한 지표가 있으며, 그룹 변경은 계정마다 다른 결과로 이어질 수 있습니다.

## 중복 액세스 사용

**‘여러 계정이 보는 채팅’에서는** 공유된 소스와 사용 가능한 작업 공간 관찰 범위가 표시됩니다. 해당 채널 및 슈퍼그룹은 **‘… 계정과 함께 내보내기’ 기능을** 사용하여 하나의 채팅 기록 수집을 분할할 수 있습니다. 비공개 채팅과 일반 그룹은 메시지 번호가 해당 계정의 기록에 속하므로 시작 계정에 그대로 유지됩니다.

## 그룹을 패키지로 내보내기

**내보내기 그룹은** 각 계정의 서명된 내보내기 파일과 해당 파일 목록의 서명본을 포함하는 하나의 ZIP 파일을 생성합니다. 원본 작업 공간의 식별 정보와 지문은 검증용으로 계속 사용할 수 있습니다. 이러한 참조 정보를 활용하여 계정 간 서사를 구성하십시오. 단일 통합 타임라인은 여전히 별도로 작성됩니다.

[보고서 설계](https://phishdestroy.github.io/TgWitness/ko/docs/reports/), [작업 공간 내의 케이스 보드](https://phishdestroy.github.io/TgWitness/ko/docs/case-board/), 또는 [내보내기 확인](https://phishdestroy.github.io/TgWitness/ko/docs/exports/)을 계속 진행하십시오.
