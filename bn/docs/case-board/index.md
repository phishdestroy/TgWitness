# একটি কেস বোর্ড তৈরি করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/case-board/

সংরক্ষিত বার্তাকে এমন কেসে পরিণত করুন যেখানে আপনার দল একসাথে কাজ করে।

বুকমার্ক, হুবহু উদ্ধৃতি, স্লাইস ও আলোচনা, প্রতিটি তার উৎসের সাথে যুক্ত। প্রতিটি পরিবর্তন একটি স্বাক্ষরিত সংশোধন।

## বার্তা থেকে কেস কার্ডে

1. **তদন্ত → Case Board** (স্ট্যান্ডার্ড বা বিশেষজ্ঞ মোড)। কেসের জন্য একটি সংগ্রহ বানান।
2. **জার্নাল** বা কোনো চ্যাটে **বোর্ডে** (বা **B**) চাপুন। কার্ড ইনবক্সে আসে, শিরোনাম দিয়ে সরিয়ে নিন।
3. বার্তায় লেখা নির্বাচন করুন, **হাইলাইট → বোর্ড** হুবহু উদ্ধৃতি ও সংস্করণ রাখে। কেন গুরুত্বপূর্ণ তা লিখুন।
4. আলোচনা করুন, অবস্থা ঠিক করুন, দরকার হলেই উৎসে ফিরে যান। **উপস্থাপনা** দলকে ধাপে ধাপে দেখায়।

### একটি পরিবর্তিত পেমেন্ট লিঙ্ক অনুসরণ করুন

কৃত্রিম উদাহরণ · স্থানীয় চিত্রায়ন

1. **ক্যাপচার করুন।** সংরক্ষিত পর্যবেক্ষণ #142 এবং এর বার্তা সংস্করণ খুলুন।
2. **বুকমার্ক।** উদ্ধৃতি, উৎস রেফারেন্স এবং আপনার প্রশ্ন একটি কার্ডে রাখুন।
3. **পর্যালোচনা।** একটি টিম মন্তব্য যোগ করুন এবং কার্ডটি পর্যালোচনা ধাপে সরান।
4. **উপস্থাপিত।** সংগ্রহের মধ্য দিয়ে যান এবং উদ্ধৃত উৎসের প্রসঙ্গ খুলুন।

#### দলগত পর্যালোচনা

বিশ্লেষক: পর্যবেক্ষণ #101-এর সাথে তুলনা করুন।

স্থিতি: পর্যালোচনা · সংশোধন রাখা হয়েছে

#### উৎস প্রসঙ্গ

কার্ড → সংরক্ষিত সংস্করণ → পূর্ববর্তী পর্যবেক্ষণ

অ্যানোটেশন এবং টেলিগ্রাম পর্যবেক্ষণ পৃথকভাবে শনাক্তযোগ্য থাকে।

## একবার একটি দরকারী পরিসর সংরক্ষণ করুন

দুটি বার্তায় Shift-ক্লিক করে **মাঝের স্লাইস**, **সময় অনুযায়ী স্লাইস** ব্যবহার করুন, বা বর্তমান জার্নাল ফিল্টার সংরক্ষণ করুন। **বুকমার্কের পর যোগ হওয়া রেকর্ড দেখান** পরে যা এসেছে তা দেখায়।

সময়ের স্লাইস পর্যবেক্ষণের সময় ব্যবহার করে; বার্তা-ID স্লাইস সেই বার্তাগুলোর পরিবর্তনের সাথে চলে।

## প্রতিটি সহকর্মীকে সঠিক ভূমিকা দিন

**পর্যালোচক** পড়েন, **বিশ্লেষক** কার্ড ও মন্তব্য যোগ করেন, **অপারেটর** সংগ্রহ ও সিদ্ধান্তও পরিচালনা করেন। চ্যাটের অনুমতি কার্ডেও প্রযোজ্য।

## কাজটিকে একটি ডেলিভারযোগ্য ফরম্যাটে উপস্থাপন করুন

স্লাইস স্বাক্ষরিত JSON বা CSV হিসেবে এক্সপোর্ট হয়। রিপোর্টে বুকমার্ক, স্লাইস ও মন্তব্য থাকতে পারে, এটি [Report studio](https://phishdestroy.github.io/TgWitness/bn/docs/reports/)-তে ঠিক করুন। সীমিত প্রাপকের জন্য [হস্তান্তর](https://phishdestroy.github.io/TgWitness/bn/docs/handover/) ব্যবহার করুন।
