การวิเคราะห์ข้อมูลในคลัง

ค้นหาข้อความที่บันทึกไว้ ตรวจสอบข้อมูลที่ AI ให้มา และเก็บรายงานวิเคราะห์พร้อมแหล่งอ้างอิง

เนื้อหาหลักปัจจุบัน: ใช้การเช็คเอาต์จากแหล่งที่มา; เวอร์ชัน 0.7.0 portable preview ยังไม่มีคุณสมบัตินี้

คู่มือขั้นตอนการทำงาน · Wiki

ใช้ บันทึก สำหรับการค้นหาในเครื่องโดยไม่ใช้ AI สำหรับ ถามคลังข้อมูล ให้เปิดใช้งาน และตั้งค่าผู้ให้บริการใน การบูรณาการ ก่อน ตัวเลือกพื้นที่ทำงานใช้เลือก บัญชี ส่วนแบบฟอร์มใช้เลือกแชทและช่วงเวลาการสังเกตการณ์ การดึงข้อมูลทำงาน ในเครื่อง วลีที่ตรงกันทุกคำหรือโดเมนจะจำกัดขอบเขตการดึงข้อมูลให้แคบลง ส่วน ID ข้อความจะเรียกดูเวอร์ชัน ที่บันทึกไว้ ตรวจสอบข้อความที่ตัดตอนมา แล้วเปิดรายการบันทึกหรือบริบทของข้อความนั้น ไม่มีฐานข้อมูลเวกเตอร์หรือการดำเนินการอัตโนมัติบน Telegram

ผู้ให้บริการและความยินยอม#

AI ถูกปิดไว้โดยเริ่มต้นในทุกพื้นที่ทำงาน (workspace) ผู้บริหารหลักเท่านั้นที่สามารถกำหนดค่า โมเดล จุดปลายทาง (endpoint) กุญแจ API ที่เข้ารหัส ขีดจำกัดของบริบท/ผลลัพธ์ เวลาหมดอายุ และ งบประมาณคำขอรายวันได้ กุญแจจะไม่ถูกส่งกลับไปยังเบราว์เซอร์เลย ให้ทิ้งช่องกุญแจไว้ว่าง เพื่อรักษากุญแจปัจจุบัน หรือลบมันออกอย่างชัดเจน

Ollama ใช้จุดปลายทาง /api/chat ที่ได้รับการบันทึกไว้ พร้อมผลลัพธ์ JSON แบบไม่สตรีมมิ่ง ที่อยู่เริ่มต้นคือ http://127.0.0.1:11434 บน เซิร์ฟเวอร์ TgWitness ผู้ใช้งานสามารถเปลี่ยนที่อยู่ได้โดยใช้ TGWITNESS_AI_LOCAL_ENDPOINT; ที่อยู่นี้ไม่ถูกควบคุมโดยโมเดล ติดตั้ง โมเดลที่เลือกด้วยตนเอง TgWitness ไม่ดาวน์โหลดโมเดลนี้โดยอัตโนมัติ

ผู้ให้บริการที่รองรับต้องใช้ URL ฐานที่ลงท้ายด้วย /v1 และ โปรโตคอล Chat Completions: messages, โหมดตอบสนอง JSON: max_completion_tokens, และ choices[0].message.content บริการที่ไม่มีฟิลด์เหล่านี้จะไม่ได้รับการสนับสนุน การทดสอบการเชื่อมต่อจะส่งข้อความสังเคราะห์และนับรวมในงบประมาณคำขอ

ทุกคำขอจะใช้เส้นทางภายนอกที่ตั้งค่าไว้ในพื้นที่ทำงาน เส้นทางที่ถูกบล็อกหรือ MTProxy ที่ใช้เฉพาะ Telegram จะก่อให้เกิดข้อผิดพลาด; ไม่มีการลองใหม่โดยตรง ที่อยู่ Ollama ท้องถิ่นที่ กำหนดไว้อย่างจงใจจะอนุญาตให้ใช้ปลายทางส่วนตัว ในขณะที่ยังคงใช้ เส้นทางที่เลือกไว้ สำหรับบริการส่วนตัวอื่น ๆ จะใช้ตัวเลือกการเปิดใช้งานปลายทางส่วนตัว ระดับเซิร์ฟเวอร์ที่มีอยู่ แผงควบคุมจะแสดงจุดปลายทางที่ตั้งค่าไว้จริง

ก่อนการสร้างข้อมูลที่ส่งไปยังโมเดลจะแสดงคำขอ: คำถาม, ส่วนที่ถูกเลือก, ประเภทเหตุการณ์, เวลาสังเกตการณ์ และเครื่องหมายขอบเขต Telegram เซสชัน, สนามข้อมูลดิบ, กุญแจผู้ให้บริการ, ไบต์ของไฟล์แนบ และบันทึกเต็มรูปแบบ ไม่รวมอยู่ในบริบทนั้น ให้ยกเลิกการเลือกแหล่งข้อมูลที่ไม่ต้องการ แล้วอนุมัติ การประมวลผลอย่างชัดเจน ผู้ให้บริการภายนอกอาจเก็บรักษาเนื้อหาที่ส่งมาตาม นโยบายของตนเอง การดำเนินการในเครื่องท้องถิ่นหมายความว่าจุดปลายทางอยู่ภายในเครื่องท้องถิ่น; สิ่งนี้ไม่ใช่การรับประกัน เกี่ยวกับพฤติกรรมของบริการที่ได้รับการกำหนดค่าอย่างอิสระ

มีคำขอจากผู้ให้บริการพร้อมกันสูงสุดสองคำขอทั่วโลก และหนึ่งคำขอต่อ พื้นที่ทำงาน การดูตัวอย่างจะหมดอายุหลังจากสิบนาที และสามารถสร้างคำตอบได้หนึ่งคำตอบ จำนวนโทเค็นที่ผู้ให้บริการรายงานจะแสดงขึ้น; การประมาณค่าใช้จ่ายจะปรากฏขึ้นเพียง เมื่ออัตราค่าบริการทั้งด้านเข้าและออกได้รับการกำหนดแล้วเท่านั้น การลองที่ล้มเหลวก็ ใช้ส่วนหนึ่งของงบประมาณคำขอรายวันเช่นกัน การลองใหม่แบบอัตโนมัติจะไม่ใช้ส่วนเพิ่มเติมของงบประมาณ

แหล่งข้อมูลและข้อจำกัด#

ฟังก์ชัน Retrieval ตรวจสอบข้อความที่บันทึกไว้ด้วยการค้นหาคำศัพท์แบบจำกัดขอบเขต โดยจะแสดง ผลลัพธ์สูงสุด 24 แหล่ง และทำเครื่องหมายส่วนที่ถูกตัดทอนหรือชุดผลลัพธ์ที่ไม่สมบูรณ์ ช่วง เวลาที่ระบุหมายถึงช่วงเวลาการสังเกตการณ์ ไม่ใช่การยืนยันว่าประวัติ Telegram นั้น ครบถ้วน เหตุการณ์ที่ครอบคลุมทั้งพื้นที่ทำงานจะไม่ถูกแสดงในการเข้าถึงที่จำกัดเฉพาะแชท ข้อมูลที่ขาดหายไปจะถูกอธิบายว่าไม่พบในคลังข้อมูลที่มีอยู่

โมเดลไม่ได้รับเครื่องมือใดๆ ID แหล่งที่มาจะถูกตรวจสอบกับ บันทึกที่เลือกไว้ ค่าแฮชจะถูกตรวจสอบซ้ำ และข้อความที่อ้างอิงต้องปรากฏในบันทึกเหล่านั้น ID ที่ไม่รู้จัก คำพูดที่ถูกแก้ไข และข้ออ้างที่ไม่มีแหล่งอ้างอิง จะทำให้คำตอบถูกปฏิเสธ แอปพลิเคชัน สร้างลิงก์; URL ที่สร้างโดยโมเดลไม่ถูกใช้เป็นแหล่งอ้างอิง การตรวจสอบเหล่านี้ ยืนยันการมีอยู่ของแหล่งข้อมูลและความถูกต้องของคำพูด ไม่ใช่ความจริงของข้อสรุป ตรวจสอบข้อสรุปกับบันทึกก่อนที่จะเชื่อถือมัน

รายงาน#

บันทึกคำตอบที่ได้รับการตรวจสอบแล้วเป็นรายงานวิเคราะห์แยกต่างหาก ซึ่งรวมถึง สรุปโมเดล ลำดับเวลาที่สังเกตได้ ลิงก์และแฮนเดิลที่สกัดได้ บันทึกการแก้ไข/การลบ ขอบเขตการครอบคลุม และแฮชของเหตุการณ์ต้นทาง พร้อมด้วยข้อมูลเกี่ยวกับผู้ให้บริการ โมเดล จุดปลายทาง เวลา และ เวอร์ชันของแม่แบบคำสั่ง ไม่มีการรวมข้อมูลส่วนบุคคลโดยอัตโนมัติ

การแก้ไขและบันทึกของนักวิเคราะห์ถูกเก็บไว้แยกต่างหากจากสรุปของโมเดล รายงาน ถูกเก็บไว้ในไฟล์ที่เข้ารหัสและสร้างขึ้นจากข้อมูลต้นฉบับ พร้อมด้วยดัชนีนอกสตรีมเหตุการณ์ที่ลงนาม; เหตุการณ์และสื่อต้นฉบับไม่มีการเปลี่ยนแปลง ผู้เป็นเจ้าของหรือผู้ดูแลระบบเท่านั้นที่สามารถ เปิดรายงานได้ และสิทธิ์การเข้าถึงแหล่งข้อมูลจะถูกตรวจสอบอีกครั้ง การดาวน์โหลดยังต้องได้รับ สิทธิ์การส่งออกด้วย เวอร์ชัน 1 ไม่ลงนามรายงานหรือระบุว่าข้อสรุปของโมเดลเป็น หลักฐานที่ได้รับการตรวจสอบแล้ว ข้อจำกัด: 100 รายงานต่อพื้นที่ทำงาน และ 100 การแก้ไขของนักวิเคราะห์ ต่อรายงาน

สำหรับการแปลงตัวอักษรด้วย OCR แบบแมนนวลและการถอดความ ดูที่ส่วนการประมวลผลสื่อ สำหรับการเข้าถึงของลูกค้า ดูที่ MCP.
