參考資料 / 存檔與整合功能

檔案分析

搜尋已儲存的訊息、檢視 AI 輸入內容，並保存附有來源參考的分析報告。

當前主要版本：請使用原始碼檢出；0.7.0 便攜版預覽版尚未包含此功能。

工作流程指南 · 維基

在面板中開啟「查詢存檔」功能。工作區選擇器用於選擇帳戶； 表單則用於選擇聊天室及觀察期間。搜尋在本地執行，不 使用 AI。輸入精確短語或網域可縮小檢索範圍；輸入訊息 ID 可查詢已儲存的 版本。檢視搜尋結果的摘錄，並開啟其日誌記錄或上下文。 本工具不包含向量資料庫，亦不會自動執行任何 Telegram 操作。

服務提供者與同意聲明#

AI 功能在每個工作區中預設為停用狀態。僅有主要管理員可設定 模型、端點、加密 API 金鑰、上下文／輸出限制、超時設定及每日 請求配額。金鑰絕不會傳回瀏覽器。若要保留現行金鑰，請將金鑰欄位 留空；若要移除金鑰，則需明確刪除。

Ollama 使用其已記錄的 /api/chat 端點 並以非串流式的 JSON 格式輸出。其預設位址為 TgWitness 伺服器上的 http://127.0.0.1:11434。操作者可透過 TGWITNESS_AI_LOCAL_ENDPOINT 變更此位址；此並非由模型控制的位址。請自行安裝 所選的模型。TgWitness 不會自動下載該模型。

相容的服務提供者需具備以 /v1 結尾的基礎網址，並支援 「聊天內容補全」協定： messages、JSON 回應模式、max_completion_tokens 及 choices[0].message.content。缺乏這些欄位的服務將不被支援。 連線測試會傳送合成文字，並計入請求配額。

每個請求均使用工作區所設定的外部路由。 若路徑遭封鎖或 僅限 Telegram 的 MTProxy 會引發錯誤；系統不會直接重試。透過刻意 設定的本地 Ollama 位址，可允許使用私有目的地，同時仍使用 所選的路徑。對於其他私有服務，則適用現有的伺服器層級私有 目的地選擇加入機制。控制面板會顯示實際設定的端點。

生成前，傳送至模型的資料會顯示該請求：問題、 已勾選的摘錄、事件類型、觀察時間及覆蓋標記。Telegram 對話、原始欄位、供應商金鑰、附件位元組以及完整的日誌 均不屬於該上下文範圍。請取消勾選不需要的來源，然後明確批准 處理。 外部供應商可能會依據其自身的 政策保留已提交的內容。本地執行意指端點位於本地端；這並不保證 獨立配置的服務會遵循特定行為。

全球範圍內最多同時存在兩項服務供應商請求，且每個 工作區僅限一項。預覽將於十分鐘後過期，且僅能產生一個回覆。 系統會顯示服務提供者回報的代幣數量；成本估算僅在 輸入與輸出費率皆已設定時才會顯示。失敗的嘗試也會 消耗每日請求預算。自動重試不會消耗額外預算。

來源與限制#

檢索功能會透過有限範圍的詞彙搜尋，分析已儲存的訊息內容。該功能最多會返回 24 個來源，並標示被截斷的摘錄或不完整的結果集。此 時間範圍僅指觀察期間，並非聲稱 Telegram 歷史紀錄 完整無缺。工作區範圍內的事件，不會包含在聊天室範圍的存取權限中。 缺失的資料將被描述為「在現有存檔中未找到」。

該模型不接收任何工具。其來源 ID 會與選定的 記錄進行比對，雜湊值會重新核對，且引用的字串必須出現在這些記錄中。 若出現未知 ID、引文內容變更或未經引用的主張，則會駁回該答案。本應用程式 會產生連結；模型生成的 URL 不得用作引用來源。這些檢查 旨在確認來源的存在與引文的準確性，而非推論的真實性。 在依賴推論結果之前，請務必根據原始紀錄進行核對。

報告#

將經審核的回覆儲存為獨立的分析報告。該報告包含模型 摘要、觀察到的時間軸、提取的連結與識別碼、編輯／刪除記錄、 覆蓋範圍限制，以及來源事件雜湊值。報告中同時附有提供者、模型、端點、時間及 提示詞模板版本。系統不會自動合併任何身分資訊。

分析師的修訂與註記會與模型摘要分開儲存。報告 存放在加密的衍生檔案中，其索引位於簽名事件流之外； 原始事件與媒體內容不會被變更。僅有擁有者或管理員才能 開啟報告，且會再次驗證來源存取權限。 下載亦需取得匯出 權限。第 1 版不會對報告進行簽名，亦不暗示模型結論即為 經驗證的證據。限制：每個工作區 100 份報告，每份報告 100 次分析師修訂 。

有關手動 OCR 及文字轉錄，請參閱「媒體處理」。 有關客戶端存取，請參閱 MCP。
