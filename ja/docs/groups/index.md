# アカウントグループの管理

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/groups/

複数の収集アカウントをまとめて管理しつつ、各アカウントの記録と署名IDを明確に区別してください。

アカウントグループを使用すると、接続状況、監視制御、共有設定、およびエクスポート機能を 1 つの作業画面に集約できます。これは、複数のアカウントで同じ調査を担当する場合や、一貫した運用設定が必要な場合に役立ちます。

## グループの概要を開く

「**アカウント**」でグループを開きます。各アカウントには、監視状態、接続経路、直近のチェックが成功した際の測定された経路遅延、および最後に保存されたメッセージが表示されます。「**注意が必要**」リンクは対応が必要なアカウントを示し、**「修正」**をクリックすると、関連するワークスペースとコントロール画面が開きます。

**「すべて開始」**および「**すべて一時停止」**は、確認後に対象となるアカウントに対して実行されます。**「グループ設定」**では選択した設定が共有されます。独自の値が設定されているアカウントは、上書きするまでその値を維持します。

### グループ全体での経路変更を確認する

合成例・説明用のチェック項目と結果

1. **[選択]。**グループを選択し、どのアカウントが変更されるかを確認してください。
2. **準備。**分離しておく必要がある場合は、アカウント固有の経路を維持してください。
3. **確認。**提案された接続をテストし、測定結果を確認してください。
4. **適用してください。**保存前に再確認し、各アカウントの結果を精査してください。

#### ケースチーム

チャンネルコレクター · グループコレクター · 参照アカウント

3つの独立したワークスペース

#### 選定済みの内容

2つのアカウントが提案された手順に従います。

参照アカウントは独自の経路を維持します。

#### 準備確認事項

チャンネルコレクター：Telegram転送時間 84 ms

グループコレクター：Telegram転送 91 ms

これらの数値は、例示のための架空の測定値です。

#### アプリケーションの結果

チャンネルコレクター：保存済み、監視再開。

グループコレクター：再確認に失敗したため、以前の設定が復元されました。

参照アカウント：独自のルートが維持されています。

## レビュー工程を追加してプロセスを変更する

1. **「グループルートの変更**」を選択し、接続タイプと設定を選択してください。
2. **「Review selection」**を選択してください。一覧表示されたアカウントと、それぞれのルートオーバーライドを確認してください。
3. **「準備」**を選択し**、「チェック」を実行してください**。チェックでは新しいTelegramトランスポートが使用されます。サポートされているHTTPルートについては、HTTPS出口チェックの結果も報告されます。
4. **「Apply checked connection」**を選択し、各アカウントの結果を確認してください。以前に実行されていた監視は、アプリケーションが正常に動作した箇所から再開されます。非アクティブなアカウントは非アクティブなままとなります。

「レイテンシー」とは、測定されたTelegramの接続確立時間を指します。「出口IPチェック」とは、記録されたチェック時点におけるその経路の状態を指します。アカウントの認証および監視状態にはそれぞれ独自の指標があり、グループの変更はアカウントごとに異なる結果をもたらす可能性があります。

## 重複するアクセス権を使用する

**「複数のアカウントが閲覧できるチャット」**では、共有されたソースと、ワークスペースの監視範囲が表示されます。対象となるチャンネルおよびスーパーグループでは、**「…アカウントでエクスポート」**機能を使用して、1つのチャットの履歴取得を分割することができます。プライベートチャットおよび通常のグループは、メッセージ番号がアカウントの履歴に属するため、開始アカウントに留まります。

## グループをパッケージとしてエクスポートする

**エクスポート機能では、**各アカウントの署名付きエクスポートデータと、それらのファイルの署名付きリストを1つのZIPファイルにまとめて作成します。検証用に、元のワークスペースのIDおよびフィンガープリントは引き続き利用可能です。これらの参照情報を用いてアカウント横断的な経緯を構築してください。単一の統合タイムラインは、引き続き別途作成されます。

[レポートの設計](https://phishdestroy.github.io/TgWitness/ja/docs/reports/)、[ワークスペース内の「Case Board」](https://phishdestroy.github.io/TgWitness/ja/docs/case-board/)、または[エクスポートの検証](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)に進んでください。
