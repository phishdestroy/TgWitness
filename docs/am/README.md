## መጫን

Python አብሮ ተካትቷል። ለማዘመንም እነዚሁኑ ትእዛዞች ይጠቀሙ።

**Linux / macOS**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**Windows · PowerShell ወይም CMD**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

<sub>Ubuntu አገልጋይ፦ እንደ root ያስኪዱ። ዴስክቶፕ፦ እንደ መደበኛ ተጠቃሚዎ ያስኪዱ። `-ExecutionPolicy Bypass` የሚመለከተው ይህን አንድ የPowerShell ሂደት ብቻ ነው።</sub>

