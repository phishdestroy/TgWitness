مرحلہ 01

ماخذ حاصل کریں۔

ماخذ ZIP فائل ڈاؤن لوڈ کریں اور اسے نکالیں، یا ریپوزیٹری کلون کریں:

git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

ماخذ لانچ کے لیے Python 3.11+ درکار ہے۔ اگر Python موجود نہ ہو تو Windows لانچر انسٹالیشن کی پیشکش کرتا ہے۔

↗ پر ریلیزز براؤز کریں

ونڈوز پر پائتھن نہیں ہے؟ پورٹیبل پیکیج ڈاؤن لوڈ کریں، اسے نکالیں اور TgWitness.cmd پر ڈبل کلک کریں۔

مرحلہ 02

چلانے کا طریقہ منتخب کریں۔

Start.cmd پر ڈبل کلک کریں، یا پاور شیل میں چلائیں:

.\Start.cmd

صرف دریافت کر رہے ہیں؟ ایک الگ تھلگ ڈیمو کے لیے scripts\Demo.cmd پر ڈبل کلک کریں۔ ٹیلیگرام لاگ ان کی ضرورت نہیں۔

Python 3.11+ اور venv دستیاب ہیں:

sh start.sh

اس کے بجائے فرضی جریدہ کھولنے کے لیے sh start.sh --demo چلائیں۔

جب Docker چل رہا ہو اور Compose 2.20+ انسٹال ہو:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

دوسری کمانڈ آپ کا نجی پینل ٹوکن دکھاتی ہے۔ اسے اپنی مشین پر محفوظ رکھیں۔

لانچ کے بعد 127.0.0.1:8787 پر ↗ کھولیں۔

ماخذ انسٹالیشن کے لیے ٹوکن data/live/panel-token.txt میں موجود ہے۔ ٹیلیگرام سائن ان بلٹ ان API سیٹنگز یا my.telegram.org سے آپ کے اپنے جوڑے کا استعمال کر سکتا ہے۔ مکمل سیٹ اپ گائیڈ ↗
