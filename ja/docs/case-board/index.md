# Case Boardの作成

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/case-board/

保存したメッセージを、チームで一緒に取り組むケースに変えます。

ブックマーク、正確な引用、スライス、議論。それぞれが元の記録にリンクしています。変更はすべて署名付きの改訂になります。

## メッセージからケースカードへ

1. **調査 → Case Board**（標準またはエキスパートモード）。ケース用のコレクションを作ります。
2. **ジャーナル**やチャットで**ボードへ**（または **B**）を押します。カードは受信箱に入るので、タイトルを付けて移動します。
3. メッセージの文字を選択し、**ハイライト → ボード**で正確な引用と版を保存します。なぜ重要かを書き添えます。
4. 議論し、ステータスを付け、必要なときはいつでも元の記録に戻ります。**プレゼンテーション**でチームに順を追って見せます。

### 変更された支払いリンクを1つ追跡してください

合成例・ローカルな図解

1. **キャプチャ。**保存済みの観察記録 #142 およびそのメッセージバージョンを開きます。
2. **ブックマーク。**引用文、出典情報、およびご質問をカードに保存してください。
3. **レビュー。**チームコメントを追加し、カードを「レビュー」に移動してください。
4. **現在形を使用してください。**収集手順を順を追って説明し、引用されたソースのコンテキストを開いてください。

#### 保存された観察記録 #142

「新しい支払いリンクをご利用ください。」

運用チャット・メッセージ 38・確認時刻 09:12 UTC

#### カード：宛先を変更

> 新しい支払いリンクをご利用ください。

質問：以前のバージョンにはどの宛先が表示されていましたか？

#### チームによるレビュー

アナリスト：観察事項#101と比較してください。

ステータス：レビュー済み・修正内容を反映

#### 原文の文脈

カード → 保存されたバージョン → 以前の観察記録

注釈とTelegramの監視記録は、それぞれ個別に識別可能です。

## 有用な範囲を一度保存する

2 つのメッセージを Shift+クリックして**その間のスライス**、**時間でスライス**を使うか、現在のジャーナルのフィルターを保存します。**ブックマーク以降に追加されたレコードを表示**で、後から届いたものが見えます。

時間のスライスは観察時刻を使い、メッセージ ID のスライスはそのメッセージの変化を追います。

## 各同僚に適切な役割を割り当てる

**レビュー担当者**は閲覧、**アナリスト**はカードとコメントを追加、**オペレーター**はさらにコレクションと決定を管理します。チャットの権限はカードにも適用されます。

## この作業を成果物としてまとめ上げてください

スライスは署名付き JSON または CSV でエクスポートできます。レポートにはブックマーク、スライス、コメントを入れられ、[Report studio](https://phishdestroy.github.io/TgWitness/ja/docs/reports/) で設定します。限られた相手には[引き渡し](https://phishdestroy.github.io/TgWitness/ja/docs/handover/)を使ってください。
