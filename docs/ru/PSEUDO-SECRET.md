# Секретные чаты: установка и запись

Опубликованное приложение включает бэкенд «Секретного чата», интеграцию с сборщиком, маршруты API и интерфейс **Pseudo-secret**. Библиотека протоколов представляет собой отдельный модуль: откройте **Pseudo-secret**, нажмите **Установить и включите его**. Автоматический приём входящих сообщений остаётся отключённым до тех пор, пока вы его не включите.

<a id="protocol-module"></a>
## Модуль протокола

|  |  |
| --- | --- |
| Модуль | `kiaro-telethon-secret-chat` 0.2.0 |
| Автор | KiaroSama |
| Лицензия | GPL-3.0-или-более-поздней-версии; файлы `LICENSE` и `NOTICE` находятся в сохраненном архиве |
| Исходный код | [KiaroSama/Telethon-Secret-Chat, версия](https://github.com/KiaroSama/Telethon-Secret-Chat) на момент фиксации `d87bf037b90060383c7b704d8a06ebb98c621c6f` |
| Проверка | SHA-256: `c80feb9b5bc28201677c140d20930fbd730d7efdebb8ca789a19040c3f00ce5c`, сверьте со списком файлов пакета и их собственными значениями SHA-256 |

**Установка и включение** доступны главному администратору. TgWitness загружает исходный архив данной фиксации с GitHub через маршрут рабочей области для запросов за пределами Telegram, сравнивает каждый файл пакета со значением, зафиксированным в выпуске TgWitness, сохраняет архив как `modules/telethon-secret-chat-<commit>.zip` в каталоге данных и загружает код из памяти. Перезапуск не требуется. Проверка запускается заново при каждом запуске; архив, содержащий отличия, не загружается, о чём сообщается на странице. Изменение, отсутствие или добавление файла пакета приводит к сбою проверки.

Данный модуль представляет собой отдельное произведение, распространяемое по собственной лицензии. TgWitness не включает его в состав дистрибутива: при каждой установке он загружается из репозитория автора. На странице **подробностей** отображаются сведения о загруженном модуле, его авторе, лицензии, коммите и SHA-256.

Хост, не имеющий доступа к GitHub, может вместо этого установить тот же коммит в среду Python; в таком случае панель будет использовать эту копию:

```sh
python -m pip install ".[secret-chats]"
```

TgWitness становится конечной точкой для чатов, которые он создаёт или принимает. Он записывает сообщения, доступные вложения, изменения таймера и уведомления об удалении в подписанный журнал. Ранее сохранённое содержимое остаётся доступным даже после последующего уведомления об удалении.

<a id="package-availability"></a>
## Доступность пакета

8 ноября 2026 года опубликованный установочный пакет был проверен по исходному коду [`b35f8e18f3d1`](https://github.com/phishdestroy/TgWitness/commit/b35f8e18f3d13c329af12e0036f50e0c8f340a2c), релизу `b35f8e18f3d1-1ff85ec98bb2` и версии 0.9.1 preview. [Неизменяемый](https://get.destroy.tools/releases/b35f8e18f3d1-1ff85ec98bb2/tgwitness-0.9.1-py3-none-any.whl)файл [wheel](https://get.destroy.tools/releases/b35f8e18f3d1-1ff85ec98bb2/tgwitness-0.9.1-py3-none-any.whl) и его блокировка зависимостей прошли проверку подписей выпуска с использованием алгоритмов SHA-256 и RSA. Включённые в пакет бэкенд и интерфейс полностью совпадали с данной ревизией исходного кода байт за байтом. Пакет также содержит регистрацию API и хуки сборщика.

Данный пакет не содержал библиотеку протоколов, и она отсутствует в списке зависимостей. Дополнительный элемент `secret-chats` в [файле pyproject.toml](../../pyproject.toml) указывает на тот же коммит, что и кнопка панели.

Данная проверка пакета определяет, какие файлы и декларации зависимостей поставляются. [Запись проверки](VERIFICATION.md) указывает отдельные проверки во время выполнения. В предыдущем руководстве от 6 ноября описывался снэпшот разработки; оно больше не относится к вышеуказанному пакету.

<a id="use-the-interface"></a>
## Использование интерфейса

Откройте **Pseudo-secret**, установите модуль, если он предлагается на странице, включите его для аккаунта и подключитесь. Входящие запросы ожидают подтверждения, если не включена функция автоматического принятия. Запуск, принятие, отправка и закрытие осуществляются с использованием прав взаимодействия аккаунта и защиты от чтения.

| Действие | Сохраненный результат |
| --- | --- |
| Запуск чата по имени пользователя или идентификатору пользователя | Исходящий запрос; собеседник принимает его на своём устройстве. |
| Принять запрос | TgWitness становится принимающей конечной точкой. |
| Отправка или получение сообщения | `secret_chat.message` с указанием направления, содержания и заданного таймера. |
| Приём файла | Расшифрованные байты, защищённые алгоритмом SHA-256, и квитанция `secret_chat.file`; включаются в экспорт доказательств. |
| Получение таймера или уведомления об удалении | Отдельная запись о действии наряду с сохраненными сообщениями и файлами. |
| Просмотр чата | Ход переписки, квитанции о получении файлов, уведомления и визуализация ключей. |

Существующие секретные чаты на другом устройстве сохраняют свои ключи, привязанные к данному устройству. При импорте сеанса из облака эти ключи не передаются. Ключевые материалы и счетчики секретных чатов хранятся в хранилище рабочей области; сохраненные сообщения и расшифрованные файлы защищены стандартными средствами защиты хранилища рабочей области.

<a id="find-saved-messages"></a>
## Поиск сохраненных сообщений

Используйте **функцию Поиск сообщений** в открытом чате, чтобы найти точную фразу с игнорированием регистра. **Кнопки Предыдущее** и **Следующее** или комбинации клавиш Enter и Shift+Enter в поле поиска позволяют перемещаться между соответствующими сообщениями. Счётчик подсчитывает количество сообщений; первая совпадающая фраза в каждом сообщении выделяется. Нажатие клавиши Escape очищает поле поиска.

При поиске остаются видимыми сопутствующие сообщения, сохраненные файлы и уведомления об удалении. Поиск осуществляется по записям, уже загруженным в панель. Если имеются более ранние записи, панель отображает соответствующее уведомление; **команда Загрузить более старые записи** расширяет историю и обновляет результаты поиска, сохраняя текущее сообщение на месте.

Каждый чат сохраняет свой поиск при переключении в пределах одной рабочей области. Блокировка панели или смена рабочих областей очищает эти поисковые запросы. Поисковые запросы остаются в памяти страницы и не сохраняются в хранилище браузера, а также не отправляются в виде запросов API. Поиск не отправляет сообщения Telegram и не генерирует уведомления о вводе текста или прочтении. Существующие настройки видимости по-прежнему регулируют открытие чата и другие действия.

**Отчёт по сборке** сохраняет область охвата выбранного чата; поиск на экране не ограничивает экспортируемые записи незаметно. Перед загрузкой отчёта просмотрите его выбор.

<a id="persistence-and-interaction-controls"></a>
## Управление сохранностью данных и взаимодействиями

Встроенная реализация использует устойчивый поиск по журналу для обнаружения дубликатов, сохраняет задания на загрузку вложений в состоянии ожидания после неудачной загрузки и направляет закрытие через тот же механизм защиты взаимодействия, что и другие удалённые действия. Эти механизмы заменяют три пути, о которых сообщалось в предыдущем аудите снимка разработки от 6 ноября.

Расшифрованные сообщения, запись которых в журнал завершилась неудачей, хранятся в хранилище для повторной попытки. Проверки размера вложений и свободного места на диске приостанавливают загрузку, сохраняя при этом соответствующие задания. Модуль повторно использует существующее соединение аккаунта. Уведомления о прочтении и наборе текста отправляются только в соответствии с настройками, выбранными в разделе [Что видит собеседник](INVESTIGATION-MODE.md#what-the-other-side-sees); уведомления в виде снимков экрана никогда не отправляются. См. [файл secret_chats.py](../../tgwitness/secret_chats.py), [маршруты API](../../tgwitness/api/secret_chats.py) и [политику доступа](../../tgwitness/access.py).

В [историческом отчёте](../../website/validation/audit/REPORT.md) сохранены исходные результаты моментального снимка. Информацию о текущей доступности и реализации следует извлекать из указанной выше версии пакета и сведений о [текущих возможностях](STATUS.md).
