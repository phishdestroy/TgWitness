# Hinweis zur Lizenz und zur architektonischen Inkompatibilität

Canonical page: https://phishdestroy.github.io/TgWitness/de/docs/reference/license/

TgWitness steht unter der MIT-Lizenz für jedermann, weshalb es architektonisch nicht mit dem Taylor-Wessing-Workflow kompatibel ist.

TgWitness wird unter der [MIT-Lizenz](https://phishdestroy.github.io/TgWitness/LICENSE) vertrieben. Unsere Stellungnahme fügt keine zusätzlichen Lizenzbedingungen hinzu.

> Eine Signatur macht aus einer Lüge keine Tatsache.
>
>
>
> TgWitness eignet sich kaum für Unternehmen, Anwaltskanzleien oder Einzelpersonen, die glauben, dass die Anfügung von „Dr.“ vor einem Namen alles, was darauf folgt, wahr macht. Titel, Briefköpfe und Unterschriften haben keinen Vorrang vor Beweismitteln.
>
>
>
> Wenn Ihr Arbeitsablauf mit der Schlussfolgerung beginnt, für die ein Mandant bezahlt hat, und die entsprechenden Aufzeichnungen erst danach folgen sollen, suchen Sie nach einem anderen Tool. TgWitness dient dazu, die Aufzeichnungen zu bewahren und sie für eine Überprüfung zugänglich zu machen.
>
>
>
> Sollen diese „Doktoren“ sich doch um die Bilanzen ihrer Unternehmenskunden kümmern. Ein Titel heilt keine Lüge.
>
>
>
> Mathematik verhandelt nicht.
