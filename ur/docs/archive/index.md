# Telegram · آرکائیو پر کام کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/archive/

پیغام تلاش کریں۔ ماخذ کی تصدیق کریں۔ کیس تیار کریں۔

01**تاریخ شامل کریں**

فعال ذرائع کے پرانے پیغامات ورک اسپیس میں کھینچیں۔

02**ماخذوں کی پیروی کریں**

تلاش کریں، پھر ہر نتیجے کے پیچھے محفوظ پیغام کھولیں۔

03**ہینڈ آف کو واضح رکھیں**

آپ کا تجزیہ ایک فائل میں، دستخط شدہ ثبوت اس کے ساتھ۔

محفوظ شدہ ریکارڈز، شناخت شدہ متن اور تجزیہ کار کے نتائج الگ الگ رہتے ہیں۔

## گزشتہ پیغامات لوڈ کریں

1. **ذرائع ← دائرے میں چیٹس**: فعال چیٹس دیکھیں، مشاہدہ شروع کریں۔
2. **پوری تاریخ لوڈ کریں**۔ یہ ذرائع کی فہرست ویسی ہی لیتا ہے جیسی ابھی ہے۔
3. **تاریخ روکیں** / **تاریخ جاری رکھیں** کسی بھی وقت۔ ری اسٹارٹ کے بعد خود دوبارہ شروع کریں۔
4. ہر ذریعے کے نتائج اور ڈاؤن لوڈ قطار دیکھیں، دستخط شدہ پیش رفت رپورٹ ایکسپورٹ کے ساتھ رکھیں۔

یہ ورک اسپیس بھرتا ہے۔ ایک چیٹ کا HTML/JSON ایکسپورٹ الگ چیز ہے۔ [تفصیلات](https://phishdestroy.github.io/TgWitness/ur/docs/reference/history/)۔

## پہلے تلاش کریں، پھر AI کے بارے میں فیصلہ کریں

1. **جرنل** مقامی طور پر تلاش کرتا ہے، ذریعے اور وقت سے فلٹر کریں۔
2. کوئی جملہ یا ڈومین تلاش کریں، ریکارڈ اور اس کے ورژن کھولیں۔
3. AI کے لیے ایڈمن **انٹیگریشنز** میں فراہم کنندہ سیٹ کرتا ہے۔ پھر **آرکائیو سے پوچھیں**: چیٹس اور مدت چنیں، **ماڈل کو بھیجا گیا ڈیٹا** دیکھیں اور جو باہر نہیں جانا چاہیے اس کا نشان ہٹا دیں۔
4. حوالے جانچیں، جواب کو رپورٹ کے طور پر محفوظ کریں، اپنے نوٹس شامل کریں۔

تلاش کے لیے AI ضروری نہیں۔ رپورٹس دستخط شدہ جرنل سے الگ اپنے ذرائع اور نظرثانیاں رکھتی ہیں۔ [فراہم کنندہ سیٹ اپ](https://phishdestroy.github.io/TgWitness/ur/docs/reference/analysis/)۔

## اپنی مطلوبہ کنکشن منتخب کریں

| ٹاسک | کھلا | سیٹ اپ |
| --- | --- | --- |
| AI کلائنٹ کو منتخب چیٹس پڑھنے دیں | **انٹیگریشنز → MCP** | [MCP انسٹال کریں، محدود ٹوکن بنائیں، جوڑیں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/mcp/) |
| محفوظ شدہ میڈیا میں متن کی شناخت کریں | `media.saved` ریکارڈ → **منسلکہ کو پہچانیں** | [مقامی Docker ورکر سیٹ کریں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/media-analysis/) |
| واقعات کو n8n یا SIEM کو بھیجیں | **انٹیگریشنز → آؤٹ گوئنگ ویب ہُکس** | [وصول کنندہ شامل کریں، HMAC جانچیں، دہرے ID ہٹائیں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/webhooks/) |

**کون سا ایکسس ٹوکن کہاں استعمال ہوتا ہے؟**

پینل تک رسائی لوگوں کے لیے ہے۔ MCP کے اپنے صرف پڑھنے والے ٹوکن ہیں، webhooks کا اپنا HMAC سیکرٹ۔ کسی کو Telegram سیشن نہیں چاہیے۔

[پینل تک رسائی شیئر کریں](https://phishdestroy.github.io/TgWitness/ur/docs/access/) یا [MCP کلائنٹ ترتیب دیں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/mcp/)۔
