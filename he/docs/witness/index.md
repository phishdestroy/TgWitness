## הכינו בוט וערוץ

צרו בוט עם BotFather ותנו לו לפרסם בערוץ שלכם. הריצו את העד במקום אחר: מארח אחר, רצוי בניהול של מישהו אחר, שווה הרבה יותר מתהליך שני ליד האוסף.

## שלושה שלבים ב"תוספות"

1. **גישה לקריאה בלבד.** **תוספות ← עד עצמאי**, צרו טוקן, שמרו את הקובץ. הוא קורא נקודות ביקורת ותקינות, ותו לא.
2. **ערוץ ומרווח.** ערוץ Telegram או webhook של Discord, ועוד כתובת אוסף שהעד יכול להגיע אליה. שמרו את קובץ ההגדרות.
3. **הפעלה.** שימו את `witness.json`, `witness-token.txt` ו-`bot-token.txt` יחד על מארח העד והריצו:

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

חכו לפוסט החתום הראשון בערוץ, ואז שמרו את טביעת האצבע של העד במקום בטוח.

מעדיפים Discord? שמרו את כתובת ה-webhook כ-`discord-webhook.txt`. עד אחד מפרסם במקום אחד; בדיקות ארוכות מגיעות כקובץ ב-Discord.

## בחרו את תדירות הפרסום

פרסום של כל בדיקה נותן תיעוד חיצוני קבוע: כל חמש דקות זה בערך 288 פוסטים ביום לכל סביבת עבודה. הגדרות מתקדמות יכולות לפרסם רק בשינויים או בעיות, להשתמש בפרוקסי או ב-Bot API מותאם.

**על מה בדיוק מעיד הבוט?**

הוא מבקש מהאוסף נקודת ביקורת חתומה, בודק אותה מול המפתח הצפוי ושומר יומן חתום משלו, כולל תשובות שהוחמצו ונדחו.

הוא בודק את מצב היומן, הוא לא עוקב אחרי Telegram בעצמו. לשם כך, בצעו בדיקת מסירה מבוקרת.

## בדקו את הראיות מאוחר יותר
