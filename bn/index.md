## S3 কপি। বাহ্যিক যাচাইকরণ।

এনক্রিপ্টকৃত কপিগুলো সংরক্ষণ করুন এবং স্বাধীন যাচাইকরণ যোগ করুন।

ডিফল্টভাবে বন্ধ

### সবকিছু S3-সামঞ্জস্যপূর্ণ স্টোরেজে কপি করুন

জার্নাল, ফাইল, টাইমস্ট্যাম্পযুক্ত চেকপয়েন্ট এবং চ্যাট এক্সপোর্ট — AWS S3 বা সামঞ্জস্যপূর্ণ স্টোরেজে আপলোডের আগে এনক্রিপ্ট করা।

**স্টোরেজ সেটিংস এবং পুনরুদ্ধার**

ক্লায়েন্ট-সাইড এনক্রিপশন

`AES-256-GCM` এই মেশিনের অবজেক্টগুলো এনক্রিপ্ট করে। প্রদানকারী এনক্রিপ্ট করা অবজেক্টগুলো গ্রহণ করে।

নির্ধারিত বা ম্যানুয়াল অনুলিপি

এখনই অনুলিপি করুন, অথবা ১ থেকে ১,৪৪০ মিনিটের মধ্যে একটি সময়সীমা নির্বাচন করুন। প্যানেলে অগ্রগতি পরীক্ষা করুন।

অবজেক্ট লক

বাকট যখন রিটেনশন ডে এবং মোড সমর্থন করে, তখন সেগুলো নির্বাচন করুন। প্যানেল রিপোর্ট করে যে আপলোডকৃত অবজেক্টে রিটেনশন নিশ্চিত হয়েছে কিনা।

নিশ্চিত পুনরুদ্ধার

এনক্রিপশন কী ডাউনলোড করুন এবং তা আলাদাভাবে সংরক্ষণ করুন। অন্য কোনো মেশিনে পুনরুদ্ধার করুন; যাচাইকরণ সম্পন্ন হলেই ফাইলগুলো প্রকাশিত হবে।

![সম্পূর্ণ অফ-সাইট কপি প্যানেল: এন্ডপয়েন্ট, অঞ্চল, বাকেট, অ্যাক্সেস কী, সময়সূচি, অবজেক্ট লক এবং রিকভারি কী নিয়ন্ত্রণসমূহ](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

উন্নত বিকল্পসহ সম্পূর্ণ প্যানেল প্রসারিত। কোনো স্টোরেজ শংসাপত্র দেখানো নেই।

জার্নাল এবং মিডিয়া`AES-256-GCM`S3-সামঞ্জস্যপূর্ণ স্টোরেজ

[S3 কনফিগার করুন এবং একটি কপি পুনরুদ্ধার করুন](https://phishdestroy.github.io/TgWitness/bn/docs/exports/#s3)[-এর যাচাইকরণ বিবরণ পড়ুন।](https://phishdestroy.github.io/TgWitness/bn/docs/reference/evidence/#off-site-copy-and-restore-s3)

করে না। রপ্তানি করা ডিক্রিপশন কী ছাড়া এটি পুনরুদ্ধার করে না বা একটি স্বাধীন সাক্ষীকে প্রতিস্থাপন করে না।

### অবহিতকরণ · অবহিত করা

সমস্যা সতর্কতা, চ্যাট পরিবর্তন এবং দৈনিক সারসংক্ষেপ Apprise-এর মাধ্যমে: মেসেঞ্জার, ইমেইল বা আপনার নিজস্ব JSON ওয়েবহুক।

**করে না।** আপনি যদি উদ্ধৃতিগুলি সক্ষম না করেন তবে এটি বার্তার টেক্সট পাঠায় না।

 [নোটিফিকেশন গন্তব্যসমূহ কনফিগার করুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/operations/#notifications)

**করে না** এটি একটি পেন্ডিং ক্যালেন্ডার রসিদকে নিশ্চিত বিটকয়েন টাইমস্ট্যাম্প হিসেবে গণ্য করে না।

 [টাইমস্ট্যাম্প প্রমাণগুলি পরীক্ষা করুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/timestamp/)

### স্বতন্ত্র সাক্ষী

একটি পৃথক হোস্ট স্বাক্ষরিত পর্যবেক্ষণ সংরক্ষণ করে এবং `TGW1` চেকপয়েন্ট প্রকাশ করতে পারে।

**করে না** এটি একটি কালেক্টর হোস্টে থাকা দুইটি ওয়ার্কস্পেসকে স্বাধীন সাক্ষ্যে পরিণত করে না।

 [নামে একটি সাক্ষী সেট আপ করুন।](https://phishdestroy.github.io/TgWitness/bn/docs/witness/)

### পুনরুদ্ধার এবং দৃশ্যমান ফাঁক

পুনরায় শুরু করার পর পুনরায় শুরু করুন। পুনরায় যাচাইকরণ এবং `coverage.json` পুনরুদ্ধারকৃত বার্তা এবং ফাঁকগুলি দেখায়।

**করে না:** এটি প্রতিটি মিস করা সম্পাদনা বা অদৃশ্য হয়ে যাওয়া বার্তা পুনর্গঠন করে না।

 [অব্যাহততা এবং ফাঁক পরিদর্শন করুন](https://phishdestroy.github.io/TgWitness/bn/guides/modes.html#continuity)

[সেটআপ গাইডটি পড়ুন।](https://phishdestroy.github.io/TgWitness/demo/guide.html?lang=bn)

**একটি আমদানি করা সেশন, একটি চলমান ক্লায়েন্ট।**

একই সময়ে Telegram Desktop এবং TgWitness-এ আমদানি করা TData/session কী ব্যবহার করবেন না। Telegram শেয়ার করা অনুমোদন বাতিল করে দিতে পারে (AUTH_KEY_DUPLICATED)। সমান্তরাল ব্যবহারের জন্য ফোন বা QR কোডের মাধ্যমে একটি পৃথক TgWitness লগইন তৈরি করুন।

[সেশন ইমপোর্ট সতর্কবার্তা পড়ুন](https://phishdestroy.github.io/TgWitness/demo/guide.html?lang=bn#session-warning)

**সংযোগ করার আগে একবার দেখে নিন।**

টেলিগ্রাম অ্যাকাউন্ট ছাড়াই কাল্পনিক কর্মক্ষেত্রটি ব্যবহার করে দেখুন।

[অনলাইন ডেমো খুলুন →](https://phishdestroy.github.io/TgWitness/demo/?lang=bn)

ধাপ ০১

### উৎসটি পান।

[সোর্স ZIP ফাইলটি ডাউনলোড](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) করে আনজিপ করুন, অথবা রেপোজিটরিটি ক্লোন করুন:

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

সোর্স লঞ্চের জন্য Python 3.11 বা তার পরবর্তী সংস্করণ প্রয়োজন। Windows লঞ্চার Python অনুপস্থিত থাকলে ইনস্টলেশন অফার করে।

[রিলিজগুলো ব্রাউজ করুন](https://github.com/phishdestroy/TgWitness/releases)

উইন্ডোজে পাইথন নেই? [পোর্টেবল প্যাকেজটি ডাউনলোড করুন](https://github.com/phishdestroy/TgWitness/releases/download/v0.7.0/TgWitness-0.7.0-windows-amd64-portable.zip), এটি এক্সট্র্যাক্ট করুন এবং `TgWitness.cmd`-এ ডাবল-ক্লিক করুন।

ধাপ ০২

### কীভাবে চালাতে হবে তা নির্বাচন করুন।

`Start.cmd`-এ ডাবল-ক্লিক করুন, অথবা PowerShell-এ চালান:

```
.\Start.cmd
```

শুধুমাত্র অন্বেষণ করছেন? একটি বিচ্ছিন্ন ডেমোর জন্য `scripts\Demo.cmd`-এ ডাবল-ক্লিক করুন। টেলিগ্রাম লগইন প্রয়োজন নেই।

Python 3.11+ এবং `venv` উপলব্ধ:

```
sh start.sh
```

কল্পিত জার্নাল খুলতে, `sh start.sh --demo` চালান।

Docker চলছে এবং Compose 2.20+ ইনস্টল করা আছে:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

দ্বিতীয় কমান্ডটি আপনার প্রাইভেট প্যানেল টোকেন দেখায়। এটি আপনার মেশিনে রাখুন।

লঞ্চ করার পর [127.0.0.1:8787 এ](http://127.0.0.1:8787) খুলুন।

সোর্স ইনস্টলের জন্য টোকেনটি `data/live/panel-token.txt`-এ রয়েছে। টেলিগ্রাম সাইন-ইন বিল্ট-ইন API সেটিংস ব্যবহার করতে পারে অথবা [my.telegram.org](https://my.telegram.org) থেকে আপনার নিজস্ব জোড়া ব্যবহার করতে পারে। [সম্পূর্ণ সেটআপ গাইড ↗](https://phishdestroy.github.io/TgWitness/bn/docs/reference/quickstart/)

## শুরু করার আগে।

**এই পৃষ্ঠা কি টেলিগ্রামের সাথে সংযুক্ত?**

না। এটি একটি স্থির প্রকল্প পৃষ্ঠা, যাতে কাল্পনিক উদাহরণ এবং স্ক্রিনশট রয়েছে। প্রকৃত অ্যাপ্লিকেশনটি আপনার কম্পিউটার বা সার্ভারে চলে; সাইন-ইন সেখানেই হয়।

**এটি ক্যাপচারের আগে মুছে ফেলা বার্তা পুনরুদ্ধার করতে পারে কি?**

না। TgWitness সংগ্রহ চলার সময় আপনার অ্যাকাউন্টে দেখা বিষয়বস্তু সংরক্ষণ করে। পরবর্তীতে নেওয়া হিস্ট্রি স্ন্যাপশট মিস হওয়া সম্পাদনা বা মুছে ফেলা বার্তা পুনর্গঠন করতে পারে না।

**আমার পুরো জার্নাল কি এনক্রিপ্ট করা আছে?**

অ্যাকাউন্টের শংসাপত্র এবং স্বাক্ষর গোপনীয়তা একটি এনক্রিপ্ট করা ভল্টে সংরক্ষিত থাকে। স্থানীয় বার্তা এবং সংযুক্তিগুলির জন্য একটি এনক্রিপ্ট করা ডিস্ক বা ভলিউম প্রয়োজন। রপ্তানি ঐচ্ছিকভাবে পাসওয়ার্ড-সুরক্ষিত AES-256 ZIP ব্যবহার করতে পারে।

**এটি টেলিগ্রামের সাথে যুক্ত কি?**

না। TgWitness একটি স্বাধীন প্রকল্প যা Telethon ব্যবহার করে এবং MIT লাইসেন্সের অধীনে বিতরণ করা হয়েছে। আপনি বিল্ট-ইন API সেটিংস বা আপনার নিজস্ব API পেয়ার ব্যবহার করে আপনার নিজস্ব অ্যাকাউন্টগুলো অনুমোদন করেন।
