# Telegram · Bir necha daqiqada boshlang

Canonical page: https://phishdestroy.github.io/TgWitness/uz/docs/start/

Avval demoni aylanib chiqing, so'ng o'z hisobingizni ulang.

## Hisobisiz atrofga nazar soling

Loyihani oling, **Python 3.11 yoki yangisi** bo'lsin, demoni ishga tushiring. Qolganini ishga tushirgich sozlaydi.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

Brauzerda to'qima xabarlar bilan ish maydoni ochiladi. Chatni oching, tahrirni solishtiring, eksportni ko'ring. Telegram ishtirok etmaydi.

![TgWitness suhbat ko'rinishi namunali xabarlar bilan](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Namuna ish maydoni. Sizning jurnaliz alohida boshlanadi.

## O'zingizning ish maydoningizni yarating

Demoni yoping, so'ng:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Ishga tushirgich ko'rsatgan manzilni oching va u nomlagan fayldan **panelga kirish tokeni**ni joylashtiring. Bu TgWitness uchun, Telegram uchun emas.

## Birinchi xabaringizni qayd eting

1. [Maxsus Telegram hisobini ulang.](https://phishdestroy.github.io/TgWitness/uz/docs/accounts/)
2. Guruh yoki kanalni tanlang va kuzatuvni boshlang.
3. Sinov guruhingizda xabar yuboring va uning jurnalda paydo bo'lishini kuzating.

Serverni o'rnatish uchun "[Uni ishga tushirishda saqlang](https://phishdestroy.github.io/TgWitness/uz/docs/server/)" bo'limiga rioya qiling.
