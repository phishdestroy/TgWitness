git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

Python 3.11+ দরকার। Windows－এ লঞ্চার এটি ইনস্টল করার প্রস্তাব দেয়।

কীভাবে চালাতে হবে তা নির্বাচন করুন।

Start.cmd－এ ডাবল－ক্লিক করুন， অথবা PowerShell－এ চালান：

.\Start.cmd

শুধুমাত্র অন্বেষণ করছেন？ একটি বিচ্ছিন্ন ডেমোর জন্য scripts\Demo.cmd－এ ডাবল－ক্লিক করুন। টেলিগ্রাম লগইন প্রয়োজন নেই।

Python 3.11+ এবং venv উপলব্ধ：

sh start.sh

কল্পিত জার্নাল খুলতে， sh start.sh --demo চালান।

Docker চলছে এবং Compose 2.20+ ইনস্টল করা আছে：

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

শুরু করার আগে।

এই পৃষ্ঠা কি টেলিগ্রামের সাথে সংযুক্ত？

না। এটি ভুয়া উদাহরণসহ একটি স্থির পেজ। অ্যাপ আপনার নিজের মেশিনে চলে এবং আপনি সেখানেই সাইন ইন করেন।

এটি ক্যাপচারের আগে মুছে ফেলা বার্তা পুনরুদ্ধার করতে পারে কি？

না। চলাকালীন আপনার অ্যাকাউন্ট যা দেখেছে তাই রাখে। পরের স্ন্যাপশট মিস হওয়া সম্পাদনা বা মুছে ফেলা বার্তা আবার তৈরি করতে পারে না।

আমার পুরো জার্নাল কি এনক্রিপ্ট করা আছে？

সেশন ও কী হ্যাঁ। বার্তা ও ফাইল না， ডিস্ক এনক্রিপশন ব্যবহার করুন। এক্সপোর্টে AES－256 পাসওয়ার্ড দেওয়া যায়।

এটি টেলিগ্রামের সাথে যুক্ত কি？

না। এটি Telethon－এর উপর তৈরি MIT লাইসেন্সের একটি স্বাধীন প্রকল্প। আপনি নিজের অ্যাকাউন্ট দিয়ে লগইন করেন।
