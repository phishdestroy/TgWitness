# Telegram · یک نسخهٔ اشتراک‌گذاری آماده کنید

Canonical page: https://phishdestroy.github.io/TgWitness/fa/docs/handover/

فقط آنچه لازم است را به اشتراک بگذارید، اصل دست‌نخورده می‌ماند.

تحویل یک برگزیده امضاشده جداگانه است: گفتگوها و افراد را انتخاب کنید، هویت‌ها یا متن را پنهان کنید، فایل‌ها و یادداشت‌های تیم را انتخاب کنید. فهرست ثبت می‌کند چه نگه داشته، کوتاه و کنار گذاشته شد.

## خروجی گیرنده را آماده کنید

1. **خروجی‌ها ← برگزیده تحویل**: هدف را بنویسید، گفتگوها و بازه را انتخاب کنید، اگر افراد بانام لازم دارید **بارگذاری افراد گفتگوهای انتخابی**.
2. بقیه: نام مستعار، کنار گذاشته، یا همان‌طور که ثبت شده. متن و فایل‌ها کلیدهای جداگانه‌اند؛ تلفن‌ها و ایمیل‌ها را می‌توان پوشاند.
3. Case Board: هیچ، نشانک‌ها و برش‌ها، یا کارت‌ها با نظرات. نام اعضای تیم را می‌توان با نام مستعار عوض کرد.
4. **دانلود برگزیده تحویل**، بازش کنید، تأییدش کنید، پیش از ارسال نگاهی بیندازید.

### یک نسخهٔ اصلی، یک نسخهٔ اشتراکی عمدی

مثال مصنوعی · صرفاً برای نمایش هویت

1. **انتخاب کنید.** گفتگوی پرونده را شامل کنید و فردی را که استخراج دربارهٔ اوست شناسایی کنید.
2. **حداقل‌سازی.** انتخاب کنید که شرکت‌کنندهٔ دیگر چگونه در نسخهٔ مشترک‌شده ظاهر شود.
3. **بازرسی کنید.** گزارش و سوابق آرشیو تولیدشده را پیش از ارسال باز کنید.
4. **اشتراک‌گذاری.** نسخهٔ بررسی‌شده را تحویل دهید و اثر انگشت معتبر آن را به‌طور جداگانه اعلام کنید.

#### مشاهدهٔ اصلی

نورا · کاربر ۷۱۰۰۲

«لینک اصلاح‌شده را دریافت کردم.»

ژورنال منبع این مشاهدهٔ ذخیره شده را حفظ می‌کند.

#### نسخه دریافت‌کننده

به‌صورت ضبط‌شده نمایش دهید: نورا · کاربر ۷۱۰۰۲ · «لینک اصلاح‌شده را دریافت کردم.»

نام مستعار: P01 · «لینک اصلاح‌شده را دریافت کردم.»

حذف: پیام این شرکت‌کننده از متن کپی حذف می‌شود.

#### فایل‌های واقعی را بازرسی کنید

فایل‌های report.html و records.jsonl را بخوانید.

هویت‌ها، متن، پیوست‌ها و نظرات اختیاری تیم را بررسی کنید.

#### خروجی امضا شده

انتخاب + هش‌های فایل + مانیفست امضا شده

یک بستهٔ جداگانه که به مرز مجلهٔ منبع خود پیوند خورده است

## کنترل‌ها را با هم استفاده کنید

| کنترل | تأثیر بر کپی |
| --- | --- |
| افراد | افراد انتخاب‌شده با نام می‌مانند؛ بقیه نام مستعار می‌گیرند یا کنار گذاشته می‌شوند. |
| متن | همه متن، فقط متن افراد انتخاب‌شده و حساب شما، یا هیچ. |
| فایل‌ها | فایل‌های افراد انتخاب‌شده و حساب شما، همه فایل‌های نمایش‌داده‌شده، یا هیچ. |
| تخته پرونده | هیچ، نشانک‌ها و برش‌ها، یا کارت‌ها با بحث. |

متن و فایل‌ها را هم بخوانید: نام مستعار نام‌هایی را که داخل پیام یا پیوست نوشته شده حذف نمی‌کند. اگر فایل انتخابی گم شده، بازیابی‌اش کنید یا پیوست‌ها را کنار بگذارید.

## متن را به‌گونه‌ای نگه‌دارید که به‌طور مستقل قابل بررسی باشد.

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

بایگانی اصلی و نقاط بازرسی را خودتان نگه دارید. گیرنده می‌تواند نسخه‌اش را بدون گرفتن کل فضای کاری تأیید کند. طرح: [Report studio](https://phishdestroy.github.io/TgWitness/fa/docs/reports/). مرجع‌های مورد اعتماد: [تأیید خروجی](https://phishdestroy.github.io/TgWitness/fa/docs/exports/).
