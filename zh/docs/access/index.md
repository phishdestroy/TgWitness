# 分享案例

Canonical page: https://phishdestroy.github.io/TgWitness/zh/docs/access/

分享他人需要的案例。其余内容由您掌控。

01**选择证据**

可选择整个账户的工作区或单个已记录的聊天记录。

02**选择操作**

允许查看、导出或授予该人员所需的特定操作权限。

03**设置限制**

生成一个带有有效期、会话限制及可选 IP 限制的个人令牌。

采集范围决定了记录的内容。访问范围决定了用户可以查看和执行的操作。

## 授予某人访问权限

1. 以管理员身份登录并打开**“访问”页面**。
2. 请输入访问名称，并选择工作区和聊天群组。
3. 保留**“查看”**功能供审阅者使用。如需下载记录，请添加**“导出”功能**。
4. 设置权限限制，然后点击**“创建访问权限**”。
5. 请复制一次显示的令牌。将其与面板地址一起私下发送。
6. 在移交前，请在单独的浏览器会话中检查允许的查看范围。

## 从他们需要完成的工作入手

| 人物 | 访问 | 结果 |
| --- | --- | --- |
| 审稿人 | 精选聊天记录；仅限查看 | 在不修改采集内容的情况下阅读捕获的对话记录。 |
| 分析师 | 精选聊天记录；查看和导出 | 查看并下载本案所需的记录。 |
| 操作员 | 精选的完整工作区；来源与收集 | 管理监控内容，并启动或停止采集器。 |

这些是您自行选择的配置，而非固定的角色。即使启用了其他权限，全局账户设置和完整日志导出功能仍对受聊天限制的用户保持关闭状态。所有工作区访问权限均包含未来创建的账户。

## 您可以随时改变主意

编辑访问权限以更改后续请求可执行的操作。结束单个会话或撤销全部访问权限以终止所有会话。已下载的文件无法撤回。结束面板会话不会停止数据收集。

**会话和 IP 限制**

限制并行会话和成功登录次数，设置绝对截止日期，允许指定 IP 地址或子网，或将访问权限绑定至首次登录的地址。会话过期以无活动状态为判定标准；打开的面板的轮询计数也视为活动。当应用程序在代理或隧道后运行时，请检查应用程序显示的客户端地址。

**主密钥和活动日志**

管理员持有主面板令牌。已授予访问权限的用户无法管理他人的访问权限，也无法打开管理员控制台。控制台显示跨工作区的当前进程活动；签名的访问记录会保留授权和会话事件，但不会包含令牌信息。各工作区共享主机进程，其数据不会与服务器管理员的数据隔离。

请使用[完整的权限参考](https://phishdestroy.github.io/TgWitness/zh/docs/reference/access/)文档，涵盖全部七项权限、会话规则以及管理员权限边界。
