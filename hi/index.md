चरण 01

### स्रोत प्राप्त करें।

[स्रोत ZIP डाउनलोड करें](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) और उसे एक्सट्रेक्ट करें， या रिपॉजिटरी क्लोन करें：

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

Python 3.11+ ज़रूरी है। Windows पर लॉन्चर इसे इंस्टॉल करने की पेशकश करता है।

[रिलीज़ ब्राउज़ करें](https://github.com/phishdestroy/TgWitness/releases)

चरण 02

### चलाने का तरीका चुनें।

`Start.cmd` पर डबल－क्लिक करें， या PowerShell में चलाएँ：

```
.\Start.cmd
```

सिर्फ़ देख रहे हैं？ एक अलग डेमो के लिए `scripts\Demo.cmd` पर डबल－क्लिक करें। टेलीग्राम लॉगिन की आवश्यकता नहीं है।

पाइथन 3.11+ और `venv` उपलब्ध：

```
sh start.sh
```

कल्पनिक जर्नल खोलने के लिए इसके बजाय `sh start.sh --demo` चलाएँ।

Docker चलने और Compose 2.20+ स्थापित होने पर：

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

दूसरा कमांड आपका निजी पैनल टोकन दिखाता है। इसे अपनी मशीन पर रखें।

लॉन्च के बाद [127.0.0.1:8787 पर](http://127.0.0.1:8787) खोलें।

सोर्स से इंस्टॉल करने पर टोकन `data/live/panel-token.txt` में रहता है। [my.telegram.org](https://my.telegram.org) से अपनी API जोड़ी वैकल्पिक है। [पूरी सेटअप गाइड ↗](https://phishdestroy.github.io/TgWitness/hi/docs/reference/quickstart/)

## शुरू करने से पहले।

**क्या यह पेज टेलीग्राम से जुड़ता है？**

नहीं। यह नकली उदाहरणों वाला स्थिर पेज है। ऐप आपकी अपनी मशीन पर चलता है और आप वहीं साइन इन करते हैं।

**क्या यह कैप्चर से पहले हटाए गए संदेशों को पुनः प्राप्त कर सकता है？**

नहीं। यह वही रखता है जो आपके खाते ने चलते समय देखा। बाद का स्नैपशॉट छूटे संपादन या हटाए गए संदेश दोबारा नहीं बना सकता।

**क्या मेरा पूरा जर्नल एन्क्रिप्टेड है？**

सेशन और कुंजियाँ हाँ। संदेश और फ़ाइलें नहीं， डिस्क एन्क्रिप्शन इस्तेमाल करें। एक्सपोर्ट पर AES－256 पासवर्ड लग सकता है।

**क्या यह टेलीग्राम से संबद्ध है？**

नहीं। यह Telethon पर बना MIT－लाइसेंस वाला स्वतंत्र प्रोजेक्ट है। आप अपने खातों से लॉगिन करते हैं।
