## S3 نقول۔ بیرونی تصدیقات۔

انکرپٹ شدہ نقول محفوظ رکھیں اور آزادانہ جانچ شامل کریں۔

ڈیفالٹ طور پر بند

### سب کچھ S3 کے مطابقت پذیر اسٹوریج میں کاپی کریں

جرنل، فائلیں، ٹائم اسٹیمپ شدہ چیک پوائنٹس اور چیٹ ایکسپورٹس — AWS S3 یا مطابقت رکھنے والی اسٹوریج میں اپ لوڈ سے پہلے انکرپٹ کیے جاتے ہیں۔

**اسٹوریج کی ترتیبات اور بازیابی**

کلائنٹ سائیڈ انکرپشن

`AES-256-GCM` اس مشین پر اشیاء کو انکرپٹ کرتا ہے۔ فراہم کنندہ انکرپٹ شدہ اشیاء وصول کرتا ہے۔

شیڈول شدہ یا دستی کاپیاں

ابھی کاپی کریں، یا 1 سے 1,440 منٹ کے وقفے کا انتخاب کریں۔ پینل میں پیش رفت دیکھیں۔

آبجیکٹ لاک

رکھنے کے دن اور جب بکنک اس کی حمایت کرے تو ایک موڈ منتخب کریں۔ پینل رپورٹ کرتا ہے کہ آیا اپلوڈ کی گئی شے پر برقرار رکھنے کی تصدیق ہوئی یا نہیں۔

تصدیق شدہ بازیابی

انکرپشن کلید ڈاؤن لوڈ کریں اور اسے الگ رکھیں۔ دوسری مشین پر بحال کریں؛ فائلیں صرف تصدیق کے بعد شائع کی جاتی ہیں۔

![مکمل آف سائٹ کاپی پینل: اینڈ پوائنٹ، خطہ، بکیٹ، رسائی کیز، شیڈول، آبجیکٹ لاک اور ریکوری کی کنٹرولز](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

مکمل پینل جدید اختیارات کے ساتھ کھولا گیا ہے۔ کوئی اسٹوریج کی تفصیلات دکھائی نہیں گئی ہیں۔

جرنل اور میڈیا`AES-256-GCM`S3 کے مطابق اسٹوریج

[S3 کو کنفیگر کریں اور ایک کاپی بحال کریں](https://phishdestroy.github.io/TgWitness/ur/docs/exports/#s3)[تصدیقی تفصیلات پڑھیں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/evidence/#off-site-copy-and-restore-s3)

### ماخذ حاصل کریں۔

[ماخذ ZIP فائل ڈاؤن لوڈ کریں](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) اور اسے نکالیں، یا ریپوزیٹری کلون کریں:

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

ماخذ لانچ کے لیے Python 3.11+ درکار ہے۔ اگر Python موجود نہ ہو تو Windows لانچر انسٹالیشن کی پیشکش کرتا ہے۔

[پر ریلیزز براؤز کریں](https://github.com/phishdestroy/TgWitness/releases)

ونڈوز پر پائتھن نہیں ہے؟ [پورٹیبل پیکیج ڈاؤن لوڈ کریں](https://github.com/phishdestroy/TgWitness/releases/download/v0.7.1/TgWitness-0.7.1-windows-amd64-portable.zip)، اسے نکالیں اور `TgWitness.cmd` پر ڈبل کلک کریں۔

مرحلہ 02

### چلانے کا طریقہ منتخب کریں۔

`Start.cmd` پر ڈبل کلک کریں، یا پاور شیل میں چلائیں:

```
.\Start.cmd
```

صرف دریافت کر رہے ہیں؟ ایک الگ تھلگ ڈیمو کے لیے `scripts\Demo.cmd` پر ڈبل کلک کریں۔ ٹیلیگرام لاگ ان کی ضرورت نہیں۔

Python 3.11+ اور `venv` دستیاب ہیں:

```
sh start.sh
```

اس کے بجائے فرضی جریدہ کھولنے کے لیے `sh start.sh --demo` چلائیں۔

جب Docker چل رہا ہو اور Compose 2.20+ انسٹال ہو:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

دوسری کمانڈ آپ کا نجی پینل ٹوکن دکھاتی ہے۔ اسے اپنی مشین پر محفوظ رکھیں۔

لانچ کے بعد [127.0.0.1:8787 پر](http://127.0.0.1:8787) کھولیں۔

ماخذ انسٹالیشن کے لیے ٹوکن `data/live/panel-token.txt` میں موجود ہے۔ ٹیلیگرام سائن ان بلٹ ان API سیٹنگز یا [my.telegram.org](https://my.telegram.org) سے آپ کے اپنے جوڑے کا استعمال کر سکتا ہے۔ [مکمل سیٹ اپ گائیڈ ↗](https://phishdestroy.github.io/TgWitness/ur/docs/reference/quickstart/)

**کیا یہ صفحہ ٹیلیگرام سے منسلک ہے؟**

نہیں۔ یہ ایک جامد پروجیکٹ صفحہ ہے جس میں خیالی مثالیں اور اسکرین شاٹس ہیں۔ اصل ایپلیکیشن آپ کے کمپیوٹر یا سرور پر چلتی ہے؛ سائن ان وہاں ہوتا ہے۔

**کیا یہ کیپچر سے پہلے حذف شدہ پیغامات کو بازیافت کر سکتا ہے؟**

نہیں۔ TgWitness آپ کے اکاؤنٹ نے جب کلیکشن چل رہی تھی تو دیکھی گئی مواد کو محفوظ رکھتا ہے۔ بعد میں لیا گیا ہسٹری سنپ شاٹ چھوٹی ہوئی ترامیم یا حذف شدہ پیغامات کو دوبارہ بحال نہیں کر سکتا۔

**کیا میرا پورا جرنل انکرپٹڈ ہے؟**

اکاؤنٹ کی اسناد اور دستخطی راز ایک خفیہ شدہ والٹ میں محفوظ کیے جاتے ہیں۔ مقامی پیغامات اور منسلکات کے لیے ایک خفیہ شدہ ڈسک یا والیوم درکار ہے۔ برآمدات اختیاری طور پر پاس ورڈ سے محفوظ شدہ AES-256 ZIP استعمال کر سکتی ہیں۔

**کیا یہ ٹیلیگرام سے منسلک ہے؟**

نہیں۔ TgWitness ایک آزاد منصوبہ ہے جو Telethon استعمال کرتا ہے اور MIT لائسنس کے تحت تقسیم کیا گیا ہے۔ آپ اپنے اکاؤنٹس کو بلٹ ان API ترتیبات یا اپنی API جوڑی کے ذریعے خود مجاز کرتے ہیں۔
