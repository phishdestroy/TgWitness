# 准备一份共享副本

Canonical page: https://phishdestroy.github.io/TgWitness/zh/docs/handover/

只分享需要的内容，原件保持不变。

移交是一份独立的签名摘要：选择聊天和人员，隐藏身份或文本，选择文件和团队笔记。清单记录了保留、裁剪和排除的内容。

## 准备收件人的数据提取文件

1. **导出 → 移交提取**：写明用途，选择聊天和时间段，如需具名人员则**加载所选聊天记录中的人员**。
2. 其他所有人：使用化名、排除，或按记录原样。文本和文件是分开的开关；电话和电子邮件可以遮蔽。
3. Case Board：不包含、书签和切片，或带评论的卡片。团队成员姓名可替换为别名。
4. **下载移交摘要**，打开、验证，并在发送前通读一遍。

### 一份正本，一份经授权的共享副本

合成示例 · 仅用于说明身份

1. **选择。**包含案件聊天记录，并标明该摘录涉及的对象。
2. **最小化。**选择其他参与者在共享副本中的显示方式。
3. **检查。**在发送生成的存档文件之前，请先打开其报告和记录进行**检查**。
4. **分享。**提交经核对的译文，并单独提供其可信指纹。

#### 原始观察

Nora · 用户 71002

“我已收到修订后的链接。”

源日志会保留此保存的观察记录。

#### 收件人副本

按记录显示：Nora · 用户 71002 · “我已收到修订后的链接。”

化名：P01 · “我已收到修订后的链接。”

省略：此参与者的消息未包含在译文中。

#### 检查实际文件

请阅读 report.html 和 records.jsonl 文件。

请核对身份信息、文本、附件及可选的团队评论。

#### 已签名的摘录

选定内容 + 文件哈希值 + 签名清单

一个与源日志边界关联的独立包

## 综合运用各项控件

| 控制 | 对文案的影响 |
| --- | --- |
| 人员 | 选定的人员保留姓名；其他人使用化名或被排除。 |
| 文本 | 全部文本、仅选定人员和您账户的文本，或不包含。 |
| 文件 | 选定人员和您账户的文件、全部显示的文件，或不包含。 |
| 案件看板 | 不包含、书签和切片，或带讨论的卡片。 |

请也读一读文本和文件：化名不会删除写在消息或附件中的名字。如果选定的文件缺失，请恢复它或排除附件。

## 确保译文内容可独立核查

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

原始存档和检查点请自己保留。接收方无需获得整个工作区就能验证其副本。设计：[Report studio](https://phishdestroy.github.io/TgWitness/zh/docs/reports/)。可信参照：[导出验证](https://phishdestroy.github.io/TgWitness/zh/docs/exports/)。
