# הכן עותק לשיתוף

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/handover/

שתפו רק מה שצריך, המקור נשאר ללא שינוי.

מסירה היא תמצית חתומה נפרדת: בחרו צ'אטים ואנשים, הסתירו זהויות או טקסט, בחרו קבצים והערות צוות. המניפסט מתעד מה נשמר, קוצץ והושמט.

## הכן את התמצית עבור הנמען

1. **ייצואים ← תמצית מסירה**: כתבו את המטרה, בחרו צ'אטים ותקופה, **טעינת אנשים מהצ'אטים שנבחרו** אם צריך אנשים בשמם.
2. כל השאר: כינויים, מושמטים, או כפי שתועדו. טקסט וקבצים הם מתגים נפרדים; אפשר למסך טלפונים ודוא"ל.
3. Case Board: כלום, סימניות ופרוסות, או כרטיסים עם תגובות. אפשר להחליף שמות צוות בכינויים.
4. **הורדת תמצית מסירה**, פתחו אותה, אמתו אותה, עברו עליה לפני השליחה.

### עותק מקורי אחד, עותק משותף אחד

דוגמה סינתטית · להמחשה בלבד

1. **בחר.** כלול את צ'אט התיק וזיהוי האדם שעליו עוסק הקטע.
2. **צמצמו.** בחרו כיצד יופיע משתתף אחר בעותק המשותף.
3. **בדקו.** פתחו את הדוח והרשומות שבארכיון שנוצר לפני שליחתו.
4. **שתף.** העבר את העותק המאושר והעבר בנפרד את טביעת האצבע המאושרת שלו.

#### הערה מקורית

נורה · משתמש 71002

"קיבלתי את הקישור המעודכן."

יומן המקור שומר את התצפית שנשמרה זו.

#### עותק לנמען

הצג כפי שנרשם: נורה · משתמש 71002 · "קיבלתי את הקישור המעודכן."

שם בדוי: P01 · "קיבלתי את הקישור המעודכן."

יש להשמיט: הודעתו של משתתף זה לא נכללת בטקסט.

#### בדקו את הקבצים עצמם

קרא את הקובץ report.html ואת הקובץ records.jsonl.

יש לבדוק זהויות, טקסט, קבצים מצורפים והערות צוות אופציונליות.

#### קטע חתום

בחירה + חתימות קובץ + מניפסט חתום

חבילה נפרדת המקושרת לגבולות היומן המקורי שלה

## יש להשתמש בפקדים יחד

| בקרה | השפעה על הטקסט |
| --- | --- |
| אנשים | אנשים נבחרים נשארים בשמם; האחרים מקבלים כינויים או מושמטים. |
| טקסט | כל הטקסט, רק של האנשים הנבחרים ושל החשבון שלכם, או כלום. |
| קבצים | קבצים של האנשים הנבחרים ושל החשבון שלכם, כל הקבצים המוצגים, או כלום. |
| Case Board | כלום, סימניות ופרוסות, או כרטיסים עם דיון. |

קראו גם את הטקסט והקבצים: כינוי לא מסיר שמות שכתובים בתוך הודעה או קובץ מצורף. אם קובץ נבחר חסר, שחזרו אותו או השמיטו קבצים מצורפים.

## יש להקפיד על כך שניתן יהיה לאמת את הטקסט באופן עצמאי

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

שמרו בעצמכם את הארכיון המקורי ואת נקודות הביקורת. הנמען יכול לאמת את העותק שלו בלי לקבל את כל סביבת העבודה. עיצוב: [Report studio](https://phishdestroy.github.io/TgWitness/he/docs/reports/). נקודות ייחוס מהימנות: [אימות הייצוא](https://phishdestroy.github.io/TgWitness/he/docs/exports/).
