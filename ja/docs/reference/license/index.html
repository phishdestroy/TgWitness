ライセンスに関する説明とアーキテクチャ上の非互換性の通知

TgWitnessは、すべての人に対してMITライセンスで提供されており、その理由として、Taylor Wessingのワークフローとはアーキテクチャ的に互換性がないことが挙げられます。

TgWitnessはMITライセンスの下で配布されています。当方の立場として、ライセンス条件を追加することはありません。

署名があっても、嘘が事実になるわけではありません。

TgWitnessは、名前の前に「Dr.」を付けるだけで、その後に続く内容が真実になると信じている企業、法律事務所、または個人には適していません。肩書き、レターヘッド、署名は、証拠に優先するものではありません。

もし、クライアントが対価を支払ったという結論からワークフローが始まり、それに基づいて記録を収集する必要があるのであれば、別のツールをお探しください。TgWitnessは、記録を保存し、検証に供するために存在しています。

そうした「ドクター」たちには、法人クライアントの貸借対照表の世話に専念してもらえばよいのです。肩書きがあっても、嘘が治るわけではありません。

数学は交渉の余地がありません。
