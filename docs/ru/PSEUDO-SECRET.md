# «Секретные чаты»: установка и запись

Опубликованное приложение включает в себя бэкенд «Секретного чата», интеграцию с коллектором,
маршруты API и интерфейс **Псевдосекрет**. Библиотека протоколов представляет собой отдельный модуль:
откройте **Псевдосекрет** и нажмите **«Установить и включить»**. Автоматическое принятие входящих сообщений
останется отключенным, пока вы его не включите.

<a id="protocol-module"></a>
## Модуль протокола

|  |  |
| --- | --- |
| Модуль | `kiaro-telethon-secret-chat` 0.2.0 |
| Автор | Киаро-сама |
| Лицензия | GPL-3.0 или более поздней версии; элементы `LICENSE` и `NOTICE` остаются в сохраненном архиве |
| Источник | [KiaroSama/Telethon-Secret-Chat](https://github.com/KiaroSama/Telethon-Secret-Chat) в коммите `d87bf037b90060383c7b704d8a06ebb98c621c6f` |
| Проверить | SHA-256 `c80feb9b5bc28201677c140d20930fbd730d7efdebb8ca789a19040c3f00ce5c` над списком файлов пакетов и их собственными значениями SHA-256 |

Функция **«Установить и включить»** доступна главному администратору. TgWitness загружает
исходный архив данного коммита с GitHub через маршрут рабочей области для запросов
за пределами Telegram, сравнивает каждый файл пакета со значением, зафиксированным в
релизе TgWitness, сохраняет архив как `modules/telethon-secret-chat-<commit>.zip` в
каталоге данных и загружает код из памяти. Перезапуск не требуется. Проверка выполняется
заново при каждом запуске; архив, содержащий отличия, не загружается, и на странице отображается соответствующее сообщение.
Измененный, отсутствующий или добавленный файл пакета приводит к сбою проверки.

Этот модуль представляет собой отдельное произведение, распространяемое по собственной лицензии. TgWitness не включает его в состав дистрибутива: при каждой
установке он загружается из репозитория автора. **Подробнее** на странице содержит данные о
загруженном модуле, его авторе, лицензии, коммите и SHA-256.

Пользователь, не имеющий доступа к GitHub, может вместо этого установить тот же коммит в среду Python;
в этом случае панель будет использовать именно эту копию:

```sh
python -m pip install ".[secret-chats]"
```

TgWitness становится конечной точкой для чатов, которые он создает или принимает. Он записывает
сообщения, имеющиеся вложения, изменения таймера и уведомления об удалении в подписанный
журнал. Ранее сохраненное содержимое остается доступным даже после поступления уведомления об удалении.

<a id="use-the-interface"></a>
## Использование интерфейса

Откройте **Псевдосекрет**, установите модуль, если он предлагается на странице, включите его для учетной записи и подключите.
Входящие запросы ожидают подтверждения, если не включена функция автоматического подтверждения.
Запуск, подтверждение, отправка и закрытие осуществляются с учетом прав взаимодействия учетной записи
и защиты от чтения.

| Действие | Сохраненный результат |
| --- | --- |
| Начать чат по имени пользователя или идентификатору пользователя | Исходящий запрос; абонент принимает его на своём устройстве. |
| Принять запрос | TgWitness становится конечной точкой приема. |
| Отправить или получить сообщение | `secret_chat.message` с указанием направления, содержания и встроенного таймера. |
| Получить файл | Расшифрованные байты, сохраненные с помощью алгоритма SHA-256, и квитанция `secret_chat.file`; включены в экспорт доказательств. |
| Получить уведомление о таймере или удалении | Отдельный журнал действий наряду с сохраненными сообщениями и файлами. |
| Просмотреть чат | Переписка, квитанции об отправке файлов, уведомления и визуализация ключей. |

Существующие секретные чаты на другом устройстве сохраняют свои ключи, привязанные к данному устройству. При
импорте сеанса из облака эти ключи не передаются. Ключевые материалы и
счетчики секретных чатов хранятся в хранилище рабочей области; сохраненные сообщения и расшифрованные файлы защищены
стандартными средствами защиты хранилища рабочей области.

<a id="find-saved-messages"></a>
## Найти сохраненные сообщения

Используйте функцию **Поиск сообщений** в открытом чате, чтобы найти точную фразу с игнорированием
регистра. Кнопки **Назад** и **Далее**, а также клавиши Enter и Shift+Enter в поле поиска
позволяют перемещаться между сообщениями, содержащими искомую фразу. Счетчик показывает количество сообщений; первая совпадающая
фраза в каждом сообщении выделяется. Клавиша Escape очищает поле поиска.

Функция поиска позволяет видеть окружающий диалог, сохраненные файлы и уведомления об удалении.
Она осуществляет поиск по записям, уже загруженным в панель. Если имеются более ранние
записи, панель отображает соответствующее сообщение; кнопка **Загрузить более старые записи** расширяет историю и
обновляет результаты поиска, при этом текущее сообщение остается на месте.

При переключении между чатами в пределах одного рабочего пространства поисковые запросы сохраняются. Блокировка
панели или смена рабочего пространства приводит к очистке этих запросов. Поисковые запросы остаются в
памяти страницы и не сохраняются в хранилище браузера, а также не отправляются в виде запросов к API.
Поиск не отправляет сообщения в Telegram и не генерирует уведомления о вводе текста или прочтении. Существующие
настройки видимости по-прежнему регулируют открытие чата и другие действия.

**Создать отчёт** сохраняет область охвата отчета для выбранного чата; поиск в окне просмотра
не ограничивает экспортируемые записи без уведомления. Просмотрите выбор данных для отчета
перед его загрузкой.

<a id="persistence-and-interaction-controls"></a>
## Параметры сохранения и взаимодействия

В интегрированной реализации для обнаружения дубликатов используется механизм проверки журнала на наличие дубликатов,
задания на загрузку вложений остаются в состоянии ожидания после сбоя загрузки, а завершение операции проходит через
тот же механизм контроля взаимодействия, что и другие удаленные действия. Эти изменения заменяют три пути,
указанные в предыдущем отчете по результатам аудита версии development-snapshot от 6 ноября.

Расшифрованные сообщения, запись которых в журнал завершилась неудачей, хранятся в хранилище для повторной попытки.
Проверка размера вложений и свободного места на диске приводит к отсрочке загрузки, при этом задания сохраняются.
Модуль повторно использует существующее соединение учетной записи. Уведомления о прочтении и наборе текста отправляются
только в соответствии с настройками в разделе
[Что видит собеседник](../INVESTIGATION-MODE.md#what-the-other-side-sees); уведомления
о скриншотах никогда не отправляются. См. [secret_chats.py](../../tgwitness/secret_chats.py),
[маршруты API](../../tgwitness/api/secret_chats.py) и
[политика доступа](../../tgwitness/access.py).

В [историческом отчете](../../website/validation/audit/REPORT.md) сохранены исходные
результаты проверки. Информацию о текущей доступности и внедрении следует извлекать из
данных о версии пакета, приведенных выше, и из раздела [текущие возможности](../STATUS.md).
