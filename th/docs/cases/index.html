สืบสวนในทุกการสนทนา

คดีหนึ่งทั้งคดีครอบคลุมช่อง กลุ่ม แชทส่วนตัว และบอท: เก็บข้อมูล เชื่อมโยงจุดต่างๆ สร้างไทม์ไลน์ใหม่ แล้วส่งมอบ

เหตุการณ์สมมติหนึ่งเรื่อง ตั้งแต่ต้นจนจบ การเก็บข้อมูล การค้นหา และโปรไฟล์บุคคลค้นพบรายการ Case Board จัดระเบียบ Report studio นำเสนอ

กรณีที่ได้รับการตรวจสอบ / จุดหมายปลายทางการชำระเงินที่เปลี่ยนแปลง

เหตุการณ์หนึ่ง สี่บทสนทนา ร่องรอยที่ต้องสร้างขึ้นใหม่

โพสต์ในช่องชี้ไปยังบอท กลุ่มหนึ่งพูดถึงลิงก์ชำระเงินใหม่และบอทแสดงลิงก์นั้น โพสต์ถูกแก้ไข แชทส่วนตัวพูดซ้ำลิงก์ ข้อความในกลุ่มหายไป

การโหลดประวัติ AI, MCP, OCR และ webhook: ทำงานกับคลังข้อมูล

1. กำหนดขอบเขตการบันทึกให้ครอบคลุมทั้งบัญชี

ขอบเขตทั้งบัญชีใช้กับบัญชีเฉพาะเท่านั้น บัญชีหลักใช้แชทที่เลือกหรือหนึ่งโฟลเดอร์

  1. เชื่อมต่อบัญชี ในพื้นที่ทำงานของตัวเอง จดเลขอ้างอิงคดี ID บัญชี พื้นที่ทำงาน และลายนิ้วมือคีย์
  2. แหล่งข้อมูล → ขอบเขตการสังเกต → โหมดสืบสวน: ทั้งบัญชี แหล่งข้อมูลทั้งสี่ประเภท การกระทำของตนเอง แชทใหม่ทุกแชทจะถูกบันทึกโปรไฟล์และ ข้อความที่มองเห็น 200 ข้อความ ล่าสุด บันทึกขอบเขต แล้วยืนยัน
  3. โหลดแชท แล้วเทียบกับรายการแชทของบัญชี ขีดจำกัดคือ 1,000 บทสนทนา (สูงสุด 20,000 ใน พารามิเตอร์ → แชทที่อ่านจากรายการของบัญชี) แชทที่เกินจะปรากฏเมื่อมีความเคลื่อนไหว
  4. การตั้งค่าการบันทึก → กิจกรรมที่มองเห็นทั้งหมด ตรวจขีดจำกัดไฟล์แนบและพื้นที่ดิสก์ เริ่ม แล้วทดสอบด้วยข้อความ การแก้ไข และการลบอย่างละหนึ่ง
ช่องกลุ่มการสนทนาส่วนตัวบอท
หนึ่งบัญชี / หนึ่งกุญแจลงนามทุกกิจกรรมที่บัญชีสามารถมองเห็นได้ → รวมเป็นบันทึกเดียว

ข้อความ · การแก้ไข · แจ้งการลบ · ปฏิกิริยาที่มองเห็นได้ · เหตุการณ์สมาชิก · การกระทำของตนเอง

"ทั้งบัญชี" หมายถึงทุกแชทที่บัญชีนี้เปิดได้ ลบด้วยรายการที่ยกเว้น ไม่รวมแชทลับ แชทใหม่เข้ามาเมื่อปรากฏ ประวัติเก่าไม่ถูกดาวน์โหลดอัตโนมัติ

2. รวบรวมประวัติและเก็บรักษาไฟล์

สร้างคอลเลกชัน Case Board และบุ๊กมาร์กสิ่งที่สำคัญ เก็บทะเบียนแหล่งข้อมูล: ID แชท ชื่อ บัญชี บทบาท เวลาเริ่มบันทึกสด ผลประวัติ ผลสื่อ ช่องว่าง

เลือกข้อมูลที่ตอบคำถาม
ต้องการการดำเนินการในแผงควบคุมสิ่งที่ให้บริการ
ประวัติการสนทนาในทุกห้องสนทนาที่เปิดใช้งานแหล่งข้อมูล → โหลดประวัติทั้งหมดข้อความเก่าที่มีอยู่จะถูกบันทึกไว้ในบันทึกพื้นที่ทำงาน พร้อมด้วยฟังก์ชันหยุด/ต่อ และรายงานความคืบหน้าที่ลงนามแล้ว คู่มือประวัติ
บริบทการสนทนาที่มีอยู่ภายในบันทึกแหล่งข้อมูล → การตั้งค่าการบันทึก → ภาพถ่ายประวัติข้อความล่าสุดเป็นรายการที่ลงนาม ค่าเริ่มต้น 500 สูงสุด 10,000 ใน พารามิเตอร์ → สแนปช็อตประวัติที่ใหญ่ที่สุด
ประวัติการสนทนาทั้งหมดที่มองเห็นได้ในขณะนี้ของแชทหนึ่งส่งออกบทสนทนาทั้งหมด → ส่งออกบทสนทนาทั้งหมด หรือ บทสนทนา → ส่งออกบทสนทนาชุดที่ลงนามแยกต่างหากซึ่งมี chat.json และ chat.html หนึ่งชุดต่อแชท
บริบทเมื่อมีบทสนทนาใหม่ปรากฏขึ้นขอบเขตการสังเกต → เมื่อมีการสนทนาหรือบอทใหม่ปรากฏขึ้นโปรไฟล์และข้อความล่าสุดสูงสุด 1,000 ข้อความ (200 ในโหมดสืบสวน) ไม่ใช้กับแชทที่มีอยู่แล้ว
ขนาดไฟล์แนบดาวน์โหลดไฟล์แนบที่แสดงได้ + ข้อจำกัดตามประเภทไฟล์มองหา media.saved พร้อม SHA-256 และขนาด อยู่ในคิว ข้าม หรือล้มเหลว หมายถึงยังไม่ได้บันทึก

การส่งออกแชทไม่เข้าไปในบันทึกหรือโปรไฟล์บุคคล หากต้องการค้นหาประวัติเก่าภายใน TgWitness ให้ใช้ โหลดประวัติเต็ม หรือสแนปช็อต

ในที่นี้: ช่อง กลุ่ม แชทบอท และแชทส่วนตัว รวมถึงไฟล์ใบแจ้งหนี้และค่าแฮชของมัน สิ่งที่ถูกลบก่อนเริ่มบันทึกหายไปแล้ว

3. ติดตามการสนทนาที่พัฒนาไปอย่างต่อเนื่องและพฤติกรรมของคุณเอง

ปล่อยให้ทำงานต่อไป ติดดาวแชทที่ร้อนแรงเป็นลำดับความสำคัญ ปรับการตรวจซ้ำใน การตั้งค่าการบันทึก → ตรวจสอบซ้ำ และคอยดู recheck.completed, FloodWait และผลสื่อ

แชท → โปรไฟล์ → บันทึกโปรไฟล์ตอนนี้ บันทึกคำอธิบายแชท คำสั่งบอท และเมทาดาทาอื่นๆ

การติดตามบอทหรือคำเชิญเป็นส่วนหนึ่งของคดี
  1. แชท → เปิดลิงก์ Telegram บันทึกตัวอย่างก่อน ลิงก์และตัวอย่างจะกลายเป็นรายการที่ลงนาม
  2. หากจำเป็น เข้าร่วม / เปิดและสังเกต จะเข้าร่วมแชทหรือเริ่มบอทด้วยพารามิเตอร์เริ่มต้นของมัน
  3. หากต้องการบันทึกการกระทำ ให้ตอบกลับหรือใช้ กดปุ่ม จากแผงควบคุม คุณจะได้ interaction.requested และ interaction.result พร้อมคำตอบของบอท

นี่คือการกระทำจริง ปุ่มที่กดในแอปอื่นมองไม่เห็น เห็นเพียงคำตอบของบอท ไม่รองรับเว็บแอป การชำระเงิน หรือโทรศัพท์/ตำแหน่ง

4. ติดตามบุคคล ลิงก์ และไฟล์ในทุกการสนทนา

  1. บันทึก, แหล่งข้อมูลทั้งหมด ค้นหาวลี โดเมน หรือชื่อผู้ใช้ เปิดผลลัพธ์แล้วส่ง ไปยังบอร์ด
  2. แชท → บุคคล → เปิดโปรไฟล์ เลือกบุคคล: ประวัติชื่อ การตอบกลับ กิจกรรม พบใน… ลิงก์ กระเป๋าเงิน โทรศัพท์ เปิดรายการที่อ้างอิง
  3. ติดตาม ID ผู้ใช้แบบตัวเลขเดียวกันไปยังแชทอื่น ชื่อ กระเป๋าเงิน หรืออวาตาร์ที่ตรงกันเป็นเบาะแส ไม่ใช่หลักฐาน
  4. เทียบค่าแฮชของไฟล์ SHA-256 เดียวกัน = ไบต์เดียวกัน ใครเป็นคนแชร์เป็นอีกคำถามหนึ่ง
สิ่งที่เชื่อมโยงบันทึกตัวอย่างเหล่านี้
การเชื่อมต่อการสังเกตสนับสนุนสรุปว่าควรเก็บไว้
บัญชี Telegram เดียวกันID ผู้ใช้ 71001 ในกลุ่ม #146 และแชทส่วนตัว #205ID ผู้ส่งเดียวกันในทั้งสองแชท ตัวจริงคือใครเป็นอีกคำถามหนึ่ง
ปลายทางที่ซ้ำกันpay.example.invalid/new ใน #146, ข้อมูลเมตาของปุ่ม #173, โพสต์ที่แก้ไข #188 และ #205ลิงก์เดียวกันในสี่ที่ ใครควบคุมมันต้องใช้แหล่งข้อมูลอื่น
ขนาดไฟล์เท่าเดิมค่า SHA-256 ที่เท่ากันในใบเสร็จสื่อที่เสร็จสมบูรณ์ #151 และ #209ไฟล์ทั้งสองเหมือนกันทุกไบต์

โปรไฟล์ครอบคลุมเฉพาะคนที่เขียนอะไรบางอย่างใน พื้นที่ทำงานนี้ ไม่ใช่รายชื่อสมาชิก จำนวนการอ้างอิงต่อข้อเท็จจริง: พารามิเตอร์ → รายการที่อ้างอิงต่อข้อเท็จจริง

    ข้อสังเกตก่อนหน้านี้ยังคงมีอยู่; ไม่มีการระบุทั้งผู้ลบข้อความหรือเวลาการลบที่แม่นยำ

เวลาการสังเกตและข้อมูลอ้างอิงที่แสดงเป็นตัวอย่าง มีบันทึกอื่น ๆ ในสมุดบันทึกนี้ระหว่างรายการดังกล่าว

ลำดับในบันทึกคือลำดับที่มาถึง ไม่จำเป็นต้องเป็นลำดับที่เกิดขึ้น แยกรายการสด สแนปช็อต ข้อความที่กู้คืน การลบ และ "หายไปเมื่อตรวจซ้ำ" ออกจากกัน และทำเครื่องหมายทุกช่องว่างว่าไม่ทราบ

6. ขยายกรณีนี้ไปยังบัญชีอื่น ๆ ที่ใช้เก็บรวบรวมข้อมูล

หนึ่งพื้นที่ทำงานต่อหนึ่งบัญชี ขั้นตอนเดิม จดบทบาทและลายนิ้วมือของแต่ละบัญชี หมายเลขข้อความนับแยกตามบัญชี จึงต้องระบุพื้นที่ทำงานและแชทเสมอ

กลุ่มบัญชี แสดงสถานะ แชร์การตั้งค่า และส่งออกทุกบัญชีพร้อมกัน แต่ละบัญชียังมีบันทึกและคีย์ของตัวเอง ไทม์ไลน์ข้ามบัญชีคุณสร้างเองในบันทึกย่อ

คดียาว? เพิ่ม พยานอิสระ และทดสอบว่าแต่ละบัญชีจับอะไรได้จริง

7. ส่งมอบชุดข้อมูลคดีที่สามารถตรวจสอบได้

ZIP ที่ลงนามจากทุกพื้นที่ทำงาน (บันทึกเต็มเสมอ ตัวกรองไม่มีผล) พร้อมโปรไฟล์บุคคล การส่งออกแชท และไฟล์

CASE-001/                         # assembled by the analyst
  case-notes.md                   # question, findings, alternative explanations
  sources.csv                     # every chat, role, acquisition result and gap
  timeline.csv                    # account + chat + message + seq + both times
  workspace-A/
    evidence.zip                  # complete signed observation journal
    retained-checkpoint.json
    profiles-operations.json      # separately signed people profiles
    history-channel.zip           # signed current-history export
    history-group.zip
    verification.txt
  workspace-B/                    # separate journal and trusted fingerprint
  witness/                        # retained checks, journal and signed posts
  SHA256SUMS                      # hashes of the delivered files

ส่งลายนิ้วมือแยกต่างหาก ตรวจสอบทุกอย่างกับพื้นที่ทำงานของมันเอง:

python -m tgwitness.verify evidence.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --checkpoint retained-checkpoint.json
python -m tgwitness.verify profiles-operations.json --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --evidence evidence.zip
python -m tgwitness.verify history-channel.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
