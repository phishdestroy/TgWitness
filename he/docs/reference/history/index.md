# טען היסטוריית המקור

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/reference/history/

טען הודעות קודמות ממקורות מופעלים, עצור והמשך, ואמת דוח התקדמות חתום.

ב"**מקורות**", עברו על הצ'אטים המופעלים, התחילו את המעקב, ואז בחרו **"טען היסטוריה מלאה**". הפעולה קובעת את רשימת המקורות וקוראת את ההודעות העבר הזמינות שלהם אל תוך "צ'אטים" ואל יומן המעקב החתום. קבצי מדיה משתמשים בהגדרות הקיימות לנספחים ובתור ההורדות הקבוע. זה נפרד מהייצוא החתום בפורמט JSON/HTML לכל צ'אט בנפרד.

לאיסוף נתונים מכל החשבון, בחר "**חשבון שלם**", התחל מעקב כדי לטעון את רשימת המקורות, ובדוק את הרשימה לפני שתתחיל את ההיסטוריה. מגבלת רשימת הדיאלוגים עדיין חלה (1,000 כברירת מחדל, ניתן להתאמה בפרמטרים). הפעלה מוצלחת אינה מוכיחה שכל שיחות החשבון נכללו ברשימה. צ'אטים שהתגלו או הופעלו מאוחר יותר מצריכים הפעלה נוספת.

## השהיה, התחלה מחדש ותוצאות חלקיות

- **השהיית ההיסטוריה** מפסיקה את הקריאה. **המשך ההיסטוריה** מתחדש מההודעה האחרונה שנשמרה בכל מקור; גם הפעלה מחדש של האפליקציה משאירה את הריצה בהשהיה עד לחידושה. יש להפעיל מחדש את התצפית תחילה. לחידוש נדרש אותו חשבון טלגרם.
- תצפית על הודעה, משימת צירוף קובץ ואישור באמצעות הסמן מתבצעים בעסקה אחת. הפעלה מחודשת אינה חוזרת על תצפיות שכבר אושרו. לכידה בזמן אמת או הפעלה נפרדת, שהושקה במפורש, עשויות לתעד באופן עצמאי את אותה ההודעה.
- כל מקור קובע מזהה הודעה עליון בקריאה הראשונה שלו. הודעות חדשות יותר שייכות לניטור בזמן אמת, ולא לדפים ההיסטוריים הנותרים של אותו מקור.
- מקורות שאינם נגישים ומקורות שהושבתו במהלך האיסוף נשארים גלויים כ "נכשלו" או "הוחסרו". מקורות אחרים ממשיכים לפעול; התוצאה הכוללת אינה שלמה.
- עיכובים של FloodWait מכבדים את זמן ההמתנה שנשמר עבור החשבון. פקיעת זמן העברה ומחסור בשטח דיסק מעכבים את הפעולה תוך שמירה על מיקום הסמן. יש לחדש את הפעולה לאחר פתרון הבעיה.
- **סיום ריצת ההיסטוריה הנוכחית** משמר את התצפיות שנשמרו. הוא אינו מסיר אותן או מבטל הורדות קבצים מצורפים שכבר נמצאות בתור. ריצה חדשה קוראת מחדש את המקורות המופעלים.

השלמת ההיסטוריה מתייחסת לקריאת ההיסטוריה בלבד. קבצים מצורפים עשויים להישאר במצב "ממתין", להיכשל, או להיכלל במדיניות שהוגדרה. יש לבדוק את אישורי קבלת המדיה ביומן ובתור הקבצים המצורפים; רק אישור שהושלם עם בייטים שנשמרו מהווה קובץ מצורף שנשמר. פעולת ההיסטוריה היא בקשה מפורשת לצילום מצב והיא נפרדת מהמתגים שבוחרים קטגוריות של אירועים חיים עתידיים.

## העברה ואימות

שמור את **דוח ההתקדמות החתום**, ולאחר מכן השתמש ב**"ייצא ראיות"** כדי להוריד את יומן הראיות והקובצים המצורפים שנשמרו. ייצוא ראיות מאוחר יותר עשוי לכלול רשומות נוספות; הדוח מקשר את המספרים הסידוריים שלו לקידומת היומן בזמן יצירתו. הפעל את תוכנת האימות מגרסה מהימנה של גרסה זו:

```
python tgwitness/verify.py tgwitness-history-report.json --evidence evidence.zip --fingerprint TRUSTED_FINGERPRINT
```

יש לשמור את טביעת האצבע הצפויה של מפתח החתימה באופן עצמאי. המאמת בודק את חתימת הדוח, ארכיון הראיות, נקודת הבדיקה של הדוח, תוכנית המקור, החשבון ומספר ההודעות שנשמרו או שאינן זמינות. ללא `--evidence`, הוא בודק רק את הדוח החתום ואת העקביות הפנימית שלו. שלבי ההתקדמות, הכותרות, הסמנים ו סיכומי הקבצים המצורפים הם הצהרות חתומות של האספן, ולא משוחזרים באופן עצמאי על ידי בודק הדוח הזה. בודק הראיות עדיין בודק את בתים המדיה בארכיון.

לא החתימה ולא השלמת ההיסטוריה הזמינה מוכיחות את מקורן ב-Telegram, תמונת מצב אטומית או שלמות היסטורית. הודעות עשויות להשתנות בזמן הקריאה; הודעות שנמחקו, עריכות ביניים שלא נראו וצ'אטים סודיים אינם משוחזרים. מפעיל השולט במפתח החתימה יכול לזייף יומן לפני שקיימים התחייבויות חיצוניות. יש להשתמש בנקודות ביקורת שנשמרו בנפרד או בעד עצמאי לצורך תכונות זיהוי החבלה המתועדות.

סמן הרכישה מייצג את מצב סביבת העבודה המקומית. שחזור קובץ ZIP של הראיות בלבד אינו משחזר משימת רכישה תלויה או הפעלת טלגרם. שמרו את גיבוי סביבת העבודה אם נדרשת המשך המשימה המקורית.
