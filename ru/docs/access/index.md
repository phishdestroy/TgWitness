# Поделиться делом

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/access/

Поделитесь тем материалом, который кому-то нужен. Остальное держите под контролем.

01**Выберите доказательство**

Выберите рабочие пространства всего аккаунта или отдельные записанные чаты.

02**Выберите действия**

Предоставьте пользователю права на просмотр, экспорт или конкретные операционные разрешения, необходимые ему для работы.

03**Установите ограничения**

Выдайте личный токен со сроком действия, ограничениями на количество сеансов и опциональными ограничениями по IP-адресам.

Объём сбора данных определяет, что именно фиксируется. Объём доступа определяет, что пользователь может видеть и делать.

## Предоставить кому-либо доступ

1. Войдите в систему как администратор и откройте раздел **«Доступ**».
2. Укажите имя доступа и выберите рабочие пространства и чаты.
3. Оставьте **функцию «Просмотр»** для рецензента. Добавьте **функцию «Экспорт»,** если рецензенту потребуется скачать записи.
4. Установите ограничения, затем нажмите **«Создать доступ**».
5. Один раз скопируйте отображаемый токен. Отправьте его в личных сообщениях вместе с адресом панели.
6. Перед передачей проверьте доступность страницы в отдельном окне браузера.

## Начните с описания задачи, которую им необходимо выполнить

| Лицо | Доступ | Результат |
| --- | --- | --- |
| Рецензент | Выбранные чаты; только для просмотра | Прочитайте сохраненный разговор без изменения исходного текста. |
| Аналитик | Выбранные чаты; просмотр и экспорт | Просмотрите и загрузите записи, необходимые для данного дела. |
| Оператор | Выбранные полные рабочие пространства; источники и сбор данных | Управляйте объектами наблюдения и запускайте или останавливайте сборщики данных. |

Речь идёт о настраиваемых параметрах, а не о фиксированных ролях. Настройки на уровне учётной записи и полный экспорт журнала остаются недоступными для доступа, ограниченного чатами, даже при включении других разрешений. Доступ ко всем рабочим пространствам распространяется на будущие учётные записи.

## Вы можете изменить своё решение в любой момент

Измените настройки доступа, чтобы определить, какие действия могут выполняться в последующих запросах. Завершите одну сессию или отозвите весь доступ, чтобы завершить все сессии. Уже загруженные файлы невозможно отозвать. Завершение сессии панели не останавливает сбор данных.

**Ограничения по сеансам и IP-адресам**

Ограничьте количество параллельных сеансов и успешных входов в систему, установите абсолютную дату окончания, разрешите доступ по IP-адресам или подсетям либо привяжите доступ к адресу, с которого был осуществлён первый вход. Истечение срока действия сеанса определяется отсутствием активности; опрос открытой панели считается активностью. Проверьте адрес клиента, отображаемый приложением, когда оно работает через прокси или туннель.

**Основной ключ и журнал активности**

Администратор хранит токен главной панели. Пользователи, получившие доступ, не могут управлять доступом других лиц или открывать консоль администратора. Консоль отображает активность текущих процессов во всех рабочих пространствах; подписанные записи о доступе сохраняют события предоставления прав и сеансов без использования токенов. Рабочие пространства используют общий хост-процесс и не изолируют данные от администратора сервера.

Используйте [полный справочник](https://phishdestroy.github.io/TgWitness/ru/docs/reference/access/) по всем семи разрешениям, правилам сеансов и границам прав администратора.
