# Telegram · Mulakan dalam beberapa minit

Canonical page: https://phishdestroy.github.io/TgWitness/ms/docs/start/

Terokai demo dahulu, kemudian sambungkan akaun anda sendiri.

## Lihat sekeliling tanpa akaun

Dapatkan projek, sediakan **Python 3.11 atau lebih baharu**, jalankan demo. Pelancar menyediakan yang lain.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

Ruang kerja dengan mesej rekaan dibuka dalam pelayar. Buka sembang, bandingkan suntingan, lihat eksport. Telegram tidak terlibat.

![Paparan perbualan TgWitness dengan contoh mesej](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Ruang kerja contoh. Jurnal anda sendiri bermula secara berasingan.

## Mulakan ruang kerja anda sendiri

Tutup demo, kemudian:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Buka alamat yang ditunjukkan pelancar dan tampal **token akses panel** daripada fail yang dinamakannya. Itu untuk TgWitness, bukan Telegram.

## Rekod mesej pertama anda

1. [Sambungkan akaun Telegram khusus.](https://phishdestroy.github.io/TgWitness/ms/docs/accounts/)
2. Pilih kumpulan atau saluran dan mulakan pemerhatian.
3. Hantar mesej dalam kumpulan ujian anda dan lihat ia muncul dalam jurnal.

Untuk pemasangan pelayan, ikuti [Keep it running](https://phishdestroy.github.io/TgWitness/ms/docs/server/).
