ホーム / ドキュメント

TGWITNESS / ドキュメント

Telegramの記録から、明確な事件へ。

保存されたメッセージや変更内容を処理し、調査結果をそのソースに関連付け、レビュー用の署名済みファイルを準備します。

04 ↗

数分で始められます

サンプルデータを使ってTgWitnessをお試しいただき、その後、Windows、Linux、またはmacOS上で独自のTelegram監視ワークスペースを立ち上げてみてください。

03 ↗

専用アカウント

収集用に別のTelegramアカウントを用意してください。

05 ↗

アカウントを連携する

QRコード、電話番号、またはセッションのインポートにより、Telegramを接続してください。ソースを選択し、新しいメッセージがジャーナルに正常に反映されることを確認してください。

06 ↗

プロキシを選択してください

MTProxyの自動ルーティングを維持するか、独自のプロキシをご利用ください。IPモード、フォールバックルール、および外部リクエストのルーティングを選択してください。

07 ↗

エクスポートと検証

キャプチャしたTelegramの履歴をエクスポートし、署名を検証し、ジャーナルを独立した証人が保持しているチェックポイントと比較することができます。

02 ↗

GitHub Actionsのキャプチャ

一時的な GitHub ランナーで Takeout，通常 API によるエクスポート，またはチャットログを選択します．

保存された記録から共有レポートへ

09 ↗

すべてのチャットを横断的に調査する

チャンネル、グループ、プライベートチャット、ボットを横断して、Telegramの調査をエンドツーエンドで実施します。アカウント全体のキャプチャ、履歴、参加者、リンク、ファイル、タイムライン、および検証済みの証拠を網羅します。

10 ↗

Case Boardの作成

保存された観察結果、正確なハイライト、アクションスライスをプライベートボードに収集し、チームと議論して、収集結果を提示してください。

11 ↗

レポートの作成

レポートデータ、8種類のデザインから1つ、および内容を選択し、プレビューを行った後、HTML、署名付きPDF、または完全な証拠パッケージとしてエクスポートします。

12 ↗

共有用コピーを作成してください

受信者が受け取ることができる記録とフィールドを選択し、完成したコピーを確認して、署名済みのマニフェストおよびソースジャーナルの境界を検証してください。

13 ↗

アカウントグループの管理

グループワークスペースを比較し、ソースを検索し、監視期間を確認し、アカウントごとの例外設定を適用して共有設定を適用します。

実際に試して学んでみましょう

08 ↗

証拠の仕組みをご覧ください

メッセージの取得からチェックポイントまでの流れを追跡します。サンプルレコードを変更し、そのSHA-256チェーンを再計算して、保持されているチェックポイントが何を検出するかを確認してください。

14 ↗

セキュリティを確保してください

セッション、鍵、証拠データの保存場所、端末から送信される情報、保護対象の範囲、およびインストールのセキュリティ強化方法についてご確認ください。

16 ↗

Witnessボットの設定

署名済みのジャーナルのチェックポイントを、個別のウィットネス、独自の鍵、および読み取り専用コレクターアクセス権を設定して、Telegramチャンネルに公開できます。

EXPERIMENT / EN ↗

Export Clinic

Watch a controlled Telegram Desktop export experiment, compare seven test conversations, and inspect the original recording and paired files.

必要な情報のみを追加してください

01 ↗

アーカイブの操作

履歴の読み込み、保存された記録の検索、AIソースの確認、およびツールの連携が可能です。

15 ↗

事例を共有する

レビュー担当者やアナリストに対し、個別の権限、セッション制限、および取り消し可能なトークンを設定して、選択されたアカウントやチャットへのアクセス権を付与します。

17 ↗

稼働を継続してください

TgWitnessは、永続的なストレージ、プライベートパネルへのアクセス、バックアップ機能、および再起動後のチェック機能を備えたサーバー上で実行してください。

18 ↗

何が問題だったのかを確認する

各問題に応じた適切なシグナルを使用して、パネルへのアクセス状況、Telegramとの接続状況、メッセージの欠落、FloodWait、およびWitnessのステータスを確認してください。
