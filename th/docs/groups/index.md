# จัดการกลุ่มบัญชี

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/groups/

รันหลายบัญชีพร้อมกัน แต่ละบัญชียังมีรายการและคีย์ของตัวเอง

กลุ่มรวมสถานะการเชื่อมต่อ เริ่ม/หยุดชั่วคราว การตั้งค่าร่วม และการส่งออกไว้ในหน้าจอเดียว สะดวกเมื่อหลายบัญชีทำคดีเดียวกัน

## เปิดหน้าสรุปกลุ่ม

เปิดกลุ่มใน **บัญชี** แต่ละบัญชีแสดงสถานะ เส้นทาง ความหน่วง และข้อความที่บันทึกล่าสุด **ต้องการความสนใจ** แสดงรายการที่มีปัญหา **แก้ไข** พาคุณไปที่นั่นโดยตรง

**เริ่มทั้งหมด** / **หยุดทั้งหมดชั่วคราว** จะถามก่อนดำเนินการ **การตั้งค่ากลุ่ม** ใช้ร่วมกัน แต่ค่าของบัญชีเองยังคงอยู่จนกว่าคุณจะแทนที่

### ตรวจสอบการเปลี่ยนแปลงเส้นทางในกลุ่ม

ตัวอย่างสังเคราะห์ · การตรวจสอบและผลลัพธ์เพื่อแสดงตัวอย่าง

1. **เลือก.** เลือกกลุ่มและตรวจสอบบัญชีใดที่จะมีการเปลี่ยนแปลง
2. **เตรียมตัวไว้.** รักษาเส้นทางเฉพาะของบัญชีเมื่อจำเป็นต้องแยกไว้ต่างหาก
3. **ตรวจสอบ.** ทดสอบการเชื่อมต่อที่เสนอและตรวจสอบผลการวัด
4. **ดำเนินการแปล** ตรวจสอบอีกครั้งก่อนบันทึก และตรวจสอบผลลัพธ์สำหรับแต่ละบัญชี

#### ทีม Case

Channel collector · Group collector · Reference account

3 พื้นที่ทำงานแยกกัน

#### ส่วนที่ได้รับการตรวจสอบ

2 บัญชีใช้เส้นทางที่เสนอ

บัญชีอ้างอิงมีเส้นทางของตัวเอง

#### การตรวจสอบก่อนดำเนินการ

Channel collector: เวลาส่งข้อมูล Telegram 84 ms

Group collector: Telegram transport 91 ms

ตัวเลขเหล่านี้เป็นตัวเลขสมมติที่ใช้ในตัวอย่าง

#### ผลลัพธ์ของแอปพลิเคชัน

Channel collector: การบันทึกได้ดำเนินการเรียบร้อยแล้ว การสังเกตการณ์ได้กลับมาดำเนินการต่อ

Group collector: การตรวจสอบซ้ำล้มเหลว, การตั้งค่าเดิมถูกคืนค่า

บัญชีอ้างอิง: เก็บเส้นทางเดิมไว้

## เปลี่ยนขั้นตอนโดยเพิ่มขั้นตอนการตรวจสอบ

1. **เปลี่ยนเส้นทางของกลุ่ม** เลือกประเภทและการตั้งค่า
2. **ตรวจทานการเลือก**: ดูว่าบัญชีใดเปลี่ยนและบัญชีใดมีเส้นทางของตัวเอง
3. **เตรียมและตรวจ** ทดสอบการเชื่อมต่อ Telegram ใหม่ พร้อม IP ขาออกหากทำได้
4. **ใช้การเชื่อมต่อที่ตรวจแล้ว** แล้วดูผลแต่ละรายการ บัญชีที่ทำงานอยู่จะทำงานต่อ บัญชีที่หยุดอยู่ยังคงหยุด

ความหน่วงคือเวลาตั้งค่าการเชื่อมต่อ Telegram IP ขาออกคือสิ่งที่เส้นทางแสดง ณ เวลาที่ตรวจ ผลอาจต่างกันในแต่ละบัญชี

## ใช้สิทธิ์การเข้าถึงที่ทับซ้อน

**แชทที่หลายบัญชีเห็น** แสดงแหล่งข้อมูลร่วมและความครอบคลุม ช่องและซูเปอร์กรุ๊ปส่งออกโดยหลายบัญชีพร้อมกันได้ด้วย **ส่งออกด้วย … บัญชี** แชทส่วนตัวและกลุ่มพื้นฐานทำไม่ได้ เพราะหมายเลขข้อความนับแยกตามบัญชี

## ส่งออกกลุ่มเป็นแพ็กเกจ

**ส่งออกกลุ่ม** ให้ ZIP เดียวที่มีการส่งออกที่ลงนามของทุกบัญชีและรายการที่ลงนาม แต่ละรายการคงลายนิ้วมือของตัวเองไว้สำหรับการตรวจสอบ ไทม์ไลน์รวมคุณยังต้องสร้างเอง
