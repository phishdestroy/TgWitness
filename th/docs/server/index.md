# ให้ระบบทำงานต่อไป

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/server/

ให้เครื่องมือเก็บข้อมูลยังคงใช้งานได้และข้อมูลยังคงสมบูรณ์แม้หลังการรีสตาร์ท

## เลือกวิธีการเปิดตัว

สำหรับการติดตั้งแบบเนทีฟ ให้ใช้ตัวเปิดใช้งาน ([launcher](https://phishdestroy.github.io/TgWitness/th/docs/start/)) และตัวอย่างบริการใน[โฟลเดอร์ deploy/](https://github.com/phishdestroy/TgWitness/blob/main/deploy/README.md) สำหรับ Docker ให้ติดตั้ง Docker พร้อม Compose และรันจากไดเรกทอรีของโครงการ:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

แผงควบคุมแบบค่าเริ่มต้นจะรับฟังที่ที่อยู่ loopback ของโฮสต์ พอร์ต 8787 เปิดใช้งานได้ทั้งในเครื่องท้องถิ่นหรือผ่านอุโมงค์ SSH ใช้โทเค็นจากคำสั่งที่สองเพื่อปลดล็อกแผงควบคุม

## เก็บไดเรกทอรีข้อมูลทั้งหมดไว้

การติดตั้งแบบเนทีฟใช้ `data/live` ส่วน Docker ใช้โวลุ่มแบบถาวร `tgwitness-data` เก็บสมุดบันทึก เซสชันบัญชี กุญแจ และสถานะการทำงานไว้ด้วยกัน การส่งออกที่มีลายเซ็นเป็นหลักฐานที่มีประโยชน์ แต่ไม่ใช่การสำรองข้อมูลการติดตั้งแบบเต็มรูปแบบ

1. หยุดการเก็บข้อมูลก่อนที่จะทำการสำรองข้อมูลอย่างสม่ำเสมอ
2. คัดลอกไดเรกทอรีข้อมูลส่วนตัวทั้งหมดไปยังพื้นที่จัดเก็บข้อมูลที่ได้รับการป้องกันนอกเครื่องโฮสต์
3. ลองทำการกู้คืนข้อมูลในระบบติดตั้งที่แยกเป็นอิสระก่อนที่จะพึ่งพาข้อมูลสำรอง

## ตรวจสอบอีกครั้งหลังจากรีสตาร์ท

ตรวจสอบพื้นที่ทำงานและกุญแจที่คาดไว้ การเชื่อมต่อ Telegram แหล่งข้อมูลที่เลือกไว้ และการจับข้อความใหม่ สถานะ MTProto ที่บันทึกไว้และฟังก์ชัน catch-up ช่วยกู้คืนการอัปเดตที่ Telegram ยังเก็บไว้ แต่ไม่สามารถสร้างใหม่ได้ทุกการอัปเดตที่หมดอายุหรือการแก้ไขที่ถูกลบก่อนการจับข้อความ

สถานะความพร้อมของคอนเทนเนอร์ หมายถึง เซิร์ฟเวอร์เว็บตอบสนองได้ ให้ใช้ข้อความที่ควบคุมได้และการตรวจสอบจากพยาน เพื่อประเมินการเก็บรวบรวมข้อมูลและการเผยแพร่สู่ภายนอก

## เผยแพร่เฉพาะสิ่งที่คุณตั้งใจเท่านั้น

คู่มือการติดตั้งรวมถึงตัวอย่าง HTTPS, คำสั่งสำหรับ persistent-volume, ขั้นตอนการอัปเดตและการกู้คืนข้อมูล มีคำสั่ง Docker สำหรับการติดตั้ง; [บันทึกการตรวจสอบ](https://phishdestroy.github.io/TgWitness/th/docs/reference/verification/)ความถูกต้องปัจจุบันระบุสภาพแวดล้อมที่ได้รับการทดสอบจริง
