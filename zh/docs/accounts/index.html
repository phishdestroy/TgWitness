连接账户

一个工作区包含一个账户、其日志及其签名密钥。

选择登录方式

登录账户，添加工作区并打开其连接设置。请使用专用的账户进行监控。

  • 二维码：请通过 Telegram 的设备设置扫描该二维码，并确认新登录。
  • 电话号码：请输入号码、Telegram发送的验证码，以及（若已启用）您的两步验证密码。
  • 会话导入：导入您拥有的受支持会话或 Telegram Desktop 数据。

选择一个内置的 API 配置文件，或输入您自己的 API ID 和哈希值。API 配置文件用于识别客户端；它不会登录任何账户，也不会使连接匿名化。

需要先设置代理吗？

您可以在登录前选择并测试连接路径。每个账户都有其专属的连接路径。

选择监控内容

  1. 打开源列表，选择您需要的聊天、群组或频道。
  2. 在开始监控之前，请检查数据采集设置，包括媒体文件。
  3. 启动采集器，并检查其连接状态及近期活动。

该账户必须能够访问源数据。不同角色的用户可见不同的事件；日志反映的是该账户收到的内容。

若需针对整个账户展开调查，请使用“来源”→“观察范围”→“调查模式”，检查设置后点击“保存范围”。完整的调查指南涵盖所有可见的聊天类型、历史记录、用户资料、跨聊天引用以及证据移交流程。

检查完整路径

在您控制的测试群组中，使用另一个账号发送一条唯一消息，对其进行编辑并删除。确认日志中记录了这三项操作，然后导出并验证该记录。

“已连接”状态表明连接成功。“捕获的测试消息”则证实特定事件已到达此工作区。

添加另一个账户

在“账户”中创建另一个工作区，并重复上述设置。请保留每个账户的签名密钥指纹，以便日后识别其导出数据。
