Install with one command, connect a Telegram account and choose what to save.

Install on your computer

The installer includes Python and dependencies. Start with a chat export; add observation and investigation tools when you need them.

Linux / macOS

curl -fsSL https://get.destroy.tools/install.sh | bash

Windows · PowerShell / CMD

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"

Ubuntu server: run as root. Desktop: run as your normal user.

Open the panel address shown by the installer and use its access key. Then connect your Telegram account. The panel key and your Telegram authorization are separate.

Installation, signatures and updates explains the downloaded build, local access and server options. Source and Docker instructions remain available.

Choose your first task

  1. Connect an account by phone, QR or a supported session import.
  2. Choose the chats, folder or account scope.
  3. Export the selected history, or start observation to retain future changes.
  4. Verify the archive against a separately trusted key fingerprint.

Use a temporary GitHub runner

GitHub Actions capture guides you through the fork, authorization, scope and archive password. Download the encrypted result and its workflow provenance after the run. No permanent collector server is needed for this workflow.
