Підключити обліковий запис

Один робочий простір містить один обліковий запис, його журнал та ключ підпису.

Виберіть спосіб входу

Створіть облікові записи, додайте робочу область та відкрийте її налаштування підключення. Для спостереження використовуйте окремий обліковий запис.

  • QR-код: відскануйте його в налаштуваннях пристрою Telegram і підтвердьте новий логін.
  • Номер телефону: введіть номер, код, надісланий Telegram, та пароль двоступеневої верифікації, якщо ця функція увімкнена.
  • Імпорт сеансу: імпортуйте підтримуваний сеанс або дані Telegram Desktop, що належать вам.

Оберіть вбудований профіль API або введіть власний ідентифікатор API та хеш. Профіль API ідентифікує клієнта; він не здійснює вхід в обліковий запис і не робить з’єднання анонімним.

Спочатку потрібен проксі-сервер?

Ви можете вибрати та перевірити маршрут з’єднання перед входом у систему. Кожен обліковий запис має свій власний маршрут.

Виберіть, що спостерігати

  1. Відкрийте список джерел і виберіть потрібні вам чати, групи або канали.
  2. Перед початком спостереження перегляньте налаштування збору даних, зокрема щодо мультимедійних файлів.
  3. Запустіть колектор та перевірте його з’єднання й останню активність.

Акаунт повинен мати доступ до джерела. Різні ролі можуть бачити різні події; журнал відображає те, що отримав саме цей акаунт.

Для справи, що охоплює весь обліковий запис, скористайтеся меню «Джерела» → «Обсяг спостереження» → «Режим розслідування», перегляньте налаштування та натисніть «Зберегти обсяг». Повний покроковий посібник з розслідування охоплює всі види чатів, що відображаються, стару історію, профілі користувачів, перехресні посилання між чатами та передачу доказів.

Перегляньте весь шлях

У тестовій групі, яку ви контролюєте, надішліть унікальне повідомлення з іншого облікового запису, відредагуйте його та видаліть. Переконайтеся, що всі три події відобразилися в журналі, а потім експортуйте та перевірте запис.

Статус «підключено» підтверджує наявність з’єднання. Зафіксоване тестове повідомлення підтверджує, що конкретна подія надійшла до цього робочого простору.

Додати ще один обліковий запис

Створіть ще одну робочу область у розділі «Акаунти» та повторіть налаштування. Зберігайте відбиток ключа підпису кожного акаунта, щоб згодом можна було ідентифікувати експортовані дані.
