# Telegram · レポートの作成

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/reports/

読み手をケースの問いから保存された記録へまっすぐ導きます。

Report studio は、選んだデータ、変更履歴、グラフ、あなたの調査結果をまとめます。8 つのデザイン、HTML とネイティブ PDF。HTML、PDF、JSON のレポートはすべてあなたの鍵で封印されます。

## 3つのステップでレポートを作成する

1. **エクスポート → 設定とプレビュー → データ**：ワークスペース全体、またはチャット、作成者、日付（UTC、TgWitness が記録を見た時刻）、記録の種類を選びます。
2. **デザインとコンテンツ**：デザインと中身を選びます：グラフ、参加者、トランスクリプト、変更、Case Board の項目、ケースの詳細、メモ。
3. **プレビュー**：件数、アクティビティ、サンプル、欠けている ID の範囲を確認します。保存してから、必要な形式をダウンロードします。

### 保存された資料を、読者が理解しやすいように整理してください

合成例・概略レイアウトであり、生成されたレポートではありません

1. **[選択]。**本案件の対象となるチャットを2つと、観察期間を選択してください。
2. **文章を作成してください。**レイアウトを選択し、質問に答えるセクションを選んでください。
3. **プレビュー。**選択された件数と、保存された「変更前」および「変更後」のテキストを確認してください。
4. **検証を行ってください。**最終ファイルを生成し、その署名を信頼できるワークスペースのフィンガープリントと照合して確認してください。

## 読み方のスタイルを選択してください

**Classic, Editorial, Briefing, Analytics, Technical, Overview, Reading series, and Ledger & margin**：同じ記録で、見た目が違います。切り替えても選択とメモは保持されます。25 言語のどれでも使えます。

PDF は同梱のフォントで作成され、ブラウザーは不要です。中国語、日本語、韓国語にはサーバー上に Noto Sans CJK などのフォント（システム全体または `TGWITNESS_FONT_DIR`）が必要で、ない場合は HTML と JSON のみになります。

## 変更内容をその文脈とともに読み取る

編集は前後を、削除は最後に保存された版を表示します。返信、転送、リアクション、ボタン、添付ファイルは参照を保ちます。

デザインのプレビューは最初の 50,000 件の記録を使い、データのプレビューはすべてを正確に数えます。最終的なページレイアウトは PDF を作成して確認してください。

## 受信者向けの文言は慎重に選定してください

フィルターはレポートの形を決めるだけで、証拠 ZIP には引き続きジャーナル全体とファイルが入ります。相手に渡す量を減らすなら、[最小化した引き渡し](https://phishdestroy.github.io/TgWitness/ja/docs/handover/)を使ってください。詳しくは：[レポートの内容](https://phishdestroy.github.io/TgWitness/ja/docs/reference/case-reports/)、[エクスポートの検証](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)。
