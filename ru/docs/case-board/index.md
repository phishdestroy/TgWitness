# Доска дела: сообщения и доказательства Telegram

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/case-board/

Превратите сохранённые сообщения в дело, над которым работает вся команда.

Закладки, точные цитаты, срезы и обсуждения, каждое связано с источником. Каждое изменение — подписанная ревизия.

## От сообщения до карточки дела

1. **Расследование → Case Board** (режим «Стандартный» или «Эксперт»). Создайте коллекцию для дела.
2. В **Журнале** или в чате нажмите **На доску** (или **B**). Карточка попадёт во «Входящие», дайте ей название и переместите.
3. Выделите текст в сообщении — **Выделить → на доску** сохранит точную цитату и версию. Отметьте, почему это важно.
4. Обсуждайте, ставьте статус, возвращайтесь к источнику, когда нужно. **Презентация** проведёт команду по всему материалу.

### Следуйте по одной измененной ссылке для оплаты

Синтетический пример · локальная иллюстрация

1. **Захват.** Откройте сохраненное наблюдение № 142 и его версию сообщения.
2. **Добавьте в закладки.** Сохраните цитату, ссылку на источник и свой вопрос на карточке.
3. **Проверка.** Добавьте комментарий команды и переместите карточку в статус «Проверка».
4. **Представить.** Пройтись по процессу сбора данных и открыть контекст цитируемого источника.

Аннотации и данные наблюдения за Telegram остаются отдельно идентифицируемыми.

## Сохраните полезный диапазон один раз

Shift-клик по двум сообщениям для **Срез между**, **Срез по времени** или сохранение текущих фильтров журнала. **Показать записи после закладки** покажет, что пришло позже.

Срезы по времени используют время наблюдения, срезы по ID сообщений следят за этими сообщениями по мере их изменений.

## Назначьте каждому коллеге соответствующую роль

**Рецензент** читает, **Аналитик** добавляет карточки и комментарии, **Оператор** ещё и управляет коллекциями и решениями. Права на чаты действуют и на карточки.

## Подготовьте конечный результат

Срезы экспортируются в подписанный JSON или CSV. В отчёты можно включить закладки, срезы и комментарии — это настраивается в [Report studio](https://phishdestroy.github.io/TgWitness/ru/docs/reports/). Для получателя с ограниченным доступом используйте [передачу](https://phishdestroy.github.io/TgWitness/ru/docs/handover/).
