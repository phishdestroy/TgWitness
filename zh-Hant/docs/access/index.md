# 分享案例

Canonical page: https://phishdestroy.github.io/TgWitness/zh-Hant/docs/access/

分享他人所需的案例。其餘部分則由您掌控。

01**選擇證據**

可選擇整個帳戶的工作區，或個別已記錄的聊天紀錄。

02**選擇操作**

允許查看、匯出，或授予該人員所需的特定操作權限。

03**設定限制**

發行一個帶有有效期限、會話限制及可選 IP 限制的個人令牌。

收集範圍決定了記錄的內容；存取範圍則決定了使用者能查看和執行的操作。

## 授予某人存取權限

1. 請以管理員身分登入，並開啟「**存取」頁面**。
2. 請指定存取權限，並選擇工作區及聊天室。
3. 保留**「檢視」**功能供審閱者使用。若審閱者需下載紀錄，則新增「**匯出」功能**。
4. 設定權限限制後，請按下「**建立存取權限」**。
5. 請複製畫面中顯示的代碼一次，並將其與面板地址一併以私訊方式傳送。
6. 在移交前，請先於另一個瀏覽器視窗中確認允許的檢視範圍。

## 從他們需要完成的工作開始

| 人物 | 存取 | 結果 |
| --- | --- | --- |
| 審閱者 | 精選對話；僅限檢視 | 閱讀已擷取的對話內容，且不改變原始資料集。 |
| 分析師 | 精選對話；檢視與匯出 | 檢視並下載本案所需的紀錄。 |
| 操作員 | 精選完整工作區；來源與蒐集 | 管理監測內容，並啟動或停止資料收集器。 |

這些是您自行選擇的設定，而非固定的角色。即使啟用了其他權限，全帳戶設定及完整日誌匯出功能仍會對「僅限聊天室」的存取權限保持關閉狀態。「所有工作區」存取權限包含未來的帳戶。

## 您可隨時改變主意

編輯存取權限以變更後續請求可執行的操作。終止單一會話，或撤銷全部存取權限以終止所有會話。已下載的檔案無法收回。終止面板會話不會停止資料收集。

**會話與 IP 限制**

可限制並行連線數與成功登入次數、設定絕對截止日期、允許特定 IP 位址或子網，或將存取權限綁定至首次登入的 IP 位址。連線過期機制以閒置時間為準；開啟的面板若持續進行輪詢，則視為有活動。當應用程式透過代理伺服器或隧道運行時，請檢查應用程式顯示的客戶端位址。

**主金鑰與活動日誌**

管理員持有主面板的存取憑證。已授予的存取權限無法管理他人的存取權限，亦無法開啟管理員控制台。控制台會顯示跨工作區的當前進程活動；簽署過的存取記錄會保留授權與連線事件，且不包含存取憑證。各工作區共用主進程，其資料不會與伺服器管理員的資料隔離。

請參閱[完整的權限參考](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/reference/access/)資料，以了解所有七項權限、會話規則及管理員權限範圍。
