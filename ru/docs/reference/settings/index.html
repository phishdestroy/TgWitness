Справочник / Установка

Первоначальная настройка и параметры

Мастер настройки, цели, уровни интерфейса, маршруты подключения и настройки, общие для группы аккаунтов.

Аккаунты · Связь · Доступ

Новая рабочая область открывается /first-run: язык и время, уровень интерфейса, цель, подключение, Telegram и чаты. Каждый ответ сохраняется на сервере сразу же после его изменения, поэтому при перезагрузке процесс продолжается с того же шага. На последнем экране отображается список ответов, и вы можете вернуться к любому из них.

Язык, часовой пояс IANA, тема и уровень сохраняются для каждого оператора и каждого рабочего пространства. По умолчанию используются язык браузера, часовой пояс устройства, системная тема и простой интерфейс. При смене языка настройки панели сохраняются. Время в подписанном журнале никогда не меняется.

/settings редактирует те же записи, что и мастер. Поиск охватывает основные поля, параметры и расширенные формы; скрытое поле можно открыть без изменения уровня. Уровни влияют только на то, что отображается: сервер самостоятельно проверяет права доступа. Настройки коллекции и первое подключение принадлежат администратору рабочей области.

Цели#

Цель Коллекция Файлы Внешние сервисы Адрес сервера
Архивная копия Выключено; «Запустить» запускает экспорт Фотографии размером до 20 МБ Выключить Автоматически
Подписка на чаты Непрерывный Фотографии и видео продолжительностью до 60 секунд / размером до 20 МБ Временные метки и уведомления о проблемах Автоматически
Доказательства Непрерывный Все файлы размером до 1 ГБ Временные метки, drand, уведомления Нет, скрыть

В качестве доказательств рекомендуется использовать внесерверную копию, бота-свидетеля и проверку кода. Для адресов хранилища и уведомлений сначала необходимо указать пункт назначения. Функция, взаимодействующая с внешним сервисом, запрашивает разрешение на отправку запросов за пределы Telegram; отключение этой функции предлагает одновременно отключить временные метки, уведомления и внесерверную копию.

При изменении целевого значения сначала отображаются различия, а ручные изменения можно сохранить. Поле, отличающееся от целевого значения, помечается как «Изменено вами» и может быть восстановлено. Ревизия настроек предотвращает применение проверенного изменения поверх изменения, внесённого на другой вкладке.

Связь#

Automatic сначала пробует подключиться к публичным серверам MTProxy, затем к WARP, а затем — к прямому соединению, причём последнее используется только в том случае, если адрес сервера может быть отображён. Automatic и WARP могут устанавливать компоненты с проверкой хешей и регистрировать сервер в Cloudflare. WARP использует существующий менеджер wgcf/wireproxy и локальный порт SOCKS5; таблица маршрутизации системы не изменяется. При необходимости использования внешних сервисов Automatic отдаёт предпочтение WARP перед MTProxy.

Ваш собственный прокси принимает tg://proxy, socks5://, http:// и https://. Сертификат HTTPS- прокси проверяется перед отправкой ему учетных данных.

Проверка подключения действительна в течение пяти минут и привязана к маршруту, политике и ответам мастера; изменение любого из этих параметров требует новой проверки. Доступна опция «Продолжить без проверки», которая не заменяет вход в Telegram. Выбранный маршрут перепроверяется в фоновом режиме, а функция «Автоматический» повторно запускает цепочку действий после потери соединения. Если ни один из общедоступных прокси не отвечает, индикатор становится красным, и запускаются действия WARP и повторная проверка.

Группы аккаунтов#

Аккаунты в группе используют общие настройки. Откройте «Аккаунты» → «Группы и общие настройки» → «Общие настройки» или «Настройки группы» на странице «Настройки» аккаунта.

Группа совместно использует цель, сохраненные файлы, временные метки, drand, уведомления о проблемах, внешнюю копию, запросы за пределами Telegram, IP-режим, параметры записи, график повторной проверки, правила уведомлений, настройки отчетов, параметры и маршрут подключения. Адреса для уведомлений, учетные данные прокси и данные для входа сохраняются для каждого аккаунта отдельно, так же как и запуск и приостановка сбора данных.

  • Каждый участник подписан на группу. В настройках можно выбрать значение 🔗 из группы или ✏️ собственное значение; нажатие «Вернуть значение группы» восстанавливает исходное значение.
  • При внесении изменения отображается список затронутых аккаунтов (применимо к 2 из 3 аккаунтов), и перед заменой собственного значения запрашивается подтверждение для каждого аккаунта. Аккаунты, галочка у которых снята, сохраняют свои значения.
  • Параметр, которым группа не делится, остаётся в состоянии «Не поделиться»: каждый аккаунт сохраняет своё собственное значение, пока вы не нажмёте «Поделиться этим значением».
  • При копировании настроек из одной учётной записи значения выбранной учётной записи становятся значениями для всей группы.
  • Аккаунту, перемещённому в группу, задаётся вопрос: «Принять настройки группы?». В противном случае он сохраняет свои собственные настройки, отмеченные значком ✏️. Аккаунты, добавленные позже, изначально используют настройки группы.
  • Учетная запись-наблюдатель сохраняет свой IP-режим до тех пор, пока не будет приостановлена.

Каждое изменение фиксируется в подписанном журнале основного рабочего пространства и каждого участника, к которому оно доходит. При удалении группы её аккаунты и их текущие значения сохраняются.

Страница группы /groups/<id> отображает участников, задачи, требующие внимания, и чаты, доступные нескольким аккаунтам. См. раздел «Группы аккаунтов».

Существующие рабочие пространства#

В рабочей области, содержащей сессию или ранее завершённую настройку, мастер не отображается. Её значения не заменяются целью при загрузке страницы. Скрытие поля не отключает эту функцию и не удаляет её значение.

Оценка объёма и времени учитывает до трёх выбранных чатов и до 20 сообщений из каждого. Это приблизительная оценка: она не учитывает ограничения Telegram, скорость конкретного сервера или файлы в каждом чате.
