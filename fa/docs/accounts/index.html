Telegram · اتصال یک حساب

یک فضای کاری = یک حساب، ژورنال آن و کلید آن.

انتخاب روش ورود

حساب‌ها ← افزودن فضای کاری ← تنظیمات اتصال. برای این کار از یک حساب جداگانه استفاده کنید.

  • کد QR: آن را از صفحه دستگاه‌ها در Telegram اسکن و تأیید کنید.
  • شماره تلفن: شماره، کد، سپس رمز 2FA اگر دارید.
  • وارد کردن نشست: فایل نشست خودتان یا داده‌های Telegram Desktop.

از نمایه API داخلی یا API ID و hash خودتان استفاده کنید. فقط برنامه را شناسایی می‌کند، شما را وارد نمی‌کند و چیزی را پنهان نمی‌کند.

ابتدا به پروکسی نیاز دارید؟

می‌توانید قبل از ورود، مسیر اتصال را انتخاب و آزمایش کنید. هر حساب مسیر مخصوص به خود را دارد.

انتخاب کنید چه چیزی را مشاهده کنید

  1. گفتگوها، گروه‌ها یا کانال‌هایی را که لازم دارید انتخاب کنید.
  2. تنظیمات جمع‌آوری، از جمله رسانه، را بررسی کنید.
  3. اجرا کنید و اتصال و فعالیت اخیر را بررسی کنید.

حساب باید دسترسی داشته باشد. مدیران و اعضا چیزهای متفاوتی می‌بینند و ژورنال نشان می‌دهد این حساب چه دریافت کرد.

کل حساب؟ منابع ← محدوده مشاهده ← حالت تحقیق، بررسی کنید، ذخیره محدوده. راهنمای کامل: تحقیق روی کل یک حساب.

مسیر کامل را بررسی کنید

در گروه آزمایشی، از حساب دیگری پیامی بفرستید، ویرایشش کنید، حذفش کنید. هر سه باید در ژورنال دیده شوند. سپس خروجی بگیرید و تأیید کنید.

«متصل» یعنی اتصال کار می‌کند. پیام آزمایشی ثبت‌شده یعنی رویدادها واقعاً می‌رسند.

حساب دیگری اضافه کنید

فضای کاری جدید در حساب‌ها، همان مراحل. اثر انگشت کلید هر حساب را یادداشت کنید تا بعداً خروجی‌ها را از هم تشخیص دهید.
