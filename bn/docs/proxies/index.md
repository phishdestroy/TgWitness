# একটি প্রক্সি নির্বাচন করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/proxies/

অ্যাকাউন্ট সংযুক্ত রাখুন। স্পষ্টভাবে নির্ধারণ করুন কখন এর পথ সার্ভারের ঠিকানা ব্যবহার করতে পারে।

## প্রথমে আইপি মোড নির্বাচন করুন

01**আইপি লুকান**

প্রক্সি ব্যবহার করুন। যখন কোনোটিই কাজ না করে, সরাসরি টেলিগ্রাম সংযোগ ছাড়া অপেক্ষা করুন।

02**ব্যাকআপ ব্যবহারের অনুমতি দিন**

নির্ধারিত বিলম্বের পর সরাসরি অনুমতি দিন; কেউ উত্তর দিলে কর্মক্ষম প্রক্সিতে ফিরে যান।

03**টানেল / ভিপিএন**

হোস্টের নেটওয়ার্কের মাধ্যমে সরাসরি রুটগুলি অনুমোদন করুন। এই বিকল্পটি VPN ইনস্টল বা যাচাই করে না।

রুট সংযোগটি নির্বাচন করে। আইপি মোড নির্ধারণ করে সরাসরি সংযোগ অনুমোদিত কিনা।

## পুলটিকে পথটি বজায় রাখতে দিন

1. অ্যাকাউন্ট খুলুন → সেটিংস → সংযোগ সেটিংস।
2. IP মোড এবং **অটোমেটিক MTProxy** নির্বাচন করুন, অথবা একটি স্থায়ী রুট প্রবেশ করান।
3. সংরক্ষণ করুন এবং **টেলিগ্রাম সংযোগ পরীক্ষা** চালান। এটি সাইন-ইন করার আগেও কাজ করে।
4. সংগ্রহ শুরু করার পর যাচাই করুন যে একটি নিয়ন্ত্রিত বার্তা জার্নালে পৌঁছেছে।

নতুন কর্মস্থানগুলো স্বয়ংক্রিয় MTProxy ব্যবহার করে আইপি লুকানোর বৈশিষ্ট্যসহ। পুলটি চারটি পাবলিক সোর্স একত্রিত করে, এন্ট্রিগুলো পরীক্ষা করে, কার্যকর রুটগুলো ধরে রাখে এবং ব্যর্থ প্রক্সিগুলো প্রতিস্থাপন করে। ব্যর্থ ডাউনলোডগুলো পূর্ববর্তী স্ন্যাপশটগুলো ধরে রাখে।

## আপনার নিজস্ব প্রক্সি ব্যবহার করুন

SOCKS5 বা HTTP CONNECT বিবরণ প্রবেশ করান, একটি সমর্থিত টেলিগ্রাম প্রক্সি লিঙ্ক পেস্ট করুন, অথবা অপারেটর ক্যাটালগ প্রদান করুন। একটি সক্রিয় রুট পরিবর্তন করার আগে পর্যবেক্ষণ বিরতি দিন। `ee` দিয়ে শুরু হওয়া ভুয়া TLS MTProxy গোপনীয়তাগুলি এখনও সমর্থিত নয়।

**ঘূর্ণন, ভাগাভাগি এবং পুনঃচেষ্টা সেটিংস**

**প্যারামিটার → অটোম্যাটিক MTProxy-এর** অধীনে ব্যর্থতার সীমা, কুলডাউন, পরিকল্পিত রোটেশন এবং প্রতি প্রক্সির অ্যাকাউন্ট সেট করুন। শেয়ারিং সীমা এক নির্ধারণ করলে কোনো এক্সক্লুসিভ এন্ট্রি উপলব্ধ না থাকলে অ্যাকাউন্টটি অপেক্ষা করবে। লিস্ট রিফ্রেশ এবং প্রব ইন্টারভালগুলো প্রধান ওয়ার্কস্পেসের মান অনুসরণ করে। পৃথক প্রক্সিগুলো পৃথক এক্সিট আইপি নিশ্চিত করে না।

## বহিঃপ্রাঙ্গণ অনুরোধ থেকে টেলিগ্রামকে আলাদা করুন

MTProxy শুধুমাত্র টেলিগ্রাম ট্র্যাফিক বহন করে। টাইমস্ট্যাম্প, বিজ্ঞপ্তি, কপি এবং সোর্স চেক আলাদা একটি SOCKS5/HTTP প্রক্সি, অ্যাকাউন্টের SOCKS5/HTTP রুট বা IP মোড অনুমোদিত হলে Direct ব্যবহার করে। এই বাহ্যিক অনুরোধগুলো নিষ্ক্রিয় করা যেতে পারে।

`TGWITNESS_PROXY_FEED_PROXY` স্পষ্টভাবে ফিড ডাউনলোডার-এর রুট কনফিগার করে। [স্বাধীন সাক্ষী](https://phishdestroy.github.io/TgWitness/bn/docs/witness/) তার নিজস্ব সেটিংস বজায় রাখে। এই নিয়ন্ত্রণগুলো সিস্টেম VPN ইনস্টল করে না বা ব্রাউজার ট্র্যাফিকের রুট পরিবর্তন করে না।

[সমস্ত মোড, ডিফল্ট এবং সোর্স তালিকা](https://phishdestroy.github.io/TgWitness/bn/docs/reference/connection/#ip-modes) দেখুন, অথবা [নির্বাচন করুন কে একটি অ্যাকাউন্টের পথ পরিবর্তন করতে পারবে](https://phishdestroy.github.io/TgWitness/bn/docs/access/)।
