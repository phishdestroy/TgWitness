อ้างอิง

การตั้งค่าเริ่มต้นอย่างรวดเร็วรูปแบบบัญชีและเซสชันการเข้าถึงและสิทธิ์การเชื่อมต่อ, พร็อกซี และการคุ้มครองข้อมูลการติดตั้ง
Collectวิธีการเก็บรวบรวมข้อมูลโหลดประวัติแหล่งที่มาขั้นตอนการทำงานและการดำเนินการโหมดการสืบสวนคุณสมบัติและข้อจำกัด
การเก็บรักษาข้อมูลและการบูรณาการการวิเคราะห์ข้อมูลในคลังMCP แบบอ่านเท่านั้นOCR และแปลงข้อความเป็นข้อความแบบท้องถิ่นwebhooks ส่งออก
หลักฐานวิธีการทำงานของหลักฐานรูปแบบหลักฐานพยานอิสระข้อมูลเวลา

แบ่งปันกรณีศึกษา

แบ่งปันกรณีที่ใครนั้นต้องการ และรักษาการควบคุมส่วนที่เหลือ

ให้สิทธิ์การเข้าถึงแก่ผู้ใช้

  1. ลงชื่อเข้าใช้ในฐานะผู้ดูแลระบบและเปิดส่วน Access
  2. ระบุชื่อการเข้าถึง และเลือกพื้นที่ทำงานและห้องสนทนา
  3. เก็บหน้า "View" ไว้สำหรับผู้ตรวจสอบ และเพิ่มหน้า "Export" หากผู้ตรวจสอบต้องการดาวน์โหลดบันทึก
  4. กำหนดขีดจำกัด แล้วกด "สร้างสิทธิ์เข้าถึง"
  5. คัดลอกโทเค็นที่แสดงขึ้นเพียงครั้งเดียว แล้วส่งไปแบบส่วนตัวพร้อมกับที่อยู่ของแผงควบคุม
  6. ตรวจสอบสิทธิ์การเข้าถึงในเซสชันเบราว์เซอร์แยกต่างหากก่อนส่งมอบ

เริ่มจากงานที่พวกเขาต้องทำ

บุคคลเข้าถึงผลลัพธ์
ผู้ตรวจสอบการสนทนาที่เลือกไว้; ดูได้เท่านั้นอ่านบทสนทนาที่บันทึกไว้โดยไม่เปลี่ยนแปลงข้อมูลที่เก็บรวบรวม
นักวิเคราะห์การสนทนาที่เลือกไว้; ดูและส่งออกตรวจสอบและดาวน์โหลดบันทึกที่จำเป็นสำหรับคดี
ผู้ดำเนินการพื้นที่ทำงานที่เลือกไว้ทั้งหมด; แหล่งข้อมูลและการรวบรวมจัดการข้อมูลที่บันทึกไว้ และเริ่มหรือหยุดการทำงานของตัวเก็บข้อมูล

นี่คือการตั้งค่าที่คุณเลือกเอง ไม่ใช่บทบาทที่กำหนดไว้ล่วงหน้า การตั้งค่าระดับบัญชีและการส่งออกบันทึกเต็มรูปแบบจะยังคงถูกจำกัดการเข้าถึงเฉพาะการสนทนา แม้เมื่อมีการเปิดใช้งานสิทธิ์อื่นแล้วก็ตาม การเข้าถึงทุกพื้นที่ทำงานจะรวมถึงบัญชีในอนาคตด้วย

คุณสามารถเปลี่ยนใจได้ทุกเมื่อ

ปรับการเข้าถึงเพื่อกำหนดว่าคำขอถัดไปสามารถทำอะไรได้ ยุติเซสชันหนึ่งหรือเพิกถอนสิทธิ์การเข้าถึงทั้งหมดเพื่อยุติเซสชันทั้งหมด ไฟล์ที่ดาวน์โหลดไปแล้วไม่สามารถเรียกคืนได้ การยุติเซสชันของแผงควบคุมจะไม่หยุดการเก็บข้อมูล

ข้อจำกัดเกี่ยวกับเซสชันและ IP

จำกัดจำนวนเซสชันที่ทำงานพร้อมกันและจำนวนการเข้าสู่ระบบที่สำเร็จ ตั้งวันที่สิ้นสุดแบบสัมบูรณ์ อนุญาตที่อยู่ IP หรือซับเน็ต หรือผูกการเข้าถึงกับที่อยู่ IP ที่ใช้เข้าสู่ระบบครั้งแรก การหมดอายุเซสชันจะวัดจากความไม่มีการใช้งาน; การรีเฟรชหน้าต่างที่เปิดอยู่จะนับเป็นกิจกรรม ตรวจสอบที่อยู่ไคลเอนต์ที่แสดงโดยแอปพลิเคชันเมื่อทำงานผ่านพร็อกซีหรือทูนเนล

กุญแจหลักและบันทึกกิจกรรม

ผู้ดูแลระบบเก็บโทเค็นของแผงควบคุมหลักไว้ ผู้ใช้ที่ได้รับสิทธิ์เข้าถึงไม่สามารถจัดการสิทธิ์เข้าถึงของผู้อื่นหรือเปิดคอนโซลผู้ดูแลระบบได้ คอนโซลแสดงกิจกรรมของกระบวนการปัจจุบันในทุกพื้นที่ทำงาน; บันทึกสิทธิ์เข้าถึงที่ลงนามจะเก็บรักษาเหตุการณ์การมอบสิทธิ์และเซสชันโดยไม่ใช้โทเค็น พื้นที่ทำงานใช้กระบวนการโฮสต์ร่วมกันและไม่แยกข้อมูลจากผู้ดูแลระบบเซิร์ฟเวอร์

ใช้ข้อมูลอ้างอิงสิทธิ์การเข้าถึงแบบครบถ้วนสำหรับสิทธิ์การเข้าถึงทั้งเจ็ดประเภท กฎเซสชัน และขอบเขตของผู้ดูแลระบบ
