# TgWitness فوری آغاز

TgWitness ایک خود مختار ایپلیکیشن ہے جو آپ کے اکاؤنٹس کے قابلِ رسائی ٹیلیگرام گروپس اور چینلز کی نگرانی کے لیے استعمال ہوتی ہے۔ یہ مقامی طور پر اپنی مخصوص ڈیٹا ڈائریکٹری کے ساتھ چلتی ہے۔

**پہلی بار آئے ہیں؟** اکاؤنٹ منسلک کرنے سے پہلے [ڈیمو دیکھیں۔](#انٹرفیس-کو-دریافت-کریں) پروکسیز، گواہوں، ایکسپورٹس یا سرور سیٹ اپ کے لیے [رہنما منتخب کریں](../README.md)۔

## انسٹال کریں اور شروع کریں

ایک طریقہ منتخب کریں۔ پورٹیبل ڈاؤن لوڈز ریلیز بلڈ شائع ہونے کے بعد دستیاب ہوتے ہیں:

| میزبان | کچھ بھی انسٹال نہیں ہوا | ماخذ سے: پائتھن 3.11+ | Docker: Engine/Desktop Compose 2.20+ کے ساتھ |
| --- | --- | --- | --- |
| ونڈوز | `TgWitness-<version>-windows-amd64-portable.zip` کو GitHub Releases سے نکالیں، `TgWitness.cmd` پر ڈبل کلک کریں۔ | `Start.cmd` پر ڈبل کلک کریں | `Docker.cmd` پر ڈبل کلک کریں |
| لینکس / میک او ایس | — | `sh start.sh` | `sh docker-start.sh` |

ماخذ طریقوں کے لیے GitHub Releases سے ماخذ ZIP ڈاؤن لوڈ کریں اور اسے نکالیں یا ریپوزیٹری کلون کریں۔ `Start.cmd` آپ کے Windows صارف کے لیے Python 3.12 انسٹال کرنے کی پیشکش کرتا ہے اگر کوئی موزوں Python نہ ملے (winget یا signed python.org انسٹالر کے ذریعے)۔ `start.sh` اگر Python موجود نہ ہو تو آپ کی Linux ڈسٹری بیوشن یا macOS کے لیے درست انسٹال کمانڈ دکھاتا ہے۔ پہلا سورس لانچ `.venv` بناتا ہے اور انحصار خودکار طور پر انسٹال کرتا ہے۔

Docker ایپلیکیشن کو بناتا ہے اور اسے پسِ منظر میں چلاتا ہے؛ ہوسٹ Python غیر ضروری ہے۔ `Docker.cmd` اور `docker-start.sh` کنٹینر کے صحت مند ہونے پر پینل کا پتہ اور ٹوکن پرنٹ کرتے ہیں۔ ہر سپورٹڈ ہوسٹ پر مساوی Docker کمانڈز یہ ہیں:

```sh
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

**http://127.0.0.1:8787** کھولیں۔ Docker ہیلپر یا دوسری Docker کمانڈ کے ذریعے پرنٹ کیا گیا ٹوکن استعمال کریں، یا پورٹیبل یا سورس انسٹالیشن کے لیے **data/live/panel-token.txt** پڑھیں۔ نیچے **Connect Telegram** پر جاری رکھیں۔ نیٹیو اور Docker انسٹالیشنز الگ الگ اسٹوریج استعمال کرتی ہیں؛ Docker شروع کرنے سے موجودہ نیٹیو جرنل امپورٹ نہیں ہوتا۔

سرور کے لیے [تعیناتی](DEPLOYMENT.md) میں خودکار HTTPS، ری اسٹارٹ، شائع شدہ تصاویر، اپ ڈیٹس، اور بیک اپ شامل ہیں۔

## انٹرفیس کو دریافت کریں

1. پورٹیبل پیکیج میں **TgWitness-Demo.cmd** چلائیں، ونڈوز سورس فولڈر میں **Demo.cmd** چلائیں، یا لینکس/macOS پر `sh start.sh --demo` چلائیں۔ سورس لانچ پہلے `.venv` بناتا ہے اور انحصارات انسٹال کرتا ہے۔
2. **http://127.0.0.1:8787** کھولیں۔
3. مقامی ڈیمو نمونہ جرنل خود بخود کھولتا ہے۔ براہِ راست مقامی رسائی کے لیے ٹوکن کاپی کرنے کی ضرورت نہیں ہے۔

ڈیمو پیغامات خیالی ہیں۔ ڈیمو موڈ حقیقی ٹیلیگرام اکاؤنٹ سے منسلک نہیں ہو سکتا۔

## ٹیلیگرام سے کنیکٹ کریں

> [!WARNING]
> **وہ کچھ بھی استعمال نہ کریں جسے آپ کھونے کا متحمل نہیں ہو سکتے۔** ہم سختی سے مشورہ دیتے ہیں کہ ذاتی یا قیمتی اکاؤنٹس کو منسلک نہ کریں اور جس اکاؤنٹ کی آپ قدر کرتے ہیں اس پر API ID/ہیش نہ بنائیں۔ ٹیلیگرام کلائنٹ کی پرواہ کیے بغیر اکاؤنٹس کو غیر متوقع اور اکثر مستقل طور پر بلاک کر دیتا ہے۔ ایک ہموار ٹیسٹ رن ٹیلیگرام پر منحصر ہے، TgWitness پر نہیں، اور مستقبل کے لیے کوئی ضمانت نہیں دیتا۔

1. اگر مقامی ڈیمو چل رہا ہے تو اسے روک دیں اور **Start.cmd** یا `sh start.sh` چلائیں۔ ورنہ اوپر چلتی ہوئی لائیو تنصیب کو اسی طرح چلتا رہنے دیں۔
2. پینل کھولنے کے لیے اپنے انسٹالیشن طریقہ کار کے لیے پینل ٹوکن استعمال کریں۔
3. اگر آپ کو پروکسی کی ضرورت ہو تو اسے **اکاؤنٹ → سیٹنگز → کنکشن سیٹنگز → کنکشن راستہ تبدیل کریں** کے تحت محفوظ کریں۔
4. **اکاؤنٹ** میں اپنا فون نمبر درج کریں اور **Continue** دبائیں، **QR کوڈ → Show QR code** منتخب کریں، یا فائلز منتخب کر کے **Connect account** دبائیں۔ **API ID + Hash** اختیاری ہے: ورک اسپیس اپنی محفوظ یا درآمد شدہ جوڑی استعمال کرتا ہے، یا بلٹ ان پول سے ایک فعال جوڑی۔ اپنی ایپ استعمال کرنے کے لیے، ایک `API ID:API Hash` جوڑا API ID میں پیسٹ کریں۔ مکمل اتھارائزیشن کلید کے لیے، **Auth key** منتخب کریں، تمام 512 ہیکساڈیسمل حروف پیسٹ کریں، اور فراہم کردہ DC ID منتخب کریں۔ User ID اختیاری ہے اور درج کرنے پر چیک کی جاتی ہے۔
5. اپنا منتخب کردہ سائن ان طریقہ مکمل کریں: فون/کوڈ/2FA، QR کے لیے سائن ان شدہ ٹیلیگرام ایپ سے تصدیق، یا ایک معاون مجاز سیشن امپورٹ۔
6. دکھائی گئی اکاؤنٹ آئی ڈی چیک کریں۔ اوپن **سورسز**: آپ کی چیٹس خود بخود لوڈ ہو جاتی ہیں؛ اپنے گروپس شامل کریں۔
7. **'محفوظ رکھنے والی تبدیلیاں منتخب کریں**' کے تحت ایونٹ کیٹیگریز یا **'پیغامات، ترامیم اور حذف شدہ**' پری سیٹ منتخب کریں، پھر مانیٹرنگ سیٹنگز محفوظ کریں۔
8. منسلک کی ترتیبات علیحدہ سے منتخب کریں، پھر **'مشاہدہ شروع کریں'** پر کلک کریں۔

API کی اسناد آپ کی ایپلیکیشن کی شناخت کرتی ہیں؛ یہ بذاتِ خود کسی اکاؤنٹ کو مجاز نہیں بناتی۔ نجی گروپس کو عوامی صارف نام کی ضرورت نہیں ہوتی، لیکن آپ کے اکاؤنٹ کو رسائی حاصل ہونی چاہیے۔

موجودہ اکاؤنٹس کے لیے [اکاؤنٹس اور سیشن فارمیٹس](../ACCOUNTS.md) دیکھیں: پینل Telethon StringSession، Telethon/Pyrogram SQLite، سنگل اکاؤنٹ TData ZIP، اور سپورٹڈ اکاؤنٹ JSON قبول کرتا ہے۔ ایک سیشن اور اس کے ساتھ والا JSON منتخب کریں، پھر **Connect account** دبائیں۔ QR لاگ ان بھی دستیاب ہے، اسی اختیاری API ترتیبات کے ساتھ۔ TDLib، بوٹس، اور بلک اکاؤنٹ لسٹس کی حمایت نہیں کی جاتی۔

ایک اور اکاؤنٹ شامل کرنے کے لیے اکاؤنٹ منتخب کرنے والے کے پاس **+** دبائیں یا **اکاؤنٹ → ترتیبات → کنکشن ترتیبات → ورک اسپیسز** کھولیں، یا **اکاؤنٹس** استعمال کریں۔ ورک اسپیسز کے الگ الگ سیشنز، جرنلز، کیز، سورسز اور قطاریں ہوتی ہیں۔ ویوز تبدیل کرنے سے دیگر کلیکٹرز چلتے رہتے ہیں۔ اسی ٹیلیگرام اکاؤنٹ کو اس تنصیب میں دو ورک اسپیسز میں تفویض نہیں کیا جا سکتا۔ ورک اسپیسز کی کوئی مقررہ تعداد نہیں ہے؛ یہ ایک ہی عمل کو شیئر کرتے ہیں، لہٰذا صلاحیت مشین پر منحصر ہوتی ہے۔

لائو پینل ٹوکن آپ کی ٹیلیگرام اجازتوں اور محفوظ کردہ مواد تک رسائی کو محفوظ کرتا ہے؛ یہ ٹیلیگرام API کی شناختی معلومات سے الگ ہے۔ صرف ایک واضح طور پر شروع کیا گیا اور براہِ راست رسائی والا مقامی ڈیمو خودکار طور پر داخل ہوتا ہے۔ ایک دور دراز/پراکسی شدہ ڈیمو اب بھی `data/demo/panel-token.txt` استعمال کرتا ہے۔

## نظرثانی اور برآمد

- **جرنل:** ماخذ اور واقعے کی قسم کے لحاظ سے مشاہدات تلاش اور فلٹر کریں۔
- ایک واقعہ منتخب کریں تاکہ اس کے اصل ریکارڈ، منسوبہ کاری اور محفوظ شدہ ورژنز کا معائنہ کیا جا سکے۔
- ترتیب میں ترمیم کرنے سے دستیاب پہلے/بعد کے مواد کو دکھاتا ہے۔ حذف کرنے کی تفصیلات میں آخری محفوظ شدہ مواد دکھایا جاتا ہے، اگر کوئی ہو؛ ایک نامعلوم فریق نامعلوم ہی رہتا ہے۔
- **ایکسپورٹس:** دستخط شدہ ZIP، JSONL، CSV اور آف لائن HTML۔
- **مکمل چیٹ ایکسپورٹ** (Sources → Full chat export): ایک چیٹ کی پوری دکھائی دینے والی تاریخ کو ایک دستخط شدہ بنڈل کے طور پر ڈاؤن لوڈ کریں جس میں `chat.json` (Telegram-export طرز) اور ایک قابلِ مطالعہ `chat.html` شامل ہو۔ نجی چیٹس اس وقت کام کرتی ہیں جب اکاؤنٹ رکن ہو۔ یہ ایک موجودہ سنپ شاٹ ہے، حذف شدہ یا پہلے ترمیم شدہ پیغامات کی تعمیرِ نو نہیں۔ ایک کاپی کی تصدیق `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256` کے ساتھ کریں۔
- **چیک پوائنٹ محفوظ کریں:** دستخط شدہ جرنل کی حد کو کلیکٹر کے باہر رکھیں۔
- **دستیاب شدہ رن رسید ڈاؤن لوڈ کریں:** کلیکٹر کے پروگرام/ورژن کا ریکارڈ محفوظ کریں۔
- **ٹائم اسٹیمپ کی درخواست تیار کریں:** ٹائم اسٹیمپ اتھارٹی کے لیے آف لائن درخواست تیار کریں؛ جواب حاصل کرنے اور اس کی تصدیق کے لیے [TIMESTAMP.md کی](../TIMESTAMP.md) ہدایات پر عمل کریں۔
- **جرنل کی تصدیق کریں:** ایونٹ سگنیچرز اور چین لنکس چیک کریں۔ زپ ایکسپورٹ میڈیا بھی چیک کرتا ہے۔

مدعومہ براؤزرز بڑے ایکسپورٹس کو براہِ راست منتخب کردہ فائل میں محفوظ کرتے ہیں۔ دیگر براؤزرز زیادہ سے زیادہ 128 MiB تک بفر کرتے ہیں۔ جب سرور چل رہا ہو، تو اسٹریمنگ CLI پورے جواب کو بفر کیے بغیر بڑے ڈاؤن لوڈز کی حمایت کرتا ہے:

```sh
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

دوسرے ورک اسپیس کے لیے، **Exports → Workspace ID** کے ذریعے `--profile ID` شامل کریں۔ ریموٹ سرور کے لیے، `--url https://your-server` شامل کریں۔ ڈیفالٹ ٹرانسفر حد 5 GiB ہے؛ `--max-mib` اسے تبدیل کرتا ہے۔ سائن شدہ ZIP مواد کے لیے ڈیفالٹ طور پر 4 GiB کی الگ غیر کمپریسڈ تصدیقی حد ہوتی ہے (**Parameters** اسے بڑھاتا ہے؛ ایسے آرکائیوز کو `verify.py --max-gib N` کے ساتھ تصدیق کریں)۔ آرکائیو کو ایک معتبر Verifier کی کاپی اور ایک آزادانہ طور پر محفوظ کردہ کلید کے فنگر پرنٹ/چیک پوائنٹ کے ذریعے تصدیق کریں۔

## انسٹالیشن چیک کریں

```sh
python start.py --setup-only
python start.py --check
python start.py --check --json
```

`--check` مقامی انحصار، دستخط کی حمایت، ذخیرہ، کلید کی تشکیلات اور سننے کے پتے کا جائزہ لیتا ہے۔ یہ کچھ بھی انسٹال نہیں کرتا اور ٹیلیگرام سے منسلک نہیں ہوتا۔ مصروف پورٹ کا مطلب ہو سکتا ہے کہ کوئی اور مثال چل رہی ہے۔ مختلف `--port` استعمال کریں یا پہلے اسے روک دیں۔

لانچر `.venv` میں انسٹال ہوتا ہے۔ ضمنی `python -m tgwitness...` کمانڈز کو ونڈوز پر `.venv\Scripts\python.exe` یا لینکس/macOS پر `.venv/bin/python` استعمال کرنا چاہیے، جب تک کہ وہ ماحول پہلے سے فعال نہ ہو۔

## سیشنز، تحفظ اور آپریشن

ایک بند، مستقل Telethon SQLite `.session` کو مقامی طور پر `python -m tgwitness.sessions account.session --out account.tgwitness-session` کے ذریعے تبدیل کیا جا سکتا ہے، پھر اکاؤنٹ میں لوڈ کیا جا سکتا ہے۔ براہِ راست فائل امپورٹ اور QR لاگ ان بھی دستیاب ہیں۔ لاگ ان فارمیٹس، SOCKS5، HTTP CONNECT، MTProxy اور بیرونی ماسٹر کیز کے لیے [CONNECTION-SECURITY.md](../CONNECTION-SECURITY.md) دیکھیں۔

**مشاہدہ معطل کرنے سے** جمع بندی رک جاتی ہے۔ **لاک** صرف براؤزر کی رسائی بند کرتا ہے۔ ٹیب بند کرنے سے کلیکٹر کا عمل چلتا رہتا ہے۔ عمل کو روکنے سے جمع بندی منقطع ہو جاتی ہے؛ ہسٹری کا اسنیپ شاٹ تمام چھوٹی گئی ترامیم یا حذف شدہ مواد کو دوبارہ ترتیب نہیں دے سکتا۔ دیکھیں کہ ایونٹ پالیسیاں، منسلکات کی قطاریں، اکاؤنٹ کی علیحدگی، اور دوبارہ شروع کرنے کے رویے کے لیے [جمع بندی کیسے کام کرتی ہے۔](../COLLECTION.md)

سیشنز اور سیکرٹس انکرپٹڈ ہیں۔ پیغام کا مواد، میڈیا اور ایکسپورٹس کے لیے ایک انکرپٹڈ ڈسک یا والیوم ضروری ہے۔ سگنیچرز ایک معتبر کلید کے حوالے سے سالمیت کا تعین کرتے ہیں؛ یہ ٹیلیگرام کے ماخذ ہونے کی تصدیق نہیں کرتے اور نہ ہی اس آپریٹر کی جانب سے جعلسازی کو روکتے ہیں جو کلیکٹر اور اس کی کلید پر قابو رکھتا ہو۔
