Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/

まずは最初のキャプチャを取得し、証拠の仕組みを確認してから、必要な設定を構築してください。

## 最初にキャプチャされたメッセージ

[### 数分で始められます サンプルデータを使ってTgWitnessをお試しいただき、その後、Windows、Linux、またはmacOS上で独自のTelegram監視ワークスペースを立ち上げてみてください。](https://phishdestroy.github.io/TgWitness/ja/docs/start/)[### 専用アカウント 収集用に別のTelegramアカウントを用意してください。](https://phishdestroy.github.io/TgWitness/ja/docs/dedicated-account/)[### アカウントを連携する QRコード、電話番号、またはセッションのインポートにより、Telegramを接続してください。ソースを選択し、新しいメッセージがジャーナルに正常に反映されることを確認してください。](https://phishdestroy.github.io/TgWitness/ja/docs/accounts/)[### プロキシを選択してください MTProxyの自動ルーティングを維持するか、独自のプロキシをご利用ください。IPモード、フォールバックルール、および外部リクエストのルーティングを選択してください。](https://phishdestroy.github.io/TgWitness/ja/docs/proxies/)[### エクスポートと検証 キャプチャしたTelegramの履歴をエクスポートし、署名を検証し、ジャーナルを独立した証人が保持しているチェックポイントと比較することができます。](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)[### GitHub Actionsのキャプチャ 一時的な GitHub Runner 上で、Telegram のチャットを 1 件エクスポートします。](https://phishdestroy.github.io/TgWitness/ja/docs/capture/)

## 実際に試して学んでみましょう

[### 証拠の仕組みをご覧ください メッセージの取得からチェックポイントまでの流れを追跡します。サンプルレコードを変更し、そのSHA-256チェーンを再計算して、保持されているチェックポイントが何を検出するかを確認してください。](https://phishdestroy.github.io/TgWitness/ja/docs/concepts/)[### すべてのチャットを横断的に調査する チャンネル、グループ、プライベートチャット、ボットを横断して、Telegramの調査をエンドツーエンドで実施します。アカウント全体のキャプチャ、履歴、参加者、リンク、ファイル、タイムライン、および検証済みの証拠を網羅します。](https://phishdestroy.github.io/TgWitness/ja/docs/cases/)[### セキュリティを確保してください セッション、鍵、証拠データの保存場所、端末から送信される情報、保護対象の範囲、およびインストールのセキュリティ強化方法についてご確認ください。](https://phishdestroy.github.io/TgWitness/ja/docs/security/)

## 必要な情報のみを追加してください

[### アーカイブの操作 履歴の読み込み、保存された記録の検索、AIソースの確認、およびツールの連携が可能です。](https://phishdestroy.github.io/TgWitness/ja/docs/archive/)[### 事例を共有する レビュー担当者やアナリストに対し、個別の権限、セッション制限、および取り消し可能なトークンを設定して、選択されたアカウントやチャットへのアクセス権を付与します。](https://phishdestroy.github.io/TgWitness/ja/docs/access/)[### Witnessボットの設定 署名済みのジャーナルのチェックポイントを、個別のウィットネス、独自の鍵、および読み取り専用コレクターアクセス権を設定して、Telegramチャンネルに公開できます。](https://phishdestroy.github.io/TgWitness/ja/docs/witness/)[### 稼働を継続してください TgWitnessは、永続的なストレージ、プライベートパネルへのアクセス、バックアップ機能、および再起動後のチェック機能を備えたサーバー上で実行してください。](https://phishdestroy.github.io/TgWitness/ja/docs/server/)[### 何が問題だったのかを確認する 各問題に応じた適切なシグナルを使用して、パネルへのアクセス状況、Telegramとの接続状況、メッセージの欠落、FloodWait、およびWitnessのステータスを確認してください。](https://phishdestroy.github.io/TgWitness/ja/docs/troubleshooting/)
