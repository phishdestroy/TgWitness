# Pemberitahuan mengenai lisensi dan ketidakcocokan arsitektur

Canonical page: https://phishdestroy.github.io/TgWitness/id/docs/reference/license/

TgWitness dilisensikan di bawah lisensi MIT untuk semua orang, dan mengapa alat ini secara arsitektural tidak kompatibel dengan alur kerja Taylor Wessing.

TgWitness didistribusikan di bawah [Lisensi MIT](https://phishdestroy.github.io/TgWitness/LICENSE). Posisi kami tidak menambahkan syarat lisensi apa pun.

> Sebuah tanda tangan tidak mengubah kebohongan menjadi fakta.
>
>
>
> TgWitness tidak cocok untuk perusahaan, firma hukum, atau individu yang percaya bahwa menempatkan "Dr." di depan nama membuat apa pun yang mengikutinya menjadi benar. Gelar, kop surat, dan tanda tangan tidak mengesampingkan bukti.
>
>
>
> Jika alur kerja Anda dimulai dengan kesimpulan yang telah dibayar oleh klien dan mengharuskan catatan mengikuti kesimpulan tersebut, Anda sedang mencari alat yang berbeda. TgWitness hadir untuk melestarikan catatan dan membuatnya terbuka untuk pemeriksaan.
>
>
>
> Biarkan para “dokter” itu mengurus neraca keuangan klien korporat mereka. Sebuah gelar tidak dapat menyembuhkan kebohongan.
>
>
>
> Matematika tidak bernegosiasi.
