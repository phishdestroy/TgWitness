# Comece em poucos minutos

Canonical page: https://phishdestroy.github.io/TgWitness/pt/docs/start/

Explore a demo primeiro e depois conecte sua própria conta.

## Navegue pelo site sem precisar de uma conta

Baixe o projeto, tenha **Python 3.11 ou mais recente** e rode a demo. O inicializador cuida do resto.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

Um espaço com mensagens inventadas abre no navegador. Abra um chat, compare uma edição, olhe uma exportação. O Telegram não participa.

![Visualização de conversas no TgWitness com exemplos de mensagens](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Um exemplo de área de trabalho. Seu próprio registro é iniciado separadamente.

## Crie seu próprio espaço de trabalho

Feche a demo e então:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Abra o endereço mostrado pelo inicializador e cole o **token de acesso ao painel** do arquivo indicado. Ele é do TgWitness, não do Telegram.

## Registre sua primeira mensagem

1. [Conecte uma conta dedicada do Telegram.](https://phishdestroy.github.io/TgWitness/pt/docs/accounts/)
2. Escolha um grupo ou canal e inicie a observação.
3. Envie uma mensagem no seu grupo de teste e veja-a aparecer no diário.

Para a instalação em servidor, siga as instruções em [“Keep it running](https://phishdestroy.github.io/TgWitness/pt/docs/server/)”.
