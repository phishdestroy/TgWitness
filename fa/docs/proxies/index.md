# Telegram · یک پروکسی انتخاب کنید

Canonical page: https://phishdestroy.github.io/TgWitness/fa/docs/proxies/

حساب را آنلاین نگه دارید و خودتان تصمیم بگیرید که آیا اصلاً مجاز است IP سرور شما را نشان دهد.

## ابتدا حالت IP را انتخاب کنید

01**پنهان کردن آدرس**

فقط پروکسی. اگر هیچ‌کدام کار نکند، صبر می‌کند.

02**به‌عنوان آخرین راه‌حل**

پس از تأخیری مستقیم وصل می‌شود و به محض کار کردن یک پروکسی به آن برمی‌گردد.

03**سرور پشت تونل یا VPN**

اتصال مستقیم مشکلی ندارد. VPN را برای شما تنظیم یا بررسی نمی‌کند.

مسیر، اتصال را انتخاب می‌کند. حالت IP تعیین می‌کند که آیا اتصال مستقیم مجاز است یا خیر.

## بگذارید استخر مسیر را حفظ کند

1. **حساب ← تنظیمات ← تنظیمات اتصال**.
2. حالت IP و **MTProxy خودکار**، یا یک مسیر ثابت را انتخاب کنید.
3. ذخیره کنید، **آزمایش اتصال Telegram** (پیش از ورود هم کار می‌کند).
4. جمع‌آوری را شروع کنید و برای خودتان پیام آزمایشی بفرستید.

فضاهای کاری جدید با MTProxy خودکار و **پنهان کردن آدرس** شروع می‌شوند. استخر چهار فهرست عمومی را می‌گیرد، سرورها را بررسی می‌کند، خوب‌ها را نگه می‌دارد و مرده‌ها را عوض می‌کند.

## از پروکسی خود استفاده کنید

SOCKS5، HTTP CONNECT، لینک پروکسی Telegram یا کاتالوگ اپراتور. پیش از تغییر، مشاهده را متوقف کنید. رازهای Fake TLS (`ee`…) کار نمی‌کنند.

**تنظیمات چرخش، اشتراک‌گذاری و تلاش مجدد**

**پارامترها ← MTProxy خودکار**: آستانه‌های خطا، زمان‌های استراحت، چرخش، تعداد حساب برای هر پروکسی. حد 1 یعنی حساب به‌جای اشتراک صبر می‌کند. پروکسی‌های مختلف همچنان ممکن است IP خروجی مشترک داشته باشند.

## جدا کردن تلگرام از درخواست‌های خارجی

MTProxy فقط Telegram را حمل می‌کند. مهرهای زمانی، اعلان‌ها، کپی‌ها و بررسی‌های کد از یک پروکسی SOCKS5/HTTP جداگانه، مسیر SOCKS5/HTTP حساب، یا اگر حالت اجازه دهد مستقیم می‌روند. یا خاموششان کنید.

`TGWITNESS_PROXY_FEED_PROXY` مسیر دانلود فهرست‌ها را تعیین می‌کند. [شاهد](https://phishdestroy.github.io/TgWitness/fa/docs/witness/) تنظیمات خودش را دارد. هیچ‌کدام از این‌ها به مرورگر یا شبکه سیستم شما دست نمی‌زند.
