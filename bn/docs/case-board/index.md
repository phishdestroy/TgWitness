# একটি কেস বোর্ড তৈরি করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/case-board/

সংরক্ষিত টেলিগ্রাম পর্যবেক্ষণগুলোকে একটি কেসে রূপান্তর করুন, যা আপনার দল একসঙ্গে পর্যালোচনা করতে পারে।

Case Board বুকমার্ক, সঠিক-পাঠ হাইলাইট, সংরক্ষিত স্লাইস এবং আলোচনাকে তাদের উৎস রেফারেন্সের পাশে রাখে। একটি সংগ্রহ কেসকে একটি কার্যকরী কাঠামো প্রদান করে; স্বাক্ষরিত সংশোধনসমূহ দল কীভাবে এটি তৈরি করেছে তা সংরক্ষণ করে।

## বার্তা থেকে কেস কার্ডে

1. **অন্বেষণ → কেস বোর্ড** স্ট্যান্ডার্ড বা এক্সপার্ট মোডে খুলুন। মামলার জন্য একটি সংগ্রহ তৈরি করুন এবং এর চ্যাট স্কোপ নির্বাচন করুন।
2. **জার্নাল** বা সংরক্ষিত চ্যাটে, **'To board**' নির্বাচন করুন, অথবা রেকর্ডটিতে ফোকাস করে **B** চাপুন। কার্ডটি ইনবক্সে প্রবেশ করবে; একটি উপযোগী শিরোনাম দিন এবং এটি আপনার সংগ্রহে সরান।
3. সংরক্ষিত চ্যাট বার্তার একটি অংশ নির্বাচন করুন এবং সঠিক উদ্ধৃতি ও বার্তার সংস্করণ ধরে রাখতে **Highlight → board** নির্বাচন করুন। কেন এটি গুরুত্বপূর্ণ তা ব্যাখ্যা করে একটি নোট যোগ করুন।
4. কার্ডটি আলোচনা করুন, পর্যালোচনা অবস্থা নির্ধারণ করুন, এবং যখনই কোনো দাবী যাচাই করার প্রয়োজন হয়, তখন তার উৎস প্রসঙ্গে ফিরে যান। সহকর্মীদের সাথে সংগ্রহটি পর্যালোচনা করতে **Presentation** ব্যবহার করুন।

### একটি পরিবর্তিত পেমেন্ট লিঙ্ক অনুসরণ করুন

কৃত্রিম উদাহরণ · স্থানীয় চিত্রায়ন

1. **ক্যাপচার করুন।** সংরক্ষিত পর্যবেক্ষণ #142 এবং এর বার্তা সংস্করণ খুলুন।
2. **বুকমার্ক।** উদ্ধৃতি, উৎস রেফারেন্স এবং আপনার প্রশ্ন একটি কার্ডে রাখুন।
3. **পর্যালোচনা।** একটি টিম মন্তব্য যোগ করুন এবং কার্ডটি পর্যালোচনা ধাপে সরান।
4. **উপস্থাপিত।** সংগ্রহের মধ্য দিয়ে যান এবং উদ্ধৃত উৎসের প্রসঙ্গ খুলুন।

অ্যানোটেশন এবং টেলিগ্রাম পর্যবেক্ষণ পৃথকভাবে শনাক্তযোগ্য থাকে।

## একবার একটি দরকারী পরিসর সংরক্ষণ করুন

একই চ্যাটে Shift-click করে দুটি রেকর্ড **সিলেস বিটুইনের** জন্য **নির্বাচন** করুন, **সময় অনুযায়ী স্লাইস** নির্বাচন করুন, অথবা বর্তমান জার্নাল ফিল্টার সংরক্ষণ করুন। সংরক্ষণের আগে গণনা পর্যালোচনা করুন। স্লাইস পুনরায় খুলে সংরক্ষিত কুয়েরি প্রয়োগ করুন; **বুকমার্কের** পর **যোগ হওয়া রেকর্ডগুলো দেখাতে 'bookmark since**' নির্বাচন করুন।

সংগ্রাহকের পর্যবেক্ষণ সময়ের পর একটি সময় স্লাইস অনুসরণ করে। নির্বাচিত বার্তাগুলির পর একটি মেসেজ-আইডি স্লাইস অনুসরণ করতে পারে যখন পরবর্তী পরিবর্তনগুলি আসে। সংরক্ষিত সৃষ্টির সীমা প্রাপককে মূল নির্বাচন এবং এর পরবর্তী অবস্থার তুলনা করতে দেয়।

## প্রতিটি সহকর্মীকে সঠিক ভূমিকা দিন

**রিভিউকারী** বোর্ডটি পড়ে; **বিশ্লেষক** কার্ড এবং মন্তব্য যোগ করে; **অপারেটর** সংগ্রহ এবং পর্যালোচনা সিদ্ধান্তও পরিচালনা করে। ওয়ার্কস্পেস এবং চ্যাট অনুমতি কার্ড, উৎস প্রসঙ্গ এবং আলোচনায় প্রযোজ্য। স্পষ্ট স্বীকৃতির জন্য নামকৃত অ্যাক্সেস গ্রান্ট ব্যবহার করুন।

## কাজটিকে একটি ডেলিভারযোগ্য ফরম্যাটে উপস্থাপন করুন

একটি স্লাইস স্বাক্ষরিত JSON হিসেবে রপ্তানি করুন, অথবা স্প্রেডশিটের জন্য CSV ব্যবহার করুন। রিপোর্ট সেটিংসে বুকমার্ক এবং স্লাইস অন্তর্ভুক্ত থাকতে পারে, নির্বাচিত হলে দলের মন্তব্যসহ। এই বিষয়বস্তুগুলো [রিপোর্ট](https://phishdestroy.github.io/TgWitness/bn/docs/reports/)স্টুডিওতে নির্বাচন করুন; সংরক্ষিত স্লাইস স্বয়ংক্রিয়ভাবে রিপোর্ট কনফিগার করে না। সীমাবদ্ধ প্রাপকের জন্য পৃথক [হস্তান্তর নিয়ন্ত্রণ](https://phishdestroy.github.io/TgWitness/bn/docs/handover/) ব্যবহার করুন।

স্বাক্ষরিত সংশোধন, সঠিক উদ্ধৃতি মিলान, নির্বাচন যাচাইকরণ এবং অনুমতিসমূহের জন্য [Case Board রেফারেন্স](https://phishdestroy.github.io/TgWitness/bn/docs/reference/case-board/) পড়ুন।
