# Telegram · התחילו תוך דקות ספורות

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/start/

הסתובבו קודם בהדגמה, ואז חברו את החשבון שלכם.

## תסתכלו מסביב ללא צורך בחשבון

הורידו את הפרויקט, ודאו שיש **Python 3.11 ומעלה**, הריצו את ההדגמה. המפעיל מסדר את כל השאר.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

סביבת עבודה עם הודעות מומצאות נפתחת בדפדפן. פתחו צ'אט, השוו עריכה, הסתכלו על ייצוא. Telegram לא מעורב.

![תצוגת שיחה ב-TgWitness עם דוגמאות להודעות](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

דוגמה לסביבת עבודה. היומן האישי שלכם מתחיל בנפרד.

## הקימו סביבת עבודה משלכם

סגרו את ההדגמה, ואז:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

פתחו את הכתובת שהמפעיל מציג והדביקו את **טוקן הגישה ללוח** מהקובץ שהוא מציין. זה בשביל TgWitness, לא Telegram.

## תעד את ההודעה הראשונה שלך

1. [חבר חשבון טלגרם ייעודי.](https://phishdestroy.github.io/TgWitness/he/docs/accounts/)
2. בחרו קבוצה או ערוץ והתחילו מעקב.
3. שלחו הודעה בקבוצת הבדיקה וצפו בה מופיעה ביומן.

להתקנת שרת, עקבו אחר ההוראות [ב-Keep it running](https://phishdestroy.github.io/TgWitness/he/docs/server/).
