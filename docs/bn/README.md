## ইনস্টল

Python সঙ্গেই আছে। আপডেটের জন্যও একই কমান্ড চালান।

**Linux / macOS**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**Windows · PowerShell বা CMD**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

<sub>Ubuntu সার্ভার: root হিসেবে চালান। ডেস্কটপ: আপনার সাধারণ ব্যবহারকারী হিসেবে চালান। `-ExecutionPolicy Bypass` শুধু এই একটি PowerShell প্রসেসে প্রযোজ্য।</sub>

স্বাক্ষরিত বিল্ড আসে পাবলিক [ইনস্টলার ওয়ার্কফ্লো](../../.github/workflows/installer.yml) থেকে, আর ইনস্টল করার আগে ইনস্টলার প্রতিটি প্যাকেজের SHA-256 ও RSA স্বাক্ষর যাচাই করে।

[আগে স্ক্রিপ্ট যাচাই করুন](../INSTALLATION.md#verify-before-running) · [প্রথম সেটআপ](../SETTINGS.md) · [রিলিজ](https://github.com/phishdestroy/TgWitness/releases) · [Docker](../DEPLOYMENT.md)

## এমন রেকর্ড, যা অন্য কেউ যাচাই করতে পারে

অ্যাকাউন্ট বা ইনস্টল ছাড়াই যাচাই করুন। প্রকাশিত নমুনার ভেতরেই তার নিজস্ব যাচাইকারী আছে:

```sh
curl -LO https://phishdestroy.github.io/TgWitness/demo/downloads/tgwitness-demo.zip
unzip -o tgwitness-demo.zip verify.py        # যাচাইকারী আর্কাইভের ভেতরেই থাকে
python verify.py tgwitness-demo.zip          # Python 3.11+, শুধু `cryptography` লাগে
```

এটি স্বাক্ষরিত রেকর্ড, নতুনতম রেকর্ডের হ্যাশ ও স্বাক্ষরকারীর ফিঙ্গারপ্রিন্ট দেখায় এবং কোড `0` দিয়ে শেষ হয়।
নমুনাটি কাল্পনিক; একই যাচাইকারী যেকোনো আসল রপ্তানিতে চলে।

রপ্তানিতে থাকে বার্তা, ফাইল এবং যাচাইকারী। প্রাপককে আপনার
কী ফিঙ্গারপ্রিন্ট অন্য কোনো চ্যানেলে পাঠান, তাহলে তিনি নিজেই এটি যাচাই করতে পারবেন:

```sh
python -m tgwitness.verify evidence.zip --fingerprint TRUSTED_SHA256 --tsa-ca TSA-ROOT.pem --require evidence
```

যাচাইকারী স্বাক্ষর, জার্নালের শৃঙ্খল, ফাইলের তালিকা ও সংযুক্তি যাচাই করে।
প্রমাণ হিসেবে গণ্য হতে এর দরকার আপনার কী ফিঙ্গারপ্রিন্ট এবং শেষ রেকর্ডকে আওতায় নেওয়া
তৃতীয় পক্ষের টাইমস্ট্যাম্প, যেমন কর্তৃপক্ষের রুট সার্টিফিকেট দিয়ে যাচাই করা RFC 3161 টাইমস্ট্যাম্প।

**বার্তাগুলো কোথা থেকে আসে।** TgWitness অফিসিয়াল অ্যাপের মতোই অ্যাকাউন্টের এনক্রিপ্ট করা
MTProto সেশনের মাধ্যমে Telegram থেকে বার্তাগুলো গ্রহণ করে, এবং প্রতিটি বার্তা আসামাত্র
স্বাক্ষর করে জার্নালে লেখে। [GitHub Actions ক্যাপচার](../SEALED-ACTIONS.md) এবং
[Phala Intel TDX](../HIGH-ASSURANCE.md) বার্তাগুলো গ্রহণকারী সংগ্রাহকেরও প্রত্যয়ন দেয়।

**মামলার প্রমাণ**। উত্তর থেকেই লক্ষ্য ও ইন্টারফেসের স্তর ঠিক হয়, তাই
প্যানেল শুধু সেই কাজের প্রয়োজনীয় বিভাগগুলো দেখায়। এরপর পাঁচটি ধাপে আসে সংযোগ, Telegram সাইন-ইন এবং
চ্যাট বাছাই। সংযোগ পরীক্ষা নিজে থেকেই চলে, আর
রুটের বিকল্পগুলো খোলে কেবল তা ব্যর্থ হলে। বিশেষজ্ঞ টুলগুলো মাত্র একটি সুইচ দূরে।

**সিস্টেম মানচিত্র** দেখায় ইনস্টলেশন কীভাবে Telegram ও বাইরের
সেবাগুলোতে পৌঁছায়: প্যানেল অ্যাক্সেস, প্রতিটি অ্যাকাউন্টের রুট ও Telegram গন্তব্য, জার্নাল ও
সাক্ষীর পথ, এবং সর্বশেষ নেটওয়ার্ক পর্যবেক্ষণ। কোনো পর্যবেক্ষণ না থাকলে তা
অনুপস্থিত হিসেবেই চিহ্নিত হয়।

TgWitness সংযুক্ত Telegram অ্যাকাউন্টে পৌঁছানো বিষয়বস্তু রেকর্ড করে, সঙ্গে থাকে
চ্যাট, বার্তা ও প্রেরকের শনাক্তকারী, ক্যাপচার করা সংস্করণ এবং সংগ্রহের মেটাডেটা।
আর্কাইভ এই রেকর্ড, সংরক্ষিত সংযুক্তি ও যাচাইয়ের ডেটা
পর্যালোচনার জন্য একসঙ্গে আনে।

| যাচাই | প্রাপক কী যাচাই করেন |
| --- | --- |
| স্বাক্ষরিত জার্নাল ও ম্যানিফেস্ট | প্রত্যাশিত স্বাক্ষর কী-এর সঙ্গে রেকর্ডের স্বাক্ষর, হ্যাশ শৃঙ্খল ও হস্তান্তর করা ফাইল। |
| আলাদাভাবে সংরক্ষিত চেকপয়েন্ট | আগে রেকর্ড করা দৈর্ঘ্য ও নতুনতম রেকর্ডের হ্যাশের সঙ্গে জার্নাল। |
| স্বতন্ত্র সাক্ষী | একটি পৃথক সাক্ষীর রাখা চেকপয়েন্টের সঙ্গে জার্নাল। |
| GitHub Actions ক্যাপচার | এর প্রত্যয়ন, অনুমোদিত হোস্টেড ওয়ার্কফ্লো ও সংগ্রাহকের সংস্করণের সঙ্গে আর্কাইভ। |

[Export Clinic](https://phishdestroy.github.io/TgWitness/docs/export-clinic/)
একটি Telegram কথোপকথনকে ইচ্ছাকৃতভাবে বদলানো Desktop রপ্তানি ফাইলের পাশাপাশি দেখায়।
সংস্করণগুলো তুলনা করুন, পরিবর্তনগুলো পরীক্ষা করুন, এবং স্বাক্ষরিত TgWitness আর্কাইভের
সংগ্রহ ও যাচাইয়ের ধাপগুলো অনুসরণ করুন।
