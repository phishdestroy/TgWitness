# Telegram · Підготуйте копію для поширення

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/handover/

Діліться лише потрібним, оригінал лишається недоторканим.

Передача — це окрема підписана виписка: оберіть чати й людей, приховайте особи чи текст, відберіть файли й нотатки команди. Маніфест фіксує, що лишено, скорочено й виключено.

## Підготуйте витяг для одержувача

1. **Експорт → Виписка для передачі**: вкажіть мету, оберіть чати й період, **Завантажити людей вибраних чатів**, якщо потрібні конкретні люди.
2. Усі інші: псевдоніми, виключення або як записано. Текст і файли вмикаються окремо, телефони й пошту можна приховати.
3. Case Board: нічого, закладки й зрізи або картки з коментарями. Імена команди можна замінити псевдонімами.
4. **Завантажити виписку для передачі**, відкрийте, перевірте, перегляньте перед відправленням.

### Один оригінал, одна копія для поширення

Синтетичний приклад · наведено лише для ілюстрації

1. **Виберіть.** Включіть чат справи та вкажіть особу, про яку йдеться у витягу.
2. **Зменшуйте обсяг тексту.** Вибирайте, як інший учасник відображатиметься у копії, що надається для спільного доступу.
3. **Перевірте.** Відкрийте згенерований звіт та записи архіву перед відправленням.
4. **Поділіться.** Надішліть перевірений текст та окремо повідомте його надійний цифровий відбиток.

#### Початкове зауваження

Нора · користувач 71002

«Я отримав переглянуте посилання».

Журнал джерел зберігає ці збережені спостереження.

#### Копія для одержувача

Показати так, як записано: Нора · користувач 71002 · «Я отримала оновлене посилання».

Псевдонім: P01 · «Я отримав оновлене посилання».

Опустити: повідомлення цього учасника не включається до тексту.

#### Перегляньте фактичні файли

Ознайомтеся з файлами report.html та records.jsonl.

Перевіряйте ідентифікаційні дані, текст, вкладення та додаткові коментарі команди.

#### Підписаний витяг

Вибір + хеші файлів + підписаний маніфест

Окремий пакет, пов’язаний із межами вихідного журналу

## Використовуйте ці елементи управління разом

| Контроль | Вплив на текст |
| --- | --- |
| Люди | Вибрані люди лишаються названими, інші отримують псевдоніми або виключаються. |
| Текст | Увесь текст, лише текст вибраних людей і вашого акаунта або жодного. |
| Файли | Файли вибраних людей і вашого акаунта, усі показані файли або жодних. |
| Дошка випадків | Нічого, закладки й зрізи або картки з обговоренням. |

Прочитайте і сам текст, і файли: псевдонім не прибирає імен, написаних усередині повідомлення чи вкладення. Якщо вибраного файлу немає, відновіть його або виключіть вкладення.

## Текст має бути таким, щоб його можна було незалежно перевірити

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

Оригінальний архів і контрольні точки зберігайте в себе. Отримувач може перевірити свою копію, не отримуючи весь простір. Оформлення: [Report studio](https://phishdestroy.github.io/TgWitness/uk/docs/reports/). Довірені посилання: [перевірка експорту](https://phishdestroy.github.io/TgWitness/uk/docs/exports/).
