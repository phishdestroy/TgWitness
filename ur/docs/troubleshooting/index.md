# پتہ لگائیں کہ کیا غلط ہوا

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/troubleshooting/

علامت سے شروع کریں۔ ایک ایک پرت کی جانچ کریں۔

## پینل ایک ٹوکن طلب کرتا ہے

لانچر میں دکھائی گئی مقامی فائل سے پینل ٹوکن استعمال کریں۔ Docker کے لیے `docker compose exec tgwitness cat /data/panel-token.txt` چلائیں۔ ٹیلیگرام لاگ ان کوڈ، BotFather ٹوکن اور ریڈ-اوನ್لی وِٹنس ٹوکن کے مختلف مقاصد ہیں۔

## ٹیلیگرام کنیکٹ نہیں ہوتا

کنیکشن کی ترتیبات کھولیں اور کنیکشن چیک چلائیں۔ اگر عوامی پراکسی استعمال کر رہے ہیں تو کوئی دوسرا اندراج آزمائیں اور راستہ واضح طور پر محفوظ کریں۔ پراکسی کی قسم اور سپورٹڈ خفیہ فارمیٹ چیک کریں۔ عوامی فہرست کو ریفریش کرنے سے اکاؤنٹ کا راستہ تبدیل نہیں ہوتا۔

## منسلک ہے، لیکن کوئی نئے پیغامات نہیں۔

1. تصدیق کریں کہ مشاہدہ درست ورک اسپیس میں چل رہا ہے۔
2. تصدیق کریں کہ ماخذ منتخب ہے اور اس اکاؤنٹ کے لیے دکھائی دے رہا ہے۔
3. ایک کنٹرول شدہ گروپ میں ایک منفرد نیا پیغام بھیجیں اور بالکل اسی متن کو تلاش کریں۔
4. آپریشنل جرنل کا جائزہ لیں تاکہ رکاوٹیں، کام میں تاخیر یا ٹیلیگرام کی غلطیوں کا پتہ چل سکے۔

تاریخی سنپ شاٹس اور نئے پیغامات کے واقعات مختلف ہیں۔ ایک خاموش ماخذ کو نئے پیغامات پیدا کیے بغیر منسلک کیا جا سکتا ہے۔ جب مکمل ہونے کا معاملہ ہو تو کنٹرول شدہ ترسیل کے ٹیسٹ کا استعمال کریں۔

## FloodWait یا دوبارہ شروع کرنے کے بعد وقفہ

FloodWait کا مطلب ہے کہ ٹیلیگرام کو وقفے کی ضرورت ہے۔ دریافت کردہ مدت تک انتظار کریں اور جمع کرنے کے کام کا جائزہ لیں۔ بار بار دوبارہ کنکشن کرنے سے حد ختم نہیں ہوتی۔ محفوظ شدہ اپ ڈیٹ کی حالت ری اسٹارٹ کے بعد پیچھے رہ جانے والے کام کو پورا کرنے میں مدد دیتی ہے، لیکن ختم شدہ اپ ڈیٹس اور کچھ وقفے کی کھڑکیاں اب بھی محدودیت ہیں۔ جرنل کو مکمل سمجھنے کے بجائے وقفے کو ریکارڈ کریں۔

## بوٹ ترتیب دیا گیا ہے لیکن کچھ بھی پوسٹ نہیں کرتا

یقینی بنائیں کہ ویٹنس عمل درحقیقت چل رہا ہے، بوٹ چینل میں پوسٹ کر سکتا ہے اور ویٹنس کلیکٹر اور بوٹ API تک پہنچ سکتا ہے۔ ناکام اشاعتوں کے لیے اس کے جرنل کا معائنہ کریں۔ صرف ایک کامیاب کلیکٹر پول چینل پوسٹ کی تصدیق نہیں کرتا۔

## GitHub ٹوکن انٹیگریشن کہاں ہے؟

**منصوبہ بندی شدہ۔** اضافی میں مجوزہ فورک اور بلڈ کی تصدیق کے ورک فلو کی وضاحت کی گئی ہے۔ فی الحال کوئی GitHub ٹوکن فارم یا خودکار تصدیق موجود نہیں ہے کہ چلتی ہوئی تنصیب کسی ریپوزیٹری سے مطابقت رکھتی ہے۔ [موجودہ فیچر کی حیثیت](https://phishdestroy.github.io/TgWitness/ur/docs/reference/features/) دیکھیں۔

جب کسی مسئلے کی رپورٹنگ کریں تو ورژن، آپریٹنگ سسٹم، اقدامات اور ایک ترمیم شدہ خرابی شامل کریں۔ سیشنز، ٹوکنز، نجی پیغامات اور ڈیٹا ڈائریکٹری کو عوامی مسائل سے دور رکھیں۔
