# Witnessボットの設定

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/witness/

別のプロセスでジャーナルを検証させ、署名付きのチェックポイントをチャンネルに公開しましょう。

## 2つのホスト、2つの署名鍵

ホスト / コレクター**アカウント + ジャーナル**

Telegramセッションコレクターの署名鍵

読み取り専用チェックポイントのエンドポイント

← 署名付きの回答をリクエスト →

HOST B / WITNESS**検証＋保存**

固定されたコレクターのフィンガープリント 個別のWitness署名鍵

独自のジャーナル + ボットトークン

Witness → Telegram Bot API →**あなたのチャンネル · 署名付き TGW1 投稿**

Witnessは自身で検証を行います。コレクターへのアクセスは読み取り専用です。ボットによる公開には、Witnessの接続とトークンが使用されます。Witnessにはアカウントセッションは付与されません。

03 / チェックポイントの決定事項参考となる回答例

最終承認日**120件の記録**`head 9c7d…`

次の回答**128件の記録**`head a4f2…`

承認済み：カウントが増加し、署名が検証され、鍵が一致しました。Witnessはこの新しい境界を保持します。

すべての回答例は、有効な署名と固定鍵が存在することを前提としています。ここでのハッシュ値は、説明のための省略形です。ハッシュ値の合計数が大きいという事実だけでは、古いプレフィックス全体が変更されていないことを証明することはできません。チェックポイントが保持されているエクスポートデータと比較してください。

## ボットとチャンネルの準備

BotFatherを使用してボットを作成し、ご自身が管理するチャンネルへの投稿を許可してください。Witness用のコンピュータまたはサーバーを選択してください。収集者のサーバー上で別のプロセスを実行するよりも、独立したホストとオペレーターを用意することで、より強固な独立性が確保されます。

## 「Extras」の3つの手順

1. **読み取り専用アクセス.****追加情報 → 独立した証人**を開き、ウィットネストークンを作成してアクセスファイルを保存します。これにより、チェックポイントやヘルス状態を読み取ることができますが、会話やコレクターの制御機能にはアクセスできません。
2. **チャンネルと間隔。**TelegramチャンネルまたはDiscordのWebhookを選択し、ウィットネスからアクセス可能なコレクターアドレスを入力します。設定ファイルを保存します。
3. **起動。**`witness.json`、`witness-token.txt`、およびWitnessホスト上で作成された`bot-token.txt`を一緒に配置してください。インストール済みのプロジェクト環境で、以下のコマンドを実行してください。

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

ファイルをダウンロードしても、Witnessは起動しません。チャンネルに最初の署名付き投稿が表示されていることを確認し、Witnessの公開鍵のフィンガープリントを別途保存しておいてください。

Discord については、チャンネルの Webhook URL を `discord-webhook.txt` として保存してください。ウィットネスは、TelegramチャンネルまたはDiscordチャンネルのいずれか1か所に投稿します。Discordメッセージよりも長いチェックデータは、添付ファイルとして届きます。

## 公開頻度を選択してください

チェックを毎回公開することで、定期的な外部記録が作成されます。5分間隔の場合、ワークスペース1つあたり1日約288件の投稿となります。詳細設定では、変更や問題が発生した際の公開、プロキシ、およびカスタムBot APIアドレスの設定も可能です。

**このボットは実際には何を証明するのでしょうか？**

Witnessはコレクターに署名付きチェックポイントを要求し、期待される鍵と照合して検証を行い、別途署名付きジャーナルを保持します。成功した検証だけでなく、欠落した応答や拒否された回答も記録します。公開は、Witnessが稼働しており、TelegramのBot APIに接続できているかどうかに依存します。

本ツールは、コレクターから報告されたジャーナルの状態を確認するものです。Telegramのすべてのメッセージを独自に監視するものではありません。その場合は、「受信確認テスト」を追加してください。

## 後で証拠を確認してください

証言ジャーナル、チャンネルの投稿、および個別に保存されたフィンガープリントを保持してください。[完全な検証手順](https://phishdestroy.github.io/TgWitness/ja/docs/reference/witness/#verify)では、これらを収集者が署名したエクスポートデータと比較します。
