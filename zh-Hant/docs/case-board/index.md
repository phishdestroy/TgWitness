# Telegram · 建立「案件看板」

Canonical page: https://phishdestroy.github.io/TgWitness/zh-Hant/docs/case-board/

把保存的訊息變成團隊一起處理的案件。

書籤、精確引文、切片和討論，每一項都連結到來源。每次變更都是一個簽名修訂。

## 從訊息到案件卡片

1. **調查 → 案件看板**（標準或專家模式）。為案件建立一個集合。
2. 在**日誌**或聊天室中按**新增至案板**（或按 **B**）。卡片會進入收件匣，替它加上標題再移動。
3. 在訊息中選取文字，**標示 → 看板**會保存精確引文和版本。寫下它為什麼重要。
4. 討論、設定狀態，需要時隨時跳回來源。**簡報**帶團隊逐項瀏覽。

### 請點擊此已變更的付款連結

綜合範例 · 本地化說明

1. **擷取。**開啟已儲存的觀察紀錄 #142 及其訊息版本。
2. **加入書籤。**將引文、來源參考資料及您的問題記錄在卡片上。
3. **審核。**新增團隊評論並將卡片移至「審核」階段。
4. **當前。**逐步引導使用者進行資料蒐集，並開啟引用的來源上下文。

## 一次儲存一個實用的範圍

按住 Shift 點選兩則訊息進行**區間切片**，使用**按時間切片**，或儲存目前的日誌篩選條件。**顯示自書籤標記後新增的記錄**會顯示後來進來的內容。

時間切片使用觀察時間；訊息 ID 切片會跟著這些訊息的變化。

## 為每位同事分配適當的角色

**審閱者**閱讀，**分析師**新增卡片和留言，**操作員**還管理集合和決定。聊天室權限同樣適用於卡片。

## 將此工作轉化為可交付成果

切片可匯出為簽名 JSON 或 CSV。報告可以包含書籤、切片和留言，在 [Report studio](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/reports/) 中設定。對於受限的接收方，請使用[移交](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/handover/)。
