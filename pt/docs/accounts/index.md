# Conecte uma conta

Canonical page: https://phishdestroy.github.io/TgWitness/pt/docs/accounts/

Um espaço = uma conta, seu diário e sua chave.

## Escolha como fazer login

**Contas** → adicionar espaço → configurações de conexão. Use uma conta separada para isso.

- **Código QR:** escaneie pela tela Dispositivos do Telegram e confirme.
- **Número de telefone:** número, código e, se tiver, a senha 2FA.
- **Importar sessão:** seu próprio arquivo de sessão ou dados do Telegram Desktop.

Use um perfil de API embutido ou seu próprio API ID e hash. Ele só identifica o app: não faz login nem esconde nada.

**Precisa de um proxy primeiro?**

É possível [escolher e testar a rota de conexão](https://phishdestroy.github.io/TgWitness/pt/docs/proxies/) antes de fazer o login. Cada conta possui sua própria rota.

## Escolha o que deseja monitorar

1. Escolha os chats, grupos ou canais de que precisa.
2. Confira as configurações de coleta, incluindo mídia.
3. Inicie e confira a conexão e a atividade recente.

A conta precisa ter acesso. Admins e membros veem coisas diferentes; o diário mostra o que esta conta recebeu.

A conta inteira? **Fontes → Escopo de observação → Modo investigação**, confira e clique em **Salvar escopo**. Passo a passo completo: [investigar uma conta inteira](https://phishdestroy.github.io/TgWitness/pt/docs/cases/).

## Verifique o caminho completo

No seu grupo de teste, envie uma mensagem de outra conta, edite e exclua. Os três eventos devem aparecer no diário. Depois, [exporte e verifique](https://phishdestroy.github.io/TgWitness/pt/docs/exports/).

"Conectado" significa que a conexão funciona. Uma mensagem de teste capturada significa que os eventos realmente chegam.

## Adicionar outra conta

Novo espaço em **Contas**, mesmos passos. Anote a impressão digital da chave de cada conta para diferenciar as exportações depois.
