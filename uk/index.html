Налаштування зберігання та відновлення
Шифрування на стороні клієнта
AES-256-GCM шифрує об’єкти на цьому комп’ютері. Провайдер отримує зашифровані об’єкти.
Заплановані або ручні копії
Скопіюйте зараз або виберіть інтервал від 1 до 1 440 хвилин. Перевіряйте хід виконання у панелі.
Object Lock
Виберіть термін зберігання та режим, якщо це підтримується сховищем. Панель повідомляє, чи було підтверджено зберігання завантаженого об’єкта.
Перевірене відновлення
Завантажте ключ шифрування та зберігайте його окремо. Відновіть дані на іншому комп’ютері; файли публікуються лише після перевірки.

Отримати вихідний код.

Завантажте ZIP-архів із вихідним кодом і розпакуйте його, або клонуйте репозиторій:

git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

Для запуску програми необхідна версія Python 3.11+. Програма запуску для Windows пропонує встановити Python, якщо його немає.

Переглянути випуски ↗

Немає Python на Windows? Завантажте портативний пакет, розпакуйте його та двічі клацніть на файл «TgWitness.cmd».

КРОК 02

Оберіть спосіб запуску.

Двічі клацніть на Start.cmd або запустіть у PowerShell:

.\Start.cmd

Просто ознайомлюєтеся? Двічі клацніть на scripts\Demo.cmd, щоб перейти до ізольованої демоверсії. Вхід у Telegram не потрібен.

З Python 3.11+ та venv:

sh start.sh

Щоб відкрити вигаданий журнал, запустіть sh start.sh --demo.

За умови запуску Docker та встановлення Compose 2.20+:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

Друга команда показує ваш особистий токен панелі. Зберігайте його на своєму комп’ютері.

Після запуску відкрийте 127.0.0.1:8787 ↗.

Чи пов’язана ця сторінка з Telegram?

Ні. Це статична сторінка проєкту з вигаданими прикладами та скріншотами. Фактична програма працює на вашому комп’ютері або сервері; вхід у систему відбувається саме там.

Чи можна відновити повідомлення, видалені до початку запису?

Ні. TgWitness зберігає вміст, який був доступний у вашому акаунті під час збору даних. Пізніший знімок історії не дозволяє відтворити пропущені редагування або видалені повідомлення.

Чи зашифрований весь мій журнал?

Реквізити облікового запису та секрети підпису зберігаються у зашифрованому сховищі. Для локальних повідомлень та вкладень необхідний зашифрований диск або том. При експорті можна за бажанням використовувати ZIP-архів із шифруванням AES-256, захищений паролем.

Чи пов’язаний цей ресурс із Telegram?

Ні. TgWitness — це незалежний проєкт, що використовує Telethon, який розповсюджується за ліцензією MIT. Ви авторизуєте свої власні акаунти, використовуючи вбудовані налаштування API або власну пару API.
