完整参考资料

本项目所有文档均在此呈现，并附有相应图表。指南提供了快速入门路径；而这些页面则包含所有细节。

设置

01 ↗

快速入门

安装和启动 TgWitness 的所有方法：Windows 安装包、Python、Docker 以及综合演示，并附带初步测试。

02 ↗

账户与会话格式

支持通过手机、二维码或授权密钥登录，可导入 Telethon、Pyrogram 或 Telegram Desktop 的会话数据，并同时管理多个账户。

03 ↗

连接、代理和数据保护

API 配对、登录方式、SOCKS5、HTTP 和 MTProxy 路由、公共代理列表以及各路由所提供的保护功能。

04 ↗

部署

可在 Windows、Linux、macOS 或 Docker 环境中将 TgWitness 作为服务运行，通过 HTTPS 访问，并支持备份和更新。

收集

05 ↗

数据采集原理

观察范围、实时更新、复核、附件、用户操作以及“缺口”的含义，逐条记录。

06 ↗

工作流程与操作

控制面板的日常操作：模式、监控类别、参数、通知、导出、备份及容量。

07 ↗

调查模式

涵盖频道、群组、私聊和机器人的全账户调查，从调查范围到经过验证的案件资料包。

08 ↗

功能与限制

TgWitness 当前已实现的功能、Telegram 平台的限制以及未来仍需完成的工作。

证据

09 ↗

证据的运作原理

通过验证者实际使用的精确公式，详细解释了哈希链、签名、检查点和见证人等概念。

10 ↗

证据格式

签名 ZIP 文件的内容、记录类型、操作收据、用户资料、异地副本及离线验证。

11 ↗

独立见证者

运行一个带有独立密钥和机器人的 Witness 实例，将签名后的检查点发布到频道中，并据此验证导出数据。

12 ↗

时间戳

签名检查点采用 RFC 3161 时间戳：向认证机构发送的内容以及如何验证响应。

安全与数据处理

威胁模型、访问模型、静态机密、网络暴露、会话导入以及如何报告漏洞。

14 ↗

架构

收集器、控制面板、日志、工作进程和见证程序的组成部分，以及数据在它们之间如何流动。

Telegram 实时测试、自动化检查、浏览器检查以及尚未经过验证的内容。
