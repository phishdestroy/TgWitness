# แหล่งอ้างอิงครบถ้วน

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/reference/

เอกสารทุกชิ้นของโครงการ ซึ่งแสดงไว้ที่นี่พร้อมด้วยแผนภาพ คู่มือเป็นทางลัด ส่วนหน้าเว็บเหล่านี้เก็บรายละเอียดทั้งหมด

## การตั้งค่า

[### เริ่มต้นอย่างรวดเร็ว ทุกวิธีในการติดตั้งและเปิดใช้งาน TgWitness: แพ็กเกจ Windows, Python, Docker และเดโมจำลอง พร้อมขั้นตอนตรวจสอบเบื้องต้น](https://phishdestroy.github.io/TgWitness/th/docs/reference/quickstart/)[### ติดตั้ง ตรวจสอบ และอัปเดต ติดตั้งด้วยคำสั่งเดียว ตรวจสอบลายเซ็นและค่าแฮช อัปเดตและลบการติดตั้ง](https://phishdestroy.github.io/TgWitness/th/docs/reference/installation/)[### การตั้งค่าและกำหนดค่าครั้งแรก ตัวช่วยตั้งค่า, เป้าหมาย, ระดับอินเทอร์เฟซ, เส้นทางการเชื่อมต่อ และการตั้งค่าที่กลุ่มบัญชีใช้ร่วมกัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/settings/)[### รูปแบบบัญชีและเซสชัน ลงชื่อเข้าใช้ผ่านโทรศัพท์มือถือ รหัส QR หรือกุญแจการยืนยันตัวตน นำเข้าเซสชันจาก Telethon Pyrogram หรือ Telegram Desktop และจัดการหลายบัญชีได้](https://phishdestroy.github.io/TgWitness/th/docs/reference/accounts/)[### การเข้าถึงและสิทธิ์ กำหนดสิทธิ์การเข้าถึงบัญชีและห้องสนทนา, เลือกสิทธิ์การเข้าถึง, จำกัดจำนวนเซสชันและที่อยู่ IP, และยกเลิกสิทธิ์การเข้าถึง](https://phishdestroy.github.io/TgWitness/th/docs/reference/access/)[### การเชื่อมต่อ, พร็อกซี และการคุ้มครองข้อมูล การยืนยันตัวตน, กลุ่มพร็อกซีอัตโนมัติ, โหมด IP, นโยบายสำรอง, คำขอจากภายนอก และการจัดเก็บข้อมูลลับ](https://phishdestroy.github.io/TgWitness/th/docs/reference/connection/)[### การติดตั้ง เรียกใช้ TgWitness ในรูปแบบบริการบน Windows, Linux, macOS หรือ Docker ผ่าน HTTPS พร้อมด้วยระบบสำรองข้อมูลและการอัปเดต](https://phishdestroy.github.io/TgWitness/th/docs/reference/deployment/)[### การปรับใช้ที่มีความมั่นใจสูง เซิร์ฟเวอร์ที่ได้รับการรักษาความปลอดภัยอย่างแน่นหนาและทำงานตลอด 24/7 บน Hetzner หรือ Phala Cloud, Gateway DNS และขั้นตอนการตรวจสอบที่ฝ่ายที่สามสามารถทำซ้ำได้](https://phishdestroy.github.io/TgWitness/th/docs/reference/high-assurance/)

## Collect

[### คู่มือแผงควบคุม ทุกหน้าจอของแผงควบคุม: การสนทนา, บันทึก, แหล่งข้อมูล, การส่งออก, Extras, โหมดการป้องกัน และการตรวจสอบโค้ด](https://phishdestroy.github.io/TgWitness/th/docs/reference/panel/)[### วิธีการเก็บรวบรวมข้อมูล ขอบเขตการสังเกตการณ์, การอัปเดตแบบเรียลไทม์, การตรวจสอบซ้ำ, ไฟล์แนบ, การดำเนินการของผู้ใช้เอง และความหมายของช่องว่าง (gap) — บันทึกอย่างละเอียดทีละรายการ](https://phishdestroy.github.io/TgWitness/th/docs/reference/collection/)[### Secret Chats: implementation and demo Understand the separate Secret Chat implementation, try the fictional interface and review outstanding defects.](https://phishdestroy.github.io/TgWitness/th/docs/reference/secret-chats/)[### โหลดประวัติแหล่งที่มา โหลดข้อความที่ผ่านมาจากแหล่งข้อมูลที่เปิดใช้งาน หยุดชั่วคราวและต่อใหม่ และตรวจสอบรายงานความคืบหน้าที่ลงนามแล้ว](https://phishdestroy.github.io/TgWitness/th/docs/reference/history/)[### ขั้นตอนการทำงานและการดำเนินการ การดำเนินงานประจำวันของแผงควบคุม: โหมดการทำงาน, หมวดหมู่การติดตาม, พารามิเตอร์, การแจ้งเตือน, การส่งออกข้อมูล, การสำรองข้อมูล และขีดความสามารถ](https://phishdestroy.github.io/TgWitness/th/docs/reference/operations/)[### โหมดการสืบสวน การสืบสวนบัญชีทั้งหมด รวมถึงช่อง กลุ่ม การสนทนาส่วนตัว และบอต ตั้งแต่ขั้นตอนการกำหนดขอบเขตไปจนถึงการจัดทำชุดหลักฐานที่ได้รับการยืนยัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/investigation/)[### คุณสมบัติและข้อจำกัด โมเดลการเก็บรวบรวมข้อมูลปัจจุบัน กระบวนการทำงานแบบหลายบัญชี การส่งออกข้อมูล และขอบเขตการดำเนินงานของ TgWitness](https://phishdestroy.github.io/TgWitness/th/docs/reference/features/)

## การเก็บรักษาข้อมูลและการบูรณาการ

[### อ้างอิง Case Board บุ๊กมาร์ก, การเน้นข้อความที่แม่นยำ, ส่วนการดำเนินการ, การสนทนา, การเข้าถึงตามขอบเขต และประวัติคำอธิบายประกอบที่ลงนาม ซึ่งใช้โดย Case Board.](https://phishdestroy.github.io/TgWitness/th/docs/reference/case-board/)[### การวิเคราะห์ข้อมูลในคลัง ค้นหาข้อความที่บันทึกไว้ ตรวจสอบข้อมูลที่ AI ให้มา และเก็บรายงานวิเคราะห์พร้อมแหล่งอ้างอิง](https://phishdestroy.github.io/TgWitness/th/docs/reference/analysis/)[### การค้นหาข้อความเต็ม ค้นหาข้อความที่บันทึกไว้ตามรูปแบบคำ วลีที่ตรงกันเป๊ะ โดเมน และ @usernames โดยแสดงผลลัพธ์ที่ตรงกันมากที่สุดก่อน พร้อมทั้งดัชนีที่เชื่อมโยงกับบันทึกที่ลงนามแล้ว](https://phishdestroy.github.io/TgWitness/th/docs/reference/search/)[### MCP แบบอ่านเท่านั้น เชื่อมต่อไคลเอนต์ MCP กับพื้นที่ทำงานและห้องสนทนาที่เลือกไว้ โดยให้สิทธิ์การเข้าถึงที่มีระยะเวลาจำกัดและสามารถเพิกถอนได้](https://phishdestroy.github.io/TgWitness/th/docs/reference/mcp/)[### บรรทัดคำสั่ง ค้นหา อ่านบริบท นับกิจกรรม และส่งออกข้อความที่บันทึกไว้จากสคริปต์และเอเจนต์ ด้วยผลลัพธ์ --json รหัสออกที่เสถียร และโทเค็นอ่านอย่างเดียวที่มีขอบเขต](https://phishdestroy.github.io/TgWitness/th/docs/reference/cli/)[### OCR และแปลงข้อความเป็นข้อความแบบท้องถิ่น ระบุภาพและเสียงที่บันทึกได้ด้วย local worker; รักษาข้อความที่สร้างขึ้นให้เชื่อมโยงกับไฟล์ต้นฉบับ](https://phishdestroy.github.io/TgWitness/th/docs/reference/media-analysis/)[### webhooks ส่งออก ส่งเหตุการณ์ที่ระบุขอบเขตไปยังผู้รับ HTTPS พร้อมลายเซ็น HMAC การลองส่งซ้ำ และสถานะการส่ง](https://phishdestroy.github.io/TgWitness/th/docs/reference/webhooks/)[### แสดงผลงานสาธารณะ เผยแพร่ข้อความที่บันทึกไว้จากช่องสาธารณะที่เลือกไว้และภาพสแนปช็อตที่ลงนามแล้ว ผ่านลิงก์ที่มีอายุการใช้งานจำกัดและสามารถยกเลิกได้](https://phishdestroy.github.io/TgWitness/th/docs/reference/showcase/)

## หลักฐาน

[### วิธีการทำงานของหลักฐาน อธิบายเกี่ยวกับโซ่แฮช (hash chain), ลายเซ็น (signatures), จุดตรวจสอบ (checkpoints) และพยาน (witnesses) ด้วยสูตรที่ผู้ตรวจสอบใช้จริง](https://phishdestroy.github.io/TgWitness/th/docs/reference/how-it-works/)[### การตั้งค่าและตรวจสอบรายงาน ตัวกรองรายงาน, แปดแบบออกแบบ, การตั้งค่าเนื้อหาล่วงหน้า, ประวัติการเปลี่ยนแปลงที่บันทึกไว้ และการประเมินผลที่รวมอยู่ในไฟล์ส่งออกที่ลงนามแล้ว](https://phishdestroy.github.io/TgWitness/th/docs/reference/case-reports/)[### การส่งออกบัญชี ส่งออกข้อมูลที่บัญชีสามารถอ่านได้ในขณะนี้: ขอบเขตการเข้าถึง, งานที่สามารถต่อได้, ไฟล์เก็บถาวรที่ลงนามแล้ว และสำเนาที่แชร์ในโหมดย่อ](https://phishdestroy.github.io/TgWitness/th/docs/reference/account-export/)[### รูปแบบหลักฐาน เนื้อหาของไฟล์ ZIP ที่ลงนาม, ประเภทบันทึก, ใบยืนยันการดำเนินการ, โปรไฟล์ผู้ใช้, สำเนาที่เก็บไว้นอกระบบ และการตรวจสอบแบบออฟไลน์](https://phishdestroy.github.io/TgWitness/th/docs/reference/evidence/)[### พยานอิสระ เรียกใช้ witness ด้วยกุญแจและบอทของตัวเอง เผยแพร่จุดตรวจสอบที่ลงนามแล้วไปยังช่อง และตรวจสอบการส่งออกข้อมูลกับจุดตรวจสอบดังกล่าว](https://phishdestroy.github.io/TgWitness/th/docs/reference/witness/)[### ข้อมูลเวลา การประทับเวลาตาม RFC 3161 สำหรับจุดตรวจสอบที่ลงนาม: สิ่งที่ส่งไปยังหน่วยงานที่มีอำนาจ และวิธีการตรวจสอบความถูกต้องของคำตอบ](https://phishdestroy.github.io/TgWitness/th/docs/reference/timestamp/)[### การเก็บรักษาและกู้คืนข้อมูล การสำรองข้อมูล การย้ายไฟล์เก่าไปยังคลาวด์ การคัดลอกภายใต้ Object Lock และการกู้คืนบนเครื่องใหม่](https://phishdestroy.github.io/TgWitness/th/docs/reference/storage/)

## ความปลอดภัยและโครงการ

[### ความปลอดภัยและการจัดการข้อมูล โมเดลภัยคุกคาม, โมเดลการเข้าถึง, ข้อมูลลับที่เก็บไว้, ความเสี่ยงในการเปิดเผยผ่านเครือข่าย, การนำเข้าเซสชัน และวิธีการรายงานช่องโหว่](https://phishdestroy.github.io/TgWitness/th/docs/reference/security/)[### สถาปัตยกรรม ส่วนประกอบของระบบ ได้แก่ collector, panel, journal, workers และ witness รวมถึงวิธีการที่ข้อมูลถูกส่งผ่านระหว่างส่วนต่าง ๆ](https://phishdestroy.github.io/TgWitness/th/docs/reference/architecture/)[### สิ่งที่ได้รับการทดสอบแล้ว การทดสอบ Telegram แบบเรียลไทม์ การตรวจสอบอัตโนมัติ การตรวจสอบผ่านเบราว์เซอร์ และสิ่งที่ยังไม่ได้รับการยืนยัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/verification/)[### ประกาศเรื่องใบอนุญาตและความไม่เข้ากันทางสถาปัตยกรรม TgWitness ได้รับใบอนุญาต MIT สำหรับทุกคน และเหตุผลที่มันไม่เข้ากันทางสถาปัตยกรรมกับกระบวนการทำงานของ Taylor Wessing](https://phishdestroy.github.io/TgWitness/th/docs/reference/license/)[### ประกาศความไม่เข้ากันได้ของผู้ดำเนินการ ประกาศของผู้ดำเนินการของเราเกี่ยวกับ Taylor Wessing และบันทึกแหล่งที่มาของมัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/notice/)[### บันทึกการเปลี่ยนแปลง ทุกการเปลี่ยนแปลงตามเวอร์ชัน รวมถึงการเปลี่ยนแปลงที่ยังไม่ได้รับการปล่อยออก](https://phishdestroy.github.io/TgWitness/th/docs/reference/changelog/)
