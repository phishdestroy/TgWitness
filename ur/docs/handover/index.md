# شیئر کرنے کے لیے ایک کاپی تیار کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/handover/

متعلقہ مشاہدات شیئر کریں جبکہ اصل ورک اسپیس کو برقرار رکھیں۔

ہینڈ اوور ایک الگ دستخط شدہ خلاصہ ہوتا ہے۔ چیٹس اور افراد کا انتخاب کریں، شناختوں یا متن کو کم کریں، اور فیصلہ کریں کہ کون سی فائلیں اور ٹیم کے نوٹس وصول کنندہ کی کاپی میں شامل ہونے چاہئیں۔ اس کا منیفیسٹ انتخاب اور غیر تبدیل شدہ، کم کیے گئے اور خارج کردہ ریکارڈز کی تعداد کو ریکارڈ کرتا ہے۔

## موصول کنندہ کا استخراج تیار کریں

1. **Exports → Handover extract** کھولیں۔ اس کا مقصد لکھیں، چیٹس اور اختیاری UTC مدت منتخب کریں، پھر اگر نامزد موضوعات درکار ہوں تو **منتخب کردہ چیٹس کے افراد لوڈ** کریں۔
2. باقی سب کے ساتھ سلوک کا طریقہ منتخب کریں: مستعار نام استعمال کریں، ان کے پیغامات کو حذف کریں، یا ریکارڈ شدہ کے طور پر دکھائیں۔ پیغام کے متن اور منسلکات کو الگ الگ ترتیب دیں؛ اختیاری طور پر فون نمبرز اور ای میل پتے کو مسک کریں۔
3. یہ فیصلہ کریں کہ کیس بورڈ کے بُک مارکس اور سلائسز شامل کیے جائیں یا تبصروں کے ساتھ کارڈز۔ تفتیش کار کے عرفی نام اس متن میں ٹیم کے ناموں کی جگہ لے سکتے ہیں۔
4. **ڈاؤن لوڈ ہینڈ اوور ایکسٹریکٹ** منتخب کریں۔ تیار شدہ رپورٹ اور منتخب کردہ ریکارڈز کو مقامی طور پر کھولیں، آرکائیو کی تصدیق کریں، اور بھیجنے سے پہلے کاپی کا معائنہ کریں۔

### ایک اصل، ایک جان بوجھ کر شیئر کرنے کے لیے کاپی

مصنوعی مثال · صرف شناختی وضاحت کے لیے

1. **منتخب کریں۔** کیس چیٹ شامل کریں اور اس شخص کی شناخت کریں جس کے بارے میں اقتباس ہے۔
2. **کم کریں۔** شیئر کی گئی کاپی میں دوسرے شرکاء کی نمائش کا طریقہ منتخب کریں۔
3. **معائنہ کریں۔** بھیجنے سے پہلے تیار کردہ آرکائیو کی رپورٹ اور ریکارڈز کھولیں۔
4. **شیئر کریں۔** تصدیق شدہ کاپی فراہم کریں اور اس کے قابلِ اعتماد فنگر پرنٹ کو الگ سے مطلع کریں۔

#### اصلی مشاہدہ

نورا · صارف 71002

"مجھے نظر ثانی شدہ لنک موصول ہوا۔"

ماخذ جرنل اس محفوظ شدہ مشاہدے کو برقرار رکھتا ہے۔

#### موصول کنندہ کی کاپی

جیسا ریکارڈ کیا گیا ہے دکھائیں: نورا · صارف 71002 · "مجھے نظر ثانی شدہ لنک موصول ہوا۔"

تخفیفی نام: P01 · "مجھے نظر ثانی شدہ لنک موصول ہوا۔"

چھوڑیں: اس شرکاء کا پیغام کاپی سے خارج کیا گیا ہے۔

#### اصل فائلوں کا معائنہ کریں

report.html اور records.jsonl پڑھیں۔

شناختیں، متن، منسلکات اور اختیاری ٹیم تبصرے چیک کریں۔

#### دستخط شدہ اقتباس

انتخاب + فائل ہیشز + دستخط شدہ منیفیسٹ

ایک الگ پیکیج جو اپنے ماخذ جرنل کی حد سے منسلک ہے

## کنٹرولز کو ایک ساتھ استعمال کریں

| کنٹرول | نسخے پر اثر |
| --- | --- |
| لوگ | منتخب کردہ موضوعات کو قابلِ شناخت رکھیں؛ دیگر شرکاء کو اپنی پسند کے مطابق مستعار نام دیں یا حذف کریں۔ |
| متن | تمام متن شامل کریں، صرف منتخب کردہ افراد اور مشاہداتی اکاؤنٹ کے متن کو شامل کریں، یا پیغام کے متن اور اس کے متن پر مشتمل تفصیلی فیلڈز کو حذف کر دیں۔ |
| فائلیں | منتخب کردہ افراد اور مشاہداتی اکاؤنٹ کی فائلیں منتخب کریں، تمام دکھائے گئے پیغامات کی فائلیں، یا کوئی فائلیں نہیں۔ |
| کیس بورڈ | کوئی بورڈ مواد، بُک مارکس اور سلائسز، یا ٹیم کی بحث کے ساتھ کارڈز نہ منتخب کریں۔ |

آزاد شکل کے متن اور فائل کے مندرجات کے ساتھ ساتھ شناختوں کا جائزہ لیں: ایک مستعار نام خود بخود پیغام یا منسلک میں لکھے گئے ہر نام کو ختم نہیں کرتا۔ اگر منتخب شدہ محفوظ شدہ فائل دستیاب نہ ہو تو اسے بحال کریں یا خلاصہ تیار کرنے سے پہلے منسلکات کو واضح طور پر خارج کر دیں۔

## متن کو آزادانہ طور پر تصدیق کے قابل رکھیں

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

اصلی دستخط شدہ شواہد کے آرکائیو اور چیک پوائنٹس کو الگ الگ برقرار رکھیں۔ ہینڈ اوور اپنی پروجیکشن کو ریکارڈ کرتا ہے، تاکہ وصول کنندہ پورے ورک اسپیس کو وصول کیے بغیر فراہم کردہ کاپی کی تصدیق کر سکے۔ [رپورٹ اسٹوڈیو](https://phishdestroy.github.io/TgWitness/ur/docs/reports/) اپنا ریڈنگ ڈیزائن فراہم کرتا ہے؛ [ایکسپورٹ ویریفیکیشن](https://phishdestroy.github.io/TgWitness/ur/docs/exports/) قابل اعتماد حوالہ جات کی وضاحت کرتا ہے۔
