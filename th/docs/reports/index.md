# Telegram · ออกแบบรายงาน

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/reports/

พาผู้อ่านจากคำถามของคดีไปยังรายการที่บันทึกไว้โดยตรง

Report studio รวมข้อมูลที่คุณเลือก ประวัติการเปลี่ยนแปลง แผนภูมิ และข้อค้นพบของคุณ แปดดีไซน์ HTML และ PDF แบบเนทีฟ รายงาน HTML, PDF และ JSON ทุกฉบับผนึกด้วยคีย์ของคุณ

## สร้างรายงานในสามขั้นตอน

1. **การส่งออก → กำหนดค่าและดูตัวอย่าง → ข้อมูล**: ทั้งพื้นที่ทำงาน หรือเลือกแชท ผู้เขียน วันที่ (UTC เวลาที่ TgWitness เห็นรายการ) และประเภทรายการ
2. **ดีไซน์และเนื้อหา**: เลือกดีไซน์และสิ่งที่จะใส่: แผนภูมิ ผู้เข้าร่วม บันทึกบทสนทนา การเปลี่ยนแปลง รายการ Case Board รายละเอียดคดีและบันทึกย่อของคุณ
3. **ดูตัวอย่าง**: ตรวจจำนวน กิจกรรม ตัวอย่าง และช่วง ID ที่หายไป บันทึก แล้วดาวน์โหลดรูปแบบที่ต้องการ

### จัดเรียงเนื้อหาที่บันทึกไว้ให้สอดคล้องกับผู้อ่าน

ตัวอย่างสังเคราะห์ · แบบร่างแผนผัง ไม่ใช่รายงานที่สร้างขึ้น

1. **เลือก.** เลือกการสนทนาสองครั้งและช่วงเวลาการสังเกตการณ์สำหรับคดีนี้
2. **เขียนเนื้อหา** เลือกแบบจัดวางและส่วนที่ตอบคำถาม
3. **ดูตัวอย่าง.** ตรวจสอบจำนวนที่เลือกและข้อความก่อนและหลังที่บันทึกไว้
4. **ตรวจสอบความถูกต้อง** สร้างไฟล์สุดท้ายและตรวจสอบลายเซ็นของไฟล์นั้นกับลายนิ้วมือของพื้นที่ทำงานที่เชื่อถือได้

#### ข้อสังเกตที่เลือกมา

2 การสนทนา · 1 วันสังเกตการณ์

ข้อความ การแก้ไข และแจ้งเตือนการลบ

#### โครงสร้างรายงาน

##### เปลี่ยนปลายทางการชำระเงิน

คำถามของคดี → ขอบเขต → ผลการตรวจสอบ → อ้างอิงบันทึก

**บริบทของข้อความ**

ข้อสังเกต #142: “ใช้ลิงก์การชำระเงินใหม่”

**การเปลี่ยนแปลงที่บันทึกไว้**

ก่อน: old.example.invalid → หลัง: new.example.invalid

#### ตรวจสอบการเลือก

18 ข้อสังเกต · 2 การแก้ไขที่บันทึกไว้

เวลาส่ง เวลาแก้ไข และเวลาตรวจสอบ มีป้ายกำกับแยกกัน

#### ผลลัพธ์สุดท้าย

PDF ที่ลงนาม + JSON ที่ลงนาม หรือ ZIP ที่ลงนามพร้อมรายงานที่อ่านได้

ผู้รับจะตรวจสอบไฟล์และลายนิ้วมือดิจิทัลที่เชื่อถือได้

## เลือกสไตล์การอ่าน

**Classic, Editorial, Briefing, Analytics, Technical, Overview, Reading series, and Ledger & margin**: รายการเดียวกัน หน้าตาต่างกัน เมื่อสลับ การเลือกและบันทึกย่อยังคงอยู่ ใช้ได้ทุกภาษาจาก 25 ภาษา

PDF สร้างด้วยฟอนต์ที่มาพร้อมกัน ไม่ต้องใช้เบราว์เซอร์ ภาษาจีน ญี่ปุ่น และเกาหลีต้องมีฟอนต์อย่าง Noto Sans CJK บนเซิร์ฟเวอร์ (ทั้งระบบหรือใน `TGWITNESS_FONT_DIR`) มิฉะนั้นจะได้เพียง HTML และ JSON

## อ่านการเปลี่ยนแปลงพร้อมบริบท

การแก้ไขแสดงก่อนและหลัง การลบแสดงเวอร์ชันที่บันทึกล่าสุด การตอบกลับ การส่งต่อ รีแอ็กชัน ปุ่ม และไฟล์แนบคงการอ้างอิงไว้

ตัวอย่างดีไซน์ใช้ 50,000 รายการแรก ตัวอย่างข้อมูลนับทุกอย่างอย่างแม่นยำ สำหรับเลย์เอาต์หน้าสุดท้าย ให้สร้าง PDF

## เลือกสำเนาสำหรับผู้รับอย่างระมัดระวัง

ตัวกรองกำหนดรูปรายงานเท่านั้น ZIP หลักฐานยังมีบันทึกและไฟล์ทั้งหมด หากผู้รับควรได้น้อยกว่านี้ ให้ใช้ [การส่งมอบแบบย่อ](https://phishdestroy.github.io/TgWitness/th/docs/handover/) เพิ่มเติม: [เนื้อหารายงาน](https://phishdestroy.github.io/TgWitness/th/docs/reference/case-reports/), [การตรวจสอบการส่งออก](https://phishdestroy.github.io/TgWitness/th/docs/exports/)
