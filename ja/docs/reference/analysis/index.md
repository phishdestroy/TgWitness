# アーカイブ分析

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/reference/analysis/

保存されたメッセージを検索し、AIの入力内容を検証し、出典情報を記載した分析レポートを管理できます。

[ワークフローガイド](https://phishdestroy.github.io/TgWitness/docs/archive/) · [Wiki](https://github.com/phishdestroy/TgWitness/blob/main/docs/wiki/Archive-and-Integrations.md)

AI を使用しないローカル検索には**「Journal」**を使用してください。[全文検索](https://phishdestroy.github.io/TgWitness/ja/docs/reference/search/)（プレビュー）[は](https://phishdestroy.github.io/TgWitness/ja/docs/reference/search/)、 単語の形態、フレーズ、ドメイン、@ユーザー名に一致します。**「Ask the archive**」を使用するには、まず 「**Integrations**」でプロバイダーを有効化し、設定を行ってください。ワークスペースセレクターで アカウントを選択し、フォームでチャットと観測期間を選択します。 検索処理は ローカルで実行されます。正確なフレーズやドメインを指定すると検索範囲が絞り込まれ、メッセージIDを指定すると保存された バージョンが取得されます。抜粋を確認し、ジャーナル記録やコンテキストを開くことができます。 ベクトルデータベースやTelegramへの自動アクション機能はありません。

## プロバイダーおよび同意

AI機能は、すべてのワークスペースで初期状態では無効になっています。モデル、エンドポイント、暗号化されたAPIキー、コンテキスト／出力の制限、タイムアウト、および1日あたりの リクエスト上限の設定は、メイン管理者のみが変更可能です。キーはブラウザに返されることはありません。現在のキーを維持するには、キーフィールドを空白のままにしておくか、 明示的に削除してください。

Ollamaは、ドキュメントに記載された[`/api/chat`エンドポイント](https://docs.ollama.com/api/chat)を使用し、 ストリーミング形式ではないJSON出力を生成します。デフォルトのアドレスは、 TgWitnessサーバー上の`http://127.0.0.1:11434`です。オペレーターは `TGWITNESS_AI_LOCAL_ENDPOINT`を使用してこれを変更できます。これはモデルによって制御されるアドレスではありません。選択したモデルは ご自身でインストールしてください。TgWitnessは自動的にダウンロードしません。

互換性のあるプロバイダーは、`/v1` で終わるベース URL および [Chat Completions プロトコル](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)（ `messages`、JSON レスポンスモード、`max_completion_tokens`、 `choices[0].message.content`）に対応している必要があります。これらのフィールドがないサービスはサポートされません。 接続テストでは合成テキストが送信され、リクエスト予算にカウントされます。

すべてのリクエストは、ワークスペースで設定された外部ルートを使用します。ブロックされたルートや Telegram専用のMTProxyはエラーとなり、直接的な再試行は行われません。意図的に 設定されたローカルOllamaアドレスは、プライベートな宛先を許可します。 ループバックAI エンドポイントには、ワークスペースの「Direct」外部ルートが必要です。プロキシルートは 送信前に拒否されます。その他のプライベートサービスについては、既存のサーバーレベルのプライベート 宛先オプトインが適用されます。プレビューには、エンドポイントと外部ルートが表示され、 該当する場合はプロキシホストも含まれます。そのルートを変更するには、新しいプレビューが必要です。

生成前に、**モデルに送信されるデータには**、リクエスト（質問、 チェックされた抜粋、イベントの種類、観測時刻、およびカバレッジマーカー）が含まれます。Telegram セッション、生データフィールド、プロバイダーキー、添付ファイルのバイトデータ、および完全なジャーナルは、 そのコンテキストには含まれません。不要なソースのチェックを外し、処理を明示的に承認してください。 外部プロバイダーは、自社の ポリシーに基づき、送信されたコンテンツを保持する場合があります。「ローカル実行」とは、エンドポイントがローカルにあることを意味しますが、 個別に構成されたサービスの動作を保証するものではありません。

プロバイダーへの同時リクエストは、グローバルで最大2件、ワークスペースごとに 1件までです。プレビューは10分後に失効し、1回の回答を生成できます。 プロバイダーから報告されたトークン数が表示されます。コストの見積もりは、 入力と出力の両方の料金体系が設定されている場合にのみ表示されます。失敗したリクエストも 1日のリクエスト予算を消費します。自動再試行による追加の予算消費はありません。

## 出典と制限事項

検索は、[全文インデックスが](https://phishdestroy.github.io/TgWitness/ja/docs/reference/search/#ask-the-archive-and-mcp) 完成している場合にそれを使用します。選択されたチャット全体から、語形を含めた最適な一致結果を返します。最近の変更や特定のメッセージのバージョンに関する 問い合わせ、およびインデックスの 構築中の検索については、最新のレコードを対象とした範囲限定の語彙検索が行われます。プレビューには その手法名が記載されています。検索結果は最大24件まで返され、長いテキストは一致箇所を中心に切り詰められます。 切り詰められた抜粋や不完全な結果セットにはマークが付きます。この 期間は**観測**期間を指すものであり、Telegramの履歴が 完全であることを保証するものではありません。ワークスペース全体を対象とするイベントは、チャット範囲のアクセスからは除外されます。 欠落しているデータについては、利用可能なアーカイブ内に「見つかりませんでした」と表示されます。

モデルにはツールは提供されません。そのソースIDは選択された レコードに対して照合され、ハッシュ値は再確認され、引用された文字列はそれらのレコード内に存在しなければなりません。 不明なID、変更された引用、出典のない主張がある場合は、回答は却下されます。本アプリケーションは リンクを生成しますが、モデルが生成したURLは引用元として使用されません。これらのチェックは 出典の存在と引用の正確性を確認するものであり、推論の真偽を保証するものではありません。 推論を信頼する前に、記録と照らし合わせて確認してください。

## レポート

レビュー済みの回答を、独立した分析レポートとして保存します。これには、モデルの 要約、観測された時系列、抽出されたリンクとハンドル、編集・削除記録、 カバレッジの制限、およびソースイベントのハッシュが含まれます。プロバイダー、モデル、エンドポイント、時刻、 およびプロンプトテンプレートのバージョンも併記されます。身元情報は自動的に統合されません。

アナリストによる修正や注記は、モデルの要約とは別に保存されます。レポートは 暗号化された派生ファイル内に格納され、インデックスは署名付きイベントストリームの外部に配置されます。 元のイベントやメディアは変更されません。レポートを開くことができるのは所有者または管理者のみであり、 ソースへのアクセスは再度確認されます。 ダウンロードにもエクスポート 権限が必要です。バージョン1では、レポートへの署名や、モデルの結論が 検証済みの証拠であることを示唆するものではありません。制限：ワークスペースあたり100件のレポート、およびレポート1件あたり100件のアナリストによる修正 。

手動によるOCRおよび文字起こしについては、「[メディア処理」](https://phishdestroy.github.io/TgWitness/ja/docs/reference/media-analysis/)を参照してください。 クライアントへのアクセスについては、[MCPを](https://phishdestroy.github.io/TgWitness/ja/docs/reference/mcp/)参照してください。
