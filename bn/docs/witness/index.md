# Telegram · একটি উইটনেস বট সেট আপ করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/witness/

একটি আলাদা প্রক্রিয়া আপনার জার্নাল যাচাই করে এবং স্বাক্ষরিত চেকপয়েন্ট একটি চ্যানেলে পোস্ট করে।

## দুই হোস্ট, দুইটি স্বাক্ষর কী

হোস্ট এ / কালেক্টর**অ্যাকাউন্ট + জার্নাল**

টেলিগ্রাম সেশন কালেক্টর স্বাক্ষর কী

শুধুমাত্র-পঠনযোগ্য চেকপয়েন্ট এন্ডপয়েন্ট

← স্বাক্ষরিত উত্তর অনুরোধ করুন →

হোস্ট বি / সাক্ষী**যাচাই করুন + ধরে রাখুন**

পিনযুক্ত কালেক্টর ফিঙ্গারপ্রিন্ট পৃথক সাক্ষী স্বাক্ষর কী

নিজের জার্নাল + বট টোকেন

সাক্ষী → টেলিগ্রাম বট API →**আপনার চ্যানেল · স্বাক্ষরিত TGW1 পোস্টসমূহ**

উইটনেস নিজেই চেকগুলি টেনে আনে। কালেক্টর অ্যাক্সেস শুধুমাত্র পড়ার জন্য। বট প্রকাশনা উইটনেসের সংযোগ এবং টোকেন ব্যবহার করে; উইটনেসকে কোনো অ্যাকাউন্ট সেশন দেওয়া হয় না।

০৩ / চেকপয়েন্ট সিদ্ধান্তসমূহউদাহরণস্বরূপ উত্তরসমূহ

সর্বশেষ গৃহীত**১২০টি রেকর্ড**`head 9c7d…`

পরবর্তী উত্তর**১২৮টি রেকর্ড**`head a4f2…`

গ্রহণ করা হয়েছে: গণনা বৃদ্ধি পাচ্ছে, স্বাক্ষর যাচাই হচ্ছে এবং কী মিলছে। সাক্ষী এই নতুন সীমা বজায় রাখে।

সমস্ত উত্তর উদাহরণ বৈধ স্বাক্ষর এবং পিন করা কী-কে ধরে নেয়। এখানে হ্যাশগুলো সংক্ষিপ্ত উদাহরণ। শুধুমাত্র বড় সংখ্যা দেখিয়ে পুরো পুরনো প্রিফিক্স অপরিবর্তিত আছে তা প্রমাণ করা যায় না; চেকপয়েন্ট সংরক্ষণ করে করা একটি এক্সপোর্টের সাথে তুলনা করুন।

## একটি বট এবং একটি চ্যানেল প্রস্তুত করুন

BotFather দিয়ে একটি বট বানান এবং আপনার চ্যানেলে পোস্ট করতে দিন। সাক্ষী অন্য কোথাও চালান: অন্য হোস্ট, ভালো হয় অন্য কেউ চালালে, কালেক্টরের পাশে দ্বিতীয় প্রক্রিয়ার চেয়ে অনেক বেশি মূল্যবান।

## এক্সট্রাস-এ তিনটি ধাপ

1. **শুধু-পড়ার অ্যাক্সেস।** **অতিরিক্ত → স্বাধীন সাক্ষী**, টোকেন বানান, ফাইল সংরক্ষণ করুন। এটি শুধু চেকপয়েন্ট ও স্বাস্থ্য পড়ে।
2. **চ্যানেল ও ব্যবধান।** Telegram চ্যানেল বা Discord webhook, সাথে এমন কালেক্টর ঠিকানা যেখানে সাক্ষী পৌঁছাতে পারে। সেটিংস ফাইল সংরক্ষণ করুন।
3. **চালু করুন।** `witness.json`, `witness-token.txt` ও `bot-token.txt` সাক্ষী হোস্টে একসাথে রেখে চালান:

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

চ্যানেলে প্রথম স্বাক্ষরিত পোস্টের জন্য অপেক্ষা করুন, তারপর সাক্ষীর ফিঙ্গারপ্রিন্ট নিরাপদ জায়গায় রাখুন।

Discord চান? webhook URL `discord-webhook.txt` হিসেবে সংরক্ষণ করুন। একটি সাক্ষী এক জায়গায় পোস্ট করে; লম্বা যাচাই Discord-এ ফাইল হিসেবে আসে।

## কত ঘনঘন প্রকাশ করবেন তা নির্বাচন করুন

প্রতিটি যাচাই পোস্ট করলে নিয়মিত বাইরের রেকর্ড তৈরি হয়: প্রতি পাঁচ মিনিটে মানে ওয়ার্কস্পেস প্রতি দিনে প্রায় 288টি পোস্ট। উন্নত সেটিংস শুধু পরিবর্তন বা সমস্যায় পোস্ট, প্রক্সি বা কাস্টম Bot API ব্যবহার করতে পারে।

**বটটি আসলে কী নিশ্চিত করে?**

এটি কালেক্টরের কাছে স্বাক্ষরিত চেকপয়েন্ট চায়, প্রত্যাশিত কী দিয়ে যাচাই করে এবং নিজের স্বাক্ষরিত জার্নাল রাখে, মিস হওয়া ও প্রত্যাখ্যাত উত্তরসহ।

এটি জার্নালের অবস্থা যাচাই করে, নিজে Telegram দেখে না। তার জন্য নিয়ন্ত্রিত ডেলিভারি পরীক্ষা চালান।

## পরে প্রমাণগুলো দেখুন

সাক্ষীর জার্নাল, পোস্ট ও ফিঙ্গারপ্রিন্ট রাখুন। কালেক্টরের এক্সপোর্টের সাথে [কীভাবে মেলাবেন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/witness/#verify)।
