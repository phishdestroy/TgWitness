# Bir necha daqiqada boshlang

Canonical page: https://phishdestroy.github.io/TgWitness/uz/docs/start/

Avvalo, ishlayotgan misolni ko'rib chiqing. Keyin o'zingizning hisobingizni ulang.

## Hisobisiz atrofga nazar soling

Loyihani yuklab oling yoki klonlang, **Python 3.11 yoki undan keyingi versiyasini** o'rnating va demo dasturini ishga tushiring. Launcher mahalliy muhitni yaratadi va belgilangan bog'liqliklarni o'rnatadi.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

Brauzer soxta xabarlar bilan ish maydonini ochadi. Suhbatni oching, tahrirni solishtiring va eksportni tekshiring. Demo rejimi Telegramga ulanmaydi.

![TgWitness suhbat ko'rinishi namunali xabarlar bilan](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Namuna ish maydoni. Sizning jurnaliz alohida boshlanadi.

## O'zingizning ish maydoningizni yarating

Demo jarayonini yoping, so'ng odatiy ishga tushiruvchidan foydalaning:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Ishga tushiruvchi tomonidan ko'rsatilgan mahalliy manzilni oching. Agar so'ralsa, terminalda nomlangan mahalliy fayldan **panel kirish token**ini kiriting. Bu TgWitnessni ochadi; u Telegramga kirishdan alohida.

## Birinchi xabaringizni qayd eting

1. [Maxsus Telegram hisobini ulang.](https://phishdestroy.github.io/TgWitness/uz/docs/accounts/)
2. Hisob kirish imkoniga ega bo'lgan guruh yoki kanalni tanlang, so'ng kuzatuvni boshlang.
3. O'zingiz nazorat qiladigan test guruhida yangi xabar yuboring va uning jurnalga tushganini tekshiring.

Serverni o'rnatish uchun "[Uni ishga tushirishda saqlang](https://phishdestroy.github.io/TgWitness/uz/docs/server/)" bo'limiga rioya qiling.
