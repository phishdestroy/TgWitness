Choose a route, save it and test the Telegram connection.

Three connections, separate settings

Pick from a public list

  1. Open the account’s connection settings and choose Change connection route.
  2. Select a public MTProxy and save the route.
  3. Run the Telegram connection check. You can do this before signing in.

The installation includes a public-list snapshot. Refresh from the internet fetches the configured public feeds. Refreshing the list keeps the selected account route unchanged. If a source fails, its last usable list is retained.

Use your own proxy

Paste a tg://proxy?… or https://t.me/proxy?… link, or enter SOCKS5, HTTP CONNECT or MTProxy details manually. Stop observation before changing an active account’s route.

Public entries are suggestions, not verified services. If one fails, choose another and test again. Automatic server rotation is not implemented.

Supported secrets and feed privacy

MTProxy supports 32 hexadecimal characters and dd plus 32 hexadecimal characters. Fake TLS secrets beginning with ee are excluded. Public feeds cannot select local or reserved IP addresses.

Feeds are downloaded over a separate HTTPS connection, direct by default. Set TGWITNESS_PROXY_FEED_PROXY for an HTTP/SOCKS5 download route. Session credentials and panel or bot tokens are not sent to list providers. TGWITNESS_PROXY_CATALOG replaces public subscriptions with an operator-managed local catalog.

The witness has its own network settings

MTProxy applies to the collecting Telegram account. The witness bot uses HTTP/SOCKS5 settings and, optionally, your own Bot API endpoint.
