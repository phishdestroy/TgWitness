# เตรียมสำเนาเพื่อแบ่งปัน

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/handover/

แชร์เฉพาะที่จำเป็น ต้นฉบับยังคงไม่ถูกแตะต้อง

การส่งมอบคือชุดสกัดที่ลงนามแยกต่างหาก: เลือกแชทและบุคคล ซ่อนตัวตนหรือเนื้อหา เลือกไฟล์และบันทึกย่อของทีม แมนิเฟสต์บันทึกว่าอะไรถูกเก็บ ตัดทอน และตัดออก

## เตรียมข้อมูลที่คัดลอกสำหรับผู้รับ

1. **การส่งออก → ชุดสกัดสำหรับส่งมอบ**: เขียนวัตถุประสงค์ เลือกแชทและช่วงเวลา **โหลดบุคคลจากแชทที่เลือก** หากต้องการบุคคลที่ระบุชื่อ
2. ทุกคนที่เหลือ: นามแฝง ตัดออก หรือตามที่บันทึกไว้ เนื้อหาและไฟล์เป็นสวิตช์แยกกัน โทรศัพท์และอีเมลปิดบังได้
3. Case Board: ไม่ใส่ บุ๊กมาร์กและส่วนตัด หรือการ์ดพร้อมความคิดเห็น ชื่อทีมเปลี่ยนเป็นนามแฝงได้
4. **ดาวน์โหลดชุดสกัดสำหรับส่งมอบ** เปิด ตรวจสอบ และอ่านทวนก่อนส่ง

### ต้นฉบับหนึ่งฉบับ และสำเนาสำหรับแบ่งปันที่จัดทำขึ้นอย่างตั้งใจ

ตัวอย่างสังเคราะห์ · ใช้เพื่อแสดงตัวอย่างเท่านั้น

1. **เลือก.** รวมแชทของคดีและระบุบุคคลที่ข้อมูลที่คัดลอกนั้นเกี่ยวข้อง
2. **ลดขนาดให้เล็กที่สุด** เลือกวิธีที่ผู้เข้าร่วมอื่นจะปรากฏในสำเนาที่แชร์
3. **ตรวจสอบ.** เปิดรายงานและบันทึกในไฟล์เก็บถาวรที่สร้างขึ้นก่อนส่งไป
4. **แชร์** ส่งมอบสำเนาที่ตรวจสอบแล้ว และส่งข้อมูลลายนิ้วมือที่เชื่อถือได้แยกต่างหาก

#### ข้อสังเกตต้นฉบับ

Nora · ผู้ใช้ 71002

“ผมได้รับลิงก์ที่แก้ไขแล้ว”

หนังสือบันทึกต้นฉบับเก็บรักษาการสังเกตการณ์ที่บันทึกไว้นี้

#### สำเนาสำหรับผู้รับ

แสดงตามที่บันทึก: Nora · ผู้ใช้ 71002 · “ฉันได้รับลิงก์ที่แก้ไขแล้ว”

ชื่อปลอม: P01 · “ผมได้รับลิงก์ที่แก้ไขแล้ว”

ละเว้น: ข้อความของผู้เข้าร่วมนี้ไม่ถูกนำเข้ามาในเนื้อหา

#### ตรวจสอบไฟล์จริง

อ่านไฟล์ report.html และ records.jsonl.

ตรวจสอบข้อมูลประจำตัว ข้อความ ไฟล์แนบ และความคิดเห็นของทีม (หากมี)

#### ส่วนที่ลงนาม

การเลือก + ค่าแฮชของไฟล์ + รายการเนื้อหาที่ลงนาม

แพ็กเกจแยกต่างหากที่เชื่อมโยงกับขอบเขตของวารสารต้นทาง

## ใช้เครื่องมือควบคุมร่วมกัน

| Control | ผลกระทบต่อเนื้อหา |
| --- | --- |
| บุคคล | บุคคลที่เลือกยังคงชื่อเดิม คนอื่นได้นามแฝงหรือถูกตัดออก |
| ข้อความ | เนื้อหาทั้งหมด เฉพาะของบุคคลที่เลือกและบัญชีของคุณ หรือไม่ใส่ |
| ไฟล์ | ไฟล์ของบุคคลที่เลือกและบัญชีของคุณ ไฟล์ทั้งหมดที่แสดง หรือไม่ใส่ |
| Case Board | ไม่ใส่ บุ๊กมาร์กและส่วนตัด หรือการ์ดพร้อมการอภิปราย |

อ่านเนื้อหาและไฟล์ด้วย: นามแฝงไม่ได้ลบชื่อที่เขียนอยู่ในข้อความหรือไฟล์แนบ หากไฟล์ที่เลือกหายไป ให้กู้คืนหรือตัดไฟล์แนบออก

## ให้เนื้อหาสามารถตรวจสอบได้อย่างอิสระ

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

เก็บไฟล์เก็บถาวรต้นฉบับและ checkpoint ไว้เอง ผู้รับตรวจสอบสำเนาของตนได้โดยไม่ต้องได้รับทั้งพื้นที่ทำงาน ดีไซน์: [Report studio](https://phishdestroy.github.io/TgWitness/th/docs/reports/) จุดอ้างอิงที่เชื่อถือได้: [การตรวจสอบการส่งออก](https://phishdestroy.github.io/TgWitness/th/docs/exports/)
