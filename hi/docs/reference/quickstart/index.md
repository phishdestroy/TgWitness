TgWitness टेलीग्राम समूहों और चैनलों को देखने के लिए एक स्टैंडअलोन एप्लिकेशन है, जिन्हें आपके खाते एक्सेस कर सकते हैं। यह अपनी स्वयं की डेटा निर्देशिका के साथ स्थानीय रूप से चलता है।

**पहली बार आए हैं?** कोई खाता कनेक्ट करने से पहले [डेमो देखें](https://phishdestroy.github.io/TgWitness/hi/docs/reference/quickstart/#explore-the-interface)। प्रॉक्सी, विटनेस, एक्सपोर्ट या सर्वर सेटअप के लिए [एक गाइड चुनें](https://github.com/phishdestroy/TgWitness/blob/main/docs/README.md)।

## इंस्टॉल करें और शुरू करें

[GitHub Actions से संग्रह (पूर्वावलोकन)](https://github.com/phishdestroy/TgWitness/blob/main/docs/SEALED-ACTIONS.md)

एक विधि चुनें। पोर्टेबल डाउनलोड एक रिलीज़ बिल्ड प्रकाशित होने के बाद उपलब्ध हो जाते हैं:

| होस्ट | कुछ भी स्थापित नहीं | स्रोत: पाइथन 3.11+ | Docker: इंजन/डेस्कटॉप कम्पोज़ 2.20+ के साथ |
| --- | --- | --- | --- |
| विंडोज | GitHub रिलीज़ से `TgWitness-<version>-windows-amd64-portable.zip` निकालें, `TgWitness.cmd` पर डबल-क्लिक करें | `Start.cmd` पर डबल-क्लिक करें | `scripts\Docker.cmd` पर डबल-क्लिक करें |
| लिनक्स / मैकओएस | — | `sh start.sh` | `sh scripts/docker-start.sh` |

सोर्स मेथड्स के लिए, GitHub रिलीज़ से सोर्स ZIP डाउनलोड और एक्सट्रेक्ट करें या रिपॉजिटरी को क्लोन करें। `Start.cmd` आपके विंडोज यूज़र के लिए पाइथन 3.12 इंस्टॉल करने का विकल्प देता है यदि कोई उपयुक्त पाइथन नहीं मिलता है (winget, या साइन किए गए python.org इंस्टॉलर)। `start.sh` यदि पाइथन मौजूद नहीं है तो आपके लिनक्स डिस्ट्रिब्यूशन या मैकोस के लिए सटीक इंस्टॉल कमांड प्रिंट करता है। पहला सोर्स लॉन्च `.venv` बनाता है और निर्भरता को स्वचालित रूप से इंस्टॉल करता है।

Docker एप्लिकेशन का निर्माण करता है और इसे पृष्ठभूमि में शुरू करता है; होस्ट Python अनावश्यक है। `scripts\Docker.cmd` और `scripts/docker-start.sh` कंटेनर स्वस्थ होने पर पैनल का पता और टोकन प्रिंट करते हैं। प्रत्येक समर्थित होस्ट पर समकक्ष Docker कमांड हैं:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

http://127.0.0.1:8787 खोलें। Docker हेल्पर या दूसरी Docker कमांड द्वारा प्रिंट किए गए टोकन का उपयोग करें, या पोर्टेबल या सोर्स इंस्टॉलेशन के लिए **data/live/panel-token.txt** पढ़ें। नीचे **'टेलीग्राम कनेक्ट करें**' पर जारी रखें। नेटिव और डॉकर इंस्टॉलेशन अलग-अलग स्टोरेज का उपयोग करते हैं; डॉकर शुरू करने पर मौजूदा नेटिव जर्नल आयात नहीं होता है।

एक सर्वर के लिए, [डिप्लॉयमेंट](https://phishdestroy.github.io/TgWitness/hi/docs/reference/deployment/) में स्वचालित HTTPS, रीस्टार्ट, प्रकाशित छवियाँ, अपडेट और बैकअप शामिल हैं।

## इंटरफ़ेस का अन्वेषण करें

1. पोर्टेबल पैकेज में **TgWitness-Demo.cmd** , विंडोज स्रोत फ़ोल्डर में **scripts\Demo.cmd** , या लिनक्स/मैकओएस पर `sh start.sh --demo` चलाएँ। एक स्रोत लॉन्च पहले `.venv` बनाता है और निर्भरताएँ इंस्टॉल करता है।
2. **http://127.0.0.1:8787** खोलें।
3. स्थानीय डेमो स्वचालित रूप से नमूना जर्नल खोलता है। सीधे स्थानीय पहुँच के लिए टोकन कॉपी की आवश्यकता नहीं है।

डेमो संदेश काल्पनिक हैं। डेमो मोड वास्तविक टेलीग्राम खाते से कनेक्ट नहीं कर सकता।

## टेलीग्राम कनेक्ट करें

> [!चेतावनी] **किसी भी ऐसी चीज़ का उपयोग न करें जिसे आप खोने का जोखिम नहीं उठा सकते।** हम व्यक्तिगत या मूल्यवान खातों को जोड़ने और किसी ऐसे खाते पर API ID / हैश बनाने के खिलाफ दृढ़ता से सलाह देते हैं जिसे आप महत्व देते हैं। टेलीग्राम क्लाइंट की परवाह किए बिना, अप्रत्याशित रूप से और अक्सर स्थायी रूप से खातों पर प्रतिबंध लगाता है। एक सुचारू परीक्षण रन टेलीग्राम पर निर्भर करता है, न कि TgWitness पर, और बाद के लिए कोई गारंटी नहीं देता।

1. यदि नेटिव डेमो चल रहा है, तो उसे रोकें और **Start.cmd** या `sh start.sh` चलाएँ। अन्यथा, ऊपर चल रही लाइव इंस्टॉलेशन को चालू ही रखें।
2. पैनल खोलने के लिए अपने इंस्टॉलेशन विधि के लिए पैनल टोकन का उपयोग करें।
3. यदि आपको प्रॉक्सी की आवश्यकता है, तो इसे **Account → Settings → Connection settings → Change connection route** में सहेजें।
4. खाते में, अपना फ़ोन नंबर दर्ज करें और जारी रखें दबाएँ, QR कोड → QR कोड दिखाएँ चुनें, या फ़ाइलें चुनें और खाते को कनेक्ट करें दबाएँ। API ID + हैश वैकल्पिक है: वर्कस्पेस अपनी सहेजी गई या आयात की गई जोड़ी का उपयोग करता है, या अंतर्निर्मित पूल से एक काम करने वाली जोड़ी का उपयोग करता है। अपना ऐप उपयोग करने के लिए, API ID में एक `API ID:API Hash` जोड़ी पेस्ट करें। एक पूर्ण ऑथराइज़ेशन कुंजी के लिए, Auth key चुनें, सभी 512 हेक्साडेसिमल अक्षर पेस्ट करें, और प्रदान की गई DC ID चुनें। यूज़र आईडी वैकल्पिक है और दर्ज करने पर जाँची जाती है।
5. अपनी चुनी हुई साइन-इन विधि पूरी करें: फ़ोन/कोड/2FA, QR के लिए साइन-इन किए हुए टेलीग्राम ऐप से पुष्टि, या एक समर्थित अधिकृत सत्र आयात।
6. प्रदर्शित खाता आईडी की जाँच करें। खुले स्रोत: आपकी चैट्स स्वचालित रूप से लोड होती हैं; अपने समूह जोड़ें।
7. **'किस परिवर्तन को संरक्षित किया जाए**' के अंतर्गत, इवेंट श्रेणियाँ या **'संदेश, संपादन और हटाने'** प्रीसेट चुनें, फिर निगरानी सेटिंग्स सहेजें।
8. संलग्नक सेटिंग्स को अलग से चुनें, फिर **अवलोकन शुरू** करें।

एपीआई क्रेडेंशियल आपके एप्लिकेशन की पहचान करते हैं; वे स्वयं खाते को अधिकृत नहीं करते हैं। निजी समूहों को सार्वजनिक उपयोगकर्ता नाम की आवश्यकता नहीं होती है, लेकिन आपके खाते को एक्सेस होना चाहिए।

मौजूदा खातों के लिए, [खाते और सत्र प्रारूप](https://phishdestroy.github.io/TgWitness/hi/docs/reference/accounts/) देखें: पैनल Telethon StringSession, Telethon/Pyrogram SQLite, एकल-खाते TData ZIP, और समर्थित खाते JSON को स्वीकार करता है। एक सत्र और उसके साथी JSON को एक साथ चुनें, **'खाता कनेक्ट करें**' दबाएँ। QR लॉगिन भी समान वैकल्पिक API सेटिंग्स के साथ उपलब्ध है। TDLib, बॉट्स, और थोक खाता सूचियाँ समर्थित नहीं हैं।

एक और खाता जोड़ने के लिए, खाता चयनकर्ता के बगल में + दबाएँ या खाता → सेटिंग्स → कनेक्शन सेटिंग्स → वर्कस्पेस खोलें, या खातों का उपयोग करें। वर्कस्पेस के अलग-अलग सत्र, जर्नल, कुंजी, स्रोत और कतारें होती हैं। दृश्य बदलने पर अन्य कलेक्टर चलते रहते हैं। इस इंस्टॉलेशन में एक ही टेलीग्राम खाते को दो वर्कस्पेस में असाइन नहीं किया जा सकता। वर्कस्पेस की कोई निश्चित संख्या नहीं है; वे एक ही प्रक्रिया साझा करते हैं, इसलिए क्षमता मशीन पर निर्भर करती है।

लाइव पैनल टोकन आपके टेलीग्राम अधिकृतकरणों और सहेजी गई सामग्री तक पहुंच की सुरक्षा करता है; यह टेलीग्राम एपीआई क्रेडेंशियल्स से अलग है। केवल एक स्पष्ट रूप से शुरू किया गया, सीधे एक्सेस किया गया स्थानीय डेमो ही स्वचालित रूप से प्रवेश पाता है। एक रिमोट/प्रॉक्सी वाला डेमो अभी भी `data/demo/panel-token.txt` का उपयोग करता है।

## समीक्षा और निर्यात

- **जर्नल:** स्रोत और घटना प्रकार के अनुसार अवलोकनों को खोजें और फ़िल्टर करें।
- किसी घटना का चयन करें ताकि उसके मूल रिकॉर्ड, श्रेय और सहेजे गए संस्करणों का निरीक्षण किया जा सके।
- संपादन विवरण उपलब्ध पहले/बाद की सामग्री दिखाते हैं। मिटान विवरण दिखाते हैं अंतिम कैप्चर की गई सामग्री, यदि कोई हो; एक अज्ञात कर्ता अज्ञात बना रहता है।
- निर्यात: हस्ताक्षरित ZIP, JSONL, CSV और ऑफ़लाइन HTML।
- **पूर्ण चैट एक्सपोर्ट** (स्रोत → पूर्ण चैट एक्सपोर्ट): किसी एक चैट का पूरा दृश्यमान इतिहास `chat.json` के साथ एक हस्ताक्षरित बंडल के रूप में डाउनलोड करें (टेलीग्राम-एक्सपोर्ट शैली) और एक पठनीय `chat.html`। निजी चैट तब काम करती हैं जब खाता एक सदस्य हो। यह एक वर्तमान स्नैपशॉट है, न कि हटाए गए या पहले संपादित संदेशों का पुनर्निर्माण। `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256` के साथ एक प्रति की सत्यापित करें।
- **चेकपॉइंट सहेजें:** हस्ताक्षरित जर्नल की सीमा कलेक्टर के बाहर रखें।
- **हस्ताक्षरित रन रसीद डाउनलोड करें:** कलेक्टर के प्रोग्राम/संस्करण रिकॉर्ड को संरक्षित करें।
- **टाइमस्टैम्प अनुरोध तैयार करें:** टाइमस्टैम्प प्राधिकरण के लिए एक ऑफ़लाइन अनुरोध तैयार करें; प्रतिक्रिया प्राप्त करने और सत्यापित करने के लिए [TIMESTAMP.md](https://phishdestroy.github.io/TgWitness/hi/docs/reference/timestamp/) का पालन करें।
- **जर्नल सत्यापित करें:** इवेंट हस्ताक्षरों और चेन लिंक की जाँच करें। ZIP एक्सपोर्ट मीडिया की भी जाँच करता है।

समर्थित ब्राउज़र बड़ी एक्सपोर्ट्स को सीधे एक चुनी हुई फ़ाइल में सेव करते हैं। अन्य ब्राउज़र अधिकतम 128 MiB तक बफ़र करते हैं। जब सर्वर चल रहा हो, तो स्ट्रीमिंग CLI पूरे रिस्पॉन्स को बफ़र किए बिना बड़े डाउनलोड्स को सपोर्ट करता है:

```
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

किसी अन्य वर्कस्पेस के लिए, **एक्सपोर्ट्स → वर्कस्पेस आईडी** का उपयोग करके `--profile ID` जोड़ें। एक रिमोट सर्वर के लिए, `--url https://your-server` जोड़ें। डिफ़ॉल्ट ट्रांसफर सीमा है 5 GiB; `--max-mib` इसे बदलता है। हस्ताक्षरित ZIP सामग्री की डिफ़ॉल्ट बिना-संपीडित सत्यापन सीमा अलग से 4 GiB है (**Parameters** इसे बढ़ाता है; ऐसे आर्काइव को `verify.py --max-gib N` से सत्यापित करें)। सत्यापनकर्ता की एक विश्वसनीय प्रति और स्वतंत्र रूप से रखे गए कुंजी फिंगरप्रिंट/चेकपॉइंट का उपयोग करके आर्काइव को सत्यापित करें।

## स्थापना की जाँच करें

```
python start.py --setup-only

python start.py --check --json
```

`--check` स्थानीय निर्भरताएँ, हस्ताक्षर समर्थन, भंडारण, कुंजी कॉन्फ़िगरेशन और लिसनिंग एड्रेस की जाँच करता है। यह कुछ भी इंस्टॉल नहीं करता है या टेलीग्राम से कनेक्ट नहीं होता है। एक व्यस्त पोर्ट का मतलब हो सकता है कि कोई दूसरा इंस्टेंस चल रहा है। एक अलग `--port` का उपयोग करें या पहले इसे बंद कर दें।

लॉन्चर `.venv` में इंस्टॉल होता है। सहायक `python -m tgwitness...` कमांड्स को विंडोज पर `.venv\Scripts\python.exe` या लिनक्स/मैकओएस पर `.venv/bin/python` का उपयोग करना चाहिए, जब तक कि वह वातावरण पहले से सक्रिय न हो।

## सत्र, सुरक्षा और संचालन

एक बंद, सुसंगत Telethon SQLite `.session` को स्थानीय रूप से `python -m tgwitness.sessions account.session --out account.tgwitness-session` के साथ परिवर्तित किया जा सकता है, फिर इसे अकाउंट में लोड किया जा सकता है। डायरेक्ट फ़ाइल इम्पोर्ट और QR लॉगिन भी उपलब्ध हैं। लॉगिन फ़ॉर्मेट, SOCKS5, HTTP CONNECT, MTProxy और बाहरी मास्टर कीज़ के लिए [CONNECTION-SECURITY.md](https://phishdestroy.github.io/TgWitness/hi/docs/reference/connection/) देखें।

**अवलोकन रोकें** संग्रहण रोकता है। **लॉक करें** केवल ब्राउज़र से पहुँच बंद करता है। टैब बंद करने पर संग्रहण प्रक्रिया चलती रहती है। प्रक्रिया रोकने से संग्रहण रुक जाता है; इतिहास का स्नैपशॉट सभी छूटे हुए संपादनों या हटाए गए संदेशों को पुनः प्राप्त नहीं कर सकता। इवेंट नीतियों, अटैचमेंट कतारों, खातों के पृथक्करण और दोबारा शुरू करने के व्यवहार के लिए [संग्रहण कैसे काम करता है](https://phishdestroy.github.io/TgWitness/hi/docs/reference/collection/) देखें।

सत्र और रहस्य एन्क्रिप्ट किए जाते हैं। संदेश की सामग्री, मीडिया और एक्सपोर्ट के लिए एक एन्क्रिप्टेड डिस्क या वॉल्यूम की आवश्यकता होती है। हस्ताक्षर एक विश्वसनीय कुंजी के सापेक्ष अखंडता स्थापित करते हैं; वे टेलीग्राम उत्पत्ति स्थापित नहीं करते हैं या एक ऑपरेटर द्वारा जालसाजी को नहीं रोकते हैं जो कलेक्टर और उसकी कुंजी को नियंत्रित करता है।
