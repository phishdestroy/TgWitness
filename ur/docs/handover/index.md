# Telegram · شیئر کرنے کے لیے ایک کاپی تیار کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/handover/

صرف ضروری چیز شیئر کریں، اصل جوں کا توں رہتا ہے۔

حوالگی ایک الگ دستخط شدہ اقتباس ہے: چیٹس اور افراد چنیں، شناخت یا متن چھپائیں، فائلیں اور ٹیم نوٹس چنیں۔ مینی فیسٹ درج کرتا ہے کیا رکھا، کاٹا اور نکالا گیا۔

## موصول کنندہ کا استخراج تیار کریں

1. **ایکسپورٹس ← حوالگی اقتباس**: مقصد لکھیں، چیٹس اور مدت چنیں، نام والے افراد چاہئیں تو **منتخب چیٹس کے افراد لوڈ کریں**۔
2. باقی سب: فرضی نام، خارج، یا جیسا درج ہے۔ متن اور فائلیں الگ سوئچ ہیں؛ فون اور ای میل چھپائے جا سکتے ہیں۔
3. Case Board: کچھ نہیں، بک مارکس اور سلائسز، یا تبصروں والے کارڈز۔ ٹیم کے نام عرفیت سے بدلے جا سکتے ہیں۔
4. **حوالگی اقتباس ڈاؤن لوڈ کریں**، کھولیں، تصدیق کریں، بھیجنے سے پہلے دیکھ لیں۔

### ایک اصل، ایک جان بوجھ کر شیئر کرنے کے لیے کاپی

مصنوعی مثال · صرف شناختی وضاحت کے لیے

1. **منتخب کریں۔** کیس چیٹ شامل کریں اور اس شخص کی شناخت کریں جس کے بارے میں اقتباس ہے۔
2. **کم کریں۔** شیئر کی گئی کاپی میں دوسرے شرکاء کی نمائش کا طریقہ منتخب کریں۔
3. **معائنہ کریں۔** بھیجنے سے پہلے تیار کردہ آرکائیو کی رپورٹ اور ریکارڈز کھولیں۔
4. **شیئر کریں۔** تصدیق شدہ کاپی فراہم کریں اور اس کے قابلِ اعتماد فنگر پرنٹ کو الگ سے مطلع کریں۔

#### موصول کنندہ کی کاپی

جیسا ریکارڈ کیا گیا ہے دکھائیں: نورا · صارف 71002 · "مجھے نظر ثانی شدہ لنک موصول ہوا۔"

تخفیفی نام: P01 · "مجھے نظر ثانی شدہ لنک موصول ہوا۔"

چھوڑیں: اس شرکاء کا پیغام کاپی سے خارج کیا گیا ہے۔

#### اصل فائلوں کا معائنہ کریں

report.html اور records.jsonl پڑھیں۔

شناختیں، متن، منسلکات اور اختیاری ٹیم تبصرے چیک کریں۔

#### دستخط شدہ اقتباس

انتخاب + فائل ہیشز + دستخط شدہ منیفیسٹ

ایک الگ پیکیج جو اپنے ماخذ جرنل کی حد سے منسلک ہے

## کنٹرولز کو ایک ساتھ استعمال کریں

| کنٹرول | نسخے پر اثر |
| --- | --- |
| لوگ | منتخب افراد کے نام رہتے ہیں؛ باقی کو فرضی نام ملتے ہیں یا خارج ہوتے ہیں۔ |
| متن | تمام متن، صرف منتخب افراد اور آپ کے اکاؤنٹ کا، یا کچھ نہیں۔ |
| فائلیں | منتخب افراد اور آپ کے اکاؤنٹ کی فائلیں، تمام دکھائی گئی فائلیں، یا کچھ نہیں۔ |
| کیس بورڈ | کچھ نہیں، بک مارکس اور سلائسز، یا بحث والے کارڈز۔ |

متن اور فائلیں بھی پڑھیں: فرضی نام پیغام یا اٹیچمنٹ کے اندر لکھے ناموں کو نہیں ہٹاتا۔ اگر منتخب فائل غائب ہو تو اسے بحال کریں یا اٹیچمنٹس نکال دیں۔

## متن کو آزادانہ طور پر تصدیق کے قابل رکھیں

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

اصل آرکائیو اور چیک پوائنٹس خود رکھیں۔ وصول کنندہ پوری ورک اسپیس لیے بغیر اپنی کاپی کی تصدیق کر سکتا ہے۔ ڈیزائن: [Report studio](https://phishdestroy.github.io/TgWitness/ur/docs/reports/)۔ قابلِ اعتماد حوالے: [ایکسپورٹ کی تصدیق](https://phishdestroy.github.io/TgWitness/ur/docs/exports/)۔
