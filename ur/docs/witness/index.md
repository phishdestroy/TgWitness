## دو ہوسٹس، دو دستخطی کلیدیں

منسلک کلیکٹر فنگر پرنٹ الگ وِٹنس دستخطی کلید

اپنا جرنل + بوٹ ٹوکن

گواہ → ٹیلیگرام بوٹ API →**آپ کا چینل · TGW1 کے دستخط شدہ پوسٹس**

ویٹنس خود چیکس کھینچتا ہے۔ کلیکٹر کی رسائی صرف پڑھنے تک محدود ہے۔ بوٹ کی اشاعت ویٹنس کے کنکشن اور ٹوکن کا استعمال کرتی ہے؛ ویٹنس کو کوئی اکاؤنٹ سیشن نہیں دیا جاتا۔

قبول شدہ: تعداد بڑھ رہی ہے، دستخط تصدیق شدہ ہیں اور کلید میل کھاتی ہے۔ گواہ اس نئی حد کو برقرار رکھتا ہے۔

تمام جوابی مثالیں ایک درست دستخط اور پن کی ہوئی کلید کو فرض کرتی ہیں۔ یہاں ہیشز مختصر مثالیں ہیں۔ صرف زیادہ تعداد سے یہ ثابت نہیں ہوتا کہ پورا پرانا پری فکس بغیر تبدیلی کے ہے؛ برقرار رکھے گئے چیک پوائنٹس کے ساتھ ایک ایکسپورٹ کا موازنہ کریں۔

## ایک بوٹ اور ایک چینل تیار کریں

BotFather سے بوٹ بنائیں اور اسے اپنے چینل میں پوسٹ کرنے دیں۔ گواہ کہیں اور چلائیں: دوسرا ہوسٹ، بہتر ہے کوئی اور چلائے، کلیکٹر کے ساتھ دوسرے عمل سے کہیں زیادہ قیمتی ہے۔

## Extras میں تین مراحل

1. **صرف پڑھنے کی رسائی۔** **اضافی ← آزاد گواہ**، ٹوکن بنائیں، فائل محفوظ کریں۔ یہ صرف چیک پوائنٹس اور صحت پڑھتا ہے۔
2. **چینل اور وقفہ۔** Telegram چینل یا Discord webhook، ساتھ کلیکٹر کا پتہ جس تک گواہ پہنچ سکے۔ سیٹنگز فائل محفوظ کریں۔
3. **آغاز۔** `witness.json`، `witness-token.txt` اور `bot-token.txt` گواہ ہوسٹ پر ایک ساتھ رکھیں اور چلائیں:

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

چینل میں پہلی دستخط شدہ پوسٹ کا انتظار کریں، پھر گواہ کا فنگر پرنٹ محفوظ جگہ رکھیں۔

اس کی بجائے Discord؟ webhook URL کو `discord-webhook.txt` کے طور پر محفوظ کریں۔ ایک گواہ ایک جگہ پوسٹ کرتا ہے؛ لمبی جانچیں Discord پر فائل کی صورت آتی ہیں۔

## شائع کرنے کی تعدد منتخب کریں

ہر جانچ پوسٹ کرنے سے باقاعدہ بیرونی ریکارڈ بنتا ہے: ہر پانچ منٹ یعنی فی ورک اسپیس روزانہ تقریباً 288 پوسٹس۔ ایڈوانس سیٹنگز صرف تبدیلیوں یا مسائل پر پوسٹ، پراکسی یا کسٹم Bot API استعمال کر سکتی ہیں۔

**یہ بوٹ حقیقت میں کس چیز کی تصدیق کرتا ہے؟**

یہ کلیکٹر سے دستخط شدہ چیک پوائنٹ مانگتا ہے، متوقع کلید سے جانچتا ہے اور اپنا دستخط شدہ جرنل رکھتا ہے، چھوٹے اور مسترد جوابات سمیت۔

یہ جرنل کی حالت جانچتا ہے، خود Telegram پر نظر نہیں رکھتا۔ اس کے لیے کنٹرول شدہ ترسیل ٹیسٹ چلائیں۔

## بعد میں شواہد چیک کریں

گواہ کا جرنل، پوسٹس اور فنگر پرنٹس رکھیں۔ کلیکٹر کے ایکسپورٹ کے مقابل [انہیں کیسے جانچیں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/witness/#verify)۔
