# इसे चालू रखें

Canonical page: https://phishdestroy.github.io/TgWitness/hi/docs/server/

कलेक्टर को उपलब्ध रखें और पुनरारंभों के दौरान इसके डेटा को अक्षुण्ण रखें।

## लॉन्च विधि चुनें

नेटिव इंस्टॉलेशन के लिए, [deploy/](https://github.com/phishdestroy/TgWitness/blob/main/deploy/README.md) में दिए गए [लॉन्चर](https://phishdestroy.github.io/TgWitness/hi/docs/start/) और सेवा उदाहरणों का उपयोग करें। Docker के लिए, Compose के साथ Docker इंस्टॉल करें और प्रोजेक्ट डायरेक्टरी से चलाएँ:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

डिफ़ॉल्ट पैनल होस्ट के लूपबैक एड्रेस, पोर्ट 8787 पर सुनता है। इसे स्थानीय रूप से या SSH टनल के माध्यम से खोलें। पैनल को अनलॉक करने के लिए दूसरी कमांड से प्राप्त टोकन का उपयोग करें।

## पूरे डेटा निर्देशिका को रखें

नेटिव इंस्टॉलेशन `data/live` का उपयोग करते हैं। डॉकर स्थायी `tgwitness-data` वॉल्यूम का उपयोग करता है। जर्नल, खाता सत्र, कुंजियाँ और परिचालन स्थिति एक साथ रखें। एक हस्ताक्षरित एक्सपोर्ट उपयोगी साक्ष्य है, लेकिन यह पूर्ण इंस्टॉलेशन बैकअप नहीं है।

1. सुसंगत बैकअप लेने से पहले संग्रहण बंद करें।
2. पूरे निजी डेटा निर्देशिका की प्रति होस्ट के बाहर सुरक्षित भंडारण में कॉपी करें।
3. बैकअप पर निर्भर करने से पहले एक अलग इंस्टॉलेशन में पुनर्स्थापना का परीक्षण करें।

## पुनरारंभ के बाद जाँचें

अपेक्षित कार्यक्षेत्र और कुंजी, टेलीग्राम कनेक्शन, चयनित स्रोत और नए संदेश कैप्चर की पुष्टि करें। सहेजा गया MTProto राज्य और कैच-अप सहायता उन अपडेट्स को पुनः प्राप्त करने में मदद करते हैं जिन्हें टेलीग्राम अभी भी रखता है। वे हर समाप्त हो चुके अपडेट या कैप्चर से पहले हटाए गए संपादन को पुनर्स्थापित नहीं कर सकते।

कंटेनर स्वास्थ्य का अर्थ है कि वेब सर्वर प्रतिक्रिया देता है। संग्रहण और बाहरी प्रकाशन का आकलन करने के लिए एक नियंत्रित संदेश और एक विटनेस चेक का उपयोग करें।

## केवल वही प्रकाशित करें जो आपका इरादा हो

डिप्लॉयमेंट संदर्भ में HTTPS उदाहरण, पर्सिस्टेंट-वॉल्यूम कमांड, अपडेट और पुनर्स्थापना चरण शामिल हैं। डिप्लॉयमेंट के लिए Docker कमांड प्रदान किए गए हैं; वर्तमान [वैलिडेशन रिकॉर्ड](https://phishdestroy.github.io/TgWitness/hi/docs/reference/verification/) वास्तव में परीक्षण किए गए वातावरणों की पहचान करता है।
