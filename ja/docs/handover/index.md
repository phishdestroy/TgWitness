# 共有用コピーを作成してください

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/handover/

元のワークスペースをそのまま維持しつつ、関連する所見を共有してください。

引き渡しとは、別途署名された抜粋のことです。チャットや人物を選択し、個人情報を削除またはテキストを短縮し、どのファイルやチームノートを受取人のコピーに含めるかを決定します。そのマニフェストには、選択内容と、変更なし、短縮、および省略された記録の数が記録されます。

## 受信者向けの抜粋を作成する

1. **[エクスポート] → [引き渡し用抽出]** を開きます。その目的を記入し、チャットと任意のUTC期間を選択した後、対象者の氏名が必要な場合は、[**選択したチャットの人物を読み込む]** を選択してください。
2. その他のユーザーについては、仮名を使用するか、メッセージを省略するか、記録どおりに表示するかを選択できます。メッセージ本文と添付ファイルは個別に設定でき、必要に応じて電話番号やメールアドレスをマスクすることも可能です。
3. 「Case Board」のブックマークやスライスを含めるか、コメント付きのカードを含めるかを選択してください。この文章では、チーム名の代わりに調査担当者の別名を使用することができます。
4. **「ダウンロード引継ぎ抽出」**を選択してください。生成されたレポートと選択した記録をローカルで開き、アーカイブを確認し、送信前にコピーを点検してください。

## 各操作を組み合わせて使用してください

| 制御 | 翻訳文への影響 |
| --- | --- |
| 人物 | 対象となる人物については識別可能な状態を維持し、その他の参加者については、必要に応じて仮名化または省略してください。 |
| テキスト | すべてのテキストを含めるか、選択された人物および観察用アカウントのテキストのみを含めるか、あるいはメッセージ本文とそのテキストを含む詳細フィールドを省略するかを選択してください。 |
| ファイル | 選択した人物および監視対象アカウントのファイル、表示されたすべてのメッセージのファイル、またはファイルなしのいずれかを選択してください。 |
| Case Board | ボード素材、ブックマーク、スライス、およびチームディスカッションを含むカードは使用しないでください。 |

自由形式のテキストやファイルの内容、および身元情報も確認してください。仮名を使用しても、メッセージや添付ファイルに記載されたすべての名前が自動的に削除されるわけではありません。選択した保存用ファイルが利用できない場合は、抽出データを生成する前に、そのファイルを復元するか、添付ファイルを明示的に除外してください。

## 翻訳文は、独立して検証可能であるようにしてください。

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

署名済みの元の証拠アーカイブとチェックポイントは、別々に保管してください。引き渡しプロセスでは独自の投影データが記録されるため、受領者はワークスペース全体を受け取ることなく、引き渡されたコピーを確認できます。[Report Studio](https://phishdestroy.github.io/TgWitness/ja/docs/reports/)は独自の表示デザインを提供し、[エクスポート検証機能では](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)信頼できる参照元について説明しています。
