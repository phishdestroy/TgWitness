# عوامی نمائش

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/reference/showcase/

منتخب عوامی چینلز کے محفوظ شدہ پیغامات اور دستخط شدہ سنپ شاٹس کو ختم ہونے والے، منسوخ کیے جانے والے لنکس کے ذریعے شائع کریں۔

**رسائی → عوامی نمائش** موجودہ access-token سسٹم استعمال کرتے ہوئے ایک الگ، صرف-پڑھنے والا صفحہ بناتا ہے۔ یہ تنصیب میں محفوظ شدہ مشاہدات پڑھتا ہے۔ یہ کلیکٹر شروع نہیں کرتا، ٹیلیگرام میں سائن ان نہیں کرتا اور زائر کے لیے کوئی چینل حاصل نہیں کرتا۔

## صفحہ شائع کریں

1. ہر عوامی چینل کے لیے جسے آپ دکھانا چاہتے ہیں، ایک ماخذ پروفائل محفوظ کریں۔ ایک چینل کے لیے ضروری ہے کہ اس کے تازہ ترین محفوظ شدہ پروفائل میں ایک عوامی صارف نام ہو؛ گروپس اور نجی چیٹس اہل نہیں ہیں۔
2. اوپن **ایکسس → عوامی نمائش** (یا `/showcase-manage.html`) بطور منتظم۔
3. 16 ورک اسپیسز تک کے چینلز منتخب کریں، عوامی صفحے کا عنوان درج کریں، اور لنک کی میعاد 1، 7 یا 30 دن کے لیے منتخب کریں۔ اندرونی ورک اسپیس لیبلز شائع نہیں کئے جاتے۔ 64 چینلز تک شامل کیے جا سکتے ہیں۔
4. منتخب چینلز کے متن کو اشاعت کے لیے جائزہ لیں، پھر **'منتخب ریکارڈز کا پیش نظارہ' پر** کلک کریں۔ پیش نظارہ وزیٹر صفحے کی طرح سرور سائیڈ پروجیکشن استعمال کرتا ہے۔
5. **'Create showcase' کے لنک پر** کلک کریں۔ جب تک یہ دکھائی دے رہا ہو، لنک کاپی کریں۔ اسے تقسیم کرنے سے پہلے وصول کنندہ کے صفحے کا جائزہ لینے کے لیے ایک الگ براؤزر میں کھولیں۔

لنک کے یو آر ایل فرگمنٹ میں ایک ایکسیس ٹوکن ہوتا ہے۔ صفحہ API کی درخواستیں کرنے سے پہلے اس فرگمنٹ کو ہٹا دیتا ہے اور اسے ایک براؤزر سیشن کے لیے تبدیل کر دیتا ہے۔ جو کوئی بھی لنک رکھتا ہے وہ منتخب کردہ مواد کو ختم ہونے یا منسوخ ہونے تک کھول سکتا ہے۔ نئے لنکس 100 بیک وقت سیشنز کی اجازت دیتے ہیں، جن میں سے ہر ایک زیادہ سے زیادہ ایک گھنٹہ جاری رہتا ہے۔ موجودہ ایکسیس کنٹرولز گرانٹ API کے ذریعے پتے کی پابندیاں اور سائن ان کی حدیں بھی نافذ کر سکتے ہیں۔ عام جائزہ نگار کی رسائی ایک مختلف موڈ ہے اور اس میں اب بھی اصل اجازت یافتہ پیغامات اور فائلیں شامل ہیں۔

## زائرین کو کیا دکھائی دیتا ہے

| نظر آنے والا | نجی رکھا گیا |
| --- | --- |
| منتخب عوامی چینل کے عنوانات، صارف نام اور پروفائل مشاہدے کی تاریخیں | اکاؤنٹ کی شناختیں، اندرونی ورک اسپیس کے لیبلز اور غیر منتخب شدہ ذرائع |
| محفوظ شدہ متن اور ہر محفوظ شدہ ترمیم | ساخت شدہ بھیجنے والی شناختیں، نام، صارف نام، فون نمبر اور پروفائل کی قدریں |
| مٹانے کے مشاہدات، اگر پہلے محفوظ شدہ متن دستیاب ہو۔ | منسلکات، اوتار، تھمب نیلز، فائل کے نام اور اصل پے لوڈ |
| وہ نشانات جو بتاتے ہیں کہ کوئی مصنف/پروفائل یا منسلک ریکارڈ کیا گیا تھا | فارورڈنگ اور جواب کے میٹا ڈیٹا، نیٹ ورک راستے، آئی پی پتے اور اسناد |
| منتخب چینلز کے واقعات کی تعداد، موجودہ کلیکشن سوئچز، دل کی دھڑکن اور چیک پوائنٹ وقفہ | جمع کنٹرولز اور عام ثبوت برآمد کرنے والی APIs |
| فنگر پرنٹ پر دستخط، جرنل چیک پوائنٹ اور مطابقت کا ثبوت | دستخطی کلیدیں اور ٹیلیگرام سیشنز |

**عوامی پیغام کا متن خودکار طور پر گمنام نہیں کیا جاتا۔** پیغام میں لکھا گیا نام، ذکر، فون نمبر یا لنک اس متن کا حصہ رہتا ہے۔ `Redacted`یہ ساخت یافتہ مصنف/پروفائل فیلڈز پر لاگو ہوتا ہے۔ شائع کرنے سے پہلے اصل منتخب کردہ مواد کا جائزہ لیں، بشمول محفوظ شدہ ترامیم اور حذف شدگیاں۔

اہلیت **تازہ ترین محفوظ شدہ ماخذ پروفائل** کی عکاسی کرتی ہے، نہ کہ لائیو ٹیلیگرام تلاش کی۔ اگر بعد کے پروفائل میں اب عوامی چینل کا صارف نام نہ ہو تو نئی درخواستیں چینل کو خارج کر دیتی ہیں۔ جب عوامی نمائش تبدیل ہو تو ماخذ پروفائلز کو ریفریش کریں۔ قارئین کے پاس پہلے موصول شدہ مواد پہلے سے ہی محفوظ ہو سکتا ہے۔

اصل دستخط شدہ ریکارڈز بغیر تبدیلی کے رہتے ہیں۔ دکھائی گئی پیش گوئی الگ سے دستخط کی جاتی ہے اور اس میں اس کے اصل ریکارڈز کے حوالہ جات کے ہیشز شامل ہوتے ہیں۔ ایک پیش گوئی کا دستخط دکھائی گئی عبارت کی تصدیق کرتا ہے؛ یہ حذف شدہ بائٹس پر اصل واقعے کے دستخط نہیں ہوتا۔

## دستیخطوں اور تسلسل کی جانچ کریں

**فنگر پرنٹ اور دستخط شدہ چیک پوائنٹ** کو وسعت دیں اور ایک سنپ شاٹ ڈاؤن لوڈ کریں۔ صفحہ ریفریش ہونے کے بعد، ڈاؤن لوڈ میں پچھلا براؤزر سنپ شاٹ اور ان کے جرنل کی حدوں کے درمیان مرکل مطابقت کا ثبوت شامل ہوتا ہے۔ خودکار ریفریش اس وقت ہوتا ہے جب صفحہ دکھائی دے رہا ہو اور مشاہدات کا پہلا صفحہ دکھا رہا ہو، ایک منٹ میں ایک بار۔

TgWitness انسٹال ہونے کے ساتھ، ڈاؤن لوڈ کردہ فائل کو آف لائن تصدیق کریں:

```
python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256
```

فنگر پرنٹ ایک علیحدہ معتبر حوالہ سے ہونا چاہیے۔ خود محفوظ کردہ سنک پک کے خلاف موازنہ کے لیے، استعمال کریں `--previous earlier.json`؛ یہ ڈاؤن لوڈ کے اندر موجود پچھلی سنک اسنیپ شاٹ کو اوور رائیڈ کر دیتا ہے۔ موجودہ ثبوت کو اسی محفوظ شدہ حد سے شروع ہونا چاہیے۔ تصدیق شدہ کلائنٹس اس ثبوت کو استعمال کرتے ہوئے درخواست کر سکتے ہیں `GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>`۔ ایک مختصر جرنل خاموشی سے حد کو ری سیٹ کرنے کے بجائے HTTP 409 واپس کرتا ہے۔

دستخط شدہ چیک پوائنٹ **پورے کلیکٹر جرنل** کو محفوظ کرتا ہے، بشمول اس کے ریکارڈز کی تعداد اور غیر شفاف ہیڈ ہیش۔ دکھائی گئی پیغامات کی تعداد صرف منتخب کردہ عوامی چینلز پر لاگو ہوتی ہے۔ صفحہ کبھی بھی دوسرے جرنل کے مندرجات کی فہرست نہیں دیتا۔ یہ ایونٹس کی تعداد ہیں، نہ کہ منفرد پیغامات کی تعداد۔ ترتیبات موجودہ کنفیگریشن کو بیان کرتی ہیں، نہ کہ ہر پچھلے ریکارڈنگ وقفے کو۔

دستخط اور مطابقت کی تصدیق برقرار رکھی گئی حد کے حوالے سے تبدیلیوں کا پتہ لگا سکتی ہے۔ یہ آزادانہ طور پر دستخط شدہ کاؤنٹرز کو دوبارہ شمار نہیں کرتی، ٹیلیگرام کے ماخذ کی تصدیق نہیں کرتی، بلا تعطل ریکارڈنگ کا مظاہرہ نہیں کرتی، یا کسی آزاد گواہ کو تبدیل نہیں کرتی۔ اس جائزے کے لیے، [شواہد کی تصدیق کنندہ](https://github.com/phishdestroy/TgWitness/blob/main/docs/TRUST.md)، [آزاد گواہ](https://phishdestroy.github.io/TgWitness/ur/docs/reference/witness/) اور [آزمایا گیا ریکارڈ](https://phishdestroy.github.io/TgWitness/ur/docs/reference/verification/) استعمال کریں۔ مصنوعی تنصیبات کو واضح طور پر 'مصنوعی' کے طور پر لیبل کیا گیا ہے۔

## صفحہ منسوخ کریں یا ہوسٹ کریں

لنک کو بند کرنے اور اس کے تمام سیشنز کو ختم کرنے کے لیے شوزکیس مینیجر یا موجودہ **رسائی** سیکشن میں **Revoke** استعمال کریں۔ جب کوئی درخواست یہ معلوم کرتی ہے کہ رسائی ختم ہو چکی ہے تو وزیٹر ظاہر شدہ ریکارڈز کو صاف کر دیتا ہے۔ ہر درخواست پر میعاد ختم ہونے اور اجازتوں کی جانچ کی جاتی ہے۔ شوزکیس گرانٹس کو عام پینل رسائی میں تبدیل نہیں کیا جا سکتا؛ موڈ تبدیل کرنے کے لیے نیا گرانٹ بنائیں۔

صفحہ کو انسٹالیشن کے موجودہ HTTPS پتے کے ذریعے فراہم کریں۔ لنک شائع کرنے سے کوئی نیا پورٹ نہیں کھلتا، کوئی سرنگ نہیں بنتی اور DNS تبدیل نہیں ہوتا۔ HTML اور API صارف کی انسٹالیشن پر ہی رہتے ہیں۔ ایک شوکیس وزیٹر اس رسائی کے ساتھ عام پیغام، پروفائل، میڈیا، ایکسپورٹ یا مینجمنٹ APIs استعمال نہیں کر سکتا۔
