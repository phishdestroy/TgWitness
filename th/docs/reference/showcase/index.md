# แสดงผลงานสาธารณะ

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/reference/showcase/

เผยแพร่ข้อความที่บันทึกไว้จากช่องสาธารณะที่เลือกไว้และภาพสแนปช็อตที่ลงนามแล้ว ผ่านลิงก์ที่มีอายุการใช้งานจำกัดและสามารถยกเลิกได้

[TgWitness](https://github.com/phishdestroy/TgWitness/blob/main/README.md) / [เอกสารประกอบ](https://github.com/phishdestroy/TgWitness/blob/main/docs/README.md) · [การติดตั้งและกู้คืน](https://phishdestroy.github.io/TgWitness/th/docs/reference/deployment/)

![การติดตั้งและกู้คืน](https://phishdestroy.github.io/TgWitness/assets/chapter-operate.svg)

**Access → Public showcase** สร้างหน้าแยกต่างหากแบบอ่านอย่างเดียวโดยใช้ระบบ access-token ที่มีอยู่ มันอ่านข้อมูลการสังเกตที่บันทึกไว้ของระบบติดตั้ง แต่ไม่ เริ่มทำงานของ collector ไม่ลงชื่อเข้าใช้ Telegram และไม่สร้างช่องสำหรับผู้เยี่ยมชม

## เผยแพร่หน้า

1. บันทึกโปรไฟล์แหล่งที่มาสำหรับช่องสาธารณะแต่ละช่องที่คุณต้องการแสดง ช่องนั้นต้อง มีชื่อผู้ใช้สาธารณะในโปรไฟล์ที่บันทึกไว้ล่าสุด; กลุ่มและแชทส่วนตัว ไม่ตรงตามเงื่อนไข
2. Open **Access → Public showcase** (หรือ `/showcase-manage.html`) ในฐานะผู้ดูแลระบบ
3. เลือกช่องจากสูงสุด 16 พื้นที่ทำงาน ป้อนชื่อหน้าสาธารณะ และ เลือกระยะเวลาใช้งานของลิงก์เป็น 1, 7 หรือ 30 วัน ป้ายพื้นที่ทำงานภายในจะไม่ ถูกเผยแพร่ สามารถรวมช่องได้สูงสุด 64 ช่อง
4. ตรวจสอบข้อความของช่องที่เลือกเพื่อเผยแพร่ แล้วคลิก **"ดูตัวอย่างบันทึกที่เลือก**" การดูตัวอย่างใช้การฉายภาพด้านเซิร์ฟเวอร์เดียวกันกับหน้าผู้เยี่ยมชม
5. คลิก **"Create showcase link**" (สร้างลิงก์แสดงตัวอย่าง) คัดลอกลิงก์ขณะที่ยังแสดงอยู่ เปิดลิงก์นั้นใน เบราว์เซอร์อื่นเพื่อตรวจสอบหน้าของผู้รับก่อนที่จะส่งลิงก์ไป

ลิงก์นี้ประกอบด้วยโทเค็นการเข้าถึงในส่วนย่อยของ URL หน้าเว็บจะลบ ส่วนย่อยดังกล่าวออกก่อนที่จะส่งคำขอ API และแลกเปลี่ยนมันกับเซสชันของเบราว์เซอร์ ใครก็ตามที่ถือลิงก์นี้สามารถเปิดเนื้อหาที่เลือกไว้ได้จนกว่าจะหมดอายุหรือถูกเพิกถอน ลิงก์ใหม่รองรับ 100 เซสชันพร้อมกัน โดยแต่ละเซสชันมีระยะเวลาสูงสุดหนึ่งชั่วโมง การควบคุมการเข้าถึงที่มีอยู่ ยังสามารถบังคับใช้ข้อจำกัดที่อยู่และขีดจำกัดการลงชื่อเข้าใช้ผ่าน API grant ได้ การเข้าถึงของผู้ตรวจสอบแบบปกติเป็นโหมดที่ต่างออกไป และยังคงรวมถึง ข้อความและไฟล์ที่ได้รับอนุญาตเดิม

## สิ่งที่ผู้เยี่ยมชมเห็น

| มองเห็นได้ | ตั้งเป็นส่วนตัว |
| --- | --- |
| ชื่อช่องสาธารณะที่เลือกไว้ ชื่อผู้ใช้ และวันที่ตรวจสอบโปรไฟล์ | ข้อมูลประจำตัวบัญชี, ป้ายกำกับพื้นที่ทำงานภายใน และแหล่งข้อมูลที่ยังไม่ถูกเลือก |
| ข้อความที่บันทึกไว้และการแก้ไขแต่ละครั้งที่บันทึก | ID ผู้ส่งที่จัดโครงสร้าง, ชื่อ, ชื่อผู้ใช้, หมายเลขโทรศัพท์ และค่าโปรไฟล์ |
| บันทึกการลบพร้อมข้อความที่บันทึกไว้ก่อนหน้านี้ (หากมี) | ไฟล์แนบ, อวาตาร์, ภาพขนาดย่อ, ชื่อไฟล์ และข้อมูลต้นฉบับ |
| เครื่องหมายที่ระบุว่าผู้เขียน/โปรไฟล์หรือไฟล์แนบได้ถูกบันทึกแล้ว | ข้อมูลเมตาดาต้าการส่งต่อและตอบกลับ, เส้นทางเครือข่าย, ที่อยู่ IP และข้อมูลรับรอง |
| จำนวนเหตุการณ์ในช่องที่เลือก, สวิตช์คอลเลกชันปัจจุบัน, สัญญาณชีพ และช่วงเวลาตรวจสอบจุดตรวจสอบ | การควบคุมคอลเลกชันและ API ปกติสำหรับการส่งออกหลักฐาน |
| ลายนิ้วมือการลงนาม, จุดตรวจสอบบันทึก และหลักฐานความสอดคล้อง | กุญแจการลงนามและเซสชัน Telegram |

**ข้อความสาธารณะจะไม่ถูกทำให้ไม่ระบุตัวตนโดยอัตโนมัติ** ชื่อ การกล่าวถึง หมายเลขโทรศัพท์ หรือลิงก์ที่เขียนไว้ในข้อความจะยังคงเป็นส่วนหนึ่งของข้อความนั้น `Redacted`ใช้กับสนามผู้เขียน/โปรไฟล์ที่มีโครงสร้าง ตรวจสอบเนื้อหาที่เลือกไว้จริง ก่อนเผยแพร่ รวมถึงการแก้ไขและลบที่เก็บไว้

คุณสมบัติที่ตรงตามเงื่อนไขจะสะท้อนจาก**โปรไฟล์แหล่งข้อมูลที่บันทึกไว้ล่าสุด** ไม่ใช่จากการค้นหา Telegram แบบเรียลไทม์ หากโปรไฟล์ถัดไปไม่มีชื่อผู้ใช้ช่องสาธารณะอีกต่อไป คำขอใหม่ จะไม่รวมช่องดังกล่าวไว้ด้วย โปรดอัปเดตโปรไฟล์แหล่งข้อมูลเมื่อสถานะการมองเห็นสาธารณะมีการเปลี่ยนแปลง ผู้อ่านอาจได้บันทึกเนื้อหาที่รับไว้ก่อนหน้านี้แล้ว

บันทึกต้นฉบับที่มีลายเซ็นจะยังคงไม่เปลี่ยนแปลง การแสดงผลที่ปรากฏจะได้รับการลงลายเซ็น แยกต่างหาก และมาพร้อมกับค่าแฮชที่อ้างอิงถึงบันทึกต้นฉบับ การลงลายเซ็น ของการแสดงผลนี้ใช้เพื่อยืนยันความถูกต้องของข้อความที่แสดง; มันไม่ใช่ลายเซ็นของเหตุการณ์ต้นฉบับ ที่ลงบนไบต์ที่ถูกปกปิด

## ตรวจสอบลายเซ็นและความต่อเนื่อง

ขยาย **Fingerprint & signed checkpoint** และดาวน์โหลดสแนปช็อต หลังจากหน้า รีเฟรช การดาวน์โหลดจะรวมถึงสแนปช็อตเบราว์เซอร์ก่อนหน้าและ Merkle consistency proof ระหว่างขอบเขตของบันทึกของทั้งสอง การรีเฟรชอัตโนมัติจะเกิดขึ้นทุก หนึ่งนาที ขณะที่หน้ายังแสดงอยู่และแสดงหน้าแรกของการสังเกตการณ์

หลังจากติดตั้งTgWitness แล้ว ให้ตรวจสอบไฟล์ที่ดาวน์โหลดมาในโหมดออฟไลน์:

```
python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256
```

ลายนิ้วมือต้องมาจากแหล่งอ้างอิงที่เชื่อถือได้แยกต่างหาก เพื่อเปรียบเทียบกับ ภาพถ่ายที่คุณเก็บไว้เอง ให้ใช้ `--previous earlier.json`; วิธีนี้จะแทนที่ ภาพถ่ายหน้าจอเดิมที่อยู่ในไฟล์ดาวน์โหลด หลักฐานปัจจุบันต้องเริ่มต้น จากจุดแบ่งที่เก็บไว้ดังกล่าว ลูกค้าที่ผ่านการยืนยันตัวตนสามารถขอหลักฐานดังกล่าวได้โดยใช้ `GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>`. หากบันทึกมีขนาดสั้นกว่า จะส่งคืน HTTP 409 แทนที่จะรีเซ็ตขอบเขตโดยไม่มีข้อความแจ้งเตือน

จุดตรวจสอบที่ลงนามจะถูกบันทึกไปยังบันทึก**ของตัวเก็บข้อมูลทั้งหมด** รวมถึง จำนวนบันทึกและแฮชหัวที่ไม่โปร่งใส จำนวนข้อความที่แสดงใช้เฉพาะกับ ช่องสาธารณะที่เลือกไว้เท่านั้น หน้านี้จะไม่แสดงเนื้อหาของบันทึกอื่น นี่คือจำนวนเหตุการณ์ ไม่ใช่จำนวนข้อความที่ไม่ซ้ำกัน การตั้งค่าอธิบาย การกำหนดค่าปัจจุบัน ไม่ใช่ทุกช่วงเวลาการบันทึกก่อนหน้านี้

การตรวจสอบลายเซ็นและความสอดคล้องสามารถตรวจจับการเปลี่ยนแปลงได้เมื่อเทียบกับ ขอบเขตที่เก็บไว้ มันไม่ทำการนับใหม่ตัวนับที่ลงนามอย่างอิสระ ไม่รับรอง แหล่งที่มาของ Telegram ไม่แสดงการบันทึกที่ไม่ถูกขัดจังหวะ และไม่แทนที่พยานอิสระ สำหรับการตรวจสอบดังกล่าว ให้ใช้[เครื่องมือตรวจสอบหลักฐาน](https://github.com/phishdestroy/TgWitness/blob/main/docs/TRUST.md) [พยานอิสระ](https://phishdestroy.github.io/TgWitness/th/docs/reference/witness/) และ[บันทึกที่ผ่านการทดสอบในระดับจริง](https://phishdestroy.github.io/TgWitness/th/docs/reference/verification/) การติดตั้งแบบสังเคราะห์จะถูกติดป้ายอย่างชัดเจนว่าเป็นแบบสังเคราะห์

## ยกเลิกสิทธิ์หรือโฮสต์หน้านี้

ใช้ **Revoke** ในผู้จัดการ Showcase หรือส่วน **Access** ที่มีอยู่เพื่อปิด ลิงก์และยุติเซสชันทั้งหมด ผู้เยี่ยมชมจะลบบันทึกที่แสดงเมื่อ คำขอตรวจพบว่าสิทธิ์การเข้าถึงได้สิ้นสุดลง การตรวจสอบวันหมดอายุและสิทธิ์การเข้าถึงจะดำเนินการในทุก คำขอ สิทธิ์การเข้าถึง Showcase ไม่สามารถแปลงเป็นสิทธิ์การเข้าถึงแผงควบคุมทั่วไปได้โดยตรง; สร้างสิทธิ์การเข้าถึงใหม่เพื่อเปลี่ยนโหมด

ให้บริการหน้าเว็บผ่านที่อยู่ HTTPS ที่มีอยู่ของระบบติดตั้ง การเผยแพร่ ลิงก์จะไม่เปิดพอร์ตใหม่ ไม่สร้างอุโมงค์ และไม่เปลี่ยนแปลง DNS HTML และ API ยังคงอยู่บนระบบติดตั้งของผู้ใช้ ผู้เยี่ยมชมหน้าแสดงตัวอย่างไม่สามารถใช้ API ปกติ สำหรับข้อความ โปรไฟล์ สื่อ การส่งออก หรือการจัดการ ด้วยการเข้าถึงนี้
