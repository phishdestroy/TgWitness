# Telegram · חבר חשבון

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/accounts/

סביבת עבודה אחת = חשבון אחד, היומן שלו והמפתח שלו.

## בחר כיצד להתחבר

**חשבונות** ← הוספת סביבת עבודה ← הגדרות חיבור. השתמשו בחשבון נפרד לזה.

- **קוד QR:** סרקו אותו ממסך המכשירים ב-Telegram ואשרו.
- **מספר טלפון:** מספר, קוד, ואז סיסמת 2FA אם יש.
- **ייבוא סשן:** קובץ הסשן שלכם או נתוני Telegram Desktop.

השתמשו בפרופיל API מובנה או ב-API ID וב-hash משלכם. זה רק מזהה את האפליקציה, לא מחבר אתכם ולא מסתיר שום דבר.

**צריך פרוקסי קודם?**

ניתן [לבחור ולבדוק את מסלול החיבור](https://phishdestroy.github.io/TgWitness/he/docs/proxies/) לפני הכניסה. לכל חשבון יש מסלול משלו.

## בחרו מה לעקוב אחריו

1. בחרו את הצ'אטים, הקבוצות או הערוצים שאתם צריכים.
2. בדקו את הגדרות האיסוף, כולל מדיה.
3. הפעילו ובדקו את החיבור ואת הפעילות האחרונה.

לחשבון חייבת להיות גישה. מנהלים וחברים רואים דברים שונים, והיומן מראה מה החשבון הזה קיבל.

החשבון כולו? **מקורות ← היקף המעקב ← מצב חקירה**, בדקו, **שמירת היקף**. הדרכה מלאה: [חקירת חשבון שלם](https://phishdestroy.github.io/TgWitness/he/docs/cases/).

## בדוק את הנתיב המלא

בקבוצת הבדיקה, שלחו הודעה מחשבון אחר, ערכו אותה, מחקו אותה. שלושתם צריכים להופיע ביומן. ואז [ייצאו ואמתו](https://phishdestroy.github.io/TgWitness/he/docs/exports/).

"מחובר" אומר שהחיבור עובד. הודעת בדיקה שנקלטה אומרת שאירועים באמת מגיעים.

## הוסף חשבון נוסף

סביבת עבודה חדשה ב-**חשבונות**, אותם שלבים. רשמו את טביעת האצבע של המפתח של כל חשבון כדי להבדיל בין ייצואים בהמשך.
