# עבוד עם הארכיון

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/archive/

מצא את ההודעה. בדוק את המקור. בנה את התיק.

01**הוסף את ההיסטוריה**

משכו הודעות קודמות מהמקורות הפעילים אל סביבת העבודה.

02**עקבו אחר המקורות**

חפשו, ואז פתחו את ההודעה השמורה שמאחורי כל תוצאה.

03**יש לשמור על בהירות בהעברת האחריות**

הניתוח שלכם בקובץ אחד, הראיה החתומה לצידו.

הרשומות שנאספו, הטקסט שזוהה ומסקנות האנליסטים נשמרים בנפרד.

## טען הודעות קודמות

1. **מקורות ← צ'אטים בהיקף**: בדקו את הצ'אטים הפעילים, התחילו מעקב.
2. **טעינת היסטוריה מלאה**. היא לוקחת את רשימת המקורות כפי שהיא עכשיו.
3. **השהיית היסטוריה** / **המשך היסטוריה** בכל עת. אחרי הפעלה מחדש, המשיכו ידנית.
4. בדקו תוצאות לכל מקור ואת תור ההורדות, שמרו את דוח ההתקדמות החתום עם הייצוא.

זה ממלא את סביבת העבודה. ייצוא HTML/JSON של צ'אט בודד הוא דבר אחר. [פרטים](https://phishdestroy.github.io/TgWitness/he/docs/reference/history/).

## חפשו תחילה, ורק אחר כך החליטו לגבי השימוש ב-AI

1. **יומן** מחפש מקומית, עם סינון לפי מקור וזמן.
2. חפשו ביטוי או דומיין, פתחו את הרשומה ואת הגרסאות שלה.
3. ל-AI, המנהל מגדיר ספק ב-**שילובים**. ואז **שאלו את הארכיון**: בחרו צ'אטים ותקופה, הסתכלו ב-**נתונים שנשלחים למודל** והסירו סימון ממה שלא אמור לצאת.
4. בדקו את הציטוטים, שמרו את התשובה כדוח, הוסיפו הערות.

חיפוש לא צריך AI. דוחות שומרים את המקורות והגרסאות שלהם, בנפרד מהיומן החתום. [הגדרת ספק](https://phishdestroy.github.io/TgWitness/he/docs/reference/analysis/).

## בחר את החיבור הדרוש לך

| המשימה | פתוח | הגדרה |
| --- | --- | --- |
| תנו ללקוח AI לקרוא צ'אטים נבחרים | **שילובים → MCP** | [התקינו MCP, צרו טוקן מוגבל, התחברו](https://phishdestroy.github.io/TgWitness/he/docs/reference/mcp/) |
| זיהוי טקסט במדיה שמורה | רשומת `media.saved` → **זיהוי קובץ מצורף** | [הגדירו את ה-worker המקומי של Docker](https://phishdestroy.github.io/TgWitness/he/docs/reference/media-analysis/) |
| שלח אירועים ל-n8n או ל-SIEM | **שילובים → ווב-הוקים יוצאים** | [הוסיפו נמען, בדקו HMAC, סננו מזהים כפולים](https://phishdestroy.github.io/TgWitness/he/docs/reference/webhooks/) |

**לאן שייך כל אסימון גישה?**

גישה ללוח מיועדת לאנשים. ל-MCP יש טוקנים לקריאה בלבד משלו, ול-webhooks סוד HMAC משלהם. אף אחד מהם לא צריך סשן Telegram.

[שתף גישה ללוח הבקרה](https://phishdestroy.github.io/TgWitness/he/docs/access/) או [הגדר לקוח MCP](https://phishdestroy.github.io/TgWitness/he/docs/reference/mcp/).
