# アーカイブの操作

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/archive/

メッセージを見つけ、出典を確認し、証拠を構築する。

01**履歴を取り込む**

有効化済みのソースから過去のメッセージをワークスペースに読み込みます。

02**情報源を参照**

アーカイブを検索し、各検索結果に対応する保存済みメッセージを開くことができます。

03**引き継ぎ内容を明確にする**

分析結果を別途保存し、その横に署名済みの証拠をエクスポートしてください。

記録されたデータ、認識されたテキスト、および分析者の結論は、それぞれ明確に区別されています。

## 過去のメッセージを読み込む

1. **出典 → 対象範囲のチャット**を開き、有効化されたチャットを確認して、監視を開始してください。
2. **「全履歴を読み込む**」を選択してください。実行時には、その時点で選択されているソースリストが使用されます。
3. 必要に応じて「**履歴の一時停止」**と「**履歴の再開」**を使用してください。再起動後は、明示的に再開してください。
4. ソースごとの結果と添付ファイルのキューを確認してください。証拠のエクスポートとともに、署名付きの進捗レポートを保存してください。

これにより、ワークスペースに利用可能なメッセージが一覧表示されます。チャットごとのHTML/JSONエクスポートは、別途行う操作となります。[履歴および復元に関する詳細](https://phishdestroy.github.io/TgWitness/ja/docs/reference/history/)。

## まずは検索し、その後AIの利用を判断する

1. ローカル検索を行うには**ジャーナル**を開きます。ワークスペースを選択し、出典と期間のフィルターを使用してください。
2. フレーズまたはドメインを検索します。一致した記録とその保存されたバージョンを開きます。
3. AI分析を行うには、管理者が**連携機能**でプロバイダーを有効化して設定します。**アーカイブに問い合わせる**を開き、チャットと期間を選択してください。リクエストを承認する前に、**モデルに送信されるデータ**を確認し、不要な抜粋のチェックを外してください。
4. 返された引用を確認してください。回答をレポートとして保存し、独自の修正やメモを追加してください。

検索はAIを使用せずにローカルで実行されます。分析レポートには出典情報と改訂履歴が保持されており、これらは署名付きジャーナルとは別個に管理されます。[プロバイダーの設定とレポート](https://phishdestroy.github.io/TgWitness/ja/docs/reference/analysis/)。

## 必要な接続方法を選択してください

| タスク | 開く | セットアップ |
| --- | --- | --- |
| AIクライアントからのチャットの一部を読む | **連携機能 → MCP** | [MCP エクストラをインストールし、スコープ付きトークンを発行して、クライアントを接続します](https://phishdestroy.github.io/TgWitness/ja/docs/reference/mcp/) |
| 保存されたメディア内のテキストを認識する | `media.saved`レコード → **添付ファイルを認識** | [ローカルの Docker ワーカーおよび必要な言語/モデルファイルを設定する](https://phishdestroy.github.io/TgWitness/ja/docs/reference/media-analysis/) |
| イベントを n8n または SIEM に送信する | **連携機能 → 送信用ウェブフック** | [受信者を追加し、HMACを検証し、イベントIDの重複排除を行う](https://phishdestroy.github.io/TgWitness/ja/docs/reference/webhooks/) |

**どのアクセストークンをどこに設定すればよいですか？**

パネルへのアクセス権は、案件を審査する担当者のみが持っています。MCP接続には、別途読み取り専用のアーカイブトークンが発行されます。Webhook受信者は独自のHMACシークレットを使用します。いずれの場合も、Telegramのセッションファイルは必要ありません。

[パネルのアクセス権を共有](https://phishdestroy.github.io/TgWitness/ja/docs/access/)するか、[MCPクライアントを設定してください](https://phishdestroy.github.io/TgWitness/ja/docs/reference/mcp/)。

## 情報源と結論を提示する

審査済みの分析レポートは、署名付き証拠ZIPファイルと一緒に保管してください。レポートには情報源の分析結果が記載されており、ZIPファイルにより、受信者は保存された記録を、独立して信頼できるフィンガープリントおよびチェックポイントと照合して確認することができます。
