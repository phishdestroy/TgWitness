Belgeler / 02

Özel hesap

Toplanan verileri kişisel sohbetlerden ayrı tutun. Ayrı bir hesap da yine de Telegram kısıtlamalarına maruz kalabilir.

Bağlanmadan önce

  • Kayıt için kullanılan telefon numarasının kontrolünü elinizde tutun.
  • İki aşamalı doğrulamayı etkinleştirin ve bir kurtarma e-postası ekleyin.
  • Telegram Ayarlar → Cihazlar bölümünden aktif oturumları inceleyin.

API kimlik bilgileri

API kimliği ve hash, uygulamayı tanımlar. Telegram yetkilendirmeniz ayrıdır.

GitHub yakalama iş akışı için kendi API kimliğinizi ve hash değerinizi kullanın.

API kimlik bilgilerini oluşturun

İçe aktarılan oturumlar

Aynı içe aktarılmış yetkilendirmeyi iki istemcide aynı anda çalıştırmayın. Telegram, AUTH_KEY_DUPLICATED hatasıyla bu yetkilendirmeyi iptal edebilir. Paralel kullanım için, telefon veya QR kodu ile ayrı bir oturum açma bilgisi oluşturun.

Hesabı bağlayın

  1. Paneli açın ve telefon veya QR koduyla giriş seçeneğini seçin.
  2. Telegram doğrulamasını tamamlayın ve kaynaklarınızı seçin.
  3. Toplamaya başlayın ve yeni mesajların göründüğünü kontrol edin.

Hesap bağlama kılavuzu

Telefon numaraları

Saklayabileceğiniz bir numara seçin. Tek bir oturum açma kodu almak, gelecekte hesabınızı kurtarabileceğinizi garanti etmez.
