# Telegram · עיצוב דוח

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/reports/

קחו את הקורא משאלת התיק ישר אל הרשומות השמורות.

Report studio מרכיב את הנתונים שבחרתם, היסטוריות שינויים, גרפים והממצאים שלכם. שמונה עיצובים, HTML ו-PDF מקורי. כל דוח HTML, PDF ו-JSON נחתם במפתח שלכם.

## הכנת דוח בשלושה שלבים

1. **ייצואים ← הגדרה ותצוגה מקדימה ← נתונים**: סביבת העבודה כולה, או בחרו צ'אטים, כותבים, תאריכים (UTC, מתי ש-TgWitness ראה את הרשומה) וסוגי רשומות.
2. **עיצוב ותוכן**: בחרו עיצוב ומה נכנס: גרפים, משתתפים, תמליל, שינויים, פריטי Case Board, פרטי התיק וההערות שלכם.
3. **תצוגה מקדימה**: בדקו ספירות, פעילות, דוגמאות וטווחי מזהים חסרים. שמרו, ואז הורידו את הפורמט שאתם צריכים.

### ארגנו את אותו החומר שנשמר כך שיהיה נוח לקורא

דוגמה סינתטית · פריסה סכמטית, לא דוח שנוצר

1. **בחר.** בחר שני צ'אטים ותקופת התצפית עבור התיק.
2. **כתוב את הטקסט.** בחר פריסה ואת הסעיפים העונים על השאלה.
3. **תצוגה מקדימה.** בדקו את מספר המילים שנבחרו ואת הטקסט שנשמר לפני ואחרי התרגום.
4. **יש לאמת.** יש ליצור את הקובץ הסופי ולבדוק את חתימתו מול טביעת האצבע של סביבת העבודה המהימנה.

## בחרו סגנון קריאה

**Classic, Editorial, Briefing, Analytics, Technical, Overview, Reading series, and Ledger & margin**: אותן רשומות, מראה שונה. החלפה שומרת את הבחירה וההערות. כל אחת מ-25 השפות.

קובצי PDF נבנים עם גופנים מצורפים, בלי צורך בדפדפן. סינית, יפנית וקוריאנית צריכות גופן כמו Noto Sans CJK על השרת (ברמת המערכת או ב-`TGWITNESS_FONT_DIR`), אחרת תקבלו רק HTML ו-JSON.

## קרא את השינוי בהקשר שלו

עריכות מציגות לפני ואחרי, מחיקות מציגות את הגרסה השמורה האחרונה. תגובות, העברות, תגובות אמוג'י, כפתורים וקבצים מצורפים שומרים על ההפניות שלהם.

התצוגה המקדימה של העיצוב משתמשת ב-50,000 הרשומות הראשונות, והתצוגה המקדימה של הנתונים סופרת הכול במדויק. לפריסת עמודים סופית, הפיקו את ה-PDF.

## בחרו את נוסח היעד בקפידה

מסננים רק מעצבים את הדוח, ה-ZIP של הראיות עדיין מכיל את היומן המלא והקבצים. אם הנמען צריך לקבל פחות, השתמשו ב[מסירה מצומצמת](https://phishdestroy.github.io/TgWitness/he/docs/handover/). עוד: [תוכן הדוח](https://phishdestroy.github.io/TgWitness/he/docs/reference/case-reports/), [אימות הייצוא](https://phishdestroy.github.io/TgWitness/he/docs/exports/).
