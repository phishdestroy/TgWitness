# Telegram · แบ่งปันกรณีศึกษา

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/access/

แบ่งปันกรณีที่ใครนั้นต้องการ และรักษาการควบคุมส่วนที่เหลือ

01**เลือกหลักฐาน**

ทั้งพื้นที่ทำงานหรือแชทเดี่ยว

02**เลือกการดำเนินการ**

ดู ส่งออก หรือเฉพาะการดำเนินการที่จำเป็น

03**กำหนดขีดจำกัด**

โทเค็นส่วนตัวพร้อมวันหมดอายุ ขีดจำกัดเซสชัน และกฎ IP หากต้องการ

ขอบเขตการเก็บข้อมูลกำหนดว่าข้อมูลใดจะถูกบันทึก ส่วนขอบเขตการเข้าถึงกำหนดว่าผู้ใช้สามารถดูและทำอะไรได้

## ให้สิทธิ์การเข้าถึงแก่ผู้ใช้

1. ในฐานะผู้ดูแล เปิด **การเข้าถึง**
2. ตั้งชื่อ เลือกพื้นที่ทำงานและแชท
3. ผู้ตรวจทานต้องการเพียง **ดู** เพิ่ม **ส่งออก** สำหรับการดาวน์โหลด
4. กำหนดขีดจำกัด แล้วกด "**สร้างสิทธิ์เข้าถึง**"
5. คัดลอกโทเค็น (แสดงครั้งเดียว) แล้วส่งแบบส่วนตัวพร้อมที่อยู่แผงควบคุม
6. ตรวจสิ่งที่เขาจะเห็นในเซสชันเบราว์เซอร์แยกก่อน

## เริ่มจากงานที่พวกเขาต้องทำ

| บุคคล | เข้าถึง | ผลลัพธ์ |
| --- | --- | --- |
| ผู้ตรวจสอบ | การสนทนาที่เลือกไว้; ดูได้เท่านั้น | อ่านแชท เปลี่ยนอะไรไม่ได้ |
| นักวิเคราะห์ | การสนทนาที่เลือกไว้; ดูและส่งออก | อ่านและดาวน์โหลดสิ่งที่คดีต้องการ |
| ผู้ดำเนินการ | พื้นที่ทำงานที่เลือกไว้ทั้งหมด; แหล่งข้อมูลและการรวบรวม | ตัดสินใจว่าจะสังเกตอะไร เริ่มและหยุดเครื่องเก็บข้อมูล |

นี่เป็นเพียงตัวอย่าง ไม่ใช่บทบาทตายตัว สิทธิ์ที่จำกัดเฉพาะแชทไม่มีทางได้การตั้งค่าบัญชีหรือการส่งออกบันทึกเต็ม สิทธิ์ทุกพื้นที่ทำงานรวมบัญชีที่เพิ่มภายหลังด้วย

## คุณสามารถเปลี่ยนใจได้ทุกเมื่อ

แก้ไขสิทธิ์ได้ทุกเมื่อ มีผลตั้งแต่คำขอถัดไป สิ้นสุดเซสชันเดียวหรือเพิกถอนทั้งหมด ไฟล์ที่ดาวน์โหลดไปแล้วเรียกคืนไม่ได้ การเก็บข้อมูลยังดำเนินต่อไป

**ข้อจำกัดเกี่ยวกับเซสชันและ IP**

จำกัดเซสชันพร้อมกันและการเข้าสู่ระบบ ตั้งวันสิ้นสุด อนุญาต IP หรือซับเน็ต หรือล็อกกับ IP ที่เข้าสู่ระบบครั้งแรก วันหมดอายุนับจากการไม่ใช้งาน แผงควบคุมที่เปิดอยู่นับว่าใช้งาน หากอยู่หลังพร็อกซี ให้ตรวจว่าแอปเห็น IP ไคลเอนต์ใด

**กุญแจหลักและบันทึกกิจกรรม**

โทเค็นหลักอยู่กับผู้ดูแล สิทธิ์ที่ออกให้ไม่สามารถจัดการสิทธิ์ของผู้อื่นหรือเปิดคอนโซลผู้ดูแลได้ การเปลี่ยนสิทธิ์และเซสชันถูกลงนามลงในบันทึกโดยไม่มีโทเค็น ผู้ดูแลเซิร์ฟเวอร์ยังเห็นทุกอย่างได้
