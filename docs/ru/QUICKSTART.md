# TgWitness: от запуска до первого сообщения

TgWitness сохраняет наблюдаемые сообщения Telegram и их изменения на вашем
компьютере или сервере. Для начала достаточно одного аккаунта и одного источника.
[Все инструкции](START-HERE.md) · [Дополнения](EXTRAS.md)

## Ознакомьтесь с интерфейсом

Установите Python 3.11 или новее, скачайте исходники и распакуйте их. Для демо
запустите **Demo.cmd** в Windows или `sh start.sh --demo` в Linux/macOS.
Лаунчер создаст `.venv` и установит зависимости.

В браузере откроется пример с вымышленными переписками. Откройте чат, сравните
правку и посмотрите экспорт. Входить в Telegram не нужно.

## Установка и запуск

Завершите процесс демо и запустите своё рабочее пространство:

| Система | Команда в каталоге проекта |
| --- | --- |
| Windows | Дважды нажмите **Start.cmd** или выполните `.Start.cmd` |
| Linux / macOS | `sh start.sh` |

Откройте **http://127.0.0.1:8787**. Если панель просит токен, возьмите его
из **data/live/panel-token.txt**. Это токен доступа к TgWitness; он не заменяет
код входа Telegram и не является токеном бота.

<details>
<summary>Portable для Windows и Docker</summary>

После публикации portable-сборки её можно скачать из GitHub Releases:
распакуйте `TgWitness-<version>-windows-amd64-portable.zip` и запустите
**TgWitness.cmd**. Python включён в сборку, для демо есть **TgWitness-Demo.cmd**.

Для Docker нужен Docker Engine/Desktop с Compose 2.20+. Выполните:

```sh
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

Вторая команда показывает токен панели. Обычная установка и Docker используют
разные хранилища: запуск контейнера сам по себе не переносит ваш прежний журнал.
[Установка на сервер, HTTPS и резервные копии](../DEPLOYMENT.md).

</details>

## Подключитесь к Telegram

Используйте отдельный аккаунт, который не жалко потерять: Telegram может
ограничивать или блокировать аккаунты. [Подробности подключения](../ACCOUNTS.md).

1. Откройте **Аккаунты** и настройку подключения.
2. Выберите QR-код, вход по телефону или импорт своей сессии. При входе по номеру
   укажите код от Telegram и пароль двухэтапной проверки, если он включён.
3. Выберите встроенный профиль API или укажите собственные API ID и hash.
4. Отметьте доступные аккаунту источники и включите наблюдение.
5. С другого аккаунта отправьте новое сообщение в свою тестовую группу.
   Убедитесь, что оно появилось в журнале. Измените и удалите его, проверяя каждое событие.

Если нужен прокси, [выбрать и проверить его](PROXIES.md) можно ещё до входа.
Для второго аккаунта создайте другое рабочее пространство: у него будут свои
сессия, журнал, ключ, источники и настройки.

## Просмотр и экспорт

В **Чатах** удобно читать переписку, а в **Журнале** — искать события и смотреть
сохранённые версии. Уведомление об удалении не стирает уже захваченный текст.
Если аккаунт не получил событие, запись о нём может отсутствовать.

Для передачи проверяемых материалов:

1. Сохраните отпечаток открытого ключа рабочего пространства отдельно.
2. Во время сбора сохраняйте подписанные контрольные точки вне коллектора.
3. В **Экспорте** скачайте подписанный ZIP. Он содержит полный журнал рабочего
   пространства независимо от фильтров панели; просмотрите его перед передачей.
4. Проверьте архив доверенной копией программы, заменив пути и отпечаток:

```sh
python -m tgwitness.verify evidence.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256 --checkpoint retained-checkpoint.json
```

После успешной проверки обоих ориентиров результат содержит `key_pinned: true`
и `checkpoint_checked: true`. Контрольная точка должна быть не позднее границы
экспорта. [Формат и подробная проверка](../EVIDENCE.md#investigation-handoff).

Самостоятельные HTML и CSV удобны для чтения, но не имеют отдельной подписи.
Подпись проверяет целостность записанного; доставку конкретных событий проверяет
[контрольный сценарий на стенде](PROOF.md).

## Проверьте установку

```sh
python start.py --check
python start.py --check --json
```

Проверка оценивает локальные зависимости, поддержку подписи, хранилище и параметры
запуска. Она ничего не устанавливает и не подключается к Telegram. Занятый порт
может означать, что приложение уже работает.

Команды `python -m tgwitness…` выполняйте в окружении проекта. Если оно не
активировано, замените `python` на `.venv\Scripts\python.exe` в Windows
или `.venv/bin/python` в Linux/macOS.

## Сеансы, защита и эксплуатация

**Остановить наблюдение** прекращает сбор. **Заблокировать панель** закрывает
доступ через браузер. Закрытие вкладки не останавливает работающий процесс.

Секреты и сессии защищены хранилищем приложения. Для содержимого сообщений,
вложений и экспортов используйте защищённый диск. Делайте полную резервную копию
каталога данных, включая ключи: экспорт доказательств её не заменяет.

Для постоянной работы откройте [развёртывание](../DEPLOYMENT.md), для сбоев —
[эксплуатацию](../OPERATIONS.md), для внешних контрольных точек —
[настройку бота-свидетеля](WITNESS.md).
