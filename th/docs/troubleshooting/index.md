# Telegram · ค้นหาว่าเกิดข้อผิดพลาดอะไร

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/troubleshooting/

เริ่มจากอาการ ตรวจทีละอย่าง

## คณะกรรมการขอโทเค็น

มันต้องการโทเค็นแผงควบคุมจากไฟล์ที่ตัวเปิดโปรแกรมพิมพ์ออกมา Docker: `docker compose exec tgwitness cat /data/panel-token.txt` ไม่ใช่รหัส Telegram ไม่ใช่โทเค็นบอท ไม่ใช่โทเค็นพยาน

## Telegram ไม่เชื่อมต่อ

รันการตรวจการเชื่อมต่อ หากใช้พร็อกซีสาธารณะ ให้เลือกตัวอื่นแล้วบันทึก ตรวจประเภทพร็อกซีและรูปแบบความลับ การรีเฟรชรายการไม่ได้สลับเส้นทางให้เอง

## มีการเชื่อมต่อ แต่ไม่มีข้อความใหม่

1. การสังเกตทำงานอยู่ในพื้นที่ทำงานที่ถูกต้องหรือไม่?
2. แหล่งข้อมูลถูกเลือกและบัญชีนั้นมองเห็นหรือไม่?
3. ส่งข้อความที่ไม่ซ้ำในกลุ่มทดสอบแล้วค้นหามัน
4. มองหาการหยุดชะงักหรือข้อผิดพลาดของ Telegram ในบันทึก

แชทที่เงียบก็แค่ไม่มีอะไรใหม่ หากความครบถ้วนสำคัญ ให้ทำการทดสอบการส่งถึงแบบควบคุม

## FloodWait หรือช่องว่างหลังการรีสตาร์ท

FloodWait คือ Telegram บอกว่า "ช้าลงหน่อย" รอให้ผ่านไปและลดภาระ การเชื่อมต่อใหม่ไม่ช่วย หลังรีสตาร์ต TgWitness ตามเก็บสิ่งที่ Telegram ยังมีอยู่ ส่วนที่เหลือคือช่องว่าง ให้จดไว้

## บอทได้ถูกตั้งค่าแล้ว แต่ยังไม่โพสต์อะไรเลย

พยานทำงานอยู่หรือไม่ บอทโพสต์ในช่องได้หรือไม่ เข้าถึงเครื่องเก็บข้อมูลและ Bot API ได้หรือไม่? มองหาโพสต์ที่ล้มเหลวในบันทึกของมัน การโพลฝั่งเครื่องเก็บข้อมูลไม่ได้หมายความว่าโพสต์ถูกส่งออกไปแล้ว

## การบูรณาการโทเค็น GitHub อยู่ที่ไหน?

**อยู่ในขั้นตอนการวางแผน ส่วน** Extras อธิบายถึงกระบวนการ fork และขั้นตอนการตรวจสอบการสร้างระบบที่เสนอไว้ ปัจจุบันยังไม่มีแบบฟอร์มโทเค็น GitHub หรือระบบยืนยันอัตโนมัติว่าระบบที่ทำงานอยู่ตรงกับรีโพสิตอรี ดู[สถานะคุณสมบัติปัจจุบัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/features/)

รายงานบั๊ก? ระบุเวอร์ชัน ระบบปฏิบัติการ ขั้นตอน และข้อผิดพลาดที่ปิดข้อมูลส่วนตัวแล้ว อย่าใส่เซสชัน โทเค็น ข้อความส่วนตัว หรือไดเรกทอรีข้อมูลใน issue สาธารณะ
