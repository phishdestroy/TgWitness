# একটি শেয়ার করার কপি প্রস্তুত করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/handover/

মূল কর্মক্ষেত্র অক্ষত রেখে প্রাসঙ্গিক পর্যবেক্ষণগুলো শেয়ার করুন।

হ্যান্ডওভার একটি স্বতন্ত্র স্বাক্ষরিত সারসংক্ষেপ। চ্যাট এবং অংশগ্রহণকারীদের নির্বাচন করুন, পরিচয় বা পাঠ্য সংক্ষিপ্ত করুন, এবং নির্ধারণ করুন কোন ফাইল এবং দলের নোট প্রাপকের কপিতে অন্তর্ভুক্ত হবে। এর ম্যানিফেস্টে নির্বাচনের বিবরণ এবং অপরিবর্তিত, সংক্ষিপ্ত ও বাদ দেওয়া রেকর্ডের সংখ্যা লিপিবদ্ধ থাকে।

## প্রাপ্তকারীর এক্সট্র্যাক্ট প্রস্তুত করুন

1. **Exports → Handover extract** খুলুন। এর উদ্দেশ্য লিখুন, চ্যাটগুলো এবং ঐচ্ছিক UTC সময়সীমা নির্বাচন করুন, তারপর যদি নামযুক্ত বিষয় প্রয়োজন হয় তবে **নির্বাচিত চ্যাটগুলোর লোড অপশন** নির্বাচন করুন।
2. অন্যান্য সবাইকে কীভাবে পরিচালনা করবেন তা নির্বাচন করুন: ছদ্মনাম ব্যবহার করুন, তাদের বার্তা বাদ দিন, অথবা রেকর্ডকৃত হিসেবে দেখান। বার্তার টেক্সট এবং সংযুক্তিগুলি স্বতন্ত্রভাবে সেট করুন; ঐচ্ছিকভাবে ফোন নম্বর এবং ইমেল ঠিকানা মাস্ক করুন।
3. Case Board-এর বুকমার্ক এবং স্লাইস বা মন্তব্যসহ কার্ড অন্তর্ভুক্ত করার মধ্যে নির্বাচন করুন। এই কপিতে তদন্তকারীর ছদ্মনাম দলগুলোর নাম প্রতিস্থাপন করতে পারে।
4. **ডাউনলোড হ্যান্ডওভার এক্সট্র্যাক্ট** নির্বাচন করুন। তৈরি করা রিপোর্ট এবং নির্বাচিত রেকর্ডগুলো স্থানীয়ভাবে খুলুন, আর্কাইভ যাচাই করুন, এবং পাঠানোর আগে কপিটি পরীক্ষা করুন।

### একটি মূল, একটি ইচ্ছাকৃত শেয়ারিং কপি

কৃত্রিম উদাহরণ · শুধুমাত্র পরিচয় চিত্রায়ন

1. **নির্বাচন করুন।** মামলার চ্যাট অন্তর্ভুক্ত করুন এবং সেই ব্যক্তিকে চিহ্নিত করুন যার সম্পর্কে এক্সট্র্যাক্টটি।
2. **মিনিমাইজ করুন।** শেয়ারিং কপিতে অন্য অংশগ্রহণকারী কীভাবে প্রদর্শিত হবে তা নির্বাচন করুন।
3. **পরিদর্শন করুন।** প্রেরণের আগে তৈরি করা আর্কাইভের রিপোর্ট এবং রেকর্ডগুলো খুলুন।
4. **শেয়ার করুন।** যাচাইকৃত কপি সরবরাহ করুন এবং এর বিশ্বাসযোগ্য ফিঙ্গারপ্রিন্ট আলাদাভাবে যোগাযোগ করুন।

#### বাস্তব ফাইলগুলো পরিদর্শন করুন

পরিচয়, টেক্সট, সংযুক্তি এবং ঐচ্ছিক দলীয় মন্তব্য যাচাই করুন।

## নিয়ন্ত্রণগুলো একসঙ্গে ব্যবহার করুন

| নিয়ন্ত্রণ | কপির উপর প্রভাব |
| --- | --- |
| মানুষ | নির্বাচিত বিষয়গুলোকে শনাক্তযোগ্য রাখুন; অন্যান্য অংশগ্রহণকারীদের ইচ্ছামতো ছদ্মনাম দিন বা বাদ দিন। |
| টেক্সট | সমস্ত টেক্সট অন্তর্ভুক্ত করুন, শুধুমাত্র নির্বাচিত ব্যক্তিদের এবং পর্যবেক্ষণকারী অ্যাকাউন্টের টেক্সট, অথবা বার্তার টেক্সট এবং টেক্সট-যুক্ত বিস্তারিত ক্ষেত্রগুলো বাদ দিন। |
| ফাইলসমূহ | নির্বাচিত ব্যক্তি এবং পর্যবেক্ষণকারী অ্যাকাউন্টের ফাইল নির্বাচন করুন, প্রদর্শিত সমস্ত বার্তার ফাইল, অথবা কোনো ফাইল নয়। |
| কেস বোর্ড | বোর্ড উপাদান, বুকমার্ক এবং স্লাইস বা টিম আলোচনা সহ কার্ড নির্বাচন করবেন না। |

মুক্ত ফরম্যাটের টেক্সট এবং ফাইলের বিষয়বস্তুসহ পরিচয়সমূহ পর্যালোচনা করুন: ছদ্মনাম স্বয়ংক্রিয়ভাবে বার্তা বা সংযুক্তিতে লেখা প্রতিটি নাম মুছে ফেলে না। যদি নির্বাচিত সংরক্ষিত ফাইলটি অনুপলব্ধ হয়, তবে এক্সট্র্যাক্ট তৈরি করার আগে তা পুনরুদ্ধার করুন অথবা সংযুক্তিগুলো স্পষ্টভাবে বাদ দিন।

## লেখাটি স্বাধীনভাবে যাচাইযোগ্য রাখুন

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

মূল স্বাক্ষরিত প্রমাণ সংরক্ষণাগার এবং চেকপয়েন্টগুলো পৃথকভাবে রাখুন। হস্তান্তর প্রক্রিয়াটি নিজস্ব প্রজেকশন রেকর্ড করে, যাতে প্রাপক সম্পূর্ণ ওয়ার্কস্পেস না পেলেও সরবরাহিত কপি যাচাই করতে পারে। [রিপোর্ট স্টুডিও](https://phishdestroy.github.io/TgWitness/bn/docs/reports/) তার পাঠ্য বিন্যাস সরবরাহ করে; [রপ্তানি যাচাই](https://phishdestroy.github.io/TgWitness/bn/docs/exports/) বিশ্বস্ত রেফারেন্সগুলো ব্যাখ্যা করে।
