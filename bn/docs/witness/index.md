# একটি উইটনেস বট সেট আপ করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/witness/

একটি পৃথক প্রক্রিয়া জার্নাল পরীক্ষা করুক এবং আপনার চ্যানেলে স্বাক্ষরিত চেকপয়েন্টগুলি প্রকাশ করুক।

## দুই হোস্ট, দুইটি স্বাক্ষর কী

হোস্ট এ / কালেক্টর**অ্যাকাউন্ট + জার্নাল**

টেলিগ্রাম সেশন কালেক্টর স্বাক্ষর কী

শুধুমাত্র-পঠনযোগ্য চেকপয়েন্ট এন্ডপয়েন্ট

← স্বাক্ষরিত উত্তর অনুরোধ করুন →

হোস্ট বি / সাক্ষী**যাচাই করুন + ধরে রাখুন**

পিনযুক্ত কালেক্টর ফিঙ্গারপ্রিন্ট পৃথক সাক্ষী স্বাক্ষর কী

নিজের জার্নাল + বট টোকেন

সাক্ষী → টেলিগ্রাম বট API →**আপনার চ্যানেল · স্বাক্ষরিত TGW1 পোস্টসমূহ**

উইটনেস নিজেই চেকগুলি টেনে আনে। কালেক্টর অ্যাক্সেস শুধুমাত্র পড়ার জন্য। বট প্রকাশনা উইটনেসের সংযোগ এবং টোকেন ব্যবহার করে; উইটনেসকে কোনো অ্যাকাউন্ট সেশন দেওয়া হয় না।

০৩ / চেকপয়েন্ট সিদ্ধান্তসমূহউদাহরণস্বরূপ উত্তরসমূহ

সর্বশেষ গৃহীত**১২০টি রেকর্ড**`head 9c7d…`

পরবর্তী উত্তর**১২৮টি রেকর্ড**`head a4f2…`

গ্রহণ করা হয়েছে: গণনা বৃদ্ধি পাচ্ছে, স্বাক্ষর যাচাই হচ্ছে এবং কী মিলছে। সাক্ষী এই নতুন সীমা বজায় রাখে।

সমস্ত উত্তর উদাহরণ বৈধ স্বাক্ষর এবং পিন করা কী-কে ধরে নেয়। এখানে হ্যাশগুলো সংক্ষিপ্ত উদাহরণ। শুধুমাত্র বড় সংখ্যা দেখিয়ে পুরো পুরনো প্রিফিক্স অপরিবর্তিত আছে তা প্রমাণ করা যায় না; চেকপয়েন্ট সংরক্ষণ করে করা একটি এক্সপোর্টের সাথে তুলনা করুন।

## একটি বট এবং একটি চ্যানেল প্রস্তুত করুন

BotFather-এর মাধ্যমে একটি বট তৈরি করুন এবং এটিকে আপনার নিয়ন্ত্রণাধীন একটি চ্যানেলে পোস্ট করার অনুমতি দিন। সাক্ষীর জন্য একটি কম্পিউটার বা সার্ভার নির্বাচন করুন। একটি পৃথক হোস্ট এবং অপারেটর সংগ্রহকারীর সার্ভারে দ্বিতীয় প্রক্রিয়ার তুলনায় আরও শক্তিশালী স্বাধীনতা প্রদান করে।

## এক্সট্রাস-এ তিনটি ধাপ

1. **শুধুমাত্র পড়ার অ্যাক্সেস। এক্সট্রা → আপনার চ্যানেলে একটি বট** খুলুন, একটি উইটনেস টোকেন তৈরি করুন এবং অ্যাক্সেস ফাইল সংরক্ষণ করুন। এটি চেকপয়েন্ট এবং হেলথ পড়তে দেয়, কথোপকথন বা কালেক্টর নিয়ন্ত্রণ নয়।
2. **চ্যানেল এবং ইন্টারভাল।** চ্যানেল এবং উইটনেস থেকে যোগাযোগযোগ্য একটি কালেক্টর ঠিকানা লিখুন। সেটিংস ফাইল সংরক্ষণ করুন।
3. **লঞ্চ।** `witness.json`, `witness-token.txt` এবং `bot-token.txt`-কে উইটনেস হোস্টে একসঙ্গে তৈরি করুন। ইনস্টলকৃত প্রকল্প পরিবেশে নিচের কমান্ডগুলো চালান।

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

ফাইলগুলো ডাউনলোড করলে উইটনেস শুরু হয় না। চ্যানেলে প্রথম স্বাক্ষরিত পোস্টটি দেখা যাচ্ছে কিনা তা যাচাই করুন, তারপর উইটনেসের পাবলিক-কী ফিঙ্গারপ্রিন্টটি আলাদাভাবে সংরক্ষণ করুন।

## কত ঘনঘন প্রকাশ করবেন তা নির্বাচন করুন

প্রতিটি চেক প্রকাশ করলে একটি নিয়মিত বাহ্যিক রেকর্ড তৈরি হয়। পাঁচ মিনিটের ব্যবধানে, যা প্রতিদিন প্রতি ওয়ার্কস্পেসে প্রায় ২৮৮টি পোস্ট। উন্নত সেটিংস পরিবর্তন বা সমস্যার ক্ষেত্রে প্রকাশ, একটি প্রক্সি এবং একটি কাস্টম বট এপিআই ঠিকানাও প্রদান করে।

**বটটি আসলে কী নিশ্চিত করে?**

সাক্ষী কালেক্টরের কাছে স্বাক্ষরিত চেকপয়েন্ট চায়, এটি প্রত্যাশিত কী-র বিরুদ্ধে যাচাই করে এবং একটি পৃথক স্বাক্ষরিত জার্নাল রাখে। এতে অনুপস্থিত প্রতিক্রিয়া, প্রত্যাখ্যাত উত্তর এবং সফল যাচাইকরণগুলি রেকর্ড করা হয়। প্রকাশনা এখনও নির্ভর করে সাক্ষীর চলমান অবস্থায় টেলিগ্রামের বট এপিআই-এ পৌঁছানোর ওপর।

এটি কালেক্টরের রিপোর্টকৃত জার্নাল অবস্থা পরীক্ষা করে। এটি প্রতিটি টেলিগ্রাম বার্তা স্বতন্ত্রভাবে পর্যবেক্ষণ করে না। এর জন্য নিয়ন্ত্রিত ডেলিভারি পরীক্ষা যোগ করুন।

## পরে প্রমাণগুলো দেখুন

সাক্ষী জার্নাল, চ্যানেল পোস্ট এবং স্বতন্ত্রভাবে সংরক্ষিত ফিঙ্গারপ্রিন্টগুলো রাখুন। [সম্পূর্ণ যাচাইকরণ প্রক্রিয়া](https://phishdestroy.github.io/TgWitness/bn/docs/reference/witness/#verify) সেগুলোকে সংগ্রাহকের স্বাক্ষরিত রপ্তানির সাথে তুলনা করে।
