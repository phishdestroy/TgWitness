# پتہ لگائیں کہ کیا غلط ہوا

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/troubleshooting/

علامت سے شروع کریں، ایک وقت میں ایک چیز جانچیں۔

## پینل ایک ٹوکن طلب کرتا ہے

اسے لانچر کی چھاپی فائل سے پینل ٹوکن چاہیے۔ Docker: `docker compose exec tgwitness cat /data/panel-token.txt`۔ نہ Telegram کوڈ، نہ بوٹ ٹوکن، نہ گواہ ٹوکن۔

## ٹیلیگرام کنیکٹ نہیں ہوتا

کنکشن چیک چلائیں۔ عوامی پراکسی پر کوئی اور چنیں اور محفوظ کریں۔ پراکسی کی قسم اور سیکرٹ کا فارمیٹ جانچیں۔ فہرستیں ریفریش کرنے سے راستہ خود نہیں بدلتا۔

## منسلک ہے، لیکن کوئی نئے پیغامات نہیں۔

1. کیا مشاہدہ صحیح ورک اسپیس میں چل رہا ہے؟
2. کیا ذریعہ منتخب ہے اور اس اکاؤنٹ کو نظر آتا ہے؟
3. اپنے ٹیسٹ گروپ میں منفرد پیغام بھیجیں اور اسے تلاش کریں۔
4. جرنل میں رکاوٹیں یا Telegram کی غلطیاں دیکھیں۔

خاموش چیٹ میں بس کچھ نیا نہیں۔ اگر مکمل ہونا اہم ہے تو کنٹرول شدہ ترسیل ٹیسٹ چلائیں۔

## FloodWait یا دوبارہ شروع کرنے کے بعد وقفہ

FloodWait کا مطلب ہے Telegram کہہ رہا ہے "آہستہ"۔ اس کے گزرنے کا انتظار کریں اور بوجھ کم کریں، دوبارہ جڑنے سے فائدہ نہیں۔ ری اسٹارٹ کے بعد TgWitness وہ پورا کرتا ہے جو Telegram کے پاس اب بھی ہے؛ باقی خلا ہے، اسے لکھ لیں۔

## بوٹ ترتیب دیا گیا ہے لیکن کچھ بھی پوسٹ نہیں کرتا

کیا گواہ چل رہا ہے، کیا بوٹ چینل میں پوسٹ کر سکتا ہے، کیا یہ کلیکٹر اور Bot API تک پہنچ سکتا ہے؟ اس کے جرنل میں ناکام پوسٹس دیکھیں۔ کلیکٹر کی طرف پول کا مطلب یہ نہیں کہ پوسٹ چلی گئی۔

## GitHub ٹوکن انٹیگریشن کہاں ہے؟

**منصوبہ بندی شدہ۔** اضافی میں مجوزہ فورک اور بلڈ کی تصدیق کے ورک فلو کی وضاحت کی گئی ہے۔ فی الحال کوئی GitHub ٹوکن فارم یا خودکار تصدیق موجود نہیں ہے کہ چلتی ہوئی تنصیب کسی ریپوزیٹری سے مطابقت رکھتی ہے۔ [موجودہ فیچر کی حیثیت](https://phishdestroy.github.io/TgWitness/ur/docs/reference/features/) دیکھیں۔

بگ رپورٹ کر رہے ہیں؟ ورژن، OS، مراحل اور ذاتی معلومات ہٹائی ہوئی غلطی۔ کبھی سیشنز، ٹوکنز، نجی پیغامات یا ڈیٹا ڈائریکٹری عوامی issue میں نہ ڈالیں۔
