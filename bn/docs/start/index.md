# মিনিটখানেকের মধ্যে শুরু করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/start/

আগে ডেমোতে ঘুরে দেখুন, তারপর নিজের অ্যাকাউন্ট যুক্ত করুন।

## অ্যাকাউন্ট ছাড়াই চারপাশে দেখুন

প্রকল্প নিন, **Python 3.11 বা নতুন** রাখুন, ডেমো চালান। বাকি সব লঞ্চার সেট করে।

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### উইন্ডোজ

```
.\scripts\Demo.cmd
```

### লিনাক্স / ম্যাকওএস

```
sh start.sh --demo
```

বানানো বার্তাসহ একটি ওয়ার্কস্পেস ব্রাউজারে খোলে। একটি চ্যাট খুলুন, একটি সম্পাদনা তুলনা করুন, একটি এক্সপোর্ট দেখুন। Telegram জড়িত নয়।

![নমুনা বার্তা সহ TgWitness কথোপকথন দৃশ্য](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

একটি নমুনা কর্মস্থান। আপনার নিজস্ব জার্নাল আলাদাভাবে শুরু হয়।

## আপনার নিজস্ব কর্মক্ষেত্র শুরু করুন

ডেমো বন্ধ করুন, তারপর:

### উইন্ডোজ

```
.\Start.cmd
```

### লিনাক্স / ম্যাকওএস

```
sh start.sh
```

লঞ্চার যে ঠিকানা দেখায় তা খুলুন এবং উল্লেখ করা ফাইল থেকে **প্যানেল অ্যাক্সেস টোকেন** পেস্ট করুন। এটি TgWitness-এর জন্য, Telegram-এর জন্য নয়।

## আপনার প্রথম বার্তাটি ধারণ করুন

1. [একটি নিবেদিত টেলিগ্রাম অ্যাকাউন্ট সংযুক্ত করুন।](https://phishdestroy.github.io/TgWitness/bn/docs/accounts/)
2. একটি গ্রুপ বা চ্যানেল বেছে পর্যবেক্ষণ শুরু করুন।
3. আপনার টেস্ট গ্রুপে একটি বার্তা পাঠান এবং জার্নালে তা আসতে দেখুন।

সার্ভার ইনস্টলেশনের জন্য [Keep it running](https://phishdestroy.github.io/TgWitness/bn/docs/server/) অনুসরণ করুন।
