# Telegram · Робота з архівом

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/archive/

Знайдіть повідомлення. Перевірте джерело. Складіть справу.

01**Додайте історію**

Завантажте минулі повідомлення ввімкнених джерел у простір.

02**Слідкуйте за джерелами**

Шукайте, а потім відкривайте збережене повідомлення за кожним результатом.

03**Забезпечте чіткість передачі інформації**

Ваш аналіз — в одному файлі, підписані докази — поруч.

Зафіксовані записи, розпізнаний текст та висновки аналітиків чітко розмежовуються.

## Завантажити попередні повідомлення

1. **Джерела → Чати в охопленні**: перевірте ввімкнені чати й запустіть спостереження.
2. **Завантажити всю історію**. Береться список джерел у його поточному вигляді.
3. **Призупинити історію** / **Продовжити історію** — будь-коли. Після перезапуску продовжуйте вручну.
4. Перевірте результат за кожним джерелом і чергу завантажень, збережіть підписаний звіт про перебіг разом з експортом.

Так заповнюється простір. Експорт одного чату в HTML/JSON — окрема операція. [Докладніше](https://phishdestroy.github.io/TgWitness/uk/docs/reference/history/).

## Спочатку здійсніть пошук, а потім вирішуйте щодо використання ШІ

1. **Журнал** шукає локально, з фільтрами за джерелом і часом.
2. Знайдіть фразу чи домен, відкрийте запис і його версії.
3. Для ШІ адміністратор налаштовує провайдера в **Інтеграціях**. Потім **Запитати архів**: оберіть чати й період, перегляньте **Дані для моделі** та зніміть позначки з того, що не має піти.
4. Перевірте цитати, збережіть відповідь як звіт і додайте свої нотатки.

Пошуку ШІ не потрібен. Звіти зберігають джерела й правки окремо від підписаного журналу. [Налаштування провайдера](https://phishdestroy.github.io/TgWitness/uk/docs/reference/analysis/).

## Оберіть потрібний варіант підключення

| Завдання | Відкрити | Налаштування |
| --- | --- | --- |
| Дати ШІ-клієнту читати вибрані чати | **Інтеграції → MCP** | [Встановити MCP, створити обмежений токен, підключити](https://phishdestroy.github.io/TgWitness/uk/docs/reference/mcp/) |
| Розпізнавання тексту у збережених медіафайлах | Запис `media.saved` → **Розпізнати вкладення** | [Налаштувати локальний Docker-воркер](https://phishdestroy.github.io/TgWitness/uk/docs/reference/media-analysis/) |
| Надсилайте події до n8n або SIEM | **Інтеграції → Вихідні веб-хуки** | [Додати отримувача, перевіряти HMAC, відсіювати дублі ID](https://phishdestroy.github.io/TgWitness/uk/docs/reference/webhooks/) |

**Який токен доступу куди вводити?**

Доступ до панелі — для людей. MCP має власні токени лише для читання, вебхуки — власний секрет HMAC. Сесія Telegram нікому з них не потрібна.

[Надайте доступ до панелі](https://phishdestroy.github.io/TgWitness/uk/docs/access/) або [налаштуйте клієнт MCP](https://phishdestroy.github.io/TgWitness/uk/docs/reference/mcp/).
