## S3 نقول۔ بیرونی تصدیقات۔

انکرپٹ شدہ نقول محفوظ رکھیں اور آزادانہ جانچ شامل کریں۔

ڈیفالٹ طور پر بند

### سب کچھ S3 کے مطابقت پذیر اسٹوریج میں کاپی کریں

جرنل، فائلیں، چیک پوائنٹس اور چیٹ ایکسپورٹس، S3 پر جانے سے پہلے انکرپٹ۔

**اسٹوریج کی ترتیبات اور بازیابی**

کلائنٹ سائیڈ انکرپشن

`AES-256-GCM` آپ کی مشین پر۔ فراہم کنندہ صرف سائفر ٹیکسٹ دیکھتا ہے۔

شیڈول شدہ یا دستی کاپیاں

ابھی کاپی کریں یا ہر 1 سے 1，440 منٹ بعد، پیش رفت پینل میں۔

آبجیکٹ لاک

برقراری کے دن اور موڈ چنیں، پینل جانچتا ہے کہ واقعی لاگو ہوا۔

تصدیق شدہ بازیابی

کلید الگ رکھیں۔ کہیں بھی بحال کریں، فائلیں صرف تصدیق کے بعد نکلتی ہیں۔

![مکمل آف سائٹ کاپی پینل： اینڈ پوائنٹ، خطہ، بکیٹ، رسائی کیز، شیڈول، آبجیکٹ لاک اور ریکوری کی کنٹرولز](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

مکمل پینل جدید اختیارات کے ساتھ کھولا گیا ہے۔ کوئی اسٹوریج کی تفصیلات دکھائی نہیں گئی ہیں۔

جرنل اور میڈیا`AES-256-GCM`S3 کے مطابق اسٹوریج

[S3 کو کنفیگر کریں اور ایک کاپی بحال کریں](https://phishdestroy.github.io/TgWitness/ur/docs/exports/#s3)[تصدیقی تفصیلات پڑھیں](https://phishdestroy.github.io/TgWitness/ur/docs/reference/evidence/#off-site-copy-and-restore-s3)

### ماخذ حاصل کریں۔

[ماخذ ZIP فائل ڈاؤن لوڈ کریں](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) اور اسے نکالیں، یا ریپوزیٹری کلون کریں：

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

Python 3.11+ درکار ہے۔ Windows پر لانچر اسے انسٹال کرنے کی پیشکش کرتا ہے۔

[پر ریلیزز براؤز کریں](https://github.com/phishdestroy/TgWitness/releases)

مرحلہ 02

### چلانے کا طریقہ منتخب کریں۔

`Start.cmd` پر ڈبل کلک کریں، یا پاور شیل میں چلائیں：

```
.\Start.cmd
```

صرف دریافت کر رہے ہیں؟ ایک الگ تھلگ ڈیمو کے لیے `scripts\Demo.cmd` پر ڈبل کلک کریں۔ ٹیلیگرام لاگ ان کی ضرورت نہیں۔

Python 3.11+ اور `venv` دستیاب ہیں：

```
sh start.sh
```

اس کے بجائے فرضی جریدہ کھولنے کے لیے `sh start.sh --demo` چلائیں۔

جب Docker چل رہا ہو اور Compose 2.20+ انسٹال ہو：

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

لانچ کے بعد [127.0.0.1:8787 پر](http://127.0.0.1:8787) کھولیں۔

## شروع کرنے سے پہلے

**کیا یہ صفحہ ٹیلیگرام سے منسلک ہے؟**

نہیں۔ یہ جعلی مثالوں والا جامد صفحہ ہے۔ ایپ آپ کی اپنی مشین پر چلتی ہے اور آپ وہیں سائن اِن کرتے ہیں۔

**کیا یہ کیپچر سے پہلے حذف شدہ پیغامات کو بازیافت کر سکتا ہے؟**

نہیں۔ یہ وہی رکھتا ہے جو آپ کے اکاؤنٹ نے چلتے وقت دیکھا۔ بعد کا اسنیپ شاٹ چھوٹی ہوئی ترامیم یا حذف شدہ پیغامات دوبارہ نہیں بنا سکتا۔
