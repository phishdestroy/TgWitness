# Створити «Case Board»

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/case-board/

Перетворіть збережені повідомлення на справу, над якою працює вся команда.

Закладки, точні цитати, зрізи й обговорення, кожне пов'язане з джерелом. Кожна зміна — підписана ревізія.

## Від повідомлення до картки справи

1. **Розслідування → Case Board** (режим «Стандартний» або «Експерт»). Створіть колекцію для справи.
2. У **Журналі** або в чаті натисніть **На дошку** (або **B**). Картка потрапить у «Вхідні», дайте їй назву й перемістіть.
3. Виділіть текст у повідомленні — **Виділити → на дошку** збереже точну цитату й версію. Позначте, чому це важливо.
4. Обговорюйте, ставте статус, повертайтеся до джерела, коли треба. **Презентація** проведе команду через увесь матеріал.

### Слідуйте за одним зміненим посиланням для оплати

Синтетичний приклад · локальна ілюстрація

1. **Збір даних.** Відкрийте збережене спостереження № 142 та його версію повідомлення.
2. **Додайте до закладок.** Запишіть цитату, посилання на джерело та своє запитання на картці.
3. **Переглянути.** Додайте коментар команди та перемістіть картку до статусу «Переглянути».
4. **Покажіть.** Пройдіться по колекції та відкрийте контекст цитованого джерела.

## Збережіть корисний діапазон один раз

Shift-клік по двох повідомленнях для **Зріз між**, **Зріз за часом** або збереження поточних фільтрів журналу. **Показати записи після закладки** покаже, що надійшло пізніше.

Зрізи за часом використовують час спостереження, зрізи за ID повідомлень стежать за цими повідомленнями в міру їхніх змін.

## Присвойте кожному колезі відповідну роль

**Рецензент** читає, **Аналітик** додає картки й коментарі, **Оператор** ще й керує колекціями та рішеннями. Права на чати діють і на картки.

## Перенесіть результат роботи у кінцевий продукт

Зрізи експортуються в підписаний JSON або CSV. У звіти можна додати закладки, зрізи й коментарі — це налаштовується в [Report studio](https://phishdestroy.github.io/TgWitness/uk/docs/reports/). Для отримувача з обмеженим доступом використовуйте [передачу](https://phishdestroy.github.io/TgWitness/uk/docs/handover/).
