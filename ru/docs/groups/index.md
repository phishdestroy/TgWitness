# Управление группой учетных записей

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/groups/

Ведите несколько аккаунтов вместе — у каждого по-прежнему свои записи и ключ.

Группа собирает статус подключения, запуск/паузу, общие настройки и экспорт на одном экране. Удобно, когда несколько аккаунтов работают по одному делу.

## Открыть обзор группы

Откройте группу в **Аккаунтах**. У каждого аккаунта видно состояние, маршрут, задержку и последнее сохранённое сообщение. **Требует внимания** перечисляет сломанные, **Исправить** ведёт прямо туда.

**Запустить все** / **Приостановить все** спрашивают перед действием. **Настройки группы** общие, но собственные значения аккаунта остаются, пока вы их не замените.

### Проверьте изменение маршрута в группе

Синтетический пример · иллюстративные проверки и результаты

1. **Выберите.** Выберите группу и проверьте, какие аккаунты будут изменены.
2. **Подготовка.** Сохраняйте отдельный маршрут для каждого аккаунта, когда это необходимо.
3. **Проверьте.** Протестируйте предложенное соединение и проанализируйте результаты измерений.
4. **Приступить к работе.** Перед сохранением проверьте текст ещё раз и проанализируйте результат для каждой учётной записи.

#### Команда по делу

Коллектор каналов · Коллектор групп · Справочная учетная запись

3 отдельных рабочих пространства

#### Проверенный текст

2 аккаунта следуют предложенному маршруту.

Справочный аккаунт следует собственному маршруту.

#### Проверки перед началом работы

Коллектор каналов: время передачи данных в Telegram — 84 мс

Групповой сборщик: время передачи данных Telegram — 91 мс

Эти цифры являются вымышленными показателями, приведенными в качестве примера.

#### Результаты применения

Коллектор каналов: маршрут сохранен, наблюдение возобновлено.

Групповой сборщик: повторная проверка завершилась неудачно, восстановлены предыдущие настройки.

Справочный аккаунт: собственный маршрут сохранен.

## Измените маршрут, добавив этап проверки

1. **Изменить маршрут группы**, выберите тип и настройки.
2. **Проверить выбор**: какие аккаунты изменятся и у каких свой маршрут.
3. **Подготовить и проверить** проверяет новое подключение к Telegram и, где возможно, внешний IP.
4. **Применить проверенное подключение** и посмотрите на каждый результат. Работавшие аккаунты продолжат, простаивавшие так и останутся.

Задержка — это время установки соединения с Telegram, внешний IP — то, что показал маршрут во время проверки. Результаты у аккаунтов могут отличаться.

## Используйте перекрывающийся доступ

**Чаты, которые видят несколько аккаунтов**, показывают общие источники и их охват. Каналы и супергруппы можно экспортировать сразу несколькими аккаунтами через **Экспорт … аккаунтами**. Личные чаты и обычные группы — нет: номера сообщений там свои у каждого аккаунта.

## Экспорт группы в виде пакета

**Экспорт группы** даёт один ZIP с подписанным экспортом каждого аккаунта и подписанным их списком. У каждого свой отпечаток для проверки. Общую хронологию по-прежнему собираете вы.
