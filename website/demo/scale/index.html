WHAT IS COUNTED

Messages and events

Messages count distinct source keys within a run. Retries and duplicate keys do not increase that count. Signed events also include observations and are shown separately.

WHAT STAYS PRIVATE

Source archives

Full message bodies, authors, source IDs, account identifiers and original archives remain private. This preview presents aggregate measurements and signed checkpoints.
