# Подготовьте копию для распространения

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/handover/

Делитесь соответствующими замечаниями, сохраняя исходную рабочую среду в неизменном виде.

Передача представляет собой отдельный подписанный выдержку. Выберите чаты и участников, сократите идентификационные данные или текст и определите, какие файлы и заметки команды должны войти в копию получателя. В манифесте фиксируется выбор, а также количество неизменённых, сокращённых и пропущенных записей.

## Подготовьте выдержку для получателя

1. Откройте **«Экспорт» → «Выдержка для передачи**». Укажите цель, выберите чаты и, при необходимости, период в формате UTC, затем выберите **«Загрузить участников выбранных чатов»**, если вам нужны имена участников.
2. Выберите, как обрабатывать остальных участников: использовать псевдонимы, опускать их сообщения или отображать их в том виде, в каком они были записаны. Устанавливайте текст сообщений и вложения независимо друг от друга; при желании маскируйте номера телефонов и адреса электронной почты.
3. Решите, следует ли включать закладки и фрагменты Case Board или карточки с комментариями. В данном тексте псевдонимы следователей могут заменить названия команд.
4. Выберите **«Скачать выдержку для передачи**». Откройте сгенерированный отчет и выбранные записи локально, проверьте архив и ознакомьтесь с копией перед отправкой.

### Один оригинал, одна копия для обмена

Синтетический пример · иллюстрация носит исключительно ознакомительный характер

1. **Выберите.** Включите чат по делу и укажите, о каком лице идет речь в выдержке.
2. **Минимизировать.** Выберите, как другой участник будет отображаться в копии, предназначенной для совместного доступа.
3. **Проверьте.** Откройте сгенерированный отчет и записи из архива перед отправкой.
4. **Поделитесь.** Предоставьте проверенную копию и отдельно сообщите её проверенный отпечаток.

#### Исходные замечания

Нора · пользователь 71002

«Я получил ссылку на отредактированный вариант».

Источник журнала сохраняет эту запись.

#### Копия для получателя

Показать так, как записано: Нора · пользователь 71002 · «Я получила исправленную ссылку».

Псевдоним: P01 · «Я получил исправленную ссылку».

Опустить: сообщение этого участника не включается в текст.

#### Ознакомьтесь с фактическими файлами

Ознакомьтесь с файлами report.html и records.jsonl.

Проверьте идентификационные данные, текст, вложения и дополнительные комментарии команды.

#### Подписанный отрывок

Выбор + хеши файлов + подписанный манифест

Отдельный пакет, привязанный к границе исходного журнала

## Используйте элементы управления в комплексе

| Контроль | Влияние на текст |
| --- | --- |
| Люди | Обеспечьте идентифицируемость выбранных субъектов; других участников псевдонимизируйте или опускайте по усмотрению. |
| Текст | Включить весь текст, только текст выбранных пользователей и наблюдательного аккаунта или опустить текст сообщений и содержащие текст поля с подробностями. |
| Файлы | Выберите файлы выбранных лиц и наблюдаемого аккаунта, файлы всех отображаемых сообщений или никаких файлов. |
| Case Board | Не используйте материалы доски, закладки и фрагменты, а также карточки с обсуждением в команде. |

Проверяйте текст в свободной форме и содержимое файлов, а также идентификационные данные: использование псевдонима не приводит к автоматическому удалению всех имен, упомянутых в сообщении или вложении. Если выбранный файл, подлежащий сохранению, недоступен, восстановите его или явно исключите вложения перед генерацией выдержки.

## Текст должен поддаваться независимой проверке

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

Храните отдельно исходный подписанный архив доказательств и контрольные точки. Процесс передачи фиксирует собственную проекцию, поэтому получатель может проверить переданную копию, не получая всю рабочую область. [Studio отчетов](https://phishdestroy.github.io/TgWitness/ru/docs/reports/) обеспечивает свой формат представления данных; [проверка экспорта](https://phishdestroy.github.io/TgWitness/ru/docs/exports/) объясняет достоверность ссылок.
