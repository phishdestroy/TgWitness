## เตรียมบอทและช่อง

สร้างบอทด้วย BotFather และอนุญาตให้โพสต์ในช่องของคุณ รันพยานที่อื่น: โฮสต์อื่นที่ดีที่สุดคือมีคนอื่นดูแล มีค่ามากกว่ากระบวนการที่สองข้างเครื่องเก็บข้อมูลมาก

## สามขั้นตอนในส่วน Extras

1. **สิทธิ์อ่านอย่างเดียว** **ส่วนเสริม → พยานอิสระ** สร้างโทเค็น บันทึกไฟล์ มันอ่าน checkpoint และสถานะเท่านั้น
2. **ช่องและช่วงเวลา** ช่อง Telegram หรือ webhook ของ Discord พร้อมที่อยู่เครื่องเก็บข้อมูลที่พยานเข้าถึงได้ บันทึกไฟล์การตั้งค่า
3. **เปิดใช้งาน** วาง `witness.json`, `witness-token.txt` และ `bot-token.txt` ไว้ด้วยกันบนโฮสต์พยานแล้วรัน:

```
python -m tgwitness.witness run --config witness.json --check-config
python -m tgwitness.witness run --config witness.json
```

รอโพสต์ที่ลงนามโพสต์แรกในช่อง แล้วบันทึกลายนิ้วมือของพยานไว้ในที่ปลอดภัย

ใช้ Discord แทน? บันทึก URL ของ webhook เป็น `discord-webhook.txt` พยานหนึ่งตัวโพสต์ไปที่เดียว การตรวจที่ยาวจะมาถึง Discord เป็นไฟล์

## เลือกความถี่ในการเผยแพร่

การโพสต์ทุกการตรวจให้บันทึกภายนอกที่สม่ำเสมอ: ทุกห้านาทีเท่ากับประมาณ 288 โพสต์ต่อวันต่อพื้นที่ทำงาน การตั้งค่าขั้นสูงสามารถโพสต์เฉพาะเมื่อมีการเปลี่ยนแปลงหรือปัญหา ใช้พร็อกซี หรือ Bot API แบบกำหนดเอง

**บอทนี้ยืนยันอะไรกันแน่?**

มันขอ checkpoint ที่ลงนามจากเครื่องเก็บข้อมูล ตรวจกับคีย์ที่คาดไว้ และเก็บบันทึกที่ลงนามของตัวเอง รวมถึงคำตอบที่พลาดและถูกปฏิเสธ

มันตรวจสถานะบันทึก ไม่ได้เฝ้าดู Telegram เอง สำหรับเรื่องนั้น ให้ทำการทดสอบการส่งถึงแบบควบคุม

## ตรวจสอบหลักฐานในภายหลัง
