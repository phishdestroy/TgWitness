# เริ่มใช้งานได้ภายในไม่กี่นาที

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/start/

ก่อนอื่น ลองดูตัวอย่างที่ทำงานได้ก่อน แล้วจึงเชื่อมต่อบัญชีของคุณเอง

## ดูรอบๆ โดยไม่ต้องมีบัญชี

ดาวน์โหลดหรือคัดลอกโครงการนี้ ติดตั้ง **Python 3.11 หรือเวอร์ชันที่ใหม่กว่า** และรันเดโม โปรแกรมเปิดตัวจะสร้างสภาพแวดล้อมท้องถิ่นและติดตั้งส่วนประกอบที่จำเป็น

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

เบราว์เซอร์จะเปิดพื้นที่ทำงานที่มีข้อความสมมติ เปิดการสนทนา เปรียบเทียบการแก้ไข และตรวจสอบไฟล์ที่ส่งออก โหมดสาธิตไม่เชื่อมต่อกับ Telegram

![หน้าแสดงการสนทนาของ TgWitness พร้อมตัวอย่างข้อความ](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

ตัวอย่างพื้นที่ทำงานของคุณ บันทึกของคุณจะเริ่มต้นแยกต่างหาก

## สร้างพื้นที่ทำงานของคุณเอง

ปิดกระบวนการเดโม แล้วใช้โปรแกรมเปิดปกติ:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

เปิดที่อยู่ท้องถิ่นที่แสดงโดยโปรแกรมเปิดใช้งาน หากถูกถาม ให้ป้อน**โทเค็นการเข้าถึงแผง**ควบคุมจากไฟล์ท้องถิ่นที่ระบุในเทอร์มินัล การนี้จะปลดล็อก TgWitness; กระบวนการนี้แยกต่างหากจากการเข้าสู่ระบบ Telegram

## บันทึกข้อความแรกของคุณ

1. [เชื่อมต่อบัญชี Telegram ที่ใช้เฉพาะสำหรับวัตถุประสงค์นี้](https://phishdestroy.github.io/TgWitness/th/docs/accounts/)
2. เลือกกลุ่มหรือช่องที่บัญชีสามารถเข้าถึงได้ แล้วเริ่มการสังเกตการณ์
3. ส่งข้อความใหม่ในกลุ่มทดสอบที่คุณควบคุม และตรวจสอบว่าข้อความนั้นปรากฏในบันทึกหลักฐานหรือไม่

สำหรับการติดตั้งบนเซิร์ฟเวอร์ โปรดทำตามขั้นตอนในส่วน [“Keep it running](https://phishdestroy.github.io/TgWitness/th/docs/server/)”
