## Sizning birinchi yozib olingan xabaringiz

[### Bir necha daqiqada boshlang TgWitness-ni namunaviy ma'lumotlar bilan sinab ko'ring, so'ng Windows, Linux yoki macOS-da o'zingizning Telegram kuzatuv ish maydoningizni ishga tushiring.](https://phishdestroy.github.io/TgWitness/uz/docs/start/)[### Maxsus hisob Yig'ish uchun alohida Telegram akkauntini tayyorlang.](https://phishdestroy.github.io/TgWitness/uz/docs/dedicated-account/)[### Hisobni bog'lang Telegramni QR-kod, telefon raqami yoki sessiyani import qilish orqali ulanib, manbalarni tanlang va yangi xabarlar jurnalga yetib kelishini tekshiring.](https://phishdestroy.github.io/TgWitness/uz/docs/accounts/)[### Proxy tanlang Avtomatik MTProxy yo'nalishlarini saqlang yoki o'zingizning proksiyangizdan foydalaning. IP rejimlarini, zaxira qoidalarini va tashqi so'rovlar uchun yo'nalishni tanlang.](https://phishdestroy.github.io/TgWitness/uz/docs/proxies/)[### Eksport va tekshirish Qayd etilgan Telegram tarixini eksport qiling, imzolarni tasdiqlang va mustaqil guvoh saqlagan tekshiruv nuqtasidagi jurnal bilan solishtiring.](https://phishdestroy.github.io/TgWitness/uz/docs/exports/)[### GitHub Actions yozib oladi Vaqtinchalik GitHub runner'da bitta Telegram suhbatini eksport qiling.](https://phishdestroy.github.io/TgWitness/uz/docs/capture/)

## Sinab ko'rib o'rganing

[### Dalillar qanday ishlashini ko'ring Xabarni ushlashdan tekshiruv nuqtasigacha kuzating. Namuna yozuvni o'zgartiring, uning SHA-256 zanjirini qayta hisoblang va saqlangan tekshiruv nuqtasi nima aniqlashini ko'ring.](https://phishdestroy.github.io/TgWitness/uz/docs/concepts/)[### Barcha suhbatlarni tergov qiling Telegram bo'ylab kanallar, guruhlar, shaxsiy suhbatlar va botlar bo'ylab end-to-end tergov o'tkazing: butun hisobni qamrab olish, tarix, odamlar, havolalar, fayllar, vaqt chiziqlari va tasdiqlangan dalillar.](https://phishdestroy.github.io/TgWitness/uz/docs/cases/)[### Xavfsiz saqlang Sessiyalar, kalitlar va dalillar qayerda saqlanishini, nima qurilmangizdan chiqib ketishini, himoyalar nimani qamrab olishini va o'rnatishni qanday mustahkamlashni ko'ring.](https://phishdestroy.github.io/TgWitness/uz/docs/security/)
