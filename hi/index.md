## S3 प्रतियाँ। बाहरी जांचें।

एन्क्रिप्टेड प्रतियाँ रखें और स्वतंत्र जांच जोड़ें।

डिफ़ॉल्ट रूप से बंद

### सब कुछ S3-संगत स्टोरेज में कॉपी करें

जर्नल, फ़ाइलें, टाइमस्टैम्प वाले चेकपॉइंट और चैट एक्सपोर्ट — AWS S3 या संगत स्टोरेज में अपलोड होने से पहले एन्क्रिप्ट किए जाते हैं।

**भंडारण सेटिंग्स और पुनर्प्राप्ति**

क्लाइंट-साइड एन्क्रिप्शन

`AES-256-GCM` इस मशीन पर ऑब्जेक्ट्स को एन्क्रिप्ट करता है। प्रदाता एन्क्रिप्ट किए गए ऑब्जेक्ट्स प्राप्त करता है।

निर्धारित या मैन्युअल प्रतियाँ

अभी कॉपी करें, या 1 से 1,440 मिनट के बीच कोई अंतराल चुनें। पैनल में प्रगति देखें।

ऑब्जेक्ट लॉक

जब बकेट इसका समर्थन करता है, तो प्रतिधारण दिनों और एक मोड चुनें। पैनल रिपोर्ट करता है कि अपलोड की गई वस्तु पर प्रतिधारण की पुष्टि हुई थी या नहीं।

सत्यापित पुनर्प्राप्ति

एन्क्रिप्शन कुंजी डाउनलोड करें और उसे अलग से सुरक्षित रखें। किसी अन्य मशीन पर पुनर्स्थापित करें; फाइलें केवल सत्यापन के बाद प्रकाशित की जाती हैं।

![पूर्ण ऑफ़-साइट कॉपी पैनल: एंडपॉइंट, क्षेत्र, बकेट, एक्सेस कीज़, शेड्यूल, ऑब्जेक्ट लॉक और रिकवरी की नियंत्रण](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

उन्नत विकल्पों के साथ पूरा पैनल विस्तारित। कोई भंडारण क्रेडेंशियल नहीं दिखाए गए हैं।

जर्नल और मीडिया`AES-256-GCM`S3-संगत भंडारण

[S3 कॉन्फ़िगर करें और एक प्रति पुनर्स्थापित करें](https://phishdestroy.github.io/TgWitness/hi/docs/exports/#s3)[के सत्यापन विवरण पढ़ें](https://phishdestroy.github.io/TgWitness/hi/docs/reference/evidence/#off-site-copy-and-restore-s3)

**क्या नहीं करता** यह निर्यात की गई डिक्रिप्शन कुंजी के बिना पुनर्स्थापित नहीं करता और न ही किसी स्वतंत्र गवाह को प्रतिस्थापित करता है।

### सूचनाएं · अप्राइज़

प्रॉब्लम अलर्ट, चैट में बदलाव और दैनिक सारांश Apprise के माध्यम से: मैसेंजर, ईमेल या आपका अपना JSON वेबहुक।

यह**नहीं करता।** यह संदेश पाठ तब तक नहीं भेजता जब तक आप अंश सक्षम नहीं करते।

 [सूचना गंतव्यों को कॉन्फ़िगर करें](https://phishdestroy.github.io/TgWitness/hi/docs/reference/operations/#notifications)

### बाहरी टाइमस्टैम्प

RFC 3161 और OpenTimestamps के साथ टाइमस्टैम्प चेकपॉइंट हैश।

**क्या नहीं करता** यह लंबित कैलेंडर रसीद को पुष्टि किए गए बिटकॉइन टाइमस्टैम्प के रूप में नहीं मानता।

 [टाइमस्टैम्प प्रमाण देखें](https://phishdestroy.github.io/TgWitness/hi/docs/reference/timestamp/)

### स्वतंत्र गवाह

एक अलग होस्ट हस्ताक्षरित अवलोकन रखता है और प्रकाशित कर सकता है `TGW1` चेकपॉइंट्स।

**क्या नहीं करता** यह एक कलेक्टर होस्ट पर दो वर्कस्पेस को स्वतंत्र गवाहों में नहीं बदलता।

**क्या नहीं करता** यह हर चूके गए संपादन या गायब संदेश को पुनर्निर्मित नहीं करता।

चरण 01

### स्रोत प्राप्त करें।

[स्रोत ZIP डाउनलोड करें](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) और उसे एक्सट्रेक्ट करें, या रिपॉजिटरी क्लोन करें:

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

स्रोत लॉन्च के लिए Python 3.11+ आवश्यक है। यदि Python मौजूद नहीं है तो Windows लॉन्चर इंस्टॉलेशन की सुविधा प्रदान करता है।

[रिलीज़ ब्राउज़ करें](https://github.com/phishdestroy/TgWitness/releases)

Windows पर Python नहीं है? [पोर्टेबल पैकेज डाउनलोड करें](https://github.com/phishdestroy/TgWitness/releases/download/v0.7.0/TgWitness-0.7.0-windows-amd64-portable.zip), इसे एक्सट्रेक्ट करें और `TgWitness.cmd` पर डबल-क्लिक करें।

चरण 02

### चलाने का तरीका चुनें।

`Start.cmd` पर डबल-क्लिक करें, या PowerShell में चलाएँ:

```
.\Start.cmd
```

सिर्फ़ देख रहे हैं? एक अलग डेमो के लिए `scripts\Demo.cmd` पर डबल-क्लिक करें। टेलीग्राम लॉगिन की आवश्यकता नहीं है।

पाइथन 3.11+ और `venv` उपलब्ध:

```
sh start.sh
```

कल्पनिक जर्नल खोलने के लिए इसके बजाय `sh start.sh --demo` चलाएँ।

Docker चलने और Compose 2.20+ स्थापित होने पर:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

दूसरा कमांड आपका निजी पैनल टोकन दिखाता है। इसे अपनी मशीन पर रखें।

## शुरू करने से पहले।

**क्या यह पेज टेलीग्राम से जुड़ता है?**

नहीं। यह एक स्थिर प्रोजेक्ट पेज है जिसमें काल्पनिक उदाहरण और स्क्रीनशॉट हैं। वास्तविक एप्लिकेशन आपके कंप्यूटर या सर्वर पर चलता है; साइन-इन वहीं होता है।

**क्या यह कैप्चर से पहले हटाए गए संदेशों को पुनः प्राप्त कर सकता है?**

नहीं। TgWitness आपके खाते द्वारा संग्रहण चलने के दौरान देखी गई सामग्री को बनाए रखता है। बाद का इतिहास स्नैपशॉट छूटी हुई संपादनों या हटाए गए संदेशों को पुनर्स्थापित नहीं कर सकता।

**क्या मेरा पूरा जर्नल एन्क्रिप्टेड है?**

खाता क्रेडेंशियल और हस्ताक्षर रहस्य एक एन्क्रिप्टेड वॉल्ट में संग्रहीत होते हैं। स्थानीय संदेशों और संलग्नकों के लिए एक एन्क्रिप्टेड डिस्क या वॉल्यूम आवश्यक है। निर्यात वैकल्पिक रूप से पासवर्ड-संरक्षित AES-256 ZIP का उपयोग कर सकते हैं।

**क्या यह टेलीग्राम से संबद्ध है?**

नहीं। TgWitness एक स्वतंत्र परियोजना है जो Telethon का उपयोग करती है और MIT लाइसेंस के तहत वितरित की जाती है। आप अंतर्निहित API सेटिंग्स या अपने स्वयं के API जोड़े का उपयोग करके अपने स्वयं के खातों को अधिकृत करते हैं।
