# Виберіть проксі-сервер

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/proxies/

Тримайте акаунт на зв'язку й самі вирішуйте, чи може він колись показати IP вашого сервера.

## Спочатку виберіть режим IP

01**Приховати адресу**

Лише проксі. Якщо жоден не працює — чекає.

02**Direct — як крайній захід**

Після затримки йде напряму, а щойно проксі запрацює — повертається до нього.

03**Сервер за тунелем або VPN**

Напряму можна. VPN цей режим не налаштовує й не перевіряє.

Маршрут визначає тип з’єднання. Режим IP визначає, чи дозволено пряме з’єднання.

## Нехай пул підтримує маршрут

1. **Акаунт → Налаштування → Налаштування підключення**.
2. Оберіть режим IP і **Автоматичний MTProxy** або фіксований маршрут.
3. Збережіть, потім **Перевірити підключення до Telegram** (працює і до входу).
4. Запустіть збір і надішліть собі тестове повідомлення.

Нові простори стартують на автоматичному MTProxy з режимом **Приховувати адресу**. Пул бере чотири публічні списки, перевіряє сервери, лишає робочі й замінює мертві.

## Використовуйте власний проксі-сервер

SOCKS5, HTTP CONNECT, посилання на проксі Telegram або каталог оператора. Перед перемиканням призупиніть спостереження. Секрети Fake TLS (`ee`…) не підтримуються.

**Налаштування черговості, обміну та повторних спроб**

**Параметри → Автоматичний MTProxy**: пороги збоїв, паузи, ротація, акаунтів на проксі. Ліміт 1 означає, що акаунт чекатиме, а не ділитиме проксі. Різні проксі однаково можуть мати спільну зовнішню IP.

## Відокремлення Telegram від зовнішніх запитів

MTProxy возить лише Telegram. Мітки часу, сповіщення, копії й перевірка коду йдуть через окремий SOCKS5/HTTP-проксі, маршрут акаунта SOCKS5/HTTP або напряму, якщо режим дозволяє. Або вимкніть їх.

`TGWITNESS_PROXY_FEED_PROXY` задає маршрут для завантаження списків. [Свідок](https://phishdestroy.github.io/TgWitness/uk/docs/witness/) має власні налаштування. Ніщо з цього не торкається вашого браузера й системної мережі.

Ще: [режими й типові значення](https://phishdestroy.github.io/TgWitness/uk/docs/reference/connection/#ip-modes), [хто може змінювати маршрути](https://phishdestroy.github.io/TgWitness/uk/docs/access/).
