# Telegramの記録から、明確な事件へ。

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/

保存されたメッセージや変更内容を処理し、調査結果をそのソースに関連付け、レビュー用の署名済みファイルを準備します。

## 最初にキャプチャされたメッセージ

[### 数分で始められます サンプルデータを使ってTgWitnessをお試しいただき、その後、Windows、Linux、またはmacOS上で独自のTelegram監視ワークスペースを立ち上げてみてください。](https://phishdestroy.github.io/TgWitness/ja/docs/start/)[### 専用アカウント 収集用に別のTelegramアカウントを用意してください。](https://phishdestroy.github.io/TgWitness/ja/docs/dedicated-account/)[### アカウントを連携する QRコード、電話番号、またはセッションのインポートにより、Telegramを接続してください。ソースを選択し、新しいメッセージがジャーナルに正常に反映されることを確認してください。](https://phishdestroy.github.io/TgWitness/ja/docs/accounts/)[### プロキシを選択してください MTProxyの自動ルーティングを維持するか、独自のプロキシをご利用ください。IPモード、フォールバックルール、および外部リクエストのルーティングを選択してください。](https://phishdestroy.github.io/TgWitness/ja/docs/proxies/)[### エクスポートと検証 キャプチャしたTelegramの履歴をエクスポートし、署名を検証し、ジャーナルを独立した証人が保持しているチェックポイントと比較することができます。](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)[### GitHub Actionsのキャプチャ 一時的な GitHub Runner 上で、Telegram のチャットを 1 件エクスポートします。](https://phishdestroy.github.io/TgWitness/ja/docs/capture/)

## 保存された記録から共有レポートへ

[### すべてのチャットを横断的に調査する チャンネル、グループ、プライベートチャット、ボットを横断して、Telegramの調査をエンドツーエンドで実施します。アカウント全体のキャプチャ、履歴、参加者、リンク、ファイル、タイムライン、および検証済みの証拠を網羅します。](https://phishdestroy.github.io/TgWitness/ja/docs/cases/)[### Case Boardの作成 保存された観察結果、正確なハイライト、アクションスライスをプライベートボードに収集し、チームと議論して、収集結果を提示してください。](https://phishdestroy.github.io/TgWitness/ja/docs/case-board/)[### レポートの作成 レポートデータ、8種類のデザインから1つ、および内容を選択し、プレビューを行った後、HTML、署名付きPDF、または完全な証拠パッケージとしてエクスポートします。](https://phishdestroy.github.io/TgWitness/ja/docs/reports/)[### 共有用コピーを作成してください 受信者が受け取ることができる記録とフィールドを選択し、完成したコピーを確認して、署名済みのマニフェストおよびソースジャーナルの境界を検証してください。](https://phishdestroy.github.io/TgWitness/ja/docs/handover/)[### アカウントグループの管理 グループワークスペースを比較し、ソースを検索し、監視期間を確認し、アカウントごとの例外設定を適用して共有設定を適用します。](https://phishdestroy.github.io/TgWitness/ja/docs/groups/)

## 実際に試して学んでみましょう

[### 証拠の仕組みをご覧ください メッセージの取得からチェックポイントまでの流れを追跡します。サンプルレコードを変更し、そのSHA-256チェーンを再計算して、保持されているチェックポイントが何を検出するかを確認してください。](https://phishdestroy.github.io/TgWitness/ja/docs/concepts/)[### セキュリティを確保してください セッション、鍵、証拠データの保存場所、端末から送信される情報、保護対象の範囲、およびインストールのセキュリティ強化方法についてご確認ください。](https://phishdestroy.github.io/TgWitness/ja/docs/security/)[### Witnessボットの設定 署名済みのジャーナルのチェックポイントを、個別のウィットネス、独自の鍵、および読み取り専用コレクターアクセス権を設定して、Telegramチャンネルに公開できます。](https://phishdestroy.github.io/TgWitness/ja/docs/witness/)
