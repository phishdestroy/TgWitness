এটি চালু রাখুন

কলেক্টরটিকে উপলব্ধ রাখুন এবং রিস্টার্টের পরও এর ডেটা অক্ষত রাখুন।

একটি লঞ্চ পদ্ধতি নির্বাচন করুন

নেটিভ ইনস্টলেশনের জন্য, deploy/ ফোল্ডারে থাকা লঞ্চার এবং সার্ভিস উদাহরণগুলো ব্যবহার করুন। Docker-এর জন্য, Compose সহ Docker ইনস্টল করুন এবং প্রজেক্ট ডিরেক্টরি থেকে চালান:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

ডিফল্ট প্যানেল হোস্টের লুপব্যাক ঠিকানা, পোর্ট 8787-এ শোনা করে। এটিকে স্থানীয়ভাবে বা SSH টানেলের মাধ্যমে খুলুন। প্যানেল আনলক করতে দ্বিতীয় কমান্ড থেকে টোকেন ব্যবহার করুন।

পুরো ডেটা ডিরেক্টরিটি রাখুন

নেটিভ ইনস্টলেশনগুলো data/live ব্যবহার করে। Docker স্থায়ী tgwitness-data ভলিউম ব্যবহার করে। জার্নাল, অ্যাকাউন্ট সেশন, কী এবং অপারেশনাল স্টেট একসঙ্গে সংরক্ষণ করে। একটি স্বাক্ষরিত এক্সপোর্ট প্রমাণ হিসেবে উপযোগী, তবে এটি সম্পূর্ণ ইনস্টলেশনের ব্যাকআপ নয়।

  1. সুসংগত ব্যাকআপ নেওয়ার আগে সংগ্রহ বন্ধ করুন।
  2. পূর্ণ ব্যক্তিগত ডেটা ডিরেক্টরিটি হোস্টের বাইরের সুরক্ষিত স্টোরেজে অনুলিপি করুন।
  3. ব্যাকআপের ওপর নির্ভর করার আগে একটি বিচ্ছিন্ন ইনস্টলেশনে পুনরুদ্ধার পরীক্ষা করুন।

পুনরায় চালু করার পর পরীক্ষা করুন

প্রত্যাশিত কর্মক্ষেত্র এবং কী, টেলিগ্রাম সংযোগ, নির্বাচিত উৎস এবং নতুন বার্তা ক্যাপচার নিশ্চিত করুন। সংরক্ষিত MTProto অবস্থা এবং ক্যাচ-আপ সাহায্য টেলিগ্রাম এখনও ধরে রাখা আপডেটগুলো পুনরুদ্ধার করতে। তারা প্রতিটি মেয়াদোত্তীর্ণ আপডেট বা ক্যাপচারের আগে মুছে ফেলা কোনো সম্পাদনা পুনর্গঠন করতে পারে না।

কন্টেইনারের স্বাস্থ্য মানে ওয়েব সার্ভার সাড়া দিচ্ছে। সংগ্রহ এবং বাহ্যিক প্রকাশের মূল্যায়নের জন্য একটি নিয়ন্ত্রিত বার্তা এবং একটি সাক্ষী যাচাই ব্যবহার করুন।

আপনি যা প্রকাশ করতে চান শুধুমাত্র সেটাই প্রকাশ করুন।

ডিপ্লয়মেন্ট রেফারেন্সে HTTPS উদাহরণ, পার্সিস্টেন্ট-ভলিউম কমান্ড, আপডেট এবং পুনরুদ্ধার ধাপগুলি অন্তর্ভুক্ত রয়েছে। ডিপ্লয়মেন্টের জন্য Docker কমান্ডগুলি প্রদান করা হয়েছে; বর্তমান ভ্যালিডেషన్ রেকর্ডটি প্রকৃতপক্ষে পরীক্ষা করা পরিবেশগুলিকে চিহ্নিত করে।
