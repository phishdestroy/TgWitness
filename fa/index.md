## نسخه‌های S3. بررسی‌های خارجی.

نسخه‌های رمزگذاری‌شده را حفظ کرده و بررسی‌های مستقل اضافه کنید.

به‌طور پیش‌فرض غیرفعال

### همه چیز را به یک فضای ذخیره‌سازی سازگار با S3 کپی کنید

ژورنال، فایل‌ها، نقاط بازرسی و خروجی‌های گفتگو، پیش از ارسال به S3 رمزگذاری می‌شوند.

**تنظیمات ذخیره‌سازی و بازیابی**

رمزگذاری سمت کلاینت

`AES-256-GCM` روی دستگاه شما. ارائه‌دهنده فقط متن رمزشده را می‌بیند.

نسخه‌های زمان‌بندی‌شده یا دستی

همین حالا یا هر 1 تا 1,440 دقیقه کپی کنید، پیشرفت در پنل دیده می‌شود.

قفل اشیاء

روزها و حالت نگهداری را انتخاب کنید، پنل بررسی می‌کند که واقعاً اعمال شده باشد.

بازیابی تأییدشده

کلید را جداگانه نگه دارید. هر جا بازیابی کنید، فایل‌ها فقط پس از تأیید بیرون می‌آیند.

![پنل کامل کپی خارج از محل: کنترل‌های نقطه پایانی، منطقه، باکت، کلیدهای دسترسی، زمان‌بندی، قفل شیء و کلید بازیابی](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

پنل کامل با گزینه‌های پیشرفته بازشده. هیچ‌یک از اطلاعات اعتبارسنجی ذخیره‌سازی نمایش داده نمی‌شوند.

مجله و رسانه‌ها`AES-256-GCM`ذخیره‌سازی سازگار با S3

[پیکربندی S3 و بازیابی یک نسخه](https://phishdestroy.github.io/TgWitness/fa/docs/exports/#s3)[جزئیات تأیید را در بخوانید](https://phishdestroy.github.io/TgWitness/fa/docs/reference/evidence/#off-site-copy-and-restore-s3)

**کلید بازیابی** جداگانه نگه دارید، بدون آن کپی خواندنی نیست.

### اخطاریه‌ها · اپرایز

مشکلات، تغییرات گفتگو و خلاصه روزانه به پیام‌رسان‌ها، ایمیل یا webhook خودتان.

 [مقاصد اعلان را پیکربندی کنید](https://phishdestroy.github.io/TgWitness/fa/docs/reference/operations/#notifications)

### برچسب‌های زمانی خارجی

هش‌های نقطه‌کنترل زمانی را با RFC 3161 و OpenTimestamps ثبت کنید.

**نتیجه را دنبال کنید** پاسخ TSA را بررسی کنید یا رسید OpenTimestamps را به اثبات Bitcoin ارتقا دهید.

 [مدارک مهر زمانی را بررسی کنید](https://phishdestroy.github.io/TgWitness/fa/docs/reference/timestamp/)

### شاهد مستقل

یک میزبان جداگانه مشاهدات امضا شده را نگهداری می‌کند و می‌تواند منتشر کند `TGW1` نقاط کنترل را ذخیره می‌کند.

**مرجع را جدا کنید** روی میزبان دیگری با کلید و ژورنال خودش اجرا کنید.

 [شاهد را راه‌اندازی کنید](https://phishdestroy.github.io/TgWitness/fa/docs/witness/)

### بازیابی و شکاف‌های قابل مشاهده

پس از راه‌اندازی مجدد از سر بگیرید. بازبینی مجدد و `coverage.json` نمایش پیام‌های بازیابی‌شده و فواصل زمانی.

**بازه را مرور کنید** پیام‌های بازیابی‌شده و شکاف‌های ثبت‌شده کنار هم.

### منبع را دریافت کنید.

[فایل ZIP منبع را دانلود](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip) و از حالت فشرده خارج کنید، یا مخزن را کلون کنید:

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

به Python 3.11 یا بالاتر نیاز دارد. در Windows راه‌انداز پیشنهاد نصب آن را می‌دهد.

[مرور نسخه‌های منتشرشده](https://github.com/phishdestroy/TgWitness/releases)

مرحلهٔ ۰۲

### انتخاب کنید چگونه اجرا شود.

روی `Start.cmd` دوبار کلیک کنید، یا در PowerShell اجرا کنید:

```
.\Start.cmd
```

فقط در حال کاوش هستید؟ برای یک دمو جداگانه روی `scripts\Demo.cmd` دوبار کلیک کنید. نیازی به ورود به تلگرام نیست.

با پایتون ۳.۱۱+ و `venv` در دسترس:

```
sh start.sh
```

برای باز کردن مجلهٔ فرضی، دستور `sh start.sh --demo` را اجرا کنید.

با اجرای Docker و نصب Compose 2.20+:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

دستور دوم توکن پنل خصوصی شما را نمایش می‌دهد. آن را روی دستگاه خود نگه دارید.

پس از راه‌اندازی، [127.0.0.1:8787](http://127.0.0.1:8787) را باز کنید.

در نصب از سورس، توکن در `data/live/panel-token.txt` است. جفت API خودتان از [my.telegram.org](https://my.telegram.org) اختیاری است. [راهنمای کامل راه‌اندازی ↗](https://phishdestroy.github.io/TgWitness/fa/docs/reference/quickstart/)

## قبل از شروع.

**آیا این صفحه به تلگرام متصل است؟**

نه. این یک صفحه ایستا با نمونه‌های جعلی است. برنامه روی دستگاه خودتان اجرا می‌شود و همان‌جا وارد می‌شوید.

**آیا می‌تواند پیام‌هایی را که قبل از ضبط حذف شده‌اند بازیابی کند؟**

نه. چیزی را نگه می‌دارد که حساب شما هنگام اجرا دید. اسنپ‌شات بعدی نمی‌تواند ویرایش‌های ازدست‌رفته یا پیام‌های حذف‌شده را بازسازی کند.

**آیا کل دفترچهٔ یادداشت من رمزگذاری شده است؟**

نشست‌ها و کلیدها بله. پیام‌ها و فایل‌ها نه، از رمزگذاری دیسک استفاده کنید. خروجی‌ها می‌توانند رمز AES-256 بگیرند.

**آیا این با تلگرام مرتبط است؟**

نه. این یک پروژه مستقل با مجوز MIT است که روی Telethon ساخته شده. با حساب‌های خودتان وارد می‌شوید.
