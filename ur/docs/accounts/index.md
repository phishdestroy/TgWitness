# اکاؤنٹ منسلک کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/accounts/

ایک ورک اسپیس میں ایک اکاؤنٹ، اس کا جرنل اور اس کی دستخطی کلید شامل ہوتی ہے۔

## سائن ان کرنے کا طریقہ منتخب کریں

**اکاؤنٹس** کھولیں، ایک ورک اسپیس شامل کریں اور اس کی کنکشن سیٹنگز کھولیں۔ مشاہدے کے لیے ایک مخصوص اکاؤنٹ استعمال کریں۔

- **QR کوڈ:** اسے ٹیلیگرام کی ڈیوائس سیٹنگز سے اسکین کریں اور نئے لاگ ان کی تصدیق کریں۔
- **فون نمبر:** نمبر درج کریں، Telegram کی جانب سے بھیجا گیا کوڈ اور اگر دو مرحلہ جاتی تصدیق فعال ہو تو اپنا پاس ورڈ درج کریں۔
- **سیشن امپورٹ:** ایک سپورٹڈ سیشن یا آپ کے زیرِ ملکیت ٹیلیگرام ڈیسک ٹاپ ڈیٹا امپورٹ کریں۔

بلٹ ان API پروفائل منتخب کریں یا اپنا API ID اور ہیش درج کریں۔ ایک API پروفائل کلائنٹ کی شناخت کرتا ہے؛ یہ کسی اکاؤنٹ میں سائن ان نہیں کرتا اور نہ ہی کنکشن کو گمنام بناتا ہے۔

**کیا پہلے پروکسی کی ضرورت ہے؟**

آپ سائن ان کرنے سے پہلے [کنکشن کا راستہ منتخب اور آزما](https://phishdestroy.github.io/TgWitness/ur/docs/proxies/) سکتے ہیں۔ ہر اکاؤنٹ کا اپنا راستہ ہوتا ہے۔

## مشاہدہ کرنے کے لیے انتخاب کریں

1. ماخذ فہرست کھولیں اور مطلوبہ چیٹس، گروپس یا چینلز منتخب کریں۔
2. مشاہدہ شروع کرنے سے پہلے میڈیا سمیت مجموعہ کی ترتیبات کا جائزہ لیں۔
3. کلیکٹر کو شروع کریں اور اس کے کنکشن اور حالیہ سرگرمی کی جانچ کریں۔

اکاؤنٹ کو ماخذ تک رسائی حاصل ہونی چاہیے۔ مختلف کردار مختلف واقعات دیکھ سکتے ہیں؛ جرنل اس بات کی عکاسی کرتا ہے کہ اس اکاؤنٹ کو کیا موصول ہوا۔

پورے اکاؤنٹ پر محیط کیس کے لیے **Sources → Observation scope → Investigation mode** استعمال کریں، ترتیبات کا جائزہ لیں اور **Save scope** دبائیں۔ [مکمل تفتیشی رہنمائی](https://phishdestroy.github.io/TgWitness/ur/docs/cases/) تمام قابلِ دید چیٹ اقسام، پرانی تاریخ، صارفین کے پروفائلز، کراس چیٹ حوالہ جات اور شواہد کی منتقلی کا احاطہ کرتی ہے۔

## پورے راستے کی جانچ کریں

ایک ٹیسٹ گروپ جس پر آپ کا کنٹرول ہو، اس میں دوسرے اکاؤنٹ سے ایک منفرد پیغام بھیجیں، اسے ترمیم کریں اور حذف کر دیں۔ جرنل میں ان تینوں واقعات کی تصدیق کریں، پھر ریکارڈ کو [ایکسپورٹ کر کے اس کی توثیق کریں](https://phishdestroy.github.io/TgWitness/ur/docs/exports/)۔

منسلک حیثیت کنکشن کی تصدیق کرتی ہے۔ ایک ریکارڈ شدہ ٹیسٹ پیغام اس بات کی تصدیق کرتا ہے کہ ایک مخصوص واقعہ اس ورک اسپیس تک پہنچا ہے۔

## ایک اور اکاؤنٹ شامل کریں

**اکاؤنٹس** میں ایک اور ورک اسپیس بنائیں اور سیٹ اپ دہرائیں۔ ہر اکاؤنٹ کی سائننگ کی فنگر پرنٹ محفوظ رکھیں تاکہ آپ بعد میں اس کے ایکسپورٹس کی شناخت کر سکیں۔
