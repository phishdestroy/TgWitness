# کیس بورڈ بنائیں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/case-board/

محفوظ پیغامات کو ایسے کیس میں بدلیں جس پر آپ کی ٹیم مل کر کام کرے۔

بک مارکس، لفظ بہ لفظ اقتباسات، سلائسز اور بحث، ہر ایک اپنے ذریعے سے جڑا۔ ہر تبدیلی ایک دستخط شدہ نظرثانی ہے۔

## پیغام سے کیس کارڈ تک

1. **تفتیش ← Case Board** (معیاری یا ماہر موڈ)۔ کیس کے لیے کلیکشن بنائیں۔
2. **جرنل** یا کسی چیٹ میں **بورڈ پر** (یا **B**) دبائیں۔ کارڈ ان باکس میں آتا ہے، اسے عنوان دیں اور منتقل کریں۔
3. پیغام میں متن منتخب کریں، **ہائی لائٹ ← بورڈ** لفظ بہ لفظ اقتباس اور ورژن رکھتا ہے۔ نوٹ کریں کہ یہ کیوں اہم ہے۔
4. بحث کریں، اسٹیٹس طے کریں، جب چاہیں ذریعے پر واپس جائیں۔ **پریزنٹیشن** ٹیم کو قدم بہ قدم دکھاتا ہے۔

### ایک تبدیل شدہ ادائیگی کے لنک کی پیروی کریں

مصنوعی مثال · مقامی وضاحت

1. **کیپچر کریں۔** محفوظ شدہ مشاہدہ #142 اور اس کے پیغام کے ورژن کو کھولیں۔
2. **بُک مارک۔** اقتباس، ماخذ کا حوالہ اور اپنا سوال ایک کارڈ پر رکھیں۔
3. **نظرثانی۔** ایک ٹیم تبصرہ شامل کریں اور کارڈ کو نظرثانی میں منتقل کریں۔
4. **موجود ہے۔** کلیک کرکے مجموعے کو دیکھیں اور حوالہ شدہ ماخذ کے سیاق و سباق کو کھولیں۔

#### محفوظ شدہ مشاہدہ #142

"نیا ادائیگی کا لنک استعمال کریں۔"

آپریشنز چیٹ · پیغام 38 · مشاہدہ 09:12 UTC

#### کارڈ: تبدیل شدہ منزل

> نیا ادائیگی کا لنک استعمال کریں۔

سوال: کون سا منزل پچھلے ورژن میں ظاہر ہوا تھا؟

#### ٹیم کا جائزہ

تجزیہ کار: مشاہدہ #101 کے ساتھ موازنہ کریں۔

حالت: جائزہ · نظر ثانی برقرار رکھی گئی

#### ماخذ کا سیاق و سباق

کارڈ → محفوظ شدہ ورژن → سابقہ مشاہدہ

تشریح اور ٹیلیگرام مشاہدہ الگ الگ قابلِ شناخت رہتے ہیں۔

## ایک مرتبہ مفید حد محفوظ کریں

دو پیغامات پر Shift-کلک کر کے **درمیان سلائس**، **وقت سے سلائس** استعمال کریں، یا موجودہ جرنل فلٹرز محفوظ کریں۔ **بک مارک کے بعد شامل ریکارڈز دکھائیں** بعد میں آنے والی چیزیں دکھاتا ہے۔

وقت کی سلائسز مشاہدے کا وقت استعمال کرتی ہیں؛ پیغام ID سلائسز ان پیغامات کی تبدیلیوں کے ساتھ چلتی ہیں۔

## ہر ساتھی کو مناسب کردار دیں

**جائزہ کار** پڑھتا ہے، **تجزیہ کار** کارڈز اور تبصرے شامل کرتا ہے، **آپریٹر** کلیکشنز اور فیصلے بھی سنبھالتا ہے۔ چیٹ کی اجازتیں کارڈز پر بھی لاگو ہوتی ہیں۔

## کام کو ایک قابلِ ترسیل دستاویز میں منتقل کریں۔

سلائسز دستخط شدہ JSON یا CSV کے طور پر ایکسپورٹ ہوتی ہیں۔ رپورٹس میں بک مارکس، سلائسز اور تبصرے شامل ہو سکتے ہیں، یہ [Report studio](https://phishdestroy.github.io/TgWitness/ur/docs/reports/) میں سیٹ کریں۔ محدود وصول کنندہ کے لیے [حوالگی](https://phishdestroy.github.io/TgWitness/ur/docs/handover/) استعمال کریں۔
