שתף מקרה

שתפו את המקרה שמישהו זקוק לו. שמרו על השליטה בשאר.

הענק גישה למישהו

  1. היכנס כמנהל מערכת ופתח את "Access".
  2. ציינו את פרטי הגישה ובחרו את סביבות העבודה והצ'אטים.
  3. שמור את האפשרות "הצגה" עבור בודק. הוסף את האפשרות "ייצוא" אם עליהם להוריד את הרישומים.
  4. הגדר הגבלות, ולאחר מכן לחץ על "צור גישה".
  5. העתיקו את האסימון המוצג פעם אחת. שלחו אותו באופן פרטי יחד עם כתובת הפאנל.
  6. בדקו את תצוגת התוכן המותרת בחלון דפדפן נפרד לפני שתעבירו אותו.

מפעילסביבות עבודה שלמות שנבחרו; מקורות ואוסףנהל את הנתונים שנאספו והפעל או עצור את תוכנות האיסוף.

אלה הן תצורות שאתם בוחרים, ולא תפקידים קבועים. הגדרות ברמת החשבון וייצוא מלא של היומן נשארים סגורים לגישה המוגבלת לצ'אט, גם כאשר הרשאה אחרת מופעלת. הגישה לכל סביבת העבודה כוללת חשבונות עתידיים.

ניתן לשנות את דעתך בכל עת

ערוך את הגישה כדי לשנות את הפעולות שניתן לבצע בבקשות עתידיות. סיים הפעלה אחת או בטל את הגישה כולה כדי לסיים את כל ההפעלות. לא ניתן לבטל קבצים שכבר הורדו. סיום הפעלת לוח הבקרה אינו עוצר את האיסוף.

מגבלות על מספר הפעלות וכתובות IP

הגבל את מספר ההפעלות המקבילות והכניסות המוצלחות, קבע תאריך סיום מוחלט, אפשר כתובות IP או תת-רשתות, או קשר את הגישה לכתובת הכניסה הראשונה. תוקף ההפעלה נמדד על פי חוסר פעילות; סקר בפאנל פתוח נחשב כפעילות. בדוק את כתובת הלקוח המוצגת על ידי היישום כאשר הוא פועל מאחורי פרוקסי או מנהרה.

המפתח הראשי ויומן הפעילות

המנהל מחזיק באסימון של לוח הבקרה הראשי. גישה שהוענקה אינה מאפשרת לנהל את הגישה של משתמשים אחרים או לפתוח את קונסולת המנהל. הקונסולה מציגה את פעילות התהליכים הנוכחית בכל סביבות העבודה; רשומות הגישה החתומות שומרות אירועי הענקת הרשאות ואירועי הפעלה ללא צורך באסימונים. סביבות העבודה חולקות את תהליך המארח ואינן מבודדות את הנתונים ממנהל השרת.

יש להשתמש בהפניה המלאה לכל שבעת ההרשאות, לכללי ההפעלה ולתחום הסמכות של המנהל.
