# Передача доказательств Telegram с ограничением данных

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/handover/

Делитесь только нужным, оригинал остаётся нетронутым.

Передача — это отдельная подписанная выписка: выберите чаты и людей, скройте личности или текст, отберите файлы и заметки команды. Манифест фиксирует, что оставлено, сокращено и исключено.

## Подготовьте выдержку для получателя

1. **Экспорт → Выписка для передачи**: укажите цель, выберите чаты и период, **Загрузить людей выбранных чатов**, если нужны конкретные люди.
2. Все остальные: псевдонимы, исключение или как записано. Текст и файлы включаются отдельно, телефоны и почту можно скрыть.
3. Case Board: ничего, закладки и срезы или карточки с комментариями. Имена команды можно заменить псевдонимами.
4. **Скачать выписку для передачи**, откройте, проверьте, просмотрите перед отправкой.

### Один оригинал, одна копия для обмена

Синтетический пример · иллюстрация носит исключительно ознакомительный характер

1. **Выберите.** Включите чат по делу и укажите, о каком лице идет речь в выдержке.
2. **Минимизировать.** Выберите, как другой участник будет отображаться в копии, предназначенной для совместного доступа.
3. **Проверьте.** Откройте сгенерированный отчет и записи из архива перед отправкой.
4. **Поделитесь.** Предоставьте проверенную копию и отдельно сообщите её проверенный отпечаток.

#### Исходные замечания

Нора · пользователь 71002

«Я получил ссылку на отредактированный вариант».

Источник журнала сохраняет эту запись.

#### Копия для получателя

Показать так, как записано: Нора · пользователь 71002 · «Я получила исправленную ссылку».

Псевдоним: P01 · «Я получил исправленную ссылку».

Опустить: сообщение этого участника не включается в текст.

#### Ознакомьтесь с фактическими файлами

Ознакомьтесь с файлами report.html и records.jsonl.

Проверьте идентификационные данные, текст, вложения и дополнительные комментарии команды.

#### Подписанный отрывок

Выбор + хеши файлов + подписанный манифест

Отдельный пакет, привязанный к границе исходного журнала

## Используйте элементы управления в комплексе

| Контроль | Влияние на текст |
| --- | --- |
| Люди | Выбранные люди остаются названными, остальные получают псевдонимы или исключаются. |
| Текст | Весь текст, только текст выбранных людей и вашего аккаунта или никакого. |
| Файлы | Файлы выбранных людей и вашего аккаунта, все показанные файлы или никаких. |
| Доска дел | Ничего, закладки и срезы или карточки с обсуждением. |

Прочитайте и сам текст, и файлы: псевдоним не убирает имена, написанные внутри сообщения или вложения. Если выбранного файла нет, восстановите его или исключите вложения.

## Текст должен поддаваться независимой проверке

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

Оригинальный архив и контрольные точки храните у себя. Получатель может проверить свою копию, не получая всё пространство. Оформление: [Report studio](https://phishdestroy.github.io/TgWitness/ru/docs/reports/). Доверенные ссылки: [проверка экспорта](https://phishdestroy.github.io/TgWitness/ru/docs/exports/).
