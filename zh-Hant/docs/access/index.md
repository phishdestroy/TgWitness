# Telegram · 分享案例

Canonical page: https://phishdestroy.github.io/TgWitness/zh-Hant/docs/access/

分享他人所需的案例。其餘部分則由您掌控。

01**選擇證據**

整個工作區或單一聊天室。

02**選擇操作**

檢視、匯出，或只限他們需要的操作。

03**設定限制**

個人權杖，可依需要設定到期時間、工作階段限制和 IP 規則。

收集範圍決定了記錄的內容；存取範圍則決定了使用者能查看和執行的操作。

## 授予某人存取權限

1. 以管理員身分開啟**存取**。
2. 命名，選擇工作區和聊天室。
3. 審閱者只需要**檢視**。若要下載請加上**匯出**。
4. 設定權限限制後，請按下「**建立存取權限」**。
5. 複製權杖（只顯示一次），連同面板網址私下傳送。
6. 先在另一個瀏覽器工作階段中檢查他們會看到什麼。

## 從他們需要完成的工作開始

| 人物 | 存取 | 結果 |
| --- | --- | --- |
| 審閱者 | 精選對話；僅限檢視 | 閱讀聊天室，不能變更任何內容。 |
| 分析師 | 精選對話；檢視與匯出 | 閱讀並下載案件所需內容。 |
| 操作員 | 精選完整工作區；來源與蒐集 | 決定觀察哪些內容，啟動和停止收集器。 |

這些只是範例，不是固定角色。限於聊天室的存取權永遠不會取得帳戶設定或完整日誌匯出。所有工作區的存取權包括之後新增的帳戶。

## 您可隨時改變主意

可隨時編輯存取權，從下一次請求起生效。可結束單一工作階段或全部撤銷。已下載的檔案無法收回。收集會繼續執行。

**會話與 IP 限制**

限制並行工作階段和登入次數，設定結束日期，允許特定 IP 或子網路，或鎖定為首次登入的 IP。到期時間依閒置時間計算，開著的面板算作活動。在代理之後時，請檢查應用程式看到的是哪個用戶端 IP。

**主金鑰與活動日誌**

主權杖留在管理員手上。發出的存取權不能管理他人的存取，也不能開啟管理主控台。存取變更和工作階段會簽名寫入日誌，不含權杖。伺服器管理員仍然看得到一切。

全部七項權限和工作階段規則：[存取參考](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/reference/access/)。
