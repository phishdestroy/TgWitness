# ابدأ في غضون دقائق

Canonical page: https://phishdestroy.github.io/TgWitness/ar/docs/start/

تجوّل في العرض التوضيحي أولاً، ثم اربط حسابك.

## تصفح الموقع دون الحاجة إلى إنشاء حساب

احصل على المشروع، وجهّز **Python 3.11 أو أحدث**، وشغّل العرض التوضيحي. يتولى المشغّل الباقي.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

تُفتح في المتصفح مساحة عمل برسائل مختلقة. افتح محادثة، وقارن تعديلاً، وألقِ نظرة على تصدير. لا علاقة لـ Telegram بذلك.

![عرض محادثة TgWitness مع أمثلة على الرسائل](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

نموذج لمساحة العمل. يبدأ سجل الأدلة الخاص بك بشكل منفصل.

## ابدأ مساحة العمل الخاصة بك

أغلق العرض التوضيحي، ثم:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

افتح العنوان الذي يعرضه المشغّل والصق **رمز الوصول إلى اللوحة** من الملف الذي يذكره. هذا الرمز لـ TgWitness وليس لـ Telegram.

## التقط رسالتك الأولى

1. [قم بربط حساب Telegram مخصص.](https://phishdestroy.github.io/TgWitness/ar/docs/accounts/)
2. اختر مجموعة أو قناة وابدأ المراقبة.
3. أرسل رسالة في مجموعة الاختبار وشاهدها تظهر في السجل.

لتثبيت الخادم، اتبع إرشادات [«Keep it running](https://phishdestroy.github.io/TgWitness/ar/docs/server/)».
