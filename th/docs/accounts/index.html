เอกสาร / 02

เชื่อมต่อบัญชี

พื้นที่ทำงานหนึ่งจะเก็บบัญชีหนึ่ง พร้อมทั้งบันทึกและกุญแจลงนามของบัญชีนั้น

เลือกวิธีลงชื่อเข้าใช้

เปิดบัญชี เพิ่มพื้นที่ทำงาน และเปิดการตั้งค่าการเชื่อมต่อ ใช้บัญชีเฉพาะสำหรับการสังเกตการณ์

  • รหัส QR: สแกนจากตั้งค่าอุปกรณ์ของ Telegram และยืนยันการเข้าสู่ระบบใหม่
  • หมายเลขโทรศัพท์: กรอกหมายเลขโทรศัพท์ รหัสที่ Telegram ส่งมา และรหัสผ่านยืนยันสองขั้นตอน (หากเปิดใช้งาน)
  • การนำเข้าเซสชัน: นำเข้าเซสชันที่ได้รับการสนับสนุนหรือข้อมูล Telegram Desktop ที่เป็นของคุณ

เลือกโปรไฟล์ API ที่มี sẵn หรือป้อน API ID และแฮชของคุณเอง โปรไฟล์ API ใช้เพื่อระบุตัวลูกค้าเท่านั้น; มันไม่ใช้เพื่อลงชื่อเข้าใช้บัญชีหรือทำให้การเชื่อมต่อเป็นแบบไม่ระบุตัวตน

ต้องการใช้พร็อกซีก่อนหรือไม่?

คุณสามารถเลือกและทดสอบเส้นทางการเชื่อมต่อก่อนที่จะลงชื่อเข้าใช้ได้ แต่ละบัญชีมีเส้นทางการเชื่อมต่อของตัวเอง

เลือกสิ่งที่ต้องการติดตาม

  1. เปิดรายชื่อแหล่งข้อมูลและเลือกการสนทนา กลุ่ม หรือช่องที่คุณต้องการ
  2. ตรวจสอบการตั้งค่าการเก็บข้อมูล รวมถึงสื่อ ก่อนเริ่มการสังเกตการณ์
  3. เริ่มทำงานของตัวเก็บข้อมูล และตรวจสอบการเชื่อมต่อและกิจกรรมล่าสุด

บัญชีดังกล่าวต้องสามารถเข้าถึงแหล่งข้อมูลได้ ผู้ใช้ในบทบาทต่าง ๆ สามารถเห็นเหตุการณ์ต่าง ๆ ได้; บันทึกดังกล่าวสะท้อนสิ่งที่บัญชีนั้นได้รับ

สำหรับกรณีที่ครอบคลุมบัญชีทั้งหมด ให้ใช้ Sources → Observation scope → Investigation mode ตรวจสอบการตั้งค่าและกด Save scope ขั้นตอนการสอบสวนแบบครบวงจรนี้ครอบคลุมทุกประเภทการสนทนาที่มองเห็นได้ ประวัติการสนทนาเก่า โปรไฟล์ผู้ใช้ การอ้างอิงระหว่างการสนทนา และการส่งต่อหลักฐาน

ตรวจสอบเส้นทางทั้งหมด

ในกลุ่มทดสอบที่คุณควบคุม ให้ส่งข้อความที่ไม่ซ้ำกันจากบัญชีอื่น แก้ไขข้อความนั้น และลบข้อความนั้นออก ตรวจสอบให้แน่ใจว่าทั้งสามเหตุการณ์ปรากฏในบันทึก จากนั้นส่งออกและตรวจสอบความถูกต้องของบันทึก

สถานะ "เชื่อมต่อ" ยืนยันว่ามีการเชื่อมต่อแล้ว ข้อความทดสอบที่บันทึกไว้ยืนยันว่าเหตุการณ์เฉพาะนั้นได้ส่งถึงพื้นที่ทำงานนี้แล้ว

เพิ่มบัญชีอีกบัญชี

สร้างพื้นที่ทำงานอีกแห่งในส่วน "บัญชี" และทำตามขั้นตอนการตั้งค่าซ้ำอีกครั้ง เก็บลายนิ้วมือของกุญแจลงนามของแต่ละบัญชีไว้ เพื่อที่คุณจะสามารถระบุไฟล์ที่ส่งออกได้ในภายหลัง

อ้างอิงเต็ม →ขั้นตอนต่อไปส่งออกและตรวจสอบ →

คู่มือเหล่านี้อธิบายการนำไปใช้ในปัจจุบัน ผลการตรวจสอบความถูกต้องและช่องว่างที่ยังเหลืออยู่ได้รับการบันทึกไว้อย่างแยกต่างหาก สิ่งที่ได้รับการทดสอบแล้ว →
