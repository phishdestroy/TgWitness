# แหล่งอ้างอิงครบถ้วน

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/reference/

เอกสารทุกชิ้นของโครงการ ซึ่งแสดงไว้ที่นี่พร้อมด้วยแผนภาพ คู่มือเป็นทางลัด ส่วนหน้าเว็บเหล่านี้เก็บรายละเอียดทั้งหมด

## การตั้งค่า

[### เริ่มต้นอย่างรวดเร็ว ทุกวิธีในการติดตั้งและเปิดใช้งาน TgWitness: แพ็กเกจ Windows, Python, Docker และเดโมจำลอง พร้อมขั้นตอนตรวจสอบเบื้องต้น](https://phishdestroy.github.io/TgWitness/th/docs/reference/quickstart/)[### รูปแบบบัญชีและเซสชัน ลงชื่อเข้าใช้ผ่านโทรศัพท์มือถือ รหัส QR หรือกุญแจการยืนยันตัวตน นำเข้าเซสชันจาก Telethon Pyrogram หรือ Telegram Desktop และจัดการหลายบัญชีได้](https://phishdestroy.github.io/TgWitness/th/docs/reference/accounts/)[### การเข้าถึงและสิทธิ์ กำหนดสิทธิ์การเข้าถึงบัญชีและห้องสนทนา, เลือกสิทธิ์การเข้าถึง, จำกัดจำนวนเซสชันและที่อยู่ IP, และยกเลิกสิทธิ์การเข้าถึง](https://phishdestroy.github.io/TgWitness/th/docs/reference/access/)[### การเชื่อมต่อ, พร็อกซี และการคุ้มครองข้อมูล การยืนยันตัวตน, กลุ่มพร็อกซีอัตโนมัติ, โหมด IP, นโยบายสำรอง, คำขอจากภายนอก และการจัดเก็บข้อมูลลับ](https://phishdestroy.github.io/TgWitness/th/docs/reference/connection/)[### การติดตั้ง เรียกใช้ TgWitness ในรูปแบบบริการบน Windows, Linux, macOS หรือ Docker ผ่าน HTTPS พร้อมด้วยระบบสำรองข้อมูลและการอัปเดต](https://phishdestroy.github.io/TgWitness/th/docs/reference/deployment/)

## Collect

[### วิธีการเก็บรวบรวมข้อมูล ขอบเขตการสังเกตการณ์, การอัปเดตแบบเรียลไทม์, การตรวจสอบซ้ำ, ไฟล์แนบ, การดำเนินการของผู้ใช้เอง และความหมายของช่องว่าง (gap) — บันทึกอย่างละเอียดทีละรายการ](https://phishdestroy.github.io/TgWitness/th/docs/reference/collection/)[### โหลดประวัติแหล่งที่มา โหลดข้อความที่ผ่านมาจากแหล่งข้อมูลที่เปิดใช้งาน หยุดชั่วคราวและต่อใหม่ และตรวจสอบรายงานความคืบหน้าที่ลงนามแล้ว](https://phishdestroy.github.io/TgWitness/th/docs/reference/history/)[### ขั้นตอนการทำงานและการดำเนินการ การดำเนินงานประจำวันของแผงควบคุม: โหมดการทำงาน, หมวดหมู่การติดตาม, พารามิเตอร์, การแจ้งเตือน, การส่งออกข้อมูล, การสำรองข้อมูล และขีดความสามารถ](https://phishdestroy.github.io/TgWitness/th/docs/reference/operations/)[### โหมดการสืบสวน การสืบสวนบัญชีทั้งหมด รวมถึงช่อง กลุ่ม การสนทนาส่วนตัว และบอต ตั้งแต่ขั้นตอนการกำหนดขอบเขตไปจนถึงการจัดทำชุดหลักฐานที่ได้รับการยืนยัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/investigation/)[### คุณสมบัติและข้อจำกัด สิ่งที่ TgWitness ได้พัฒนาไว้ในปัจจุบัน สิ่งที่แพลตฟอร์ม Telegram จำกัด และสิ่งที่ยังต้องพัฒนาต่อไปในอนาคต](https://phishdestroy.github.io/TgWitness/th/docs/reference/features/)

## การเก็บรักษาข้อมูลและการบูรณาการ

[### การวิเคราะห์ข้อมูลในคลัง ค้นหาข้อความที่บันทึกไว้ ตรวจสอบข้อมูลที่ AI ให้มา และเก็บรายงานวิเคราะห์พร้อมแหล่งอ้างอิง](https://phishdestroy.github.io/TgWitness/th/docs/reference/analysis/)[### MCP แบบอ่านเท่านั้น เชื่อมต่อไคลเอนต์ MCP กับพื้นที่ทำงานและห้องสนทนาที่เลือกไว้ โดยให้สิทธิ์การเข้าถึงที่มีระยะเวลาจำกัดและสามารถเพิกถอนได้](https://phishdestroy.github.io/TgWitness/th/docs/reference/mcp/)[### OCR และแปลงข้อความเป็นข้อความแบบท้องถิ่น ระบุภาพและเสียงที่บันทึกได้ด้วย local worker; รักษาข้อความที่สร้างขึ้นให้เชื่อมโยงกับไฟล์ต้นฉบับ](https://phishdestroy.github.io/TgWitness/th/docs/reference/media-analysis/)[### webhooks ส่งออก ส่งเหตุการณ์ที่ระบุขอบเขตไปยังผู้รับ HTTPS พร้อมลายเซ็น HMAC การลองส่งซ้ำ และสถานะการส่ง](https://phishdestroy.github.io/TgWitness/th/docs/reference/webhooks/)

## หลักฐาน

[### วิธีการทำงานของหลักฐาน อธิบายเกี่ยวกับโซ่แฮช (hash chain), ลายเซ็น (signatures), จุดตรวจสอบ (checkpoints) และพยาน (witnesses) ด้วยสูตรที่ผู้ตรวจสอบใช้จริง](https://phishdestroy.github.io/TgWitness/th/docs/reference/how-it-works/)[### รูปแบบหลักฐาน เนื้อหาของไฟล์ ZIP ที่ลงนาม, ประเภทบันทึก, ใบยืนยันการดำเนินการ, โปรไฟล์ผู้ใช้, สำเนาที่เก็บไว้นอกระบบ และการตรวจสอบแบบออฟไลน์](https://phishdestroy.github.io/TgWitness/th/docs/reference/evidence/)[### พยานอิสระ เรียกใช้ witness ด้วยกุญแจและบอทของตัวเอง เผยแพร่จุดตรวจสอบที่ลงนามแล้วไปยังช่อง และตรวจสอบการส่งออกข้อมูลกับจุดตรวจสอบดังกล่าว](https://phishdestroy.github.io/TgWitness/th/docs/reference/witness/)[### ข้อมูลเวลา การประทับเวลาตาม RFC 3161 สำหรับจุดตรวจสอบที่ลงนาม: สิ่งที่ส่งไปยังหน่วยงานที่มีอำนาจ และวิธีการตรวจสอบความถูกต้องของคำตอบ](https://phishdestroy.github.io/TgWitness/th/docs/reference/timestamp/)

## ความปลอดภัยและโครงการ

[### ความปลอดภัยและการจัดการข้อมูล โมเดลภัยคุกคาม, โมเดลการเข้าถึง, ข้อมูลลับที่เก็บไว้, ความเสี่ยงในการเปิดเผยผ่านเครือข่าย, การนำเข้าเซสชัน และวิธีการรายงานช่องโหว่](https://phishdestroy.github.io/TgWitness/th/docs/reference/security/)[### สถาปัตยกรรม ส่วนประกอบของระบบ ได้แก่ collector, panel, journal, workers และ witness รวมถึงวิธีการที่ข้อมูลถูกส่งผ่านระหว่างส่วนต่าง ๆ](https://phishdestroy.github.io/TgWitness/th/docs/reference/architecture/)[### สิ่งที่ได้รับการทดสอบแล้ว การทดสอบ Telegram แบบเรียลไทม์ การตรวจสอบอัตโนมัติ การตรวจสอบผ่านเบราว์เซอร์ และสิ่งที่ยังไม่ได้รับการยืนยัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/verification/)[### ประกาศเรื่องใบอนุญาตและความไม่เข้ากันทางสถาปัตยกรรม TgWitness ได้รับใบอนุญาต MIT สำหรับทุกคน และเหตุผลที่มันไม่เข้ากันทางสถาปัตยกรรมกับกระบวนการทำงานของ Taylor Wessing](https://phishdestroy.github.io/TgWitness/th/docs/reference/license/)[### ประกาศความไม่เข้ากันได้ของผู้ดำเนินการ ประกาศของผู้ดำเนินการของเราเกี่ยวกับ Taylor Wessing และบันทึกแหล่งที่มาของมัน](https://phishdestroy.github.io/TgWitness/th/docs/reference/notice/)[### บันทึกการเปลี่ยนแปลง ทุกการเปลี่ยนแปลงตามเวอร์ชัน รวมถึงการเปลี่ยนแปลงที่ยังไม่ได้รับการปล่อยออก](https://phishdestroy.github.io/TgWitness/th/docs/reference/changelog/)
