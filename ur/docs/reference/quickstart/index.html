تیزی سے آغاز

TgWitness کو انسٹال اور لانچ کرنے کے تمام طریقے: ونڈوز پیکیج، پائتھن، ڈاکر اور مصنوعی ڈیمو، ابتدائی جانچ کے ساتھ۔

انگریزی · روسی · یوکرینی · اسپینش · پرتگالی (برازیل) · ترکی · عربی · فارسی · اردو · ہندی · انڈونیشیائی زبان · ویتنام زبان · سادہ چینی

TgWitness ایک خود مختار ایپلیکیشن ہے جو آپ کے اکاؤنٹس تک رسائی والے ٹیلیگرام گروپس اور چینلز کا مشاہدہ کرتی ہے۔ یہ مقامی طور پر اپنی ڈیٹا ڈائریکٹری کے ساتھ چلتی ہے۔

پہلی بار آئے ہیں؟ اکاؤنٹ منسلک کرنے سے پہلے ڈیمو دیکھیں۔ پراکسیز، ویٹنسز، ایکسپورٹس یا سرور سیٹ اپ کے لیے ایک گائیڈ منتخب کریں۔

انسٹال کریں اور شروع کریں#

ایک طریقہ منتخب کریں۔ پورٹیبل ڈاؤن لوڈز ریلیز بلڈ شائع ہونے کے بعد دستیاب ہو جاتے ہیں:

میزبان کچھ بھی انسٹال نہیں ماخذ سے: پائتھن 3.11+ Docker: Engine/Desktop Compose 2.20+ کے ساتھ
ونڈوز TgWitness-<version>-windows-amd64-portable.zip کو GitHub Releases سے نکالیں، TgWitness.cmd پر ڈبل کلک کریں۔ Start.cmd پر ڈبل کلک کریں scripts\Docker.cmd پر ڈبل کلک کریں
لینکس / میک او ایس — sh start.sh sh scripts/docker-start.sh

ماخذ طریقوں کے لیے، GitHub Releases سے ماخذ ZIP ڈاؤن لوڈ اور نکالیں یا ریپوزیٹری کلون کریں۔ Start.cmd آپ کے Windows صارف کے لیے Python 3.12 انسٹال کرنے کی پیشکش کرتا ہے اگر کوئی موزوں Python نہ ملے (winget، یا دستخط شدہ python.org انسٹالر)۔ start.sh اگر پائتھن موجود نہ ہو تو آپ کی لینکس ڈسٹری بیوشن یا میک او ایس کے لیے انسٹال کرنے کا بالکل درست کمانڈ پرنٹ کرتا ہے۔ پہلا سورس لانچ .venv بناتا ہے اور انحصار (dependencies) کو خودکار طور پر انسٹال کرتا ہے۔

Docker ایپلیکیشن کو بلڈ کرتا ہے اور اسے پسِ منظر میں چلاتا ہے؛ ہوسٹ پائتھن غیر ضروری ہے۔ scripts\Docker.cmd اور scripts/docker-start.sh کنٹینر کے صحت مند ہونے پر پینل کا پتہ اور ٹوکن پرنٹ کرتے ہیں۔ ہر سپورٹڈ ہوسٹ پر مساوی Docker کمانڈز یہ ہیں:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

http://127.0.0.1:8787 کھولیں۔ Docker ہیلپر یا دوسری Docker کمانڈ کے ذریعے پرنٹ کیا گیا ٹوکن استعمال کریں، یا پورٹیبل یا سورس انسٹالیشن کے لیے data/live/panel-token.txt پڑھیں۔ نیچے 'ٹیلیگرام سے کنیکٹ کریں' پر جاری رکھیں۔ نیٹیو اور ڈاکر انسٹالیشنز الگ اسٹوریج استعمال کرتی ہیں؛ ڈاکر شروع کرنے سے موجودہ نیٹیو جرنل امپورٹ نہیں ہوتا۔

سرور کے لیے، تعیناتی میں خودکار HTTPS، ری اسٹارٹ، شائع شدہ تصاویر، اپ ڈیٹس، اور بیک اپ شامل ہیں۔

انٹرفیس دریافت کریں#

  1. پورٹیبل پیکیج میں TgWitness-Demo.cmd چلائیں، ونڈوز سورس فولڈر میں scripts\Demo.cmd ، یا لینکس/macOS پر sh start.sh --demo ۔ سورس لانچ پہلے .venv بناتا ہے اور انحصارات انسٹال کرتا ہے۔
  2. http://127.0.0.1:8787 کھولیں۔
  3. مقامی ڈیمو نمونہ جرنل خود بخود کھولتا ہے۔ براہِ راست مقامی رسائی کے لیے ٹوکن کی کاپی کی ضرورت نہیں۔

ڈیمو پیغامات خیالی ہیں۔ ڈیمو موڈ حقیقی ٹیلیگرام اکاؤنٹ سے منسلک نہیں ہو سکتا۔

ٹیلیگرام سے کنیکٹ کریں#

[!انتباہ] ایسی کوئی بھی چیز استعمال نہ کریں جسے آپ کھونے کا متحمل نہیں ہو سکتے۔ ہم سختی سے مشورہ دیتے ہیں کہ ذاتی یا قیمتی اکاؤنٹس کو نہ جوڑیں اور نہ ہی کسی ایسے اکاؤنٹ پر API ID / ہیش بنائیں جسے آپ اہمیت دیتے ہیں۔ ٹیلیگرام کلائنٹ کی پرواہ کیے بغیر، غیر متوقع اور اکثر مستقل طور پر اکاؤنٹس پر پابندی لگا دیتا ہے۔ ایک کامیاب ٹیسٹ رن ٹیلیگرام پر منحصر ہے، نہ کہ TgWitness پر، اور مستقبل کے لیے کسی چیز کی ضمانت نہیں دیتا۔

  1. اگر مقامی ڈیمو چل رہا ہے تو اسے روک دیں اور Start.cmd یا sh start.sh چلائیں۔ ورنہ اوپر چلتی ہوئی لائیو تنصیب کو چلتا رہنے دیں۔
  2. پینل کھولنے کے لیے اپنے انسٹالیشن طریقہ کار کے لیے پینل ٹوکن استعمال کریں۔
  3. اگر آپ کو پروکسی کی ضرورت ہو تو اسے اکاؤنٹ → ترتیبات → کنکشن کی ترتیبات → کنکشن کا راستہ تبدیل کریں کے تحت محفوظ کریں۔
  4. اکاؤنٹ میں اپنا فون نمبر درج کریں اور Continue دبائیں، QR کوڈ → Show QR کوڈ منتخب کریں، یا فائلز منتخب کر کے Connect account دبائیں۔ API ID + Hash اختیاری ہے: ورک اسپیس اپنی محفوظ یا درآمد شدہ جوڑی استعمال کرتا ہے، یا بلٹ ان پول سے ایک فعال جوڑی۔ اپنی ایپ استعمال کرنے کے لیے، ایک API ID:API Hash جوڑی کو API ID میں پیسٹ کریں۔ مکمل اتھارائزیشن کلید کے لیے، Auth key کا انتخاب کریں، تمام 512 ہیکساڈیسمل حروف پیسٹ کریں، اور فراہم کردہ DC ID کا انتخاب کریں۔ یوزر آئی ڈی اختیاری ہے اور درج کرنے پر چیک کی جاتی ہے۔
  5. اپنا منتخب کردہ سائن ان طریقہ مکمل کریں: فون/کوڈ/2FA، QR کے لیے سائن ان شدہ ٹیلیگرام ایپ سے تصدیق، یا ایک معاون مجاز سیشن امپورٹ۔
  6. دکھائی گئی اکاؤنٹ آئی ڈی چیک کریں۔ اوپن سورسز: آپ کی چیٹس خود بخود لوڈ ہو جاتی ہیں؛ اپنے گروپس شامل کریں۔
  7. 'محفوظ کرنے والی تبدیلیاں منتخب کریں' کے تحت، ایونٹ کیٹیگریز یا 'پیغامات، ترامیم اور حذف شدگیاں' کا پری سیٹ منتخب کریں، پھر مانیٹرنگ سیٹنگز محفوظ کریں۔
  8. منسلک کی ترتیبات علیحدہ طور پر منتخب کریں، پھر مشاہدہ شروع کرنے کے لیے دبائیں۔

API کی اسناد آپ کی ایپلیکیشن کی شناخت کرتی ہیں؛ یہ بذاتِ خود کسی اکاؤنٹ کو مجاز نہیں بناتیں۔ نجی گروپس کو عوامی صارف نام کی ضرورت نہیں ہوتی، لیکن آپ کے اکاؤنٹ کو رسائی حاصل ہونی چاہیے۔

موجودہ اکاؤنٹس کے لیے، اکاؤنٹس اور سیشن فارمیٹس دیکھیں: پینل Telethon StringSession، Telethon/Pyrogram SQLite، سنگل اکاؤنٹ TData ZIP، اور سپورٹڈ اکاؤنٹ JSON قبول کرتا ہے۔ ایک سیشن اور اس کے ساتھ والا JSON ایک ساتھ منتخب کریں، Connect account دبائیں۔ QR لاگ ان بھی دستیاب ہے، اسی اختیاری API ترتیبات کے ساتھ۔ TDLib، بوٹس، اور اکاؤنٹس کی بڑی فہرستیں سپورٹ نہیں کی جاتی ہیں۔

ایک اور اکاؤنٹ شامل کرنے کے لیے، اکاؤنٹ منتخب کرنے والے کے پاس موجود + کو دبائیں یا اکاؤنٹ → ترتیبات → کنکشن کی ترتیبات → ورک اسپیسز کھولیں، یا اکاؤنٹس استعمال کریں۔ ورک اسپیسز کے الگ الگ سیشنز، جرنلز، کیز، سورسز اور قطاریں ہوتی ہیں۔ ویوز تبدیل کرنے سے دیگر کلیکٹرز چلتے رہتے ہیں۔ اس انسٹالیشن میں ایک ہی ٹیلیگرام اکاؤنٹ دو ورک اسپیسز کو تفویض نہیں کیا جا سکتا۔ ورک اسپیسز کی کوئی مقررہ تعداد نہیں ہے؛ یہ ایک ہی عمل کو شیئر کرتے ہیں، لہٰذا گنجائش مشین پر منحصر ہوتی ہے۔

لائو پینل ٹوکن آپ کی ٹیلیگرام اجازتوں اور محفوظ شدہ مواد تک رسائی کو محفوظ کرتا ہے؛ یہ ٹیلیگرام API کی شناختی معلومات سے الگ ہے۔ صرف ایک واضح طور پر شروع کیا گیا، براہِ راست رسائی والا مقامی ڈیمو خودکار طور پر داخل ہوتا ہے۔ ایک دور دراز/پراکسی شدہ ڈیمو اب بھی data/demo/panel-token.txt استعمال کرتا ہے۔

نظرثانی اور برآمد#

  • جرنل: مشاہدات کو ماخذ اور واقعے کی قسم کے لحاظ سے تلاش اور فلٹر کریں۔
  • ایک واقعہ منتخب کریں تاکہ اس کے اصل ریکارڈ، منسوبہ کاری اور محفوظ شدہ ورژنز کا معائنہ کیا جا سکے۔
  • ترمیم کی تفصیلات دستیاب پہلے/بعد کے مواد کو دکھاتی ہیں۔ حذف کی تفصیلات دکھاتی ہیں آخری ریکارڈ شدہ مواد، اگر کوئی ہو؛ ایک نامعلوم فریق نامعلوم ہی رہتا ہے۔
  • ایکسپورٹس: دستخط شدہ ZIP، JSONL، CSV اور آف لائن HTML۔
  • مکمل چیٹ ایکسپورٹ (ماخذ → مکمل چیٹ ایکسپورٹ): ایک چیٹ کی پوری دکھائی دینے والی تاریخ کو ایک دستخط شدہ بنڈل کے طور پر chat.json کے ساتھ (Telegram-export طرز) اور ایک قابلِ مطالعہ chat.html کے ساتھ ڈاؤن لوڈ کریں۔ نجی چیٹس اس وقت کام کرتی ہیں جب اکاؤنٹ رکن ہو۔ یہ ایک موجودہ اسنیپ شاٹ ہے، حذف شدہ یا پہلے ترمیم شدہ پیغامات کی تعمیرِ نو نہیں۔ python verify.py chat-export.zip --fingerprint TRUSTED_SHA256 کے ساتھ ایک نقل کی تصدیق کریں۔
  • چیک پوائنٹ محفوظ کریں: دستخط شدہ جرنل کی حد کو کلیکٹر کے باہر رکھیں۔
  • دستیاب شدہ رن رسید ڈاؤن لوڈ کریں: کلیکٹر کے پروگرام/ورژن کے ریکارڈ کو محفوظ کریں۔
  • ٹائم اسٹیمپ کی درخواست تیار کریں: ٹائم اسٹیمپ اتھارٹی کے لیے آف لائن درخواست تیار کریں؛ جواب حاصل کرنے اور اس کی تصدیق کے لیے TIMESTAMP.md کی پیروی کریں۔
  • جرنل کی تصدیق کریں: ایونٹ سگنیچرز اور چین لنکس چیک کریں۔ زپ ایکسپورٹ میڈیا بھی چیک کرتا ہے۔

مدد یافتہ براؤزرز بڑے ایکسپورٹس کو براہِ راست منتخب کردہ فائل میں محفوظ کرتے ہیں۔ دیگر براؤزرز زیادہ سے زیادہ 128 MiB تک بفر کرتے ہیں۔ جب سرور چل رہا ہو، تو اسٹریمنگ CLI پورے جواب کو بفر کیے بغیر بڑے ڈاؤن لوڈز کی حمایت کرتا ہے:

python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip

دوسرے ورک اسپیس کے لیے، Exports → Workspace ID استعمال کرتے ہوئے --profile ID شامل کریں۔ دور دراز سرور کے لیے، --url https://your-server شامل کریں۔ ڈیفالٹ ٹرانسفر حد ہے 5 GiB؛ --max-mib اسے تبدیل کرتا ہے۔ دستخط شدہ ZIP مواد کی ڈیفالٹ غیر کمپریسڈ تصدیقی حد 4 GiB ہے (Parameters اسے بڑھاتا ہے؛ ایسے آرکائیوز کو verify.py --max-gib N کے ساتھ تصدیق کریں)۔ آرکائیو کو ویریفائر کی ایک قابلِ اعتماد کاپی اور ایک آزادانہ طور پر محفوظ کردہ کلید فنگر پرنٹ/چیک پوائنٹ کے ذریعے تصدیق کریں۔

انسٹالیشن چیک کریں#

python start.py --setup-only
python start.py --check
python start.py --check --json

--check مقامی انحصار، دستخط کی حمایت، ذخیرہ، کلید کی تشکیلات اور سننے کے پتے کا جائزہ لیتا ہے۔ یہ کچھ بھی انسٹال نہیں کرتا اور نہ ہی ٹیلیگرام سے جڑتا ہے۔ اگر کوئی بند پورٹ ہے تو اس کا مطلب ہے کہ کوئی اور مثال چل رہی ہے۔ ایک مختلف --port استعمال کریں یا پہلے اسے روک دیں۔

لانچر .venv میں انسٹال ہوتا ہے۔ ضمنی python -m tgwitness... کمانڈز کو ونڈوز پر .venv\Scripts\python.exe یا لِنکس/میک او ایس پر .venv/bin/python استعمال کرنا چاہیے، جب تک کہ وہ ماحول پہلے سے فعال نہ ہو۔

ایک بند، مستقل Telethon SQLite .session کو مقامی طور پر python -m tgwitness.sessions account.session --out account.tgwitness-session کے ساتھ تبدیل کیا جا سکتا ہے، پھر اکاؤنٹ میں لوڈ کیا جا سکتا ہے۔ براہِ راست فائل امپورٹ اور QR لاگ ان بھی دستیاب ہیں۔ لاگ ان فارمیٹس، SOCKS5، HTTP CONNECT، MTProxy اور بیرونی ماسٹر کیز کے لیے CONNECTION-SECURITY.md دیکھیں۔

وقف کرنے سے مشاہدہ رک جاتا ہے۔ لاک صرف براؤزر کی رسائی کو بند کرتا ہے۔ ٹیب بند کرنے سے کلیکٹر کا عمل چلتا رہتا ہے۔ عمل کو روکنے سے جمع کرنا رک جاتا ہے؛ ہسٹری کا ایک اسنیپ شاٹ تمام رہ جانے والی ترامیم یا حذف شدہ چیزوں کی بحالی نہیں کر سکتا۔ دیکھیں کہ ایونٹ پالیسیاں، منسلکات کی قطاریں، اکاؤنٹ کی علیحدگی، اور دوبارہ شروع کرنے کے رویے کے لیے جمع کیسے کام کرتا ہے۔

سیشنز اور راز محفوظ شدہ ہیں۔ پیغام کا مواد، میڈیا اور ایکسپورٹس کے لیے ایک محفوظ شدہ ڈسک یا والیوم درکار ہے۔ دستخطات ایک معتبر کلید کے حوالے سے سالمیت کا تعین کرتے ہیں؛ یہ ٹیلیگرام کے اصل ماخذ کی تصدیق نہیں کرتے اور نہ ہی ایسے آپریٹر کی جعلسازی کو روکتے ہیں جو جمع کرنے والے اور اس کی کلید پر قابو رکھتا ہو۔
