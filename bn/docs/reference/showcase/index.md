# জনসাধারণের প্রদর্শনী

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/reference/showcase/

নির্বাচিত পাবলিক চ্যানেলের সংরক্ষিত বার্তা এবং স্বাক্ষরিত স্ন্যাপশটগুলো মেয়াদোত্তীর্ণ, প্রত্যাহারযোগ্য লিঙ্কের মাধ্যমে প্রকাশ করুন।

[টিজিউইটনেস](https://github.com/phishdestroy/TgWitness/blob/main/README.md) / [ডকুমেন্টেশন](https://github.com/phishdestroy/TgWitness/blob/main/docs/README.md) · [Deployment and recovery](https://phishdestroy.github.io/TgWitness/bn/docs/reference/deployment/)

![Deployment & recovery](https://phishdestroy.github.io/TgWitness/assets/chapter-operate.svg)

**অ্যাক্সেস → পাবলিক শোকেস** বিদ্যমান অ্যাক্সেস-টোকেন সিস্টেম ব্যবহার করে একটি পৃথক, শুধুমাত্র-পঠনযোগ্য পৃষ্ঠা তৈরি করে। এটি ইনস্টলেশনের সংরক্ষিত পর্যবেক্ষণগুলো পড়ে। এটি কোনো কালেক্টর শুরু করে না, টেলিগ্রামে সাইন ইন করে না বা দর্শকের জন্য কোনো চ্যানেল অর্জন করে না।

## একটি পৃষ্ঠা প্রকাশ করুন

1. প্রদর্শন করতে চান এমন প্রতিটি পাবলিক চ্যানেলের জন্য একটি সোর্স প্রোফাইল সংরক্ষণ করুন। একটি চ্যানেলের সর্বশেষ সংরক্ষিত প্রোফাইলে অবশ্যই একটি পাবলিক ব্যবহারকারীর নাম থাকতে হবে; গ্রুপ এবং ব্যক্তিগত চ্যাট যোগ্য নয়।
2. ওপেন **অ্যাক্সেস → পাবলিক শোগকেস** (অথবা `/showcase-manage.html`) প্রশাসক হিসেবে।
3. ১৬টি ওয়ার্কস্পেস জুড়ে চ্যানেল নির্বাচন করুন, পাবলিক পেজের শিরোনাম লিখুন, এবং লিঙ্কের মেয়াদ ১, ৭ বা ৩০ দিন নির্বাচন করুন। অভ্যন্তরীণ ওয়ার্কস্পেস লেবেলগুলো প্রকাশিত হয় না। সর্বোচ্চ ৬৪টি চ্যানেল অন্তর্ভুক্ত করা যেতে পারে।
4. প্রকাশের জন্য নির্বাচিত চ্যানেলগুলির টেক্সট পর্যালোচনা করুন, তারপর **'নির্বাচিত রেকর্ডগুলির প্রিভিউ'** ক্লিক করুন। প্রিভিউ ভিজিটর পৃষ্ঠার মতো একই সার্ভার-সাইড প্রজেকশন ব্যবহার করে।
5. **'Create showcase' লিঙ্কে** ক্লিক করুন। লিঙ্কটি দৃশ্যমান থাকা অবস্থায় কপি করুন। বিতরণ করার আগে প্রাপকের পৃষ্ঠা পর্যালোচনা করতে এটিকে একটি পৃথক ব্রাউজারে খুলুন।

লিঙ্কে এর URL ফ্রেগমেন্টে একটি অ্যাক্সেস টোকেন থাকে। পৃষ্ঠাটি API অনুরোধ করার আগে ফ্রেগমেন্টটি সরিয়ে ফেলে এবং এটিকে একটি ব্রাউজার সেশনের জন্য বিনিময় করে। যে কেউ লিঙ্কটি ধারণ করলে মেয়াদ শেষ বা বাতিল হওয়া পর্যন্ত নির্বাচিত বিষয়বস্তু খুলতে পারে। নতুন লিঙ্কগুলি ১০০টি সমান্তরাল সেশন অনুমোদন করে, প্রতিটি সর্বোচ্চ এক ঘণ্টা স্থায়ী হয়। বিদ্যমান অ্যাক্সেস নিয়ন্ত্রণগুলি গ্রান্ট API-এর মাধ্যমে ঠিকানা সীমাবদ্ধতা এবং সাইন-ইন সীমাও আরোপ করতে পারে। সাধারণ পর্যালোচকের অ্যাক্সেস একটি ভিন্ন মোড এবং এতে এখনও মূল অনুমোদিত বার্তা এবং ফাইলগুলি অন্তর্ভুক্ত থাকে।

## পরিদর্শীরা যা দেখেন

| দৃশ্যমান | গোপন রাখা হয়েছে |
| --- | --- |
| নির্বাচিত পাবলিক চ্যানেলের শিরোনাম, ব্যবহারকারীর নাম এবং প্রোফাইল পর্যবেক্ষণ তারিখসমূহ | অ্যাকাউন্ট পরিচয়, অভ্যন্তরীণ ওয়ার্কস্পেস লেবেল এবং অনির্বাচিত উৎসসমূহ |
| রেকর্ডকৃত টেক্সট এবং প্রতিটি সংরক্ষিত সম্পাদনা | গঠিত প্রেরক আইডি, নাম, ব্যবহারকারীর নাম, ফোন নম্বর এবং প্রোফাইল মানসমূহ |
| যদি পূর্বে সংরক্ষিত টেক্সট থাকে, মুছে ফেলার পর্যবেক্ষণসহ | সংযুক্তি, অবতার, থাম্বনেইল, ফাইলনাম এবং মূল পেলোড |
| লেখক/প্রোফাইল বা সংযুক্তি রেকর্ড করা হয়েছে এমন নির্দেশক | ফরওয়ার্ডিং ও উত্তর মেটাডেটা, নেটওয়ার্ক রুট, আইপি ঠিকানা এবং ক্রেডেনশিয়াল |
| নির্বাচিত চ্যানেলের ইভেন্ট গণনা, বর্তমান সংগ্রহ সুইচ, হার্টবিট এবং চেকপয়েন্ট ইন্টারভাল | সংগ্রহ নিয়ন্ত্রণ এবং সাধারণ প্রমাণ-রপ্তানি API-সমূহ |
| স্বাক্ষর ফিঙ্গারপ্রিন্ট, জার্নাল চেকপয়েন্ট এবং সামঞ্জস্য প্রমাণ | স্বাক্ষর কী এবং টেলিগ্রাম সেশন |

**পাবলিক মেসেজের টেক্সট স্বয়ংক্রিয়ভাবে অজ্ঞাতনামা করা হয় না।** মেসেজে লেখা কোনো নাম, উল্লেখ, ফোন নম্বর বা লিঙ্ক সেই টেক্সটের অংশ হিসেবেই থাকে। `Redacted`এটি কাঠামোবদ্ধ লেখক/প্রোফাইল ক্ষেত্রগুলিতে প্রযোজ্য। প্রকাশের আগে নির্বাচিত প্রকৃত বিষয়বস্তু পর্যালোচনা করুন, সংরক্ষিত সম্পাদনা এবং মুছে ফেলা অংশগুলি সহ।

যোগ্যতা **সর্বশেষ সংরক্ষিত উৎস প্রোফাইল** প্রতিফলিত করে, লাইভ টেলিগ্রাম লুকআপ নয়। যদি পরবর্তী প্রোফাইলে আর কোনো পাবলিক চ্যানেল ব্যবহারকারীর নাম না থাকে, নতুন অনুরোধগুলো চ্যানেলটিকে বাদ দেয়। পাবলিক দৃশ্যমানতা পরিবর্তনের সময় উৎস প্রোফাইলগুলো রিফ্রেশ করুন। পাঠকরা ইতিমধ্যেই পূর্বে প্রাপ্ত সামগ্রী সংরক্ষণ করে থাকতে পারেন।

মূল স্বাক্ষরিত রেকর্ডগুলো অপরিবর্তিত থাকে। প্রদর্শিত প্রজেকশনটি পৃথকভাবে স্বাক্ষরিত হয় এবং এতে এর মূল রেকর্ডগুলোকে নির্দেশ করে এমন হ্যাশ থাকে। একটি প্রজেকশন স্বাক্ষর প্রদর্শিত বিবৃতিকে প্রমাণীকরণ করে; এটি মূল ইভেন্টের সম্পাদিত বাইটের উপর স্বাক্ষর নয়।

## স্বাক্ষর এবং ধারাবাহিকতা যাচাই করুন

**ফিঙ্গারপ্রিন্ট ও স্বাক্ষরিত চেকপয়েন্ট** প্রসারিত করুন এবং একটি স্ন্যাপশট ডাউনলোড করুন। পৃষ্ঠা রিফ্রেশের পর, ডাউনলোডে পূর্ববর্তী ব্রাউজার স্ন্যাপশট এবং তাদের জার্নাল সীমানার মধ্যে একটি মেরকেল সামঞ্জস্য প্রমাণ অন্তর্ভুক্ত থাকে। পৃষ্ঠা দৃশ্যমান থাকা এবং পর্যবেক্ষণের প্রথম পৃষ্ঠা প্রদর্শন করার সময় প্রতি মিনিটে একবার স্বয়ংক্রিয় রিফ্রেশ হয়।

TgWitness ইনস্টল করার পর, ডাউনলোডকৃত ফাইলটি অফলাইনে যাচাই করুন:

```
python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256
```

ফিঙ্গারপ্রিন্টটি অবশ্যই পৃথকভাবে বিশ্বাসযোগ্য কোনো রেফারেন্স থেকে আসতে হবে। আপনি নিজে সংরক্ষণ করা একটি স্ন্যাপশটের বিরুদ্ধে তুলনা করতে, ব্যবহার করুন `--previous earlier.json`; এটি ডাউনলোডের ভিতরে থাকা পূর্ববর্তী স্ন্যাপশটকে ওভাররাইড করে। বর্তমান প্রমাণটি সেই সংরক্ষিত সীমা থেকে শুরু হতে হবে। যাচাইকৃত ক্লায়েন্টরা প্রমাণটি অনুরোধ করতে পারে `GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>`. একটি সংক্ষিপ্ত জার্নাল নীরবে সীমানা রিসেট করার পরিবর্তে HTTP 409 ফেরত দেয়।

স্বাক্ষরিত চেকপয়েন্ট **পুরো কালেক্টর**জার্নালে commit করে, যার মধ্যে রয়েছে এর রেকর্ড সংখ্যা এবং অস্পষ্ট হেড হ্যাশ। প্রদর্শিত মেসেজ সংখ্যা শুধুমাত্র নির্বাচিত পাবলিক চ্যানেলগুলোর জন্য প্রযোজ্য। পৃষ্ঠাটি কখনোই অন্য জার্নালের বিষয়বস্তু তালিকাভুক্ত করে না। এগুলো ইভেন্টের সংখ্যা, অনন্য-মেসেজের সংখ্যা নয়। সেটিংসগুলো বর্তমান কনফিগারেশন বর্ণনা করে, প্রতিটি পূর্ববর্তী রেকর্ডিং ইন্টারভাল নয়।

স্বাক্ষর ও সামঞ্জস্য যাচাই সংরক্ষিত সীমার তুলনায় পরিবর্তন সনাক্ত করতে পারে। এটি স্বতন্ত্রভাবে স্বাক্ষরিত কাউন্টারগুলো পুনরায় গণনা করে না, টেলিগ্রামের উৎপত্তি প্রত্যয়ন করে না, অবিচ্ছিন্ন ক্যাপচার প্রদর্শন করে না, বা স্বাধীন সাক্ষীকে প্রতিস্থাপন করে না। সেই পর্যালোচনার জন্য [প্রমাণ যাচাইকারী](https://github.com/phishdestroy/TgWitness/blob/main/docs/TRUST.md), [স্বাধীন সাক্ষী](https://phishdestroy.github.io/TgWitness/bn/docs/reference/witness/) এবং [পরীক্ষিত-স্কেল রেকর্ড](https://phishdestroy.github.io/TgWitness/bn/docs/reference/verification/) ব্যবহার করুন। সিন্থেটিক ইনস্টলেশনগুলো দৃশ্যমানভাবে সিন্থেটিক হিসেবে লেবেল করা হয়।

## পৃষ্ঠা বাতিল বা হোস্ট করুন

শোকেস ম্যানেজার বা বিদ্যমান **অ্যাক্সেস** সেকশনে **Revoke** ব্যবহার করে লিঙ্কটি বন্ধ করুন এবং এর সমস্ত সেশন শেষ করুন। যখন কোনো অনুরোধ সনাক্ত করে যে অ্যাক্সেস শেষ হয়েছে, তখন ভিজিটর প্রদর্শিত রেকর্ডগুলো মুছে ফেলে। প্রতিটি অনুরোধে মেয়াদোত্তীর্ণতা এবং অনুমতিগুলো যাচাই করা হয়। শোকেস গ্রান্টগুলো সরাসরি সাধারণ প্যানেল অ্যাক্সেসে রূপান্তর করা যায় না; মোড পরিবর্তন করতে একটি নতুন গ্রান্ট তৈরি করুন।

ইনস্টলেশনের বিদ্যমান HTTPS ঠিকানার মাধ্যমে পৃষ্ঠাটি পরিবেশন করুন। একটি লিঙ্ক প্রকাশ করলে নতুন কোনো পোর্ট খোলা হবে না, কোনো টানেল তৈরি হবে না বা DNS পরিবর্তন হবে না। HTML এবং API ব্যবহারকারীর ইনস্টলেশনেই থাকবে। একজন শোরকেস ভিজিটর এই অ্যাক্সেসের মাধ্যমে সাধারণ মেসেজ, প্রোফাইল, মিডিয়া, এক্সপোর্ট বা ম্যানেজমেন্ট API ব্যবহার করতে পারবেন না।
