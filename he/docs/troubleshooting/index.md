# גלה מה השתבש

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/troubleshooting/

התחל מהתסמין. בדוק שכבה אחת בכל פעם.

## הפאנל מבקש אסימון

השתמש באסימון הפאנל מהקובץ המקומי המוצג על ידי תוכנת ההפעלה. עבור Docker, הפעל את `docker compose exec tgwitness cat /data/panel-token.txt`. קוד כניסה ל-Telegram, אסימון BotFather ואסימון Witness לקריאה בלבד משמשים למטרות שונות.

## Telegram אינו מתחבר

פתח את הגדרות החיבור והפעל את בדיקת החיבור. אם אתה משתמש בפרוקסי ציבורי, נסה ערך אחר ושמור את המסלול במפורש. בדוק את סוג הפרוקסי ואת פורמט המפתח הסודי הנתמך. רענון רשימה ציבורית אינו משנה את מסלול החשבון.

## מחובר, אך אין הודעות חדשות

1. ודאו שה-observation פועל בסביבת העבודה הנכונה.
2. יש לוודא שהמקור נבחר וגלוי לחשבון זה.
3. שלחו הודעה חדשה וייחודית בקבוצה מבוקרת וחפשו את הטקסט המדויק הזה.
4. בדקו את יומן הפעילות כדי לאתר הפרעות, עיכובים בעבודה או שגיאות ב-Telegram.

תמונות מצב היסטוריות ואירועי הודעות חדשות הם שני דברים שונים. ניתן להתחבר למקור שקט מבלי לייצר הודעות חדשות. יש להשתמש במבחן משלוח מבוקר כאשר יש חשיבות לשלמות הנתונים.

## FloodWait או פער לאחר הפעלה מחדש

FloodWait פירושו ש-Telegram דורש הפסקה. יש להמתין למשך הזמן המצוין ולבדוק את עומס העבודה של האיסוף; חיבורים חוזרים ונשנים אינם מבטלים את המגבלה. מצב העדכון השמור מסייע להשלים את הפעולה לאחר הפעלה מחדש, אך עדכונים שפג תוקפם וחלונות הפרעה מסוימים נותרים מגבלות. יש לתעד את הפער במקום להתייחס ליומן כאל שלם.

## הבוט מוגדר אך אינו מפרסם דבר

יש לוודא שתהליך ה-Witness פועל כראוי, שהבוט יכול לפרסם בערוץ ושה-Witness יכול להגיע לאספן ול-Bot API. יש לבדוק ביומן האם היו פרסומים שנכשלו. סקר מוצלח של האספן לבדו אינו מאשר פרסום בערוץ.

## היכן ניתן למצוא את שילוב האסימון של GitHub?

**בתכנון.** בסעיף "תוספות" מתואר תהליך העבודה המוצע לאימות הפורק והבנייה. כרגע אין טופס אסימון GitHub או אישור אוטומטי לכך שהתקנה הפועלת תואמת למאגר. ראו את [מצב התכונות הנוכחי](https://phishdestroy.github.io/TgWitness/he/docs/reference/features/).

בעת דיווח על בעיה, יש לציין את הגרסה, מערכת ההפעלה, השלבים ואת השגיאה (לאחר עריכת הפרטים המזהים). יש להימנע מפרסום פרטים כגון הפעלות, אסימונים, הודעות פרטיות וספריית הנתונים בפורומים הציבוריים.
