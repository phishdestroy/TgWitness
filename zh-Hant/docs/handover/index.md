# 準備一份分享用副本

Canonical page: https://phishdestroy.github.io/TgWitness/zh-Hant/docs/handover/

在保持原始工作區完整的前提下，分享相關觀察結果。

移交是一份獨立且經簽署的摘錄文件。請選擇對話內容與相關人員，刪減身分資訊或文字內容，並決定哪些檔案及團隊筆記應包含在收件方的副本中。其清單會記錄選取內容，以及未變更、已縮減及已省略的紀錄數量。

## 準備收件者的擷取檔

1. 開啟「**匯出」→「移交擷取」**。填寫其目的、選擇聊天室及可選的 UTC 時間範圍，若需列出受調查對象姓名，請勾選「**載入所選聊天室中的人員**」。
2. 可選擇如何處理其他人員：使用化名、省略其訊息，或顯示為已記錄內容。訊息正文與附件可獨立設定；可選擇性地遮蔽電話號碼和電子郵件地址。
3. 請決定是否包含「案件看板」的書籤與切片，或是附有註解的卡片。本文件中，可使用調查員別名取代團隊名稱。
4. 選擇「**下載移交摘要」**。在本地開啟生成的報告及選定的紀錄，驗證存檔內容，並在傳送前檢查副本。

### 一份原始文件，一份經審核後分享的副本

合成範例 · 僅供說明用途

1. **選取。**請包含案件聊天紀錄，並標明該摘錄所涉及的人物。
2. **最小化。**選擇其他參與者在共享副本中的顯示方式。
3. **檢查。**在傳送前，請開啟生成的壓縮檔中的報告與紀錄。
4. **分享。**請提交經核對的譯稿，並另行提供其可信指紋。

Nora · 使用者 71002

「我已收到修訂後的連結。」

原始日誌會保留此項已儲存的觀察記錄。

省略：此參與者的訊息未包含在文本中。

請參閱 report.html 及 records.jsonl 檔案。

請核對身分資訊、文字內容、附件及可選的團隊評論。

#### 已簽署的摘錄

選取項目 + 檔案雜湊值 + 簽名清單

## 請一併使用這些控制項

| 控制 | 對文案的影響 |
| --- | --- |
| 人員 | 請確保選定的對象可被識別；其他參與者則可依選擇進行假名化或省略。 |
| 文字 | 請包含所有文字、僅包含選定人員及觀察帳戶的文字，或省略訊息文字及其包含文字的詳細資料欄位。 |
| 檔案 | 請選擇特定人員及監控帳戶的檔案、所有顯示訊息的檔案，或不選擇任何檔案。 |
| 案件看板 | 請勿選用看板素材、書籤與切片，亦請勿選用附有團隊討論的卡片。 |

請審閱自由格式文字、檔案內容以及身分資訊：使用化名並不會自動移除訊息或附件中出現的所有姓名。若選定的保存檔案無法取得，請在產生摘錄前將其還原，或明確省略相關附件。

## 確保翻譯內容可獨立核對

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

請將原始的簽名證據檔案與檢查點分別保留。移交過程會記錄其自身的投影，因此接收方無需取得整個工作區，即可核對已交付的副本。「[報告工作室」](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/reports/)提供其閱讀設計；[匯出驗證](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/exports/)則說明可信參考來源。
