# 아카이브 활용하기

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/archive/

메시지를 찾아보세요. 출처를 확인하세요. 증거를 구축하세요.

이 도구들은 현재 메인 브랜치에서 사용할 수 있습니다. 0.7.0 휴대용 미리보기 버전은 이보다 이전 버전입니다. 이 워크플로를 사용하려면 소스 코드를 체크아웃하십시오.

01**이력을 불러오기**

활성화된 소스의 과거 메시지를 작업 공간으로 불러옵니다.

02**출처를 확인하세요**

아카이브를 검색하고 각 검색 결과 뒤에 있는 저장된 메시지를 열어보세요.

03**인계 과정을 명확히 하십시오**

분석 결과를 별도로 저장하고, 그와 함께 서명된 증거 자료를 내보내세요.

캡처된 기록, 인식된 텍스트 및 분석가의 결론은 명확히 구분됩니다.

## 이전 메시지 불러오기

1. **출처 → 범위 내 대화**를 열어 활성화된 대화를 검토하고 관찰을 시작하세요.
2. **'전체 기록 불러오기'를** 선택하십시오. 실행 시 해당 시점에 선택된 소스 목록이 사용됩니다.
3. 필요에 따라 **‘중지 내역**’과 **‘계속 내역’을** 사용하십시오. 재시작 후에는 명시적으로 작업을 재개하십시오.
4. 소스별 결과 및 첨부 파일 대기열을 확인하십시오. 증거 내보내기 시 서명된 진행 보고서를 저장하십시오.

이 기능을 사용하면 작업 공간에 사용 가능한 메시지가 채워집니다. 채팅별 HTML/JSON 내보내기는 별도의 작업입니다. [기록 및 복구 세부 정보](https://phishdestroy.github.io/TgWitness/ko/docs/reference/history/).

## 먼저 검색한 후, AI 사용 여부를 결정하세요

1. 로컬 검색을 하려면 **저널**을 여세요. 작업 공간을 선택하고 출처 및 시간 필터를 사용하세요.
2. 구문 또는 도메인을 검색하세요. 일치하는 기록과 저장된 버전을 열어보세요.
3. AI 분석을 사용하려면 관리자가 **연동 기능**에서 제공업체를 활성화하고 설정해야 합니다. **아카이브에 문의하기**를 열고 대화와 기간을 선택하세요. 요청을 승인하기 전에 **모델로 전송된 데이터**를 검토하고 원하지 않는 발췌문은 선택 해제하세요.
4. 반환된 인용 정보를 확인하십시오. 답변을 보고서로 저장하고, 직접 수정하거나 메모를 추가하십시오.

검색은 AI 없이 로컬에서 실행됩니다. 분석 보고서에는 출처 참조 정보와 수정 내역이 포함되며, 이는 서명된 기록부와 별도로 관리됩니다. [제공자 설정 및 보고서](https://phishdestroy.github.io/TgWitness/ko/docs/reference/analysis/).

## 필요한 연결 방식을 선택하세요

| 과제 | 열기 | 설정 |
| --- | --- | --- |
| AI 클라이언트의 채팅 내용 중 일부 읽기 | **연동 기능 → MCP** | [MCP 확장 기능을 설치하고, 범위 지정 토큰을 발급한 후 클라이언트를 연결하십시오.](https://phishdestroy.github.io/TgWitness/ko/docs/reference/mcp/) |
| 저장된 미디어 내 텍스트 인식 | `media.saved` 기록 → **첨부 파일 인식** | [로컬 Docker 워커 및 필요한 언어/모델 파일을 설정합니다.](https://phishdestroy.github.io/TgWitness/ko/docs/reference/media-analysis/) |
| 이벤트를 n8n 또는 SIEM으로 전송 | **연동 → 발신 웹훅** | [수신자 추가, HMAC 검증 및 이벤트 ID 중복 제거](https://phishdestroy.github.io/TgWitness/ko/docs/reference/webhooks/) |

**어떤 액세스 토큰을 어디에 입력해야 하나요?**

패널 접근 권한은 사건을 검토하는 사람들을 위한 것입니다. MCP 연결 사용자에게는 별도의 읽기 전용 아카이브 토큰이 제공됩니다. 웹훅 수신기는 자체 HMAC 비밀 키를 사용합니다. 누구도 텔레그램 세션 파일이 필요하지 않습니다.

[패널 액세스 권한을 공유하거나](https://phishdestroy.github.io/TgWitness/ko/docs/access/) [MCP 클라이언트를 구성하세요](https://phishdestroy.github.io/TgWitness/ko/docs/reference/mcp/).

## 출처 및 결론 제시

검토를 거친 분석 보고서는 서명된 증거 ZIP 파일과 함께 보관하십시오. 보고서는 출처에 대한 귀하의 해석을 설명하며, ZIP 파일을 통해 수신자는 저장된 기록을 독립적으로 신뢰할 수 있는 지문 및 체크포인트와 대조하여 확인할 수 있습니다.
