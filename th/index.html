บันทึก, ไฟล์, จุดตรวจสอบที่มีเวลาประทับ และข้อมูลการส่งออกการสนทนา — ถูกเข้ารหัสก่อนการอัปโหลดไปยัง AWS S3 หรือพื้นที่จัดเก็บข้อมูลที่เข้ากันได้

การคัดลอกตามกำหนดเวลาหรือแบบมือ

Object Lock
เลือกจำนวนวันเก็บรักษาและโหมดการทำงานเมื่อ bucket รองรับ ฟีเจอร์นี้ แผงควบคุมจะรายงานว่า การเก็บรักษาได้รับการยืนยันแล้วหรือไม่ สำหรับวัตถุที่อัปโหลด
การกู้คืนที่ได้รับการยืนยัน

ก่อนที่จะเริ่ม

หน้านี้มีการเชื่อมต่อกับ Telegram หรือไม่?

ไม่ นี่เป็นหน้าโครงการแบบคงที่ที่มีตัวอย่างและภาพหน้าจอที่สร้างขึ้นเพื่อตัวอย่างเท่านั้น แอปพลิเคชันจริงจะทำงานบนคอมพิวเตอร์หรือเซิร์ฟเวอร์ของคุณ และการลงชื่อเข้าใช้จะเกิดขึ้นที่นั่น

เครื่องมือนี้สามารถกู้คืนข้อความที่ถูกลบก่อนการบันทึกได้หรือไม่?

ไม่ TgWitness เก็บรักษาเนื้อหาที่บัญชีของคุณได้สังเกตเห็นในขณะที่กระบวนการเก็บข้อมูลกำลังทำงานอยู่ ภาพถ่ายประวัติในภายหลังไม่สามารถสร้างใหม่การแก้ไขที่พลาดไปหรือข้อความที่ถูกลบได้

บันทึกทั้งหมดของฉันถูกเข้ารหัสหรือไม่?

ข้อมูลรับรองบัญชีและข้อมูลลับสำหรับการลงนามถูกเก็บไว้ในคลังข้อมูลที่เข้ารหัส ข้อความและไฟล์แนบในเครื่องจำเป็นต้องใช้ดิสก์หรือโวลุ่มที่เข้ารหัส การส่งออกข้อมูลสามารถเลือกใช้ไฟล์ ZIP ที่เข้ารหัสด้วย AES-256 และป้องกันด้วยรหัสผ่านได้
