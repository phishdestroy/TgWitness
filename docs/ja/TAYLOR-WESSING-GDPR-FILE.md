## 2. 36秒と、脆弱な「Anlage 1 / Taylor Wessing」ラベル

私たちは何の専門家でもありません。だからこそ、私たちの脆弱性通知はフリーランス・プラットフォーム自身にも博士にも無視されたのでしょう。理屈は明快です。彼らこそが法なのだから、どんな脆弱性があり得るというのでしょう？

しかし博士の言葉はいったん脇に置いて、技術を見てみましょう。私たちは同等のWindows環境を用意し、整理済みのファイルを取り出して図形を配置してみました。数百個の黒い図形を、記録されたセッションの長さとちょうど同じ **36秒** で手作業で配置するのは、私たちの見る限り不可能です。どう見ても、黒い枠はすでに文書上にありました。私たちは、その36秒間に追加されたのは1ページ目右上のちょうど一つのオブジェクト、すなわち `"Anlage 1 / Taylor Wessing"` ラベルだと考えています。そして脆弱なのは、まさにそれを配置したソフトウェアなのです。

* **マーカーから見たオブジェクト：** `(929, 294)` から `(1139, 372)` まで、つまり `210 × 78 px`、中心はおよそ `(1034, 333)`。
* **見える枠：** `(936, 300)` から `(1133, 367)` まで、約 `197 × 67 px`、縦横比はおよそ `3 : 1`。用紙の上端は `y ≈ 275`。
* **縮尺：** 文書の左側の定規で測ると `1 cm ≈ 82 px`（定規はほぼ確実にセンチメートル単位です。インチなら用紙は `15″` より広くなってしまいます）。

バッジのスタイルと見た目は返却されたファイルと一致します。しかし元の作成環境にアクセスできず、また初期形式（変換があった場合）もわからない以上、実験は純粋なものにはなり得ません。したがって100%の確信をもってこれを主張することはできません。

通報は444ページから始まり、あの同性愛嫌悪の通報もそこに含まれます。重要な点が一つあります。
