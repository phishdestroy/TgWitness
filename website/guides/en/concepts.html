Messages change. Your record of what you saw shouldn't, and anyone should be able to check that.

Two small experiments below. Fake messages, everything runs in your browser, nothing goes to Telegram.

From a chat export to a verifiable record

A Telegram Desktop export saves the history you can see right now as HTML or JSON. TgWitness adds a running journal of changes, signatures on every record and checkpoints others can compare against.

TaskTelegram Desktop exportTgWitness
Read saved conversationsHTML or JSON with selected mediaSaved chats, searchable journal and offline reports
Follow a change over timeThe history available when exportedOld versions, later edits and deletions, all kept

The comparison is based on the Telegram Desktop export code as of 2 November 2026.

One message, three observations

A new message, an edit and a deletion become three separate records. The edit doesn't overwrite the first one, and the deletion doesn't erase it.

Change a record. Follow the hash.

Every record contains the hash of the one before it. A checkpoint kept somewhere else pins the journal length and the last hash.

The actual rules, in a few lines

HASH + SIGNATURE
h0 = 064
hi = hex(SHA-256(C(ei)))
σi = Ed25519.Sign(sk, unhex(hi))

C is the nine event fields as UTF-8 JSON: sorted keys, no extra whitespace, no ASCII escaping, no NaN/infinity. previous_hash is hi−1, h0 is 64 zeros, signatures cover the 32 raw digest bytes.

The fields: seq, observed_at, source_at, kind, chat_id, message_id, actor_id, payload, previous_hash. Full spec: event encoding.

RETAINED CHECKPOINT
Nexport ≥ Ncheckpoint
hexport[Ncheckpoint] = Hcheckpoint

Check the checkpoint signature against the pinned key, then compare it with the journal. A later export can be longer, but it has to match at the checkpoint.

Three questions, three different checks

01 / INTEGRITYDid this record change?

Hashes and signatures against a key you trust.

02 / CONTINUITYWhat was retained earlier?

Compare the export with checkpoints a witness kept.

03 / DELIVERYDid these test events arrive?

Send, edit and delete test messages and see what each account caught.

Signatures answer "was it changed", checkpoints answer "does it match what was there before", test messages answer "did we catch everything". What verification proves.
