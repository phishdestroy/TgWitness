# Telegram · הקימו לוח תיקים

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/case-board/

הפכו הודעות שמורות לתיק שהצוות עובד עליו יחד.

סימניות, ציטוטים מדויקים, פרוסות ודיון, כל אחד מקושר למקור שלו. כל שינוי הוא גרסה חתומה.

## מהודעה לכרטיס תיק

1. **חקירה ← Case Board** (מצב רגיל או מומחה). צרו אוסף לתיק.
2. ב-**יומן** או בצ'אט לחצו **ללוח** (או **B**). הכרטיס נוחת בתיבת הדואר הנכנס, תנו לו כותרת והזיזו אותו.
3. בחרו טקסט בהודעה, **הדגשה ← לוח** שומר את הציטוט המדויק ואת הגרסה. רשמו למה זה חשוב.
4. דונו, קבעו סטטוס, קפצו חזרה למקור מתי שצריך. **מצגת** מעבירה את הצוות שלב אחרי שלב.

### יש לעקוב אחר קישור תשלום אחד ששונה

דוגמה סינתטית · איור מקומי

1. **לכידה.** פתח את התצפית השמורה מס' 142 ואת גרסת ההודעה שלה.
2. **סימניה.** שמור את הציטוט, הפניה למקור והשאלה שלך על כרטיס.
3. **בדיקה.** הוסף הערה של הצוות והעבר את הכרטיס ל"בדיקה".
4. **הצג.** עבר על תהליך האיסוף ופתח את הקשר של המקור המצוטט.

ההערות ותצפיות ה-Telegram נותרות ניתנות לזיהוי בנפרד.

## שמור טווח שימושי פעם אחת

Shift-לחיצה על שתי הודעות ל**פרוסה ביניהן**, השתמשו ב**פרוסה לפי זמן**, או שמרו את מסנני היומן הנוכחיים. **הצגת רשומות שנוספו מאז הסימנייה** מראה מה נכנס אחר כך.

פרוסות זמן משתמשות בזמן הצפייה; פרוסות לפי מזהה הודעה עוקבות אחרי ההודעות האלה כשהן משתנות.

## הקצו לכל עמית את התפקיד המתאים

**סוקר** קורא, **אנליסט** מוסיף כרטיסים ותגובות, **מפעיל** גם מנהל אוספים והחלטות. הרשאות צ'אט חלות גם על כרטיסים.

## הפוך את העבודה לתוצר סופי

פרוסות מיוצאות כ-JSON חתום או CSV. דוחות יכולים לכלול סימניות, פרוסות ותגובות, הגדירו את זה ב-[Report studio](https://phishdestroy.github.io/TgWitness/he/docs/reports/). לנמען מוגבל, השתמשו ב[מסירה](https://phishdestroy.github.io/TgWitness/he/docs/handover/).
