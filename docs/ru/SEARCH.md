# Полнотекстовый поиск

[Анализ архива](ANALYSIS.md) · [Локальное распознавание текста и транскрипция](MEDIA-ANALYSIS.md) · [Вики](../wiki/Archive-and-Integrations.md)

**Предварительный просмотр.** В разделе **Журнал** выберите **Лучшее совпадение · формы слова** рядом с полем поиска. Результаты ранжируются по алгоритму BM25 и включают другие формы одного и того же слова: *при поиске перевод* будут найдены *переводом* и *переводы*, при поиске *transfer* — *transfers*, а китайская фраза будет найдена без пробелов. **Сначала самые новые · Точный текст** сохраняет предыдущий поиск подстроки по всей записи.

Индекс представляет собой производные данные. Он воссоздаётся на основе подписанного журнала, сам по себе никогда не подписывается и никогда не включается в экспорт. Исходные записи не изменяются.

<a id="search-syntax"></a>
## Синтаксис поиска

| Запись | Находит |
| --- | --- |
| `перевод карта` | Записи, содержащие оба слова в любой форме |
| `"переводом на карту"` | Точную фразу в указанном порядке |
| `бонус OR подарок` | Любое из слов |
| `перевод -казино` | Записи без исключённого слова |
| `example.com` | Домен и его поддомены, в том числе в скрытых ссылках и URL-адресах кнопок |
| `@username`, `t.me/username` | Упоминания и ссылки, связанные с аккаунтом, а также отправленные им сообщения |
| `#tag` | Хештег |
| `+79991234567`, адрес кошелька, адрес электронной почты | Одно и то же значение в тексте или ссылках |
| `from:@username`, `from:123456` | Сообщения от этого отправителя |
| `chat:-1001234567890` | Один чат; это может ограничить только ваш собственный доступ |
| `id:42` | Сохраненные версии сообщения № 42 |
| `since:2026-01-01 until:2026-01-31` | Период наблюдения; дата без указания времени охватывает весь день |
| `kind:edited` | Только изменения (`new`, `snapshot`, `edited`, `recovered`) |
| `source:ocr`, `source:transcription`, `source:all` | Распознанный текст вместо сообщений или вместе с ними |

Предлоги и другие служебные слова игнорируются при наличии других слов. Похожие буквы, входящие в состав слова (например, латинская буква *а* в кириллическом слове), полноширинные и декоративные символы Unicode, а также невидимые символы нормализуются.

<a id="languages"></a>
## Языки

Язык определяется для каждой записи по её письменности и буквам:

| Письменность | Соответствие |
| --- | --- |
| Кириллица | Русские и украинские леммы с использованием [pymorphy3](https://github.com/no-plagiarism/pymorphy3). При отсутствии дополнительного украинского словаря применяется упрощённый украинский стеммер |
| Латинский | Английский стеммер Snowball; диакритические знаки игнорируются |
| Китайский, японский, корейский, тайский, лаосский, кхмерский, бирманский | Пары символов, що перекриваються: будь-яка фраза знаходиться без пробілів. Китайські запити розбиваються на слова за допомогою jieba |
| Інші алфавіти | Точные слова |

Украинский словарь (`pymorphy3-dicts-uk`) распространяется по лицензии GPL-3.0, поэтому он не устанавливается по умолчанию. Установите его с помощью команды `pip install "tgwitness[uk-dictionary]"`; индекс распознает новый анализатор и перестроится самостоятельно.

<a id="where-the-index-lives"></a>
## Местоположение индекса

| Режим | Хранение | Использование |
| --- | --- | --- |
| На диске (по умолчанию) | Файл `search/fulltext.sqlite3` в каталоге рабочей области | Крупные архивы; сохраняется при перезапуске |
| Только в памяти | Ничего на диске; восстанавливается при каждом запуске | На диске отсутствует производная копия текста сообщения |
| Отключено | Индекс отсутствует; **сначала отображаются самые новые сообщения ·** сохраняется **точный текст** | Минимальные настройки |

Главный администратор выбирает режим в меню **Журнал → Фильтры → Индекс поиска** для каждой рабочей области. Параметр ``TGWITNESS_FULLTEXT=disk|memory|off`` устанавливает значение по умолчанию для рабочих областей, не имеющих собственного выбора. Переключение на режим «память» или «выключено» приводит к удалению файла. Файл индекса имеет ту же защиту, что и журнал: он находится в каталоге с личными данными. При создании резервных копий и внешних копий он не включается.

Новые записи индексируются в фоновом режиме в течение нескольких секунд; при поиске сначала индексируется небольшой накопившийся объем данных, поэтому запись, сохраненная буквально мгновение назад, будет найдена. Существующий журнал индексируется после обновления без блокировки панели; до этого момента результаты охватывают индексированные записи, а в журнале отображается ход выполнения. **Перестроение индекса** начинается заново с первой записи.

```sh
python -m tgwitness index status --data-dir data/live
python -m tgwitness index rebuild --data-dir data/live --json
```

Для выполнения команды `rebuild` необходимо остановить работу панели (в противном случае будет возвращён код завершения 3). При использовании параметра `--json` в стандартный вывод выводится только результат; информация о ходе выполнения выводится в стандартный поток ошибок.

<a id="results-and-the-signed-journal"></a>
## Результаты и подписанный журнал

Индекс хранит порядковый номер и хеш последней записи журнала, которую он охватывает, и сверяет их с журналом при его открытии. Замена, восстановление или редактирование журнала вызывает перестроение индекса. Каждый ответ сообщает об этой позиции, и каждое совпадение считывается из подписанного журнала по его порядковому номеру: индекс определяет, какие записи отображать и в каком порядке, но никогда не определяет их содержание. Доступ к чату применяется к собственному полю чата журнала, а не к содержимому индекса.

<a id="recognized-text"></a>
## Распознанный текст

Результаты OCR и транскрипты остаются в своих зашифрованных файлах. Их индекс существует только в памяти и перестраивается по завершении задания распознавания. Соответствие отображается в записи `media.saved` с пометкой «машинное распознавание», указанием движка, модели и отрывка; оно никогда не представляется в виде текста, отправленного в Telegram. Тот же индекс используется для функции **Поиск распознанного текста**, которая по-прежнему также выполняет поиск по простым подстрокам.

<a id="access"></a>
## Доступ

Доступ в пределах чата находит только записи из соответствующих чатов, включая распознанный текст их вложений. Фильтры `chat:` и другие могут лишь сузить этот набор. Статус индекса, отображаемый при доступе в пределах чата, не включает общие данные по журналу. Только главный администратор может изменить режим или перестроить индекс.

<a id="ask-the-archive-and-mcp"></a>
## «Запросить архив» и MCP

**Дополнительные инструменты → Запрос к архиву** извлекает данные из этого индекса после его завершения: лучшие совпадения по выбранным чатам, при этом сохраненный текст учитывается только один раз. Отправляется до 24 источников; длинные тексты обрезаются вокруг места совпадения и помечаются как усечённые. Запросы о недавних изменениях, сохраненных версиях одного сообщения и поиски, выполняемые пока индекс ещё формируется, используют прежнюю хронологическую выдачу результатов. В предварительном просмотре отображается, какой метод был использован.

Клиенты MCP могут вызывать функцию ``search_messages`` с параметром ``ranked=true`` и функцию `page` с параметром ``next_offset``. Соединения с ограниченной областью действия получают только данные своих чатов.

Пагинация с ранжированием охватывает не более первых 1 000 результатов, независимо от размера страницы. Уточните запрос, чат или период, чтобы просмотреть дополнительные совпадения. При поиске «Сначала самые новые» сообщения, результаты OCR и транскрипции сортируются перед выбором каждой страницы.

<a id="dependencies"></a>
## Зависимости

| Пакет | Лицензия | Почему |
| --- | --- | --- |
| pymorphy3, pymorphy3-dicts-ru, DAWG2-Python | MIT | Русские и украинские леммы; словари загружаются локально |
| snowballstemmer | BSD-3-Clause | Английские корни, на чистом Python |
| jieba | MIT | Сегментация китайских запросов, на чистом Python (только исходный код) |
| pymorphy3-dicts-uk (необязательно) | GPL-3.0 | Полный украинский словарь |

Требуется SQLite FTS5 с токенизатором `unicode61`; он входит в состав SQLite в текущих сборках Python. Без него при поиске по наилучшему совпадению выдается сообщение о недоступности функции.

<a id="benchmark"></a>
## Тестирование производительности

Команда `python tools/bench_fulltext.py --messages 1000000 --work <empty directory>` создаёт детерминированный подписанный журнал, содержащий смешанные сообщения на русском, украинском, английском, китайском и японском языках со ссылками и идентификаторами в 200 чатах, формирует индекс и измеряет время выполнения типичных поисковых запросов (50 результатов, медиана по 7 прогонам).

Измерения проводились на Windows 11, процессоре Intel Core i9-13900K, 128 ГБ ОЗУ, Python 3.12.10, SQLite 3.49.1, данные на диске с файловой системой exFAT, с использованием анализатора `fulltext-v1+pymorphy3-ru+light-uk+snowball-en`:

| Показатель | Результат |
| --- | --- |
| Журнал с подписью | 1 000 000 сообщений, 1,50 ГиБ, записано за 19 минут |
| Построение индекса на основе журнала | 71 с, около 14 141 сообщений в секунду |
| Файл индекса | 58 MiB, 3,8 % от объёма журнала |
| Поиск сразу после появления новой записи | медиана 8 мс, 9 мс (p95) |
| Поиск предыдущей подстроки в том же журнале | `перевод` — 3,2 с, `银行转账` — 2,6 с, `verify-account.example` — 2,6 с |

| Поиск | Соответствующие записи | Наилучшее совпадение, медиана | p95 | Сначала самые новые, медиана |
| --- | --- | ---: | ---: | ---: |
| Распространённое слово, формы слова: `перевод` | 134 403 | 82 мс | 85 мс | 7 мс |
| Два слова: `оплата карта` | 28 996 | 43 мс | 43 мс | 14 мс |
| Редкое слово: `розыгрыш подарок` | 28 881 | 42 мс | 47 мс | 13 мс |
| Точная фраза: `"переказ коштів на картку"` | не учитывается | 35 мс | 36 мс | 6 мс |
| Домен с поддоменами: `verify-account.example` | 12 435 | 17 мс | 17 мс | 3 мс |
| @username: `@support_desk_bot` | 10 331 | 15 мс | 16 мс | 3 мс |
| Китайский без пробелов: `银行转账` | 17 691 | 23 мс | 24 мс | 3 мс |
| Японский: `リンク` | 16 603 | 23 мс | 25 мс | 3 мс |
| Английский корень: `withdrawal` | 27 775 | 26 мс | 26 мс | 2 мс |
| OR и исключения: `бонус OR подарок -казино` | 268 034 | 190 мс | 193 мс | 19 мс |
| Фильтр чата: `chat:-1000000000007 перевод` | 652 | 9 мс | 9 мс | 6 мс |
| Фильтр по периоду: `since:2026-01-01 until:2026-01-31 выплата` | 115 732 | 155 мс | 156 мс | 81 мс |

Точная фраза проверяется буквально по кандидатам в порядке ранжирования до тех пор, пока страница не заполнится, поэтому её итоговое значение не учитывается. Время обработки увеличивается с ростом количества совпадающих записей; сужение диалога или периода ускоряет широкий поиск. В синтетическом корпусе повторяется небольшой словарный запас, поэтому распространённые слова дают гораздо больше совпадений, чем в реальных диалогах.
