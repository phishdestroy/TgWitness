## Von gespeicherten Datensätzen zum gemeinsamen Bericht

[### Untersuchungen über alle Chats hinweg Führen Sie eine lückenlose Telegram-Untersuchung über Kanäle, Gruppen, private Chats und Bots hinweg durch: Erfassung des gesamten Kontos, Verlauf, Personen, Links, Dateien, Zeitachsen und verifizierte Beweise.](https://phishdestroy.github.io/TgWitness/de/docs/cases/)[### Erstellen Sie ein Case Board Sammeln Sie gespeicherte Beobachtungen, genaue Markierungen und Aktionsausschnitte auf einem privaten Board, besprechen Sie diese mit Ihrem Team und präsentieren Sie eine Zusammenstellung.](https://phishdestroy.github.io/TgWitness/de/docs/case-board/)[### Erstellen Sie einen Bericht Wählen Sie die Berichtsdaten, eines von acht Designs und den Inhalt aus, zeigen Sie dann eine Vorschau an und exportieren Sie HTML, ein signiertes PDF oder ein vollständiges Beweismittelpaket.](https://phishdestroy.github.io/TgWitness/de/docs/reports/)[### Bereiten Sie eine Kopie zur Weitergabe vor Wählen Sie die Datensätze und Felder aus, die ein Empfänger erhalten darf, prüfen Sie die fertige Kopie und verifizieren Sie das signierte Manifest sowie die Grenzen des Quelljournals.](https://phishdestroy.github.io/TgWitness/de/docs/handover/)[### Verwalten Sie eine Gruppe von Konten Vergleichen Sie Gruppen-Arbeitsbereiche, suchen Sie eine Quelle, überprüfen Sie Beobachtungszeiträume und wenden Sie gemeinsame Einstellungen mit Ausnahmen pro Konto an.](https://phishdestroy.github.io/TgWitness/de/docs/groups/)
