參考資料 / 存檔與整合功能

公開展示

透過會過期且可撤銷的連結，發佈所選公開頻道的已儲存訊息及經簽名的快照。

「存取 → 公開展示」會利用現有的 存取憑證系統，建立一個獨立的唯讀頁面。該頁面會讀取安裝程式中儲存的觀察記錄，但不會 為訪客啟動資料收集器、登入 Telegram 或取得頻道。

發佈頁面#

  1. 請為您想顯示的每個公開頻道儲存一個來源設定檔。該頻道必須 在其最新儲存的設定檔中擁有公開使用者名稱；群組和私人聊天室 則不符合資格。
  2. 開放存取 → 公開展示區（或 /showcase-manage.html）以管理員身分存取。
  3. 從最多 16 個工作區中選取頻道，輸入公開頁面的標題，並 選擇連結有效期為 1 天、7 天或 30 天。工作區內的標籤不會 對外公開。最多可包含 64 個頻道。
  4. 檢視選取頻道的文字內容以確認是否適合發布，然後點擊「預覽選取的 記錄」。此預覽功能採用與訪客頁面相同的伺服器端投影。
  5. 點擊「建立展示連結」。在連結顯示期間將其複製。請在 另一個瀏覽器中開啟該連結，於分享前預覽收件者的頁面。

該連結的 URL 片段中包含一個存取憑證。頁面在發出 API 請求前會移除該 片段，並將其換成瀏覽器會話。 任何持有該連結的人士皆可開啟所選內容，直至連結過期或被撤銷為止。 新連結允許 100 個同時連線，每個連線最長持續一小時。現有的 存取控制亦可透過 授權 API 實施網址限制與登入次數限制。一般審閱者的存取權限屬於不同模式，仍包含 原始允許的訊息與檔案。

訪客所見內容#

可見 設為私有
精選的公開頻道名稱、使用者名稱及個人檔案觀察日期 帳戶身分、內部工作區標籤及未選中的來源
擷取的文字及每次儲存的編輯內容 結構化的發送者 ID、姓名、使用者名稱、電話號碼及個人資料值
刪除記錄（如有）將附帶先前儲存的文字內容 附件、頭像、縮圖、檔案名稱及原始資料內容
標示作者／個人檔案或附件已被記錄的標記 轉發與回覆的元資料、網路路徑、IP 位址及憑證
選定頻道的事件計數、當前收集開關、心跳訊號與檢查點間隔 資料集控制功能與標準證據匯出 API
簽名指紋、日誌檢查點與一致性證明 簽名金鑰與 Telegram 連線

公開訊息的文字內容不會自動匿名化。訊息中寫入的姓名、提及、電話 號碼或連結仍會保留在該文字內容中。 Redacted此規則適用於結構化的作者／個人資料欄位。發布前請檢視實際選取的內容， 包括保留的編輯與刪除部分。

「符合資格」反映的是最新儲存的來源設定檔，而非即時查詢 Telegram 的結果。 若後續的設定檔中已無該公開頻道的使用者名稱，新的請求 將排除該頻道。當公開可見性發生變更時，請重新整理來源設定檔。 讀者可能已經儲存了先前收到的內容。

原始的簽名記錄保持不變。顯示的投影會 另行簽名，並包含指向原始記錄的雜湊值。投影 簽名用於驗證顯示的內容；它並非原始事件 對經刪節字節所做的簽名。

檢查簽名與連續性#

展開「指紋與簽名檢查點」，並下載快照。頁面 重新整理後，下載內容將包含先前的瀏覽器快照，以及兩者日誌邊界之間的一份 Merkle 一致性證明。當頁面可見且顯示其第一頁觀察記錄時，系統會每 分鐘自動重新整理一次。

安裝 TgWitness 後，請在離線狀態下驗證下載的檔案：

python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256

指紋必須來自一個獨立的可信參考來源。若要與 您自行保留的快照進行比對，請使用 --previous earlier.json；此操作將覆寫 下載檔案中內嵌的先前快照。當前的證明必須從 該保留的邊界開始。經認證的客戶端可透過 GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>。 若日誌較短，系統將返回 HTTP 409 狀態碼，而非靜默重設邊界。

已簽名的檢查點會提交至整個收集器日誌，包括其 記錄數量與不透明的頭部雜湊值。顯示的訊息數量僅適用於 選定的公開頻道。該頁面絕不會列出其他日誌的內容。 這些是事件數量，而非唯一訊息數量。設定描述的是 當前配置，而非每個較早的記錄區間。

簽名與一致性驗證可偵測相對於保留 邊界所發生的變更。它不會獨立重新計算已簽名的計數器、認證 Telegram 來源、證明擷取過程未中斷，亦不會取代獨立見證人。 若需進行此類審查，請使用證據驗證器、 獨立見證人及經規模測試的記錄。 模擬安裝會明確標示為「模擬」。

撤銷或託管該頁面#

請在展示管理員中使用「撤銷」功能，或透過現有的「存取權限」區段來關閉 該連結並終止所有相關連線。當系統偵測到存取已結束時， 訪客將清除已顯示的記錄。每次 請求時都會檢查有效期限與權限。展示權限無法直接轉換為一般面板存取權； 請建立新的權限以變更模式。

透過安裝環境現有的 HTTPS 網址提供此頁面。發佈 連結不會開啟新埠、建立隧道或變更 DNS。HTML 及 API 仍保留在用戶的安裝環境中。展示網站的訪客無法透過此存取權限使用一般的 訊息、個人檔案、媒體、匯出或管理 API。

python tools/check_showcase.py
python tools/check_showcase_browser.py

兩者皆使用合成記錄及本機 HTTP 伺服器，且不會連線至 Telegram。
