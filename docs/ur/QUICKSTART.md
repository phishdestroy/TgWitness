# TgWitness: فوری آغاز

TgWitness ایک خود مختار ایپلیکیشن ہے جس سے آپ اُن Telegram گروپس اور چینلز کا مشاہدہ کرتے ہیں
جن تک آپ کے اکاؤنٹس کی رسائی ہے۔ یہ اپنی الگ ڈیٹا ڈائریکٹری کے ساتھ مقامی طور پر چلتی ہے۔

**پہلی بار آئے ہیں؟** اکاؤنٹ منسلک کرنے سے پہلے [ڈیمو دیکھیں](#explore-the-interface)۔
پراکسی، گواہوں، ایکسپورٹس یا سرور سیٹ اپ کے لیے [رہنما منتخب کریں](../README.md)۔
[GitHub Actions کیپچر](../SEALED-ACTIONS.md) (پیش نظارہ) مقامی انسٹالیشن کے بجائے آپ کے اپنے
GitHub فورک میں کیپچر چلاتا ہے۔

<a name="install-and-start"></a>

## انسٹال کریں اور شروع کریں

رہنمائی والے انسٹالر میں اپنا Python شامل ہے، اور یہ انسٹال کرنے سے پہلے پیکیجز کے ہیش اور ریلیز
کے دستخط جانچتا ہے۔ اسے دوبارہ چلانے سے موجودہ انسٹالیشن اپ ڈیٹ ہو جاتی ہے۔

**Linux / macOS:**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**Windows (PowerShell یا Command Prompt):**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

Ubuntu سرور پر بیک گراؤنڈ سروس انسٹال کرنے کے لیے اسے root کے طور پر چلائیں؛ ڈیسک ٹاپ پر اپنے
عام صارف کے طور پر چلائیں۔ Ubuntu پر انسٹالر پینل کا پتہ اور رسائی کی کلید دکھاتا ہے؛ macOS اور
Windows پر مقامی پینل آپ کے براؤزر میں کھل جاتا ہے۔ نیچے **Telegram جوڑیں** سے آگے بڑھیں۔
[انسٹال، تصدیق اور اپ ڈیٹ](../INSTALLATION.md) میں سرور تک رسائی کے اختیارات، چلانے سے پہلے
اسکرپٹ کی جانچ، اپ ڈیٹس اور ہٹانے کا طریقہ بیان کیا گیا ہے۔

### دیگر طریقے

GitHub ریلیزز، سورس کوڈ اور Docker انسٹالر کے متبادل ہیں۔ پورٹیبل ڈاؤن لوڈز ریلیز بلڈ شائع
ہونے کے بعد دستیاب ہوتے ہیں:

| ہوسٹ | کچھ بھی انسٹال کیے بغیر | سورس سے: Python 3.11+ | Docker: Compose 2.20+ کے ساتھ Engine/Desktop |
| --- | --- | --- | --- |
| Windows | GitHub Releases سے `TgWitness-<version>-windows-amd64-portable.zip` نکالیں، `TgWitness.cmd` پر ڈبل کلک کریں | `Start.cmd` پر ڈبل کلک کریں | `scripts\Docker.cmd` پر ڈبل کلک کریں |
| Linux / macOS | — | `sh start.sh` | `sh scripts/docker-start.sh` |

سورس والے طریقوں کے لیے [موجودہ `main` ڈاؤن لوڈ کر کے نکالیں](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip)
یا ریپوزیٹری کلون کریں:

```sh
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

اگر کوئی موزوں Python نہ ملے تو `Start.cmd` آپ کے Windows صارف کے لیے Python 3.12 انسٹال کرنے
کی پیشکش کرتا ہے (winget کے ذریعے، یا python.org کے دستخط شدہ انسٹالر سے)۔ Python موجود نہ ہو تو
`start.sh` آپ کی Linux ڈسٹری بیوشن یا macOS کے لیے انسٹال کی درست کمانڈ دکھاتا ہے۔ سورس سے پہلی
بار چلانے پر `.venv` بنتا ہے اور ڈیپنڈنسیز خودکار طور پر انسٹال ہو جاتی ہیں۔

Docker ایپلیکیشن کو بلڈ کر کے پس منظر میں شروع کرتا ہے؛ ہوسٹ پر Python کی ضرورت نہیں۔ جب کنٹینر
صحت مند حالت میں آ جائے تو `scripts\Docker.cmd` اور `scripts/docker-start.sh` پینل کا پتہ اور ٹوکن
دکھاتے ہیں۔ ہر معاون ہوسٹ پر ان کے مساوی Docker کمانڈز یہ ہیں:

```sh
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

**http://127.0.0.1:8787** کھولیں۔ Docker ہیلپر یا دوسری Docker کمانڈ کا دکھایا ہوا ٹوکن استعمال
کریں، یا پورٹیبل یا سورس انسٹالیشن کے لیے **data/live/panel-token.txt** پڑھیں۔ نیچے
**Telegram جوڑیں** سے آگے بڑھیں۔ نیٹو اور Docker انسٹالیشنز الگ الگ اسٹوریج استعمال کرتی ہیں؛
Docker شروع کرنے سے موجودہ نیٹو جرنل امپورٹ نہیں ہوتا۔

سرور کے لیے [تعیناتی کی رہنما](DEPLOYMENT.md) خودکار HTTPS، ری اسٹارٹ، شائع شدہ امیجز، اپ ڈیٹس
اور بیک اپس کا احاطہ کرتی ہے۔

<a name="explore-the-interface"></a>

## انٹرفیس دیکھیں

1. پورٹیبل پیکیج میں **TgWitness-Demo.cmd**، Windows سورس فولڈر میں **scripts\Demo.cmd**، یا
   Linux/macOS پر `sh start.sh --demo` چلائیں۔ سورس سے چلانے پر پہلے `.venv` بنتا ہے اور
   ڈیپنڈنسیز انسٹال ہوتی ہیں۔
2. **http://127.0.0.1:8787** کھولیں۔
3. مقامی ڈیمو نمونے کا جرنل خود بخود کھول دیتا ہے۔ براہِ راست مقامی رسائی کے لیے ٹوکن کاپی کرنے کی ضرورت نہیں۔

ڈیمو کے پیغامات فرضی ہیں۔ ڈیمو موڈ کسی حقیقی Telegram اکاؤنٹ سے منسلک نہیں ہو سکتا۔

## Telegram جوڑیں

> [!WARNING]
> **اسی کام کے لیے مخصوص اکاؤنٹس استعمال کریں۔** کلائنٹ کوئی بھی ہو، Telegram درخواستوں کی اُس
> مقدار پر جسے وہ حد سے زیادہ سمجھے، اکاؤنٹس کو محدود یا مستقل طور پر بین کر سکتا ہے۔ ذاتی یا
> قیمتی اکاؤنٹس کے بجائے مشاہدے کے لیے تیار کیے گئے اکاؤنٹس منسلک کریں، اور API ID / ہیش بھی
> ایسے ہی مخصوص اکاؤنٹ پر بنائیں۔

1. اگر نیٹو ڈیمو چل رہا ہے تو اسے روک کر **Start.cmd** یا `sh start.sh` چلائیں۔
   ورنہ اوپر شروع کی گئی لائیو انسٹالیشن کو چلتا رہنے دیں۔
2. سائن ان کے لیے پینل ٹوکن استعمال کریں۔ نئی ورک اسپیس میں [ابتدائی سیٹ اپ](../SETTINGS.md) کھلتا ہے۔
   **صرف ڈاؤن لوڈ**، **چیٹس پر نظر رکھیں** یا **کیس کے لیے ثبوت** منتخب کریں۔
3. کنیکشن چیک کا نتیجہ دیکھیں۔ ضرورت ہو تو اپنی پراکسی ترتیب دیں؛ کنیکشن کی ترتیبات
   سیٹ اپ کے بعد بھی دستیاب رہتی ہیں۔
4. **ٹیلیگرام جوڑیں** والی اسکرین پر QR کوڈ اسکین کریں یا اپنا فون نمبر درج کریں۔ فائل امپورٹ
   اور مکمل اتھارائزیشن کلید **سائن ان کے دوسرے طریقے** کے تحت ہیں۔
   طلب کیے جانے پر Telegram کی تصدیق، کوڈ اور دو مرحلوں والا پاس ورڈ مکمل کریں۔
5. دکھایا گیا اکاؤنٹ چیک کریں، چیٹس منتخب کریں اور اپنی ترتیبات کا جائزہ لیں۔ آخری اسکرین سے
   سیٹ اپ مکمل کریں۔ **صرف ڈاؤن لوڈ** کے لیے **ایکسپورٹ شروع کریں** ایک بار کا ایکسپورٹ شروع
   کرتا ہے اور اس کی پیش رفت دکھانے کے لیے ایکسپورٹس کا حصہ کھولتا ہے؛ یہ مسلسل مشاہدہ فعال نہیں کرتا۔

سیٹ اپ کے بعد **چٹس → منتخب کریں** سے منتخب چیٹس بدلی جاتی ہیں۔ **سیٹنگز** جمع آوری اور
فائلوں کو کنٹرول کرتی ہیں؛ **مزید اوزار → ماخذ** معیاری یا ماہر سطح پر ماخذوں کی تفصیلی فہرست
دیتا ہے۔ [پینل گائیڈ](../PANEL.md) چھ مرکزی حصوں اور ان کے سیاق کے مطابق کنٹرولز کی وضاحت کرتی ہے۔

**API آئی ڈی + ہیش** اختیاری ہے: ورک اسپیس اپنی محفوظ یا امپورٹ کی گئی جوڑی استعمال کرتی ہے،
یا بلٹ اِن پول کی کوئی کارآمد جوڑی۔ اپنی ایپ استعمال کرنے کے لیے API شناختی کے خانے میں ایک
`API ID:API Hash` جوڑی پیسٹ کریں۔ **آتھ کی** کے لیے تمام 512 ہیکساڈیسیمل
حروف پیسٹ کریں اور فراہم کردہ ڈی سی آئی ڈی منتخب کریں۔ صارف کی شناخت اختیاری ہے اور درج کرنے پر جانچی جاتی ہے۔

API کی اسناد آپ کی ایپلیکیشن کی شناخت کرتی ہیں؛ یہ بذاتِ خود کسی اکاؤنٹ کی اتھارائزیشن
نہیں کرتیں۔ نجی گروپس کے لیے عوامی یوزر نیم ضروری نہیں، لیکن آپ کے اکاؤنٹ کو ان تک رسائی حاصل ہونی چاہیے۔

موجودہ اکاؤنٹس کے لیے [اکاؤنٹس اور سیشن فارمیٹس](../ACCOUNTS.md) دیکھیں: پینل Telethon
StringSession، Telethon/Pyrogram SQLite، ایک اکاؤنٹ والی TData ZIP اور معاون اکاؤنٹ JSON
قبول کرتا ہے۔ سیشن اور اس کے ساتھ والی JSON ایک ساتھ منتخب کریں اور
**اکاؤنٹ سے جڑیں** دبائیں۔ QR لاگ ان بھی انہی اختیاری API ترتیبات کے ساتھ
دستیاب ہے۔ TDLib، بوٹ سیشنز اور CSV/JSON اکاؤنٹ فہرستیں معاون نہیں ہیں۔

کئی اکاؤنٹس کے لیے **اکاؤنٹس → اکاؤنٹس درآمد کریں** استعمال کریں اور ان کی معاون سیشن فائلیں
منتخب کریں۔ ساتھ والی JSON فائلیں فائل کے بنیادی نام سے جوڑی جاتی ہیں؛ ہر امپورٹ کیے گئے اکاؤنٹ
کو اپنی الگ ورک اسپیس ملتی ہے۔ [بلک امپورٹ اور اکاؤنٹ گروپس](../ACCOUNTS.md#bulk-import-and-account-groups) دیکھیں۔

ایک اور اکاؤنٹ شامل کرنے کے لیے اکاؤنٹ سلیکٹر کے ساتھ **+** دبائیں یا
**اکاؤنٹس → اکاؤنٹ شامل کریں** استعمال کریں۔ ہر ورک اسپیس کے سیشنز، جرنلز، کلیدیں، ماخذ اور
قطاریں الگ ہوتی ہیں۔ ویو بدلنے سے دوسرے جمع کنندگان چلتے رہتے ہیں۔
اس انسٹالیشن میں ایک ہی Telegram اکاؤنٹ دو ورک اسپیسز کو تفویض نہیں کیا جا سکتا۔
ورک اسپیسز کی کوئی مقررہ تعداد نہیں؛ یہ ایک ہی پروسیس میں چلتی ہیں، اس لیے گنجائش مشین پر منحصر ہے۔

لائیو پینل ٹوکن آپ کی Telegram اتھارائزیشنز اور محفوظ کردہ مواد تک رسائی کی حفاظت کرتا ہے؛
یہ Telegram API کی اسناد سے الگ ہے۔ خودکار داخلہ صرف اُس مقامی ڈیمو کو ملتا ہے جو واضح طور پر
شروع کیا گیا ہو اور جسے براہِ راست کھولا گیا ہو۔ ریموٹ یا پراکسی کے ذریعے کھولا گیا ڈیمو پھر بھی
`data/demo/panel-token.txt` استعمال کرتا ہے۔

## جائزہ اور ایکسپورٹ

- **جرنل:** مشاہدات کو ماخذ اور ایونٹ کی قسم کے لحاظ سے تلاش اور فلٹر کریں۔
- کسی ایونٹ کو منتخب کر کے اس کا اصل ریکارڈ، انتساب اور محفوظ ورژنز دیکھیں۔
- ترمیم کی تفصیلات میں پہلے/بعد کا دستیاب مواد دکھایا جاتا ہے۔ حذف کی تفصیلات میں آخری بار
  محفوظ کیا گیا مواد، اگر ہو، دکھایا جاتا ہے؛ نامعلوم فاعل نامعلوم ہی رہتا ہے۔
- **ایکسپورٹس:** دستخط شدہ ZIP، JSONL، CSV اور آف لائن HTML۔
- **مکمل چیٹ کی برآمد** (**چٹس → چٹ کی برآمد**، یا **ایکسپورٹس → ایک چیٹ کیپچر یا ایکسپورٹ کریں**):
  کسی ایک چیٹ کی پوری نظر آنے والی تاریخ ایک دستخط شدہ بنڈل کے طور پر ڈاؤن لوڈ کریں، جس میں
  `chat.json` (Telegram ایکسپورٹ کے انداز میں) اور پڑھنے کے قابل `chat.html` شامل ہوتے ہیں۔ نجی
  چیٹس بھی کام کرتی ہیں بشرطیکہ اکاؤنٹ ان کا رکن ہو۔ یہ موجودہ حالت کا اسنیپ شاٹ ہے، حذف شدہ یا
  پہلے ترمیم شدہ پیغامات کی بازتعمیر نہیں۔ کاپی کی تصدیق
  `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256` سے کریں۔
- **چیک پوائنٹ محفوظ کریں:** دستخط شدہ جرنل کی حد کو جمع کنندہ سے باہر محفوظ رکھیں۔
- **دستیاب شدہ رن رسید ڈاؤن لوڈ کریں:** جمع کنندہ کے پروگرام/ورژن کا ریکارڈ محفوظ کریں۔
- **ٹائم اسٹیمپ کی درخواست تیار کریں:** ٹائم اسٹیمپ اتھارٹی کے لیے آف لائن درخواست تیار کریں؛
  جواب حاصل کرنے اور اس کی تصدیق کے لیے [TIMESTAMP.md](../TIMESTAMP.md) پر عمل کریں۔
- **جرنل کی تصدیق کریں:** ایونٹس کے دستخط اور زنجیر کے روابط جانچیں۔ ZIP ایکسپورٹ میڈیا بھی جانچتا ہے۔

معاون براؤزر بڑے ایکسپورٹس براہِ راست منتخب فائل میں محفوظ کرتے ہیں۔ دوسرے براؤزر زیادہ سے زیادہ
128 MiB بفر کرتے ہیں۔ جب تک سرور چل رہا ہو، اسٹریمنگ CLI پورا جواب بفر کیے بغیر بڑی
ڈاؤن لوڈز ممکن بناتی ہے:

```sh
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

دوسری ورک اسپیس کے لیے **ایکسپورٹس → ورک اسپیس آئی ڈی** سے لے کر `--profile ID` شامل کریں۔
ریموٹ سرور کے لیے `--url https://your-server` شامل کریں۔ ٹرانسفر کی طے شدہ حد
5 GiB ہے؛ `--max-mib` اسے بدلتا ہے۔ دستخط شدہ ZIP کے مواد کی تصدیق کے لیے بطورِ طے شدہ غیر کمپریسڈ
حجم کی الگ حد 4 GiB ہے (**مزید اوزار → پیرامیٹرز** اسے بڑھاتا ہے؛ ایسے آرکائیوز کی تصدیق
`verify.py --max-gib N` سے کریں)۔ آرکائیو کی تصدیق ویریفائر کی قابلِ اعتماد کاپی، آزادانہ طور پر
محفوظ رکھے گئے کلید کے فنگر پرنٹ اور — ثبوت کے لیے کم از کم ضرورت کے طور پر — ٹائم اسٹیمپ
اتھارٹی کے روٹ سرٹیفکیٹ (`--tsa-ca`) کے ساتھ کریں۔

## انسٹالیشن جانچیں

```sh
python start.py --setup-only
python start.py --check
python start.py --check --json
```

`--check` مقامی ڈیپنڈنسیز، دستخط کی سہولت، اسٹوریج، کلید کی ترتیب اور سننے والے پتے کو جانچتا ہے۔
یہ نہ کچھ انسٹال کرتا ہے اور نہ Telegram سے جڑتا ہے۔ پورٹ مصروف ہو تو ممکن ہے کوئی اور انسٹینس
چل رہا ہو۔ کوئی دوسرا `--port` استعمال کریں یا پہلے اسے روک دیں۔

لانچر `.venv` میں انسٹال کرتا ہے۔ معاون `python -m tgwitness...` کمانڈز کو Windows پر
`.venv\Scripts\python.exe` اور Linux/macOS پر `.venv/bin/python` سے چلانا ضروری ہے،
الا یہ کہ وہ ماحول پہلے سے فعال ہو۔

## سیشنز، تحفظ اور آپریشن

بند اور ہم آہنگ حالت والی Telethon SQLite `.session` کو
`python -m tgwitness.sessions account.session --out account.tgwitness-session` سے مقامی طور پر
تبدیل کیا جا سکتا ہے، پھر **مزید اوزار → اکاؤنٹ → فائلیں** میں لوڈ کیا جا سکتا ہے۔ براہِ راست فائل
امپورٹ اور QR لاگ ان بھی دستیاب ہیں۔ لاگ ان فارمیٹس، SOCKS5، HTTP CONNECT، MTProxy اور بیرونی
ماسٹر کلیدوں کے لیے [CONNECTION-SECURITY.md](../CONNECTION-SECURITY.md) دیکھیں۔

**مشاہدے کو معطل کریں** جمع آوری روک دیتا ہے۔ **لاک** صرف براؤزر کی رسائی بند کرتا ہے۔
ٹیب بند کرنے سے جمع کنندہ کا پروسیس چلتا رہتا ہے۔ پروسیس روکنے سے جمع آوری منقطع ہو جاتی ہے؛
ہسٹری کا اسنیپ شاٹ چھوٹ جانے والی تمام ترامیم یا حذف کو دوبارہ تشکیل نہیں دے سکتا۔
ایونٹ پالیسیوں، اٹیچمنٹ قطاروں، اکاؤنٹس کی علیحدگی اور ری اسٹارٹ کے رویے کے لیے
[جمع آوری کیسے کام کرتی ہے](../COLLECTION.md) دیکھیں۔

سیشنز اور خفیہ معلومات انکرپٹڈ رہتی ہیں۔ پیغامات کے مواد، میڈیا اور ایکسپورٹس کے لیے انکرپٹڈ
ڈسک یا والیوم درکار ہے۔ جرنل کے دستخطوں کی تصدیق کسی قابلِ اعتماد کلید سے کریں اور چیک پوائنٹس الگ محفوظ رکھیں۔
منتخب جمع آوری موڈ کے لیے کیپچر ریکارڈز، بیرونی وقت کی رسیدوں اور ماحول کی تصدیقات کا جائزہ لیں۔
