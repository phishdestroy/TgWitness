Dedicated account

Keep collection separate from personal chats. A separate account can still face Telegram restrictions.

Before connecting

  • Keep control of the phone number used for registration.
  • Enable two-step verification and add a recovery email.
  • Review active sessions in Telegram Settings → Devices.

API credentials

The API ID and hash identify the application. Your Telegram authorization is separate.

For the GitHub capture workflow, use your own API ID and hash.

Create API credentials

Imported sessions

Do not run the same imported authorization in two clients at once. Telegram may revoke it with AUTH_KEY_DUPLICATED. For parallel use, create a separate login by phone or QR.

Connect the account

  1. Open the panel and choose phone or QR login.
  2. Complete Telegram verification and select your sources.
  3. Start collection and check that new messages appear.

Phone numbers
