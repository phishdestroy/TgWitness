# Подключение аккаунта

Canonical page: https://phishdestroy.github.io/TgWitness/ru/docs/accounts/

Одно рабочее пространство содержит одну учетную запись, её журнал и ключ подписи.

## Выберите способ входа

Откройте **учетные записи**, добавьте рабочую область и откройте её настройки подключения. Для наблюдения используйте отдельную учетную запись.

- **QR-код:** отсканируйте его в настройках устройства в Telegram и подтвердите новый вход в систему.
- **Номер телефона:** введите номер, код, отправленный Telegram, а также пароль двухэтапной аутентификации, если она включена.
- **Импорт сеанса:** импортируйте поддерживаемый сеанс или принадлежащие вам данные Telegram Desktop.

Выберите встроенный профиль API или введите свой собственный идентификатор API и хеш. Профиль API идентифицирует клиента; он не осуществляет вход в учётную запись и не обеспечивает анонимность соединения.

**Вам сначала нужен прокси-сервер?**

Вы можете [выбрать и протестировать маршрут подключения](https://phishdestroy.github.io/TgWitness/ru/docs/proxies/) перед входом в систему. У каждой учетной записи есть свой собственный маршрут.

## Выберите, что следует отслеживать

1. Откройте список источников и выберите нужные вам чаты, группы или каналы.
2. Перед началом наблюдения ознакомьтесь с настройками сбора данных, включая мультимедиа.
3. Запустите сборщик данных и проверьте его подключение, а также недавнюю активность.

Учётная запись должна иметь доступ к источнику. Различные роли могут видеть разные события; журнал отражает то, что получила данная учётная запись.

Для расследования, охватывающего весь аккаунт, воспользуйтесь **меню «Источники» → «Область наблюдения» → «Режим расследования**», проверьте настройки и нажмите **«Сохранить область**». [Полное руководство по расследованию](https://phishdestroy.github.io/TgWitness/ru/docs/cases/) охватывает все видимые типы чатов, старую историю, профили пользователей, перекрестные ссылки между чатами и передачу доказательств.

## Проверьте весь путь

В тестовой группе, которую вы контролируете, отправьте уникальное сообщение с другого аккаунта, отредактируйте его и удалите. Подтвердите все три события в журнале, затем [экспортируйте и проверьте](https://phishdestroy.github.io/TgWitness/ru/docs/exports/) запись.

Статус «подключено» подтверждает наличие соединения. Зафиксированное тестовое сообщение подтверждает, что конкретное событие поступило в данную рабочую среду.

## Добавить ещё один аккаунт

Создайте ещё одну рабочую область в **разделе «Учётные записи»** и повторите настройку. Сохраните отпечаток ключа подписи каждой учётной записи, чтобы впоследствии вы могли идентифицировать экспортные данные.
