# ስለ ፈቃድና ስለ ሥነ ሕንፃ አለመጣጣም ማስታወቂያ

Canonical page: https://phishdestroy.github.io/TgWitness/am/docs/reference/license/

TgWitness በMIT ፈቃድ ለሁሉም ይቀርባል፤ ከTaylor Wessing የሥራ ሂደት ጋር በሥነ ሕንፃው ለምን እንደማይጣጣምም ያብራራል።

TgWitness በ[MIT ፈቃድ](https://phishdestroy.github.io/TgWitness/LICENSE) ሥር ይሰራጫል። የእኛ አቋም በፈቃዱ ላይ ምንም ተጨማሪ ሁኔታ አይጨምርም።

> ፊርማ ውሸትን ወደ እውነታ አይቀይረውም።

>

>
> የሥራ ሂደታችሁ ደንበኛው ከከፈለበት ድምዳሜ ተነስቶ መዝገቡ ያንን እንዲከተል የሚጠይቅ ከሆነ፣ ሌላ መሣሪያ መፈለግ አለባችሁ። TgWitness የተፈጠረው መዝገቡን ለመጠበቅና ለምርመራ ክፍት ለማድረግ ነው።
