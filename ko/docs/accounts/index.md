# 계정 연결

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/accounts/

작업 공간 하나 = 계정 하나, 그 저널과 키.

## 로그인 방법 선택

**계정** → 작업 공간 추가 → 연결 설정. 이 용도로는 별도의 계정을 사용하십시오.

- **QR 코드:** 텔레그램의 기기 화면에서 스캔하고 확인합니다.
- **전화번호:** 번호, 코드, 그리고 있다면 2단계 인증 비밀번호.
- **세션 가져오기:** 귀하의 세션 파일 또는 Telegram Desktop 데이터.

기본 제공 API 프로필이나 자체 API ID와 해시를 사용합니다. 앱을 식별할 뿐이며, 로그인시켜 주거나 무언가를 숨기지는 않습니다.

**먼저 프록시가 필요하신가요?**

로그인하기 전에 [연결 경로를 선택하고 테스트해 볼](https://phishdestroy.github.io/TgWitness/ko/docs/proxies/) 수 있습니다. 각 계정마다 고유한 경로가 있습니다.

## 관찰 대상 선택

1. 필요한 채팅, 그룹 또는 채널을 고릅니다.
2. 미디어를 포함한 수집 설정을 확인합니다.
3. 시작한 후 연결과 최근 활동을 확인합니다.

계정에 접근 권한이 있어야 합니다. 관리자와 멤버는 보는 것이 다르며, 저널은 이 계정이 받은 것을 보여 줍니다.

계정 전체라면? **소스 → 관찰 범위 → 조사 모드**를 확인하고 **범위 저장**. 전체 안내: [계정 전체 조사하기](https://phishdestroy.github.io/TgWitness/ko/docs/cases/).

## 전체 경로 확인

테스트 그룹에서 다른 계정으로 메시지를 보내고, 편집하고, 삭제합니다. 세 가지 모두 저널에 나타나야 합니다. 그런 다음 [내보내고 검증](https://phishdestroy.github.io/TgWitness/ko/docs/exports/)하십시오.

"연결됨"은 연결이 작동한다는 뜻입니다. 테스트 메시지가 기록되면 이벤트가 실제로 도착한다는 뜻입니다.

## 계정 추가

**계정**에서 새 작업 공간을 만들고 같은 단계를 따릅니다. 나중에 내보내기를 구별할 수 있도록 각 계정의 키 지문을 적어 두십시오.
