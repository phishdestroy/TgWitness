# Telegram · เลือกพร็อกซี

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/proxies/

ให้บัญชีออนไลน์อยู่เสมอ และตัดสินใจเองว่าจะให้แสดง IP ของเซิร์ฟเวอร์ได้หรือไม่

## เลือกโหมด IP ก่อน

01**ซ่อนที่อยู่**

พร็อกซีเท่านั้น หากไม่มีตัวไหนใช้ได้ ก็จะรอ

02**ใช้ Direct เป็นทางเลือกสุดท้าย**

เชื่อมต่อตรงหลังหน่วงเวลา แล้วกลับไปใช้พร็อกซีเมื่อมีตัวที่ใช้ได้

03**เซิร์ฟเวอร์ที่อยู่หลังทูนเนลหรือ VPN**

เชื่อมต่อตรงได้ ไม่ได้ตั้งค่าหรือตรวจ VPN ให้คุณ

เส้นทางจะกำหนดการเชื่อมต่อ โหมด IP จะกำหนดว่าอนุญาตให้มีการเชื่อมต่อโดยตรงหรือไม่

## ให้ pool เป็นผู้ดูแลเส้นทาง

1. **บัญชี → การตั้งค่า → การตั้งค่าการเชื่อมต่อ**
2. เลือกโหมด IP และ **MTProxy อัตโนมัติ** หรือเส้นทางคงที่
3. บันทึก แล้ว **ทดสอบการเชื่อมต่อ Telegram** (ใช้ได้ก่อนเข้าสู่ระบบด้วย)
4. เริ่มเก็บข้อมูลและส่งข้อความทดสอบถึงตัวเอง

พื้นที่ทำงานใหม่เริ่มด้วย MTProxy อัตโนมัติและ **ซ่อนที่อยู่** พูลดึงรายการสาธารณะสี่รายการ ตรวจเซิร์ฟเวอร์ เก็บตัวที่ดีไว้และสลับตัวที่ตายออก

## ใช้พร็อกซีของคุณเอง

SOCKS5, HTTP CONNECT ลิงก์พร็อกซี Telegram หรือแค็ตตาล็อกของผู้ให้บริการ หยุดการสังเกตชั่วคราวก่อนสลับ ความลับ Fake TLS (`ee`…) ใช้ไม่ได้

**การตั้งค่าการหมุนเวียน การแชร์ และการลองใหม่**

**พารามิเตอร์ → MTProxy อัตโนมัติ**: เกณฑ์ความล้มเหลว ช่วงพัก การหมุนเวียน จำนวนบัญชีต่อพร็อกซี ขีดจำกัด 1 หมายถึงบัญชีจะรอแทนการใช้ร่วมกัน พร็อกซีต่างกันก็ยังอาจใช้ IP ขาออกเดียวกันได้

## แยก Telegram ออกจากคำขอจากภายนอก

MTProxy รับส่งเฉพาะ Telegram การประทับเวลา การแจ้งเตือน สำเนา และการตรวจโค้ด จะผ่านพร็อกซี SOCKS5/HTTP แยก เส้นทาง SOCKS5/HTTP ของบัญชี หรือเชื่อมต่อตรงหากโหมดอนุญาต หรือปิดไปเลย

`TGWITNESS_PROXY_FEED_PROXY` กำหนดเส้นทางสำหรับดาวน์โหลดรายการ [พยาน](https://phishdestroy.github.io/TgWitness/th/docs/witness/) มีการตั้งค่าของตัวเอง ทั้งหมดนี้ไม่แตะเบราว์เซอร์หรือเครือข่ายระบบของคุณ
