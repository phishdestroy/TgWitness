Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/reports/

قاری کو کیس کے سوال سے سیدھا محفوظ ریکارڈز تک لے جائیں۔

Report studio آپ کا منتخب ڈیٹا، تبدیلیوں کی تاریخ، چارٹس اور آپ کے نتائج یکجا کرتا ہے۔ آٹھ ڈیزائن، HTML اور مقامی PDF۔ ہر HTML، PDF اور JSON رپورٹ آپ کی کلید سے مہر بند ہوتی ہے۔

## تین مراحل میں رپورٹ بنائیں

1. **ایکسپورٹس ← کنفیگر اور پیش نظارہ ← ڈیٹا**: پوری ورک اسپیس، یا چیٹس، مصنفین، تاریخیں (UTC، جب TgWitness نے ریکارڈ دیکھا) اور ریکارڈ کی اقسام چنیں۔
2. **ڈیزائن اور مواد**: ڈیزائن اور اس میں کیا جائے چنیں: چارٹس، شرکاء، ٹرانسکرپٹ، تبدیلیاں، Case Board آئٹمز، کیس کی تفصیلات اور نوٹس۔
3. **پیش نظارہ**: تعداد، سرگرمی، نمونے اور غائب ID رینجز جانچیں۔ محفوظ کریں، پھر ضرورت کا فارمیٹ ڈاؤن لوڈ کریں۔

### قاری کے لیے اسی محفوظ شدہ مواد کو ترتیب دیں

مصنوعی مثال · خاکہ جاتی ترتیب، تیار شدہ رپورٹ نہیں

1. **منتخب کریں۔** دو چیٹس اور کیس کے لیے مشاہداتی مدت منتخب کریں۔
2. **تخلیق کریں۔** ایک لے آؤٹ اور وہ سیکشن منتخب کریں جو سوال کا جواب دیتے ہوں۔
3. **پریویو۔** منتخب شدہ تعداد اور محفوظ شدہ پہلے اور بعد کے متن کا جائزہ لیں۔
4. **تصدیق کریں۔** حتمی فائل تیار کریں اور اس کے دستخط کو قابلِ اعتماد ورک اسپیس فنگر پرنٹ کے خلاف چیک کریں۔

## پڑھنے کا انداز منتخب کریں

**Classic, Editorial, Briefing, Analytics, Technical, Overview, Reading series, and Ledger & margin**: وہی ریکارڈز، مختلف شکل۔ بدلنے سے انتخاب اور نوٹس برقرار رہتے ہیں۔ 25 زبانوں میں سے کوئی بھی۔

PDF ساتھ آنے والے فونٹس سے بنتی ہیں، براؤزر کی ضرورت نہیں۔ چینی، جاپانی اور کوریائی کے لیے سرور پر Noto Sans CJK جیسا فونٹ چاہیے (پورے سسٹم میں یا `TGWITNESS_FONT_DIR` میں)، ورنہ صرف HTML اور JSON ملتے ہیں۔

## اپنے سیاق و سباق کے ساتھ تبدیلی کو پڑھیں

ترامیم پہلے اور بعد دکھاتی ہیں، حذف آخری محفوظ ورژن۔ جوابات، فارورڈز، ردعمل، بٹن اور اٹیچمنٹس اپنے حوالے برقرار رکھتے ہیں۔

ڈیزائن کا پیش نظارہ پہلے 50,000 ریکارڈز استعمال کرتا ہے، ڈیٹا کا پیش نظارہ سب کچھ درست گنتا ہے۔ حتمی صفحہ ترتیب کے لیے PDF بنائیں۔

## موصول کنندہ کی کاپی جان بوجھ کر منتخب کریں

فلٹرز صرف رپورٹ کی شکل بناتے ہیں، ثبوت ZIP میں پھر بھی پورا جرنل اور فائلیں ہیں۔ اگر وصول کنندہ کو کم ملنا چاہیے تو [مختصر حوالگی](https://phishdestroy.github.io/TgWitness/ur/docs/handover/) استعمال کریں۔ مزید: [رپورٹ کا مواد](https://phishdestroy.github.io/TgWitness/ur/docs/reference/case-reports/)، [ایکسپورٹ کی تصدیق](https://phishdestroy.github.io/TgWitness/ur/docs/exports/)۔
