# Telegram · Sambungkan akaun

Canonical page: https://phishdestroy.github.io/TgWitness/ms/docs/accounts/

Satu ruang kerja = satu akaun, jurnalnya dan kuncinya.

## Pilih cara untuk log masuk

**Akaun** → tambah ruang kerja → tetapan sambungan. Gunakan akaun berasingan untuk ini.

- **Kod QR:** imbas dari skrin Peranti dalam Telegram dan sahkan.
- **Nombor telefon:** nombor, kod, kemudian kata laluan 2FA jika ada.
- **Import sesi:** fail sesi anda sendiri atau data Telegram Desktop.

Gunakan profil API terbina dalam atau API ID dan hash anda sendiri. Ia hanya mengenal pasti aplikasi, ia tidak melog masuk anda atau menyembunyikan apa-apa.

**Perlukan proksi terlebih dahulu?**

Anda boleh [memilih dan menguji laluan sambungan](https://phishdestroy.github.io/TgWitness/ms/docs/proxies/) sebelum log masuk. Setiap akaun mempunyai laluan masing-masing.

## Pilih apa yang hendak diperhatikan

1. Pilih sembang, kumpulan atau saluran yang anda perlukan.
2. Semak tetapan pengumpulan, termasuk media.
3. Mulakan dan semak sambungan serta aktiviti terkini.

Akaun mesti mempunyai akses. Pentadbir dan ahli melihat perkara berbeza, jurnal menunjukkan apa yang diterima akaun ini.

Seluruh akaun? **Sumber → Skop pemerhatian → Mod siasatan**, semaknya, **Simpan skop**. Panduan penuh: [menyiasat seluruh akaun](https://phishdestroy.github.io/TgWitness/ms/docs/cases/).

## Semak keseluruhan laluan

Dalam kumpulan ujian anda, hantar mesej daripada akaun lain, suntingnya, padamnya. Ketiga-tiganya patut muncul dalam jurnal. Kemudian [eksport dan sahkan](https://phishdestroy.github.io/TgWitness/ms/docs/exports/).

"Bersambung" bermaksud sambungan berfungsi. Mesej ujian yang ditangkap bermaksud peristiwa benar-benar tiba.

## Tambah akaun lain

Ruang kerja baharu dalam **Akaun**, langkah yang sama. Catat cap jari kunci setiap akaun supaya anda boleh membezakan eksport kemudian.
