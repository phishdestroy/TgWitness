# قم بإعداد نسخة للمشاركة

Canonical page: https://phishdestroy.github.io/TgWitness/ar/docs/handover/

شارك ما يلزم فقط، ويبقى الأصل كما هو.

التسليم مستخلص موقّع منفصل: اختر المحادثات والأشخاص، وأخفِ الهويات أو النص، واختر الملفات وملاحظات الفريق. يسجّل البيان ما أُبقي وما قُلِّص وما استُبعد.

## قم بإعداد المقتطف الخاص بالمستلم

1. **الصادرات ← مستخلص التسليم**: اكتب الغرض، واختر المحادثات وفترة زمنية، و**تحميل الأشخاص من المحادثات المختارة** إذا احتجت أشخاصًا بأسمائهم.
2. الجميع غيرهم: أسماء مستعارة، أو مستبعدون، أو كما سُجّلوا. النص والملفات مفتاحان منفصلان، ويمكن إخفاء الهواتف والبريد الإلكتروني.
3. Case Board: لا شيء، أو إشارات وشرائح، أو بطاقات مع تعليقات. يمكن استبدال أسماء الفريق بأسماء بديلة.
4. **تنزيل مستخلص التسليم**، وافتحه، وتحقق منه، واطّلع عليه قبل الإرسال.

### نسخة أصلية واحدة، ونسخة مخصصة للمشاركة

مثال اصطناعي · توضيح للهوية فقط

1. **اختر.** قم بتضمين محادثة القضية وحدد الشخص الذي يتعلق به المقتطف.
2. **التقليل.** اختر كيفية ظهور مشارك آخر في النسخة المشتركة.
3. **التدقيق.** افتح التقرير والسجلات الموجودة في الأرشيف الذي تم إنشاؤه قبل إرساله.
4. **المشاركة.** قم بتسليم النسخة التي تم تدقيقها وأرسل بصمة التوثيق الخاصة بها بشكل منفصل.

#### ملاحظة أصلية

نورا · المستخدم 71002

«لقد تلقيت الرابط المعدل.»

يحتفظ السجل المصدر بهذه الملاحظة المحفوظة.

#### نسخة المستلم

اعرض النص كما هو مسجل: نورا · المستخدم 71002 · «لقد تلقيت الرابط المعدل.»

الاسم المستعار: P01 · «لقد تلقيت الرابط المعدل.»

يُحذف: رسالة هذا المشارك غير مدرجة في النص.

#### افحص الملفات الفعلية

اقرأ ملف report.html وملف records.jsonl.

تحقق من الهويات والنصوص والمرفقات وتعليقات الفريق الاختيارية.

#### مقتطف موقّع

الاختيار + تجزئات الملفات + قائمة البيانات الموقعة

حزمة منفصلة مرتبطة بحدود المجلة المصدرية الخاصة بها

## استخدم عناصر التحكم معًا

| التحكم | التأثير على النص |
| --- | --- |
| الأشخاص | الأشخاص المختارون يبقون بأسمائهم، والآخرون يحصلون على أسماء مستعارة أو يُستبعدون. |
| النص | كل النص، أو نص الأشخاص المختارين وحسابك فقط، أو لا شيء. |
| الملفات | ملفات الأشخاص المختارين وحسابك، أو كل الملفات المعروضة، أو لا شيء. |
| لوحة الحالة | لا شيء، أو إشارات وشرائح، أو بطاقات مع النقاش. |

اقرأ النص والملفات أيضًا: الاسم المستعار لا يزيل الأسماء المكتوبة داخل رسالة أو مرفق. إذا كان ملف مختار مفقودًا، فاستعده أو استبعد المرفقات.

## اجعل النص قابلاً للتحقق بشكل مستقل

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

احتفظ بالأرشيف الأصلي ونقاط التحقق بنفسك. يمكن للمستلم التحقق من نسخته دون الحصول على مساحة العمل كاملة. التصميم: [Report studio](https://phishdestroy.github.io/TgWitness/ar/docs/reports/). المراجع الموثوقة: [التحقق من التصدير](https://phishdestroy.github.io/TgWitness/ar/docs/exports/).
