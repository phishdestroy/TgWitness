اتصال یک حساب

یک فضای کاری شامل یک حساب کاربری، دفترچهٔ ثبت آن و کلید امضای آن است.

انتخاب روش ورود

حساب‌ها را باز کنید، یک فضای کاری اضافه کنید و تنظیمات اتصال آن را باز کنید. از یک حساب اختصاصی برای مشاهده استفاده کنید.

  • کد QR: آن را از تنظیمات دستگاه تلگرام اسکن کرده و ورود جدید را تأیید کنید.
  • شماره تلفن: شماره را وارد کنید، کدی که تلگرام ارسال می‌کند و در صورت فعال بودن رمز تأیید دو مرحله‌ای خود را وارد کنید.
  • وارد کردن جلسه: وارد کردن یک جلسهٔ پشتیبانی‌شده یا داده‌های Telegram Desktop متعلق به شما.

یک پروفایل API داخلی را انتخاب کنید یا شناسه و هش API خود را وارد کنید. پروفایل API مشتری را شناسایی می‌کند؛ به هیچ حسابی وارد نمی‌شود و اتصال را ناشناس نمی‌سازد.

ابتدا به پروکسی نیاز دارید؟

می‌توانید قبل از ورود، مسیر اتصال را انتخاب و آزمایش کنید. هر حساب مسیر مخصوص به خود را دارد.

انتخاب کنید چه چیزی را مشاهده کنید

  1. فهرست منابع را باز کنید و چت‌ها، گروه‌ها یا کانال‌های مورد نیاز خود را انتخاب کنید.
  2. پیش از آغاز مشاهده، تنظیمات جمع‌آوری، از جمله رسانه‌ها، را بررسی کنید.
  3. جمع‌آور را راه‌اندازی کنید و اتصال و فعالیت اخیر آن را بررسی کنید.

حساب باید بتواند به منبع دسترسی داشته باشد. نقش‌های مختلف می‌توانند رویدادهای متفاوتی را ببینند؛ دفترچه آنچه آن حساب دریافت کرده است را منعکس می‌کند.

برای یک پرونده که کل حساب را در بر می‌گیرد، از مسیر Sources → Observation scope → Investigation mode استفاده کنید، تنظیمات را بررسی کرده و روی Save scope کلیک کنید. راهنمای کامل تحقیق تمام انواع چت‌های قابل مشاهده، تاریخچه قدیمی، پروفایل افراد، ارجاعات بین‌چتی و انتقال شواهد را پوشش می‌دهد.

مسیر کامل را بررسی کنید

در یک گروه آزمایشی که کنترل آن را در دست دارید، یک پیام منحصربه‌فرد از حساب دیگری ارسال کنید، آن را ویرایش و سپس حذف کنید. هر سه رویداد را در دفترچه شواهد تأیید کنید، سپس رکورد را صادر و اعتبارسنجی نمایید.

وضعیت متصل بودن، برقراری ارتباط را تأیید می‌کند. یک پیام آزمایشی ضبط‌شده تأیید می‌کند که یک رویداد خاص به این فضای کاری رسیده است.

حساب دیگری اضافه کنید

یک فضای کاری دیگر در بخش حساب‌ها ایجاد کنید و فرایند راه‌اندازی را تکرار کنید. اثر انگشت کلید امضای هر حساب را ذخیره کنید تا بعداً بتوانید خروجی‌های آن را شناسایی کنید.
