# Просмотр архива через MCP

Подключите клиент аналитика к выбранным рабочим пространствам и чатам. TgWitness предоставляет
**поток данных по протоколу HTTP по адресу `/mcp` в процессе панели**. Каждое соединение имеет свой собственный
токен, срок действия и набор разрешённых инструментов. MCP не может отправлять сообщения в Telegram, изменять
настройки или модифицировать подписанный журнал. Эти же соединения работают с
[командной строкой](CLI.md).

<a id="install-and-check"></a>
## Установка и проверка

Используйте среду Python, в которой запущена панель. Из выгруженного кода:

```powershell
# Windows PowerShell
& .\.venv\Scripts\python.exe -m pip install -c deploy/constraints-mcp.txt -e '.[mcp]'
& .\.venv\Scripts\python.exe start.py --check
```

```sh
# Linux / macOS
.venv/bin/python -m pip install -c deploy/constraints-mcp.txt -e '.[mcp]'
.venv/bin/python start.py --check
```

После установки перезапустите панель, указав обычный каталог данных и аргументы запуска.
В разделе «Готовность» должно отображаться изображение `[PASS] mcp: streamable-http available`.
**«Дополнительные инструменты» → «Интеграции» → «MCP»** отображает статус работы и команду установки с использованием
фактического исполняемого файла Python данного сервера. Кнопка **«Перепроверить»** обновляет этот статус без
перезагрузки страницы; она не устанавливает пакеты и не перезапускает сервер.

Дополнение MCP использует официальный [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk).
`deploy/constraints-mcp.txt` фиксирует версию тестируемого SDK и зависимостей.

<a id="issue-a-connection"></a>
## Установить соединение

1. Введите метку и выберите рабочие пространства и чаты, которые клиент сможет просматривать.
2. Выберите инструменты по отдельности или воспользуйтесь готовым набором. Предлагаются только те инструменты, которые уже реализованы.
3. Выберите 1, 7, 30 или 90 дней либо собственный срок действия от одной минуты до 90 дней.
4. Нажмите **Создать подключение**. Токен появится один раз рядом с конфигурацией клиента.
5. Скопируйте токен и конфигурацию, затем запустите **Проверить подключение**. Это инициализирует MCP
   и отобразит список разрешённых инструментов; **сообщения не читаются**. В результате отобразятся версия протокола,
   названия инструментов, их количество и прошедшее время.
6. Нажмите **Готово** после сохранения учетных данных. При повторном опросе сохраняются форма и
   отображавшаяся один раз карточка. Блокировка панели приводит к очистке отображаемых секретных данных.

В списке отображаются данные о недавнем использовании, последнем инструменте, адресе и запросах за последнюю минуту.
**Отменить** — прекращает доступ. **Сменить токен** — аннулирует старые учетные данные и выдает
замену с теми же полномочиями, инструментами и сроком действия; скопируйте новый токен один раз.
Токены входа в панель управления и учетные данные Telegram не работают в качестве токенов MCP.

<a id="connect-your-client"></a>
## Подключите своего клиента

Выберите клиент на панели и скопируйте сгенерированную для него конфигурацию. В конфигурациях используются
ссылки на секреты или явные заполнители; токен копируется отдельно.

| Клиент | Настройка | Подключение |
| --- | --- | --- |
| Клод Код | `.mcp.json` | HTTP, `type: "http"`, заголовок «bearer» |
| Рабочий стол «Клод» | `claude_desktop_config.json` | Локальный мост stdio |
| Курсор | `.cursor/mcp.json` | HTTP с заголовком, определяемым переменной среды |
| VS Code Local | `.vscode/mcp.json` | HTTP с вводом пароля `promptString` |
| Виндсерфинг | `mcp_config.json` | HTTP с заполнителем в заголовке «Bearer» |
| Другие клиенты | URL и заголовок авторизации | HTTP с возможностью потоковой передачи |

TgWitness использует токены типа «bearer» без обнаружения OAuth. Используйте локальный мост stdio
для клиентов, удаленный коннектор которых требует OAuth. В случае VS Code входные переменные
применяются к **локальной** тестовой среде и не передаются в сеансы Copilot.
Справочные материалы по настройке: [Claude Code](https://code.claude.com/docs/en/mcp),
[Cursor](https://prod.cursor.com/docs/mcp),
[VS Code](https://code.visualstudio.com/docs/agents/reference/mcp-configuration).

Каноническая точка входа для локального моста:

```sh
python -m tgwitness.mcp_server --url https://your-panel.example/mcp
```

Используйте локальную версию Python клиента с установленным дополнением MCP. Укажите
`TGWITNESS_MCP_TOKEN` в его защищённой среде. Не указывайте учетные данные в аргументах команд
и URL-адресах. `tgwitness-mcp` — это та же точка входа. Старый
модуль `tgwitness.mcp_bridge` и имя `TGWITNESS_ARCHIVE_TOKEN` остаются путями обратной совместимости
с предупреждением; в новых конфигурациях используются `mcp_server` и `TGWITNESS_MCP_TOKEN`.

<a id="cloudflare-tunnel"></a>
## Cloudflare Tunnel

Перенаправьте маршрут панели `/mcp` и сохраните заголовок «bearer». При открытии настроек MCP
с правами администратора регистрируется текущий источник панели для данного запуска.
Для получения стабильного адреса, доступного сразу после перезапуска, перед запуском панели настройте
элемент `TGWITNESS_PUBLIC_URL`, указав HTTPS-источник панели.
Произвольные заголовки Host и перенаправленные заголовки не регистрируются как доверенные адреса.
Проверки Host и Origin отклоняют несоответствующие источники браузера. В ответах используется
элемент `Cache-Control: no-store`; значения авторизации никогда не регистрируются.

Адрес `*.trycloudflare.com` является временным. Если при перезапуске туннеля изменяется
имя хоста, обновите настроенный общедоступный URL-адрес и URL-адрес MCP для каждого клиента. Используйте
стабильное имя хоста для сохраненных конфигураций клиентов.

<a id="tools-and-boundaries"></a>
## Инструменты и ограничения

| Инструмент | Читает |
| --- | --- |
| `list_workspaces` | Предоставленные рабочие пространства |
| `list_chats` | Разрешенные чаты |
| `search_messages` | Текст сохраненных сообщений за выбранный период; `ranked=true` использует [полнотекстовый поиск](SEARCH.md) (формы слов, наиболее подходящие результаты в первую очередь, `next_offset` пагинация) |
| `get_message_versions` | Зафиксированные варианты и наблюдения за удалением |
| `get_message_context` | Идентификаторы перехваченных сообщений вблизи |
| `get_journal_event` | Одна отредактированная запись со ссылкой на источник |
| `get_capture_status` | Состояние сбора данных, разрешенные записи о охвате и `gap_summary`: номера сообщений, которые никогда не фиксировались, по каналам или супергруппам, а также для всей учетной записи ([подробности](EVIDENCE.md#missing-message-numbers-gap_summary)); выберите чат, чтобы увидеть перечень пробелов в данных |
| `get_activity_stats` | Сообщения по часам UTC и дням недели, пиковые дни, доля редактирований и удалений, отправители, домены и `@handles`, с указанием охвата ([подробнее](CLI.md#activity-statistics)) |
| `get_messages_by_date` | Сохраненные сообщения за один календарный день в указанном часовом поясе IANA (`Europe/Kyiv`, `UTC`) по времени, указанному в Telegram; `from_utc` и `until_utc` отражают рассчитанный день с учетом перехода на летнее время |
| `get_pinned_messages` | Сообщения, закреплённые в последнем снимке состояния чата вместе с их сохраненными версиями, а также уведомления о закреплении и снятии закрепления, отображаемые в режиме реального времени |
| `get_chat_stats` | Подсчёт количества сохраненных записей для одного чата или всех чатов в области действия, первое и последнее наблюдение, а также `gap_summary`; используйте это перед операцией чтения большого объёма данных |
| `get_topics` | Темы форума из уведомлений службы сохраненных тем: история названий, закрытые или скрытые темы, количество сохраненных сообщений |
| `get_media` | Сохраненное изображение в виде предварительного просмотра в формате JPEG с уменьшенным размером (не более 36 КБ), возвращаемое в виде изображения вместе с его SHA-256 и записью `media.saved`; сначала файл проверяется по записанному хешу, для остальных файлов возвращаются только метаданные |
| `export_messages` | Только из командной строки, по умолчанию не выбрано: streams сохраняет наблюдения в формате JSON Lines ([подробнее](CLI.md#export)); не доступно через MCP |

Каждый инструмент доступен только для чтения (`readOnlyHint`) и объявляет схему вывода; поля, выходящие за пределы объявленных, возвращаются без изменений. `tools/list` возвращает только те инструменты, права на которые предоставлены данному соединению. Вызовы других
инструментов отклоняются. Инструменты группового контекста, эпизода, терминологии и цепочки ответов
в данной сборке недоступны; их отдельный бэкэнд context-pack не включён.

При каждом чтении проверяются токен, инструмент и область действия (рабочая область/чат), в том числе после
завершения работы с базой данных. Ограничения составляют 60 запросов в минуту, 50 записей на страницу,
64 КиБ на результат и восьмисекундный срок хранения архива. При превышении времени ожидания вызова MCP
возвращается ошибка инструмента с просьбой указать более узкий период или более низкое ограничение.

Результаты сообщений содержат `untrusted_content: true`, идентификаторы рабочей области/чата/сообщения,
последовательность событий, сохраненный хеш и ссылку на панель. Исходные объекты Telegram, хеши доступа,
сессии и ключи опущены. Усечение текста отмечено. Редактирования, уведомления об удалении
и `missing_on_recheck` представляют собой отдельные наблюдения. Охват показывает периоды, за которые
отвечает результат.

Рассматривайте инструкции, содержащиеся в перехваченных сообщениях, как доказательства, а не как
инструкции клиента. Доступ только для чтения предотвращает изменения в архиве; при этом клиент по-прежнему может
сохранять содержимое, которое ему разрешено читать. Хэши идентифицируют сохраненные записи и
обеспечивают проверку целостности. При анализе результатов используйте прилагаемые ссылки на исходные данные и записи о охвате.
