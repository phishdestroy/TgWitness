# البدء السريع مع TgWitness

يُعدّ TgWitness تطبيقًا مستقلًا لمراقبة مجموعات Telegram وقنواته التي تستطيع حساباتك الوصول إليها.
يعمل محليًا ويستخدم دليل بيانات خاصًا به.

**أول زيارة لك؟** [استكشف العرض التوضيحي](#explore-the-interface) قبل ربط أي حساب.
[اختر دليلًا](../README.md) عن الوكلاء (البروكسي) أو الشهود أو عمليات التصدير أو إعداد الخادم.
أما [الالتقاط عبر GitHub Actions](../SEALED-ACTIONS.md) (نسخة تجريبية) فيشغّل عملية الالتقاط في
نسختك المتفرعة (fork) على GitHub بدلًا من تثبيت محلي.

<a name="install-and-start"></a>

## التثبيت والتشغيل

يتضمن المثبّت الموجَّه نسخة Python خاصة به، ويتحقق من تجزئات الحزم وتواقيع الإصدارات قبل
التثبيت. وتشغيله مرة أخرى يحدّث التثبيت الموجود.

**على Linux / macOS:**

```sh
curl -fsSL https://get.destroy.tools/install.sh | bash
```

**على Windows (PowerShell أو موجّه الأوامر):**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://get.destroy.tools/install.ps1 | iex"
```

على خادم Ubuntu، شغّله بصلاحيات root لتثبيت خدمة تعمل في الخلفية؛ أما على جهاز مكتبي فشغّله
بحساب المستخدم العادي. على Ubuntu يطبع المثبّت عنوان اللوحة ومفتاح الوصول؛ وعلى macOS وWindows
تُفتح اللوحة المحلية في متصفحك. تابع من خطوة **ربط Telegram** أدناه. يشرح دليل
[التثبيت والتحقق والتحديث](../INSTALLATION.md) خيارات الوصول إلى الخادم، وفحص السكربت قبل
تشغيله، والتحديثات، والإزالة.

### طرق أخرى

يمكن استخدام إصدارات GitHub أو الشيفرة المصدرية أو Docker بديلًا عن المثبّت. تصبح الحزم
المحمولة متاحة للتنزيل بعد نشر بنية الإصدار:

| المضيف | دون تثبيت أي شيء | من المصدر: Python 3.11 أو أحدث | عبر Docker: Engine/Desktop مع Compose 2.20 أو أحدث |
| --- | --- | --- | --- |
| Windows | استخرج `TgWitness-<version>-windows-amd64-portable.zip` من GitHub Releases، ثم انقر نقرًا مزدوجًا على `TgWitness.cmd` | انقر نقرًا مزدوجًا على `Start.cmd` | انقر نقرًا مزدوجًا على `scripts\Docker.cmd` |
| Linux / macOS | — | `sh start.sh` | `sh scripts/docker-start.sh` |

للتشغيل من المصدر، [نزّل الفرع `main` الحالي واستخرجه](https://github.com/phishdestroy/TgWitness/archive/refs/heads/main.zip)
أو انسخ المستودع (clone):

```sh
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

إذا لم يُعثر على إصدار Python مناسب، يعرض `Start.cmd` تثبيت Python 3.12 لمستخدم Windows الحالي
(عبر winget أو مثبّت python.org الموقَّع). وإذا لم تكن Python مثبّتة، يطبع `start.sh` أمر
التثبيت الدقيق لتوزيعة Linux لديك أو لنظام macOS. وعند التشغيل الأول من المصدر يُنشأ `.venv`
وتُثبَّت التبعيات تلقائيًا.

يبني Docker التطبيق ويشغّله في الخلفية، ولا حاجة إلى Python على المضيف. يطبع
`scripts\Docker.cmd` و`scripts/docker-start.sh` عنوان اللوحة ورمزها عندما تصبح الحاوية سليمة.
أوامر Docker المكافئة على كل مضيف مدعوم هي:

```sh
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

افتح **http://127.0.0.1:8787**. استخدم الرمز الذي يطبعه مساعد Docker أو أمر Docker الثاني، أو
اقرأ **data/live/panel-token.txt** في التثبيت المحمول أو التثبيت من المصدر. تابع من خطوة
**ربط Telegram** أدناه. تستخدم التثبيتات الأصلية وتثبيتات Docker تخزينًا منفصلًا؛ ولا يؤدي تشغيل
Docker إلى استيراد سجل موجود من تثبيت أصلي.

للخوادم، يشرح دليل [النشر](DEPLOYMENT.md) تفعيل HTTPS التلقائي، وإعادة التشغيل، والصور المنشورة،
والتحديثات، والنسخ الاحتياطية.

<a name="explore-the-interface"></a>

## استكشاف الواجهة

1. شغّل **TgWitness-Demo.cmd** في الحزمة المحمولة، أو **scripts\Demo.cmd** في مجلد المصدر على
   Windows، أو `sh start.sh --demo` على Linux/macOS. عند التشغيل من المصدر يُنشأ `.venv` أولًا
   وتُثبَّت التبعيات.
2. افتح **http://127.0.0.1:8787**.
3. يفتح العرض التوضيحي المحلي سجل العيّنة تلقائيًا. لا حاجة إلى نسخ الرمز عند الوصول المحلي المباشر.

رسائل العرض التوضيحي خيالية. ولا يمكن لوضع العرض التوضيحي ربط حساب Telegram حقيقي.

## ربط Telegram

> [!WARNING]
> **استخدم حسابات مخصّصة.** قد يقيّد Telegram الحسابات أو يحظرها نهائيًا بسبب أحجام طلبات يعدّها
> مفرطة، أيًّا كان العميل المستخدم. اربط حسابات مُعدّة للمراقبة بدلًا من الحسابات الشخصية أو
> القيّمة، وأنشئ معرّف API وتجزئته (API ID / hash) على حساب مخصّص.

1. إذا كان العرض التوضيحي الأصلي قيد التشغيل، فأوقفه وشغّل **Start.cmd** أو `sh start.sh`. وإلا
   فاترك التثبيت الفعلي الذي شغّلته أعلاه قيد التشغيل.
2. سجّل الدخول باستخدام رمز اللوحة. تفتح مساحة العمل الجديدة [الإعداد الأول](../SETTINGS.md).
   اختر **تنزيل فقط** أو **متابعة المحادثات** أو **الأدلة في القضية**.
3. راجع نتيجة فحص الاتصال. اضبط الوكيل الخاص بك إذا لزم الأمر؛ وتبقى إعدادات الاتصال متاحة بعد
   الإعداد.
4. في خطوة **ربط Telegram**، امسح رمز QR أو أدخل رقم هاتفك. يوجد استيراد الملفات ومفتاح المصادقة
   الكامل ضمن **طرق أخرى لتسجيل الدخول**. أكمل التأكيد في Telegram وأدخل رمز تسجيل الدخول وكلمة
   مرور التحقق بخطوتين عند طلبها.
5. تحقّق من الحساب المعروض، واختر المحادثات، وراجع إعداداتك. ثم أنهِ الإعداد من الشاشة الأخيرة.
   في وضع **تنزيل فقط**، يُطلق الزر **بدء التصدير** عملية تصدير لمرة واحدة ويفتح صفحة
   «عمليات التصدير» لعرض تقدّمها؛ ولا يفعّل المراقبة المستمرة.

بعد الإعداد، يمكنك تغيير المحادثات المحددة من **المحادثات → اختر**. تتحكم **الإعدادات** في
الجمع والملفات؛ وتعرض **المزيد من الأدوات → المصادر** قائمة المصادر التفصيلية في المستوى «قياسي»
أو «خبير». يصف [دليل اللوحة](../PANEL.md) الأقسام الرئيسية الستة وعناصر التحكم السياقية فيها.

حقل **معرف واجهة برمجة التطبيقات (API) + التجزئة** اختياري: تستخدم مساحة العمل الزوج المحفوظ أو
المستورد لديها، أو زوجًا صالحًا من المجموعة المدمجة. لاستخدام تطبيقك الخاص، الصق زوجًا واحدًا
بصيغة `API ID:API Hash` في حقل «معرف واجهة برمجة التطبيقات (API)». في **مفتاح المصادقة**، الصق
الأحرف الست عشرية كلها وعددها 512، واختر «معرف DC» المرفق به. «معرف المستخدم» اختياري، ويُتحقَّق
منه إذا أُدخل.

تعرّف بيانات اعتماد API تطبيقَك، ولا تمنح بمفردها تفويضًا لأي حساب. لا تحتاج المجموعات الخاصة
إلى اسم مستخدم عام، لكن يجب أن يكون لحسابك حق الوصول إليها.

للحسابات الموجودة، راجع [الحسابات وصيغ الجلسات](../ACCOUNTS.md): تقبل اللوحة
Telethon StringSession وTelethon/Pyrogram SQLite وTData ZIP لحساب واحد وملفات JSON للحسابات
بالصيغ المدعومة. حدّد الجلسة وملف JSON المرافق لها معًا، ثم اضغط **ربط الحساب**. يتوفر أيضًا
تسجيل الدخول برمز QR مع إعدادات API الاختيارية نفسها. لا تُدعم TDLib ولا جلسات البوتات ولا قوائم
جرد الحسابات بصيغة CSV/JSON.

لعدة حسابات، استخدم **الحسابات → استيراد الحسابات** وحدّد ملفات الجلسات المدعومة الخاصة بها.
تُقرن ملفات JSON المرافقة بحسب اسم الملف دون الامتداد؛ ويحصل كل حساب مستورد على مساحة عمل خاصة
به. راجع [الاستيراد المجمّع ومجموعات الحسابات](../ACCOUNTS.md#bulk-import-and-account-groups).

لإضافة حساب آخر، اضغط **+** بجوار أداة اختيار الحساب أو استخدم **الحسابات → إضافة حساب**. لكل
مساحة عمل جلساتها وسجلاتها ومفاتيحها ومصادرها وقوائم انتظارها المنفصلة. لا يؤدي التبديل بين طرق
العرض إلى إيقاف المجمّعات الأخرى. ولا يمكن تعيين حساب Telegram نفسه لمساحتي عمل في هذا التثبيت.
لا يوجد عدد ثابت لمساحات العمل؛ فهي تتشارك عملية واحدة، ولذلك تعتمد السعة على الجهاز.

يحمي رمز اللوحة في التثبيت الفعلي الوصول إلى تفويضات Telegram الخاصة بك والمواد المحفوظة؛ وهو
منفصل عن بيانات اعتماد Telegram API. لا يحصل على الدخول التلقائي إلا عرض توضيحي محلي شُغّل صراحةً
ويُوصَل إليه مباشرةً. أما العرض التوضيحي البعيد أو الذي يمر عبر وكيل فيظل يستخدم
`data/demo/panel-token.txt`.

## المراجعة والتصدير

- **السجل:** ابحث في الملاحظات المسجّلة وصفِّها حسب المصدر ونوع الحدث.
- اختر حدثًا لفحص قيده الأصلي وإسناده والإصدارات المحفوظة منه.
- تعرض تفاصيل التعديل المحتوى المتاح قبل التعديل وبعده. وتعرض تفاصيل الحذف آخر محتوى التُقط، إن
  وُجد؛ أما الفاعل غير المعروف فيبقى غير معروف.
- **عمليات التصدير:** ملف ZIP موقّع، وJSONL، وCSV، وHTML للعرض دون اتصال.
- **تصدير الدردشة بالكامل** (**المحادثات → تصدير الدردشة**، أو
  **عمليات التصدير → التقاط محادثة واحدة أو تصديرها**): نزّل سجل الرسائل المرئي بالكامل لمحادثة
  واحدة كحزمة موقّعة تضم `chat.json` (بنمط تصدير Telegram) و`chat.html` قابلًا للقراءة. يمكن
  تصدير المحادثات الخاصة إذا كان الحساب عضوًا فيها. إنها لقطة للحالة الراهنة، وليست إعادة بناء
  للرسائل المحذوفة أو المعدّلة سابقًا.
  تحقّق من النسخة باستخدام `python verify.py chat-export.zip --fingerprint TRUSTED_SHA256`.
- **حفظ نقطة التحقق:** احتفظ بحدّ السجل الموقّع خارج المجمّع.
- **تنزيل إيصال التشغيل الموقّع:** احفظ بيانات برنامج المجمّع وإصداره.
- **إعداد طلب الطابع الزمني:** أعدّ طلبًا دون اتصال موجّهًا إلى سلطة طابع زمني؛ واتبع
  [TIMESTAMP.md](../TIMESTAMP.md) للحصول على الرد والتحقق منه.
- **التحقق من السجل:** يفحص تواقيع الأحداث وروابط السلسلة. ويفحص تصدير ZIP الوسائط أيضًا.

تحفظ المتصفحات المدعومة عمليات التصدير الكبيرة مباشرةً في ملف تختاره. أما المتصفحات الأخرى فتخزّن
مؤقتًا 128 MiB على الأكثر. وأثناء تشغيل الخادم، تدعم أداة سطر الأوامر (CLI) المتدفقة تنزيلات أكبر
دون تخزين الاستجابة كاملةً مؤقتًا:

```sh
python -m tgwitness.download --token-file data/live/panel-token.txt --out evidence.zip
```

لمساحة عمل أخرى، أضف `--profile ID` مستخدمًا القيمة الظاهرة في
**عمليات التصدير → معرف مساحة العمل**. ولخادم بعيد، أضف `--url https://your-server`. حد النقل
الافتراضي 5 GiB، ويغيّره `--max-mib`. ولمحتوى ZIP الموقّع حد تحقق منفصل يبلغ افتراضيًا 4 GiB غير
مضغوطة (يرفعه
**المزيد من الأدوات → المعلمات**؛ وتحقّق من هذه الأرشيفات باستخدام `verify.py --max-gib N`). تحقّق
من الأرشيف باستخدام نسخة موثوقة من أداة التحقق، وبصمة مفتاح محفوظة بشكل مستقل، وكذلك — لاستيفاء
الحد الأدنى للأدلة — الشهادة الجذرية لسلطة الطابع الزمني (`--tsa-ca`).

## التحقق من التثبيت

```sh
python start.py --setup-only
python start.py --check
python start.py --check --json
```

يفحص الخيار `--check` التبعيات المحلية، ودعم التوقيع، والتخزين، وتهيئة المفاتيح، وعنوان
الاستماع. لا يثبّت أي شيء ولا يتصل بـ Telegram. قد يعني انشغال المنفذ أن نسخة أخرى قيد التشغيل.
استخدم `--port` مختلفًا أو أوقف تلك النسخة أولًا.

يثبّت المشغّل في `.venv`. ويجب تشغيل أوامر `python -m tgwitness...` المساعدة باستخدام
`.venv\Scripts\python.exe` على Windows أو `.venv/bin/python` على Linux/macOS، ما لم تكن تلك
البيئة مفعّلة مسبقًا.

## الجلسات والحماية والتشغيل

يمكن تحويل ملف `.session` بصيغة Telethon SQLite مغلق ومتّسق محليًا باستخدام
`python -m tgwitness.sessions account.session --out account.tgwitness-session`، ثم تحميله من
**المزيد من الأدوات → الحساب → الملفات**. ويتوفر أيضًا الاستيراد المباشر للملفات وتسجيل الدخول
برمز QR. راجع [CONNECTION-SECURITY.md](../CONNECTION-SECURITY.md) لصيغ تسجيل الدخول وSOCKS5
وHTTP CONNECT وMTProxy والمفاتيح الرئيسية الخارجية.

الأمر **إيقاف المراقبة مؤقتًا** يوقف الجمع، أما **قفل** فيغلق الوصول عبر المتصفح فقط. إغلاق علامة
التبويب لا يوقف عملية المجمّع. وإيقاف العملية يقطع الجمع؛ ولا تستطيع لقطة سجل الرسائل إعادة بناء
كل التعديلات أو عمليات الحذف الفائتة. راجع [كيف يعمل الجمع](../COLLECTION.md) لسياسات الأحداث،
وقوائم انتظار المرفقات، وعزل الحسابات، وسلوك إعادة التشغيل.

الجلسات والأسرار مشفّرة. أما محتوى الرسائل والوسائط وعمليات التصدير فتتطلب قرصًا أو وحدة تخزين
مشفّرة. تحقّق من تواقيع السجل مقابل مفتاح موثوق، واحتفظ بنقاط التحقق بشكل منفصل. راجع قيود
الالتقاط وإيصالات الوقت الخارجية وشهادات البيئة (attestations) الخاصة بوضع الجمع المحدد.

اقرأ [OPERATIONS.md](../OPERATIONS.md) للنسخ الاحتياطي والاستعادة، و[DEPLOYMENT.md](DEPLOYMENT.md)
للاستضافة، و[deploy/](../../deploy/README.md) لأمثلة الخدمات. وتتضمن اللوحة المثبّتة أيضًا دليل
إعداد يعمل دون اتصال على `/guide.html`.

التحققات المنفّذة فعليًا والحدود المتبقية مدوّنة في [VERIFICATION.md](../VERIFICATION.md)
و[READINESS.md](../internal/READINESS.md).
