# আর্কাইভ নিয়ে কাজ করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/archive/

বার্তাটি খুঁজে বের করুন। উৎস যাচাই করুন। মামলা গড়ে তুলুন।

01**ইতিহাস আনুন**

আপনার সক্ষমকৃত উৎসগুলো থেকে পূর্ববর্তী বার্তাগুলো কর্মস্থলে লোড করুন।

02**উৎসগুলো অনুসরণ করুন**

আর্কাইভ অনুসন্ধান করুন এবং প্রতিটি ফলাফলের পিছনে সংরক্ষিত বার্তাটি খুলুন।

03**হ্যান্ডঅফ পরিষ্কার রাখুন**

আপনার বিশ্লেষণটি আলাদাভাবে সংরক্ষণ করুন এবং স্বাক্ষরিত প্রমাণটি এর পাশে রপ্তানি করুন।

ধৃত রেকর্ড, স্বীকৃত পাঠ্য এবং বিশ্লেষকের উপসংহার পৃথকভাবে থাকে।

## পূর্বের বার্তাগুলো লোড করুন

1. **উৎসসমূহ → আওতাভুক্ত চ্যাটসমূহ** খুলুন, সক্রিয় চ্যাটগুলো পর্যালোচনা করুন এবং পর্যবেক্ষণ শুরু করুন।
2. **পূর্ণ ইতিহাস লোড করুন** নির্বাচন করুন। রানটি সেই মুহূর্তে নির্বাচিত উৎস তালিকা ব্যবহার করে।
3. প্রয়োজন অনুযায়ী **Pause history** এবং **Continue history** ব্যবহার করুন। রিস্টার্টের পর স্পষ্টভাবে পুনরায় চালু করুন।
4. প্রতি-উৎস ফলাফল এবং সংযুক্তি সারিতে পরীক্ষা করুন। প্রমাণ রপ্তানির সাথে স্বাক্ষরিত অগ্রগতি প্রতিবেদন সংরক্ষণ করুন।

এটি উপলব্ধ বার্তাগুলো দিয়ে কর্মক্ষেত্রটি পূরণ করে। প্রতিটি চ্যাটের HTML/JSON রপ্তানি একটি পৃথক অপারেশন। [ইতিহাস এবং পুনরুদ্ধারের বিবরণ](https://phishdestroy.github.io/TgWitness/bn/docs/reference/history/)।

## প্রথমে অনুসন্ধান করুন, তারপর এআই সম্পর্কে সিদ্ধান্ত নিন।

1. স্থানীয় অনুসন্ধানের জন্য **জার্নাল** খুলুন। একটি ওয়ার্কস্পেস নির্বাচন করুন এবং উৎস ও সময়ের ফিল্টারগুলো ব্যবহার করুন।
2. একটি ফ্রেজ বা ডোমেইন অনুসন্ধান করুন। সংশ্লিষ্ট রেকর্ড এবং এর সংরক্ষিত সংস্করণগুলো খুলুন।
3. এআই বিশ্লেষণের জন্য প্রশাসক **ইন্টিগ্রেশনসমূহ**-এ একটি প্রদানকারী সক্রিয় ও কনফিগার করেন। **আর্কাইভকে জিজ্ঞাসা করুন** খুলুন এবং চ্যাট ও একটি সময়কাল নির্বাচন করুন। অনুরোধ অনুমোদনের আগে **মডেলটিতে প্রেরিত ডেটা** পর্যালোচনা করুন এবং অবাঞ্ছিত উদ্ধৃত অংশগুলো আনচেক করুন।
4. প্রদত্ত উদ্ধৃতিগুলো যাচাই করুন। উত্তরটি একটি রিপোর্ট হিসেবে সংরক্ষণ করুন এবং আপনার নিজস্ব সংশোধন বা মন্তব্য যোগ করুন।

সার্চ স্থানীয়ভাবে এআই ছাড়াই চলে। বিশ্লেষণাত্মক প্রতিবেদনগুলো উৎস রেফারেন্স এবং সংশোধন ইতিহাস সংরক্ষণ করে; এগুলো স্বাক্ষরিত জার্নাল থেকে পৃথক। [প্রদানকারী সেটআপ এবং প্রতিবেদনসমূহ](https://phishdestroy.github.io/TgWitness/bn/docs/reference/analysis/)।

## আপনার প্রয়োজনীয় সংযোগ নির্বাচন করুন

| টাস্ক | খোলা | সেটআপ |

| একটি এআই ক্লায়েন্ট থেকে নির্বাচিত চ্যাটগুলো পড়ুন | **ইন্টিগ্রেশনসমূহ → MCP** | [MCP এক্সট্রা ইনস্টল করুন, একটি স্কোপড টোকেন ইস্যু করুন এবং ক্লায়েন্ট সংযুক্ত করুন।](https://phishdestroy.github.io/TgWitness/bn/docs/reference/mcp/) |

**কোন অ্যাক্সেস টোকেন কোথায় যাবে?**

প্যানেল অ্যাক্সেস মামলা পর্যালোচনা করা ব্যক্তিদের জন্য। MCP সংযোগগুলি পৃথক রিড-অনলি আর্কাইভ টোকেন পায়। একটি ওয়েবহুক রিসিভার তার নিজস্ব HMAC সিক্রেট ব্যবহার করে। কারোই টেলিগ্রাম সেশন ফাইলের প্রয়োজন নেই।

[প্যানেল অ্যাক্সেস শেয়ার করুন](https://phishdestroy.github.io/TgWitness/bn/docs/access/) অথবা [একটি MCP ক্লায়েন্ট কনফিগার করুন](https://phishdestroy.github.io/TgWitness/bn/docs/reference/mcp/)।

## উৎস এবং উপসংহার হস্তান্তর করুন

পর্যালোচিত বিশ্লেষণাত্মক প্রতিবেদনটি স্বাক্ষরিত প্রমাণ ZIP-এর সাথে রাখুন। প্রতিবেদনটি আপনার উৎসপাঠের ব্যাখ্যা দেয়; ZIP প্রাপককে সংরক্ষিত রেকর্ডটি স্বাধীনভাবে বিশ্বাসযোগ্য ফিঙ্গারপ্রিন্ট ও চেকপয়েন্টের বিরুদ্ধে যাচাই করার সুযোগ দেয়।
