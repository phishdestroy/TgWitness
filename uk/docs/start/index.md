# Почніть за лічені хвилини

Canonical page: https://phishdestroy.github.io/TgWitness/uk/docs/start/

Спочатку ознайомтеся з прикладом роботи. Потім підключіть свій обліковий запис.

## Ознайомтеся з сайтом без реєстрації

Завантажте або клонуйте проєкт, встановіть **Python 3.11 або новішу версію** та запустіть демоверсію. Програма запуску створює локальне середовище та встановлює закріплені залежності.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

У браузері відкривається робоча область із вигаданими повідомленнями. Відкрийте чат, порівняйте редагування та перегляньте експорт. У демо-режимі з’єднання з Telegram не встановлюється.

![Вигляд діалогу в TgWitness із прикладами повідомлень](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Приклад робочого простору. Ваш власний журнал створюється окремо.

## Створіть власний робочий простір

Закрийте демо-версію, а потім скористайтеся звичайним запускачем:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Відкрийте локальну адресу, вказану запускачем. Якщо з’явиться запит, введіть **токен доступу** до **панелі** з локального файлу, назва якого вказано в терміналі. Це розблокує TgWitness; цей процес не пов’язаний із входом у Telegram.

## Збережіть своє перше повідомлення

1. [Підключіть спеціальний обліковий запис Telegram.](https://phishdestroy.github.io/TgWitness/uk/docs/accounts/)
2. Виберіть групу або канал, до яких має доступ обліковий запис, а потім розпочніть спостереження.
3. Надішліть нове повідомлення у тестовій групі, яку ви контролюєте, і переконайтеся, що воно з’явилося у журналі.

Для встановлення на сервер дотримуйтесь інструкцій у розділі [«Keep it running](https://phishdestroy.github.io/TgWitness/uk/docs/server/)».
