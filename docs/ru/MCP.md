# Просмотр архива через MCP

Подключите клиент аналитика к выбранным рабочим областям и чатам. TgWitness предоставляет **интерфейс Streamable HTTP по адресу `/mcp` в процессе панели**. Каждое соединение имеет собственный токен, срок действия и разрешённые инструменты. MCP не может отправлять сообщения в Telegram, изменять настройки или модифицировать подписанный журнал. Те же соединения работают с [командной строкой](CLI.md).

<a id="install-and-check"></a>
## Установка и проверка

Используйте среду Python, в которой запущена панель. Из репозитория исходного кода:

```powershell
# Windows PowerShell
& .\.venv\Scripts\python.exe -m pip install -c deploy/constraints-mcp.txt -e '.[mcp]'
& .\.venv\Scripts\python.exe start.py --check
```

```sh
# Linux / macOS
.venv/bin/python -m pip install -c deploy/constraints-mcp.txt -e '.[mcp]'
.venv/bin/python start.py --check
```

После установки перезапустите панель, указав привычный каталог данных и аргументы запуска. В списке готовности должно отображаться сообщение `[PASS] mcp: streamable-http available`. В разделе **Дополнительные инструменты → Интеграции → MCP** отображается статус работы и команда установки с использованием фактического исполняемого файла Python данного сервера. **Повторная проверка** обновляет этот статус без перезагрузки страницы; она не устанавливает пакеты и не перезапускает сервер.

Дополнение MCP использует официальный [SDK MCP для Python](https://github.com/modelcontextprotocol/python-sdk). Файл ``deploy/constraints-mcp.txt`` фиксирует проверенную версию SDK и зависимости.

<a id="issue-a-connection"></a>
## Установка соединения

1. Введите метку и выберите рабочие области и чаты, которые клиент сможет просматривать.
2. Выберите инструменты по отдельности или воспользуйтесь предустановкой. Предлагаются только реализованные инструменты.
3. Выберите 1, 7, 30 или 90 дней либо собственный срок действия от одной минуты до 90 дней.
4. Нажмите **Создать подключение**. Токен отобразится один раз рядом с конфигурацией клиента.
5. Скопируйте токен и конфигурацию, затем запустите функцию **Проверить подключение**. При этом инициализируется MCP и отображается список разрешённых инструментов; **сообщения не считываются**. В результате отображаются версия протокола, названия инструментов, их количество и прошедшее время.
6. Нажмите **Готово** после сохранения учетных данных. При повторном обращении к форме сохраняются её содержимое и отображавшаяся однократно карточка. Блокировка панели приводит к очистке отображаемых секретных данных.

В списке отображаются недавние действия, последний инструмент, адрес и запросы за последнюю минуту. **Функция Отменить** прекращает доступ. **Функция Сменить токен** аннулирует старые учетные данные и выдает новые с той же областью действия, инструментами и сроком действия; скопируйте новые данные один раз. Токены входа в панель и учетные данные Telegram не работают в качестве токенов MCP. Мост stdio проверяет токен с панелью перед запуском: аннулированный, просроченный или неверный токен немедленно прерывает работу с соответствующим сообщением; то же самое происходит при недоступном адресе панели.

<a id="connect-your-client"></a>
## Подключите свой клиент

Выберите клиент в панели и скопируйте сгенерированную для него конфигурацию. В конфигурациях используются скрытые ссылки или явные заполнители; токен копируется отдельно.

| Клиент | Конфигурация | Подключение |
| --- | --- | --- |
| Код Claude | `.mcp.json` | HTTP, `type: "http"`, заголовок bearer |
| Claude Desktop | `claude_desktop_config.json` | Локальный мост stdio |
| Cursor | `.cursor/mcp.json` | HTTP с заголовком, определяемым переменной среды |
| VS Code Local | `.vscode/mcp.json` | HTTP с вводом пароля через `promptString` |
| Windsurf | `mcp_config.json` | HTTP с заполнителем в заголовке «Bearer» |
| Другие клиенты | URL и заголовок авторизации | HTTP с потоковой передачей |

TgWitness использует токены «bearer» без обнаружения OAuth. Для клиентов, удалённый коннектор которых требует OAuth, используйте локальный мост stdio. В случае VS Code входные переменные применяются к **локальной** среде тестирования и не передаются в сеансы Copilot. Справочные материалы по настройке: [Claude Code](https://code.claude.com/docs/en/mcp), [Cursor](https://prod.cursor.com/docs/mcp), [VS Code](https://code.visualstudio.com/docs/agents/reference/mcp-configuration).

Каноническая точка входа для локального моста:

```sh
python -m tgwitness.mcp_server --url https://your-panel.example/mcp
```

Используйте локальную версию Python клиента с установленным дополнением MCP. Установите переменную `TGWITNESS_MCP_TOKEN` в защищённой среде. Не указывайте учетные данные в аргументах команд или URL-адресах. Точка входа для `tgwitness-mcp` аналогична. Старый модуль `tgwitness.mcp_bridge` и имя `TGWITNESS_ARCHIVE_TOKEN` остаются путями обратной совместимости с предупреждением; в новых конфигурациях используются `mcp_server` и `TGWITNESS_MCP_TOKEN`.

<a id="cloudflare-tunnel"></a>
## Cloudflare Tunnel

Перенаправьте маршрут `/mcp` панели и сохраните заголовок bearer. Открытие настроек MCP с правами администратора регистрирует текущий источник панели для данного запуска. Чтобы получить стабильный адрес, доступный сразу после перезапуска, перед запуском панели настройте параметр `TGWITNESS_PUBLIC_URL`, указав HTTPS-источник панели. Произвольные значения полей «Host» и перенаправленные заголовки не регистрируются в качестве доверенного адреса. Проверки полей «Host» и «Origin» отклоняют несоответствующие источники браузера. В ответах используется параметр `Cache-Control: no-store`; значения авторизации никогда не регистрируются в журнале.

Адрес `*.trycloudflare.com` является временным. Если при перезапуске туннеля изменяется имя хоста, обновите настроенный публичный URL-адрес и URL-адрес MCP для каждого клиента. Для сохраненных конфигураций клиентов используйте стабильное имя хоста.

<a id="tools-and-boundaries"></a>
## Инструменты и ограничения

| Инструмент | Просмотры |
| --- | --- |
| `list_workspaces` | Предоставленные рабочие области |
| `list_chats` | Предоставленные чаты |
| `search_messages` | Текст сохраненных сообщений за выбранный период; при значении `ranked=true` используется [полнотекстовый поиск](SEARCH.md) (формы слов, лучшие совпадения в первую очередь, пагинация по `next_offset`) |
| `get_message_versions` | Зафиксированные версии и наблюдения за удалениями |
| `get_message_context` | Идентификаторы сообщений, зафиксированных поблизости |
| `get_journal_event` | Одна очищенная запись со ссылкой на источник |
| `get_capture_status` | Состояние сбора данных, разрешённые записи охвата и сводка пробелов (`gap_summary`): номера сообщений, которые никогда не были зафиксированы, с разбивкой по каналам или супергруппам, а также по всей последовательности аккаунта ([подробности](EVIDENCE.md#missing-message-numbers-gap_summary)); выберите чат, чтобы просмотреть перечень пробелов в нём |
| `get_activity_stats` | Сообщения по часам UTC и дням недели, пиковые дни, доля отредактированных и удалённых сообщений, отправители, домены и `@handles` с указанием охвата ([подробнее](CLI.md#activity-statistics)) |
| `get_messages_by_date` | Сохраненные сообщения за один календарный день в указанном часовом поясе IANA (`Europe/Kyiv`, `UTC`) по времени, сообщаемому Telegram; параметры `from_utc` и `until_utc` указывают рассчитанный день с учётом перехода на летнее время |
| `get_pinned_messages` | Сообщения, закреплённые в последнем снимке состояния чата, с их сохраненными версиями, а также уведомления о закреплении и снятии закрепления, подвергаемые наблюдению в режиме реального времени |
| `get_chat_stats` | Приблизительное количество сохраненных записей для одного чата или всех чатов в области действия, время первого и последнего наблюдения, а также сводка пробелов (`gap_summary`); рекомендуется использовать перед массовым чтением |
| `get_topics` | Темы форума из сообщений службы сохраненных тем: история названий, закрытые или скрытые темы, количество сохраненных сообщений |
| `get_media` | Сохраненное изображение в виде уменьшенного предварительного просмотра в формате JPEG (не более 36 КБ), возвращаемое в виде изображения вместе с его SHA-256 и записью ``media.saved``; файл сначала сверяется с записанным хешем, для остальных файлов возвращаются только метаданные |
| `export_messages` | Только из командной строки, по умолчанию не выбрано: потоковая передача сохраненных наблюдений в формате JSON Lines ([подробности](CLI.md#export)); не предоставляется через MCP |

Каждый инструмент доступен только для чтения (`readOnlyHint`) и объявляет схему вывода; поля, выходящие за пределы объявленных, возвращаются без изменений. Команда `tools/list` возвращает только те инструменты, доступ к которым предоставлен данному подключению. Вызовы других инструментов отклоняются. Инструменты группового контекста, эпизода, терминологии и цепочки ответов не доступны в данной сборке; их отдельный бэкенд context-pack не включён.

Каждое чтение проверяет токен, инструмент и рабочую область чата, в том числе после завершения работы с базой данных. Ограничения составляют 60 запросов в минуту, 50 записей на страницу, 64 КиБ на результат и восьмисекундный срок хранения в архиве. Вызов MCP, превысивший время ожидания, возвращает ошибку инструмента с просьбой указать более узкий период или более низкий предел.

Результаты сообщений содержат значение `untrusted_content: true`, идентификаторы рабочей области/чата/сообщения, последовательность событий, сохраненный хеш и ссылку на панель. Необработанные объекты Telegram, хеши доступа, сеансы и ключи опущены. Усечение текста отмечается. Редактирования, уведомления об удалении и состояние `missing_on_recheck` представляют собой отдельные наблюдения. Покрытие указывает периоды, к которым относится результат.

Рассматривайте инструкции, содержащиеся в перехваченных сообщениях, как доказательства, но ни в коем случае не как указания для клиента. Доступ только для чтения предотвращает изменения в архиве; при этом клиент по-прежнему может сохранять контент, который ему разрешено читать. Хеши идентифицируют сохраненные записи и обеспечивают проверку целостности. При анализе результата используйте прилагаемые ссылки на источники и записи об охвате.
