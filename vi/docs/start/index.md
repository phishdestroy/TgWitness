# Telegram · Bắt đầu chỉ trong vài phút

Canonical page: https://phishdestroy.github.io/TgWitness/vi/docs/start/

Xem thử bản demo trước, rồi kết nối tài khoản của bạn.

## Quý vị có thể tham quan trang web mà không cần tài khoản

Tải dự án, chuẩn bị **Python 3.11 trở lên**, chạy bản demo. Trình khởi chạy lo phần còn lại.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

Một không gian làm việc với tin nhắn bịa sẽ mở trong trình duyệt. Mở một cuộc trò chuyện, so sánh một lần sửa, xem một bản xuất. Không dính dáng đến Telegram.

![Giao diện cuộc trò chuyện của TgWitness kèm các tin nhắn mẫu](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

Một không gian làm việc mẫu. Nhật ký của riêng quý vị sẽ được bắt đầu riêng biệt.

## Bắt đầu không gian làm việc của riêng quý vị

Đóng bản demo, rồi:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

Mở địa chỉ mà trình khởi chạy hiển thị và dán **token truy cập bảng điều khiển** từ tệp nó chỉ ra. Token đó dành cho TgWitness, không phải Telegram.

## Ghi lại tin nhắn đầu tiên của quý vị

1. [Kết nối một tài khoản Telegram chuyên dụng.](https://phishdestroy.github.io/TgWitness/vi/docs/accounts/)
2. Chọn một nhóm hoặc kênh và bắt đầu quan sát.
3. Gửi một tin nhắn trong nhóm thử nghiệm và xem nó xuất hiện trong sổ nhật ký.

Để cài đặt trên máy chủ, vui lòng làm theo hướng dẫn tại [Keep it running](https://phishdestroy.github.io/TgWitness/vi/docs/server/).
