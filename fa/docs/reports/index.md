# طراحی یک گزارش

Canonical page: https://phishdestroy.github.io/TgWitness/fa/docs/reports/

به خواننده مسیری واضح از سؤال پرونده تا سوابق ذخیره‌شده ارائه دهید.

Report Studio مجموعه‌ای از انتخاب داده‌ها، تاریخچه‌های قابل‌خوانش تغییرات، نمودارها و یافته‌های مکتوب شما را ترکیب می‌کند. هشت طرح یکپارچه برای خروجی‌های پشتیبانی‌شده HTML و PDF بومی اعمال می‌شوند. گزارش‌های HTML، PDF و JSON دارای مهرهای امضا‌شدهٔ خود هستند؛ فهرست ZIP نیز فایل‌های داخل بسته را پیوند می‌دهد. HTML و PDF پس از تکمیل چیدمان نهایی مهر و موم می‌شوند.

## ساخت گزارش در سه مرحله

1. **Exports را** باز کنید **→ پیکربندی و پیش‌نمایش → داده‌ها**. از کل فضای کاری استفاده کنید یا چت‌ها، نویسندگان، تاریخ‌های مشاهده UTC و انواع سوابق را انتخاب کنید. این تاریخ‌ها نشان می‌دهند که TgWitness چه زمانی رکورد را مشاهده کرده است.
2. در بخش **«طراحی و محتوا**»، یک پیش‌تنظیم طراحی و محتوا را انتخاب کنید. نمودارهای فعالیت، برچسب‌های شرکت‌کنندگان، رونوشت، تغییرات ذخیره‌شده و مطالب اختیاری تخته پرونده را انتخاب کنید. جزئیات پرونده و یادداشت‌های بررسی خود را اضافه کنید.
3. **پیش‌نمایش** **را** برای بررسی تعداد، فعالیت، شرکت‌کنندگان، سوابق نمونه‌برداری‌شده و بازه‌های شناسهٔ گمشده باز کنید. تنظیمات را ذخیره کنید، سپس قالب مورد نیاز خود را دانلود کنید.

### مطالب ذخیره‌شده را برای خواننده مرتب کنید

نمونه‌ی مصنوعی · طرح شماتیک، نه گزارش تولیدشده

1. **انتخاب کنید.** دو چت و دورهٔ مشاهده برای پرونده را انتخاب کنید.
2. **نوشتن.** یک طرح‌بندی و بخش‌هایی را که به سؤال پاسخ می‌دهند، انتخاب کنید.
3. **پیش‌نمایش.** شمارش‌های انتخاب‌شده و متن‌های ذخیره شدهٔ قبل و بعد را بازبینی کنید.
4. **تأیید کنید.** فایل نهایی را تولید کرده و امضای آن را با اثر انگشت فضای کاری مورد اعتماد مقایسه کنید.

#### مشاهدات منتخب

۲ چت · ۱ روز مشاهده

پیام‌ها، ویرایش‌ها و اعلان‌های حذف

#### ساختار گزارش

##### تغییر مقصد پرداخت

پرسش پرونده → دامنه → یافته‌ها → ارجاعات سوابق

**زمینه پیام**

**تغییرات ذخیره شده**

قبل: old.example.invalid → بعد: new.example.invalid

#### انتخاب را بازبینی کنید

۱۸ مشاهده · ۲ ویرایش ذخیره شده

زمان‌های ارسال، ویرایش و مشاهده برچسب‌های جداگانه‌ای دارند.

#### تحویل‌شدنی نهایی

PDF امضا شده + JSON امضا شده، یا یک فایل ZIP امضا شده همراه با گزارش قابل خواندن

گیرنده فایل و اثر انگشت مورد اعتماد را بررسی می‌کند.

## سبک خواندن را انتخاب کنید

**کلاسیک، ویرایشگاهی، جلسه توجیهی، تحلیلی، فنی، نمای کلی، مجموعه مطالعه‌ای و دفترچه یادداشت و حاشیه،** سوابق یکسان را در ترکیب‌های مختلف ارائه می‌دهند. تغییر طرح، انتخاب داده‌ها و یادداشت‌های نوشته‌شده را حفظ می‌کند. زبان گزارش را می‌توان از میان ۲۵ زبان پشتیبانی‌شده انتخاب کرد.

خوانش سری، موارد، دامنه، یافته‌ها و تغییرات را در اطراف یک ریل بخش گروه‌بندی می‌کند. دفترچه و حاشیه از فصل‌های شماره‌گذاری‌شده و حاشیهٔ وسیع استفاده می‌کنند. هر دو همچنین از نمای کلی HTML حساب‌ها و اشتراک‌گذاری نسخه‌ها پشتیبانی می‌کنند. PDFهای بومی با فونت‌های همراه تولید می‌شوند؛ رایانه کاربر برای ایجاد PDF نیازی به نصب مرورگر یا Node ندارد. PDFهای چینی، ژاپنی و کره‌ای علاوه بر این به فونت مناسبی روی سرور، مانند Noto Sans CJK، نیاز دارند که باید در سراسر سیستم نصب شده یا در پوشه `TGWITNESS_FONT_DIR` قرار داده شود. بدون آن، فایل ZIP گزارش‌های HTML و JSON را حفظ می‌کند.

## یک تغییر را همراه با زمینهٔ آن بخوانید

ویرایش‌های ذخیره شده قبل و بعد را نمایش می‌دهند. اعلان حذف می‌تواند همراه با آخرین نسخه ضبط‌شده باشد. پاسخ‌ها، نقل‌قول‌ها، فورواردها، واکنش‌ها، دکمه‌ها و متادیتای پیوست، ارجاعات موجود خود را حفظ می‌کنند. هش‌های SHA-256 فایل و هش‌های سوابق ژورنال به‌طور جداگانه برچسب‌گذاری می‌شوند.

پیش‌نمایش طرح، با استفاده از رکوردهای همسان در میان ۵۰٬۰۰۰ رکورد اول منبع، اجزای جلد، بررسی و نمودار را نمایش می‌دهد. پیش‌نمایش جداگانه داده‌ها، برای شمارش دقیق انتخاب‌ها، کل اسنپ‌شات پایدار ژورنال را اسکن می‌کند و محدودیت‌های نمونه‌ای نمایش‌داده‌شده را برچسب‌گذاری می‌کند. یک PDF برای بررسی صفحه‌آرایی نهایی ایجاد کنید. صادرات کامل حساب کاربری دارای یک نمای کلی HTML است؛ PDFهای چت جداگانه آن از طرح انتخاب‌شده استفاده می‌کنند.

## نسخهٔ گیرنده را با دقت انتخاب کنید

فیلترهای گزارش، گزارش قابل‌خواندن را شکل می‌دهند. فایل ZIP کامل شواهد، دفترچه اصلی و پیوست‌ها را حفظ می‌کند. در صورتی که دریافت‌کننده باید تنها داده‌های منتخب را دریافت کند، از [تحویل](https://phishdestroy.github.io/TgWitness/fa/docs/handover/) [حداقلی](https://phishdestroy.github.io/TgWitness/fa/docs/handover/) استفاده کنید. [محتوای گزارش را](https://phishdestroy.github.io/TgWitness/fa/docs/reference/case-reports/) مشاهده [و تأیید کنید](https://phishdestroy.github.io/TgWitness/fa/docs/reference/case-reports/) یا [خروجی نهایی را بررسی نمایید](https://phishdestroy.github.io/TgWitness/fa/docs/exports/).
