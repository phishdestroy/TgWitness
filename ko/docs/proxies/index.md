# 프록시 선택

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/proxies/

계정을 계속 연결된 상태로 유지하십시오. 경로가 서버 주소를 사용할 수 있는 시점을 명확하게 지정하십시오.

## 먼저 IP 모드를 선택하세요

01**IP 숨기기**

프록시를 사용하십시오. 프록시가 모두 작동하지 않을 경우, 텔레그램에 직접 연결하지 않은 상태에서 기다리십시오.

02**대체 옵션 허용**

설정된 지연 시간이 지난 후 직접 접속을 허용하고, 응답이 있는 프록시로 복귀합니다.

03**터널 / VPN**

호스트의 네트워크를 통한 직접 경로를 허용합니다. 이 옵션은 VPN을 설치하거나 확인하지 않습니다.

경로에 따라 연결 방식이 결정됩니다. IP 모드는 직접 연결이 허용되는지 여부를 결정합니다.

## 풀이 경로를 유지하도록 하십시오

1. **계정** 열기 **→ 설정 → 연결 설정**.
2. IP 모드와 **자동 MTProxy를** 선택하거나, 고정 경로를 입력하십시오.
3. **'Telegram 연결 테스트'를** 저장하고 실행하세요. 로그인 전에도 작동합니다.
4. 수집을 시작한 후, 제어 메시지가 저널에 정상적으로 기록되었는지 확인하십시오.

새로운 작업 공간에서는 IP 숨기기 기능을 갖춘 자동 MTProxy를 사용합니다. 이 풀은 4개의 공개 소스를 결합하여 항목을 탐색하고, 작동하는 경로를 유지하며, 오류가 발생한 프록시를 대체합니다. 다운로드에 실패한 경우 이전 스냅샷이 유지됩니다.

## 자신의 프록시를 사용하세요

SOCKS5 또는 HTTP CONNECT 세부 정보를 입력하거나, 지원되는 텔레그램 프록시 링크를 붙여넣거나, 운영자 카탈로그를 제공하십시오. 활성 경로를 변경하기 전에 관찰을 일시 중지하십시오. `ee`로 시작하는 가짜 TLS MTProxy 비밀 키는 여전히 지원되지 않습니다.

**회전, 공유 및 재시도 설정**

**‘매개변수(Parameters)’ → ‘자동 MTProxy’에서** 오류 임계값, 대기 시간, 계획된 로테이션 및 프록시당 계정 수를 설정합니다. 공유 한도를 1로 설정하면 전용 접속 경로가 없을 때 계정이 대기 상태가 됩니다. 목록 새로고침 및 프로브 간격은 메인 작업 공간의 값을 따릅니다. 별도의 프록시를 사용한다고 해서 별도의 출구 IP가 보장되는 것은 아닙니다.

## 텔레그램과 외부 요청을 분리

MTProxy는 텔레그램 트래픽만 처리합니다. 타임스탬프, 알림, 복사본 및 출처 확인은 별도의 SOCKS5/HTTP 프록시, 계정의 SOCKS5/HTTP 경로, 또는 IP 모드가 허용하는 경우 Direct를 사용합니다. 이러한 외부 요청은 비활성화할 수 있습니다.

`TGWITNESS_PROXY_FEED_PROXY`를 명시적으로 설정하면 피드 다운로더의 경로가 구성됩니다. [독립적인](https://phishdestroy.github.io/TgWitness/ko/docs/witness/)위트니스는 자체 설정을 유지합니다. 이러한 제어 기능은 시스템 VPN을 설치하거나 브라우저 트래픽을 우회하지 않습니다.

[모든 모드, 기본 설정 및 소스 목록을](https://phishdestroy.github.io/TgWitness/ko/docs/reference/connection/#ip-modes) 확인하거나, [계정 경로를 변경할 수 있는 사용자를 선택하세요](https://phishdestroy.github.io/TgWitness/ko/docs/access/).
