# Мини-приложения

Мини-приложение Telegram — это веб-страница, которую бот открывает внутри клиента: интернет-магазин,
получение «бонуса», подключение кошелька. Мошеннические боты используют их для сбора номеров телефонов,
семенных фраз и платежей вне чата. TgWitness открывает мини-приложение так же, как это
делает клиент Telegram, загружает его один раз в изолированном «безголовом» Chromium и записывает
его действия.

<a id="in-the-panel"></a>
## На панели

Под сообщением находится кнопка мини-приложения с надписью **Открыть мини-приложение**. В чате
в разделе **Информация → Мини-приложения** перечислены чаты, в которых открываются мини-приложения:

- кнопки под сообщениями и кнопки на клавиатуре для ответа;
- ссылки `t.me/<bot>/<app>` и `t.me/<bot>?startapp` в сообщениях, объектах и кнопках-ссылках;
  ;
- в чате с ботом — кнопка меню бота и его основное приложение.

**Открыть** запрашивает подтверждение, а затем:

1. запрашивает у Telegram адрес запуска как данный аккаунт, что является действием
   аккаунта: бот узнает, что этот аккаунт открыл приложение, и видит его имя и ID.
   В случае кнопки под сообщением бот может отправить одно сообщение в чат от
   имени аккаунта, пока приложение открыто;
2. один раз загружает адрес в Chromium с экрана телефона через
   маршрут рабочей среды для запросов вне Telegram;
3. записывает результат в подписанный журнал и отображает его в разделе **Зарегистрированные
   открытия**.

Только главный администратор может открыть мини-приложение.

<a id="what-is-recorded"></a>
## Что фиксируется

- каждый запрос с указанием метода, типа, статуса, MIME-типа и размера, а также
  объекта и выдающего органа сертификата TLS; хосты, отличные от собственного хоста приложения,
  указываются отдельно;
- адреса WebSocket и до 30 фреймов для каждого;
- каждый вызов, который страница делает к API Telegram WebApp, например, запрос на
  номер телефона, оплату, открытие ссылки или отправку данных боту; запросы,
  требующие каких-либо действий от пользователя, помечаются;
- отображавшиеся диалоговые окна (они закрыты), окна, которые пытались открыть (с указанием их
  адреса; они не загружены), запущенные загрузки, формы и поля ввода;
- скриншоты через 2, 8 и 16 секунд после загрузки и всей страницы, страница в том
  виде, в каком она была после загрузки, и до 25 её скриптов;
- ссылки, домены, кошельки, аккаунты в Telegram, адреса электронной почты и номера телефонов,
  найденные на странице, её трафик и звонки в Telegram; кошельки в скриптах — только если
  их контрольная сумма действительна.

Адрес запуска содержит подписанные данные запуска (`tgWebAppData`), которые в течение некоторого времени служат в качестве
логина для входа в приложение. Эти данные удаляются из всех записей:
адрес не содержит фрагмента, а данные, их хеш и идентификатор запроса
заменяются на `[removed]` в запросах, фреймах, вызовах и сохраненных файлах.

Записи в журнале:

| Запись | Значение |
|---|---|
| `webapp.launch_requested` | Telegram вернул адрес запуска; действие с учетной записью |
| `webapp.launch_failed` | Telegram отказался открыть его, ответив: |
| `webapp.file` | один сохраненный файл (`media_sha256`, размер, роль), привязанный к архиву как сохраненный медиафайл |
| `webapp.captured` | всё, что перечислено выше, с указанием количества предметов, выпавших при достижении максимального уровня |
| `webapp.capture_failed` | не удалось загрузить приложение |

Скриншоты отображаются на временной шкале расследования и в его документах, индикаторы
отображаются в отчетах в разделе «**мини-приложение**», а в архивах доказательств файлы
хранятся под тегом `media/` и проверяются с помощью `verify.py`.

<a id="browser"></a>
## Браузер

TgWitness запускает Chromium через `--remote-debugging-pipe`; дополнительные пакеты Python
не требуются. Программа ищет файлы `chromium`, `chromium-browser`, `google-chrome` и
Playwright Chromium; укажите в `TGWITNESS_CHROMIUM` путь к нужному файлу.

Приложение работает в собственном контексте браузера. Каждое соединение, которое оно устанавливает,
включая WebSockets, проходит через шлюз обратной связи, который открывает его по
маршруту рабочей области, как и любой другой запрос за пределами Telegram. Собственные
фоновые запросы Chromium (вход в систему, обновления компонентов) поступают на второй шлюз, который их
отклоняет; хост Google, с которым браузер связывается самостоятельно, а страница никогда не запрашивалась,
указан под тегом `browser_connections` вместо
соединений приложения. Когда этот маршрут отключен или включен режим «Скрыть IP» без прокси,
приложение не открывается. Адреса внутри локальной сети отклоняются, и
WebRTC не может отправлять UDP за пределы маршрута.

Chromium работает в своей «песочнице». Когда TgWitness запускается с правами root, Chromium не может использовать
её, поэтому открытие файла будет запрещено, если не установлен атрибут `TGWITNESS_BROWSER_NO_SANDBOX=1`; делайте это
только на компьютере, используемом для этой работы.

Без браузера или в системе Windows приложение **Открыть** по-прежнему запрашивает адрес у Telegram,
а затем загружает страницу и до 12 собственных скриптов, анализируя их на наличие адресов
и конечных точек WebSocket.

<a id="api"></a>
## API

```sh
curl -sS "http://127.0.0.1:8000/api/webapp?chat_id=-1001234567890&limit=200" \
  -H "Authorization: Bearer $TGWITNESS_TOKEN"
```

Отображает только сохраненные записи и ни с кем не связывается: `entries`
— список кнопок и ссылок,
`captures`
— зарегистрированные открытия, `browser`
— информация о том, можно ли использовать браузер. Доступ
ограничен выбранными чатами, которые видят только свои собственные чаты; `GET /api/webapp/captures/{seq}?chat_id=…`
— возвращает одно зарегистрированное открытие.

```sh
curl -sS -X POST http://127.0.0.1:8000/api/webapp/open \
  -H "Authorization: Bearer $TGWITNESS_TOKEN" -H "Content-Type: application/json" \
  -d '{"chat_id": 5104055776, "entry": {"type": "button", "seq": 1522, "row": 0, "column": 0}}'
```

`entry.type` — это `button` (с записью с клавиатуры `seq`, `row` и `column`),
`link` (с `url`), `menu` или `main`.

`POST /api/webapp/inspect` с помощью `{"url": "https://app.example/start", "scripts": 12}`
загружает уже известную вам страницу без обращения к Telegram, выполняет до `scripts`
своих собственных скриптов и записывает `webapp.inspected`.

<a id="limits"></a>
## Ограничения

Одна загрузка, в один момент, с адреса данного рабочего пространства. Другому посетителю, в другое время или
с другого адреса может быть предоставлено что-то другое, и приложение может проверить, где оно
открыто. Ограничение на количество запросов составляет 400, на вызовы Telegram — 200, а общее время открытия —
около 75 секунд; количество отклоненных элементов фиксируется. TgWitness не
нажимает внутри приложения и не заполняет его формы.
