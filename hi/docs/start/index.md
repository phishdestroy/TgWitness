# Telegram · कुछ ही मिनटों में शुरू करें

Canonical page: https://phishdestroy.github.io/TgWitness/hi/docs/start/

पहले डेमो में घूमें, फिर अपना खाता जोड़ें।

## खाते के बिना देखें

प्रोजेक्ट लें, **Python 3.11 या नया** रखें, डेमो चलाएँ। बाकी सब लॉन्चर सेट करता है।

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### विंडोज

```
.\scripts\Demo.cmd
```

### लिनक्स / मैकओएस

```
sh start.sh --demo
```

गढ़े हुए संदेशों वाला वर्कस्पेस ब्राउज़र में खुलता है। कोई चैट खोलें, संपादन की तुलना करें, एक्सपोर्ट देखें। Telegram शामिल नहीं।

![TgWitness संवाद दृश्य नमूना संदेशों के साथ](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

एक नमूना कार्यक्षेत्र। आपका अपना जर्नल अलग से शुरू होता है।

## अपना स्वयं का कार्यक्षेत्र प्रारंभ करें

डेमो बंद करें, फिर:

### विंडोज

```
.\Start.cmd
```

### लिनक्स / मैकओएस

```
sh start.sh
```

लॉन्चर जो पता दिखाए उसे खोलें और बताई गई फ़ाइल से **पैनल एक्सेस टोकन** चिपकाएँ। यह TgWitness के लिए है, Telegram के लिए नहीं।

## अपना पहला संदेश कैप्चर करें

1. [एक समर्पित टेलीग्राम खाता कनेक्ट करें।](https://phishdestroy.github.io/TgWitness/hi/docs/accounts/)
2. कोई ग्रुप या चैनल चुनें और अवलोकन शुरू करें।
3. अपने टेस्ट ग्रुप में संदेश भेजें और उसे जर्नल में आते देखें।

सर्वर इंस्टॉलेशन के लिए, [Keep it running](https://phishdestroy.github.io/TgWitness/hi/docs/server/) का पालन करें।
