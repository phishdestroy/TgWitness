# چند منٹ میں شروع کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/start/

پہلے ڈیمو میں گھومیں، پھر اپنا اکاؤنٹ جوڑیں۔

## اکاؤنٹ کے بغیر دیکھیں

پروجیکٹ لیں، **Python 3.11 یا نیا** رکھیں، ڈیمو چلائیں۔ باقی سب لانچر سیٹ کرتا ہے۔

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### ونڈوز

```
.\scripts\Demo.cmd
```

### لینکس / میک او ایس

```
sh start.sh --demo
```

فرضی پیغامات والی ورک اسپیس براؤزر میں کھلتی ہے۔ چیٹ کھولیں، ترمیم کا موازنہ کریں، ایکسپورٹ دیکھیں۔ Telegram شامل نہیں۔

![TgWitness گفتگو کا منظر نمونہ پیغامات کے ساتھ](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

ایک نمونہ ورک اسپیس۔ آپ کا اپنا جریدہ الگ سے شروع ہوتا ہے۔

## اپنا ذاتی ورک اسپیس شروع کریں

ڈیمو بند کریں، پھر:

### ونڈوز

```
.\Start.cmd
```

### لینکس / میک او ایس

```
sh start.sh
```

لانچر جو پتہ دکھائے وہ کھولیں اور بتائی گئی فائل سے **پینل رسائی ٹوکن** پیسٹ کریں۔ یہ TgWitness کے لیے ہے، Telegram کے لیے نہیں۔

## اپنا پہلا پیغام محفوظ کریں

1. [ایک مخصوص ٹیلیگرام اکاؤنٹ منسلک کریں۔](https://phishdestroy.github.io/TgWitness/ur/docs/accounts/)
2. کوئی گروپ یا چینل چنیں اور مشاہدہ شروع کریں۔
3. اپنے ٹیسٹ گروپ میں پیغام بھیجیں اور اسے جرنل میں آتا دیکھیں۔

سرور انسٹالیشن کے لیے، [اسے چلتا رکھ](https://phishdestroy.github.io/TgWitness/ur/docs/server/)یں۔
