# Telegram · اکاؤنٹ منسلک کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/accounts/

ایک ورک اسپیس = ایک اکاؤنٹ، اس کا جرنل اور اس کی کلید۔

## سائن ان کرنے کا طریقہ منتخب کریں

**اکاؤنٹس** ← ورک اسپیس شامل کریں ← کنکشن سیٹنگز۔ اس کے لیے الگ اکاؤنٹ استعمال کریں۔

- **QR کوڈ:** Telegram کی ڈیوائسز اسکرین سے اسکین کریں اور تصدیق کریں۔
- **فون نمبر:** نمبر، کوڈ، پھر 2FA پاس ورڈ اگر ہو۔
- **سیشن امپورٹ:** آپ کی اپنی سیشن فائل یا Telegram Desktop ڈیٹا۔

بلٹ اِن API پروفائل یا اپنا API ID اور hash استعمال کریں۔ یہ صرف ایپ کی شناخت کرتا ہے، نہ آپ کو لاگ اِن کرتا ہے نہ کچھ چھپاتا ہے۔

**کیا پہلے پروکسی کی ضرورت ہے؟**

آپ سائن ان کرنے سے پہلے [کنکشن کا راستہ منتخب اور آزما](https://phishdestroy.github.io/TgWitness/ur/docs/proxies/) سکتے ہیں۔ ہر اکاؤنٹ کا اپنا راستہ ہوتا ہے۔

## مشاہدہ کرنے کے لیے انتخاب کریں

1. اپنی ضرورت کی چیٹس، گروپس یا چینلز چنیں۔
2. جمع کرنے کی سیٹنگز دیکھیں، میڈیا سمیت۔
3. شروع کریں اور کنکشن اور حالیہ سرگرمی جانچیں۔

اکاؤنٹ کے پاس رسائی ہونی چاہیے۔ ایڈمنز اور ممبرز مختلف چیزیں دیکھتے ہیں، جرنل دکھاتا ہے کہ اس اکاؤنٹ کو کیا ملا۔

پورا اکاؤنٹ؟ **ذرائع ← مشاہدے کا دائرہ ← تفتیشی موڈ**، جانچیں، **دائرہ محفوظ کریں**۔ مکمل رہنمائی: [پورے اکاؤنٹ کی تفتیش](https://phishdestroy.github.io/TgWitness/ur/docs/cases/)۔

## پورے راستے کی جانچ کریں

اپنے ٹیسٹ گروپ میں دوسرے اکاؤنٹ سے پیغام بھیجیں، ترمیم کریں، حذف کریں۔ تینوں جرنل میں نظر آنے چاہئیں۔ پھر [ایکسپورٹ اور تصدیق کریں](https://phishdestroy.github.io/TgWitness/ur/docs/exports/)۔

"منسلک" کا مطلب ہے کنکشن کام کر رہا ہے۔ پکڑا گیا ٹیسٹ پیغام کا مطلب ہے واقعات واقعی پہنچ رہے ہیں۔

## ایک اور اکاؤنٹ شامل کریں

**اکاؤنٹس** میں نئی ورک اسپیس، وہی مراحل۔ ہر اکاؤنٹ کی کلید کا فنگر پرنٹ نوٹ کریں تاکہ بعد میں ایکسپورٹس میں فرق کر سکیں۔
