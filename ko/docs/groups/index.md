# Telegram · 계정 그룹 관리

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/groups/

여러 계정을 함께 실행하되, 각자 자체 기록과 키를 유지합니다.

그룹은 연결 상태, 시작/일시 중지, 공유 설정, 내보내기를 한 화면에 모읍니다. 여러 계정이 같은 사건을 다룰 때 편리합니다.

## 그룹 개요 열기

**계정**에서 그룹을 엽니다. 각 계정의 상태, 경로, 지연 시간, 마지막으로 저장된 메시지가 표시됩니다. **주의 필요**에는 문제 있는 계정이 나열되고, **수정**으로 바로 이동합니다.

**모두 시작** / **모두 일시 중지**는 실행 전에 묻습니다. **그룹 설정**은 공유되지만, 계정 고유의 값은 귀하가 바꿀 때까지 유지됩니다.

### 그룹 전반에 걸친 경로 변경 사항 검토

합성 예시 · 예시적인 검증 항목 및 결과

1. **선택.** 그룹을 선택하고 변경될 계정을 검토하십시오.
2. **준비.** 별도로 유지해야 할 경우 계정의 고유 경로를 유지하십시오.
3. **확인.** 제안된 연결을 테스트하고 측정 결과를 검토하십시오.
4. **적용하십시오.** 저장하기 전에 다시 확인하고 각 계정에 대한 결과를 검토하십시오.

#### 사건 담당 팀

채널 수집기 · 그룹 수집기 · 참조 계정

3개의 별도 작업 공간

#### 검토된 내용

2개의 계정이 제안된 경로를 따릅니다.

참조 계정은 별도의 경로를 따릅니다.

#### 준비 점검 사항

채널 수집기: 텔레그램 전송 시간 84 ms

그룹 수집기: 텔레그램 전송 시간 91 ms

이 숫자들은 예시를 위한 가상의 측정값입니다.

#### 응용 결과

채널 수집기: 저장 완료, 관찰 재개.

그룹 수집기: 재확인 실패, 이전 설정으로 복원됨.

참조 계정: 기존 경로 유지.

## 검토 단계를 추가하여 경로를 변경하십시오.

1. **그룹 경로 변경**, 유형과 설정을 고릅니다.
2. **선택 검토**: 어느 계정이 바뀌고 어느 계정에 자체 경로가 있는지 봅니다.
3. **준비 및 확인**은 새 텔레그램 연결을 테스트하고, 가능하면 출구 IP도 확인합니다.
4. **확인된 연결 적용** 후 각 결과를 봅니다. 실행 중인 계정은 다시 이어 가고, 멈춰 있던 계정은 그대로 멈춰 있습니다.

지연 시간은 텔레그램 연결을 설정하는 데 걸린 시간이고, 출구 IP는 확인 시점에 경로가 보여 준 값입니다. 결과는 계정마다 다를 수 있습니다.

## 중복 액세스 사용

**여러 계정이 보는 채팅**에는 공유 소스와 그 범위가 나열됩니다. 채널과 슈퍼그룹은 **… 계정으로 내보내기**로 여러 계정이 한 번에 내보낼 수 있습니다. 개인 채팅과 일반 그룹은 안 되며, 메시지 번호가 계정별이기 때문입니다.

## 그룹을 패키지로 내보내기

**그룹 내보내기**는 모든 계정의 서명된 내보내기와 그 서명된 목록이 든 ZIP 하나를 만듭니다. 각각 검증을 위해 자체 지문을 유지합니다. 통합 타임라인은 여전히 직접 만듭니다.
