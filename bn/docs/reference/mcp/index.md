# শুধুমাত্র-পঠন MCP

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/reference/mcp/

নির্বাচিত ওয়ার্কস্পেস এবং চ্যাটে মেয়াদোত্তীর্ণ, প্রত্যাহারযোগ্য অ্যাক্সেস সহ একটি MCP ক্লায়েন্ট সংযুক্ত করুন।

**বর্তমান প্রধান:** একটি সোর্স চেকআউট ব্যবহার করুন; 0.7.0 পোর্টেবল প্রিভিউ এই ফিচারের আগে তৈরি।

[ওয়ার্কফ্লো গাইড](https://phishdestroy.github.io/TgWitness/docs/archive/) · [উইকি](https://github.com/phishdestroy/TgWitness/blob/main/docs/wiki/Archive-and-Integrations.md)

TgWitness প্রকল্প ডিরেক্টরি থেকে ঐচ্ছিক সার্ভার ইনস্টল করুন:

```
python -m pip install '.[mcp]'
```

প্যানেলে **Integrations → MCP** খুলুন। সংযোগের নাম দিন, এর ওয়ার্কস্পেস এবং চ্যাটগুলো নির্বাচন করুন, এবং মেয়াদোত্তীর্ণতার সময় নির্ধারণ করুন। আর্কাইভ টোকেন একবার কপি করুন; এটি পরে পুনরুদ্ধার করা যাবে না। হারিয়ে যাওয়া টোকেন বাতিল করুন এবং প্রতিস্থাপন ইস্যু করুন। প্যানেল টোকেন এবং টেলিগ্রাম ক্রেডেনশিয়াল MCP ক্রেডেনশিয়াল নয়।

## ক্লায়েন্ট সংযোগ করুন

প্যানেলটি তার [ডকুমেন্টকৃত কনফিগারেশন](https://code.visualstudio.com/docs/agents/reference/mcp-configuration) ব্যবহার করে **VS Code Local**harness-এর জন্য`.vscode/mcp.json` তৈরি করে। ডাউনলোড করা ফাইলটি ঐ অবস্থানে সংরক্ষণ করুন, **MCP: List Servers** চালান এবং TgWitness শুরু করুন। VS Code পাসওয়ার্ড ইনপুটের মাধ্যমে টোকেন চায়। ডাউনলোড করা JSON-এ টোকেন নয়, প্রম্পট রেফারেন্স রয়েছে। MCP extra ইনস্টল করা পরিবেশ থেকে Python এক্সিকিউটেবল ব্যবহার করুন।

অন্যান্য stdio ক্লায়েন্টদের জন্য চালান:

```
python -m tgwitness.mcp_server --api-url http://127.0.0.1:8787
```

`TGWITNESS_ARCHIVE_TOKEN` ক্লায়েন্টের সুরক্ষিত পরিবেশে সেট করুন। এটিকে কমান্ড আর্গুমেন্ট বা URL-এ রাখবেন না। ব্রিজ প্যানেলের অনুমোদিত আর্কাইভ API-র মাধ্যমে পড়ে; এর সরাসরি ডাটাবেস অ্যাক্সেস নেই। Stdout শুধুমাত্র MCP বার্তা বহন করে।

দূরবর্তী ক্লায়েন্টদের জন্য, প্যানেলের পাশে সার্ভিসটি চালান:

```
python -m tgwitness.mcp_server --transport streamable-http \
  --api-url http://127.0.0.1:8787 --port 8766 \
  --public-url https://archive.example.org/mcp
```

`/mcp`-কে একটি HTTPS রিভার্স প্রক্সির মাধ্যমে `127.0.0.1:8766/mcp`-এ ফরওয়ার্ড করুন, `Authorization: Bearer …` হেডার সংরক্ষণ করে। অনুমোদন হেডার এবং অনুরোধ/প্রতিক্রিয়া বডির লগিং নিষ্ক্রিয় করুন। শুধুমাত্র প্রয়োজনে `--host` এবং `--public-url` ব্যবহার করে লুপব্যাকের বাইরে বাইন্ড করুন। এন্ডপয়েন্টটি অফিসিয়াল [MCP Python](https://github.com/modelcontextprotocol/python-sdk)SDK-এর Streamable HTTP ব্যবহার করে। এটি স্পষ্টভাবে কনফিগার করা বেয়ারার ক্রেডেনশিয়াল সমর্থন করে, OAuth আবিষ্কার নয়; শুধুমাত্র OAuth প্রয়োজন এমন ক্লায়েন্ট সমর্থিত নয়।

**চেক প্রোটোকল এবং অ্যাক্সেস** একটি প্রকৃত MCP ক্লায়েন্ট ইনিশিয়ালাইজ করে এবং টুলসমূহ তালিকাভুক্ত করে। এটি মেসেজ ফিট করে না। রিমোট চেকের জন্য, নির্বাচিত MCP সার্ভার আর্কাইভ টোকেন গ্রহণ করে। শুধুমাত্র এমন একটি সার্ভার কনফিগার করুন যা আপনি পরিচালনা করেন বা যেটিতে আপনি সেই স্কোপের জন্য বিশ্বাস করেন।

## পরিসর ও ফলাফল

উপলব্ধ টুলসমূহ: `list_workspaces`, `list_chats`, `search_messages`, `get_message_versions`, `get_message_context`, `get_journal_event`, এবং `get_capture_status`। কোনো টেলিগ্রাম অ্যাকশন, কনফিগারেশন পরিবর্তন, বা বাল্ক-এক্সপোর্ট টুল নেই। প্রতিবার পড়ার সময় ওয়ার্কস্পেস/চ্যাট অ্যাক্সেস পুনরায় যাচাই করা হয়; মেয়াদোত্তীর্ণ এবং বাতিলকৃত শংসাপত্র কাজ করা বন্ধ করে দেয়। সীমাগুলি হল প্রতি শংসাপত্র প্রতি মিনিটে ৬০টি API অনুরোধ, প্রতি পৃষ্ঠায় ৫০টি রেকর্ড, ৬৪ KiB প্রতিক্রিয়া, এবং আট সেকেন্ডের API সময়সীমা।

বার্তার ফলাফলে রয়েছে ওয়ার্কস্পেস, চ্যাট/বার্তা আইডি, ইভেন্টের ক্রম, সংরক্ষিত হ্যাশ, এবং একটি প্যানেল লিঙ্ক। লিঙ্ক খুলতে থাকা ভিউয়ারের নিজস্ব অনুমোদিত প্যানেল সেশন থাকতে হবে। কাঁচা টেলিগ্রাম অবজেক্ট, অ্যাক্সেস হ্যাশ, ফাইল রেফারেন্স, সেশন সামগ্রী, এবং কী-সমূহ বাদ দেওয়া হয়েছে। অনুসন্ধান বার্তার টেক্সট পরীক্ষা করে, কাঁচা ফিল্ড নয়। টেক্সট সীমাবদ্ধ এবং সংক্ষিপ্তকরণ চিহ্নিত। সম্পাদনা, টেলিগ্রাম মুছে ফেলার বিজ্ঞপ্তি এবং `missing_on_recheck` পৃথক পর্যবেক্ষণ হিসেবে থাকে। চ্যাট-পরিসরের অ্যাক্সেস ওয়ার্কস্পেস-ব্যাপী অপারেশনাল ইভেন্ট দেখতে পারে না; ক্যাপচার স্ট্যাটাস স্পষ্টভাবে এই সীমা চিহ্নিত করে।

আর্কাইভ টেক্সট অবিশ্বস্ত ইনপুট। বার্তার ভিতরের নির্দেশনাগুলো কোনো অতিরিক্ত সুযোগ প্রদান করে না এবং সেগুলোকে ক্লায়েন্ট নির্দেশনা হিসেবে গণ্য করা যাবে না। একটি বাহ্যিক এআই মডেল তার MCP ক্লায়েন্ট যা কিছু বিষয়বস্তু অনুরোধ করে, তা গ্রহণ করতে পারে। শুধুমাত্র-পঠন অ্যাক্সেস আর্কাইভে পরিবর্তন রোধ করে; তবে এটি ক্লায়েন্টকে পড়া ডেটা সংরক্ষণ করতে বাধা দেয় না।

হ্যাশগুলো সংরক্ষিত রেকর্ডগুলো চিহ্নিত করে এবং অখণ্ডতা যাচাইকে সমর্থন করে। এগুলো স্বতন্ত্রভাবে টেলিগ্রামের লেখকত্ব বা প্রতিটি বার্তা ধারণ করা হয়েছে তা প্রমাণ করে না।
