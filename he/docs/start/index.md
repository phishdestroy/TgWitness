# התחילו תוך דקות ספורות

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/start/

ראשית, עיין בדוגמה מעשית. לאחר מכן, חבר את החשבון שלך.

## תסתכלו מסביב ללא צורך בחשבון

הורידו או שיכפלו את הפרויקט, התקינו **את Python 3.11 או גרסה מאוחרת יותר**, והפעילו את ההדגמה. תוכנת ההפעלה יוצרת סביבה מקומית ומתקינה את התלות הנדרשות.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

הדפדפן פותח סביבת עבודה עם הודעות פיקטיביות. פתחו שיחה, השוו עריכה ובדקו ייצוא. מצב ההדגמה אינו מתחבר ל-Telegram.

![תצוגת שיחה ב-TgWitness עם דוגמאות להודעות](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

דוגמה לסביבת עבודה. היומן האישי שלכם מתחיל בנפרד.

## הקימו סביבת עבודה משלכם

סגור את תהליך ההדגמה, ולאחר מכן השתמש במפעיל הרגיל:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

פתח את הכתובת המקומית המוצגת על ידי תוכנת ההפעלה. אם תתבקש, הזן את **אסימון הגישה לפאנל** מהקובץ המקומי ששמו מופיע במסוף. פעולה זו פותחת את TgWitness; היא נפרדת מהכניסה ל-Telegram.

## תעד את ההודעה הראשונה שלך

1. [חבר חשבון טלגרם ייעודי.](https://phishdestroy.github.io/TgWitness/he/docs/accounts/)
2. בחר קבוצה או ערוץ שהחשבון יכול לגשת אליהם, ולאחר מכן התחל במעקב.
3. שלחו הודעה חדשה בקבוצת בדיקה שבשליטתכם ובדקו שהיא מופיעה ביומן.

להתקנת שרת, עקבו אחר ההוראות [ב-Keep it running](https://phishdestroy.github.io/TgWitness/he/docs/server/).
