## ریکارڈ تبدیل کریں۔ ہیش کی پیروی کریں۔

ہر ریکارڈ میں پچھلے ریکارڈ کا ہیش شامل ہوتا ہے۔ اس کا اپنا ہیش واقعے کے فیلڈز کو کور کرتا ہے، بشمول اس لنک کے۔ ایک بیرونی طور پر برقرار رکھا گیا چیک پوائنٹ جرنل کی مخصوص لمبائی اور ہیڈ ہیش کو پن کرتا ہے۔

## اصلی قواعد، چند سطروں میں

ہیش + دستخط

h0 = 064
hi = hex(SHA-256(C(ei)))
σi = Ed25519.Sign(sk, unhex(hi))

**C** نو ایونٹ فیلڈز کو UTF-8 JSON کے طور پر سیریلائز کرتا ہے: ترتیب شدہ کیز، اضافی وائٹسپیس نہیں، ASCII ایسکیپنگ نہیں اور NaN/انفینٹی نہیں۔ ایونٹ کا `previous_hash` hi−1 ہے۔ دکھایا گیا h0 کا مطلب 64 صفر حروف ہے؛ سگنیچرز 32 خام ڈائجسٹ بائٹس کو کور کرتے ہیں۔

یہ نو فیلڈز ہیں: `seq`، `observed_at`، `source_at`، `kind`، `chat_id`، `message_id`، `actor_id`، `payload` اور `previous_hash`۔ یہ TgWitness کی [دستاویزی JSON انکوڈنگ](https://phishdestroy.github.io/TgWitness/ur/docs/reference/evidence/#event-canonicalization) ہے؛ ہیش اور سگنیچر بذاتِ خود ہیش-ان پٹ فیلڈز نہیں ہیں۔

محفوظ شدہ چیک پوائنٹ

Nexport ≥ Ncheckpoint
hexport[Ncheckpoint] = Hcheckpoint

پِن کیے گئے کلیکٹر کی تحت چیک پوائنٹ کے دستخط کی تصدیق کریں، پھر اس کی حد کو تصدیق شدہ جرنل سے موازنہ کریں۔ بعد میں کیا گیا ایکسپورٹ مزید ریکارڈز پر مشتمل ہو سکتا ہے؛ اسے پھر بھی پہلے کے چیک پوائنٹ پر مطابقت رکھنا چاہیے۔
