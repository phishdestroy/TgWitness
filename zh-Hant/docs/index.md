## 您捕獲的第一則訊息

[### 幾分鐘內即可開始使用 請使用範例資料試用 TgWitness，接著在 Windows、Linux 或 macOS 上建立您專屬的 Telegram 監測工作區。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/start/)[### 專用帳戶 請準備一個專用的 Telegram 帳號用於資料蒐集。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/dedicated-account/)[### 連結帳戶 透過 QR 碼、電話號碼或會話匯入功能連接 Telegram。選擇資料來源，並確認新訊息已成功傳送至您的日誌。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/accounts/)[### 選擇代理伺服器 維護自動 MTProxy 路由，或使用您自己的代理伺服器。選擇 IP 模式、備用規則以及外部請求的路由。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/proxies/)[### 匯出與驗證 匯出擷取的 Telegram 通訊紀錄、驗證簽名，並將日誌與獨立見證人保留的檢查點進行比對。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/exports/)[### GitHub Actions 擷取 在臨時 GitHub Runner 上匯出一個 Telegram 聊天紀錄。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/capture/)

## 親身試用，即刻掌握

[### 了解證據如何運作 追蹤訊息從擷取到檢查點的整個過程。修改一個範例記錄，重新計算其 SHA-256 鏈，並觀察保留的檢查點會偵測到什麼變化。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/concepts/)[### 跨所有聊天室進行調查 針對頻道、群組、私人聊天及機器人，進行端到端的 Telegram 調查：包含整個帳戶的擷取、歷史紀錄、聯絡人、連結、檔案、時間軸及經驗證的證據。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/cases/)[### 確保安全 了解會話、金鑰與證據的儲存位置、哪些資料會離開您的裝置、防護措施涵蓋的範圍，以及如何強化系統安全性。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/security/)

## 僅添加必要內容

[### 瀏覽檔案庫 載入歷史紀錄、搜尋已儲存的記錄、檢視 AI 來源，並串接您的工具。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/archive/)[### 分享案例 讓審查員和分析師能夠存取選定的帳戶和聊天室，並設有獨立的權限、會話限制及可撤銷的存取憑證。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/access/)[### 設定 Witness 機器人 透過獨立的見證者（配有專屬金鑰及唯讀收集器存取權限），將簽署過的日誌檢查點發佈至您的 Telegram 頻道。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/witness/)[### 讓它持續運作 請在具備持久儲存空間、私人控制台存取權限、備份功能，且重啟後能自動執行檢查的伺服器上運行 TgWitness。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/server/)[### 找出問題所在 請透過針對各問題的正確訊號，檢查控制面板存取權限、Telegram 連線狀態、訊息遺失、FloodWait 及 Witness 狀態。](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/troubleshooting/)
