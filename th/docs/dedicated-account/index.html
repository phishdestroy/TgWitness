01

ทำไมไม่ใช่บัญชีหลักของคุณ

นี่คือข้อมูลที่ถูกต้อง เราทราบอย่างแน่ชัดว่าจุดเสี่ยงของปัญหาเหล่านี้อยู่ที่ใด

  1. แฮชของแอปของคุณเอง: 99% ออกจากระบบ

    การเข้าสู่ระบบ my.telegram.org จากบัญชีที่คุณไม่มีสิทธิ์เข้าถึง เพื่อรับค่าแฮชของแอป และจากนั้นการส่งคำขอใดๆ ผ่านค่าแฮชของแอปนั้น หมายความว่ามีโอกาส 99% ที่บัญชีนั้นจะถูกออกจากระบบ คุณสามารถตรวจสอบได้

  2. การแบนเพียงเพราะระดับความเชื่อถือต่ำเกิดขึ้นบ่อยครั้ง

    บัญชีถูกแบนเพียงเพราะ Telegram ไม่เชื่อถือบัญชีดังกล่าว และการแบนเช่นนี้เกิดขึ้นบ่อยครั้ง คุณสามารถตรวจสอบเรื่องนี้ได้เช่นกัน การใช้บัญชีของคุณเองเป็นความคิดที่โง่เขลาอย่างยิ่ง

  3. กุญแจเซสชันที่คัดลอกมาสามารถถูกเพิกถอนได้

    การรันกุญแจ TData/session ที่นำเข้าใน Telegram Desktop และ TgWitness พร้อมกันอาจทำให้เกิดข้อผิดพลาด AUTH_KEY_DUPLICATED Telegram จะยกเลิกการอนุญาตนั้น ดังนั้นทั้งสองสำเนาจึงต้องเข้าสู่ระบบใหม่ การใช้บัญชีเฉพาะไม่สามารถป้องกันปัญหานี้ได้

    ปิดแอปพลิเคชันต้นฉบับอย่างสมบูรณ์และรักษาให้ปิดไว้ตลอดเวลาที่ใช้เซสชันที่นำเข้า สำหรับการใช้งานแบบขนาน ให้ลงชื่อเข้าใช้ TgWitness ผ่านโทรศัพท์หรือ QR เพื่อสร้างการอนุญาตแยกต่างหาก; แอปพลิเคชันอื่นที่ได้รับการอนุญาตแยกต่างหากสามารถยังคงลงชื่อเข้าใช้ได้

    อ่านคำเตือนเกี่ยวกับการนำเข้าเซสชัน

เอกสาร Telegram
  • ข้อผิดพลาดในการออกจากระบบ: AUTH_KEY_UNREGISTERED, SESSION_REVOKED
  • การสร้างแฮชแอปของคุณเอง: การรับ api_id

02

เหตุผลที่ TgWitness ทำงานผ่านคู่แฮช/ID แอปสาธารณะ

นั่นคือเหตุผลที่เราสร้าง TgWitness บนคู่แฮชแอป/ID แอปสาธารณะ ตามตรรกะของเรา การถูกแบนมีแนวโน้มน้อยลงเมื่อใช้คู่เหล่านี้: มีบัญชี Telegram มากกว่าหนึ่งล้านบัญชีที่ลงทะเบียนผ่านคู่เหล่านี้ และมีโปรแกรมต่าง ๆ มากมายที่ทำงานผ่านคู่เหล่านี้ ตามหลักการของเรา วิธีนี้ดีกว่าการทำงานโดยตรงกับแฮชแอปส่วนตัว: คู่ข้อมูลเหล่านี้มีอยู่มาอย่างน้อย 5 ปีแล้วอย่างแน่นอน

คู่ใหม่ของคุณเอง

สร้างขึ้นที่ my.telegram.org จากบัญชีนี้

  • ประมาณ 99% ของบัญชีได้ออกจากระบบแล้ว
  • แอปพลิเคชันใหม่หนึ่งตัว บัญชีหนึ่งบัญชี

คู่สาธารณะของพูล

คู่คำเดียวกันที่โปรแกรมหลายตัวใช้

  • มีบัญชีที่ลงทะเบียนมากกว่าหนึ่งล้านบัญชี
  • โปรแกรมต่าง ๆ มากมาย
  • มีประสบการณ์ทำงานมากกว่า 5 ปี

ทำไมไม่มีใครสามารถเห็นข้อมูลของคุณผ่านคู่เหล่านี้ได้

  • คู่ดังกล่าวเป็นชื่อ ไม่ใช่กุญแจ

    Telegram จะขอ API ID และ API hash เมื่อโปรแกรมเชื่อมต่อและเมื่อขอรหัสเข้าสู่ระบบ ข้อมูลเหล่านี้ใช้เพื่อระบุตัวแอปพลิเคชันเท่านั้น และไม่ให้สิทธิ์เข้าถึงบัญชีใดทั้งสิ้น เอกสารของ Telethon ระบุว่า คู่ข้อมูลหนึ่งสามารถใช้งานได้กับหมายเลขโทรศัพท์ใดก็ได้

  • กุญแจเซสชันของคุณจะไม่ถูกส่งออกจากเซิร์ฟเวอร์ของคุณเลย

    การลงชื่อเข้าระบบจะสร้างกุญแจการอนุญาตผ่านการแลกเปลี่ยน Diffie–Hellman ระหว่าง TgWitness ของคุณและ Telegram; กุญแจเองจะไม่ถูกส่งไปเลย เอกสารของ Telegram: หลังจากได้รับอนุญาต กุญแจจะเชื่อมโยงกับผู้ใช้ และทุกการเรียกใช้ด้วยกุญแจนี้จะทำงานในนามของผู้ใช้นั้น โปรแกรมอื่นที่มีคู่กุญแจเดียวกันจะมีกุญแจของตัวเองและไม่สามารถใช้กุญแจของคุณได้

  • ข้อมูลการสื่อสารถูกเข้ารหัสด้วยกุญแจของคุณ

    ทุกคำขอและคำตอบจะถูกเข้ารหัสด้วยกุญแจการอนุญาตของเซสชัน ไม่ใช่ด้วยแฮช API การรู้แฮช API จะไม่สามารถถอดรหัสข้อมูลใดๆ ได้

  • เจ้าของคู่ดังกล่าวจะไม่เห็นอะไรทั้งสิ้น

    Telegram ไม่มีวิธีการใดที่แสดงรายชื่อบัญชี เซสชัน หรือข้อความตาม ID API เจ้าของคู่บัญชีจะเห็นเพียงการตั้งค่าแอปของตนเองที่ my.telegram.org เท่านั้น

  • มีเพียงบัญชีของคุณเท่านั้นที่เห็นว่าเป็นแอปใด

    ในส่วน "การตั้งค่า → อุปกรณ์" ของบัญชีของคุณ จะแสดงชื่อแอปและ API ID ของแต่ละเซสชัน, อุปกรณ์, ที่อยู่ IP และวันที่ ไม่มีใครอื่นสามารถเข้าถึงรายชื่อนี้ได้

03

วิธีสร้างบัญชีเพิ่มเติม

บัญชี Telegram ต้องมีหมายเลขโทรศัพท์เพื่อรับรหัสเข้าสู่ระบบ ให้เลือกระยะเวลาที่บัญชีต้องใช้งานอยู่

  • ตัวเลือกที่ดีที่สุด

    SIM แบบเติมเงินหรือ eSIM

    สุดท้าย
    ตราบใดที่คุณเติมเงินให้เพียงพอ
    ระวัง
    วิธีที่เชื่อถือได้ที่สุด: Telegram รับหมายเลขโทรศัพท์มือถือจริงได้ดีที่สุด หมายเลขที่ผู้ให้บริการโทรคมนาคมเรียกคืนจะถูกมอบให้กับผู้อื่น

  • แอปหมายเลขเสมือน

    สุดท้าย
    แม้ว่าแอปจะเก็บจำนวน
    ระวัง
    Telegram อาจปฏิเสธหมายเลขเสมือน ไม่ส่งรหัส หรือจำกัดบัญชีใหม่ทันที; บางแอปอาจเรียกคืนหมายเลขที่ไม่ได้ใช้งาน

  • การเช่าหมายเลข

    สุดท้าย
    ระยะเวลาเช่า
    ระวัง
    เมื่อสิ้นสุดลง หมายเลขจะส่งต่อไปยังลูกค้าถัดไป

  • การเปิดใช้งานครั้งเดียว

    สุดท้าย
    One code
    ระวัง
    หมายเลขดังกล่าวจะกลับเข้าสู่กลุ่มทันที โดยมักมาพร้อมประวัติของเจ้าของเดิม ตั้งรหัสผ่านคลาวด์ก่อนที่จะดำเนินการอื่นใด

ผู้ถือหมายเลขดังกล่าวในภายหลังสามารถขอรหัสเข้าสู่ระบบได้ รหัสผ่านบนคลาวด์ (การยืนยันสองขั้นตอน) จะป้องกันไม่ให้พวกเขาเข้าสู่ระบบได้; หากไม่มีรหัสผ่านนี้ บัญชีจะเป็นของเจ้าของหมายเลขคนต่อไป

เอกสาร Telegram
  • FAQ เกี่ยวกับสแปม: หมายเลขเสมือนและเจ้าของเดิม
  • การยืนยันตัวตนสองขั้นตอน

หมายเลข +888 ที่เช่า (Fragment)

บางตลาดและบริการเสนอการเช่าใช้ชั่วคราวหมายเลข +888 อย่างเป็นทางการของ Telegram จาก Fragment

ราคาประมาณ: 20 ดอลลาร์สหรัฐต่อวัน

  • คุณสามารถสมัครบัญชีได้โดยตรงผ่าน Telegram Web หรือ Telegram Desktop
  • คุณสามารถลบบัญชีที่มีอยู่และสร้างบัญชีใหม่ได้
  • บัญชีเหล่านี้โดยทั่วไปจะผ่านการตรวจสอบป้องกันการฉ้อโกงน้อยลง แต่ไม่ให้ความคุ้มกันหรือสิทธิพิเศษใดๆ

หมายเลขนี้ไม่ใช่ของคุณ เมื่อสัญญาเช่าสิ้นสุดลง เจ้าของสามารถเรียกคืนหมายเลขนี้ได้ ตั้งรหัสผ่านคลาวด์ทันที และอย่าถือว่าบัญชีนี้เป็นบัญชีระยะยาว

การเป็นเจ้าของหมายเลข +888 ด้วยตัวเองหรือใช้ซิมการ์ดแบบเติมเงินที่คุณควบคุมได้ยังคงเป็นวิธีที่เชื่อถือได้มากกว่า

บัญชีที่สร้างไว้พร้อมใช้จากตลาดออนไลน์

บางตลาด (เช่น G2G หรือ Z2U) ขายบัญชี Telegram ที่พร้อมใช้ — ทั้งบัญชีใหม่ บัญชีที่มีอายุ หรือบัญชีที่มีไฟล์เซสชัน

  • G2G: รายชื่อบัญชี Telegram
  • Z2U: รายชื่อบัญชี Telegram

อย่าใช้บัญชีหลักของคุณเด็ดขาด! บัญชีเฉพาะที่สร้างขึ้นด้วยวิธีนี้ยังคงปลอดภัยกว่าการใส่บัญชี Telegram หลักของคุณลงใน TgWitness

คำเตือนก่อนการซื้อ

  • การกระทำนี้ละเมิดเงื่อนไขการให้บริการของ Telegram
  • บัญชีจำนวนมากถูกจดทะเบียนแบบมวลชน (การจดทะเบียนอัตโนมัติ) หรือมีประวัติที่ไม่ทราบแน่ชัด
  • ผู้ขายบางรายอาจยังมีสิทธิ์เข้าถึงเพื่อกู้คืนบัญชีอยู่
  • บัญชีจากตลาดดังกล่าวมักถูกห้ามหรือจำกัดการใช้งานในภายหลัง
  • หลีกเลี่ยงตลาดออนไลน์ที่ขายโปรแกรมขโมยข้อมูล เครื่องมือฟิชชิ่ง หรือบัญชีที่ถูกขโมยอย่างชัดเจน
  • การซื้อบัญชี — แม้แต่บัญชีที่โฆษณาว่าเป็น "การลงทะเบียนอัตโนมัติ" — จากแพลตฟอร์มที่ขายเครื่องมือฟิชชิ่ง โปรแกรมขโมยข้อมูล เซสชันที่ถูกขโมย หรือบัญชีอย่างเปิดเผย ไม่เพียงแต่ละเมิดเงื่อนไขการให้บริการของ Telegram แต่ยังละเมิดกฎหมายของประเทศส่วนใหญ่ด้วย สิ่งนี้อาจทำให้หลักฐานของคุณถูกปฏิเสธในภายหลังได้ ดังนั้นโปรดเลือกอย่างระมัดระวัง

หากคุณใช้ตัวเลือกนี้

  1. ถือว่าบัญชีนี้เป็นบัญชีใช้แล้วทิ้ง
  2. ปิดเซสชันอื่น ๆ ทั้งหมด ตั้งรหัสผ่านคลาวด์ และเปลี่ยนวิธีการกู้คืนบัญชีทันที
  3. ใช้บัญชี 2–3 บัญชีจากผู้ให้บริการต่างกัน หรือบัญชีที่คุณลงทะเบียนเอง
Premium, การลบ และระยะเวลา 7 วัน

หากบัญชีมีบริการ Premium ผู้ที่มีสิทธิ์เข้าถึงหมายเลขโทรศัพท์จะไม่สามารถลบบัญชีได้ทันที คุณจะได้รับแจ้งเตือนและมีเวลาเจ็ดวันก่อนที่บัญชีจะถูกลบ

เรื่องนี้สำคัญเพราะการสืบสวนของคุณขึ้นอยู่กับบัญชีนี้: คุณยังมีเวลาเตรียมบัญชีทดแทน

บัญชีใหม่และข้อมูลรับรอง API

หากคุณได้รับและใช้ api_id/api_hash ของตัวเองจากบัญชีใหม่ที่คุณลงทะเบียนด้วยหมายเลขจากบริการ SMS บัญชีดังกล่าวจะถูกออกจากระบบในการขอ API ครั้งแรกหรือการอนุญาตเซสชันครั้งแรก โปรดจำไว้เมื่อวางแผนการตรวจสอบ

04

การสร้างบัญชี

จากหมายเลขไปยังการสนทนาครั้งแรกที่บันทึกไว้

  1. รับหมายเลข

    ใช้ SIM แบบเติมเงินหรือ eSIM เมื่อบัญชีต้องใช้งานในระยะยาว; ส่วนสำหรับงานระยะสั้น ให้เช่าหรือเปิดใช้งานครั้งเดียว บริการต่าง ๆ มีรายชื่ออยู่ด้านล่าง

  2. ลงทะเบียนแยกจากบัญชีหลักของคุณ

    ลงทะเบียนในแอป Telegram อย่างเป็นทางการบนอุปกรณ์อื่น เอมูเลเตอร์ หรือโปรไฟล์โทรศัพท์ที่แยกต่างหาก ไม่ใช่ในบัญชีหลักของคุณ

  3. ล็อกด้วยรหัสผ่านคลาวด์

    ตั้งรหัสผ่านคลาวด์และอีเมลกู้คืนทันที โดยใช้ข้อมูลที่ไม่เคยใช้ที่อื่นมาก่อน

  4. ปิดการตั้งค่าความเป็นส่วนตัว

    หมายเลขโทรศัพท์ ไม่มีใคร, ค้นหาฉันจากหมายเลขของฉัน รายชื่อผู้ติดต่อของฉัน, ครั้งสุดท้ายที่เห็น, รูปโปรไฟล์ และข้อมูลส่วนตัว ไม่มีใคร หรือ รายชื่อผู้ติดต่อของฉัน; ปิดการซิงค์รายชื่อผู้ติดต่อ

  5. ป้องกันไม่ให้มันทำลายตัวเอง

    ตั้งระยะเวลาการทำลายบัญชีอัตโนมัติเป็นระยะเวลาที่ยาวนานที่สุด เพื่อที่ TgWitness ที่ถูกหยุดทำงานจะไม่ทำให้คุณสูญเสียบัญชี

  6. ให้โปรไฟล์เป็นกลาง

    ห้ามใช้ชื่อ รูปภาพ ชื่อผู้ใช้ หรือข้อมูลส่วนตัวจากบัญชีอื่นของคุณ และห้ามใช้ข้อมูลติดต่อส่วนตัว

  7. ให้ระบบทำงานอุ่นเครื่องก่อน

    เริ่มด้วยการเข้าร่วมแชทไม่กี่ครั้งต่อวันก่อน บัญชีใหม่ที่รีบเร่งจะถูกจำกัดก่อน

  8. อย่าแบ่งปันข้อมูลใดๆ กับบอท

    อย่ากด “แชร์หมายเลขโทรศัพท์” หรือ “แชร์ตำแหน่ง” สำหรับบอทเลย เปิดลิงก์และ Mini Apps ผ่าน VPN หรือพร็อกซีบนอุปกรณ์นั้น

  9. เชื่อมต่อกับ TgWitness

    ในพื้นที่ทำงานของตัวเอง ให้เชื่อมต่อผ่าน Account → QR code แล้วกด Sources → Investigation mode แอปคือที่ที่คุณดำเนินการ TgWitness คือบันทึก

เอกสาร Telegram
  • การยืนยันตัวตนสองขั้นตอน
  • การตั้งค่าความเป็นส่วนตัว
  • บัญชีทำลายตัวเอง
