# 访问与权限

Canonical page: https://phishdestroy.github.io/TgWitness/zh/docs/reference/access/

设置账户和聊天室的访问权限范围，选择权限类型，限制会话和 IP 地址，并撤销访问权限。

可授予审阅者访问某个聊天记录的权限，授予分析师导出案件的权限，或授予 操作员对选定账户的控制权。每个人都会获得专属令牌。主 控制面板的令牌由管理员持有。

[账户设置](https://phishdestroy.github.io/TgWitness/zh/docs/reference/accounts/) · [连接路径](https://phishdestroy.github.io/TgWitness/zh/docs/reference/connection/) · [安全模型](https://phishdestroy.github.io/TgWitness/zh/docs/reference/security/)

## 两个应用场景，两种不同的任务

**采集范围**决定了账户的记录内容：选定的聊天、Telegram 文件夹或整个账户。**访问范围则**决定了其他用户可以查看和使用哪些已记录的 账户和聊天。授予访问权限并不意味着加入 Telegram 聊天、开始采集或授予 Telegram 账户权限。

一次访问权限可打开选定的工作区、其中选定的聊天，或所有 工作区。**所有工作区（包括后续添加的工作区）**也涵盖未来的 账户。若某案件需仅限于特定工作区，请明确选定相应工作区。

## 授予某人访问权限

1. 以主管理员身份登录并打开**“访问”页面**。
2. 在“**授予某人访问权限**”下，请输入一个您在日志中能认出的名字。
3. 选择工作区，并在必要时选择具体的聊天室。
4. 选择此人可能采取的行动。**操作视图**始终包含在内。
5. 根据需要设置有效期、登录/会话限制以及允许的地址。
6. 点击**“创建访问权限**”。请立即复制该令牌：该令牌仅显示一次。
7. 请私下发送控制面板地址和令牌。收件人只需在常规登录页面输入该令牌 即可；他们无需您的主控制面板令牌，也无需 Telegram 会话。

请在单独的浏览器会话中打开包含已生成令牌的面板，并在移交前检查 可见的聊天记录及允许的操作。

## 选择权限

| 许可 | 功能介绍 |
| --- | --- |
| `view` | 可查阅获准访问的聊天记录、捕获的消息、个人资料、文件以及经过筛选的日志记录。这些内容始终包含在内。 |
| `export` | 允许导出聊天记录和档案。导出整个工作区的证据需要具备对整个工作区的访问权限。 |
| `sources` | 管理消息源、快照和个人资料捕获。受聊天限制的访问权限仅限于允许的聊天；全账户范围的消息源发现和范围设置保持关闭状态。 |
| `collect` | 启动或停止采集器。由于采集操作会影响该账户，因此需要整个工作区的访问权限。 |
| `interact` | 在访问权限范围内执行受支持的 Telegram 交互操作。受限于聊天范围的访问权限无法使用全账户范围的链接预览功能。 |
| `settings` | 可更改采集设置、时间戳、通知、异地副本及各项参数。需具备整个工作区的访问权限。 |
| `account` | 登录或退出 Telegram 并管理连接路径。需要整个工作区的访问权限。 |

权限和范围将一并核查。勾选某项权限不会 打开其他聊天记录，也不会为仅限特定聊天记录的访问权限解锁工作区范围的操作。 若要进行并行导出，访问权限必须涵盖所有选定 账户中的被导出聊天。已授予的访问权限无法创建新访问权限、管理他人的 会话或打开管理员控制台。

### 三种实用的配置方案

| 人物 | 范围 | 权限 |
| --- | --- | --- |
| 审稿人 | 某案例的记录聊天内容 | `view` |
| 分析师正在准备工作交接 | 待调查和导出的聊天记录 | `view`、`export`；仅当需要通过 Telegram 进行操作时才添加 `interact` |
| 采集操作员 | 精选完整工作区 | `view`、`sources`、`collect`；仅在需要时添加 `settings` 或 `account` |

这些是通过权限复选框进行配置的示例，并非固定的角色。

## 限制与会话

| 设置 | 工作原理 |
| --- | --- |
| 并行会议 | 将同时在线会话数限制在 1–100 之间。达到上限时，拒绝下一次登录请求或终止最旧的会话。 |
| 允许登录 | 限制使用该令牌成功启动会话的次数。即使最后一次允许的登录已被使用，现有会话也不会因此终止。 |
| 有效期至 | 访问权限设有绝对有效期。过期的访问权限无法登录或继续发起请求。 |
| 无活动记录 | 会话闲置超时，范围从 5 分钟到 30 天。成功请求会延长该时限；打开的面板可通过轮询保持活动状态。 |
| 允许的地址 | 接受特定的 IP 地址或 CIDR 子网。若未填写，则允许任何地址，除非已启用首次登录绑定功能。 |
| 绑定至首次登录 | 首次成功登录后，系统将锁定该访问的授权地址。 |

IP 地址是应用程序所识别的客户端地址。若位于反向代理或 隧道之后，请在依赖 IP 规则之前，先检查**“打开的会话**”中显示的地址： 否则，可能会出现多名用户看似共享同一代理地址的情况。

## 更改或撤销访问权限

**在“访问权限**”下编辑某条记录，以更改其范围、权限或限制。 范围和权限的变更将在后续请求中生效，包括 来自已打开会话的请求。撤销访问权限将终止其会话 并使已签发的令牌失效。**对于已打开的会话**，管理员 还可以终止单个会话，而无需撤销整个访问权限。

撤销操作无法召回用户已下载的文件。注销、 锁定面板或结束会话均不会停止正在运行的收集器。

## 管理员可见的内容

**自启动以来生成的日志**将进程日志与每个 工作区的日志活动相结合：登录、拒绝、路由变更和操作员操作。这是一个 针对当前进程的内存控制台，而非每条消息的永久副本。 高频消息事件会保留在日志中，而非填满控制台。

授予、更改和撤销访问权限，以及启动或结束会话，也会生成 经过签名的`access.*`日志记录。这些记录中不包含令牌。 已发放的令牌和会话凭据将作为哈希值保存在加密保险库中。

****主要管理员与信任边界**** 主面板令牌不受限制。使用该令牌通过浏览器登录将创建会话， 这些会话受管理员配置的会话限制约束。直接发送 主令牌的脚本仍保留完全访问权限，且不计入浏览器会话。 这是单个安装环境中的应用层访问控制。所有工作区共享 服务器进程；这并不意味着与主机管理员隔离。请确保主 令牌、Telegram 会话、签名密钥和数据目录的私密性。见证令牌 是一个独立的检查点/健康凭证，并非面板访问令牌。
