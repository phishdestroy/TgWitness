TgWitness / مستندسازی · راه‌اندازی و بازیابی

دسترسی → ویترین عمومی با استفاده از سیستم توکن دسترسی موجود، یک صفحهٔ مجزا و فقط-خواندنی ایجاد می‌کند. این صفحه مشاهدات ذخیره‌شدهٔ نصب را می‌خواند. این کار هیچ گردآورنده‌ای را راه‌اندازی نمی‌کند، به تلگرام وارد نمی‌شود و برای بازدیدکننده کانالی تهیه نمی‌کند.

انتشار یک صفحه#

  1. برای هر کانال عمومی که می‌خواهید نمایش دهید، یک پروفایل منبع ذخیره کنید. یک کانال باید در آخرین پروفایل ذخیره‌شده خود یک نام کاربری عمومی داشته باشد؛ گروه‌ها و چت‌های خصوصی واجد شرایط نیستند.
  2. دسترسی → نمایشگاه عمومی را باز کنید (یا /showcase-manage.html) را به‌عنوان مدیر باز کنید.
  3. کانال‌ها را از میان حداکثر ۱۶ فضای کاری انتخاب کنید، عنوان صفحه عمومی را وارد کنید و مدت زمان عمر لینک را ۱، ۷ یا ۳۰ روز انتخاب کنید. برچسب‌های داخلی فضای کاری منتشر نمی‌شوند. حداکثر ۶۴ کانال می‌توانند گنجانده شوند.
  4. متن کانال‌های انتخاب‌شده را برای انتشار بازبینی کنید، سپس روی «پیش‌نمایش رکوردهای انتخاب‌شده» کلیک کنید. پیش‌نمایش از همان پیش‌نمایش سمت سرور صفحه بازدیدکننده استفاده می‌کند.
  5. روی لینک «ایجاد نمایش» کلیک کنید. لینک را در حالی که قابل مشاهده است کپی کنید. آن را در یک مرورگر جداگانه باز کنید تا صفحهٔ گیرنده را پیش از توزیع بررسی کنید.

این لینک حاوی یک توکن دسترسی در بخش نشانی (fragment) نشانی اینترنتی خود است. صفحه این بخش را پیش از ارسال درخواست‌های API حذف کرده و آن را با یک جلسه مرورگر معاوضه می‌کند. هر کسی که این لینک را در اختیار داشته باشد می‌تواند تا زمان انقضا یا لغو، مطالب انتخاب‌شده را باز کند. لینک‌های جدید ۱۰۰ جلسه همزمان را مجاز می‌سازند که هر کدام حداکثر یک ساعت دوام دارند. کنترل‌های دسترسی موجود همچنین می‌توانند از طریق API اعطای دسترسی، محدودیت‌های آدرس و محدودیت‌های ورود را اعمال کنند. دسترسی معمول بازبینان یک حالت متفاوت است و همچنان شامل پیام‌ها و فایل‌های اصلی مجاز می‌شود.

آنچه بازدیدکنندگان می‌بینند#

نمایان خصوصی نگه داشته شده
عنوان‌های منتخب کانال‌های عمومی، نام‌های کاربری و تاریخ‌های مشاهده پروفایل هویت حساب‌ها، برچسب‌های داخلی فضای کاری و منابع انتخاب‌نشده
متن ضبط‌شده و هر ویرایش ذخیره‌شده شناسه‌های ساختاریافتهٔ فرستنده، نام‌ها، نام‌های کاربری، شماره‌های تلفن و مقادیر پروفایل
مشاهده حذف‌ها همراه با متن قبلاً ذخیره شده، در صورت وجود پیوست‌ها، آواتارها، تصاویر بندانگشتی، نام فایل‌ها و بارهای اصلی
نشانگرهایی که نشان می‌دهند یک نویسنده/پروفایل یا پیوست ضبط شده است مَتادیتای فوروارد و پاسخ، مسیرهای شبکه، آدرس‌های IP و اعتبارنامه‌ها
شمارش رویدادهای کانال‌های منتخب، کلیدهای فعلی جمع‌آوری، ضربان قلب و فاصله زمانی نقطه‌کنترل کنترل‌های جمع‌آوری و رابط‌های برنامه‌نویسی کاربردی معمولی برای صدور شواهد
امضای اثر انگشتی، نقطهٔ کنترل ژورنال و اثبات سازگاری کلیدهای امضا و جلسات تلگرام

متن پیام عمومی به طور خودکار ناشناس‌سازی نمی‌شود. نام، ذکر، شماره تلفن یا لینکی که در پیام نوشته شده باشد، همچنان بخشی از آن متن باقی می‌ماند. Redactedاین امر در مورد فیلدهای ساختاریافته نویسنده/پروفایل نیز صدق می‌کند. پیش از انتشار، محتوای واقعی انتخاب‌شده را، از جمله ویرایش‌ها و حذف‌های حفظ‌شده، بازبینی کنید.

شایستگی، آخرین پروفایل منبع ذخیره شده را منعکس می‌کند، نه یک جستجوی زنده در تلگرام. اگر پروفایل بعدی دیگر نام کاربری کانال عمومی نداشته باشد، درخواست‌های جدید آن کانال را حذف می‌کنند. با تغییر دیده‌شدن عمومی، پروفایل‌های منبع را تازه کنید. ممکن است خوانندگان از قبل مطالبی را که قبلاً دریافت کرده‌اند ذخیره کرده باشند.

سوابق اصلی امضا شده دست‌نخورده باقی می‌مانند. پیش‌نمایش نمایش‌داده‌شده به‌طور جداگانه امضا می‌شود و هش‌هایی را شامل می‌شود که به سوابق اصلی خود ارجاع می‌دهند. امضای پیش‌نمایش، صحت بیانیه نمایش‌داده‌شده را تأیید می‌کند؛ این امضا، امضای رویداد اصلی بر روی بایت‌های حذف‌شده نیست.

امضاها و پیوستگی را بررسی کنید#

«اثر انگشت و نقطه کنترل امضا شده» را گسترش دهید و یک اسنپ‌شات دانلود کنید. پس از تازه‌سازی صفحه، دانلود شامل اسنپ‌شات قبلی مرورگر و یک اثبات سازگاری مرکل بین مرزهای دفترچه خاطرات آن‌ها است. تازه‌سازی خودکار زمانی که صفحه قابل مشاهده است و صفحه اول مشاهدات خود را نمایش می‌دهد، هر دقیقه یک بار انجام می‌شود.

با نصب TgWitness، فایل دانلودی را به‌صورت آفلاین تأیید کنید:

python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256

اثر انگشت باید از یک مرجع جداگانه مورد اعتماد حاصل شود. برای مقایسه با یک اسنپ‌شات که خودتان نگه داشته‌اید، از ... استفاده کنید. --previous earlier.json؛ این بر اسنپ‌شات قبلی که در دانلود گنجانده شده است، اولویت دارد. اثبات فعلی باید از آن مرز نگهداری‌شده آغاز شود. کلاینت‌های احراز شده می‌توانند با استفاده از GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>. یک ژورنال کوتاه‌تر به جای ریست کردن بی‌صدا مرز، کد HTTP 409 را برمی‌گرداند.

نقطه کنترل امضا شده، کل دفترچه کل (journal) گردآورنده را ثبت می‌کند، شامل تعداد رکوردها و هش سر غیرشفاف آن. تعداد پیام‌های نمایش داده شده فقط برای کانال‌های عمومی انتخاب‌شده اعمال می‌شود. این صفحه هرگز محتوای سایر دفترچه‌های کل را فهرست نمی‌کند. این‌ها تعداد رویدادها هستند، نه تعداد پیام‌های منحصربه‌فرد. تنظیمات، پیکربندی فعلی را توصیف می‌کنند، نه هر بازه ضبط قبلی را.

تأیید امضا و سازگاری می‌تواند تغییرات را نسبت به یک مرز نگهداری‌شده تشخیص دهد. این قابلیت به‌طور مستقل شمارنده‌های امضا را دوباره شمارش نمی‌کند، اصالت تلگرام را تأیید نمی‌کند، ضبط بی‌وقفه را نشان نمی‌دهد، یا جایگزین یک شاهد مستقل نمی‌شود. برای آن بررسی، از اعتبارسنج شواهد، شاهد مستقل و سوابق مقیاس‌آزمایی‌شده استفاده کنید. نصب‌های مصنوعی به‌وضوح برچسب «مصنوعی» دارند.

صفحه را لغو یا میزبانی کنید#

برای بستن لینک و پایان دادن به تمام جلسات آن، از گزینه «Revoke» در مدیر نمایش یا بخش دسترسی موجود استفاده کنید. بازدیدکننده، سوابق نمایش‌داده‌شده را زمانی پاک می‌کند که یک درخواست تشخیص دهد دسترسی پایان یافته است. انقضا و مجوزها در هر درخواست بررسی می‌شوند. دسترسی‌های اعطا شده در نمایش نمی‌توانند به دسترسی معمولی پنل تبدیل شوند؛ برای تغییر حالت‌ها، یک دسترسی جدید ایجاد کنید.

صفحه را از طریق آدرس HTTPS موجود در نصب ارائه دهید. انتشار یک لینک، پورت جدیدی باز نمی‌کند، تونلی ایجاد نمی‌کند و DNS را تغییر نمی‌دهد. HTML و API روی نصب کاربر باقی می‌مانند. یک بازدیدکننده نمایشگاهی نمی‌تواند با این دسترسی از APIهای معمولی پیام، پروفایل، رسانه، خروجی یا مدیریت استفاده کند.
