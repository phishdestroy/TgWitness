# Рекомендации по юрисдикции в Report Studio

Откройте **«Экспорт» → «Создать отчет» → «Рекомендации по юрисдикции · необязательно»**. Выберите
соответствующую юрисдикцию и процедуру суда, проверьте ссылки на источники, а затем сохраните
настройки отчета. На вкладке «Рекомендации» отображается предварительный просмотр приложения на основе текущего черновика.
Предварительный просмотр или изменение страны не приводят к сохранению. Существующие макеты отчетов,
темы, языковые настройки, фильтры охвата и примечания к экспертизе продолжают применяться.

В каталоге представлены полные профили рекомендаций для 31 юрисдикции: Австралия, Бразилия,
Канада, материковый Китай, Хорватия, Англия и Уэльс, Франция, Грузия, Германия,
Индия, Индонезия, Иран, Италия, Казахстан, Люксембург, Малайзия, Мальта, Мексика,
Пакистан, Филиппины, Португалия, Россия, Саудовская Аравия, Сингапур, Словения,
Испания, Турция, Украина, ОАЭ, США и Вьетнам. По другим странам,
включенным в каталог экспертных экспертиз, представлены только рекомендации по проведению экспертиз. Примечания к сфере применения
определяют ограничения, такие как различия между федеральным и штатным уровнями; указание страны не заменяет
указания конкретного суда. Это перечень охватываемых юрисдикций, а не рыночный рейтинг.

<a id="defaults-and-configuration"></a>
## Настройки по умолчанию и конфигурация

Вложенный объект `jurisdiction_guidance` принимается объектами `ReportOptions` и
`report_presentation` в разделе «Учетная запись/Обмен»:

```json
{
  "jurisdiction_guidance": {
    "jurisdiction": "",
    "procedure": "civil",
    "include_in_report": true,
    "local_note": false,
    "include_methods": false
  }
}
```

| Выбор | Поведение |
| --- | --- |
| Пустая юрисдикция | Без приложения. Никогда не определяется на основе IP-адреса, языка интерфейса или местоположения провайдера. |
| Код юрисдикции, например: `BR`, `US`, `IN`, `GB-EW` | Использует эту запись из каталога. Неизвестные коды отклоняются. |
| `civil` / `criminal` | Выбирает соответствующую основу, источники и локальную сводку. Задачи по подготовке гражданских дел не используются повторно в качестве процедур по уголовным делам. |
| `include_in_report: false` | Сохраняет выделение в сохраненных настройках, но без приложения. |
| `local_note: true` | Добавляется краткое изложение на родном языке. Это не является заверенным переводом. Для открытия файла PDF требуются шрифты, соответствующие используемой кодировке; отсутствие необходимых глифов приводит к появлению явной ошибки. |
| `include_methods: true` | Добавлены пояснения относительно подписей, временных меток, хранения данных, свидетелей, TEE, визуальной фиксации и участия человека. Речь идет о возможных мерах, а не о том, что они были применены. |

`GET /api/report-guidance` предоставляет каталог с версиями авторизованным пользователям,
имеющим право на просмотр. `POST /api/report-options` использует существующее разрешение на экспорт.
При изменении этих настроек сохраняйте полный объект report-options, как и в случае с
другими настройками отчета. Эти элементы управления настраивают отчет, а не сборщик,
облачную учетную запись, политику хранения или службу свидетелей.

Используйте **Заметки об экспертизе** для определения конкретного суда, применимых региональных
правил, порядка сертификации, вопросов и профессиональной аттестации. В случае юрисдикции, не указанной
в списке, или особой процедуры оставьте поле выбора из каталога пустым и воспользуйтесь
этими примечаниями; не выбирайте соседнюю страну в качестве правового аналога.

<a id="reports-and-isolation"></a>
## Отчеты и изоляция

| Вывод | Выбор руководства |
| --- | --- |
| Журнал и передача данных в форматах HTML, PDF, JSON, а также подписанные манифесты | Сохраненные настройки отчета по рабочей среде или конкретные настройки для данного экспорта. |
| Отчет по отдельному чату | Его параметры отчета. |
| Отчет по учетной записи и отчеты по чатам | Явное указание `report_presentation` или сохраненная презентация рабочей области, если вызывающая сторона API не указывает её. |
| Сокращенная версия для публикации | Отсутствие неявного наследования. Вызывающая сторона API может явно выбрать общедоступный профиль в элементе `report_presentation` производного объекта. |
| Экспорт заметок с отдельной панели дел | Вне рамок данного отчета — варианты действий. Для данного приложения используйте отчет о фактах или отчет по счетам. |

Профили макетов многократного использования исключают объект юрисдикции, так же как и
названия дел, выводы и фильтры. Новая рабочая область создается без указания юрисдикции.
Существующие средства защиты «unsigned-preview» и «lock/workspace» также распространяются на эти поля.

Приложение содержится в теге `case_assessment.jurisdiction_guidance` и включает
версию каталога и SHA-256, дату исследования, сферу охвата, источники и статус исследования.
Данные в форматах HTML, PDF и структурированного отчёта отображают один и тот же объект. Существующие подписи
связывают приложение с предоставленной копией. Проверки криптографической оценки
не обновляются и не скрываются при выборе юрисдикции или пояснения о мерах безопасности.

Приложение начинается с раздела **«Что необходимо сделать далее с данной копией»**, составленного на основе фактической
оценки экспорта: наблюдаемого результата и следующего этапа проверки или документирования
для каждой проверки. Например, отсутствующая временная метка, непроверенная квитанция и
временная метка, охватывающая только префикс, приводят к разным инструкциям. Зафиксированные несоответствия
приводят к пояснению затронутого периода, а не к утверждению, что настройка может
исправить прошлые данные сбора. Включённые цитаты из TDX по-прежнему требуют независимой проверки.
Предварительный просмотр дизайна не придумывает эти результаты; они добавляются во время экспорта.
Этот список задач служит руководством при подготовке пакета и фиксирует проведённые проверки.

<a id="research-status"></a>
## Состояние исследований

Версия каталога `2026-11-14.2` представляет собой **рабочий проект** со ссылками на источники для каждого
маршрута; преступный маршрут в Иране обозначен `needs_local_review`. В профилях Хорватии, Грузии,
казахстанский, люксембургский, мальтийский и словенский профили ссылаются на официальные порталы законодательства в том виде, в каком они
были доступны 14 ноября 2026 года; более поздние поправки к цитируемым статьям были отслежены лишь
частично. Для каждой подачи документов необходимо подтвердить
действующее законодательство и фактические требования в отношении суда, органа, уполномоченного на получение документов, раскрытия информации, заверения подлинности,
свидетельских показаний из вторых рук (если применимо), перевода и формальностей, а также обеспечить проверку руководства на английском языке
и резюме на родном языке практикующим юристом, допущенным к практике в данной стране.

При выборе меры защиты отображается описание её преимуществ, а также указания о том, что следует сохранить и как
её усилить. При проверке журнала используется ключ доверенного сборщика данных; сохраненные контрольные точки
позволяют провести сравнение с более ранней границей журнала, наблюдавшейся независимым наблюдателем. Учетная запись провайдера,
принадлежащая сторонней организации, выводит хост и гипервизор из-под контроля оператора.

При выборе мер безопасности в приложении также приводится ссылка на
[Руководство ENFSI по передовым методам проведения криминалистической экспертизы цифровых технологий](https://enfsi.eu/wp-content/uploads/2016/09/1._forensic_examination_of_digital_technology_0.pdf)
(ENFSI-BPM-FIT-01, версия 01, ноябрь 2015 г.) — практическое руководство для криминалистических
лабораторий. Оно не является законом и не устанавливает никаких правил допустимости доказательств для какого-либо суда.

Необходимо установить политику хранения для фактических версий объектов и прав доступа;
одного только шифрования, конечной точки S3 или управления версиями недостаточно. См.
[AWS Object Lock](https://docs.aws.amazon.com/AmazonS3/latest/userguide/object-lock.html).
Заявления TEE требуют проверки соответствующих привязок развертывания и вывода;
область применения фреймворка описана в [dstack](https://github.com/Dstack-TEE/dstack).
Просмотрите видеозапись с зафиксированным маршрутом сбора данных, интервалами наблюдения и
результатами проверки регистратора.

<a id="validation"></a>
## Проверка

Внутренние регрессионные тесты охватывают настройки по умолчанию, отклонение входных данных, каждую ветвь каталога гражданских и уголовных дел,
неизменные проверки доверия, границы рабочего пространства и прав доступа, настройки по умолчанию для совместного доступа,
исключения макетов, все восемь вариантов оформления HTML/PDF, соответствие манифеста и JSON, а также
сбой подписи после изменения текста инструкций. При проверке в браузере используются синтетические
записи, обе темы, узкие и настольные области просмотра, навигация с помощью клавиатуры, сравнение сохраненных
и черновых вариантов, а также переключение между процедурами.
