# 아카이브 분석

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/reference/analysis/

저장된 메시지를 검색하고, AI 입력 내용을 검토하며, 출처 참조 정보가 포함된 분석 보고서를 보관할 수 있습니다.

**현재 메인 버전:** 소스 체크아웃을 사용하십시오. 0.7.0 휴대용 미리보기 버전은 이 기능이 구현되기 전의 버전입니다.

[워크플로우 가이드](https://phishdestroy.github.io/TgWitness/docs/archive/) · [위키](https://github.com/phishdestroy/TgWitness/blob/main/docs/wiki/Archive-and-Integrations.md)

AI 없이 로컬 검색을 하려면 **저널**을 사용하세요. **아카이브에 문의하기**를 사용하려면 먼저 **연동 기능**에서 제공업체를 활성화하고 설정해야 합니다. 작업 공간 선택기에서 계정을 선택하고, 양식에서 대화와 관찰 기간을 선택합니다. 검색은 로컬에서 실행됩니다. 정확한 문구나 도메인을 입력하면 검색 범위가 좁혀지고, 메시지 ID를 입력하면 저장된 버전을 요청합니다. 발췌문을 검토하고 해당 저널 기록이나 맥락을 열어 보세요. 벡터 데이터베이스나 텔레그램 자동 작업 기능은 없습니다.

## 제공업체 및 동의

모든 작업 공간에서 AI 기능은 기본적으로 비활성화되어 있습니다. 주 관리자만이 모델, 엔드포인트, 암호화된 API 키, 컨텍스트/출력 제한, 타임아웃 및 일일 요청 할당량을 구성할 수 있습니다. 키는 브라우저로 절대 반환되지 않습니다. 현재 키를 유지하려면 키 필드를 비워 두거나, 명시적으로 제거하십시오.

Ollama는 문서화된 [`/api/chat` 엔드포인트를](https://docs.ollama.com/api/chat) 사용하며, 스트리밍이 아닌 JSON 형식으로 출력합니다. 기본 주소는 TgWitness 서버의 `http://127.0.0.1:11434`입니다. 운영자는 `TGWITNESS_AI_LOCAL_ENDPOINT`를 사용하여 이를 변경할 수 있으며, 이는 모델에 의해 제어되는 주소가 아닙니다. 선택한 모델은 직접 설치해야 합니다. TgWitness는 이를 자동으로 다운로드하지 않습니다.

호환되는 제공업체는 `/v1`로 끝나는 기본 URL과 [채팅 완료 프로토콜](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)( `messages`, JSON 응답 모드, `max_completion_tokens`, `choices[0].message.content`)을 지원해야 합니다. 이러한 필드가 없는 서비스는 지원되지 않습니다. 연결 테스트는 합성 텍스트를 전송하며, 요청 할당량에 포함됩니다.

모든 요청은 워크스페이스에 구성된 외부 경로를 사용합니다. 경로가 차단되었거나 텔레그램 전용 MTProxy인 경우 오류가 발생하며, 직접적인 재시도는 불가능합니다. 의도적으로 구성된 로컬 Ollama 주소를 사용하면 선택한 경로를 계속 사용하면서도 비공개 목적지로 전송할 수 있습니다. 다른 비공개 서비스의 경우 기존 서버 수준의 비공개 목적지 옵트인 정책이 적용됩니다. 패널에는 실제로 구성된 엔드포인트가 표시됩니다.

생성 전에 **모델로 전송된 데이터에는** 요청 내용(질문, 선택된 발췌문, 이벤트 유형, 관측 시간 및 범위 마커)이 포함됩니다. 텔레그램 세션, 원시 필드, 제공자 키, 첨부 파일 바이트 및 전체 저널은 해당 컨텍스트에 포함되지 않습니다. 원하지 않는 소스의 선택을 해제한 후, 처리를 명시적으로 승인하십시오. 외부 제공업체는 자체 정책에 따라 제출된 콘텐츠를 보관할 수 있습니다. 로컬 실행이란 엔드포인트가 로컬에 있음을 의미하며, 이는 독립적으로 구성된 서비스의 동작에 대한 보장을 의미하지는 않습니다.

전 세계적으로 동시에 처리되는 제공자 요청은 최대 두 건이며, 워크스페이스당 한 건으로 제한됩니다. 미리보기는 10분 후에 만료되며, 한 번의 응답만 생성할 수 있습니다. 프로바이더가 보고한 토큰 수가 표시되며, 비용 추정은 입력 및 출력 요금이 모두 설정된 경우에만 나타납니다. 실패한 시도도 일일 요청 할당량에서 차감됩니다. 자동 재시도는 추가 할당량을 소모하지 않습니다.

## 출처 및 한계

검색 기능은 저장된 메시지 텍스트를 제한된 어휘 검색을 통해 분석합니다. 최대 24개의 출처를 반환하며, 잘린 발췌문이나 불완전한 결과 집합은 표시합니다. 이 기간은 **관찰 시점을** 의미할 뿐, 텔레그램 기록이 완전하다는 주장을 의미하지는 않습니다. 워크스페이스 전체에 걸친 이벤트는 채팅 범위 내 접근에서는 제외됩니다. 누락된 데이터는 사용 가능한 아카이브에서 발견되지 않은 것으로 표시됩니다.

모델은 어떠한 도구도 제공받지 않습니다. 모델의 소스 ID는 선택된 기록과 대조하여 확인되며, 해시는 재검증되고, 인용된 문자열은 해당 기록에 반드시 존재해야 합니다. 알 수 없는 ID, 변경된 인용문, 출처가 명시되지 않은 주장은 답변을 거부합니다. 애플리케이션은 링크를 생성하며, 모델이 생성한 URL은 인용으로 사용되지 않습니다. 이러한 검사는 추론의 진실성을 확인하는 것이 아니라, 출처의 존재 여부와 인용의 정확성을 확인하기 위한 것입니다. 추론에 의존하기 전에 해당 기록과 대조하여 검토하십시오.

## 보고서

검토된 답변을 별도의 분석 보고서로 저장합니다. 여기에는 모델 요약, 관찰된 시간 순서, 추출된 링크 및 핸들, 수정/삭제 기록, 범위 제한, 원본 이벤트 해시가 포함됩니다. 제공자, 모델, 엔드포인트, 시간 및 프롬프트 템플릿 버전이 함께 제공됩니다. 신원 정보는 자동으로 병합되지 않습니다.

분석가의 수정 내역과 메모는 모델 요약과 별도로 저장됩니다. 보고서는 암호화된 파생 파일에 저장되며, 인덱스는 서명된 이벤트 스트림 외부에 위치합니다. 원본 이벤트와 미디어는 변경되지 않습니다. 소유자나 관리자만 보고서를 열 수 있으며, 소스 접근 권한이 다시 확인됩니다. 다운로드 시에도 내보내기 권한이 필요합니다. 버전 1은 보고서에 서명을 하지 않으며, 모델의 결론이 검증된 증거임을 암시하지도 않습니다. 제한 사항: 워크스페이스당 100개의 보고서, 보고서당 100건의 분석가 수정 건.

수동 OCR 및 전사본에 대해서는 [미디어 처리를](https://phishdestroy.github.io/TgWitness/ko/docs/reference/media-analysis/) 참조하십시오. 클라이언트 액세스에 대해서는 [MCP를](https://phishdestroy.github.io/TgWitness/ko/docs/reference/mcp/) 참조하십시오.
