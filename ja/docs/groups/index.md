# Telegram · アカウントグループの管理

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/groups/

複数のアカウントをまとめて動かし、それぞれが自分の記録と鍵を持ち続けます。

グループは、接続状態、開始/一時停止、共有設定、エクスポートを 1 つの画面にまとめます。複数のアカウントで同じケースに取り組むときに便利です。

## グループの概要を開く

**アカウント**でグループを開きます。各アカウントの状態、ルート、遅延、最後に保存したメッセージが表示されます。**注意が必要**には問題のあるものが並び、**修正**でそこへ直接移動できます。

**すべて開始** / **すべて一時停止**は実行前に確認します。**グループ設定**は共有されますが、アカウント独自の値は置き換えるまで残ります。

### グループ全体での経路変更を確認する

合成例・説明用のチェック項目と結果

1. **[選択]。**グループを選択し、どのアカウントが変更されるかを確認してください。
2. **準備。**分離しておく必要がある場合は、アカウント固有の経路を維持してください。
3. **確認。**提案された接続をテストし、測定結果を確認してください。
4. **適用してください。**保存前に再確認し、各アカウントの結果を精査してください。

#### ケースチーム

チャンネルコレクター · グループコレクター · 参照アカウント

3つの独立したワークスペース

#### 選定済みの内容

2つのアカウントが提案された手順に従います。

参照アカウントは独自の経路を維持します。

#### 準備確認事項

チャンネルコレクター：Telegram転送時間 84 ms

グループコレクター：Telegram転送 91 ms

これらの数値は、例示のための架空の測定値です。

#### アプリケーションの結果

チャンネルコレクター：保存済み、監視再開。

グループコレクター：再確認に失敗したため、以前の設定が復元されました。

参照アカウント：独自のルートが維持されています。

## レビュー工程を追加してプロセスを変更する

1. **グループルートの変更**で種類と設定を選びます。
2. **選択内容の確認**：どのアカウントが変わり、どれが独自のルートを持つかを確認します。
3. **準備して確認**で新しい Telegram 接続をテストし、可能なら出口 IP も確認します。
4. **確認済みの接続を適用**し、それぞれの結果を見ます。動作中のアカウントは再開し、停止中のものは停止したままです。

遅延は Telegram 接続の確立にかかった時間で、出口 IP は確認時にルートが示したものです。結果はアカウントごとに異なることがあります。

## 重複するアクセス権を使用する

**複数のアカウントが閲覧できるチャット**には、共有のソースとそのカバレッジが並びます。チャンネルとスーパーグループは**… アカウントでエクスポート**で複数のアカウントから同時にエクスポートできます。個人チャットと通常のグループはできません。メッセージ番号がアカウントごとだからです。

## グループをパッケージとしてエクスポートする

**グループのエクスポート**では、各アカウントの署名付きエクスポートとその署名付き一覧を 1 つの ZIP にまとめます。それぞれが検証用に自分のフィンガープリントを保ちます。統合した時系列は自分で組み立てます。
