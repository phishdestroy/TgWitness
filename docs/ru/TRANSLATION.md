# Перевод отчётов для суда

TgWitness формирует отчёты на 25 языках. Английский язык является исходным. Остальные языки представляют собой машинные переводы, причём для некоторых из них терминология была проверена; они помогают оператору ознакомиться с отчётом и не являются заверенными переводами.

<a id="what-to-file"></a>
## Что необходимо подать

Подайте английский оригинал вместе с заверенным или присяжным переводом на язык суда. Присяжный переводчик владеет местной терминологией и знает формальные требования к судебным документам.

Если язык отчёта не является английским, ZIP-архивы с доказательствами, чатами и передаваемыми данными также содержат английский оригинал того же отчёта: `report.en.html` и `report.en.pdf`, либо `chat.en.html` и `chat.en.pdf` для экспорта чата. Они запечатаны и подписаны тем же ключом, что и отчёт на выбранном языке, и указаны с их SHA-256 в подписанном манифесте, где они обозначены как `report.original`. Отчёт, экспортированный на английском языке, сам по себе является оригиналом. Отчёт на выбранном языке открывается с той же рекомендацией и содержит ссылку на файл на английском языке.

Перед переводом сверьте оригинал с архивом:

```sh
python -m tgwitness.verify report.en.html --fingerprint KEY --evidence tgwitness-evidence.zip
```

Файл `README.txt` в каждом архиве заканчивается разделом **Для переводчиков**, в котором указаны исходные файлы и повторяются приведённые ниже термины. В [тексте отчёта и протоколе экспертизы](NARRATIVE.md) приводится одна и та же рекомендация.

<a id="what-stays-literal"></a>
## Что следует переводить дословно

- Имена файлов, команды, хеши, отпечатки ключей, ID в Telegram, номера сообщений и URL-адреса.
- Время: UTC в формате ISO 8601, как указано. Не преобразуйте его в местный часовой пояс.
- Захваченные сообщения: приводите их на языке оригинала и давайте перевод отдельно, пометив его как «перевод».

<a id="terms"></a>
## Термины

| Термин | Значение | Не следует переводить как |
| --- | --- | --- |
| журнал | Подписанная и сцеплённая хеш-цепочкой последовательность записей, ведущаяся сборщиком | Дневник, периодическое издание, журнал |
| запись | Одна подписанная запись в журнале; во всём тексте используйте для обозначения этого понятия одно слово | Заметка, статья |
| наблюдение | То, что сборщик получил в указанный момент времени | Вывод об достоверности содержания |
| сборщик | Процесс TgWitness, осуществлявший наблюдение через личный аккаунт оператора в Telegram | Сбор элементов |
| сбор данных | Приём и запись обновлений из Telegram | Сбор, формирование, компиляция |
| уведомление об удалении | Уведомление Telegram о том, что сообщение было удалено; в нём не указано, кто его удалил | Подтверждённое удаление конкретным лицом |
| отсутствует при повторной проверке | Telegram больше не отобразил сообщение при повторной проверке: оно было удалено или больше не отображается для данного аккаунта | Удалено |
| отсутствует номер сообщения | Номер, по которому в экспорте отсутствует сообщение: либо оно было удалено ранее, либо никогда не отображалось для данного аккаунта | Отсутствующее сообщение, утерянное сообщение |
| пробел | Период, в течение которого наблюдения отсутствовали | Свидетельство того, что ничего не произошло |
| предыдущая версия | Текст до внесения изменений; обе версии сохраняются | Исправление, фальсификация |
| контрольная точка | Подписанная сводка журнала до определённого номера записи | Контрольная точка в физическом смысле |
| служба временных меток (TSA) | Независимая служба временных меток, соответствующая стандарту RFC 3161 | Орган власти, государственный орган, центр сертификации |
| Квитанция о простановке временной метки | Ответ службы временных меток или квитанция OpenTimestamps, подтверждающая существование контрольной точки на определённый момент времени | Доказательство, подтверждение фактов |
| печать | Подпись Ed25519, встроенная в файл отчёта | Печать должностного лица |
| отпечаток ключа подписи | Хеш SHA-256 открытого ключа, полученный через отдельный доверенный канал | Биометрический отпечаток пальца |
| свидетель | Независимая сторона или служба, осуществляющая хранение или подтверждение контрольных точек | Лицо, дающее показания в суде |
| выписка о передаче | Часть журнала, подготовленная для другой стороны, с минимальным количеством данных о других лицах | Полный экспорт |
| запись с минимальным объёмом данных | Запись, в которой скрытые поля обозначены и заменены их хеш-кодами | Удалённая или отредактированная запись |
