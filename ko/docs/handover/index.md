# 공유용 사본을 준비하십시오

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/handover/

원본 작업 공간을 그대로 유지하면서 관련 관찰 내용을 공유하십시오.

인계 자료는 별도로 서명된 발췌본입니다. 채팅 및 참여자를 선택하고, 신원 정보나 텍스트를 축약하며, 수신자 사본에 포함될 파일과 팀 메모를 결정하십시오. 인계 목록(manifest)에는 선택된 항목과 변경되지 않은 기록, 축소된 기록, 생략된 기록의 수가 기록됩니다.

## 수신자용 발췌본 준비

1. **‘내보내기’ → ‘인계용 추출’을** 엽니다. 용도를 기재하고, 채팅과 선택 사항인 UTC 기간을 지정한 후, 피조사자의 이름이 필요한 경우 **‘선택한 채팅의 참여자 불러오기’를** 선택하십시오.
2. 나머지 사용자에 대한 처리 방식(가명 사용, 메시지 생략, 기록된 내용 그대로 표시)을 선택하십시오. 메시지 본문과 첨부 파일을 별도로 설정할 수 있으며, 선택에 따라 전화번호와 이메일 주소를 가릴 수 있습니다.
3. 케이스 보드(Case Board)의 북마크와 슬라이스를 포함할지, 아니면 주석이 달린 카드를 포함할지 선택하십시오. 이 문서에서는 팀 이름 대신 수사관 별칭을 사용할 수 있습니다.
4. **'다운로드 인계 추출'을** 선택하십시오. 생성된 보고서와 선택한 기록을 로컬에서 열고, 아카이브를 확인한 후, 사본을 검토한 뒤 전송하십시오.

### 원본 1부, 공유용 사본 1부

합성 예시 · 실제 사례와는 무관함

1. **선택.** 사건 채팅을 포함하고, 발췌 내용이 누구에 관한 것인지 명시하십시오.
2. **최소화.** 공유 사본에서 다른 참여자가 어떻게 표시될지 선택하십시오.
3. **검토.** 생성된 아카이브의 보고서와 기록을 전송하기 전에 열어 확인하십시오.
4. **공유해 주십시오.** 교정된 사본을 전달하고, 신뢰할 수 있는 지문 정보를 별도로 알려주십시오.

#### 원문 관찰 사항

Nora · 사용자 71002

“수정된 링크를 받았습니다.”

원본 저널에는 이 저장된 관찰 내용이 보관됩니다.

#### 수신자용 사본

기록된 대로 표시: Nora · 사용자 71002 · “수정된 링크를 받았습니다.”

가명: P01 · “수정된 링크를 받았습니다.”

생략: 이 참가자의 메시지는 본문에서 제외됩니다.

#### 실제 파일을 검토하십시오

report.html 및 records.jsonl 파일을 참조하십시오.

신원 정보, 본문, 첨부 파일 및 선택 사항인 팀 코멘트를 확인하십시오.

#### 서명된 발췌문

선택 항목 + 파일 해시 + 서명된 매니페스트

원본 저널 경계와 연결된 별도의 패키지

## 제어 기능을 함께 사용하십시오

| 제어 | 문안 수정 사항 |
| --- | --- |
| 사람들 | 선택된 대상은 식별 가능하도록 유지하고, 다른 참여자는 선택에 따라 가명 처리하거나 생략하십시오. |
| 텍스트 | 모든 텍스트를 포함하거나, 선택된 인물 및 관찰 계정의 텍스트만 포함하거나, 메시지 본문과 텍스트가 포함된 세부 정보 필드를 생략할 수 있습니다. |
| 파일 | 선택한 인물 및 관찰 대상 계정의 파일, 표시된 모든 메시지의 파일, 또는 파일을 선택하지 않을 수 있습니다. |
| 케이스 보드 | 보드 자료, 북마크 및 슬라이스는 포함하지 말고, 팀 토론이 포함된 카드는 선택하십시오. |

자유 형식 텍스트와 파일 내용뿐만 아니라 신원 정보도 검토하십시오. 가명을 사용한다고 해서 메시지나 첨부 파일에 기재된 모든 이름이 자동으로 제거되는 것은 아닙니다. 선택한 보존 파일이 없는 경우, 추출물을 생성하기 전에 해당 파일을 복원하거나 첨부 파일을 명시적으로 제외하십시오.

## 번역본은 독립적으로 검증 가능해야 합니다.

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

원본 서명된 증거 아카이브와 체크포인트는 별도로 보관하십시오. 인계 과정은 자체적인 투영 정보를 기록하므로, 수신자는 전체 작업 공간을 수신하지 않고도 전달된 사본을 확인할 수 있습니다. [Report Studio는](https://phishdestroy.github.io/TgWitness/ko/docs/reports/) 자체적인 읽기 설계를 제공하며, [내보내기 검증 기능은](https://phishdestroy.github.io/TgWitness/ko/docs/exports/) 신뢰할 수 있는 참조 정보를 설명합니다.
