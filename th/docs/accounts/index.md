# Telegram · เชื่อมต่อบัญชี

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/accounts/

หนึ่งพื้นที่ทำงาน = หนึ่งบัญชี พร้อมบันทึกและคีย์ของมัน

## เลือกวิธีลงชื่อเข้าใช้

**บัญชี** → เพิ่มพื้นที่ทำงาน → การตั้งค่าการเชื่อมต่อ ใช้บัญชีแยกสำหรับงานนี้

- **คิวอาร์โค้ด:** สแกนจากหน้าจออุปกรณ์ใน Telegram แล้วยืนยัน
- **หมายเลขโทรศัพท์:** หมายเลข รหัส แล้วรหัสผ่าน 2FA หากมี
- **นำเข้าเซสชัน:** ไฟล์เซสชันของคุณเองหรือข้อมูล Telegram Desktop

ใช้โปรไฟล์ API ในตัวหรือ API ID และ hash ของคุณเอง มันแค่ระบุตัวแอป ไม่ได้ทำให้คุณเข้าสู่ระบบหรือซ่อนอะไร

**ต้องการใช้พร็อกซีก่อนหรือไม่?**

คุณสามารถ[เลือกและทดสอบ](https://phishdestroy.github.io/TgWitness/th/docs/proxies/)เส้นทางการเชื่อมต่อก่อนที่จะลงชื่อเข้าใช้ได้ แต่ละบัญชีมีเส้นทางการเชื่อมต่อของตัวเอง

## เลือกสิ่งที่ต้องการติดตาม

1. เลือกแชท กลุ่ม หรือช่องที่คุณต้องการ
2. ตรวจการตั้งค่าการเก็บข้อมูล รวมถึงสื่อ
3. เริ่มแล้วตรวจการเชื่อมต่อและกิจกรรมล่าสุด

บัญชีต้องมีสิทธิ์เข้าถึง ผู้ดูแลและสมาชิกเห็นสิ่งที่ต่างกัน บันทึกแสดงสิ่งที่บัญชีนี้ได้รับ

ทั้งบัญชี? **แหล่งข้อมูล → ขอบเขตการสังเกต → โหมดสืบสวน** ตรวจแล้ว **บันทึกขอบเขต** คำแนะนำฉบับเต็ม: [การสืบสวนทั้งบัญชี](https://phishdestroy.github.io/TgWitness/th/docs/cases/)

## ตรวจสอบเส้นทางทั้งหมด

ในกลุ่มทดสอบ ส่งข้อความจากบัญชีอื่น แก้ไข แล้วลบ ทั้งสามเหตุการณ์ควรปรากฏในบันทึก จากนั้น [ส่งออกและตรวจสอบ](https://phishdestroy.github.io/TgWitness/th/docs/exports/)

"เชื่อมต่อแล้ว" หมายถึงการเชื่อมต่อใช้ได้ ข้อความทดสอบที่ถูกจับได้หมายถึงเหตุการณ์มาถึงจริง

## เพิ่มบัญชีอีกบัญชี

พื้นที่ทำงานใหม่ใน **บัญชี** ขั้นตอนเดิม จดลายนิ้วมือคีย์ของแต่ละบัญชีไว้เพื่อแยกการส่งออกในภายหลัง
