# การตั้งค่าและกำหนดค่าครั้งแรก

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/reference/settings/

ตัวช่วยตั้งค่า, เป้าหมาย, ระดับอินเทอร์เฟซ, เส้นทางการเชื่อมต่อ และการตั้งค่าที่กลุ่มบัญชีใช้ร่วมกัน

[บัญชี](https://phishdestroy.github.io/TgWitness/th/docs/reference/accounts/) · [การเชื่อมต่อ](https://phishdestroy.github.io/TgWitness/th/docs/reference/connection/) · [เข้าถึง](https://phishdestroy.github.io/TgWitness/th/docs/reference/access/)

พื้นที่ทำงานใหม่จะเปิดขึ้น `/first-run`: ภาษาและเวลา, ระดับอินเทอร์เฟซ, เป้าหมาย, การเชื่อมต่อ, Telegram และการสนทนา. ทุกคำตอบจะถูกบันทึกบนเซิร์ฟเวอร์ทันทีที่ มีการเปลี่ยนแปลง ดังนั้นการรีโหลดจะต่อจากขั้นตอนเดิม หน้าจอสุดท้ายแสดงรายการคำตอบและ ให้คุณกลับไปยังคำตอบใดก็ได้

ภาษา เขตเวลา IANA ธีม และระดับถูกเก็บไว้ตามผู้ใช้งานและตามพื้นที่ทำงาน ค่าเริ่มต้นคือภาษาของเบราว์เซอร์ เขตเวลาของอุปกรณ์ ธีมของระบบ และ อินเทอร์เฟซแบบเรียบง่าย การเปลี่ยนภาษาจะไม่ส่งผลต่อเซสชันของแผงควบคุม เวลาใน บันทึกที่ลงนามแล้วจะไม่เปลี่ยนแปลง

`/settings` แก้ไขบันทึกเดียวกันกับตัวช่วยสร้าง การค้นหาครอบคลุมสนามหลัก พารามิเตอร์ และแบบฟอร์มขยาย; สนามที่ซ่อนอยู่สามารถเปิดได้โดยไม่เปลี่ยน ระดับ ระดับเปลี่ยนเพียงสิ่งที่แสดงเท่านั้น: เซิร์ฟเวอร์ตรวจสอบสิทธิ์ด้วยตัวเอง การตั้งค่าคอลเลกชันและการเชื่อมต่อครั้งแรกเป็นของผู้ดูแลพื้นที่ทำงาน

| ระดับ | ฟิลด์ | แถบด้านข้าง |
| --- | --- | --- |
| เรียบง่าย | เฉพาะส่วนที่จำเป็นเท่านั้น | หน้าหลัก, การสนทนา, การเปลี่ยนแปลง, คลังเก็บ, การตั้งค่า |
| มาตรฐาน | การตั้งค่าทั่วไปพร้อมคำอธิบาย | เพิ่มCase Board, Accounts และ Access |
| ผู้เชี่ยวชาญ | ทุกฟิลด์ ข้อจำกัด และรายละเอียดทางเทคนิค | เพิ่มแหล่งข้อมูล, ส่วนเสริม, ถามคลังข้อมูล, พารามิเตอร์, บัญชี, บันทึกระบบ และการบูรณาการ |

[คู่มือแผง](https://phishdestroy.github.io/TgWitness/th/docs/reference/panel/)ควบคุมอธิบายรายละเอียดของแต่ละส่วน

## เป้าหมาย

| เป้าหมาย | คอลเลกชัน | ไฟล์ | บริการภายนอก | ที่อยู่เซิร์ฟเวอร์ |
| --- | --- | --- | --- | --- |
| สำเนาเก็บถาวร | ปิด; **เริ่ม**ทำงานเพื่อส่งออก | รูปภาพขนาดสูงสุด 20 MB | ปิด | อัตโนมัติ |
| ติดตามการสนทนา | ต่อเนื่อง | รูปภาพและวิดีโอความยาวสูงสุด 60 วินาที / 20 MB | เวลาบันทึกและแจ้งเตือนปัญหา | อัตโนมัติ |
| หลักฐาน | ต่อเนื่อง | ไฟล์ทั้งหมดขนาดไม่เกิน 1 GB | Timestamps, drand, การแจ้งเตือน | ไม่, ซ่อนมัน |

แนะนำให้ใช้สำเนาภายนอก (off-site copy), bot พยาน (witness bot) และการตรวจสอบโค้ด (code check) เป็นหลักฐาน ที่อยู่สำหรับจัดเก็บและรับการแจ้งเตือนจำเป็นต้องมีปลายทางก่อน ฟีเจอร์ที่ติดต่อ กับบริการภายนอกจะขอสิทธิ์อนุญาตให้ส่งคำขอไปยังบริการนอก Telegram; การปิดฟีเจอร์นี้ จะเสนอให้ปิดการบันทึกเวลา (timestamps), การแจ้งเตือน และสำเนาภายนอกไปด้วย

การเปลี่ยนเป้าหมายจะแสดงความแตกต่างก่อน และการเปลี่ยนแปลงด้วยมือสามารถเก็บไว้ได้ สนาม ที่แตกต่างจากเป้าหมายจะถูกทำเครื่องหมายว่า **“Changed by you**” และสามารถคืนค่าเดิมได้ การ แก้ไขการตั้งค่าจะป้องกันไม่ให้ความแตกต่างที่ได้รับการตรวจสอบถูกนำไปใช้ทับการเปลี่ยนแปลง ที่ทำในแท็บอื่น

## การเชื่อมต่อ

**Automatic** จะลองใช้เซิร์ฟเวอร์สาธารณะ MTProxy ก่อน แล้วตามด้วย WARP และสุดท้ายคือการเชื่อมต่อโดยตรง โดยวิธีหลังนี้จะใช้เฉพาะเมื่อที่อยู่ของเซิร์ฟเวอร์อาจถูกเปิดเผยเท่านั้น Automatic และ WARP สามารถติดตั้ง ส่วนประกอบที่ผ่านการตรวจสอบแฮช และลงทะเบียนเซิร์ฟเวอร์กับ Cloudflare ได้ WARP ใช้ ตัวจัดการ wgcf/wireproxy ที่มีอยู่และพอร์ต SOCKS5 ในเครื่อง; ตารางการกำหนดเส้นทางของระบบ ไม่ถูกเปลี่ยนแปลง เมื่อจำเป็นต้องใช้บริการจากภายนอก Automatic จะเลือกใช้ WARP แทน MTProxy

พร็อกซีของคุณเองจะรับ `tg://proxy`, `socks5://`, `http://` และ `https://`. ใบรับรองของ พร็อกซี HTTPS จะถูกตรวจสอบก่อนที่ข้อมูลรับรองจะถูกส่งไปยังพร็อกซีนั้น

การตรวจสอบการเชื่อมต่อมีอายุการใช้งาน 5 นาที และผูกกับเส้นทาง (route), นโยบาย (policy) และ คำตอบจากตัวช่วยสร้าง (wizard); การเปลี่ยนแปลงสิ่งใดก็ตามในนั้นจำเป็นต้องทำการตรวจสอบใหม่ สามารถดำเนินการต่อได้**โดยไม่ต้อง ตรวจสอบ** และไม่แทนที่การลงชื่อเข้าใช้ Telegram เส้นทางที่เลือก จะถูกตรวจสอบใหม่ในพื้นหลัง และโหมดอัตโนมัติ (Automatic) จะรันโซ่คำสั่งอีกครั้งหลังจาก การเชื่อมต่อถูกตัดขาด เมื่อไม่มีพร็อกซีสาธารณะตอบกลับ ตัวนับจะเปลี่ยนเป็นสีแดงพร้อมตัวเลือก WARP และ การตรวจสอบใหม่

## กลุ่มบัญชี

บัญชีในกลุ่มจะแบ่งปันการตั้งค่ากัน เปิด **Accounts → Groups and shared settings → Shared settings** หรือ **Group settings** บนหน้า Settings ของบัญชี

กลุ่มนี้แบ่งปันเป้าหมาย ไฟล์ที่เก็บไว้ เวลาที่บันทึก drand การแจ้งเตือนปัญหา สำเนาภายนอก Telegram คำขอจากนอก Telegram โหมด IP สิ่งที่จะบันทึก ตารางเวลา การตรวจสอบซ้ำ กฎการแจ้งเตือน การตั้งค่าการรายงาน พารามิเตอร์ และเส้นทางเชื่อมต่อ จุดหมายการแจ้งเตือน ข้อมูลรับรองพร็อกซี และการลงชื่อเข้าใช้จะเก็บไว้ตามแต่ละบัญชี เช่นเดียวกับการ เริ่มและหยุดการเก็บข้อมูล

- สมาชิกทุกคนจะติดตามกลุ่มนี้ การตั้งค่าจะกำหนดค่า 🔗 **จากกลุ่ม** หรือ ✏️ **ค่าของตนเอง**; **การกลับสู่ค่าของกลุ่ม**จะคืนค่าเดิม
- การเปลี่ยนแปลงจะแสดงรายชื่อบัญชีที่ได้รับผลกระทบ (**ใช้กับ 2 ใน 3 บัญชี**) และถามความเห็น จากแต่ละบัญชีก่อนที่จะแทนค่าเดิมด้วยค่าใหม่ บัญชีที่ไม่ได้ถูกเลือกจะรักษาค่าเดิมไว้
- พารามิเตอร์ที่กลุ่มไม่แบ่งปันจะยังคงอยู่ในสถานะ **"ไม่แบ่งปัน": แต่ละบัญชีจะเก็บ ค่าของตัวเองไว้**จนกว่าคุณจะกด **"แบ่งปันค่านี้**"
- **การคัดลอกการตั้งค่าจากบัญชีหนึ่ง**จะนำค่าของบัญชีที่เลือกมาใช้เป็นค่าของกลุ่ม
- เมื่อบัญชีถูกย้ายเข้าสู่กลุ่ม จะถูกถามว่า **“รับค่าของกลุ่มหรือไม่?”** หากไม่รับ บัญชีจะยังคงใช้ค่าเดิมของตัวเอง ซึ่งถูกทำเครื่องหมายด้วย ✏️ ส่วนบัญชีที่เพิ่มเข้ามาภายหลังจะเริ่มต้นด้วยค่าของกลุ่ม
- บัญชีผู้สังเกตการณ์จะรักษาโหมด IP ของตัวเองไว้จนกว่าจะถูกหยุดชั่วคราว

ทุกการเปลี่ยนแปลงจะถูกบันทึกไว้ในบันทึกที่ลงนามของพื้นที่ทำงานหลักและของทุก สมาชิกที่ข้อมูลนั้นส่งถึง การลบกลุ่มจะรักษาบัญชีในกลุ่มและค่าปัจจุบันของบัญชีเหล่านั้นไว้

หน้ากลุ่ม `/groups/<id>` แสดงสมาชิก สิ่งที่จำเป็นต้องติดตาม และบทสนทนา ที่บัญชีหลายบัญชีสามารถเห็นได้ ดู[กลุ่มบัญชี](https://phishdestroy.github.io/TgWitness/th/docs/reference/accounts/#bulk-import-and-account-groups)

## พื้นที่ทำงานที่มีอยู่

พื้นที่ทำงานที่มีเซสชันหรือการตั้งค่าที่เสร็จสิ้นไปแล้วจะไม่แสดงตัวช่วยตั้งค่า ค่าของมันจะไม่ถูกแทนที่ด้วยเป้าหมายเมื่อหน้าเว็บโหลดขึ้น การซ่อนฟิลด์จะไม่ ปิดใช้งานฟีเจอร์หรือลบค่าของมัน

การประมาณขนาดและเวลาจะอ่านสูงสุด 3 ห้องสนทนาที่เลือกไว้ และสูงสุด 20 ข้อความจาก แต่ละห้องสนทนา นี่เป็นการประมาณเท่านั้น: ไม่คาดการณ์ขีดจำกัดของ Telegram ความเร็วของ เซิร์ฟเวอร์เฉพาะ หรือไฟล์ในทุกห้องสนทนา

```
python tools/test_settings_hub.py
python tools/test_group_settings.py
python tools/check_group_settings_browser.py
python tools/check_first_run.py
```
