# עיצוב דוח

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/reports/

יש לספק לקורא מסלול ברור משאלת התיק ועד לתיעוד השמור.

"Report Studio" משלב בחירת נתונים, היסטוריית שינויים קריאה, תרשימים וממצאיכם הכתובים. שמונה עיצובים משולבים חלים על פלט HTML נתמך ו-PDF מקורי. דוחות בפורמטים HTML, PDF ו-JSON נושאים חותמות חתומות משלהם; קובץ ה-ZIP גם מאגד את הקבצים בחבילה. קבצי HTML ו-PDF נחתמים לאחר השלמת העיצוב הסופי שלהם.

## הכנת דוח בשלושה שלבים

1. פתח **את** **'ייצוא' → 'הגדר ותצוגה מקדימה' → 'נתונים**'. השתמש בכל סביבת העבודה או בחר צ'אטים, מחברים, תאריכי תצפית ב-UTC וסוגי רשומות. התאריכים מתארים מתי TgWitness תיעד את הרשומה.
2. ב**"עיצוב ותוכן"**, בחרו תבנית קבועה מראש לעיצוב ולתוכן. בחרו תרשימי פעילות, תוויות משתתפים, תמלול, שינויים שנשמרו וחומר אופציונלי מלוח התיק. הוסיפו את פרטי התיק והערות הבדיקה שלכם.
3. פתח **את** **"תצוגה מקדימה"** כדי לעיין במספרים, בפעילות, במשתתפים, ברשומות שנדגמו ובטווחי מזהים חסרים. שמור את ההגדרות, ולאחר מכן הורד את הפורמט הדרוש לך.

### ארגנו את אותו החומר שנשמר כך שיהיה נוח לקורא

דוגמה סינתטית · פריסה סכמטית, לא דוח שנוצר

1. **בחר.** בחר שני צ'אטים ותקופת התצפית עבור התיק.
2. **כתוב את הטקסט.** בחר פריסה ואת הסעיפים העונים על השאלה.
3. **תצוגה מקדימה.** בדקו את מספר המילים שנבחרו ואת הטקסט שנשמר לפני ואחרי התרגום.
4. **יש לאמת.** יש ליצור את הקובץ הסופי ולבדוק את חתימתו מול טביעת האצבע של סביבת העבודה המהימנה.

## בחרו סגנון קריאה

**הקטגוריות "קלאסי", "עריכה", "תדריך", "אנליטיקה", "טכני", "סקירה כללית", "סדרת קריאה" ו-"Ledger & margin"** מציגות את אותם רשומות בסיסיות בהרכבים שונים. שינוי העיצוב שומר על בחירת הנתונים וההערות הכתובות. ניתן לבחור את שפת הדוח מבין 25 השפות הנתמכות.

סדרת הקריאה מקבצת את התיק, ההיקף, הממצאים והשינויים סביב מסגרת סעיפים. "Ledger & margin" משתמשת בפרקים ממוספרים ובשוליים רחבים. שתיהן תומכות גם בסקירות HTML של חשבונות ובשיתוף עותקים. קובצי PDF מקוריים נוצרים עם גופנים מצורפים; המחשב של המשתמש אינו זקוק לדפדפן או להתקנת Node ליצירת PDF. קובצי PDF בסינית, יפנית וקוריאנית דורשים בנוסף גופן מתאים בשרת, כגון Noto Sans CJK, המותקן בכל המערכת או ממוקם ב-`TGWITNESS_FONT_DIR`. ללא גופן זה, קובץ ה-ZIP שומר את דוחות ה-HTML וה-JSON.

## קרא את השינוי בהקשר שלו

עריכות שנשמרו מוצגות לפני ואחרי. הודעת מחיקה יכולה להיות מלווה בגרסה האחרונה שנלכדה. תשובות, ציטוטים, העברות, תגובות, כפתורים ומטא-נתונים של קבצים מצורפים שומרים על ההפניות הזמינות שלהם. חתימות SHA-256 של קבצים וחתימות יומן-רשומות מסומנות בנפרד.

תצוגה מקדימה של העיצוב מציגה רכיבי עמוד שער, בדיקה ותרשימים באמצעות רשומות תואמות מתוך 50,000 הרשומות הראשונות במקור. התצוגה המקדימה הנפרדת של הנתונים סורקת את תמונת המצב המלאה והיציבה של היומן כדי לקבל ספירת בחירות מדויקת, עם ציון מגבלות המדגם המוצגות. צרו קובץ PDF כדי לבדוק את חלוקת העמודים הסופית. לייצוא חשבון מלא יש סקירה כללית ב-HTML; קבצי ה-PDF של הצ'אטים הבודדים משתמשים בעיצוב הנבחר.

## בחרו את נוסח היעד בקפידה

מסנני הדוחות מעצבים את הדוח הקריא. קובץ ה-ZIP המלא של הראיות שומר על היומן המקורי והנספחים. יש להשתמש [בהעברה](https://phishdestroy.github.io/TgWitness/he/docs/handover/) [מצומצמת](https://phishdestroy.github.io/TgWitness/he/docs/handover/) כאשר על הנמען לקבל רק נתונים נבחרים. ניתן לעיין [בתוכן הדוח ובאימותו,](https://phishdestroy.github.io/TgWitness/he/docs/reference/case-reports/) או [לאמת את הייצוא המוגמר](https://phishdestroy.github.io/TgWitness/he/docs/exports/).
