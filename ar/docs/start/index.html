ابدأ في غضون دقائق

ابدأ أولاً باستكشاف مثال عملي. ثم قم بربط حسابك الخاص.

تصفح الموقع دون الحاجة إلى إنشاء حساب

قم بتنزيل المشروع أو نسخه، وتثبيت Python 3.11 أو إصدار أحدث، ثم قم بتشغيل العرض التوضيحي. يقوم المشغل بإنشاء بيئة محلية وتثبيت التبعيات المثبتة.

git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness

Windows

.\scripts\Demo.cmd

Linux / macOS

sh start.sh --demo

يفتح المتصفح مساحة عمل تحتوي على رسائل خيالية. افتح محادثة، وقارن تعديلاً، وافحص ملفاً تم تصديره. لا يتصل وضع العرض التوضيحي بـ Telegram.

ابدأ مساحة العمل الخاصة بك

أغلق عملية العرض التوضيحي، ثم استخدم المشغل العادي:

Windows

.\Start.cmd

Linux / macOS

sh start.sh

افتح العنوان المحلي الذي يعرضه المشغل. إذا طُلب منك ذلك، أدخل رمز الوصول إلى اللوحة من الملف المحلي المسمى في المحطة الطرفية. يؤدي ذلك إلى فتح TgWitness؛ وهو أمر منفصل عن تسجيل الدخول إلى Telegram.

التقط رسالتك الأولى

  1. قم بربط حساب Telegram مخصص.
  2. اختر مجموعة أو قناة يمكن للحساب الوصول إليها، ثم ابدأ المراقبة.
  3. أرسل رسالة جديدة في مجموعة تجريبية تديرها أنت وتأكد من ظهورها في السجل.

لتثبيت الخادم، اتبع إرشادات «Keep it running».
