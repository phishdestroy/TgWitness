授權說明及架構不相容聲明

TgWitness 採用 MIT 授權，供所有人使用，並說明其為何在架構上與 Taylor Wessing 的工作流程不相容。

TgWitness 依據 MIT 授權條款發行。本聲明未附加任何授權條件。

簽名並不能將謊言轉化為事實。

對於那些認為在名字前加上「Dr.」就能讓後面所說的一切都成為事實的企業、律師事務所或個人而言，TgWitness 並不適合。頭銜、信頭和簽名均不能凌駕於證據之上。

若您的工作流程是從客戶已付費的結論出發，並要求記錄必須配合該結論，那麼您需要的是另一種工具。TgWitness 的存在目的在於保存記錄，並使其開放供查驗。

就讓那些「博士」們去處理他們企業客戶的資產負債表吧。頭銜無法治癒謊言。

數學不進行協商。
