# เตรียมสำเนาเพื่อแบ่งปัน

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/handover/

แบ่งปันข้อสังเกตที่เกี่ยวข้องโดยรักษาพื้นที่ทำงานเดิมให้คงเดิม

การส่งต่อเป็นส่วนที่แยกออกมาและลงนามแล้ว ให้เลือกการสนทนาและบุคคลที่เกี่ยวข้อง ลดข้อมูลส่วนบุคคลหรือข้อความ และตัดสินใจว่าไฟล์และบันทึกของทีมใดควรรวมอยู่ในสำเนาของผู้รับ รายการเนื้อหา (manifest) จะบันทึกการเลือกดังกล่าว รวมถึงจำนวนบันทึกที่ยังไม่เปลี่ยนแปลง บันทึกที่ถูกลดขนาด และบันทึกที่ถูกตัดออก

## เตรียมข้อมูลที่คัดลอกสำหรับผู้รับ

1. เปิด **Exports → Handover extract**. เขียนวัตถุประสงค์ เลือกการสนทนาและช่วงเวลา UTC (ตามต้องการ) แล้วเลือก **Load people of the chosen chats** หากต้องการระบุชื่อผู้เกี่ยวข้อง
2. เลือกวิธีจัดการกับผู้ใช้อื่น ๆ: ใช้ชื่อปลอม, ละเว้นข้อความของพวกเขา หรือแสดงตามบันทึกไว้ ตั้งค่าข้อความและไฟล์แนบอย่างอิสระ; สามารถเลือกปิดบังหมายเลขโทรศัพท์และที่อยู่อีเมลได้
3. เลือกว่าจะรวมบุ๊กมาร์กและสไลซ์ของ Case Board หรือการ์ดที่มีคำอธิบายประกอบไว้ด้วยหรือไม่ ชื่อแฝงของนักสืบสามารถแทนที่ชื่อทีมในข้อความนี้ได้
4. เลือก "**Download handover extract**" (ดาวน์โหลดส่วนที่ส่งต่อ) เปิดรายงานที่สร้างขึ้นและบันทึกที่เลือกไว้บนเครื่องท้องถิ่น ตรวจสอบไฟล์เก็บถาวร และตรวจสอบสำเนาก่อนส่ง

### ต้นฉบับหนึ่งฉบับ และสำเนาสำหรับแบ่งปันที่จัดทำขึ้นอย่างตั้งใจ

ตัวอย่างสังเคราะห์ · ใช้เพื่อแสดงตัวอย่างเท่านั้น

1. **เลือก.** รวมแชทของคดีและระบุบุคคลที่ข้อมูลที่คัดลอกนั้นเกี่ยวข้อง
2. **ลดขนาดให้เล็กที่สุด** เลือกวิธีที่ผู้เข้าร่วมอื่นจะปรากฏในสำเนาที่แชร์
3. **ตรวจสอบ.** เปิดรายงานและบันทึกในไฟล์เก็บถาวรที่สร้างขึ้นก่อนส่งไป
4. **แชร์** ส่งมอบสำเนาที่ตรวจสอบแล้ว และส่งข้อมูลลายนิ้วมือที่เชื่อถือได้แยกต่างหาก

#### ข้อสังเกตต้นฉบับ

Nora · ผู้ใช้ 71002

“ผมได้รับลิงก์ที่แก้ไขแล้ว”

หนังสือบันทึกต้นฉบับเก็บรักษาการสังเกตการณ์ที่บันทึกไว้นี้

#### สำเนาสำหรับผู้รับ

แสดงตามที่บันทึก: Nora · ผู้ใช้ 71002 · “ฉันได้รับลิงก์ที่แก้ไขแล้ว”

ชื่อปลอม: P01 · “ผมได้รับลิงก์ที่แก้ไขแล้ว”

ละเว้น: ข้อความของผู้เข้าร่วมนี้ไม่ถูกนำเข้ามาในเนื้อหา

#### ตรวจสอบไฟล์จริง

อ่านไฟล์ report.html และ records.jsonl.

ตรวจสอบข้อมูลประจำตัว ข้อความ ไฟล์แนบ และความคิดเห็นของทีม (หากมี)

#### ส่วนที่ลงนาม

การเลือก + ค่าแฮชของไฟล์ + รายการเนื้อหาที่ลงนาม

แพ็กเกจแยกต่างหากที่เชื่อมโยงกับขอบเขตของวารสารต้นทาง

## ใช้เครื่องมือควบคุมร่วมกัน

| Control | ผลกระทบต่อเนื้อหา |
| --- | --- |
| บุคคล | ให้หัวข้อที่เลือกไว้สามารถระบุตัวตนได้; ใช้ชื่อปลอมหรือละเว้นผู้เข้าร่วมอื่นตามความเหมาะสม |
| ข้อความ | รวมข้อความทั้งหมด, เฉพาะข้อความของผู้ใช้ที่เลือกและบัญชีผู้สังเกตการณ์, หรือไม่รวมข้อความในข้อความและสนามรายละเอียดที่มีข้อความ |
| ไฟล์ | เลือกไฟล์ของบุคคลที่เลือกและบัญชีผู้สังเกตการณ์, ไฟล์ข้อความทั้งหมดที่แสดง, หรือไม่เลือกไฟล์ใดเลย |
| Case Board | อย่าเลือกเนื้อหาบนบอร์ด, บุ๊กมาร์กและสไลซ์ หรือการ์ดที่มีการอภิปรายของทีม |

ตรวจสอบข้อความแบบอิสระและเนื้อหาไฟล์ รวมถึงข้อมูลระบุตัวตน: การใช้ชื่อปลอมจะไม่ลบชื่อทุกชื่อที่เขียนในข้อความหรือไฟล์แนบโดยอัตโนมัติ หากไฟล์ที่เลือกไว้สำหรับการเก็บรักษาไม่สามารถเข้าถึงได้ ให้กู้คืนไฟล์นั้นหรือละเว้นไฟล์แนบอย่างชัดเจนก่อนสร้างส่วนที่คัดลอก

## ให้เนื้อหาสามารถตรวจสอบได้อย่างอิสระ

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

เก็บรักษาคลังหลักฐานที่ลงนามต้นฉบับและจุดตรวจสอบ (checkpoints) แยกกันไว้ การส่งต่อบันทึกการส่งต่อจะบันทึกการฉายภาพของตัวเอง ดังนั้นผู้รับสามารถตรวจสอบสำเนาที่ส่งมาได้โดยไม่ต้องรับพื้นที่ทำงานทั้งหมด [Studio](https://phishdestroy.github.io/TgWitness/th/docs/reports/) [รายงาน](https://phishdestroy.github.io/TgWitness/th/docs/reports/)จัดเตรียมรูปแบบการอ่านของตัวเอง ส่วน[การตรวจสอบการส่งออก](https://phishdestroy.github.io/TgWitness/th/docs/exports/)จะอธิบายแหล่งอ้างอิงที่เชื่อถือได้
