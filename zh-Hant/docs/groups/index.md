# Telegram · 管理一組帳戶

Canonical page: https://phishdestroy.github.io/TgWitness/zh-Hant/docs/groups/

同時執行多個帳戶，每個帳戶仍有自己的紀錄和金鑰。

群組將連線狀態、啟動/暫停、共用設定和匯出放在同一個畫面。多個帳戶處理同一案件時很方便。

## 開啟群組概覽

在**帳戶**中開啟群組。每個帳戶顯示其狀態、路由、延遲和最後保存的訊息。**需注意**列出有問題的帳戶，**修復**直接帶您過去。

**全部開始** / **全部暫停**會先詢問再執行。**群組設定**是共用的，但帳戶自己的值會保留，直到您替換它們。

### 檢視群組內的路徑變更

合成範例 · 說明性檢查與結果

1. **選取。**選擇群組並檢視哪些帳戶將會變更。
2. **準備。**當需保持獨立時，請保留該帳戶的專屬路徑。
3. **檢查。**測試建議的連線並檢視測量結果。
4. **請進行翻譯。**儲存前請重新檢查，並審閱每個帳戶的翻譯結果。

#### 案件團隊

頻道收集器 · 群組收集器 · 參考帳戶

3 個獨立的工作區

#### 已審閱選段

有 2 個帳戶採用建議的流程。

參考帳戶將維持其原有路徑。

#### 準備檢查

頻道收集器：Telegram 傳輸時間 84 毫秒

群組收集器：Telegram 傳輸時間 91 毫秒

這些數字僅為範例中的虛構數值。

#### 應用結果

頻道收集器：已路由並保存，觀察已恢復。

群組收集器：重新檢查失敗，已還原先前設定。

參考帳戶：保留原有路徑。

## 在流程中新增「審查」步驟

1. **變更群組路由**，選擇類型和設定。
2. **檢視選擇**：查看哪些帳戶會變更，哪些有自己的路由。
3. **準備並檢查**會測試新的 Telegram 連線，並在可能時測試出口 IP。
4. **套用已檢查的連線**，並查看每個結果。執行中的帳戶會繼續，閒置的維持閒置。

延遲是建立 Telegram 連線的時間，出口 IP 是檢查時路由顯示的位址。結果可能因帳戶而異。

## 使用重疊存取權限

**多個帳戶可見的聊天室**列出共用來源及其涵蓋範圍。頻道和超級群組可以透過**以 … 個帳戶匯出**由多個帳戶同時匯出。私人聊天和一般群組不行，它們的訊息編號依帳戶計算。

## 將群組匯出為套件

**匯出群組**會產生一個 ZIP，包含每個帳戶的簽名匯出及其簽名清單。每份匯出都保留自己的指紋以供驗證。合併的時間軸仍需您自行整理。
