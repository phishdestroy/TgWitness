# از یک حساب جداگانه استفاده کنید. هرگز از حساب اصلی خود استفاده نکنید.

Canonical page: https://phishdestroy.github.io/TgWitness/fa/docs/dedicated-account/

قبل از اتصال حساب کاربری بخوانید

توصیه ما مبنی بر عدم استفاده از حساب اصلی‌تان شوخی نیست. این یک واقعیت است.

حساب اصلی

- با هَشِ اپلیکیشن خود، ۹۹٪ از حساب‌ها از سیستم خارج می‌شوند
- ممنوعیت حساب‌ها تنها به‌خاطر اعتماد پایین، شایع است
- استفاده از حساب اصلی شما یک ایده واقعاً احمقانه است

یک حساب اضافی بر روی جفت‌های شناسه/هَش API عمومی

- بیش از یک میلیون حساب کاربری از طریق این جفت‌های شناسه/هش API ثبت شده‌اند.
- این جفت‌های شناسه/هَش API بیش از ۵ سال است که فعال هستند.
- هیچ‌کس نمی‌تواند از طریق این جفت‌های API هیچ‌یک از داده‌های شما را ببیند

01

## چرا نباید از حساب اصلی خود استفاده کنید

این اطلاعات دقیق است. ما دقیقاً می‌دانیم نقاط ضعف این مشکلات کجا هستند.

1. ### با هَشِ اپلیکیشن خود، ۹۹٪ از حساب‌ها از سیستم خارج می‌شوند

   وارد شدن به my.telegram.org با حسابی که به آن دسترسی ندارید، برای به‌دست آوردن هَش اپلیکیشن، و سپس هر درخواستی از طریق آن هَش، به معنای ۹۹٪ احتمال خروج حساب کاربری است. می‌توانید آن را بررسی کنید.
2. ### ممنوعیت حساب‌ها تنها به‌خاطر اعتماد پایین، شایع است

   حساب‌ها صرفاً به این دلیل که تلگرام به آن‌ها اعتماد ندارد مسدود می‌شوند و این ممنوعیت‌ها مکرراً اتفاق می‌افتند. شما هم می‌توانید این را بررسی کنید. استفاده از حساب شخصی خودتان واقعاً ایده‌ای احمقانه است.
3. ### کلیدهای جلسه کپی‌شده را می‌توان لغو کرد

   اجرای همزمان کلید واردشده TData/session در تلگرام دسکتاپ و TgWitness می‌تواند خطای `AUTH_KEY_DUPLICATED` را فعال کند. تلگرام آن مجوز را باطل می‌کند، بنابراین هر دو نسخه به ورود مجدد نیاز دارند. یک حساب اختصاصی مانع از این امر نمی‌شود.

   کلاینت اصلی را به طور کامل ترک کنید و در حالی که از جلسه وارد شده آن استفاده می‌کنید، آن را بسته نگه دارید. برای استفاده موازی، با تلفن یا QR به TgWitness وارد شوید تا یک مجوز جداگانه ایجاد کنید؛ سایر کلاینت‌های دارای مجوز جداگانه می‌توانند همچنان وارد شده باقی بمانند.

   [هشدار وارد کردن جلسه را بخوانید](https://phishdestroy.github.io/TgWitness/demo/guide.html?lang=fa#session-warning)

مستندات تلگرام

- [خطاهای خروج: AUTH_KEY_UNREGISTERED, SESSION_REVOKED](https://core.telegram.org/api/errors)
- [ایجاد هش اپلیکیشن خود: به‌دست‌آوردن api_id](https://core.telegram.org/api/obtaining_api_id)

02

## چرا TgWitness از طریق جفت‌های عمومی هش اپلیکیشن و شناسه اپلیکیشن کار می‌کند

به همین دلیل ما TgWitness را بر پایهٔ جفت‌های عمومی هَش/شناسهٔ اپلیکیشن ساختیم. به نظر ما، با این روش احتمال مسدود شدن کمتر است: بیش از یک میلیون حساب تلگرام از طریق این جفت‌ها ثبت شده‌اند و برنامه‌های مختلف زیادی از طریق آن‌ها کار می‌کنند. از نظر منطق ما، این بهتر از کار مستقیم با هش اپلیکیشن شخصی است: این جفت‌ها قطعاً بیش از ۵ سال عمر دارند.

### جفت آی‌دی/هَش API جدید خودتان

ایجادشده در my.telegram.org از حساب کاربری.

- حدود ۹۹٪ این حساب‌ها از حالت لاگین خارج می‌شوند
- یک برنامه جدید، یک حساب

### جفت‌های شناسه/هَش API عمومی از مجموعه

همان جفت‌های شناسه/هش API که بسیاری از برنامه‌ها استفاده می‌کنند.

- بیش از یک میلیون حساب کاربری ثبت شده
- برنامه‌های مختلف
- این جفت‌های API بیش از ۵ سال است که در حال کار هستند

### چرا هیچ‌کس نمی‌تواند از طریق این جفت‌های API هیچ‌یک از داده‌های شما را ببیند

- #### این جفت API یک نام است، نه یک کلید

  تلگرام هنگام اتصال یک برنامه و درخواست کد ورود، شناسه API و هش API را می‌پرسد. این‌ها برنامه را شناسایی می‌کنند و هیچ دسترسی‌ای به هیچ حسابی نمی‌دهند؛ مستندات تل‌تون اشاره می‌کند که یک جفت با هر شماره تلفن کار می‌کند.
- #### کلید جلسه شما هرگز سرور شما را ترک نمی‌کند

  ورود با استفاده از تبادل دیفی–هلمن بین TgWitness و تلگرام یک کلید مجوز ایجاد می‌کند؛ خودِ کلید هرگز ارسال نمی‌شود. مستندات تلگرام: پس از تأیید مجوز، کلید با کاربر مرتبط می‌شود و هر فراخوانی با این کلید به‌عنوان آن کاربر اجرا می‌شود. سایر برنامه‌ها با همان جفت کلید، کلیدهای مخصوص به خود را دارند و نمی‌توانند از کلید شما استفاده کنند.
- #### ترافیک با کلید شما رمزگذاری می‌شود

  هر درخواست و پاسخ با کلید مجوز جلسه رمزگذاری می‌شود، نه با هش API. دانستن هش API هیچ چیزی را رمزگشایی نمی‌کند.
- #### صاحب یک جفت شناسه/هش API هیچ‌چیز نمی‌بیند.

  تلگرام هیچ روشی ندارد که حساب‌ها، جلسات یا پیام‌ها را بر اساس شناسه API فهرست کند. مالک یک جفت تنها تنظیمات اپلیکیشن خود را در my.telegram.org می‌بیند.
- #### فقط حساب کاربری شما می‌بیند که کدام اپ است

  تنظیمات → دستگاه‌های حساب کاربری شما، نام اپلیکیشن و شناسهٔ API هر جلسه، دستگاه، آدرس IP و تاریخ‌ها را فهرست می‌کند. هیچ‌کس دیگری این فهرست را نمی‌بیند.

## راه‌های ایجاد یک حساب اضافی

یک حساب تلگرام به شماره‌تلفنی نیاز دارد که کد ورود را دریافت کند. مدت‌زمان فعالیت حساب را مشخص کنید.

- بهترین انتخاب

  ### سیم‌کارت پیش‌پرداخت یا eSIM

  ********

  چقدر دوام دارد

  تا زمانی که آن را شارژ نگه دارید

  به خاطر داشته باشید

  مطمئن‌ترین: تلگرام بهترین پشتیبانی را از شماره‌های موبایل واقعی دارد. شماره‌ای که اپراتور آن را پس می‌گیرد، به شخص دیگری اختصاص می‌یابد.
- ### یک برنامه با شماره‌های تلفن مجازی

  ********

  چقدر دوام دارد

  تا زمانی که اپلیکیشن شماره تلفن را حفظ کند

  به خاطر داشته باشید

  تلگرام ممکن است شماره مجازی را رد کند، کد را ارسال نکند یا بلافاصله حساب جدید را محدود سازد؛ برخی اپلیکیشن‌ها شماره‌هایی را که استفاده نشده‌اند پس می‌گیرند.
- ### اجاره شماره تلفن

  ********

  چقدر دوام دارد

  برای دوره اجاره

  به خاطر داشته باشید

  وقتی پایان می‌یابد، شماره به مشتری بعدی منتقل می‌شود.
- ### فعال‌سازی یک‌باره

  ********

  چقدر دوام دارد

  تنها یک کد ورود

  به خاطر داشته باشید

  این شماره بلافاصله به استخر بازمی‌گردد، اغلب با سابقه‌ای از مالکان قبلی. قبل از هر چیز، رمز عبور رایانش ابری را تنظیم کنید.

هر کسی که بعداً شماره را در اختیار داشته باشد می‌تواند کد ورود را درخواست کند. یک رمز ابری (احراز هویت دو مرحله‌ای) مانع از ورود آن‌ها می‌شود؛ بدون آن حساب متعلق به مالک بعدی شماره خواهد بود.

مستندات تلگرام

- [سوالات متداول اسپم: شماره‌های مجازی و مالکان قبلی](https://telegram.org/faq_spam)
- [تأیید دو مرحله‌ای](https://core.telegram.org/api/srp)

### شماره‌های اجاره‌ای +888 (Fragment)

برخی بازارهای آنلاین و خدمات اجاره موقت شماره‌های رسمی +888 تلگرام از Fragment را ارائه می‌دهند.

قیمت تقریبی: ۲۰ دلار آمریکا در روز.

- می‌توانید مستقیماً در تلگرام وب یا تلگرام دسکتاپ یک حساب کاربری ثبت کنید.
- می‌توانید حساب‌های موجود را حذف کرده و حساب‌های جدید ایجاد کنید.
- این حساب‌ها عموماً با بررسی‌های کمتر ضدتقلب مواجه هستند، اما مصونیت یا امتیازات ویژه‌ای ارائه نمی‌کنند.

این شماره متعلق به شما نیست. پس از پایان اجاره، مالک می‌تواند آن را بازپس گیرد. فوراً یک رمز عبور ابری تنظیم کنید و این حساب را بلندمدت در نظر نگیرید.

داشتن شماره +888 به نام خودتان یا استفاده از سیم‌کارت پیش‌پرداختی که تحت کنترل شماست، همچنان قابل‌اعتمادتر است.

### حساب‌های آماده از مارکت‌پلیس‌ها

برخی بازارهای آنلاین (برای مثال G2G یا Z2U) حساب‌های تلگرام آماده—جدید، کهنه یا دارای فایل‌های جلسه—می‌فروشند.

- [G2G: فهرست حساب‌های تلگرام](https://www.g2g.com/uk/categories/telegram-accounts)
- [Z2U: فهرست حساب‌های تلگرام](https://www.z2u.com/telegram/accounts-5-15140)

هرگز از حساب اصلی خود استفاده نکنید! یک حساب اختصاصی که به این روش تهیه شده باشد، همچنان امن‌تر از وارد کردن حساب اصلی تلگرام شما در TgWitness است.

#### هشدارها پیش از خرید

- این کار نقض شرایط خدمات تلگرام است.
- بسیاری از حساب‌ها به‌صورت انبوه ثبت شده‌اند (خودنصب) یا تاریخچهٔ نامعلومی دارند.
- ممکن است برخی فروشندگان هنوز دسترسی بازیابی داشته باشند.
- حساب‌های حاصل از چنین بازارهایی اغلب بعداً مسدود یا محدود می‌شوند.
- از بازارهای آنلاین که علناً ابزارهای سرقت (stealers)، ابزارهای فیشینگ یا حساب‌های به‌وضوح سرقت‌شده را می‌فروشند، اجتناب کنید.
- خرید یک حساب — حتی حساب‌هایی که به‌عنوان خودکار ثبت‌شده تبلیغ می‌شوند — از پلتفرم‌هایی که آشکارا ابزارهای فیشینگ، استیلرها، جلسات یا حساب‌های سرقت‌شده را می‌فروشند، نه تنها شرایط خدمات تلگرام را نقض می‌کند بلکه قوانین اکثر کشورها را نیز زیر پا می‌گذارد. این امر می‌تواند بعداً شواهد شما را باطل کند. با دقت انتخاب کنید.

#### اگر از این گزینه استفاده کنید

1. حساب را یک‌بارمصرف در نظر بگیرید.
2. تمام جلسات دیگر را خاتمه دهید، رمز ابری را تنظیم کرده و روش‌های بازیابی را فوراً تغییر دهید.
3. از ۲–۳ حساب از ارائه‌دهندگان مختلف یا حساب‌هایی که خودتان ثبت‌نام کرده‌اید استفاده کنید.

**پریمِیوم، حذف و تأخیر هفت روزه**

اگر حساب دارای سرویس پریمیوم باشد، کسی که به شماره تلفن دسترسی دارد نمی‌تواند فوراً حساب را حذف کند. شما یک اعلان دریافت می‌کنید و هفت روز فرصت دارید پیش از حذف آن اقدام کنید.

این موضوع اهمیت دارد زیرا تحقیقات شما به حساب کاربری وابسته است: شما زمان دارید تا جایگزین را آماده کنید.

**حساب‌های جدید و اعتبارنامه‌های API**

اگر api_id/api_hash خود را از یک حساب جدید که خودتان با شماره‌ای از سرویس پیامکی ثبت‌نام کرده‌اید به‌دست آورده و استفاده کنید، حساب کاربری در اولین درخواست API یا تأیید دسترسی جلسه، از حالت لاگین خارج خواهد شد. هنگام برنامه‌ریزی یک تحقیق، این نکته را در نظر داشته باشید.

## ایجاد حساب

از دریافت شماره تلفن تا اولین گفتگوی ثبت‌شده.

1. ### دریافت شماره تلفن

   سیم‌کارت پیش‌پرداخت‌شده یا eSIM وقتی حساب باید برای مدت طولانی فعال بماند؛ اجاره یا فعال‌سازی یک‌باره برای یک کار کوتاه. خدمات در زیر فهرست شده‌اند.
2. ### به‌جز حساب اصلی خود ثبت‌نام کنید

   در اپلیکیشن رسمی تلگرام روی دستگاه جداگانه، شبیه‌ساز یا پروفایل تلفن ثبت‌نام کنید، نه در کنار حساب اصلی‌تان.
3. ### حساب را با یک رمز عبور ابری محافظت کنید

   فوراً یک رمز عبور ابری و یک ایمیل بازیابی که در هیچ جای دیگری استفاده نشده است تنظیم کنید.
4. ### محدود کردن تنظیمات حریم خصوصی حساب

   شماره تلفن **هیچ‌کس**، مرا با شماره‌ام پیدا کن **مخاطبینم**، آخرین مشاهده، عکس‌های پروفایل و بیو **هیچ‌کس** یا **مخاطبینم**؛ همگام‌سازی مخاطبین را غیرفعال کنید.
5. ### حساب را از خودویرانگری محافظت کنید

   خودویران‌سازی حساب را روی طولانی‌ترین مدت تنظیم کنید تا اگر TgWitness متوقف شود، حساب کاربری‌تان از دست نرود.
6. ### برای حساب یک پروفایل خنثی در نظر بگیرید

   بدون نام، عکس، نام کاربری یا بیو حساب‌های دیگر شما، بدون مخاطبین شخصی.
7. ### اجازه دهید حساب جدید گرم شود

   در ابتدا، روزانه فقط به چند چت بپیوندید. حساب‌های جدیدی که عجله می‌کنند، ابتدا محدود می‌شوند.
8. ### با ربات‌ها هیچ‌چیز را به اشتراک نگذارید

   هرگز دکمه «اشتراک‌گذاری شماره تلفن» یا «اشتراک‌گذاری موقعیت مکانی» را برای یک ربات فشار ندهید. لینک‌ها و اپلیکیشن‌های کوچک را از طریق VPN یا پروکسی روی آن دستگاه باز کنید.
9. ### حساب را به TgWitness متصل کنید

   در فضای کاری خود، از مسیر **حساب → کد QR** متصل شوید، سپس روی **منابع → حالت تحقیق** ضربه بزنید. اپلیکیشن جایی است که شما عمل می‌کنید، TgWitness سوابق را ثبت می‌کند.
