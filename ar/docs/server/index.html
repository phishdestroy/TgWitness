حافظ على استمرار عملها

الحفاظ على توفر أداة التجميع وسلامة بياناتها حتى بعد إعادة تشغيل النظام.

اختر طريقة الإطلاق

للتثبيت المحلي، استخدم المشغل وأمثلة الخدمة الموجودة في مجلد deploy/. بالنسبة لـ Docker، قم بتثبيت Docker مع Compose وقم بتشغيله من دليل المشروع:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

تستمع اللوحة الافتراضية إلى عنوان loopback الخاص بالمضيف، على المنفذ 8787. افتحها محليًّا أو عبر نفق SSH. استخدم الرمز المميز من الأمر الثاني لفتح اللوحة.

احتفظ بدليل البيانات بالكامل

تستخدم التثبيتات الأصلية وحدة التخزين data/live. بينما يستخدم Docker وحدة التخزين الدائمة tgwitness-data. احتفظ بالسجلات وجلسات الحسابات والمفاتيح وحالة التشغيل معًا. يُعد التصدير الموقّع دليلًا مفيدًا، لكنه ليس نسخة احتياطية كاملة للتثبيت.

  1. أوقف عملية التجميع قبل إجراء نسخ احتياطي متسق.
  2. انسخ دليل البيانات الخاصة بالكامل إلى مساحة تخزين محمية خارج المضيف.
  3. اختبر عملية الاستعادة في بيئة معزولة قبل الاعتماد على النسخة الاحتياطية.

يرجى التحقق بعد إعادة التشغيل

تأكيد مساحة العمل والمفتاح المتوقعين، والاتصال بـ Telegram، والمصادر المحددة، والتقاط الرسائل الجديدة. تساعد حالة MTProto المحفوظة ووظيفة «اللحاق بالركب» في استعادة التحديثات التي لا تزال Telegram تحتفظ بها. ولا يمكنها إعادة بناء كل تحديث منتهي الصلاحية أو تعديل تم حذفه قبل التقاطه.

تشير «صحة الحاوية» إلى استجابة خادم الويب. استخدم رسالة خاضعة للرقابة وفحصًا تثبتيًّا لتقييم عملية التجميع والنشر الخارجي.

انشر فقط ما تنوي نشره

تتضمن مرجع النشر أمثلة على بروتوكول HTTPS، وأوامر وحدة التخزين الدائمة (persistent-volume)، والتحديثات، وخطوات الاستعادة. يتم توفير أوامر Docker للنشر؛ ويحدد سجل التحقق الحالي البيئات التي تم اختبارها فعليًّا.
