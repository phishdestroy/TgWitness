# จากบันทึก Telegram สู่คดีที่ชัดเจน

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/

ทำงานกับข้อความที่บันทึกไว้และการเปลี่ยนแปลง เชื่อมโยงผลการค้นพบของคุณกับแหล่งที่มา และเตรียมไฟล์ที่ลงนามไว้เพื่อตรวจสอบ

## สำรวจขั้นตอนการทำงาน

คู่มือที่มีภาพประกอบ

[### Case Board รักษาความเชื่อมโยงระหว่างข้อสังเกต คำพูดต้นฉบับ และบันทึกของทีม](https://phishdestroy.github.io/TgWitness/th/docs/case-board/) [### Report Studio เลือกเนื้อหาและหนึ่งในแปดแบบรายงาน](https://phishdestroy.github.io/TgWitness/th/docs/reports/) [### แชร์ข้อความ เตรียมส่วนคัดลอกที่ลงนามแล้ว พร้อมด้วยข้อมูลที่ผู้รับต้องการ](https://phishdestroy.github.io/TgWitness/th/docs/handover/) [### กลุ่มบัญชี ตรวจสอบบัญชีร่วมกันและรักษาพื้นที่ทำงานให้แยกกัน](https://phishdestroy.github.io/TgWitness/th/docs/groups/)

[## โหมด, สถานการณ์ และระดับหลักฐาน ขอบเขตการเก็บรวบรวมข้อมูล, ขอบเขตเหตุการณ์, แปดกลไกการตรวจสอบ และหกสถานการณ์การสอบสวนสมมติ](https://phishdestroy.github.io/TgWitness/th/guides/modes.html)

## ข้อความแรกที่บันทึกได้

[### เริ่มใช้งานได้ภายในไม่กี่นาที ลองใช้ TgWitness ด้วยข้อมูลตัวอย่าง แล้วเปิดพื้นที่ทำงานการสังเกต Telegram ของคุณเองบน Windows, Linux หรือ macOS](https://phishdestroy.github.io/TgWitness/th/docs/start/)[### บัญชีเฉพาะ เตรียมบัญชี Telegram แยกต่างหากไว้สำหรับการเก็บรวบรวมข้อมูล](https://phishdestroy.github.io/TgWitness/th/docs/dedicated-account/)[### เชื่อมต่อบัญชี เชื่อมต่อ Telegram ผ่านรหัส QR, หมายเลขโทรศัพท์ หรือการนำเข้าเซสชัน เลือกแหล่งข้อมูลและตรวจสอบว่าข้อความใหม่ถูกส่งถึงบันทึกของคุณแล้ว](https://phishdestroy.github.io/TgWitness/th/docs/accounts/)[### เลือกพร็อกซี รักษาเส้นทาง MTProxy อัตโนมัติ หรือใช้พร็อกซีของคุณเอง เลือกโหมด IP กฎสำรอง และเส้นทางสำหรับคำขอจากภายนอก](https://phishdestroy.github.io/TgWitness/th/docs/proxies/)[### ส่งออกและตรวจสอบ ส่งออกประวัติ Telegram ที่บันทึกไว้ ตรวจสอบลายเซ็น และเปรียบเทียบบันทึกกับจุดตรวจสอบที่เก็บรักษาโดยพยานอิสระ](https://phishdestroy.github.io/TgWitness/th/docs/exports/)[### การบันทึกด้วย GitHub Actions ส่งออกการสนทนา Telegram หนึ่งครั้งบน GitHub Runner ชั่วคราว](https://phishdestroy.github.io/TgWitness/th/docs/capture/)

## จากบันทึกที่เก็บไว้สู่รายงานที่แบ่งปัน

[### สืบสวนในทุกการสนทนา ดำเนินการสืบสวน Telegram แบบ end-to-end ในช่องต่างๆ กลุ่ม การสนทนาส่วนตัว และบอต: การบันทึกข้อมูลบัญชีทั้งหมด ประวัติการสนทนา ผู้ใช้ ลิงก์ ไฟล์ ไทม์ไลน์ และหลักฐานที่ได้รับการยืนยัน](https://phishdestroy.github.io/TgWitness/th/docs/cases/)[### สร้าง Case Board รวบรวมข้อมูลการสังเกตที่บันทึกไว้ จุดสำคัญที่ระบุไว้อย่างแม่นยำ และส่วนการดำเนินการบนบอร์ดส่วนตัว หารือกับทีมของคุณ และนำเสนอชุดข้อมูลที่รวบรวมได้](https://phishdestroy.github.io/TgWitness/th/docs/case-board/)[### ออกแบบรายงาน เลือกข้อมูลรายงาน หนึ่งในแปดรูปแบบการออกแบบ และเนื้อหา จากนั้นดูตัวอย่างและส่งออกเป็น HTML PDF ที่มีลายเซ็น หรือชุดหลักฐานครบถ้วน](https://phishdestroy.github.io/TgWitness/th/docs/reports/)[### เตรียมสำเนาเพื่อแบ่งปัน เลือกบันทึกและสนามข้อมูลที่ผู้รับสามารถรับได้ ตรวจสอบสำเนาที่เสร็จสิ้น และยืนยันความถูกต้องของแมนิเฟสต์ที่ลงนามและขอบเขตของบันทึกต้นทาง](https://phishdestroy.github.io/TgWitness/th/docs/handover/)[### จัดการกลุ่มบัญชี เปรียบเทียบพื้นที่ทำงานของกลุ่ม ค้นหาแหล่งข้อมูล ตรวจสอบช่วงเวลาการสังเกตการณ์ และใช้การตั้งค่าที่แบ่งปันพร้อมข้อยกเว้นตามบัญชี](https://phishdestroy.github.io/TgWitness/th/docs/groups/)

## ลองใช้เพื่อเรียนรู้

[### ดูวิธีการทำงานของหลักฐาน ติดตามข้อความตั้งแต่การจับข้อมูลจนถึงจุดตรวจสอบ (checkpoint) แก้ไขบันทึกตัวอย่าง คำนวณใหม่โซ่ SHA-256 ของมัน และดูว่าจุดตรวจสอบที่เก็บไว้จะตรวจพบอะไร](https://phishdestroy.github.io/TgWitness/th/docs/concepts/)[### รักษาความปลอดภัย ดูว่าเซสชัน กุญแจ และหลักฐานถูกเก็บไว้ที่ใด ข้อมูลใดถูกส่งออกจากเครื่องของคุณ มาตรการป้องกันครอบคลุมอะไรบ้าง และวิธีเสริมความปลอดภัยให้ระบบติดตั้ง](https://phishdestroy.github.io/TgWitness/th/docs/security/)[### ตั้งค่าบอทพยาน เผยแพร่จุดตรวจสอบของบันทึกที่ลงนามไปยังช่อง Telegram ของคุณ โดยใช้พยานแยกต่างหาก พร้อมด้วยกุญแจเฉพาะและสิทธิ์การเข้าถึงแบบอ่านอย่างเดียวสำหรับผู้รวบรวมข้อมูล](https://phishdestroy.github.io/TgWitness/th/docs/witness/)

## เพิ่มเฉพาะสิ่งที่จำเป็นเท่านั้น

[### จัดการกับคลังข้อมูล โหลดประวัติ, ค้นหาบันทึกที่เก็บไว้, ตรวจสอบแหล่งข้อมูล AI และเชื่อมต่อเครื่องมือของคุณ](https://phishdestroy.github.io/TgWitness/th/docs/archive/)[### แบ่งปันกรณีศึกษา ให้ผู้ตรวจสอบและนักวิเคราะห์สามารถเข้าถึงบัญชีและบทสนทนาที่เลือกไว้ได้ โดยมีการกำหนดสิทธิ์การเข้าถึงแยกกัน จำกัดจำนวนเซสชัน และโทเค็นที่สามารถเพิกถอนได้](https://phishdestroy.github.io/TgWitness/th/docs/access/)[### ให้ระบบทำงานต่อไป ติดตั้ง TgWitness บนเซิร์ฟเวอร์ที่มีพื้นที่จัดเก็บข้อมูลแบบถาวร (persistent storage), การเข้าถึงผ่านแผงควบคุมส่วนตัว (private panel access), การสำรองข้อมูล (backups) และการตรวจสอบหลังการรีสตาร์ท (checks after a restart).](https://phishdestroy.github.io/TgWitness/th/docs/server/)[### ค้นหาว่าเกิดข้อผิดพลาดอะไร ตรวจสอบการเข้าถึงแผงควบคุม การเชื่อมต่อ Telegram ข้อความที่หายไป FloodWait และสถานะของ witness โดยใช้สัญญาณที่เหมาะสมสำหรับแต่ละปัญหา](https://phishdestroy.github.io/TgWitness/th/docs/troubleshooting/)
