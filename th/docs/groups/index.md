# จัดการกลุ่มบัญชี

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/groups/

จัดการบัญชีการเก็บรวบรวมหลายบัญชีพร้อมกัน โดยรักษาให้บันทึกและตัวตนผู้ลงนามของแต่ละบัญชีเป็นอิสระจากกัน

กลุ่มบัญชีจะรวมสถานะการเชื่อมต่อ การควบคุมการสังเกตการณ์ การตั้งค่าที่ใช้ร่วมกัน และการส่งออกข้อมูลไว้ในหน้าจอทำงานเดียว ซึ่งมีประโยชน์เมื่อมีหลายบัญชีที่เกี่ยวข้องกับการสอบสวนเดียวกัน หรือต้องการการตั้งค่าการทำงานที่สอดคล้องกัน

## เปิดหน้าสรุปกลุ่ม

ในส่วน **Accounts (**บัญชี), เปิดกลุ่มนั้น แต่ละบัญชีจะแสดงสถานะการสังเกต, เส้นทางการเชื่อมต่อ, ค่าความล่าช้าของเส้นทางที่วัดได้ล่าสุดเมื่อการตรวจสอบครั้งล่าสุดสำเร็จ, และข้อความที่บันทึกไว้ล่าสุด มีลิงก์ **"ต้องการความสนใจ" (Needs attention**) ที่ชี้ไปยังบัญชีที่จำเป็นต้องดำเนินการ; **ปุ่ม "Fix" (แก้ไข)** จะเปิดพื้นที่ทำงานและส่วนควบคุมที่เกี่ยวข้อง

**ปุ่ม “เริ่มทั้งหมด”** และ **“หยุดทั้งหมด”** จะทำงานกับบัญชีที่ตรงตามเงื่อนไขหลังจากได้รับการยืนยัน **การตั้งค่ากลุ่มจะแชร์**การตั้งค่าที่เลือกไว้ ส่วนบัญชีที่มีค่าของตัวเองจะเก็บค่าเดิมไว้จนกว่าคุณจะเลือกเปลี่ยนค่าใหม่

### ตรวจสอบการเปลี่ยนแปลงเส้นทางในกลุ่ม

ตัวอย่างสังเคราะห์ · การตรวจสอบและผลลัพธ์เพื่อแสดงตัวอย่าง

1. **เลือก.** เลือกกลุ่มและตรวจสอบบัญชีใดที่จะมีการเปลี่ยนแปลง
2. **เตรียมตัวไว้.** รักษาเส้นทางเฉพาะของบัญชีเมื่อจำเป็นต้องแยกไว้ต่างหาก
3. **ตรวจสอบ.** ทดสอบการเชื่อมต่อที่เสนอและตรวจสอบผลการวัด
4. **ดำเนินการแปล** ตรวจสอบอีกครั้งก่อนบันทึก และตรวจสอบผลลัพธ์สำหรับแต่ละบัญชี

#### ทีม Case

Channel collector · Group collector · Reference account

3 พื้นที่ทำงานแยกกัน

#### ส่วนที่ได้รับการตรวจสอบ

2 บัญชีใช้เส้นทางที่เสนอ

บัญชีอ้างอิงมีเส้นทางของตัวเอง

#### การตรวจสอบก่อนดำเนินการ

Channel collector: เวลาส่งข้อมูล Telegram 84 ms

Group collector: Telegram transport 91 ms

ตัวเลขเหล่านี้เป็นตัวเลขสมมติที่ใช้ในตัวอย่าง

#### ผลลัพธ์ของแอปพลิเคชัน

Channel collector: การบันทึกได้ดำเนินการเรียบร้อยแล้ว การสังเกตการณ์ได้กลับมาดำเนินการต่อ

Group collector: การตรวจสอบซ้ำล้มเหลว, การตั้งค่าเดิมถูกคืนค่า

บัญชีอ้างอิง: เก็บเส้นทางเดิมไว้

## เปลี่ยนขั้นตอนโดยเพิ่มขั้นตอนการตรวจสอบ

1. เลือก "**เปลี่ยนเส้นทางกลุ่ม**" (**Change the group route**) แล้วเลือกประเภทการเชื่อมต่อและตั้งค่า
2. เลือก**ตัวเลือก "Review**" (ตรวจสอบ). ตรวจสอบบัญชีที่แสดงในรายการและการแทนที่เส้นทางของแต่ละบัญชี
3. เลือก "**เตรียมและตรวจสอบ**" (**Prepare and check**) การตรวจสอบนี้ใช้ช่องทางส่งข้อมูล Telegram ที่ใหม่; เส้นทาง HTTP ที่ได้รับการสนับสนุนจะรายงานผลการตรวจสอบทางออก HTTPS ของตนเองด้วย
4. เลือก "**Apply checked connection"** และตรวจสอบผลลัพธ์ของแต่ละบัญชี การสังเกตการณ์ที่ดำเนินการไว้ก่อนหน้านี้จะต่อต่อเมื่อการประยุกต์ใช้งานสำเร็จ ส่วนบัญชีที่อยู่ในสถานะไม่ใช้งานจะยังคงไม่ใช้งานต่อไป

Latency อธิบายการตั้งค่าการเชื่อมต่อ Telegram ที่วัดได้ การตรวจสอบ IP ปลายทาง อธิบายเส้นทางนั้น ณ เวลาตรวจสอบที่บันทึกไว้ การอนุญาตบัญชีและสถานะการสังเกตมีตัวชี้วัดเฉพาะของตนเอง; การเปลี่ยนกลุ่มอาจให้ผลลัพธ์ที่แตกต่างกันสำหรับแต่ละบัญชี

## ใช้สิทธิ์การเข้าถึงที่ทับซ้อน

**การสนทนาที่หลายบัญชีสามารถดูได้**จะแสดงแหล่งข้อมูลที่แชร์และขอบเขตการสังเกตพื้นที่ทำงานที่มีอยู่ ช่องและกลุ่มใหญ่ที่ตรงตามเงื่อนไขสามารถใช้ตัวเลือก **“ส่งออกด้วย … บัญชี”** เพื่อแบ่งการเก็บประวัติการสนทนาหนึ่งครั้ง การสนทนาส่วนตัวและกลุ่มทั่วไปจะยังคงอยู่กับบัญชีต้นทาง เนื่องจากจำนวนข้อความของพวกมันเป็นส่วนหนึ่งของประวัติบัญชีนั้น

## ส่งออกกลุ่มเป็นแพ็กเกจ

**กลุ่มส่งออกจะสร้าง**ไฟล์ ZIP หนึ่งไฟล์ ซึ่งประกอบด้วยไฟล์ส่งออกที่ลงนามของแต่ละบัญชี และรายชื่อไฟล์เหล่านั้นที่ลงนามแล้ว ตัวตนและลายนิ้วมือของพื้นที่ทำงานต้นฉบับยังคงมีอยู่เพื่อตรวจสอบ สร้างเรื่องราวข้ามบัญชีโดยใช้ข้อมูลอ้างอิงเหล่านั้น; ส่วนไทม์ไลน์ที่รวมเป็นหนึ่งเดียวจะยังคงถูกจัดเรียงแยกต่างหาก
