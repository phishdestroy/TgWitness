# 몇 분 만에 시작하세요

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/start/

먼저 데모를 둘러본 다음, 귀하의 계정을 연결하십시오.

## 계정 없이 둘러보기

프로젝트를 받고, **Python 3.11 이상**을 준비하고, 데모를 실행합니다. 나머지는 런처가 설정합니다.

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### Windows

```
.\scripts\Demo.cmd
```

### Linux / macOS

```
sh start.sh --demo
```

지어낸 메시지가 있는 작업 공간이 브라우저에서 열립니다. 채팅을 열고, 편집을 비교하고, 내보내기를 살펴보십시오. 텔레그램은 관여하지 않습니다.

![TgWitness 대화 화면 및 예시 메시지](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

작업 공간 예시입니다. 실제 저널은 별도로 생성됩니다.

## 나만의 작업 공간 만들기

데모를 닫은 다음:

### Windows

```
.\Start.cmd
```

### Linux / macOS

```
sh start.sh
```

런처가 보여 주는 주소를 열고, 런처가 알려 주는 파일의 **패널 액세스 토큰**을 붙여 넣습니다. 이것은 TgWitness용이며 텔레그램용이 아닙니다.

## 첫 번째 메시지를 캡처하세요

1. [전용 텔레그램 계정을 연결하세요.](https://phishdestroy.github.io/TgWitness/ko/docs/accounts/)
2. 그룹이나 채널을 고르고 관찰을 시작합니다.
3. 테스트 그룹에 메시지를 보내고 저널에 나타나는지 지켜봅니다.

서버 설치를 위해서는 [‘Keep it running’을](https://phishdestroy.github.io/TgWitness/ko/docs/server/) 따르십시오.
