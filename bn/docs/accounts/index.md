# একটি অ্যাকাউন্ট সংযুক্ত করুন

Canonical page: https://phishdestroy.github.io/TgWitness/bn/docs/accounts/

একটি ওয়ার্কস্পেস = একটি অ্যাকাউন্ট, তার জার্নাল ও তার কী।

## কিভাবে সাইন ইন করবেন তা নির্বাচন করুন

**অ্যাকাউন্ট** → ওয়ার্কস্পেস যোগ করুন → সংযোগ সেটিংস। এর জন্য আলাদা অ্যাকাউন্ট ব্যবহার করুন।

- **QR কোড:** Telegram-এর ডিভাইস স্ক্রিন থেকে স্ক্যান করে নিশ্চিত করুন।
- **ফোন নম্বর:** নম্বর, কোড, তারপর 2FA পাসওয়ার্ড থাকলে।
- **সেশন আমদানি:** আপনার নিজের সেশন ফাইল বা Telegram Desktop ডেটা।

বিল্ট-ইন API প্রোফাইল বা নিজের API ID ও hash ব্যবহার করুন। এটি শুধু অ্যাপ শনাক্ত করে, আপনাকে লগইন করায় না বা কিছু লুকায় না।

**প্রথমে কি একটি প্রক্সি দরকার?**

আপনি সাইন ইন করার আগে [সংযোগের পথ বেছে নিতে এবং পরীক্ষা করতে](https://phishdestroy.github.io/TgWitness/bn/docs/proxies/) পারেন। প্রতিটি অ্যাকাউন্টের নিজস্ব পথ রয়েছে।

## কি পর্যবেক্ষণ করবেন তা নির্বাচন করুন

1. দরকারি চ্যাট, গ্রুপ বা চ্যানেল বেছে নিন।
2. সংগ্রহ সেটিংস দেখুন, মিডিয়াসহ।
3. চালু করুন এবং সংযোগ ও সাম্প্রতিক কার্যকলাপ দেখুন।

অ্যাকাউন্টের অ্যাক্সেস থাকতে হবে। অ্যাডমিন ও সদস্যরা আলাদা জিনিস দেখেন, জার্নাল দেখায় এই অ্যাকাউন্ট কী পেয়েছে।

পুরো অ্যাকাউন্ট? **উৎস → পর্যবেক্ষণ পরিসর → তদন্ত মোড**, যাচাই করুন, **পরিসর সংরক্ষণ করুন**। সম্পূর্ণ নির্দেশিকা: [পুরো অ্যাকাউন্টের তদন্ত](https://phishdestroy.github.io/TgWitness/bn/docs/cases/)।

## পুরো পথটি পরীক্ষা করুন

আপনার টেস্ট গ্রুপে অন্য অ্যাকাউন্ট থেকে বার্তা পাঠান, সম্পাদনা করুন, মুছে ফেলুন। তিনটিই জার্নালে দেখা উচিত। তারপর [এক্সপোর্ট ও যাচাই করুন](https://phishdestroy.github.io/TgWitness/bn/docs/exports/)।

"সংযুক্ত" মানে সংযোগ কাজ করছে। ধরা পড়া টেস্ট বার্তা মানে ইভেন্ট সত্যিই পৌঁছাচ্ছে।

## আরেকটি অ্যাকাউন্ট যোগ করুন

**অ্যাকাউন্ট**-এ নতুন ওয়ার্কস্পেস, একই ধাপ। প্রতিটি অ্যাকাউন্টের কী ফিঙ্গারপ্রিন্ট লিখে রাখুন যাতে পরে এক্সপোর্ট আলাদা করতে পারেন।
