管理一組帳戶

可同時管理多個收集帳戶，同時確保每個帳戶的記錄與簽署身分保持獨立。

「帳戶群組」將連線狀態、監控設定、共用設定及匯出功能整合至單一工作介面中。當多個帳戶涉及同一項調查，或需要一致的操作設定時，此功能便十分實用。

開啟群組概覽

在「帳戶」中，開啟該群組。每個帳戶會顯示其監測狀態、連線路徑、最近一次檢查成功時測得的路徑延遲，以及最後儲存的訊息。需注意連結會指向需要處理的帳戶；點擊「修復」可開啟相關工作區與控制介面。

「全部開始」與「全部暫停」功能將在確認後對符合條件的帳戶生效。「群組設定」可共用選定的設定；具有獨立設定值的帳戶將保留其設定，直至您選擇覆寫為止。

檢視群組內的路徑變更

合成範例 · 說明性檢查與結果

  1. 選取。選擇群組並檢視哪些帳戶將會變更。
  2. 準備。當需保持獨立時，請保留該帳戶的專屬路徑。
  3. 檢查。測試建議的連線並檢視測量結果。
  4. 請進行翻譯。儲存前請重新檢查，並審閱每個帳戶的翻譯結果。

準備檢查

頻道收集器：Telegram 傳輸時間 84 毫秒

群組收集器：Telegram 傳輸時間 91 毫秒

這些數字僅為範例中的虛構數值。

應用結果

頻道收集器：已路由並保存，觀察已恢復。

群組收集器：重新檢查失敗，已還原先前設定。

參考帳戶：保留原有路徑。

在流程中新增「審查」步驟

  1. 請選擇「變更群組路由」，然後選擇連線類型及設定。
  2. 選擇「審查」選項。審查清單中的帳戶及其各自的路由覆寫設定。
  3. 選擇「準備」並執行檢查。此檢查會使用全新的 Telegram 傳輸通道；受支援的 HTTP 路由亦會回報其 HTTPS 出口檢查結果。
  4. 選擇「套用已選中的連線」，並檢查每個帳戶的結果。先前正在執行的監測將在應用程式成功處繼續進行；閒置帳戶則維持閒置狀態。

延遲（Latency）描述的是測量到的 Telegram 連線建立狀況。出口 IP 檢查則描述在記錄檢查時間點的該條路徑狀況。帳戶授權與監測狀態各有其指標；群組變更可能因帳戶而異，產生不同的結果。

使用重疊存取權限

「多個帳戶可見的聊天室」功能會顯示共享來源及可用的工作區觀察範圍。符合資格的頻道和超級群組可使用「與…帳戶匯出」功能，將單一聊天室的歷史紀錄取得作業進行分攤。私人聊天室和一般群組則保留在起始帳戶下，因為其訊息編號屬於該帳戶的歷史紀錄。

將群組匯出為套件

匯出群組會建立一個 ZIP 檔案，其中包含每個帳戶的簽名匯出檔以及這些檔案的簽名清單。原始工作區的身分識別資訊與指紋仍可供驗證。請利用這些參考資料建構跨帳戶的敘事脈絡；單一的合併時間軸仍需另行彙整。

請繼續進行報告設計、工作區內的「案件看板」，或執行匯出驗證。
