# چند منٹ میں شروع کریں

Canonical page: https://phishdestroy.github.io/TgWitness/ur/docs/start/

سب سے پہلے ایک عملی مثال دیکھیں۔ پھر اپنا اکاؤنٹ منسلک کریں۔

## اکاؤنٹ کے بغیر دیکھیں

پروجیکٹ کو ڈاؤن لوڈ یا کلون کریں، **Python 3.11 یا اس کے بعد کا ورژن** انسٹال کریں، اور ڈیمو چلائیں۔ لانچر ایک مقامی ماحول بناتا ہے اور منسلک انحصارات کو انسٹال کرتا ہے۔

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### ونڈوز

```
.\scripts\Demo.cmd
```

### لینکس / میک او ایس

```
sh start.sh --demo
```

براؤزر فرضی پیغامات کے ساتھ ایک ورک اسپیس کھولتا ہے۔ ایک گفتگو کھولیں، ترمیم کا موازنہ کریں اور ایک ایکسپورٹ کا معائنہ کریں۔ ڈیمو موڈ ٹیلیگرام سے منسلک نہیں ہوتا۔

![TgWitness گفتگو کا منظر نمونہ پیغامات کے ساتھ](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

ایک نمونہ ورک اسپیس۔ آپ کا اپنا جریدہ الگ سے شروع ہوتا ہے۔

## اپنا ذاتی ورک اسپیس شروع کریں

ڈیمو کے عمل کو بند کریں، پھر معمول کے لانچر کا استعمال کریں:

### ونڈوز

```
.\Start.cmd
```

### لینکس / میک او ایس

```
sh start.sh
```

لانچر کے ذریعے دکھایا گیا مقامی پتہ کھولیں۔ اگر پوچھا جائے تو ٹرمینل میں نامزد مقامی فائل سے **پینل ایکسیس ٹوکن** درج کریں۔ یہ TgWitness کو انلاک کرتا ہے؛ یہ ٹیلیگرام سائن ان سے الگ ہے۔

## اپنا پہلا پیغام محفوظ کریں

1. [ایک مخصوص ٹیلیگرام اکاؤنٹ منسلک کریں۔](https://phishdestroy.github.io/TgWitness/ur/docs/accounts/)
2. وہ گروپ یا چینل منتخب کریں جس تک اکاؤنٹ رسائی رکھتا ہو، پھر مشاہدہ شروع کریں۔
3. ایک ٹیسٹ گروپ جس پر آپ کا کنٹرول ہے، میں ایک نیا پیغام بھیجیں اور چیک کریں کہ یہ جرنل میں ظاہر ہوتا ہے۔

سرور انسٹالیشن کے لیے، [اسے چلتا رکھ](https://phishdestroy.github.io/TgWitness/ur/docs/server/)یں۔
