01

## آپ کو اپنا مرکزی اکاؤنٹ استعمال نہیں کرنا چاہیے

یہ درست معلومات ہیں۔ ہمیں بالکل معلوم ہے کہ ان مسائل کے جال کہاں ہیں۔

1. ### اپنے ایپ ہیش کے ساتھ، 99% اکاؤنٹس لاگ آؤٹ ہو جاتے ہیں

   ایک ایسے اکاؤنٹ سے my.telegram.org میں لاگ ان کرنا جس تک آپ کی رسائی نہیں ہے تاکہ ایپ ہیش حاصل کیا جا سکے، اور پھر اس ایپ ہیش کے ذریعے کوئی بھی درخواست بھیجنے کا مطلب ہے کہ اکاؤنٹ 99% امکان کے ساتھ لاگ آؤٹ ہو جائے گا۔ آپ خود چیک کر سکتے ہیں۔
2. ### صرف کم اعتماد کی وجہ سے اکاؤنٹس پر پابندی عائد ہونا معمول ہے۔

   اکاؤنٹس صرف اس لیے بلاک کر دیے جاتے ہیں کہ ٹیلیگرام ان پر بھروسہ نہیں کرتا، اور ایسے پابندیاں اکثر ہوتی ہیں۔ آپ یہ بھی چیک کر سکتے ہیں۔ اپنا اکاؤنٹ استعمال کرنا واقعی ایک بے وقوفانہ خیال ہے۔
3. ### کاپی کی گئی سیشن کیز کو منسوخ کیا جا سکتا ہے۔

   ایک ہی وقت میں درآمد شدہ TData/سیشن کلید کو Telegram Desktop اور TgWitness میں چلانے سے `AUTH_KEY_DUPLICATED` متحرک ہو سکتا ہے۔ Telegram اس اجازت نامے کو کالعدم قرار دیتا ہے، لہٰذا دونوں نقول کو نئے لاگ ان کی ضرورت ہوتی ہے۔ ایک مخصوص اکاؤنٹ اس سے نہیں بچاتا۔

   اصلی کلائنٹ کو مکمل طور پر چھوڑ دیں اور اس کے درآمد شدہ سیشن کے استعمال کے دوران اسے بند رکھیں۔ متوازی استعمال کے لیے، TgWitness میں فون یا QR کے ذریعے سائن ان کریں تاکہ ایک الگ اجازت نامہ بنایا جا سکے؛ دیگر الگ اجازت یافتہ کلائنٹس سائن ان رہ سکتے ہیں۔

   [سیشن امپورٹ کی انتباہ پڑھیں](https://phishdestroy.github.io/TgWitness/demo/guide.html?lang=ur#session-warning)

## TgWitness عوامی ایپ ہیش اور ایپ آئی ڈی جوڑوں کے ذریعے کیوں کام کرتا ہے

اسی لیے ہم نے TgWitness کو عوامی ایپ ہیش/ایپ آئی ڈی جوڑوں پر بنایا۔ ہماری منطق کے مطابق ان کے ساتھ پابندیوں کا امکان کم ہوتا ہے: ان جوڑوں کے ذریعے ایک ملین سے زائد ٹیلیگرام اکاؤنٹس رجسٹر کیے جا چکے ہیں، اور بہت سے مختلف پروگرام ان کے ذریعے کام کرتے ہیں۔ ہماری منطق کے مطابق، یہ ذاتی ایپ ہیش کے ساتھ براہِ راست کام کرنے سے بہتر ہے: یہ جوڑے یقینی طور پر پانچ سال سے زیادہ عرصے سے فعال ہیں۔

### آپ کا اپنا نیا API ID/API ہیش جوڑا

my.telegram.org پر اکاؤنٹ سے تخلیق کیا گیا۔

- ان میں سے تقریباً 99% اکاؤنٹس لاگ آؤٹ ہو جاتے ہیں۔
- ایک نیا اطلاق، ایک اکاؤنٹ

### پول سے عوامی API ID/API ہیش جوڑے

وہی API ID/API ہیش جوڑے جو بہت سے پروگرام استعمال کرتے ہیں۔

- ایک ملین سے زائد اکاؤنٹس رجسٹرڈ
- بہت سے مختلف پروگرام
- یہ API جوڑے پانچ سال سے زائد عرصے سے کام کر رہے ہیں۔

### کیوں کوئی بھی ان API جوڑوں کے ذریعے آپ کا کوئی ڈیٹا نہیں دیکھ سکتا

- #### API جوڑا ایک نام ہے، کلید نہیں۔

  جب کوئی پروگرام کنیکٹ ہوتا ہے یا لاگ ان کوڈ کی درخواست کرتا ہے تو ٹیلیگرام API آئی ڈی اور API ہیش طلب کرتا ہے۔ یہ ایپلیکیشن کی شناخت کرتے ہیں اور کسی بھی اکاؤنٹ تک رسائی فراہم نہیں کرتے؛ ٹیلی تھون کی دستاویزات میں ذکر ہے کہ ایک جوڑا کسی بھی فون نمبر کے ساتھ کام کرتا ہے۔
- #### آپ کی سیشن کلید کبھی بھی آپ کے سرور سے باہر نہیں جاتی۔

  سائن ان کرنے سے آپ کے TgWitness اور Telegram کے درمیان ڈفی-ہلمین تبادلے کے ذریعے ایک اجازت نامہ کلید تیار ہوتی ہے؛ خود کلید کبھی بھی بھیجی نہیں جاتی۔ Telegram کی دستاویزات کے مطابق: اجازت کے بعد یہ کلید صارف سے منسلک ہو جاتی ہے، اور اس کلید کے ساتھ کی جانے والی ہر کال اسی صارف کے طور پر چلتی ہے۔ اسی جوڑے والے دیگر پروگراموں کی اپنی الگ کلیدیں ہوتی ہیں اور وہ آپ کی کلید استعمال نہیں کر سکتے۔
- #### ٹریفک آپ کی کلید سے خفیہ کردہ ہے

  ہر درخواست اور جواب سیشن کی اجازت نامہ کی کلید سے خفیہ کیا جاتا ہے، API ہیش سے نہیں۔ API ہیش جاننے سے کچھ بھی ڈی کرپٹ نہیں ہوتا۔
- #### ایک API ID/API ہیش جوڑے کا مالک کچھ بھی نہیں دیکھتا۔

  Telegram کے پاس API ID کے ذریعے اکاؤنٹس، سیشنز یا پیغامات کی فہرست بنانے کا کوئی طریقہ نہیں ہے۔ ایک جوڑے کا مالک صرف my.telegram.org پر اپنی ایپ کی ترتیبات دیکھ سکتا ہے۔
- #### صرف آپ کا اکاؤنٹ ہی دیکھ سکتا ہے کہ یہ کون سی ایپ ہے۔

  سیٹنگز → آپ کے اکاؤنٹ کے ڈیوائسز میں ہر سیشن کا ایپ نام اور API آئی ڈی، ڈیوائس، IP پتہ اور تاریخیں درج ہوتی ہیں۔ یہ فہرست کسی اور کو نہیں ملتی۔

## اضافی اکاؤنٹ بنانے کے طریقے

ایک ٹیلیگرام اکاؤنٹ کو ایک ایسے فون نمبر کی ضرورت ہوتی ہے جو لاگ ان کوڈ وصول کرے۔ منتخب کریں کہ اکاؤنٹ کو کتنی دیر تک فعال رہنا ہے۔

- بہترین انتخاب

  ### پری پیڈ سم یا ای سم

  ********

  یہ کتنی دیر تک برقرار رہتا ہے

  جب تک آپ اسے بھرپور رکھتے ہیں

  ذہن میں رکھیں

  سب سے قابلِ اعتماد: ٹیلیگرام اصل موبائل نمبرز کو بہترین طور پر قبول کرتا ہے۔ جو نمبر آپریٹر واپس لے لیتا ہے وہ کسی اور کو جاتا ہے۔
- ### ورچوئل فون نمبروں والی ایک ایپ

  ********

  یہ کتنی دیر تک برقرار رہتا ہے

  جب تک ایپ فون نمبر کو برقرار رکھتی ہے

  ذہن میں رکھیں

  ٹیلیگرام ورچوئل نمبر دینے سے انکار کر سکتا ہے، کوڈ فراہم نہیں کر سکتا یا نئے اکاؤنٹ کو فوری طور پر محدود کر سکتا ہے؛ کچھ ایپس ایسے نمبرز واپس لے لیتی ہیں جو استعمال نہیں کیے جاتے۔
- ### فون نمبر کرایہ پر لینا

  ********

  یہ کتنی دیر تک برقرار رہتا ہے

  کرایے کی مدت کے لیے

  ذہن میں رکھیں

  جب یہ ختم ہو جاتا ہے، نمبر اگلے صارف کو منتقل ہو جاتا ہے۔
- ### ایک مرتبہ فعال کرنا

  ********

  یہ کتنی دیر تک برقرار رہتا ہے

  صرف ایک لاگ ان کوڈ

  ذہن میں رکھیں

  یہ نمبر فوراً پول میں واپس چلا جاتا ہے، اکثر پچھلے مالکان کی تاریخ کے ساتھ۔ سب سے پہلے کلاؤڈ پاس ورڈ سیٹ کریں۔

جو بھی بعد میں اس نمبر کا مالک ہوگا، وہ لاگ ان کوڈ کی درخواست کر سکتا ہے۔ ایک کلاؤڈ پاس ورڈ (دو مرحلوں کی تصدیق) انہیں سائن ان کرنے سے روکتا ہے؛ اس کے بغیر یہ اکاؤنٹ نمبر کے اگلے مالک کا ہوگا۔

### کرایہ پر لیے گئے +888 نمبر (فرگمنٹ)

کچھ مارکیٹ پلیسز اور خدمات Fragment سے ٹیلیگرام کے سرکاری +888 نمبروں کی عارضی کرایہ پر فراہمی کی پیشکش کرتی ہیں۔

تقریبی قیمت: روزانہ 20 امریکی ڈالر۔

- آپ براہِ راست Telegram Web یا Telegram Desktop میں اکاؤنٹ رجسٹر کر سکتے ہیں۔
- آپ اس نمبر پر اکاؤنٹس حذف کر کے نئے اکاؤنٹس بنا سکتے ہیں۔
- یہ اکاؤنٹس عموماً کم فراڈ مخالف جانچوں کا سامنا کرتے ہیں، لیکن یہ استثنیٰ یا خصوصی مراعات فراہم نہیں کرتے۔

یہ نمبر آپ کا نہیں ہے۔ کرایہ ختم ہونے کے بعد مالک اسے واپس لے سکتا ہے۔ فوری طور پر کلاؤڈ پاس ورڈ سیٹ کریں اور اکاؤنٹ کو طویل مدتی کے طور پر نہ سمجھیں۔

خود +888 کا مالک ہونا یا ایسی پری پیڈ سم استعمال کرنا جس پر آپ کا کنٹرول ہو، زیادہ قابلِ اعتماد ہے۔

- بہت سے اکاؤنٹس بڑے پیمانے پر رجسٹر کیے گئے ہیں (خودکار رجسٹریشن) یا ان کی تاریخ نامعلوم ہے۔
- کچھ بیچنے والوں کے پاس اب بھی بحالی رسائی ہو سکتی ہے۔
- ایسے بازاروں کے اکاؤنٹس بعد میں اکثر پابندی یا محدود کر دیے جاتے ہیں۔
- ایسے مارکیٹ پلیسز سے گریز کریں جو کھلے عام سٹیلرز، فشنگ ٹولز یا واضح طور پر چوری شدہ اکاؤنٹس بیچتے ہوں۔
- ایک اکاؤنٹ خریدنا — چاہے وہ خود بخود رجسٹرڈ ہونے کا اشتہار دیا گیا ہو — ایسے پلیٹ فارمز سے جہاں کھلے عام فشنگ ٹولز، سٹیلرز، چوری شدہ سیشنز یا اکاؤنٹس فروخت کیے جاتے ہیں، نہ صرف ٹیلیگرام کی سروس کی شرائط کی خلاف ورزی ہے بلکہ زیادہ تر ممالک کے قوانین کی بھی خلاف ورزی ہے۔ اس سے بعد میں آپ کا ثبوت باطل ہو سکتا ہے۔ احتیاط سے انتخاب کریں۔

#### اگر آپ اس آپشن کا استعمال کرتے ہیں

1. اکاؤنٹ کو یکبار استعمال کے قابل سمجھیں۔
2. تمام دیگر سیشنز کو ختم کریں، کلاؤڈ پاس ورڈ سیٹ کریں اور بازیابی کے طریقے فوری طور پر تبدیل کریں۔
3. مختلف فراہم کنندگان کے 2–3 اکاؤنٹس یا وہ اکاؤنٹس استعمال کریں جو آپ نے خود رجسٹر کیے ہیں۔

**پریمیئم، حذف کرنا اور سات روزہ تاخیر**

اگر اکاؤنٹ میں پریمیم فعال ہو تو فون نمبر تک رسائی رکھنے والا شخص فوری طور پر اکاؤنٹ حذف نہیں کر سکتا۔ آپ کو اطلاع موصول ہوتی ہے اور حذف ہونے سے پہلے آپ کے پاس سات دن ہوتے ہیں۔

یہ اہم ہے کیونکہ آپ کی تفتیش اس اکاؤنٹ پر منحصر ہے: آپ کے پاس متبادل تیار کرنے کا وقت ہے۔

**نئے اکاؤنٹس اور API کی اسناد**

اگر آپ نے اپنا api_id/api_hash ایک نئے اکاؤنٹ سے حاصل کیا اور استعمال کیا جو آپ نے خود ایس ایم ایس سروس کے ذریعے فراہم کردہ نمبر استعمال کرکے رجسٹر کیا ہے، تو پہلی API درخواست یا سیشن کی اجازت کے وقت اکاؤنٹ لاگ آؤٹ ہو جائے گا۔ تفتیش کی منصوبہ بندی کرتے وقت اس بات کو ذہن میں رکھیں۔

فون نمبر حاصل کرنے سے لے کر پہلی ریکارڈ شدہ چیٹ تک۔

1. ### فون نمبر حاصل کریں

   جب اکاؤنٹ کو طویل عرصے تک فعال رہنا ہو تو پیشگی ادائیگی شدہ سم یا ای سم؛ مختصر کام کے لیے کرایہ پر لینے یا ایک مرتبہ کی ایکٹیویشن۔ خدمات درج ذیل ہیں۔
2. ### اپنے مرکزی اکاؤنٹ کے علاوہ رجسٹر کریں

   اپنے مرکزی اکاؤنٹ کے ساتھ نہیں بلکہ ایک الگ ڈیوائس، ایمولیٹر یا فون پروفائل پر سرکاری ٹیلیگرام ایپ میں رجسٹر کریں۔
3. ### اکاؤنٹ کو کلاؤڈ پاس ورڈ سے محفوظ کریں

   فوری طور پر ایک کلاؤڈ پاس ورڈ اور ایک بحالی ای میل سیٹ کریں جو کہیں اور استعمال نہ ہو۔
4. ### اکاؤنٹ کی پرائیویسی سیٹنگز کو محدود کریں

   فون نمبر: **کوئی نہیں**، مجھے میرے نمبر سے تلاش کریں۔ **میرے رابطے**، آخری بار دیکھا گیا، پروفائل تصاویر اور بایو: **کوئی نہیں** یا **میرے رابطے**؛ رابطوں کی ہم آہنگی بند کریں۔
5. ### اکاؤنٹ کو خود تباہی سے بچائیں

   اکاؤنٹ کو خود تباہی پر سب سے طویل مدت کے لیے سیٹ کریں، تاکہ اگر TgWitness بند ہو جائے تو آپ کا اکاؤنٹ ضائع نہ ہو۔
6. ### اکاؤنٹ کو ایک غیرجانبدار پروفائل دیں

   آپ کے دیگر اکاؤنٹس کا کوئی نام، تصویر، صارف نام یا بایو شامل نہیں، کوئی ذاتی رابطے نہیں۔
7. ### نئے اکاؤنٹ کو گرم ہونے دیں

   ابتدا میں صرف روزانہ چند چیٹس میں شامل ہوں۔ جو نئے اکاؤنٹس جلدی کرتے ہیں، انہیں سب سے پہلے محدود کیا جاتا ہے۔
8. ### بوٹس کے ساتھ کچھ بھی شیئر نہ کریں

   بوٹ کے لیے کبھی بھی "فون نمبر شیئر کریں" یا "مقام شیئر کریں" پر کلک نہ کریں۔ اس ڈیوائس پر VPN یا پروکسی کے ذریعے لنکس اور مینی ایپس کھولیں۔
9. ### اکاؤنٹ کو TgWitness سے منسلک کریں

   اپنے ورک اسپیس میں، **اکاؤنٹ → QR کوڈ** کے ذریعے کنیکٹ کریں، پھر **سورسز → تفتیشی موڈ** دبائیں۔ ایپ وہ جگہ ہے جہاں آپ عمل کرتے ہیں، TgWitness ریکارڈ ہے۔
