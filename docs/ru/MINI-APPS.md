# Мини-приложения

Мини-приложение Telegram — это веб-страница, которую бот открывает внутри клиента: интернет-магазин, получение «бонуса», подключение кошелька. Мошеннические боты используют их для сбора телефонных номеров, семенных фраз и платежей вне чата. TgWitness открывает мини-приложение так же, как это делает клиент Telegram, загружает его один раз в изолированной среде Chromium без графического интерфейса и записывает его действия.

<a id="in-the-panel"></a>
## На панели

Под сообщением на кнопке мини-приложения отображается надпись **Открыть мини-приложение**. В чате в меню **Информация** **→ Мини-приложения** перечислены места, где чат открывает мини-приложения:

- кнопки под сообщениями и кнопки на клавиатуре ответа;
- ссылки `t.me/<bot>/<app>` и `t.me/<bot>?startapp` в сообщениях, объектах и кнопках ссылок;
- в чате с ботом — кнопка меню бота и его основное приложение.

**При нажатии кнопки Открыть** запрашивается подтверждение, после чего:

1. запрашивает у Telegram адрес запуска от имени данного аккаунта, что является действием аккаунта: бот узнает, что данный аккаунт открыл приложение, и видит его имя и ID. В случае кнопки под сообщением бот может отправить одно сообщение в чат от имени аккаунта, пока приложение открыто;
2. один раз загружает адрес в Chromium с экраном телефона через маршрут рабочей области для запросов за пределами Telegram;
3. записывает результат в подписанный журнал и отображает его в разделе **Зарегистрированные открытия**.

Открыть мини-приложение может только главный администратор.

<a id="what-is-recorded"></a>
## Что фиксируется

- каждый запрос с указанием метода, типа, статуса, MIME-типа и размера, а также субъекта и выдающего органа сертификата TLS; хосты, отличные от собственного приложения, перечисляются отдельно;
- адреса WebSocket и до 30 фреймов для каждого;
- каждый вызов, который страница совершает к API Telegram WebApp, например запрос номера телефона, оплата, открытие ссылки или отправка данных боту; запросы, требующие действий от пользователя, помечаются;
- отображавшиеся диалоговые окна (они закрываются), окна, которые приложение пыталось открыть (с указанием их адреса; они не загружаются), запущенные загрузки, формы и поля ввода;
- скриншоты через 2, 8 и 16 секунд после загрузки, а также скриншот всей страницы в том виде, в каком она была после загрузки, и до 25 её скриптов;
- ссылки, домены, кошельки, аккаунты Telegram, адреса электронной почты и номера телефонов, обнаруженные на странице, её трафик и звонки в Telegram; кошельки в скриптах — только при условии, что их контрольная сумма является действительной.

Адрес запуска содержит подписанные данные запуска (`tgWebAppData`), которые в течение некоторого времени служат в качестве логина для входа в приложение. Эти данные удаляются из всего, что записывается: адрес не сохраняет никаких фрагментов, а данные, их хеш и идентификатор запроса заменяются на `[removed]` в запросах, фреймах, вызовах и сохраненных файлах.

Записи журнала:

| Запись | Значение |
|---|---|
| `webapp.launch_requested` | Telegram вернул адрес запуска; действие с аккаунтом |
| `webapp.launch_failed` | Telegram отказался открыть его, при этом в ответе |
| `webapp.file` | один сохраненный файл (`media_sha256`, размер, роль), привязанный к архиву как сохраненные медиафайлы |
| `webapp.captured` | всё перечисленное выше, с указанием количества элементов, выделенных заглавными буквами |
| `webapp.capture_failed` | приложение не удалось загрузить |

Скриншоты отображаются в хронике расследования и его документах, индикаторы — в отчётах в рамках **мини-приложения** «Источник», а архивы доказательств содержат файлы в папке `media/`, проверенные скриптом `verify.py`.

<a id="browser"></a>
## Браузер

TgWitness запускает Chromium через параметр `--remote-debugging-pipe`; дополнительные пакеты Python не требуются. Программа ищет `chromium`, `chromium-browser`, `google-chrome` и Playwright Chromium; чтобы выбрать один из них, задайте переменную `TGWITNESS_CHROMIUM`, указав путь.

Приложение работает в собственном контексте браузера. Каждое устанавливаемое им соединение, включая WebSockets, проходит через шлюз обратной связи, который открывает его по маршруту рабочей области, как и любой другой запрос за пределами Telegram. Собственные фоновые запросы Chromium (вход в систему, обновления компонентов) поступают на второй шлюз, который их отклоняет; хост Google, с которым браузер связывается самостоятельно, а страница никогда не запрашивалась, отображается в списке `browser_connections` вместо подключений приложения. Когда этот маршрут отключен или включен режим «Скрыть IP» без прокси, приложение не запускается. Запросы на адреса внутри локальной сети отклоняются, а WebRTC не может отправлять UDP-пакеты за пределы маршрута.

Chromium работает в своей песочнице. Когда TgWitness запускается с правами root, Chromium не может использовать эту песочницу, поэтому в открытии приложения отказывается, если не установлен параметр ``TGWITNESS_BROWSER_NO_SANDBOX=1``; устанавливайте его только на компьютере, используемом для данной работы.

Без браузера или в системе Windows **приложение Open** по-прежнему запрашивает адрес у Telegram, а затем загружает страницу и до 12 собственных скриптов, анализируя их на наличие адресов и конечных точек WebSocket.

<a id="api"></a>
## API

```sh
curl -sS "http://127.0.0.1:8787/api/webapp?chat_id=-1001234567890&limit=200" \
  -H "Authorization: Bearer $TGWITNESS_TOKEN"
```

Осуществляется чтение только сохраненных записей, связь с кем-либо не устанавливается: `entries` — список кнопок и ссылок, `captures` — записи о запусках, `browser` — информация о возможности использования браузера. Доступ ограничен выбранными чатами, которые видят только свои собственные чаты; запрос `GET /api/webapp/captures/{seq}?chat_id=…` возвращает одну запись о запуске.

```sh
curl -sS -X POST http://127.0.0.1:8787/api/webapp/open \
  -H "Authorization: Bearer $TGWITNESS_TOKEN" -H "Content-Type: application/json" \
  -d '{"chat_id": 5104055776, "entry": {"type": "button", "seq": 1522, "row": 0, "column": 0}}'
```

`entry.type` принимает значения: `button` (с записью клавиатурных нажатий: `seq`, `row` и `column`), `link` (с `url`), `menu` или `main`.

`POST /api/webapp/inspect` с параметрами `{"url": "https://app.example/start", "scripts": 12}` загружает известную вам страницу без обращения к Telegram, выполняет до `scripts` собственных скриптов и записывает данные в `webapp.inspected`.

<a id="limits"></a>
## Ограничения

Одно загрузочное действие в один момент времени с адреса данной рабочей области. Другому посетителю, в другое время или с другого адреса может быть предоставлена другая информация, а приложение может проверять, где оно открыто. Количество запросов ограничено 400, количество вызовов Telegram — 200, а общее время открытия составляет около 75 секунд; количество отклоненных элементов фиксируется. TgWitness не нажимает кнопки внутри приложения и не заполняет его формы.
