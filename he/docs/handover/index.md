# הכן עותק לשיתוף

Canonical page: https://phishdestroy.github.io/TgWitness/he/docs/handover/

יש לשתף את ההערות הרלוונטיות תוך שמירה על סביבת העבודה המקורית ללא שינוי.

העברה היא תמצית נפרדת חתומה. יש לבחור את הצ'אטים והאנשים, לצמצם זהויות או טקסט, ולהחליט אילו קבצים והערות צוות יכללו בעותק של המקבל. המניפסט שלה מתעד את הבחירה ואת מספר הרשומות שלא שונו, שצומצמו או שהושמטו.

## הכן את התמצית עבור הנמען

1. פתחו **את** **'ייצוא' → 'תמצית למסירה**'. ציינו את מטרתה, בחרו את הצ'אטים ואת טווח הזמן ב-UTC (אופציונלי), ולאחר מכן בחרו **'טען את המשתתפים בצ'אטים הנבחרים'** אם אתם זקוקים לשמות הנבדקים.
2. בחרו כיצד לטפל בשאר המשתמשים: שימוש בשמות בדויים, השמטת הודעותיהם או הצגתן כפי שנרשמו. קבעו את טקסט ההודעה והקובצים המצורפים באופן נפרד; ניתן, לפי בחירה, להסוות מספרי טלפון וכתובות דוא"ל.
3. יש לבחור אם לכלול סימניות וחתכים של Case Board, או כרטיסים עם הערות. כינויים של חוקרים יכולים להחליף שמות צוותים בטקסט זה.
4. בחרו ב**"הורדת תמצית המסירה**". פתחו את הדוח שנוצר ואת הרשומות שנבחרו באופן מקומי, אמתו את הארכיון ובדקו את העותק לפני שליחתו.

### עותק מקורי אחד, עותק משותף אחד

דוגמה סינתטית · להמחשה בלבד

1. **בחר.** כלול את צ'אט התיק וזיהוי האדם שעליו עוסק הקטע.
2. **צמצמו.** בחרו כיצד יופיע משתתף אחר בעותק המשותף.
3. **בדקו.** פתחו את הדוח והרשומות שבארכיון שנוצר לפני שליחתו.
4. **שתף.** העבר את העותק המאושר והעבר בנפרד את טביעת האצבע המאושרת שלו.

#### הערה מקורית

נורה · משתמש 71002

"קיבלתי את הקישור המעודכן."

יומן המקור שומר את התצפית שנשמרה זו.

#### עותק לנמען

הצג כפי שנרשם: נורה · משתמש 71002 · "קיבלתי את הקישור המעודכן."

שם בדוי: P01 · "קיבלתי את הקישור המעודכן."

יש להשמיט: הודעתו של משתתף זה לא נכללת בטקסט.

#### בדקו את הקבצים עצמם

קרא את הקובץ report.html ואת הקובץ records.jsonl.

יש לבדוק זהויות, טקסט, קבצים מצורפים והערות צוות אופציונליות.

#### קטע חתום

בחירה + חתימות קובץ + מניפסט חתום

חבילה נפרדת המקושרת לגבולות היומן המקורי שלה

## יש להשתמש בפקדים יחד

| בקרה | השפעה על הטקסט |
| --- | --- |
| אנשים | יש לשמור על זיהוי הנושאים הנבחרים; יש להשתמש בשמות בדויים או להשמיט משתתפים אחרים לפי בחירתכם. |
| טקסט | יש לכלול את כל הטקסט, רק את הטקסט של האנשים הנבחרים ושל חשבון הצופה, או להשמיט את טקסט ההודעה ואת שדות הפרטים המכילים טקסט. |
| קבצים | בחר קבצים של האנשים שנבחרו ושל החשבון הנצפה, את כל קבצי ההודעות שהוצגו, או ללא קבצים כלל. |
| Case Board | אין לבחור בחומרי לוח, סימניות וחתכים, או כרטיסים הכוללים דיון צוותי. |

יש לבדוק טקסט חופשי ותוכן קבצים, כמו גם זהויות: שם בדוי אינו מסיר אוטומטית כל שם המופיע בהודעה או בקובץ מצורף. אם קובץ משומר שנבחר אינו זמין, יש לשחזר אותו או להשמיט במפורש את הקבצים המצורפים לפני יצירת התמצית.

## יש להקפיד על כך שניתן יהיה לאמת את הטקסט באופן עצמאי

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

יש לשמור בנפרד את ארכיון הראיות המקורי החתום ואת נקודות הבקרה. תהליך המסירה מתעד את התצוגה שלו, כך שהמקבל יכול לבדוק את העותק שנמסר מבלי לקבל את סביבת העבודה כולה. ["Report Studio"](https://phishdestroy.github.io/TgWitness/he/docs/reports/) מספק את עיצוב הקריאה; [אימות הייצוא](https://phishdestroy.github.io/TgWitness/he/docs/exports/) מסביר את ההפניות המהימנות.
