# Telegram · 準備一份分享用副本

Canonical page: https://phishdestroy.github.io/TgWitness/zh-Hant/docs/handover/

只分享需要的內容，原始資料維持不變。

移交是一份獨立的簽名擷取：選擇聊天室和人員，隱藏身分或文字，選擇檔案和團隊筆記。清單記錄了保留、裁剪和排除的內容。

## 準備收件者的擷取檔

1. **匯出 → 移交擷取**：寫明目的，選擇聊天室和期間，若需要具名人員則**載入所選聊天室中的人員**。
2. 其他所有人：使用化名、排除，或依紀錄原樣。文字和檔案是分開的開關；電話和電子郵件可以遮蔽。
3. Case Board：不包含、書籤和切片，或附留言的卡片。團隊成員名稱可換成別名。
4. **下載移交摘要**，開啟、驗證，並在傳送前看過一遍。

### 一份原始文件，一份經審核後分享的副本

合成範例 · 僅供說明用途

1. **選取。**請包含案件聊天紀錄，並標明該摘錄所涉及的人物。
2. **最小化。**選擇其他參與者在共享副本中的顯示方式。
3. **檢查。**在傳送前，請開啟生成的壓縮檔中的報告與紀錄。
4. **分享。**請提交經核對的譯稿，並另行提供其可信指紋。

## 請一併使用這些控制項

| 控制 | 對文案的影響 |
| --- | --- |
| 人員 | 選定的人員保留名稱；其他人使用化名或被排除。 |
| 文字 | 全部文字、只有選定人員和您帳戶的文字，或不包含。 |
| 檔案 | 選定人員和您帳戶的檔案、所有顯示的檔案，或不包含。 |
| 案件看板 | 不包含、書籤和切片，或附討論的卡片。 |

也請讀一讀文字和檔案：化名不會移除寫在訊息或附件中的名字。若選定的檔案遺失，請將它還原或排除附件。

## 確保翻譯內容可獨立核對

```
python -m tgwitness.verify handover.zip --fingerprint TRUSTED_PUBLIC_KEY_SHA256
```

原始封存和檢查點請自行保留。接收方不需取得整個工作區就能驗證其副本。設計：[Report studio](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/reports/)。可信參照：[匯出驗證](https://phishdestroy.github.io/TgWitness/zh-Hant/docs/exports/)。
