# कुछ ही मिनटों में शुरू करें

Canonical page: https://phishdestroy.github.io/TgWitness/hi/docs/start/

सबसे पहले, एक कार्यशील उदाहरण देखें। फिर अपना खाता कनेक्ट करें।

## खाते के बिना देखें

परियोजना डाउनलोड या क्लोन करें, **Python 3.11 या बाद का संस्करण** स्थापित करें, और डेमो चलाएँ। लॉन्चर एक स्थानीय वातावरण बनाता है और पिन की गई निर्भरताओं को स्थापित करता है।

```
git clone https://github.com/phishdestroy/TgWitness.git
cd TgWitness
```

### विंडोज

```
.\scripts\Demo.cmd
```

### लिनक्स / मैकओएस

```
sh start.sh --demo
```

ब्राउज़र काल्पनिक संदेशों के साथ एक कार्यक्षेत्र खोलता है। एक बातचीत खोलें, एक संपादन की तुलना करें और एक निर्यात की जाँच करें। डेमो मोड टेलीग्राम से कनेक्ट नहीं होता है।

![TgWitness संवाद दृश्य नमूना संदेशों के साथ](https://phishdestroy.github.io/TgWitness/assets/chats-dark.png)

एक नमूना कार्यक्षेत्र। आपका अपना जर्नल अलग से शुरू होता है।

## अपना स्वयं का कार्यक्षेत्र प्रारंभ करें

डेमो प्रक्रिया बंद करें, फिर सामान्य लॉन्चर का उपयोग करें:

### विंडोज

```
.\Start.cmd
```

### लिनक्स / मैकओएस

```
sh start.sh
```

लॉन्चर द्वारा दिखाए गए स्थानीय पते को खोलें। यदि पूछा जाए, तो टर्मिनल में नामित स्थानीय फ़ाइल से **पैनल एक्सेस टोकन** दर्ज करें। यह TgWitness को अनलॉक करता है; यह टेलीग्राम साइन-इन से अलग है।

## अपना पहला संदेश कैप्चर करें

1. [एक समर्पित टेलीग्राम खाता कनेक्ट करें।](https://phishdestroy.github.io/TgWitness/hi/docs/accounts/)
2. उस समूह या चैनल का चयन करें जिसे खाता एक्सेस कर सकता है, फिर अवलोकन शुरू करें।
3. एक परीक्षण समूह जिसमें आपका नियंत्रण है, में एक नया संदेश भेजें और जाँचें कि वह जर्नल में दिखाई देता है।

सर्वर इंस्टॉलेशन के लिए, [Keep it running](https://phishdestroy.github.io/TgWitness/hi/docs/server/) का पालन करें।
