# 创建案件看板

Canonical page: https://phishdestroy.github.io/TgWitness/zh/docs/case-board/

把保存的消息变成团队一起处理的案件。

书签、精确引文、切片和讨论，每一项都链接到来源。每次更改都是一个签名修订。

## 从消息到案件卡片

1. **调查 → 案件看板**（标准或专家模式）。为案件创建一个集合。
2. 在**日志**或聊天中点击**添加到案板**（或按 **B**）。卡片会进入收件箱，给它起个标题再移动。
3. 在消息中选中文本，**突出显示 → 板**会保存精确引文和版本。写下它为什么重要。
4. 讨论、设置状态，需要时随时跳回来源。**演示**带团队逐项浏览。

### 请点击一个已更改的支付链接

综合示例 · 本地化说明

1. **捕获。**打开已保存的观察记录 #142 及其消息版本。
2. **添加书签。**将引文、来源参考信息和您的问题保存到卡片中。
3. **审核。**添加团队评论并将卡片移至“审核”状态。
4. **演示。**逐步演示采集过程，并打开引用的源上下文。

## 一次性保存一个有用的范围

按住 Shift 点击两条消息进行**中间切片**，使用**按时间切片**，或保存当前日志筛选条件。**显示自书签添加以来的记录**会显示后来进入的内容。

时间切片使用观察时间；消息 ID 切片会跟随这些消息的变化。

## 为每位同事分配相应的角色

**审核员**阅读，**分析师**添加卡片和评论，**操作员**还管理集合和决定。聊天权限同样适用于卡片。

## 将工作成果整理成可交付成果

切片可导出为签名 JSON 或 CSV。报告可以包含书签、切片和评论，在 [Report studio](https://phishdestroy.github.io/TgWitness/zh/docs/reports/) 中设置。对于受限的接收方，请使用[移交](https://phishdestroy.github.io/TgWitness/zh/docs/handover/)。
