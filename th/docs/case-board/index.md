# สร้าง Case Board

Canonical page: https://phishdestroy.github.io/TgWitness/th/docs/case-board/

เปลี่ยนข้อความที่บันทึกไว้ให้เป็นคดีที่ทีมทำงานร่วมกัน

บุ๊กมาร์ก คำพูดที่ตรงตัว ส่วนตัด และการอภิปราย แต่ละอย่างเชื่อมไปยังแหล่งที่มา ทุกการเปลี่ยนแปลงเป็นการแก้ไขที่ลงนาม

## จากข้อความสู่บัตรคดี

1. **การสืบสวน → Case Board** (โหมดมาตรฐานหรือผู้เชี่ยวชาญ) สร้างคอลเลกชันสำหรับคดี
2. ใน **บันทึก** หรือแชท กด **ไปยังบอร์ด** (หรือ **B**) การ์ดจะเข้าไปในกล่องขาเข้า ตั้งชื่อแล้วย้าย
3. เลือกข้อความในแชท **ไฮไลต์ → บอร์ด** เก็บคำพูดที่ตรงตัวและเวอร์ชัน จดว่าทำไมจึงสำคัญ
4. อภิปราย ตั้งสถานะ กลับไปที่แหล่งที่มาเมื่อใดก็ได้ **การนำเสนอ** พาทีมไล่ดูทีละขั้น

### โปรดติดตามลิงก์การชำระเงินที่เปลี่ยนแปลงไปหนึ่งลิงก์

ตัวอย่างสังเคราะห์ · ภาพประกอบท้องถิ่น

1. **บันทึกข้อมูล.** เปิดบันทึกการสังเกต #142 ที่เก็บไว้และเวอร์ชันข้อความของมัน
2. **บุ๊กมาร์ก.** เก็บคำอ้างอิง, แหล่งที่มา และคำถามของคุณไว้บนบัตร
3. **ตรวจสอบ.** เพิ่มความคิดเห็นของทีมและย้ายบัตรไปยังขั้นตอน "ตรวจสอบ"
4. **แสดงผล.** นำผู้ใช้ผ่านขั้นตอนการเก็บรวบรวมข้อมูลและเปิดบริบทของแหล่งข้อมูลที่อ้างอิง

#### บันทึกการสังเกตที่เก็บไว้ #142

“ใช้ลิงก์การชำระเงินใหม่”

แชทการดำเนินงาน · ข้อความที่ 38 · เวลาที่สังเกต 09:12 UTC

#### Card: เปลี่ยนจุดหมายปลายทาง

> ใช้ลิงก์การชำระเงินใหม่

คำถาม: จุดหมายปลายทางใดปรากฏในเวอร์ชันก่อนหน้า?

#### การตรวจสอบโดยทีม

นักวิเคราะห์: เปรียบเทียบกับข้อสังเกต #101.

สถานะ: ทบทวน · เก็บฉบับแก้ไขไว้

#### บริบทของข้อความต้นฉบับ

Card → เวอร์ชันที่บันทึกไว้ → การสังเกตการณ์ก่อนหน้านี้

คำอธิบายประกอบและการสังเกต Telegram ยังคงสามารถระบุแยกกันได้

## บันทึกช่วงที่มีประโยชน์ไว้ครั้งเดียว

Shift-คลิกสองข้อความเพื่อ **ตัดช่วงระหว่าง** ใช้ **ตัดตามเวลา** หรือบันทึกตัวกรองบันทึกปัจจุบัน **แสดงรายการที่เพิ่มหลังบุ๊กมาร์ก** แสดงสิ่งที่เข้ามาภายหลัง

ส่วนตัดตามเวลาใช้เวลาที่สังเกต ส่วนตัดตาม ID ข้อความจะติดตามข้อความเหล่านั้นเมื่อเปลี่ยนแปลง

## กำหนดบทบาทที่เหมาะสมให้แต่ละเพื่อนร่วมงาน

**ผู้ตรวจทาน** อ่าน **นักวิเคราะห์** เพิ่มการ์ดและความคิดเห็น **ผู้ปฏิบัติงาน** จัดการคอลเลกชันและการตัดสินใจด้วย สิทธิ์ของแชทใช้กับการ์ดด้วย

## นำงานไปจัดทำเป็นเอกสารส่งมอบ

ส่วนตัดส่งออกเป็น JSON ที่ลงนามหรือ CSV รายงานใส่บุ๊กมาร์ก ส่วนตัด และความคิดเห็นได้ ตั้งค่าใน [Report studio](https://phishdestroy.github.io/TgWitness/th/docs/reports/) สำหรับผู้รับที่จำกัด ให้ใช้ [การส่งมอบ](https://phishdestroy.github.io/TgWitness/th/docs/handover/)
