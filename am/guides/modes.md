## የምልከታውን ወሰን ይምረጡ

ሦስት ወሰኖች እና የምርመራ ቅድመ ቅንብር። የተገለሉ ቻቶች እና የተመረጡ የምንጭ አይነቶች አሁንም ይከበራሉ።

ነባሪ**የተመረጡ ቻቶች**

የሚመዘግበው

በእጅ የተመረጡ ምንጮች ብቻ።

አዲስ ቻቶች

በራስ-ሰር አይጨመሩም።

መቼ መምረጥ ይገባል

የሚታወቁ ቻናሎች ወይም ቡድኖች። በቻት ብዛት የተረጋገጠ የአቅም ገደብ የለም።

**የማያደርገው** ሌሎች ቻቶችን አያገኝም፤ የቀድሞ ታሪክንም በራስ-ሰር አያመጣም።

የመለያው አቃፊ**የTelegram አቃፊ**

የሚመዘግበው

በአቃፊው ውስጥ የተካተቱ ቻቶች እና ምድቦች፤ የተገለሉት እና ቅንብሩ ከሚያስወግዳቸው የተመዘገቡ ቻቶች በስተቀር።

አዲስ ቻቶች

ከመስፈርቱ ጋር የሚስማሙ ንቁ ቻቶች፤ የአቃፊ ለውጦች በአንድ ሰዓት ውስጥ።

መቼ መምረጥ ይገባል

ተንታኙ ለጉዳዩ የTelegram አቃፊ ሲጠቀም። ስብስቡን በተለየ መለያ ላይ ያረጋግጡ።

**የማያደርገው** የአቃፊውን የሚቀያየሩ ድምፅ-አልባ ወይም የተነበበ ሁኔታዎች አይተገብርም።

ወሰኑን ያረጋግጡ**ሙሉ መለያ**

የሚመዘግበው

በተመረጡ አይነቶች ውስጥ መለያው የሚያያቸው ቻቶች፣ የግል ውይይቶችን እና ቦቶችን ጨምሮ።

አዲስ ቻቶች

የመጀመሪያው ዝማኔ ሲደርስ ይጨመራል።

መቼ መምረጥ ይገባል

ለምልከታ የተለየ መለያ፣ በጉዳዩ ውስጥ የሚሳተፍ መለያን ጨምሮ።

**የማያደርገው** በራሱ ቻቶችን አይቀላቀልም፤ የመዳረሻ ገደቦችንም አያልፍም።

በሙሉ መለያ ላይ የተመሠረተ ቅድመ ቅንብር**የምርመራ ሁነታ**

የሚመዘግበው

ሁሉም የምንጭ አይነቶች፣ የመለያው ድርጊቶች፣ የምንጭ መገለጫዎች እና ከእያንዳንዱ አዲስ ምንጭ የመጨረሻዎቹ 200 የሚታዩ መልዕክቶች።

አዲስ ቻቶች

አዲስ ቻት ወይም ቦት መገለጫ እና የታሪክ ቅጽበታዊ ቅጂ ያገኛል።

መቼ መምረጥ ይገባል

ከፓነሉ ቡድን ሲቀላቀሉ ወይም ከቦት ጋር ሲነጋገሩ። ቅንብሩን ይመልከቱና ያስቀምጡ።

**የማያደርገው** የሁሉንም ነባር ቻቶች ቅጂ አያነሳም፤ በሌላ ደንበኛ የተጫኑ callback አዝራሮችንም አያይም።

እነዚህ ካርዶች ለንፅፅር ብቻ ናቸው። የሰብሳቢውን ወይም የመለያውን ቅንብር አይቀይሩም።

**የማያደርገው** ማንኛውም ሁነታ ሚስጥራዊ ቻቶችን አያነብም፣ ሂደቱ ሲቆም አይመዘግብም፣ በራሱ ምንጮችን አይቀላቀልም፣ ከተጠየቀው ቅጂ ወይም ማውጫ በላይ የቀድሞ ታሪክን አያመጣም።

   **ሦስተኛ ወገን የሚያረጋግጠው** በቅድሚያ በታመነው የሰብሳቢ ቁልፍ የተፈረሙ መዝገቦችን እና ቅደም ተከተላቸውን።

   **የማያደርገው** ከTelegram መምጣትን ወይም ሁሉም እንደደረሰ አያረጋግጥም።

   **የማረጋገጫ ትእዛዝ**

   ```
   python -m tgwitness.verify evidence.zip --fingerprint TRUSTED_SHA256
   ```

3. ### የተቀመጠ ወሰን

4. ### የውጭ ጊዜ

   Evidence mode የcheckpoint SHA-256 ወደ RFC 3161 ባለሥልጣናት (FreeTSA፣ DigiCert) እና ወደ OpenTimestamps ካሌንደሮች ይልካል።

   **ሦስተኛ ወገን የሚያረጋግጠው** የተረጋገጠ የTSA ምላሽ ለባይቶቹ ጊዜ ይመድባል፤ የተረጋገጠ OpenTimestamps ማስረጃ ከBitcoin ጋር ያገናኛቸዋል።

   **የማያደርገው** የተዘጋጀ ጥያቄ ወይም ያልተረጋገጠ የካሌንደር ደረሰኝ እንደተረጋገጠ የጊዜ ማህተም አይቆጠርም።

   **የማረጋገጫ ትእዛዝ**

## የማስረጃ መንገድ ይምረጡ

ልብ ወለድ ሁኔታዎች። ከሚመለከተው ክስተት በፊት ስብስቡን ይጀምሩ፤ ወሰኖችን እና ክፍተቶችን ከይዘቱ ጋር ያስቀምጡ።

### ቻናል የክፍያ መረጃ ይቀይራል

ሁነታ → ክስተቶች

የተመረጡ ቻቶች → መልዕክቶች፣ ማስተካከያዎች፣ ስረዛዎች።

ውጤት

የታዩ የልጥፍ ስሪቶች እና በሃሽ የተለዩ አባሪዎች።

ማረጋገጫ

የተፈረመ ZIP + የተቀመጠ checkpoint + የተረጋገጠ የTSA ምላሽ።

**የማያደርገው** ፈጽሞ ያልተመዘገበ ዋና መልዕክት አይመልስም።

### ከክስተት በኋላ መልዕክቶች ይጠፋሉ

ሁነታ → ክስተቶች

አቃፊ ወይም ሙሉ መለያ → ሁሉም የክስተት ምድቦች።

ውጤት

የተቀመጡ ዋና መልዕክቶች፣ የስረዛ ማሳወቂያዎች እና ክፍተቶችን የሚያሳይ coverage።

ማረጋገጫ

የተፈረመ ZIP + የነጻ ምስክር መዝገብ።

**የማያደርገው** ፈጻሚውን ያልገለጸ የስረዛ ማሳወቂያ ማን እንደሰረዘ አይወስንም።

### የመሸጫ ቦት ምርመራ

ሁነታ → ክስተቶች

የምርመራ ቅድመ ቅንብር → አዝራሮች፣ የአገናኝ ቅድመ እይታ እና በግልጽ ቦቱን ማስጀመር።

ውጤት

የተፈረሙ የግንኙነት ደረሰኞች፣ callback ምላሾች እና የተቀመጡ መገለጫዎች።

ማረጋገጫ

የተፈረመ ZIP፤ ማንኛውም የጉዳይ መረጃ ከZIP ጋር ይረጋገጣል።

**የማያደርገው** የቦት web app አይከፍትም፣ ክፍያ አይፈጽምም፣ የሌላ ደንበኛ callback-ዎችንም አይመዘግብም።

### ተሳታፊ በቻቶች መካከል ስም ይቀይራል

ሁነታ → ክስተቶች

ማንኛውም ወሰን → የታየ የላኪ እና የመገለጫ ሜታዳታ።

ውጤት

በቁጥር ID የተያያዘ የስም እና username ታሪክ፣ «በሌላም ቻት» አገናኞች እና የምርመራ ፍንጮች።

ማረጋገጫ

ከተፈረመ ZIP ጋር የሚረጋገጥ Dossier JSON።

**የማያደርገው** የክፍያ አድራሻ፣ ስልክ የሚመስል ጽሑፍ ወይም username የሰው ማንነት ማረጋገጫ አያደርግም።

### ረጅም ምልከታ ከውጭ ቅጂ ጋር

ሁነታ → ክስተቶች

ማንኛውም ወሰን → Evidence mode እና Object Lock የሚደግፍ S3 ቅጂ።

ውጤት

የተመሰጠረ ቅጂ፣ የተቀመጡ checkpoint-ዎች እና የጊዜ ማህተም ምላሾች።

ማረጋገጫ

በተላከው ቁልፍ ያስመልሱ፤ ዋናውን አገልጋይ ሳይጠቀሙ ያረጋግጡ።

**የማያደርገው** ነጻ ምስክርን ወይም በተለየ የተቀመጠ የመፍቻ ቁልፍን አይተካም።

[ዝርዝሩን ያንብቡ](https://phishdestroy.github.io/TgWitness/docs/reference/investigation/)

## የሚረጋገጥ ጥቅል ያስረክቡ
