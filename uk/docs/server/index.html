Забезпечте його безперебійну роботу

Забезпечте доступність колектора та збереження його даних після перезапуску.

Оберіть спосіб запуску

Для локальної інсталяції скористайтеся запускачем та прикладами служб у папці deploy/. Для Docker встановіть Docker з Compose та запустіть із каталогу проєкту:

docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt

Панель за замовчуванням працює на адресі loopback хоста, порт 8787. Відкрийте її локально або через SSH-тунель. Використовуйте токен із другої команди, щоб розблокувати панель.

Збережіть весь каталог даних

При локальній інсталяції використовується data/live. У Docker використовується постійний том tgwitness-data. Зберігайте журнали, сесії облікових записів, ключі та операційний стан разом. Підписаний експорт є корисним доказом, але не є повною резервною копією інсталяції.

  1. Припиніть збір даних перед тим, як створити повну резервну копію.
  2. Скопіюйте повний каталог приватних даних у захищене сховище поза межами хоста.
  3. Перед тим, як покладатися на резервну копію, протестуйте відновлення в ізольованому середовищі.

Перевірте після перезапуску

Перевірте налаштування робочого простору та ключа, підключення до Telegram, вибрані джерела та функцію фіксації нових повідомлень. Збережений стан MTProto та функція відновлення даних допомагають відновити оновлення, які Telegram ще зберігає. Неможливо відтворити всі оновлення, термін дії яких закінчився, або редагування, видалені до моменту фіксації.

«Працездатність контейнера» означає, що веб-сервер відповідає. Використовуйте контрольне повідомлення та перевірку свідка для оцінки збору даних та їх зовнішньої публікації.

Публікуйте лише те, що ви маєте намір опублікувати

Довідник з розгортання містить приклади використання HTTPS, команди для роботи з постійними томами, а також інструкції щодо оновлення та відновлення. Для розгортання надаються команди Docker; у поточному записі про перевірку вказано середовища, які фактично пройшли тестування.
