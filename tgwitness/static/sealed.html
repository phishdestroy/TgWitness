Choose what to export

The scope and settings are fixed once collection starts. All three modes use the same approved GitHub runner, signed journal and encrypted delivery.

Telegram Takeout

Telegram’s official export mechanism. All accessible cloud chats or selected chats, dates, account data and attachments. Telegram may require export approval or a wait that exceeds this runner’s lifetime.

Regular Telegram API

The same configurable account scope without Takeout initialization. Available API methods and account data differ, Telegram rate limits still apply. This mode is never substituted for Takeout automatically.

Chat event journal

History and changes observed in one chat through the regular API. Attachment rules and avatars are configurable, account categories, date filters and Desktop views do not apply.

File types, size limits and overrides

Hashes identify byte ranges of the selected photo or file. They let you compare an existing file later; they do not recreate a missing file. Avatars are a separate download choice.

Assessment details


Takeout can require confirmation in an established Telegram session, including after phone, QR or two-step login. Telegram sets the wait, which may exceed this runner’s maximum of 120 minutes including login and approval. A new runner creates a new login and may need approval again, cross-run resume is unavailable. A persistent local export can resume the same session but does not carry GitHub attestation.
