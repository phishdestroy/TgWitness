01

কেন আপনার প্রধান অ্যাকাউন্ট নয়

এটি সঠিক তথ্য। আমরা ঠিক জানি এই সমস্যাগুলির ফাঁদ কোথায় রয়েছে।

  1. আপনার নিজস্ব অ্যাপ হ্যাশ: 99% লগ আউট

    যেকোনো অ্যাকাউন্ট থেকে my.telegram.org-এ লগইন করে অ্যাপ হ্যাশ সংগ্রহ করা, এবং তারপর সেই অ্যাপ হ্যাশের মাধ্যমে যেকোনো অনুরোধ করার ফলে অ্যাকাউন্টটি ৯৯% সম্ভাবনায় লগআউট হয়ে যাবে। আপনি এটি যাচাই করতে পারেন।

  2. নিম্ন বিশ্বাসের কারণে নিষেধাজ্ঞা প্রায়ই ঘটে

    অ্যাকাউন্টগুলো শুধুমাত্র টেলিগ্রাম তাদের বিশ্বাস না করার কারণে নিষিদ্ধ করা হয়, এবং এই ধরনের নিষেধাজ্ঞা প্রায়ই ঘটে। আপনি এটিও যাচাই করতে পারেন। আপনার নিজস্ব অ্যাকাউন্ট ব্যবহার করা সত্যিই বোকামি।

  3. কপি করা সেশন কী বাতিল করা যেতে পারে

    একই সময়ে Telegram Desktop এবং TgWitness-এ আমদানি করা TData/session কী চালানো AUTH_KEY_DUPLICATED ট্রিগার করতে পারে। Telegram সেই অনুমোদন বাতিল করে, তাই উভয় অনুলিপিতে নতুন লগইন প্রয়োজন। একটি নিবেদিত অ্যাকাউন্ট এটি প্রতিরোধ করতে পারে না।

    মূল ক্লায়েন্টটি সম্পূর্ণরূপে ছেড়ে দিন এবং এর আমদানি করা সেশন ব্যবহার করার সময় এটি বন্ধ রাখুন। সমান্তরাল ব্যবহারের জন্য, ফোন বা QR দিয়ে TgWitness-এ সাইন ইন করে একটি পৃথক অনুমোদন তৈরি করুন; অন্যান্য পৃথকভাবে অনুমোদিত ক্লায়েন্টগুলো সাইন ইন অবস্থায় থাকতে পারে।

02

কেন TgWitness পাবলিক অ্যাপ হ্যাশ/অ্যাপ আইডি যুগল ব্যবহার করে

এজন্যই আমরা TgWitness তৈরি করেছি পাবলিক অ্যাপ হ্যাশ/অ্যাপ আইডি জোড়ার উপর ভিত্তি করে। আমাদের যুক্তি অনুযায়ী, এগুলোর মাধ্যমে নিষেধাজ্ঞার সম্ভাবনা কম: এই জোড়াগুলোর মাধ্যমে এক মিলিয়নেরও বেশি টেলিগ্রাম অ্যাকাউন্ট নিবন্ধিত হয়েছে, এবং অনেক ভিন্ন প্রোগ্রাম এগুলোর মাধ্যমে কাজ করে। আমাদের যুক্তি অনুযায়ী, ব্যক্তিগত অ্যাপ হ্যাশের সাথে সরাসরি কাজ করার তুলনায় এটি ভালো: এই জোড়াগুলো নিশ্চিতভাবেই ৫ বছরেরও বেশি সময় ধরে সক্রিয় রয়েছে।

আপনার নিজস্ব নতুন জোড়া

my.telegram.org-এ অ্যাকাউন্ট থেকে তৈরি।

  • প্রায় ৯৯% অ্যাকাউন্ট লগ আউট হয়েছে
  • একটি নতুন অ্যাপ্লিকেশন, একটি অ্যাকাউন্ট

পুলের পাবলিক পেয়ার

একই জোড়া অনেক প্রোগ্রাম ব্যবহার করে।

  • এক মিলিয়নেরও বেশি অ্যাকাউন্ট নিবন্ধিত
  • অনেক ভিন্ন প্রোগ্রাম
  • ৫+ বছর ধরে কাজ করছে

এই জোড়ার মাধ্যমে কেন কেউই আপনার কিছুই দেখতে পারে না

  • জোড়াটি একটি নাম, কী নয়

    টেলিগ্রাম একটি প্রোগ্রাম সংযুক্ত হলে এবং লগইন কোড অনুরোধ করলে API আইডি ও API হ্যাশ জিজ্ঞাসা করে। এগুলো অ্যাপ্লিকেশন শনাক্ত করে এবং কোনো অ্যাকাউন্টে প্রবেশাধিকার দেয় না; টেলিথনের ডকুমেন্টেশনে উল্লেখ আছে যে একটি জোড়া যেকোনো ফোন নম্বরের সাথে কাজ করে।

  • আপনার সেশন কী কখনই আপনার সার্ভার ছেড়ে যায় না

    সাইন ইন করার সময় আপনার TgWitness এবং টেলিগ্রামের মধ্যে একটি ডিফি-হেলম্যান বিনিময়ের মাধ্যমে একটি অনুমোদন কী তৈরি হয়; কীটি নিজে কখনো পাঠানো হয় না। টেলিগ্রামের ডকুমেন্টেশন: অনুমোদনের পর কীটি ব্যবহারকারীর সাথে যুক্ত হয়ে যায়, এবং এই কী দিয়ে করা প্রতিটি কল সেই ব্যবহারকারীর অধীনে চলে। একই জোড়া ব্যবহারকারী অন্য প্রোগ্রামগুলোর নিজস্ব কী থাকে এবং তারা আপনার কী ব্যবহার করতে পারে না।

  • ট্র্যাফিক আপনার কী দিয়ে এনক্রিপ্ট করা হয়

    প্রতিটি অনুরোধ এবং উত্তর সেশনের অনুমোদন কী দিয়ে এনক্রিপ্ট করা হয়, API হ্যাশ দিয়ে নয়। API হ্যাশ জানলে কিছুই ডিক্রিপ্ট হয় না।

  • একটি যুগলের মালিক কিছুই দেখতে পান না

    টেলিগ্রামে এমন কোনো পদ্ধতি নেই যা API আইডি অনুযায়ী অ্যাকাউন্ট, সেশন বা বার্তা তালিকাভুক্ত করে। একটি যুগলের মালিক my.telegram.org-এ শুধুমাত্র তার অ্যাপ সেটিংস দেখতে পান।

  • শুধুমাত্র আপনার অ্যাকাউন্টই দেখতে পায় এটি কোন অ্যাপ

    আপনার নিজস্ব অ্যাকাউন্টের সেটিংস → ডিভাইসগুলিতে প্রতিটি সেশনের অ্যাপের নাম, API আইডি, ডিভাইস, IP ঠিকানা এবং তারিখ তালিকাভুক্ত থাকে। এই তালিকা অন্য কেউ পায় না।

যিনি পরবর্তীতে নম্বরটি ধারণ করবেন, তিনি লগইন কোড অনুরোধ করতে পারবেন। একটি ক্লাউড পাসওয়ার্ড (দুই-ধাপ যাচাইকরণ) তাদের সাইন ইন করতে বাধা দেয়; এর ছাড়া অ্যাকাউন্টটি নম্বরের পরবর্তী মালিকের হবে।

  • আপনি সরাসরি Telegram Web বা Telegram Desktop-এ একটি অ্যাকাউন্ট নিবন্ধন করতে পারেন।
  • আপনি নম্বরে অ্যাকাউন্ট মুছে নতুন অ্যাকাউন্ট তৈরি করতে পারেন।
  • এই অ্যাকাউন্টগুলো সাধারণত কম প্রতারণা-বিরোধী যাচাইয়ের সম্মুখীন হয়, তবে এগুলো কোনো ইমিউনিটি বা বিশেষ সুবিধা প্রদান করে না।

এই নম্বরটি আপনার নয়। ভাড়া শেষ হলে মালিক এটি পুনরুদ্ধার করতে পারবেন। অবিলম্বে ক্লাউড পাসওয়ার্ড সেট করুন এবং অ্যাকাউন্টটিকে দীর্ঘমেয়াদী হিসেবে বিবেচনা করবেন না।

নিজে +888 নম্বরটি মালিকানা করা বা আপনার নিয়ন্ত্রণাধীন প্রিপেইড সিম ব্যবহার করাই আরও নির্ভরযোগ্য।

কখনই আপনার প্রধান অ্যাকাউন্ট ব্যবহার করবেন না! এভাবে প্রাপ্ত একটি নিবেদিত অ্যাকাউন্ট আপনার প্রধান টেলিগ্রাম অ্যাকাউন্ট TgWitness-এ যুক্ত করার তুলনায় এখনও বেশি নিরাপদ।

ক্রয়ের আগে সতর্কতা

  • এটি টেলিগ্রামের পরিষেবার শর্তাবলী লঙ্ঘন করে।
  • অনেক অ্যাকাউন্টই গণ-নিবন্ধিত (স্বয়ং-নিবন্ধন) বা অজানা ইতিহাসের।
  • কিছু বিক্রেতার কাছে এখনও পুনরুদ্ধার অ্যাক্সেস থাকতে পারে।
  • এ ধরনের বাজারের অ্যাকাউন্টগুলো পরবর্তীতে প্রায়ই নিষিদ্ধ বা সীমাবদ্ধ করা হয়।
  • স্পষ্টভাবে চোরাই স্টিলার, ফিশিং টুল বা স্পষ্টভাবে চুরি করা অ্যাকাউন্ট বিক্রি করে এমন মার্কেটপ্লেস এড়িয়ে চলুন।
  • ফিশিং টুল, স্টিলার, চুরি করা সেশন বা অ্যাকাউন্ট খোলাখুলি বিক্রি করে এমন প্ল্যাটফর্ম থেকে অ্যাকাউন্ট কেনা— এমনকি 'অটো-রেজ' হিসেবে বিজ্ঞাপিত অ্যাকাউন্টও— কেবল টেলিগ্রামের সেবার শর্তাবলীই লঙ্ঘন করে না, বরং অধিকাংশ দেশের আইনও লঙ্ঘন করে। এর ফলে পরে আপনার প্রমাণ অসিদ্ধ হয়ে যেতে পারে। সাবধানে নির্বাচন করুন।

যদি আপনি এই বিকল্পটি ব্যবহার করেন

  1. অ্যাকাউন্টটিকে এককালীন ব্যবহারের হিসেবে বিবেচনা করুন।
  2. অন্যান্য সমস্ত সেশন বন্ধ করুন, ক্লাউড পাসওয়ার্ড সেট করুন এবং পুনরুদ্ধার পদ্ধতি অবিলম্বে পরিবর্তন করুন।
  3. বিভিন্ন প্রদানকারীর ২–৩টি অ্যাকাউন্ট ব্যবহার করুন অথবা নিজে নিবন্ধিত অ্যাকাউন্টগুলো ব্যবহার করুন।
প্রিমিয়াম, মুছে ফেলা এবং সাত দিনের বিলম্ব

যদি অ্যাকাউন্টে প্রিমিয়াম থাকে, ফোন নম্বরে অ্যাক্সেস থাকা কেউই অ্যাকাউন্টটি সঙ্গে সঙ্গে মুছে ফেলতে পারবে না। আপনি একটি বিজ্ঞপ্তি পাবেন এবং মুছে ফেলার আগে আপনার কাছে সাত দিন সময় থাকবে।

এটি গুরুত্বপূর্ণ কারণ আপনার তদন্তটি ওই অ্যাকাউন্টের উপর নির্ভরশীল: আপনার কাছে বিকল্প প্রস্তুত করার সময় আছে।

নতুন অ্যাকাউন্ট এবং API শংসাপত্র

যদি আপনি SMS সার্ভিস থেকে প্রাপ্ত নম্বর ব্যবহার করে নিজেই নিবন্ধিত একটি নতুন অ্যাকাউন্ট থেকে আপনার নিজস্ব api_id/api_hash সংগ্রহ ও ব্যবহার করেন, তাহলে প্রথম API অনুরোধ বা সেশন অনুমোদনের সময় অ্যাকাউন্টটি লগ আউট হয়ে যাবে। তদন্ত পরিকল্পনা করার সময় এটি মাথায় রাখুন।

04

অ্যাকাউন্ট তৈরি করা

একটি সংখ্যা থেকে প্রথম রেকর্ডকৃত চ্যাট পর্যন্ত।

  1. একটি নম্বর পান

    অ্যাকাউন্ট দীর্ঘমেয়াদে চললে প্রিপেইড সিম বা ই-সিম; স্বল্পমেয়াদী কাজের জন্য ভাড়া বা এককালীন সক্রিয়করণ। পরিষেবাগুলি নিচে তালিকাভুক্ত।

  2. আপনার প্রধান অ্যাকাউন্ট থেকে আলাদা করে নিবন্ধন করুন

    অফিসিয়াল টেলিগ্রাম অ্যাপে আলাদা ডিভাইস, এমুলেটর বা ফোন প্রোফাইলে রেজিস্টার করুন, আপনার প্রধান অ্যাকাউন্টের পাশে নয়।

  3. ক্লাউড পাসওয়ার্ড দিয়ে তা লক করুন

    এখনি একটি ক্লাউড পাসওয়ার্ড এবং এমন একটি পুনরুদ্ধার ইমেইল সেট করুন যা অন্য কোথাও ব্যবহার হয় না।

  4. গোপনীয়তা সেটিংস বন্ধ করুন

    ফোন নম্বর কেউ নয়, আমাকে আমার নম্বর দিয়ে খুঁজে বের করুন আমার যোগাযোগের তালিকা, শেষ দেখা, প্রোফাইল ছবি এবং বায়ো কেউ নয় বা আমার যোগাযোগের তালিকা; যোগাযোগ সিঙ্ক বন্ধ করুন।

  5. এটি স্ব-ধ্বংস থেকে রক্ষা করুন

    অ্যাকাউন্ট স্ব-ধ্বংসকে সর্বোচ্চ সময়সীমায় সেট করুন, যাতে TgWitness বন্ধ হয়ে গেলেও আপনার অ্যাকাউন্ট ক্ষতিগ্রস্ত না হয়।

  6. এটি একটি নিরপেক্ষ প্রোফাইল দিন

    আপনার অন্যান্য অ্যাকাউন্ট থেকে কোনো নাম, ছবি, ব্যবহারকারীর নাম বা বায়ো ব্যবহার করবেন না, কোনো ব্যক্তিগত যোগাযোগ রাখবেন না।

  7. এটি গরম হতে দিন

    প্রথমে দিনে কয়েকটি চ্যাটে যোগ দিন। যারা তাড়াহুড়ো করে নতুন অ্যাকাউন্ট তৈরি করে, তাদের প্রথমে সীমাবদ্ধ করা হয়।

  8. বটদের সাথে কিছুই শেয়ার করবেন না

    বটের জন্য কখনই "ফোন নম্বর শেয়ার করুন" বা "অবস্থান শেয়ার করুন" চাপবেন না। সেই ডিভাইসে VPN বা প্রক্সি ব্যবহার করে লিঙ্ক এবং মিনি অ্যাপস খুলুন।

  9. এটি TgWitness-এ সংযুক্ত করুন

    নিজের ওয়ার্কস্পেসে Account → QR code-এ সংযোগ করুন, তারপর Sources → Investigation mode চাপুন। অ্যাপটি হল যেখানে আপনি কাজ করেন, TgWitness হল রেকর্ড।
