### คัดลอกข้อมูลทั้งหมดไปยังพื้นที่จัดเก็บข้อมูลที่รองรับ S3

บันทึก, ไฟล์, จุดตรวจสอบที่มีเวลาประทับ และข้อมูลการส่งออกการสนทนา — ถูกเข้ารหัสก่อนการอัปโหลดไปยัง AWS S3 หรือพื้นที่จัดเก็บข้อมูลที่เข้ากันได้

**การตั้งค่าการเก็บข้อมูลและการกู้คืน**

การเข้ารหัสฝั่งลูกค้า

`AES-256-GCM` ทำการเข้ารหัสข้อมูลบนเครื่องนี้ ผู้ให้บริการจะรับข้อมูลที่เข้ารหัสแล้ว

การคัดลอกตามกำหนดเวลาหรือแบบมือ

คัดลอกทันที หรือเลือกระยะเวลาตั้งแต่ 1 ถึง 1,440 นาที ตรวจสอบความคืบหน้าในแผงควบคุม

Object Lock

เลือกจำนวนวันเก็บรักษาและโหมดการทำงานเมื่อ bucket รองรับ ฟีเจอร์นี้ แผงควบคุมจะรายงานว่า การเก็บรักษาได้รับการยืนยันแล้วหรือไม่ สำหรับวัตถุที่อัปโหลด

การกู้คืนที่ได้รับการยืนยัน

ดาวน์โหลดกุญแจการเข้ารหัสและเก็บไว้แยกต่างหาก คืนค่าบนเครื่องอื่น; ไฟล์จะถูกเผยแพร่เพียงหลังจากผ่านการตรวจสอบแล้วเท่านั้น

![แผงคัดลอกข้อมูลนอกไซต์แบบครบถ้วน: จุดปลายทาง (endpoint), ภูมิภาค (region), บักเก็ต (bucket), กุญแจเข้าถึง (access keys), ตารางเวลา (schedule), การล็อกวัตถุ (Object Lock) และการควบคุมกุญแจกู้คืน (recovery key controls)](https://phishdestroy.github.io/TgWitness/assets/off-site-copy.png)

แผงควบคุมแบบเต็มที่มีตัวเลือกขั้นสูงถูกขยายออกแล้ว ไม่แสดงข้อมูลรับรองการเข้าถึงพื้นที่จัดเก็บข้อมูล

บันทึกและสื่อ`AES-256-GCM`พื้นที่จัดเก็บข้อมูลที่รองรับ S3

[ตั้งค่า S3 และกู้คืนสำเนา](https://phishdestroy.github.io/TgWitness/th/docs/exports/#s3)[อ่านรายละเอียดการตรวจสอบได้ที่](https://phishdestroy.github.io/TgWitness/th/docs/reference/evidence/#off-site-copy-and-restore-s3)

**ไม่ทำ** ไม่สามารถกู้คืนข้อมูลได้หากไม่มีกุญแจถอดรหัสที่ส่งออก หรือแทนที่พยานอิสระ

### การแจ้งเตือน · Apprise

รับการแจ้งเตือนปัญหา การเปลี่ยนแปลงในแชท และสรุปประจำวันผ่าน Apprise: ผ่านแอปส่งข้อความ อีเมล หรือ webhook JSON ของคุณเอง

ไม่ส่งข้อความข้อความเว้นแต่คุณจะเปิดใช้งานการคัดลอกข้อความ

 [กำหนดจุดหมายการแจ้งเตือน](https://phishdestroy.github.io/TgWitness/th/docs/reference/operations/#notifications)

### ข้อมูลเวลาจากแหล่งภายนอก

แฮชจุดตรวจสอบเวลาตาม RFC 3161 และ OpenTimestamps.

**ไม่ทำ** ไม่ถือว่าใบรับการนัดหมายในปฏิทินที่ยังไม่ได้รับการยืนยันเป็นเวลาประทับของ Bitcoin ที่ได้รับการยืนยันแล้ว

 [ตรวจสอบหลักฐานเวลา](https://phishdestroy.github.io/TgWitness/th/docs/reference/timestamp/)

### พยานอิสระ

เซิร์ฟเวอร์แยกต่างหากจะเก็บรักษาข้อมูลการสังเกตที่ลงนามแล้ว และสามารถเผยแพร่จุดตรวจสอบ`TGW1` ได้

**ไม่ทำ** ไม่ทำให้พื้นที่ทำงานสองแห่งบนโฮสต์ผู้รวบรวมข้อมูลเดียวกันกลายเป็นพยานอิสระ

 [ตั้งค่า witness](https://phishdestroy.github.io/TgWitness/th/docs/witness/)

**ไม่ทำ** ไม่สร้างใหม่ทุกการแก้ไขที่พลาดไปหรือข้อความที่หายไป

ขั้นตอน 02

### เลือกวิธีดำเนินการ

คลิกสองครั้งที่ `Start.cmd` หรือเรียกใช้ใน PowerShell:

```
.\Start.cmd
```

กำลังสำรวจอยู่ใช่ไหม? คลิกสองครั้งที่ `scripts\Demo.cmd` เพื่อดูเดโมแบบแยกส่วน ไม่จำเป็นต้องเข้าสู่ระบบ Telegram

เมื่อใช้ Python 3.11+ และ`venv`:

```
sh start.sh
```

หากต้องการเปิดสมุดบันทึกสมมติแทน ให้รันคำสั่ง `sh start.sh --demo`

เมื่อ Docker กำลังทำงานและ Compose 2.20+ ได้ติดตั้งแล้ว:

```
docker compose up -d --build --wait
docker compose exec tgwitness cat /data/panel-token.txt
```

คำสั่งที่สองจะแสดงโทเค็นของแผงควบคุมส่วนตัวของคุณ โปรดเก็บไว้บนเครื่องของคุณ

เปิด [127.0.0.1:8787](http://127.0.0.1:8787) หลังจากเปิดใช้งาน

สำหรับการติดตั้งจากแหล่งต้นแบบ โทเค็นอยู่ที่ `data/live/panel-token.txt` การลงชื่อเข้าใช้ Telegram สามารถใช้การตั้งค่า API ที่มาพร้อมระบบ หรือคู่กุญแจของคุณเองจาก [my.telegram.org](https://my.telegram.org) [คู่มือการตั้งค่าครบถ้วน ↗](https://phishdestroy.github.io/TgWitness/th/docs/reference/quickstart/)

## ก่อนที่จะเริ่ม

**หน้านี้มีการเชื่อมต่อกับ Telegram หรือไม่?**

ไม่ นี่เป็นหน้าโครงการแบบคงที่ที่มีตัวอย่างและภาพหน้าจอที่สร้างขึ้นเพื่อตัวอย่างเท่านั้น แอปพลิเคชันจริงจะทำงานบนคอมพิวเตอร์หรือเซิร์ฟเวอร์ของคุณ และการลงชื่อเข้าใช้จะเกิดขึ้นที่นั่น

**เครื่องมือนี้สามารถกู้คืนข้อความที่ถูกลบก่อนการบันทึกได้หรือไม่?**

ไม่ TgWitness เก็บรักษาเนื้อหาที่บัญชีของคุณได้สังเกตเห็นในขณะที่กระบวนการเก็บข้อมูลกำลังทำงานอยู่ ภาพถ่ายประวัติในภายหลังไม่สามารถสร้างใหม่การแก้ไขที่พลาดไปหรือข้อความที่ถูกลบได้

**บันทึกทั้งหมดของฉันถูกเข้ารหัสหรือไม่?**

ข้อมูลรับรองบัญชีและข้อมูลลับสำหรับการลงนามถูกเก็บไว้ในคลังข้อมูลที่เข้ารหัส ข้อความและไฟล์แนบในเครื่องจำเป็นต้องใช้ดิสก์หรือโวลุ่มที่เข้ารหัส การส่งออกข้อมูลสามารถเลือกใช้ไฟล์ ZIP ที่เข้ารหัสด้วย AES-256 และป้องกันด้วยรหัสผ่านได้

**เว็บไซต์นี้มีความเกี่ยวข้องกับ Telegram หรือไม่?**

ไม่ TgWitness เป็นโครงการอิสระที่ใช้ Telethon ซึ่งเผยแพร่ภายใต้ใบอนุญาต MIT คุณจะทำการอนุญาตบัญชีของคุณเอง โดยใช้การตั้งค่า API ที่มาพร้อมระบบ หรือคู่ API ของคุณเอง
