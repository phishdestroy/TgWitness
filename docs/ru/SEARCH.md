# Поиск по полному тексту

[Анализ архивов](ANALYSIS.md) · [Локальное распознавание текста и транскрипция](MEDIA-ANALYSIS.md) · [Вики](../wiki/Archive-and-Integrations.md)

**Предварительный просмотр.** В **Журнале** выберите **Наилучшее соответствие · формы слов** рядом с полем поиска.
Результаты ранжируются по алгоритму BM25 и включают другие формы того же слова:
*перевод* находит *переводом* и *переводы*, *transfer* находит *transfers*, китайская
фраза находит без пробелов. **Сначала самые новые · точный текст** сохраняет предыдущий
поиск подстроки по всей записи.

Индекс представляет собой производные данные. Он формируется на основе подписанного журнала, сам по себе никогда не подписывается
и никогда не включается в экспорт. Исходные записи не изменяются.

<a id="search-syntax"></a>
## Синтаксис поиска

| Написать | Результаты поиска |
| --- | --- |
| `перевод карта` | Записи, содержащие оба слова в любой форме |
| `"переводом на карту"` | Именно эта фраза, именно в таком порядке |
| `бонус OR подарок` | Любое из этих слов |
| `перевод -казино` | Записи, в которых отсутствует исключенное слово |
| `example.com` | Домен и его поддомены, в том числе в скрытых ссылках и URL-адресах кнопок |
| `@username`, `t.me/username` | Упоминания и ссылки на аккаунт, а также отправленные им сообщения |
| `#tag` | Хэштег |
| `+79991234567`, адрес кошелька, адрес электронной почты | Одно и то же значение в виде текста или ссылок |
| `from:@username`, `from:123456` | Сообщения от этого отправителя |
| `chat:-1001234567890` | Один чат — это может только ограничить ваш собственный доступ |
| `id:42` | Сохраненные версии сообщения № 42 |
| `since:2026-01-01 until:2026-01-31` | Период наблюдения; дата без указания времени охватывает весь день |
| `kind:edited` | Только изменения (`new`, `snapshot`, `edited`, `recovered`) |
| `source:ocr`, `source:transcription`, `source:all` | Распознанный текст вместо сообщений или наряду с ними |

Предлоги и другие служебные слова игнорируются при наличии других слов.
Похожие буквы, встречающиеся в слове (например, латинская *a* в кириллическом слове), полноширинные
и декоративные символы Unicode, а также невидимые символы нормализуются.

<a id="languages"></a>
## Языки

Язык определяется для каждой записи на основе используемого в ней сценария и букв:

| Сценарий | Сопоставление |
| --- | --- |
| Кириллица | Русские и украинские леммы с использованием [pymorphy3](https://github.com/no-plagiarism/pymorphy3). При отсутствии дополнительного украинского словаря используется упрощённый украинский стеммер |
| латинский язык | Английский стеммер «Snowball»; диакритические знаки игнорируются |
| китайский, японский, корейский, тайский, лаосский, кхмерский, бирманский | Перекрывающиеся пары символов: любая фраза ищется без пробелов. Китайские запросы разбиваются на слова с помощью Jieba |
| Другие сценарии | Точные слова |

Украинский словарь (`pymorphy3-dicts-uk`) распространяется по лицензии GPL-3.0, поэтому он
по умолчанию не устанавливается. Установите его с помощью `pip install "tgwitness[uk-dictionary]"`;
индекс распознает новый анализатор и перестроится самостоятельно.

<a id="where-the-index-lives"></a>
## Где находится индекс

| Режим | Хранение | Использование |
| --- | --- | --- |
| На диске (по умолчанию) | `search/fulltext.sqlite3` в каталоге рабочей области | Крупные архивы; сохраняются при перезапуске |
| Только для чтения | На диске ничего нет; перестраивается при каждом запуске | На диске отсутствует производственная копия текста сообщения |
| Выкл. | Индекс отсутствует; сохраняется сортировка **«Сначала самые новые · точный текст»** | Минимальные установки |

Главный администратор выбирает режим в разделе **Журнал → Фильтры → Поисковый индекс**
для каждой рабочей области. `TGWITNESS_FULLTEXT=disk|memory|off` устанавливает значение по умолчанию для
рабочих областей, у которых нет собственного выбора. Переключение в режим «В памяти» или отключение приводит к удалению файла.
Файл индекса имеет ту же защиту, что и журнал: он находится в каталоге с личными данными
. При создании резервных копий и копий за пределами сайта он не включается.

Новые записи индексируются в фоновом режиме в течение нескольких секунд; при поиске сначала индексируется
небольшой объем неиндексированных данных, поэтому запись, сохраненная буквально минуту назад, будет найдена. Существующий журнал
индексируется после обновления без блокировки панели; до этого момента результаты охватывают
индексированные записи, а в журнале отображается ход выполнения. **Перестроить индекс** начинается заново
с первой записи.

```sh
python -m tgwitness index status --data-dir data/live
python -m tgwitness index rebuild --data-dir data/live --json
```

Для `rebuild` необходимо остановить работу панели (в противном случае код завершения равен 3). В случае с `--json`
в стандартный вывод выводится только результат; информация о ходе выполнения выводится в стандартный поток ошибок.

<a id="results-and-the-signed-journal"></a>
## Результаты и подписанный журнал

Индекс хранит порядковый номер и хеш последней записи журнала, которую он охватывает,
и сверяет их с журналом при его открытии. Замена, восстановление или редактирование
журнала приводит к его перестроению. Каждый ответ сообщает эту позицию, и каждое совпадение
считывается из подписанного журнала по его порядковому номеру: индекс определяет, какие
записи отображать и в каком порядке, но никогда не определяет их содержание. Доступ к чату применяется к
собственному полю чата журнала, а не к содержимому индекса.

<a id="recognized-text"></a>
## Распознанный текст

Результаты OCR и транскрипты хранятся в зашифрованных артефактах. Их индекс существует только в
памяти и восстанавливается по завершении задания распознавания. Результат поиска отображается в записи
`media.saved` с пометкой «автоматическое распознавание», а также указанием движка, модели и
фрагмента текста; он никогда не отображается в виде текста, отправленного в Telegram. Тот же индекс используется для
**поиску распознанного текста**, который по-прежнему также находит совпадения с простыми подстроками.

<a id="access"></a>
## Доступ

Доступ в рамках чата находит только записи из соответствующих чатов, включая распознанный текст
их вложений. `chat:` и другие фильтры могут лишь сузить этот набор. Статус индекса,
отображаемый при доступе в рамках чата, не включает итоговые данные журнала. Только главный администратор может изменить
режим или перестроить индекс.

<a id="ask-the-archive-and-mcp"></a>
## Спросите в архиве и у MCP

Функция **«Дополнительные инструменты → Запрос в архиве»** извлекает данные из этого индекса после его завершения:
наилучшие совпадения по выбранным чатам, при этом сохраненный текст учитывается только один раз. Отправляется до 24
источников; длинные тексты обрезаются вокруг места совпадения и помечаются как усеченные.
Запросы о недавних изменениях, сохраненных версиях одного сообщения и поиски, пока
индекс ещё формируется, используют предыдущий метод поиска по хронологии. В предварительном просмотре
указывается, какой метод был использован.

Клиенты MCP могут вызывать `search_messages` с помощью `ranked=true` и переходить на страницу с помощью
`next_offset`. Соединения с ограниченной областью действия получают только свои чаты.

Пагинация по рейтингу охватывает не более первых 1 000 результатов, независимо от размера страницы. Чтобы просмотреть остальные совпадения, сузьте запрос, тему чата или период поиска. При поиске «Сначала самые новые» сообщения, результаты OCR и транскрипции сортируются перед выбором каждой страницы.

<a id="dependencies"></a>
## Зависимости

| Упаковка | Лицензия | Почему |
| --- | --- | --- |
| pymorphy3, pymorphy3-dicts-ru, DAWG2-Python | MIT | Русские и украинские леммы; словари загружаются локально |
| снежок-стеммер | BSD-3-пункт | Английские стеммы, чистый Python |
| jieba | MIT | Сегментация китайских запросов, на чистом Python (только исходный код) |
| pymorphy3-dicts-uk (необязательно) | GPL-3.0 | Полный украинский словарь |

Требуется модуль SQLite FTS5 с токенизатором `unicode61`; он входит в состав SQLite в
текущих сборках Python. Без него при поиске по наилучшему совпадению выдается сообщение о его недоступности.

<a id="benchmark"></a>
## Тест производительности

`python tools/bench_fulltext.py --messages 1000000 --work <empty directory>`
создает детерминированный подписанный журнал, содержащий сообщения на русском, украинском, английском,
китайском и японском языках со ссылками и идентификаторами в 200 чатах, формирует индекс
и измеряет время выполнения типичных поисковых запросов (50 результатов, медиана по 7 прогонам).

Измерено на Windows 11, процессоре Intel Core i9-13900K, 128 ГБ ОЗУ, Python 3.12.10, SQLite
3.49.1, данные на диске с файловой системой exFAT, анализатор `fulltext-v1+pymorphy3-ru+light-uk+snowball-en`:

| Мера | Результат |
| --- | --- |
| Журнал с автографом | 1 000 000 сообщений, 1,50 ГиБ, записанных за 19 минут |
| Составление указателя на основе журнала | 71 с, около 14 141 сообщений в секунду |
| Индексный файл | 58 МБ, 3,8 % от объема журнала |
| Поиск сразу после добавления новой записи | Медиана — 8 мс, p95 — 9 мс |
| Предыдущий поиск подстроки, тот же журнал | `перевод` 3,2 с, `银行转账` 2,6 с, `verify-account.example` 2,6 с |

| Поиск | Соответствующие записи | Наилучшее соответствие, медиана | стр. 95 | Сначала самые новые, по медиане |
| --- | --- | ---: | ---: | ---: |
| Общее слово, формы слова: `перевод` | 134 403 | 82 мс | 85 мс | 7 мс |
| Два слова: `оплата карта` | 28 996 | 43 мс | 43 мс | 14 мс |
| Редкое слово: `розыгрыш подарок` | 28 881 | 42 мс | 47 мс | 13 мс |
| Точная фраза: `"переказ коштів на картку"` | не учитывается | 35 мс | 36 мс | 6 мс |
| Домен с поддоменами: `verify-account.example` | 12 435 | 17 мс | 17 мс | 3 мс |
| @username: `@support_desk_bot` | 10 331 | 15 мс | 16 мс | 3 мс |
| Китайский текст без пробелов: `银行转账` | 17 691 | 23 мс | 24 мс | 3 мс |
| Японский: `リンク` | 16 603 | 23 мс | 25 мс | 3 мс |
| Английский корень: `withdrawal` | 27 775 | 26 мс | 26 мс | 2 мс |
| ИЛИ и исключение: `бонус OR подарок -казино` | 268 034 | 190 мс | 193 мс | 19 мс |
| Фильтр чата: `chat:-1000000000007 перевод` | 652 | 9 мс | 9 мс | 6 мс |
| Фильтр по периоду: `since:2026-01-01 until:2026-01-31 выплата` | 115 732 | 155 мс | 156 мс | 81 мс |

Точная фраза проверяется буквально по кандидатам в порядке ранжирования до тех пор, пока страница не
заполнится, поэтому её итоговое количество не учитывается. Время выполнения зависит от количества совпадающих записей;
сужение темы чата или периода ускоряет широкий поиск. В синтетическом корпусе повторяется
небольшой словарный запас, поэтому распространённые слова дают гораздо больше совпадений, чем в реальных чатах.
