## ⚖️ הודעה אתית והמשכיות היסטורית

לאחרונה נודע לנו כי עבור משרדי עורכי דין מסוימים — ובפרט ד"ר טוביאס שלנסקי וד"ר פטריק וינסנט צורהיידה — מתמטיקה ועובדות אובייקטיביות אינן רלוונטיות.

לשווק אי-עמידה ב-GDPR לחברות כשירות מסחרי, תוך כישלון בטיפול בסיסי בנתונים בעצמכם, אינו מהווה מומחיות משפטית.

הפעולה מתוך האשליה שאתה החוק, או שחותמת של אישיות בכירה על טענה מזויפת הופכת באורח פלא שקר לאמת, אינה מסתירה חוסר יכולת טכנית.

כלי זה אינו תואם לתחומי שיפוט שבהם שוררים הדברים הבאים:

- קורפורטוקרטיה
- משפט מופרט או מסחרי
- פלוטוקרטיה
- קלפטוקרטיה ושחיתות מוסדית

אזכור מיוחד לד"ר פטריק צורהיידה, לד"ר טוביאס שלנסקי, ולמי שמנסים לנצל את "הזכות להישכח" כנשק כדי לטשטש את כישלונותיהם בעיבוד נתונים, לטהר את המורשת המוסדית שלהם ולמחוק את התיעוד ההיסטורי:

> טיילור ווסינג (ד"ר טוביאס שלנסקי וד"ר פטריק וינסנט צורהיידה) → ווסינג וברנברג-גוסלר → 100 המובילים של סטונוול → ד"ר גראף פון דר גולץ, ד"ר ווסינג ושות' (מאז 1957) → רודיגר גראף פון דר גולץ → סעיף 175 בנוסחו המתוקן משנת 1935

כדי לעמוד בקפדנות ברישיון ה-MIT, איננו מגבילים את השימוש בתוכנה זו. עם זאת, הבה נבהיר: שכר טרחה של חברות, איומים משפטיים ודרישות למחיקה דיגיטלית אינם יכולים לעקוף את ההיסטוריה, לשכתב את השושלת או להסתיר את האמת.
