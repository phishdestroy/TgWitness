# 分享案例

Canonical page: https://phishdestroy.github.io/TgWitness/zh/docs/access/

分享他人需要的案例。其余内容由您掌控。

01**选择证据**

整个工作区或单个聊天。

02**选择操作**

查看、导出，或仅限他们需要的操作。

03**设置限制**

个人令牌，可按需设置有效期、会话限制和 IP 规则。

采集范围决定了记录的内容。访问范围决定了用户可以查看和执行的操作。

## 授予某人访问权限

1. 以管理员身份打开**访问**。
2. 命名，选择工作区和聊天。
3. 审核员只需要**查看**。如需下载请添加**导出**。
4. 设置权限限制，然后点击**“创建访问权限**”。
5. 复制令牌（只显示一次），连同面板地址私下发送。
6. 先在单独的浏览器会话中检查他们会看到什么。

## 从他们需要完成的工作入手

| 人物 | 访问 | 结果 |
| --- | --- | --- |
| 审稿人 | 精选聊天记录；仅限查看 | 阅读聊天，不能更改任何内容。 |
| 分析师 | 精选聊天记录；查看和导出 | 阅读并下载案件所需内容。 |
| 操作员 | 精选的完整工作区；来源与收集 | 决定观察哪些内容，启动和停止采集器。 |

这些只是示例，不是固定角色。限于聊天的访问权限永远不会获得账户设置或完整日志导出。所有工作区的访问权限包括之后添加的账户。

## 您可以随时改变主意

随时可编辑访问权限，从下一次请求起生效。可结束单个会话或全部撤销。已下载的文件无法收回。采集会继续运行。

**会话和 IP 限制**

限制并行会话和登录次数，设置截止日期，允许特定 IP 或子网，或锁定为首次登录的 IP。有效期按不活动时间计算，打开着的面板算作活动。在代理后面时，请检查应用看到的是哪个客户端 IP。

**主密钥和活动日志**

主令牌留在管理员手中。发放的访问权限不能管理他人的访问，也不能打开管理控制台。访问变更和会话会签名写入日志，不包含令牌。服务器管理员仍然可以看到一切。

全部七项权限和会话规则：[访问参考](https://phishdestroy.github.io/TgWitness/zh/docs/reference/access/)。
