# 메시지를 따르십시오. 증거를 이해하십시오.

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/

첫 번째 캡처를 수행하고, 증거가 어떻게 작동하는지 살펴본 다음, 필요한 설정을 구축하십시오.

[대화형 현장 가이드**변화를 만들어 보세요. 증거가 무엇을 포착하는지 확인해 보세요.** 메시지 이력을 확인하고, 기록을 수정하며, 해당 해시를 추적해 보세요. 시각적 가이드 살펴보기](https://phishdestroy.github.io/TgWitness/ko/docs/concepts/) [## 모드, 시나리오 및 증거 수준 수집 범위, 이벤트 경계, 8가지 검증 메커니즘 및 6가지 가상의 조사 시나리오.](https://phishdestroy.github.io/TgWitness/ko/guides/modes.html)

## 처음 캡처된 메시지

[### 몇 분 만에 시작하세요 샘플 데이터를 사용하여 TgWitness를 체험해 본 후, Windows, Linux 또는 macOS에서 나만의 텔레그램 모니터링 작업 공간을 구축해 보세요.](https://phishdestroy.github.io/TgWitness/ko/docs/start/)[### 전용 계정 데이터 수집을 위해 별도의 텔레그램 계정을 준비하십시오.](https://phishdestroy.github.io/TgWitness/ko/docs/dedicated-account/)[### 계정 연결 QR 코드, 전화번호 또는 세션 가져오기를 통해 텔레그램을 연결하세요. 소스를 선택하고 새 메시지가 저널에 정상적으로 수신되는지 확인하세요.](https://phishdestroy.github.io/TgWitness/ko/docs/accounts/)[### 프록시 선택 자동 MTProxy 경로를 유지하거나 사용자 지정 프록시를 사용하세요. IP 모드, 대체 규칙 및 외부 요청에 대한 경로를 선택하세요.](https://phishdestroy.github.io/TgWitness/ko/docs/proxies/)[### 내보내기 및 검증 캡처된 텔레그램 기록을 내보내고, 서명을 검증하며, 저널을 독립적인 증인이 보관하고 있는 체크포인트와 비교할 수 있습니다.](https://phishdestroy.github.io/TgWitness/ko/docs/exports/)[### GitHub Actions 캡처 임시 GitHub 러너에서 텔레그램 채팅 하나를 내보내기.](https://phishdestroy.github.io/TgWitness/ko/docs/capture/)

## 직접 사용해 보며 배워보세요

[### 증거가 어떻게 활용되는지 확인하기 메시지가 캡처된 시점부터 체크포인트에 도달할 때까지의 경로를 추적해 보세요. 샘플 기록을 변경하고, 해당 기록의 SHA-256 체인을 재계산한 후, 보존된 체크포인트가 이를 어떻게 감지하는지 확인해 보세요.](https://phishdestroy.github.io/TgWitness/ko/docs/concepts/)[### 모든 채팅을 대상으로 조사하기 채널, 그룹, 비공개 채팅 및 봇 전반에 걸쳐 텔레그램 종단 간 조사를 수행하세요: 전체 계정 캡처, 기록, 참여자, 링크, 파일, 타임라인 및 검증된 증거.](https://phishdestroy.github.io/TgWitness/ko/docs/cases/)[### 보안을 유지하세요 세션, 키 및 증거가 어디에 저장되는지, 시스템 외부로 전송되는 정보는 무엇인지, 보안 조치가 어떤 범위를 포함하는지, 그리고 설치 환경을 어떻게 강화할 수 있는지 확인하십시오.](https://phishdestroy.github.io/TgWitness/ko/docs/security/)

## 필요한 내용만 추가하십시오

[### 아카이브 활용하기 이력을 불러오고, 저장된 기록을 검색하며, AI 출처를 검토하고, 사용 중인 도구와 연동하세요.](https://phishdestroy.github.io/TgWitness/ko/docs/archive/)[### 사례 공유하기 검토자와 분석가에게 별도의 권한, 세션 제한 및 취소 가능한 토큰을 통해 선별된 계정 및 채팅에 대한 접근 권한을 부여합니다.](https://phishdestroy.github.io/TgWitness/ko/docs/access/)[### Witness 봇 설정하기 별도의 증인(witness), 고유한 키, 읽기 전용 수집기(collector) 액세스 권한을 통해 서명된 기록부 체크포인트를 텔레그램 채널에 게시하세요.](https://phishdestroy.github.io/TgWitness/ko/docs/witness/)[### 계속 운영해 주세요 TgWitness는 영구 저장소, 전용 패널 액세스, 백업 기능 및 재시작 후 점검 기능이 갖춰진 서버에서 실행하십시오.](https://phishdestroy.github.io/TgWitness/ko/docs/server/)[### 문제가 발생한 원인을 파악하세요 각 문제에 맞는 신호를 사용하여 패널 액세스, 텔레그램 연결, 누락된 메시지, FloodWait 및 위트니스 상태를 확인하십시오.](https://phishdestroy.github.io/TgWitness/ko/docs/troubleshooting/)
