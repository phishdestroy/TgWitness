תיעוד / 03

בחר פרוקסי

בחרו מסלול, שמרו אותו ובדקו את החיבור ל-Telegram.

שלוש חיבורים, הגדרות נפרדות

בחרו מרשימה ציבורית

  1. פתח את הגדרות החיבור של החשבון ובחר באפשרות "שנה מסלול חיבור".
  2. בחר MTProxy ציבורי ושמור את המסלול.
  3. הפעל את בדיקת החיבור ל-Telegram. ניתן לבצע זאת לפני הכניסה.

ההתקנה כוללת תמונת מצב של הרשימה הציבורית. רענון מהאינטרנט מביא את העדכונים הציבוריים שהוגדרו. רענון הרשימה שומר על מסלול החשבון הנבחר ללא שינוי. אם מקור מסוים נכשל, הרשימה האחרונה השמישה שלו נשמרת.

השתמש בפרוקסי משלך

הדביקו קישור מסוג tg://proxy?… או https://t.me/proxy?…, או הזינו ידנית את פרטי SOCKS5, HTTP CONNECT או MTProxy. הפסיקו את המעקב לפני שתשנו את נתיב החשבון הפעיל.

הרשומות הציבוריות הן הצעות בלבד, ולא שירותים מאומתים. אם אחד מהם נכשל, בחרו באחר ובדקו שוב. לא מיושמת רוטציה אוטומטית של שרתים.

סודות נתמכים ופרטיות הזרם

MTProxy תומך ב-32 תווים הקסדצימליים וב-dd בתוספת 32 תווים הקסדצימליים. סודות TLS מזויפים המתחילים ב-ee אינם נכללים. עדכונים ציבוריים אינם יכולים לבחור כתובות IP מקומיות או שמורות.

העדכונים מורידים באמצעות חיבור HTTPS נפרד, באופן ישיר כברירת מחדל. הגדר TGWITNESS_PROXY_FEED_PROXY למסלול הורדה באמצעות HTTP/SOCKS5. פרטי הזדהות של הפעלה ואסימוני לוח הבקרה או הבוט אינם נשלחים לספקי הרשימות. TGWITNESS_PROXY_CATALOG מחליף מנויים ציבוריים בקטלוג מקומי המנוהל על ידי המפעיל.

ל-Witness יש הגדרות רשת משלו

MTProxy מיועד לחשבון Telegram שאוסף את הנתונים. בוט ה-Witness משתמש בהגדרות HTTP/SOCKS5 ובאופן אופציונלי, בנקודת קצה של Bot API משלך.
