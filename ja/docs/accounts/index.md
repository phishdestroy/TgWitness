# Telegram · アカウントを連携する

Canonical page: https://phishdestroy.github.io/TgWitness/ja/docs/accounts/

1 ワークスペース = 1 アカウントと、そのジャーナルと鍵。

## ログイン方法をお選びください

**アカウント** → ワークスペースを追加 → 接続設定。この用途には別のアカウントを使ってください。

- **QR コード：**Telegram の「デバイス」画面でスキャンし、確認します。
- **電話番号：**番号、コード、2 段階認証があればそのパスワード。
- **セッションのインポート：**自分のセッションファイル、または Telegram Desktop のデータ。

組み込みの API プロファイル、または独自の API ID とハッシュを使います。これはアプリを識別するだけで、ログインさせたり何かを隠したりはしません。

**まずプロキシが必要ですか？**

ログインする前に、[接続経路を選択してテスト](https://phishdestroy.github.io/TgWitness/ja/docs/proxies/)することができます。各アカウントには独自の経路が割り当てられています。

## 監視対象を選択してください

1. 必要なチャット、グループ、チャンネルを選びます。
2. メディアを含む収集設定を確認します。
3. 起動し、接続と最近のアクティビティを確認します。

アカウントにアクセス権が必要です。管理者とメンバーでは見えるものが違い、ジャーナルにはこのアカウントが受け取ったものが表示されます。

アカウント全体なら、**ソース → 観察範囲 → 調査モード**を確認して**範囲を保存**します。詳しい手順：[アカウント全体の調査](https://phishdestroy.github.io/TgWitness/ja/docs/cases/)。

## パス全体をご確認ください

テストグループで、別のアカウントからメッセージを送り、編集し、削除します。3 つともジャーナルに表示されるはずです。その後[エクスポートして検証](https://phishdestroy.github.io/TgWitness/ja/docs/exports/)します。

「接続済み」は接続が機能しているという意味です。テストメッセージが記録されれば、イベントが実際に届いています。

## 別のアカウントを追加する

**アカウント**で新しいワークスペースを作り、同じ手順を行います。後でエクスポートを区別できるよう、各アカウントの鍵のフィンガープリントを控えておいてください。
