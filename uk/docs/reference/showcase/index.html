Публічна вітрина

Публікуйте збережені повідомлення з обраних публічних каналів та підписані знімки за допомогою посилань з обмеженим терміном дії, які можна скасувати.

«Доступ → Публічна вітрина» створює окрему сторінку, доступну лише для перегляду, використовуючи існуючу систему access-token. Вона зчитує збережені спостереження інсталяції. Вона не запускає колектор, не входить у Telegram і не отримує доступ до каналу для відвідувача.

Опублікувати сторінку#

  1. Збережіть профіль джерела для кожного публічного каналу, який ви хочете показати. Канал повинен мати публічне ім’я користувача в своєму останньому збереженому профілі; групи та приватні чати не підходять.
  2. Відкритий доступ → Публічна вітрина (або /showcase-manage.html) як адміністратор.
  3. Виберіть канали з максимум 16 робочих просторів, введіть назву публічної сторінки та виберіть термін дії посилання: 1, 7 або 30 днів. Внутрішні назви робочих просторів не публікуються. Можна додати до 64 каналів.
  4. Перегляньте текст вибраних каналів для публікації, а потім натисніть «Перегляд вибраних записів». У попередньому перегляді використовується та сама серверна проекція, що й на сторінці відвідувача.
  5. Натисніть «Створити посилання на вітрину». Скопіюйте посилання, поки воно відображається. Відкрийте його в окремому браузері, щоб переглянути сторінку одержувача перед її поширенням.

Посилання містить токен доступу у фрагменті URL-адреси. Сторінка видаляє цей фрагмент перед надсиланням запитів до API та замінює його сесією браузера. Будь-хто, хто має це посилання, може відкрити вибраний матеріал до закінчення терміну дії або скасування доступу. Нові посилання дозволяють 100 одночасних сесій, кожна з яких триває не більше однієї години. Існуючі засоби контролю доступу також можуть застосовувати обмеження за адресами та ліміти входу через API grant. Звичайний доступ рецензента — це інший режим, який, як і раніше, включає оригінальні дозволені повідомлення та файли.

Текст публічних повідомлень не анонімізується автоматично. Ім’я, згадка, номер телефону або посилання, вказані в повідомленні, залишаються частиною цього тексту. RedactedЦе стосується структурованих полів автора/профілю. Перегляньте фактичний вибраний вміст перед публікацією, включаючи збережені редагування та видалення.

Відповідність критеріям відображає останній збережений профіль джерела, а не поточний запит у Telegram. Якщо наступний профіль більше не містить імені користувача публічного каналу, нові запити виключають цей канал. Оновлюйте профілі джерел, коли змінюється публічна видимість. Читачі можуть вже мати збережені матеріали, які вони отримували раніше.

Оригінальні підписані записи залишаються незмінними. Відображувана проекція підписується окремо та містить хеші, що посилаються на її оригінальні записи. Підпис проекції підтверджує автентичність відображеного твердження; це не підпис оригінальної події над відредагованими байтами.

Перевірка підписів та цілісності#

Розгорніть «Fingerprint & signed checkpoint» та завантажте знімок. Після оновлення сторінки завантаження включає попередній знімок браузера та доказ узгодженості за алгоритмом Меркла між межами їхніх журналів. Автоматичне оновлення відбувається раз на хвилину, поки сторінка відображається та показує першу сторінку спостережень.

Після встановлення TgWitness перевірте завантажений файл в автономному режимі:

python -m tgwitness.showcase_verify showcase.json --fingerprint TRUSTED_COLLECTOR_SHA256

Відбиток повинен походити з окремого надійного джерела. Щоб порівняти з знімком, який ви зберегли самостійно, використовуйте --previous earlier.json; це замінить попередній знімок, що міститься у завантаженому файлі. Поточний доказ повинен починатися з цієї збереженої межі. Авторизовані клієнти можуть запросити цей доказ за допомогою GET /api/showcase/{workspace_id}?challenge=<32-hex-random>&from_count=<retained-count>. Коротший журнал повертає код статусу HTTP 409 замість того, щоб мовчки скинути межу.

Підписана контрольна точка фіксується у всьому журналі колектора, включаючи його кількість записів та непрозорий хеш заголовка. Відображувана кількість повідомлень стосується лише вибраних публічних каналів. На сторінці ніколи не відображається вміст інших журналів. Це кількість подій, а не кількість унікальних повідомлень. Налаштування описують поточну конфігурацію, а не кожен попередній інтервал запису.

Перевірка підпису та узгодженості дозволяє виявляти зміни відносно збереженої межі. Вона не здійснює самостійного перерахунку підписаних лічильників, не підтверджує походження Telegram, не демонструє безперервність запису та не замінює незалежного свідка. Для такого аналізу використовуйте верифікатор доказів, незалежного свідка та перевірений запис у масштабі. Синтетичні інсталяції помітно позначені як синтетичні.

Скасувати або розмістити сторінку#

Скористайтеся функцією «Скасувати» у менеджері вітрин або в існуючому розділі «Доступ», щоб закрити посилання та завершити всі сесії за ним. Відвідувач очищає відображені записи, коли запит виявляє, що доступ завершився. Термін дії та дозволи перевіряються під час кожного запиту. Дозволи на вітрини не можна перетворити на звичайний доступ до панелі на місці; створіть новий дозвіл, щоб змінити режим.

Сторінка надається через існуючу HTTPS-адресу інсталяції. Публікація посилання не відкриває новий порт, не створює тунель і не змінює DNS. HTML та API залишаються на інсталяції користувача. Відвідувач демонстраційної версії не може використовувати звичайні API для повідомлень, профілів, медіа, експорту чи управління з таким доступом.
