# Telegram · 사례 공유하기

Canonical page: https://phishdestroy.github.io/TgWitness/ko/docs/access/

누군가에게 필요한 사례를 공유하세요. 나머지는 직접 관리하세요.

01**증거 선택**

작업 공간 전체 또는 개별 채팅.

02**작업 선택**

보기, 내보내기, 또는 필요한 작업만.

03**한도 설정**

원하면 만료, 세션 제한, IP 규칙이 있는 개인 토큰.

수집 범위에 따라 기록되는 내용이 결정됩니다. 접근 범위에 따라 사용자가 볼 수 있는 내용과 수행할 수 있는 작업이 결정됩니다.

## 사용자 접근 권한 부여

1. 관리자로 **액세스**를 엽니다.
2. 이름을 붙이고, 작업 공간과 채팅을 고릅니다.
3. 검토자에게는 **보기**만 있으면 됩니다. 다운로드가 필요하면 **내보내기**를 추가합니다.
4. 한도를 설정한 후 **‘액세스 생성’을** 누르세요.
5. 토큰을 복사하고(한 번만 표시됨) 패널 주소와 함께 비공개로 보냅니다.
6. 먼저 별도의 브라우저 세션에서 그들이 무엇을 보게 될지 확인합니다.

## 그들이 수행해야 할 업무부터 시작하세요

| 인물 | 접근 | 결과 |
| --- | --- | --- |
| 검토자 | 선택된 채팅; 보기 전용 | 채팅을 읽고, 아무것도 바꿀 수 없습니다. |
| 분석가 | 선택한 채팅: 보기 및 내보내기 | 사건에 필요한 것을 읽고 다운로드합니다. |
| 운영자 | 선별된 전체 작업 공간; 출처 및 수집 | 무엇을 관찰할지 정하고, 수집기를 시작하고 멈춥니다. |

이것은 예시일 뿐 고정된 역할이 아닙니다. 채팅으로 제한된 액세스는 계정 설정이나 전체 저널 내보내기를 결코 얻지 못합니다. 모든 작업 공간 액세스에는 나중에 추가된 계정도 포함됩니다.

## 언제든지 마음을 바꿀 수 있습니다

액세스는 언제든 수정할 수 있고, 다음 요청부터 적용됩니다. 세션 하나를 끝내거나 모두 철회하십시오. 이미 다운로드된 파일은 되돌릴 수 없습니다. 수집은 계속됩니다.

**세션 및 IP 제한**

동시 세션과 로그인 수 제한, 종료 날짜 설정, IP나 서브넷 허용, 또는 첫 로그인 IP에 고정할 수 있습니다. 만료는 비활성 시간으로 계산하며, 열려 있는 패널은 활성으로 칩니다. 프록시 뒤에서는 앱이 어떤 클라이언트 IP를 보는지 확인하십시오.

**마스터 키 및 활동 로그**

메인 토큰은 관리자가 가집니다. 발급된 액세스는 다른 사람의 액세스를 관리하거나 관리자 콘솔을 열 수 없습니다. 액세스 변경과 세션은 토큰 없이 저널에 서명되어 기록됩니다. 서버 관리자는 여전히 모든 것을 볼 수 있습니다.

일곱 가지 권한과 세션 규칙 전체: [액세스 참조](https://phishdestroy.github.io/TgWitness/ko/docs/reference/access/).
